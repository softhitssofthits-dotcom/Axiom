# Elite on Axiom — рабочий журнал проекта

**Рабочее название:** Elite on Axiom (только рабочее; до публичного релиза название, оформление и контент подлежат отдельной проверке).
**Задание:** концепт «ELITE ON AXIOM» от 2026-10-30 (космическая игра в эстетике Elite 1984, целиком на языке Axiom, графика через `CANVAS`/`DRAWLINE`).
**Расположение проекта:** `samples/graphics/game/elite_project/` (все исходники `.axm` в одной папке — действующий договор модулей Axiom).

## Почему журнал отдельный

Журнал ведётся **внутри проекта** по решению автора от 30.10.2026: параллельно с этой работой другой агент ведёт общие документы репозитория (`docs/WORKLOG5.md`, `docs/PLANS4.md`), и одновременные записи в них создавали бы конфликты. Поэтому:

- этот журнал — единственное место текущих записей проекта Elite on Axiom;
- общие документы репозитория (`docs/WORKLOG5.md`, `docs/PLANS4.md`, `docs/plans/UNFINISHED_WORK.md`) этой сессией **не изменяются**; сводная запись в общий журнал будет добавлена только по отдельному решению автора, когда параллельная работа завершится;
- правила качества (тесты, честные отчёты, `.axm`-приёмка) применяются как в `AGENTS.md`, но фиксируются здесь.

## Обязательные требования автора к коду проекта

1. **Обильные комментарии на русском языке** в каждом файле: поясняются назначение блоков, математика, игровые правила и важные шаги.
2. **Разметка `#region` / `#endregion` в комментариях** для крупных смысловых секций каждого модуля (если нативной директивы в языке нет — как комментарии).
3. **Многофайловый модульный проект**: логическое разделение по подсистемам (конфиг, математика, мир, рендер, ввод, HUD, игровые состояния), один файл — одна ответственность; никакого гигантского `main.axm`.

## Ограничения, принятые к сведению

- Модули Axiom: файл = модуль, `IMPORT` в начале файла, `PUBLIC`/`PRIVATE`; все исходники в одной папке; вложенные папки с кодом не поддержаны.
- Массивы: квадратный договор — `DIM a[] AS T`, `a[i]`, `a[]` целиком; литералы `[...]`; вложенных массивов нет.
- `ELAPSEDSECONDS()` — монотонные часы для игрового цикла; `TIMER` для длительностей не предназначен.
- Присваивания составных значений создают независимые копии; `BYREF` — явный.
- Публичный экспорт включает `samples/` целиком (`config/public-export.json`) — судьба этой папки в публичном зеркале решается автором отдельно.

## Elite-3 - 2026-10-30 20:41 - Исследование алгоритмов Elite завершено (Этап 0, часть 2)

Фоновый веб-агент прочитал карту исходников 6502SP, профильные deep dives bbcelite.com и полный текст txtelite.c. Полный справочник с формулами и ссылками сохранён в [RESEARCH_ELITE_2026-10-30.md](RESEARCH_ELITE_2026-10-30.md). Ключевое для проекта:

- **Модель полёта:** ориентация тремя базисными векторами (нос/крыша/крыло), только pitch и roll, поворот приближением малых углов (алгоритм Минского) с периодической ортонормализацией; «вращается вселенная», не корабль; скорость сохраняется (инерция). Наша реализация использует перестройку базиса из углов Эйлера каждым шагом — эквивалентный принцип без дрейфа, собственный код.
- **Проекция:** `экран = центр ± k·(x/z)`; экранные координаты допускают выход за экран; отсечение ближней плоскости — параметрическое деление ребра (тот же принцип реализован в `math3d.ProjectEdge`).
- **Модели:** вершины/рёбра/грани с нормалями; отбор задних рёбер по нормалям граней — осознанно отложен (этап 1 рисует прозрачный каркас).
- **Галактика (этап 2):** 8×256 систем из одного 6-байтового семени, twist-переход `s2' = s0+s1+s2`, параметры системы из битов семян, имена из диграмм. **Копировать нельзя:** таблицу слогов, стартовые семена, имена — только метод.
- **Экономика (этап 3):** цена `= (базовая + колебание AND маска + экономика×градиент)×4`, количество `= (базовое + колебание − экономика×градиент) AND 0x3F` (знаковая асимметрия делает бедные системы дешёвыми производителями); покупка/продажа по одной цене; топливо 0.2 CR/LY, бак 7 LY. Таблицу товаров — свою.
- **Радар (этап 2):** проекция без перспективы, пунктирный «стик» высоты по Y; **бой (этап 4):** попадание = центр цели в радиусе прицела без разброса, ИИ по состояниям энергии; **цикл:** главный + полётный из 16 частей.
- **Правовые границы:** метод свободен, данные защищены; название «Elite» не использовать в релизе.

Предложение платформе: включать буквы в очередь нажатий либо задокументировать ограничение в keyboard-mouse-events.html.
