## Формат Master Feature Registry

Каждая feature:
```
LANG-0042:
CATEGORY: String
FEATURE: MID function
USER-VISIBLE: YES
SYNTAX: MID(string, start[, length])
SIGNATURE: MID(STRING, INTEGER[, INTEGER]) → STRING
TYPE: Built-in function
PARSER: YES (CallExpressionSyntax)
BINDER: YES (BuiltinFunctionId.Mid)
INTERPRETER: YES (Interpreter.Builtins.String.cs)
BYTECODE_VM: YES (BytecodeVm.Builtins.String.cs)
IDE: YES (highlighting + completion)
TESTS: YES (InterpreterTests.String.cs)
SAMPLES: YES (samples/functions/mid/)
DOCUMENTATION: YES (docs/manual/string-functions-slices-and-length.html)
STATUS: IMPLEMENTED
MATURITY: MATURE
DEPENDENCIES: STRING type
EVIDENCE: code + test + sample + docs
CONFIDENCE: CONFIRMED
NOTES: —
```
