## Как отличать результаты

* **Ошибка исправлена:** существующий договор был нарушен; есть воспроизведение и проверка после исправления.
* **Возможности действительно нет:** существующий API не решает задачу в требуемом общем виде. Это ещё не решение добавить её в язык.
* **Есть существующий способ:** например, альфа-канал атласа, пользовательская функция расстояния, целочисленный случайный индекс или полная перезапись небольшого текстового файла. Ограничения способа должны оставаться явно указанными.
* **Отложено или не требуется сейчас:** неподдержанные формы Tiled и расширения без подтверждённой задачи продукта. Молчаливое принятие исправлено, само расширение не реализовано.
* **Не проверено:** нет достаточного доказательства конкретной формы; нельзя заменять его общим зелёным тестом семейства.

Подробный реестр кандидатов: [API_GAP_STATUS_20261009.md](docs/audit/API_GAP_STATUS_20261009.md). Общий аудит языка **не завершён**.

## С чего продолжить на другом компьютере

1. Получить свежую ветку master из origin. Если рабочая копия чистая, использовать `git pull --ff-only`; чужие локальные изменения не стирать. Коммит, содержащий этот файл, — точка передачи.
2. Прочитать AGENTS.md, PROJECT.md и обязательные проектные документы в установленном порядке; затем этот файл и последние записи WORKLOG5.md / PLANS4.md. Верх старых документов может описывать более раннее состояние.
3. Проверить заключительный результат в AUDIT_VALIDATION_20261009.json. Тайловую часть повторно не начинать без нового воспроизведения.
4. Следующий логичный шаг общего аудита: сопоставить оставшиеся формы матрицы 335 форм с отдельными CSV-доказательствами и выбрать одну ещё не подтверждённую форму Unicode, файловой системы или числовых границ. Не считать UNVERIFIED_PER_FORM закрытым только из-за найденного кандидата теста.
5. Для выбранной формы отдельно доказать: ошибка, отсутствующая возможность, существующий альтернативный API или отсутствие необходимости для Axiom. Затем исправлять только подтверждённый случай с тестом, русским .axm-примером, руководством и записью в журнале.

Готовая команда для новой сессии: «Продолжи аудит по AUDIT_HANDOFF.md. Прочитай точку остановки и последние записи документов. Текущая тайловая часть закончена; выбери следующий незавершённый пункт с учётом Unicode, файлов и чисел».
