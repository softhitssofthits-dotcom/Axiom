# Axiom IDE

Axiom — BASIC-подобный язык с компиляцией в байт-код и настольная IDE на Electron. Ядро языка и служебный процесс написаны на C#/.NET 10; редактор использует Monaco, консоль — xterm.js.

## Подготовка и запуск

Текущий рабочий способ запуска из исходников требует Windows, .NET SDK 10 и Node.js/npm. Из корня репозитория выполнить последовательно:

```powershell
npm ci --prefix ide
npm ci --prefix ide/e2e
dotnet build src/Axiom.Cli -c Release
dotnet build src/Axiom.DesktopHost -c Debug
.\run-ide.bat
```

`run-ide.bat` проверяет наличие и свежесть DesktopHost, затем запускает Electron. Сборки .NET используют `.artifacts/bin` и `.artifacts/obj`; команды с общей промежуточной папкой выполняются последовательно. Поставка для компьютера без SDK/Node пока не принята.

## Работа с программой

Открыть файл `.axm` в IDE, проверить исходник, затем запустить его. Поддержаны отдельные документы, три темы (светлая, тёмная, QuickBASIC), диагностика во время набора, форматирование Classic/Modern, дополнение, вывод, `INPUT`, графика и трассировка. `CANVAS` открывается нативным окном DirectX служебного процесса: игровые кадры рисуются и показываются на GPU, при недоступности подходящего устройства используется WARP. `SCREEN` сохраняет нативное окно и CPU-рисование старых примитивов. Язык исполняет `BytecodeVm`.

Сохранение проверяет исходную версию файла и пишет под исключительным дескриптором. Внешние изменения требуют решения пользователя. После аварии восстанавливаются завершённые правки, безымянные и отсутствующие документы, выбранная вкладка; программа автоматически не запускается. Восстановление не включает историю отмены и точки останова. Подробности: [результат сохранности документов](docs/reports/electron/ELECTRON_LOCKED_SAVE_RECOVERY_RESULT.md).

## Проверки


Каталог Electron содержит 96 сценариев в 29 файлах. Просмотр каталога не запускает приложение:

```powershell
node ide/e2e/runner.js --list
npm --prefix ide/e2e test
node ide/e2e/runner.js files.spec.js
```

Подготовка, изоляция и ограничения: [инструкция набора](ide/e2e/README.md). Полный прогон Session 1379 — 96/96 и 546 утверждений, без ошибок страницы; [сохранённый результат](ide/e2e/evidence/electron-active-queue-results.json). Это не аппаратная приёмка всех DPI и мониторов.

Проверка документации и действующего реестра:

```powershell
dotnet run --project scripts/language-audit/Axiom.LanguageAudit.csproj -- C:/Axiom --inventory-only --output-dir .artifacts/language-inventory-current
node scripts/check-manual.mjs --inventory .artifacts/language-inventory-current/inventory.json
powershell -NoProfile -File scripts/ai-context.ps1 -StdoutOnly
```

Проверки языка и служебных компонентов: `dotnet test Axiom.sln` (последовательный запуск). Проверка CLI без исполнения: `dotnet run --project src/Axiom.Cli -- check samples/smoke/bytecode-only/compiler_execution.axm --json`.

## Версии

Номера языка, компилятора и IDE независимы и задаются в [versions.json](versions.json). Текущие номера и изменения — в [истории версий](docs/CHANGELOG.md), порядок повышения — в [VERSIONING.md](docs/VERSIONING.md). Начальная основа новой нумерации — 0.1.0; дальнейшие правки повышают затронутые компоненты.

```powershell
node scripts/versioning.mjs install-hooks
node scripts/versioning.mjs check
node scripts/versioning.mjs bump ide patch "Описание исправления IDE"
```

Обработчик Git проверяет версии перед коммитом, GitHub Actions — при публикации. `npm --prefix ide run prepare` подключает локальный обработчик автоматически. В «Справка → О программе» отображаются IDE, язык Axiom и компилятор/CLI без Git-ревизии.

## Переносимая папка приложения

На компьютере разработчика выполнить `node scripts/package-ide.mjs`. Результат: `.artifacts/distribution/Axiom IDE/Axiom IDE.exe`. Переносить всю папку; пользователь запускает exe без установки SDK, Git и Node.js. В составе находятся справочник и примеры. Адресная автоматическая проверка копии по пути с кириллицей/пробелами и недоступными инструментами разработки: `node ide/e2e/portable-smoke.cjs`. Выпуск предназначен для Windows x64; установщик и другие платформы этой командой не создаются.

## Параметры редактора

Параметры открываются командой «Настройки» справа на строке меню или сочетанием Ctrl+,. Диалог содержит восемь вкладок, поиск по всем настройкам, русские и английские пояснения при наведении и фокусе, а также предпросмотр шрифта и темы. Закреплённые строки отключаются на вкладке «Прокрутка и обзор». «Применить» сохраняет изменения без закрытия окна; «ОК» сохраняет и закрывает; «Отмена» отбрасывает изменения после последнего применения. Выбранные параметры сохраняются между запусками. Подробности: [договор диалога](docs/plans/EDITOR_SETTINGS_DIALOG.md).
