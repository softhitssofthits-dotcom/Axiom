# Помощник по подпрограммам

Реализованы связи вызовов по данным компилятора, история переходов, отметки актуальных диагностик, просмотр только для чтения и создание/переименование разделов. Вложенные функции и перегрузки различаются; обработчики, ссылки и косвенные вызовы обозначаются отдельно. Статический анализ не определяет фактические значения и выполненные ветви.

На Maze Chase: контекстное меню StepWalker → «Кто вызывает» показывает два места вызова из UpdateGameStep. Alt+← возвращает к предыдущему положению редактора.

Проверки: 18 сценариев Electron, 253 успешных утверждений; 38 проверок Node.js; последовательная сборка DesktopHost Debug без ошибок и предупреждений. В сценарии documents-outline-crlf-string-comments зарегистрирована ошибка страницы в shell.js: traceCommand читает command у undefined; все четыре утверждения сценария прошли. Остальные выбранные сценарии без ошибок страницы. Полный каталог Electron не запускался. Результаты сохранены в ide/e2e/evidence/program-assistant-*-results.json.

Исправлена обработка запоздалой потери захвата указателя при последовательном изменении размеров панелей; добавлена проверка воспроизведения.

Версии: язык 0.1.13, компилятор 0.1.13, IDE 0.5.0. Исходное состояние опубликовано коммитом e5902ee; новые возможности находятся в рабочей копии.

## Проверка traceCommand — 15 октября 2026 года

Помощник опубликован коммитом 2397168; прежняя фраза о рабочей копии описывает состояние до этой публикации.

Ошибка traceCommand воспроизведена в настоящей Electron IDE: shell.js создавал активные кнопки раньше, чем асинхронная инициализация AxiomIDE создавала TraceController. Проверка ранних событий восьми кнопок дала восемь ошибок обращения к command у undefined. Исправлено начальное состояние девяти кнопок и пунктов меню; обработчик кнопок проверяет наличие контроллера. После создания контроллера доступность определяется прежними условиями.

IDE 0.5.1. Новый сценарий shell-trace-startup-readiness прошёл 6 утверждений, включая работу точек останова после готовности. Исходный documents-outline-crlf-string-comments прошёл 4 утверждения без ошибок страницы; shell-responsive-commands — 19. DesktopHost Debug пересобран без ошибок и предупреждений. Во всех четырёх запущенных сценариях ошибки страницы отсутствуют.

Сценарий shell-toolbar-history-and-panel-state остановился после 29 успешных утверждений на ожидании бирюзового наведения неактивной вкладки Pascal. Ожидание устарело относительно серого цвета, принятого в Session 1447 и IDE 0.4.11. Полный набор не запускался. Доказательства: ide/e2e/evidence/trace-startup-results.json, trace-shell-results.json и trace-outline-results.json. Следующие шаги: согласовать прежнюю проверку оформления с принятым цветом и провести авторскую приёмку помощника на Maze Chase.
