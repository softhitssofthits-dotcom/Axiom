# Приёмка рабочих каталогов запуска — 16 октября 2026 года

## Проверяемый договор

ProgramRunService вычисляет ResourceBaseDirectory из полного пути запускаемого файла перед каждым Run. ExecutionRuntimeHostAdapter создаётся с этой базой и хранит собственный CurrentDirectory; CHANGEDIR меняет его, а не Environment.CurrentDirectory процесса. Файловые операции VM разрешают относительные пути от CurrentDirectory. Скомпилированная программа не хранит изменяемый рабочий каталог запуска.

В этом этапе реализация не изменялась. Дефект переноса каталога между проверенными запусками не подтвердился. Закрыт пробел доказательств через настоящую Electron IDE и DesktopHost.

## Проверки Electron

Добавлен ide/e2e/specs/execution-directories.spec.js. Проверочные программы и ресурсы создаются в изолированной .artifacts с кириллицей и пробелами в путях; пользовательские файлы не используются.

1. Одинаковый исходник расположен в двух папках. Файлы marker.txt в корнях и вложенных папках содержат разные заранее заданные строки. Последовательность запуска: первая папка, вторая, снова первая. Для каждого запуска сравнивается весь вывод: начальный CURRENTDIR, содержимое корневого marker.txt, успешный CHANGEDIR, новый CURRENTDIR, содержимое вложенного marker.txt и результат WRITEFILE. Проверяются точные байты записанного файла, отсутствие записи в корне и отсутствие диагностики. Рабочий каталог процесса Electron сохраняется. Итог: 13 утверждений.
2. После успешного CHANGEDIR попытка перехода в отсутствующую папку выдаёт перехваченный MB3007 и сохраняет прежнюю папку. Следующая необработанная ошибка чтения завершает программу. Повторный запуск из той же папки начинает с её корня и очищает диагностику. Затем дважды проверяется Stop во время INPUT после CHANGEDIR: следующие запуски из первой и второй папок получают собственные корни и ресурсы. Итог: 8 утверждений.

Окончательный результат: **2/2 сценария, 21 утверждение**, без отказов и ошибок страниц. Доказательство: ide/e2e/evidence/execution-directories-results.json. Ранний запуск до добавления явной проверки непосредственно после ошибки дал 19 утверждений; окончательный результат содержит расширенные 21.

## Границы и продолжение

Событие execution.finished не публикует факт попадания в кэш; оконные сценарии не объявляются измерением числа попаданий. Повторное использование одного скомпилированного объекта с разными базами отдельно подтверждено существующим тестом RunCompiled_ReusedProgramDoesNotReuseWorkingDirectory.

Проверены текстовые ресурсы и рабочие каталоги. Загрузчики изображений/TILEMAP, сетевые/отключённые тома, ссылки и все виды путей Windows не проверялись. Строка IDE28 остаётся частичной с конкретным доказательством вместо отсутствующей приёмки. Полный набор .NET и весь каталог Electron не запускались. Каталог расширен с 423 до 425 сценариев.

Существующий ручной пример: samples/functions/changedir/program_directory_scope.axm. В этом этапе он не изменялся и отдельно через Electron не запускался; приведён как вход для ручной проверки существующего договора.
