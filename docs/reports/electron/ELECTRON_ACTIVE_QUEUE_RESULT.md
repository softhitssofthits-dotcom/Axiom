# Действующая очередь Electron — 11 октября 2026 года

Работа Session 1379 охватывает весь раздел очереди; завершённые условия удаляются из UNFINISHED_WORK, неподтверждённые остаются там. Весь раздел пока не объявляется завершённым: аппаратная приёмка, отдельный чистый компьютер и оставшиеся условия матрицы требуют собственных результатов.

## Подтверждённые изменения

- Бесконечная блокировка renderer воспроизведена настоящим `while (true) {}`. Независимый диалог основного процесса позволяет продолжить ожидание, остановить программу и восстановить интерфейс либо остановить и выйти. Перехваченный запрос закрытия проверяет ответ renderer по таймеру; доступная отмена не зависит только от события `unresponsive`.
- Восстановление освобождает собственные DesktopHost/PTY и графические окна. Текст завершённых правок восстанавливается из целого снимка; автоматического повторного запуска VM нет. Авария во время уже открытого диалога сразу останавливает VM. Поздний ответ после возобновления интерфейса не уничтожает работающее окно.
- Фоновая проверка ошибочно вызывала Monaco `closeMarkersNavigation` при отсутствии видимого окна диагностики и отнимала фокус у INPUT. Теперь закрывается только видимое окно диагностики с сохранением внешнего фокуса. Отдельный сценарий воспроизводит ввод во время живой проверки.
- Реальный Windows-атрибут «только чтение» учитывается при открытии документа: редактор не позволяет правку и форматирование. Неподдерживаемый текстовый файл также не форматируется.
- Все девять кнопок трассировки переносятся на следующую строку при узком окне. Проверка границ учитывает дробную ширину CSS на системном DPI.
- Проверены выделение, прокрутка и независимая отмена между вкладками; Ctrl+F/F3/Shift+F3 и оборачивание; переходы SUB/FUNCTION/TYPE при CRLF, строках, REM и апострофах; отмена SaveAs и закрытие пустого нового документа.

## Переносимая поставка

Команда `node scripts/package-ide.mjs` публикует собственные CLI и DesktopHost для Windows x64 с включённой средой .NET и собирает `.artifacts/distribution/Axiom IDE`. Запуск — `Axiom IDE.exe`; переносить нужно всю папку. Справочник и примеры включены. Это переносимая папка, не установщик.

`node ide/e2e/portable-smoke.cjs` копирует выпуск в отдельную папку с кириллицей и пробелами. В окружении приложения недоступны команды SDK/Git/Node и задан отсутствующий DOTNET_ROOT. Получено 11 успешных утверждений: версии, русский INPUT, реальный пиксель CANVAS, видимый нативный SCREEN, остановка и продолжение трассировки, наличие справочника, отсутствие ошибок страницы. Результат сохранён отдельно от полного набора Electron.

Этот опыт не заменяет запуск на другом чистом компьютере Windows: проверка была выполнена на текущей машине с ограниченным окружением приложения. Автор решил не проводить отдельный тест на другом компьютере; это ограничение доказательств сохранено в IDE51 и не считается пройденной проверкой.

Адресный сценарий IDE09 `documents-find-replace-options-undo` прошёл: 1 сценарий, 5 утверждений, 0 отказов. Проверены регистр и целые слова, отсутствие изменений при ошибочном regex, замена regex и отмена Replace All одной командой Undo.

## Положение системных диалогов

Автор обнаружил, что при сохранении нового документа окно выбора пути появилось позади Axiom IDE. Причина подтверждена: `showSaveDialog` вызывался без родительского окна. Save As, выбор исходного файла/папки проекта и подтверждение конфликта теперь получают окно-владелец Electron. Регрессионный сценарий до исправления провалился на отсутствии владельца; после исправления проверено владение окном и отмена диалога.

По снимку автор сообщил о запросе сохранить `88.axm` при отсутствии звёздочки. Сам снимок не позволяет сравнить текст в памяти с файлом на диске, поэтому он не доказывает, что запрос сохранения был лишним. Воспроизведено расхождение для изменённой модели неактивной вкладки: проверка закрытия видела новую версию модели, но индикатор вкладки и набор `dirty` не обновлялись. Теперь хранилище документов синхронизирует оба признака при изменении любой модели. Усиленный регрессионный сценарий проверяет звёздочку, запрос именно для `88.axm` и сохранность правки после отмены закрытия.

Ошибка первого документа в «Сохранить всё» раньше прекращала обход, из-за чего следующие изменённые документы не сохранялись. Теперь операция продолжает обработку остальных файлов, сообщает путь неудачной записи, оставляет её документ изменённым и сохраняет остальные успешно записанные документы.
