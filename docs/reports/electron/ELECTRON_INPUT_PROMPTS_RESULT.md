# Повтор приглашения INPUT в Electron

## Результат 2026-10-11

Пользователь сообщил о повторе первого запроса имени в файле `C:/Users/<имя>/Downloads/88.axm`. Проверена точная копия исходного текста в отдельном тестовом каталоге и изолированном профиле новой Electron IDE. Пользовательский файл не изменялся. Старая оболочка не запускалась.

До исправления после ввода имени `Анна` консоль показывала дважды `Введите ваше имя: Анна`. Приглашение возраста исчезало. VM при этом отправила ровно два события `input.request`: одно для имени, другое для возраста. Повтор происходил при отображении, а не при повторном исполнении оператора INPUT.

## Причина и исправление

`input.request` содержит полный снимок консоли. Следующий `output.append` служебный процесс рассчитывает относительно предыдущего опубликованного вывода, который обновляется таймером. Контроллер Electron добавлял такой фрагмент к уже более свежему полному снимку. История имени попадала в консоль повторно. При перерисовке приглашение и набранный текст также не восстанавливались.

В `ide/src/renderer/execution-controller.js` добавлена отдельная база опубликованного потока. Снимок INPUT больше не меняет базу, к которой применяется append. Более свежий снимок сохраняется до того, как поток его догонит. При перерисовке отдельно восстанавливаются текущее приглашение и набранные символы. Enter очищает активное приглашение перед отправкой ответа.

Отдельно обнаружено, что `execution.finished` и `debug.paused` отправляли `result.OutputText`, содержащий чистый вывод VM без истории вопросов и ответов INPUT. В `src/Axiom.DesktopHost/DesktopHost.cs` эти два снимка теперь берутся из `_console.OutputText`, как уже делается для `input.request` и публикации вывода. После завершения история ввода остаётся в консоли.

Синтаксис и семантика языка не изменены. Исправлена согласованность представления консоли и снимков служебного процесса.

## Передача работы

Рабочие изменения ограничены контроллером вывода Electron и двумя полями снимков DesktopHost. Целевой набор INPUT подтверждён; полный набор Electron здесь не запускался. Прежде чем объявлять этап завершённым, требуется повтор существующих `backend.spec.js` и `graphics-shutdown.spec.js`, особенно ввод, остановка и повторный запуск. Эти проверки выполняет основной агент после освобождения очереди Electron. Результаты общей проверки и отправку коммита следует записать в очередном разделе WORKLOG и PLANS.

После получения изменений на другом компьютере сначала собрать DesktopHost командой выше, затем повторить `input-prompts.spec.js`. Проверки используют переносимую копию содержимого 88.axm, поэтому исходный файл в Downloads для повторения не нужен.
