# StepBack: граница выполненной файловой записи

16 октября 2026 года проверен действующий договор BytecodeVm и Electron. Изменений реализации на этом этапе нет. Новые операторы и функции не добавлены.

После успешной WRITEFILE или APPENDFILE история до внешнего эффекта очищается. Позднейшие инструкции той же исходной строки могут создать новую историю: последняя доступная остановка находится в строке записи, но уже после вызова функции. Продолжение из неё не повторяет запись. Открытый FILE исключает создание обратимого снимка; недоступная команда StepBack не потребляет текущую остановку.

## Проверки

Команда `dotnet test tests/Axiom.Execution.Tests/Axiom.Execution.Tests.csproj --no-restore --filter "FullyQualifiedName~StepBackFileBoundaryTests|FullyQualifiedName~ExecutionPipelineTests.Run_WithReversibleBytecodeStopExposesStepBackAvailability" --verbosity minimal` прошла: 6/6. Четыре варианта WRITEFILE/APPENDFILE проверяют обычную и явную UTF-8 кодировку. Продолжение после достижения границы проходит при эксклюзивной блокировке файла: повторная запись вызвала бы отказ. Проверка открытого FILE подтверждает отказ StepBack и успешное последующее продолжение через CLOSE.

Команда `node ide/e2e/runner.js trace-file-boundary.spec.js` прошла: 2/2 сценария, 34 утверждения. В настоящем Electron проверены строка остановки, доступность кнопки, Ctrl+F10 и завершение. После достижения границы файл изменён извне; шаг и продолжение сохраняют внешний текст, что исключает повторную запись. Для FILE первая исполняемая строка — OPEN, поскольку DIM без инициализатора не создаёт инструкции. Первоначальное ожидание остановки на DIM и требование отсутствия советов о неиспользуемой переменной были ошибками проверочного сценария, а не дефектами продукта.

Доказательство: `ide/e2e/evidence/trace-file-boundary-results.json`, без отказов, падений и ошибок страницы. Общий results.json восстановлен. Каталог содержит 435 сценариев; полный прогон не выполнялся. Проверочные программы создаются в изолированном каталоге .artifacts.

## Границы результата

Проверены успешные файловые записи и открытый FILE. Отмена внешних эффектов не обещается. Частичные ошибки файловых операций, другие ресурсы и графические эффекты этой проверкой не аттестованы; IDE40 остаётся частично закрытой. Следующий адресный пункт — граница StepBack при частично выполненной файловой операции с ошибкой, сначала анализ достижимого сценария и воспроизведение.

Версии без нового повышения на этом этапе: язык 0.1.15, компилятор 0.1.15, IDE 0.6.6. Повышение IDE относится к предшествующему исправлению Restart.
