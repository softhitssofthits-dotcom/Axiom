# Проверка действия 261 параметра Monaco в Axiom IDE

## Результат

Проверка выполнена в настоящих окнах Electron из текущих исходников. Итоговый набор охватывает **261 пункт**: **198** с наблюдаемым различием результатов действий, **3** с ожидаемым совпадением в выбранном контексте, **60** недоступных. Для действующих пунктов выполнены **498 вариантов значений**. Недоступные элементы отдельно проверены на русском и английском: видимость, отключение, бледная подпись и поле, пояснение при наведении на подпись и поле. Каталог и код этих возможностей сохранены.

## Как проводилась проверка

Для каждого ключа задан самостоятельный план подготовки, действия и наблюдения в [editor-settings-live-plan.cjs](../../../ide/e2e/editor-settings-live-plan.cjs). Настоящие временные программы открываются через обычный openFile. Значения выбираются через элементы диалога и сохраняются кнопкой «ОК». Затем выполняются ввод, нажатия клавиш, щелчки, наведение, прокрутка, команды Monaco или перетаскивание. Проверяются текст, выделения, реальные списки и подсказки, цвета, размеры и видимость отображаемых элементов, миникарта, область чтения и ARIA.

Тестовые языковые провайдеры не регистрируются. Используются провайдеры текущего Axiom и общие провайдеры самой Monaco. getRawOptions и сохранённый профиль записаны только для диагностики: они не являются критерием действия настройки. Для ключевых операций добавлены явные ожидаемые результаты в editor-settings-live-assertions.cjs; для остальных сохраняется наблюдаемое различие по критерию собственного плана. Это проверка выбранных пользовательских сценариев, а не всех возможных сочетаний параметров.

Для скобок проверяются отсутствие раскраски при выключении и разные цвета уровней при включении. Для заготовки — активный сеанс, положение ввода и появление или подавление подсказок. Для инерции — продолжение движения после завершения ввода. Для перетаскивания — настоящий путь без удвоенных слешей и служебного $0, отмена и повтор. Для поиска в выделении — число результатов и фактическая область поиска. Для размеров и толщины шрифта проверяется соответствие выбранному значению.

Системный ввод выполняют native-drag.ps1 и native-wheel.ps1 с проверкой принадлежности окна запущенному тестовому процессу и возвращением указателя мыши. Перетаскивается ссылка на настоящий файл из отдельного окна, а не вымышленный DataTransfer. Для инерции Windows получает серию событий колеса с неполным шагом; это не проверка конкретного физического сенсорного устройства. autoDetectHighContrast проверяется настоящим переключением параметра Windows с обязательным восстановлением исходного состояния.

## Исправления, найденные новой проверкой

- Согласованы параметры редактора и модели для раскраски скобок; сохранено решение другой машины.
- Обновляются кешируемые параметры представления с сохранением той же модели и истории отмены. Порог длинной строки сбрасывает токены Monarch без изменения текста.
- Добавлены правила отступов Axiom; простые режимы сохраняют выбор Monaco, активные заготовки защищены от структурной правки.
- Языковые и словарные дополнения участвуют совместно; для другого языка слова Axiom не выдаются.
- Правки Monaco с insertAsSnippet применяются штатным snippetController2 вместо буквального добавления служебного $0.
- Недоступные возможности оформлены через отдельный реестр причин и общий UIControls.

## Граница результатов

Три ожидаемых совпадения объясняются в строках данных: foldingStrategy и stickyScroll.defaultModel используют структуру по отступам при отсутствии собственного провайдера структуры; suggest.previewMode проверен на точном начале ABS, где все три режима показывают одно продолжение. Другие контексты этих режимов данным результатом не подтверждаются.

Лигатуры и оси шрифта проверялись с установленным Cascadia Code. Область чтения и сообщения проверялись через DOM и ARIA; аудиальный вывод внешнего экранного диктора не проверялся. Один Canceled при отмене фонового запроса штатного рабочего процесса Monaco сохранён отдельно как ожидаемая отмена. Неожиданных ошибок страницы и незавершённых строк итогового набора нет.

Большие файлы создавались в каталоге временных данных; проверка оптимизации открывает новую модель, поскольку этот параметр относится к её созданию. Личные изменения samples/graphics/game/maze_chase.axm и samples/graphics/primitives/pset_line_circle.axm не включаются в коммит.
