# Однострочный IF — результат 15 октября 2026 года

Реализованы формы `IF условие THEN оператор` и `IF условие THEN оператор ELSE оператор`. В каждой ветви один неблочный оператор, END IF отсутствует. ELSEIF, вложенный короткий IF и разделение операторов двоеточием не добавлены. Условия BOOLEAN и отдельные области видимости ветвей сохраняются. Комментарий после THEN без инструкции оставляет форму блочной.

Парсер различает формы до пропуска перевода строки. IfStatementSyntax сохраняет признак IsSingleLine; связывание и BytecodeVm используют существующее ветвление. Неподдерживаемые формы дают MB1004 с восстановлением до конца текущей строки. IDE получила локализованную заготовку; прежние словарь, категории Monaco и семантическая раскраска подтверждены реальным редактором.

## Подсказка CATCH

Отказ InputFilesCatchAndNextHaveExactIdentifierLocations воспроизведён также с парсером из HEAD до изменения IF. Причина — поиск `problem\n` в исходнике с CRLF. Проверка теперь вычисляет положение по `CATCH problem` и отдельно покрывает LF/CRLF, тип ERROR, точный диапазон и категорию errorVariable. Тестовый ERROR получает строковый код вместо неподдерживаемого числового аргумента. При полном проходе того же класса устранены ещё два аналогичных ожидания LF в проверках вложенных областей и параметров. Поведение подсказки не менялось: её правильность подтверждена через настоящий редактор и наведение мышью.
