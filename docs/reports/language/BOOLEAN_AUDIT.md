# Проверка BOOLEAN и логических операций — 13 октября 2026 года

Проверено 55 программ текущим CLI/BytecodeVm. Все результаты совпали с независимыми ожиданиями: 28 допустимых программ и вариантов ввода, 27 отклоняемых форм с ожидаемыми диагностическими кодами. Ошибок вычисления логических операций в проверенной области не выявлено. Отдельно подтверждено уже известное общее ограничение CONST/BYREF: логическая константа может быть изменена через параметр; это не считается корректной неизменяемостью и не исправлено в данном документном аудите. Это адресная проверка перечисленных договоров, а не доказательство всех сочетаний типов, оптимизаций и отладочных состояний.

## Подтверждённый договор

- TRUE/FALSE являются двумя значениями BOOLEAN. Значение по умолчанию — FALSE. Они не являются числами или строками.
- Сравнения возвращают BOOLEAN. Логические значения поддерживают только равенство/неравенство; упорядоченные сравнения отклоняются.
- Проверены все четыре сочетания двух BOOLEAN для AND/ANDALSO/OR/ORELSE/XOR/EQV/IMP и оба результата NOT.
- AND/OR/XOR/EQV/IMP вычисляют правый операнд; ANDALSO/ORELSE могут пропустить его. Пропуск выполнения не отменяет проверку имён и типов.
- Целочисленные NOT/AND/OR/XOR/EQV/IMP возвращают числа. NOT 0 = -1 не задаёт числового кода TRUE. Проверено также смешение INTEGER и LONG для AND.
- NOT имеет приоритет выше сравнения. NOT 1 = 2 даёт FALSE; NOT (1 = 2) даёт TRUE. IMP связывается слева направо.
- Числа и строки не становятся BOOLEAN при присваивании или использовании в IF/WHILE/DO. CINT/CLNG/CDBL/CDEC/STR не принимают BOOLEAN; CBOOL не зарегистрирована.
- PRINT, & и интерполяция используют текст TRUE/FALSE. Проверены объявления, логические инициализаторы CONST, сравнения, SELECT CASE и элементы BOOLEAN-массива с FALSE по умолчанию.
- INPUT принимает только TRUE/FALSE без учёта регистра. Числа, пустой ответ, русское слово и пробелы для единственного BOOLEAN отклонены с MB3003. Для двух BOOLEAN края полей очищаются до разбора.

## Справочник и постоянная приёмка

Главное описание: docs/manual/boolean.html. Добавлены таблицы истинности, типовые ограничения, порядок вычисления, побитовое отличие, приоритет NOT, ввод, текстовое представление, отсутствие числовых преобразований и пример самостоятельного выбора числа через IF. Статьи типов/операций/преобразований направляют к основному описанию; TRUE/FALSE/BOOLEAN имеют прямые ссылки из каталога. Справочник сохраняет 17 глав и содержит 119 HTML-страниц.

Постоянные программы: samples/expressions/logical/boolean_values.axm, truth_table.axm и evaluation_order.axm. Тест BooleanContractAuditTests проверяет их точный вывод 13 запрещённых форм и вычисление инициализатора CONST при выполнении объявления через публичный конвейер: 17/17. Проверка справочника: 119 страниц, 4758 ссылок, 455 уникальных целей поиска; восемь проверок оформления, поиска и браузера прошли.

В первоначальном временном сценарии использована неподдерживаемая форма WEND вместо END WHILE; исправлено до итоговой проверки кода MB2008. В первоначальном объявлении CONST пропущен обязательный AS; исправлено до итогового прогона. В первом постоянном примере имя процедуры Row совпало с предопределённой константой ROW: имя заменено на ShowTruthRow, после чего точное ожидание таблицы прошло. Эти сбои относились к проверочным исходникам, а не к реализации логических операций.

Реализация языка и IDE не менялась. Новые запускаемые примеры и адреса в генераторе справочника требуют сопровождения версий по действующим правилам проекта. Новые сценарии производительности не вводились.

Проверка новой статьи выявила неверное требование вычислять инициализатор CONST при проверке программы. Текст исправлен по реализации и статье CONST, затем отдельная программа подтвердила копирование текущего значения BOOLEAN при выполнении объявления.
