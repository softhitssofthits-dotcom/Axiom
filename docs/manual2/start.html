Начало работы

Программа Axiom — это файл .axm с объявлениями и инструкциями. Его можно проверить, запустить и отладить в Axiom IDE.

Первая программа

Инструкции выполняются сверху вниз. Объявление DIM вводит переменную, задаёт её тип и начальное значение. PRINT выводит текст и значения.

DIM name AS STRING = "Анна"
DIM age AS INTEGER = 27
PRINT "Имя: "; name
PRINT "Возраст: "; age

Результат:

Имя: Анна
Возраст: 27

Точка с запятой соединяет части вывода без добавочного пробела; пробел после двоеточия входит в строку. Запятая добавляет один пробел. Без завершающего разделителя PRINT заканчивает строку.

Проверка и запуск

«Запуск → Проверить» (Ctrl+Shift+C) анализирует исходник, но не выполняет его. «Запуск → Запустить» (Ctrl+F5) проверяет программу и запускает её. «Запуск → Остановить» (Shift+F5) прерывает выполнение, в том числе ожидание INPUT. Команда «Файл → Сохранить» записывает файл на диск.

Найденные проблемы собраны в панели «Проблемы». Каждая запись содержит код, описание и место в исходнике. Ошибка не позволяет запустить программу. Предупреждение и совет на запуск не влияют.

Комментарии

Апостроф начинает комментарий и действует до конца строки. Слово REM делает то же самое, если за ним следует пробельный символ. Комментарий может занимать отдельную строку или стоять после инструкции.

' Имя и возраст.
DIM name AS STRING = "Анна"
PRINT name  ' Комментарий после инструкции.
REM Ещё один комментарий.

Перевод строки разделяет инструкции. Двоеточие разделителем не является: запись PRINT 1: PRINT 2 даёт MB0001.

Разделы исходника

Строки ' #region Название и ' #endregion отмечают участки для панели «Структура программы» и для сворачивания кода. На выполнение они не влияют. Название раздела обязательно и может быть на русском.

' #region Приветствие
PRINT "Привет"
' #endregion

Имена и регистр

Имя начинается с латинской буквы или подчёркивания; далее допустимы латинские буквы, цифры и подчёркивание. Регистр не различается: count и Count — одно имя. Ключевые слова зарезервированы, кроме LINE: как имя оно допустимо, если не стоит в начале инструкции.
