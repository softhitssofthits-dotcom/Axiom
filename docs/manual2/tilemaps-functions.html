Функции: тайловые карты

0 функций раздела «Тайловые карты» — 0 зарегистрированных форм с типами аргументов и результата.

Общий договор

Карта загружается из формата Tiled. Номера слоёв и объектов начинаются с 0. Неподдержанная форма файла отклоняется с причиной в MB3005. Отсутствующее свойство не подменяется пустым значением.

Все перечисленные аргументы обязательны; необязательный аргумент представлен отдельной формой. Объяснение типов и общего поведения находится в главе Тайловые карты.
