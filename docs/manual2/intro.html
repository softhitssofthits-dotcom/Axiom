Введение

Axiom — язык с синтаксисом, знакомым по BASIC, и строгой типизацией. Программа живёт в файле с расширением .axm и выполняется собственной виртуальной машиной.

Как устроена программа

Исходный файл состоит из инструкций, которые выполняются одна за другой, сверху вниз. Переменная хранит значение под именем; объявление DIM вводит имя, задаёт тип и начальное значение. Оператор PRINT выводит текст и значения.

DIM name AS STRING = "Анна"
DIM age AS INTEGER = 27
PRINT "Имя: "; name
PRINT "Возраст: "; age

Программа печатает:

Имя: Анна
Возраст: 27

Точка с запятой соединяет части вывода без добавочного символа — пробел после двоеточия уже входит в строку. Запятая вставляет один пробел. Без завершающего разделителя PRINT заканчивает строку.

Проверка и запуск

В IDE команда «Запуск → Проверить» (Ctrl+Shift+C) проходит весь компилятор, но не выполняет программу. «Запуск → Запустить» (Ctrl+F5) проверяет исходник и запускает его; «Запуск → Остановить» (Shift+F5) прерывает выполнение, в том числе ожидание ответа на INPUT.

Найденные проблемы собраны в панели «Проблемы»: у каждой записи есть код, описание и место в исходнике. Ошибка не даёт программе запуститься. Предупреждение и совет на запуск не влияют.

Комментарии

Апостроф начинает комментарий до конца строки. Слово REM делает то же самое, если за ним стоит пробельный символ. Комментарий можно поставить отдельной строкой или после инструкции.

' Имя и возраст человека.
DIM name AS STRING = "Анна"
PRINT name  ' Комментарий после инструкции.
REM Ещё один комментарий.

Инструкции разделяются переводом строки. Двоеточие разделителем не является: запись PRINT 1: PRINT 2 отклоняется с ошибкой MB0001.

Разделы исходника

Строки ' #region Название и ' #endregion отмечают участки для панели «Структура программы» и для сворачивания кода. На выполнение они не влияют, название обязательно и может быть русским.

' #region Приветствие
PRINT "Привет"
' #endregion

Имена

Имя начинается с латинской буквы или подчёркивания, дальше допустимы латинские буквы, цифры и подчёркивание. Регистр не важен: count, Count и COUNT — одно имя. Ключевые слова зарезервированы; исключение — LINE, которое допустимо как имя, если не стоит в начале инструкции.
