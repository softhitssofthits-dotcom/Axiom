Процедуры и функции

SUB выполняет действие, FUNCTION возвращает значение. Параметры передаются по значению или по ссылке; функция может храниться как значение и вызываться позже.

SUB

SUB Increase(BYREF value AS INTEGER)
    value = value + 1
END SUB

DIM count AS INTEGER = 4
Increase(count)
PRINT count

Процедура не возвращает значение; её вызов записывается отдельной инструкцией. Результат примера — 5, потому что BYREF передаёт саму переменную. RETURN без выражения завершает процедуру досрочно; RETURN со значением в SUB даёт MB2006.

FUNCTION

FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION

PRINT Square(7)

Тип результата указывается после заголовка. RETURN с выражением завершает функцию; RETURN без выражения в FUNCTION даёт MB2007. Если выполнение дошло до END FUNCTION без RETURN, возвращается значение по умолчанию для типа.

Параметры

Параметр по умолчанию передаётся по значению. BYVAL указывает это явно. BYREF передаёт адрес простой переменной подходящего типа: изменения видны вызывающему коду. Другой аргумент в BYREF даёт MB2028, константа — MB2010.

Значение BYVAL-записи фиксируется в момент вычисления этого аргумента, до вычисления следующих.

Функции как значения

Тип FUNCTION(INTEGER) AS INTEGER описывает функцию с одним целочисленным параметром. Значение этого типа можно сохранить, передать аргументом и вызвать:

FUNCTION Twice(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION

DIM f AS FUNCTION(INTEGER) AS INTEGER
f = Twice
PRINT f(5)

Результат — 10. SUB как значение использоваться не может (MB2019); функция с BYREF-параметром также не становится значением (MB2029).

Замыкания

Вложенная функция видит доступные имена внешней и может вернуть их вызывающему коду вместе с собой. Такая функция сохраняет доступ к захваченным переменным после завершения внешнего вызова:

FUNCTION MakeReader() AS FUNCTION() AS INTEGER
    DIM value AS INTEGER = 41
    FUNCTION Read() AS INTEGER
        RETURN value + 1
    END FUNCTION
    RETURN Read
END FUNCTION

DIM reader AS FUNCTION() AS INTEGER
reader = MakeReader()
PRINT reader()

Результат — 42.
