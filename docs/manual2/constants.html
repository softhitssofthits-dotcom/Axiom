Константы

Константа связывает имя со значением, которое нельзя изменить присваиванием. Её используют для пределов, коэффициентов и других величин, которые должны оставаться неизменными.

Объявление

Константа объявляется через CONST с явным типом и начальным выражением. Оба обязательны.

CONST LIMIT AS INTEGER = 10
DIM count AS INTEGER = 7
PRINT count <= LIMIT
TRUE

Имя константы участвует в выражениях так же, как имя переменной. Разница одна: присваивание ей запрещено.

Защита от записи

CONST LIMIT AS INTEGER = 10
LIMIT = 11

Эта программа отклоняется с ошибкой MB2010. Защита распространяется и на передачу константы параметру BYREF: такой параметр допускает запись в исходное значение, поэтому компилятор тоже выдаёт MB2010.

Когда вычисляется значение

Начальное выражение вычисляется, когда выполнение доходит до объявления. Оно может читать переменные и вызывать функции. Позднейшее изменение исходных данных не пересчитывает уже созданную константу.

DIM source AS INTEGER = 5
CONST SNAPSHOT AS INTEGER = source + 1
source = 99
PRINT SNAPSHOT
6

SNAPSHOT хранит 6 — значение, которое source + 1 дало в момент объявления. Если объявление стоит в теле цикла, оно выполняется на каждом проходе и пересчитывает константу заново.

Три имени доступны без объявления и не могут быть переобъявлены.
