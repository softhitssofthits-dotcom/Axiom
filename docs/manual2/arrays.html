Массивы

Массив держит несколько значений одного типа под одним именем. Каждый элемент доступен по индексу, а границы измерения задаёт сам программист при объявлении.

Объявление

DIM items(1 TO 3) AS INTEGER
items(1) = 10
items(2) = 20
items(3) = 30
PRINT ARRAYLENGTH(items)
PRINT items(2)
3
20

Обе границы входят в диапазон, и нумерация не обязана начинаться с нуля. Сокращённая запись DIM items(3) не поддерживается и даёт MB1001. Нижняя граница может быть отрицательной, но не равной -2147483648.

Ранг и индексирование

DIM grid(1 TO 2, 1 TO 3) AS INTEGER
grid(2, 3) = 7
PRINT grid(2, 3)
PRINT LBOUND(grid, 1), UBOUND(grid, 2)
7
1 3

Число диапазонов через запятую задаёт ранг. Индекс проверяется по значению: дробный индекс даёт MB3007, выход за границу — MB3002. Константы ROW и COLUMN соответствуют номерам измерений 1 и 2.

Динамический массив и REDIM

DIM a() AS INTEGER
PRINT ARRAYISALLOCATED(a)
REDIM a(1 TO 3)
PRINT ARRAYISALLOCATED(a), ARRAYLENGTH(a)
FALSE
TRUE 3

Пустые скобки объявляют невыделенный массив. Границы появляются после REDIM. REDIM PRESERVE сохраняет существующие элементы, а новые получают значения по умолчанию.

DIM items(1 TO 2) AS INTEGER
items(1) = 7
items(2) = 8
REDIM PRESERVE items(1 TO 3)
items(3) = 9
PRINT ARRAYLENGTH(items)
PRINT items(1), items(3)
3
7 9

Общее хранилище

Присваивание массива другому имени не копирует элементы: оба имени указывают на один массив. Представление, полученное срезом, тоже работает с исходными элементами, пока хранилище действительно.

DIM a(1 TO 2) AS INTEGER
DIM b() AS INTEGER
b = a
b(1) = 99
PRINT a(1)
99

После REDIM или ERASE корня прежнее представление устаревает и при обращении даёт MB3014. Независимую копию создаёт ARRAYCLONE.

Пустой массив

Пустой массив имеет канонические границы 1 TO 0: ARRAYLENGTH для него равен 0, но ARRAYISALLOCATED возвращает TRUE. Произвольный обратный диапазон, например 4 TO 2, отклоняется с MB3005.
