Ветвление: IF и SELECT CASE

Ветвление выбирает, какой блок выполнить. IF проверяет условие, SELECT CASE сравнивает одно значение с набором вариантов.

IF, ELSEIF и ELSE

Оператор IF выполняет блок, когда условие истинно. Условие имеет тип BOOLEAN: это сравнение, логическое выражение или вызов функции с логическим результатом.

DIM score AS INTEGER = 75
IF score >= 90 THEN
    PRINT "Отлично"
ELSEIF score >= 70 THEN
    PRINT "Хорошо"
ELSE
    PRINT "Повторите тему"
END IF
Хорошо

Условия проверяются по порядку. Выполняется первое истинное, остальные ветви пропускаются. ELSE срабатывает, когда все условия ложны; он необязателен. ELSEIF можно повторить сколько нужно, а ELSE допускается только один раз.

Число в условии не считается истинным само по себе: IF 1 THEN — ошибка MB2008. Проверку числа записывают явным сравнением, например IF n <> 0 THEN.

Однострочная форма

Короткая запись IF условие THEN оператор ELSE оператор содержит ровно один оператор в каждой ветви и не требует END IF. Перевод строки завершает конструкцию; вложенный блок внутри ветви открыть нельзя.

DIM n AS INTEGER = 1
IF n = 1 THEN PRINT "один" ELSE PRINT "другое"
один

Если в ветви нужно несколько инструкций или вложенное условие, применяется блочная форма с END IF.

SELECT CASE

SELECT CASE сравнивает одно выражение с набором вариантов и выполняет первый подошедший. В одной ветви перечисляют значения через запятую, задают сравнение через CASE IS или диапазон через TO.

DIM code AS INTEGER = 5
SELECT CASE code
    CASE 1, 2
        PRINT "Малая ошибка"
    CASE IS >= 10
        PRINT "Серьёзная ошибка"
    CASE 3 TO 9
        PRINT "Средняя ошибка"
    CASE ELSE
        PRINT "Неизвестный код"
END SELECT
Средняя ошибка

Диапазон TO включает обе границы. CASE IS принимает любой оператор сравнения. CASE ELSE выполняется, если не подошла ни одна ветвь, и допускается один раз.

SELECT CASE работает и со строками, и с датами, и с временем: вид сравнения тот же, что у обычных операторов. Смешение разных временных видов внутри одного SELECT CASE отклоняется.
