Справочник / INPUT

INPUT

INPUT запрашивает у пользователя данные и записывает их в переменные. Он разбирает ответ по типу каждой цели и отклоняет неверное значение целиком.

Один получатель

DIM name AS STRING
INPUT "Как вас зовут"; name
PRINT "Привет, "; name

Приглашение — необязательная строка, за которой следует точка с запятой или запятая. После точки с запятой к приглашению добавляется вопрос и пробел; запятая сохраняет текст как есть. Без приглашения выводится только вопрос.

Несколько получателей

DIM name AS STRING
DIM age AS INTEGER
INPUT "Имя и возраст"; name, age
PRINT name; " — "; age

Несколько целей перечисляются через запятую. Поля ответа разбираются все сразу, до записи: если одно значение неверное, ни один получатель не меняется, и возникает MB3003.

Типы значений

INPUT принимает числа, строки, BOOLEAN и временные значения. BOOLEAN распознаёт только слова TRUE и FALSE без учёта регистра; число — запись INTEGER, LONG, DOUBLE или DECIMAL; временные значения — канонический текст своего типа. Строка получает остаток строки без разбора.

Строковое значение принимается в канонической форме: для DATE это yyyy-MM-dd, для TIME — HH:mm:ss, для DATETIME — yyyy-MM-dd HH:mm:ss. Региональные записи и формат с разделителем T не принимаются.

Место ввода

В обычной программе ответ набирается в консоли IDE. При активном SCREEN ввод выполняется в экранном окне; CANVAS не перенаправляет INPUT из консоли. Неверный ответ возвращает ошибку, которую программа может перехватить и повторить запрос.
