Функции FUNCTION

Функция похожа на процедуру, но возвращает значение. Её вызов — это выражение, результат которого можно сохранить, напечатать или передать дальше.

Объявление и вызов

FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION

PRINT Square(7)
49

После заголовка указывается тип результата. RETURN с выражением завершает функцию и возвращает значение; RETURN без выражения в функции — ошибка MB2007.

Значение по умолчанию

Если выполнение дошло до END FUNCTION, не встретив RETURN, функция возвращает значение по умолчанию для своего типа: 0 для чисел, FALSE для BOOLEAN, пустую строку для STRING. Опираться на это поведение стоит только осознанно — обычно функцию завершают явным RETURN.

Параметры

Правила те же, что у процедур: по значению по умолчанию, BYREF для изменяемого параметра. Функция с параметром BYREF не может использоваться как значение.

FUNCTION NextId(BYREF counter AS INTEGER) AS INTEGER
    counter = counter + 1
    RETURN counter
END FUNCTION

DIM current AS INTEGER = 0
PRINT NextId(current)
PRINT current
1
1

Функции как значения

Тип FUNCTION(INTEGER) AS INTEGER описывает функцию с одним целочисленным параметром. Такое значение можно сохранить, передать аргументом и вызвать через него.

FUNCTION Twice(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION

DIM f AS FUNCTION(INTEGER) AS INTEGER
f = Twice
PRINT f(5)
10

Процедура SUB как значение не используется (MB2019). Имя функции в выражении без скобок — это сама функция, а не её вызов.

Замыкания

Вложенная функция видит переменные внешней и может вернуть их вместе с собой. Такая функция сохраняет доступ к захваченным значениям даже после того, как внешний вызов завершился.

FUNCTION MakeReader() AS FUNCTION() AS INTEGER
    DIM value AS INTEGER = 41
    FUNCTION Read() AS INTEGER
        RETURN value + 1
    END FUNCTION
    RETURN Read
END FUNCTION

DIM reader AS FUNCTION() AS INTEGER
reader = MakeReader()
PRINT reader()
42

MakeReader возвращает вложенную Read, которая держит переменную value. После возврата внешней функции переменная продолжает жить внутри замыкания.
