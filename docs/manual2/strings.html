Строки

STRING хранит текст в кодировке UTF-16. Длина, позиции и срезы измеряются в кодовых единицах — это важно помнить при работе с нелатинскими символами.

Литералы

Строковый литерал записывается в двойных кавычках. Кавычка внутри строки удваивается. Перевод строки внутри литерала завершает его с ошибкой MB0002.

PRINT "Он сказал: ""привет"""
PRINT "Первая строка" & " и вторая"
Он сказал: "привет"
Первая строка и вторая

Интерполяция

Строка с префиксом $ вставляет значения выражений в фигурных скобках. Спецификатор после двоеточия задаёт формат числа.

DIM n AS INTEGER = 42
PRINT $"Число: {n:F2}"
PRINT $"Шестнадцатеричное: {n:X}"
Число: 42.00
Шестнадцатеричное: 2A

Двойные фигурные скобки {{ и }} дают сами скобки. Одиночная открывающая скобка всегда начинает вставку выражения.

Длина и фрагменты

LEN возвращает число кодовых единиц UTF-16. LEFT, RIGHT и MID измеряют фрагменты в тех же единицах; выход за границы не ошибка, а сокращение результата до доступной части. Поиск считает позиции с 1 и возвращает 0, если совпадения нет.

DIM t AS STRING = "Привет"
PRINT LEN(t)
PRINT LEFT(t, 3)
PRINT MID(t, 2, 3)
PRINT UCASE("abc")
PRINT TRIM("  x  ")

Фиксированная длина

STRING * N хранит ровно N кодовых единиц. Короткое значение дополняется пробелами справа, длинное обрезается. Длина — целая константа от 1 до 65535.

Предел значения

Одно строковое значение ограничено 16 777 216 кодовыми единицами UTF-16. Превышение при выполнении даёт MB3007, которую можно перехватить в TRY/CATCH.
