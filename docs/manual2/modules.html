Модули и IMPORT

Файл Axiom является модулем. IMPORT подключает объявления соседнего файла, а PUBLIC и PRIVATE управляют доступностью имён между файлами.

IMPORT

IMPORT tools

PRINT Add(2, 3)

IMPORT записывается в начале файла; имя модуля — имя файла без расширения. Поиск выполняется в папке точки входа. Цикл импортов и импорт самого себя запрещены (MB2052); отсутствующий модуль даёт MB2049.

Доступность

PUBLIC FUNCTION Add(a AS INTEGER, b AS INTEGER) AS INTEGER
    RETURN a + b
END FUNCTION

PRIVATE DIM cache AS INTEGER

Объявления верхнего уровня по умолчанию закрыты. PUBLIC открывает имя для импортирующих модулей, PRIVATE задаёт закрытость явно. Обращение к закрытому имени даёт MB2053; неоднозначный импорт — MB2054, конфликт имён — MB2055. Модификатор допустим только на верхнем уровне и только перед DIM, CONST, SUB, FUNCTION или TYPE.

Выполнение модулей

Выполняются только модули, достижимые от точки входа, в порядке зависимостей. Общая зависимость инициализируется один раз. Ошибка инициализации останавливает запуск до точки входа.
