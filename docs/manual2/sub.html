Процедуры SUB

Процедура объединяет последовательность действий под именем. Её вызывают, когда нужно выполнить эти действия, не получая значения обратно.

Объявление и вызов

SUB PrintHeader(title AS STRING)
    PRINT "== "; title; " =="
END SUB

PrintHeader("Отчёт")
== Отчёт ==

Процедура объявляется ключевым словом SUB и завершается END SUB. Вызов записывается как отдельная инструкция — имя процедуры со списком аргументов в скобках.

Параметры

Параметр по умолчанию передаётся по значению: процедура работает с копией. BYREF передаёт адрес переменной, поэтому изменение видно вызывающему коду.

SUB Increase(BYREF value AS INTEGER)
    value = value + 1
END SUB

DIM count AS INTEGER = 4
Increase(count)
PRINT count
5

Аргумент BYREF должен быть простой переменной подходящего типа, иначе возникает MB2028. Константу передать в BYREF нельзя — это MB2010. Слово BYVAL указывает передачу по значению явно, но оно не обязано присутствовать.

RETURN

RETURN без выражения завершает процедуру досрочно. RETURN со значением в процедуре — ошибка MB2006.

SUB Test()
    PRINT "начало"
    RETURN
    PRINT "не выполнится"
END SUB
Test()
начало

Вложенные процедуры

Процедуру можно объявить внутри другой. Вложенная видит доступные имена внешней; при этом вложенные процедуры и функции могут сохранять доступ к ним после завершения внешнего вызова — это основа замыканий, описанных в главе о функциях.
