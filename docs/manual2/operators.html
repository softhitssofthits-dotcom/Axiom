Операции и выражения

Выражение вычисляет значение, соединяя операнды операциями. Тип результата зависит от типов операндов: сравнение даёт BOOLEAN, арифметика — число, амперсанд — строку.

Приоритет

Операция с большим приоритетом выполняется раньше. Скобки меняют порядок. Справа налево связывается только возведение в степень; остальные операции одного уровня — слева направо.

Арифметика

Деление / возвращает DOUBLE или DECIMAL по правилам типов. Целочисленное деление \ работает с INTEGER и LONG, а MOD возвращает остаток.

PRINT 7 / 2
PRINT 7 \ 2
PRINT 7 MOD 2
PRINT 2 ^ 10
3.5
3
1
1024

Деление на ноль — ошибка времени выполнения MB3001. Переполнение целого результата, например 2147483647 + 1, даёт MB3008.

Сравнение

Сравнение возвращает BOOLEAN. Числа сравниваются по значению, строки — по кодовым единицам UTF-16 без языковой сортировки. Логические значения допускают только равенство и неравенство.

PRINT 3 < 4
PRINT "А" < "Б"
PRINT TRUE <> FALSE
TRUE
TRUE
TRUE

Логические операции

NOT, AND, OR, XOR, EQV и IMP применяются к BOOLEAN либо к целым числам. Для BOOLEAN результат логический, для целых — целочисленный; смешивать логическое и числовое значения в одной операции нельзя.

PRINT TRUE AND FALSE
PRINT FALSE OR TRUE
PRINT NOT FALSE
PRINT 5 AND 3
FALSE
TRUE
TRUE
1

ANDALSO и ORELSE принимают только BOOLEAN и вычисляют второй операнд не всегда: ANDALSO пропускает его при FALSE слева, ORELSE — при TRUE слева. Обычные AND и OR вычисляют оба операнда всегда.

PRINT FALSE ANDALSO (1 / 0 > 0)
PRINT FALSE AND (1 / 0 > 0)

Первая строка печатает FALSE: деление не выполняется. Вторая завершается ошибкой MB3001, потому что правый операнд вычисляется.

Соединение строк

Амперсанд & соединяет текстовые представления значений, включая числа, BOOLEAN и моменты времени. Операция + строки с числами не соединяет.

PRINT "Количество: " & 3
PRINT "Готово: " & TRUE
Количество: 3
Готово: TRUE
