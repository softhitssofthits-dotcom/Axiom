Управление ходом программы

Условия выбирают ветвь, циклы повторяют блок, а EXIT и CONTINUE меняют порядок повторения. Условие каждой конструкции имеет тип BOOLEAN.

IF, ELSEIF и ELSE

DIM score AS INTEGER = 75
IF score >= 90 THEN
    PRINT "Отлично"
ELSEIF score >= 70 THEN
    PRINT "Хорошо"
ELSE
    PRINT "Повторите тему"
END IF

Выполняется первая ветвь с истинным условием, остальные пропускаются. ELSE необязателен. Результат примера — Хорошо. Условие должно иметь тип BOOLEAN: число в условии даёт MB2008.

Однострочная форма IF условие THEN оператор ELSE оператор содержит ровно один оператор в каждой ветви, не имеет END IF и не может открывать вложенный блок. Перевод строки завершает короткую форму.

DIM n AS INTEGER = 1
IF n = 1 THEN PRINT "один" ELSE PRINT "другое"

SELECT CASE

DIM code AS INTEGER = 5
SELECT CASE code
    CASE 1, 2
        PRINT "Малая ошибка"
    CASE IS >= 10
        PRINT "Серьёзная ошибка"
    CASE 3 TO 9
        PRINT "Средняя ошибка"
    CASE ELSE
        PRINT "Неизвестный код"
END SELECT

В одной ветви перечисляют значения через запятую, задают сравнение через CASE IS или диапазон через TO. Диапазон включает обе границы. CASE ELSE выполняется, если не подошла ни одна ветвь, и допускается только один раз.

FOR и NEXT

FOR i = 1 TO 3
    PRINT i
NEXT
FOR j = 5 TO 1 STEP -2
    PRINT j
NEXT j

Счётчик создаётся циклом и доступен только внутри. STEP задаёт шаг; нулевой шаг даёт MB3004. После NEXT можно указать имя счётчика; несовпадающее имя даёт MB2048.

WHILE и DO

DIM n AS INTEGER = 0
WHILE n < 3
    n = n + 1
    PRINT n
END WHILE

WHILE проверяет условие перед каждой итерацией. DO проверяет условие до тела в форме DO WHILE / DO UNTIL и после тела в форме LOOP WHILE / LOOP UNTIL. DO без условия повторяется до EXIT DO, RETURN или ошибки.

DIM n AS INTEGER = 0
DO
    n = n + 1
    PRINT n
LOOP UNTIL n = 2

EXIT и CONTINUE

EXIT FOR и EXIT DO завершают ближайший цикл соответствующего вида. CONTINUE FOR, CONTINUE WHILE и CONTINUE DO переходят к следующей итерации. Применение вне подходящего цикла даёт MB2013, MB2014 или MB2037–MB2039.

FOR i = 1 TO 5
    IF i = 2 THEN CONTINUE FOR
    IF i = 4 THEN EXIT FOR
    PRINT i
NEXT

Программа печатает 1 и 3: значение 2 пропускается, а на 4 цикл завершается.
