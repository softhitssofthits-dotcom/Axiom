Пользовательские типы TYPE

TYPE объединяет поля под одним именем и может содержать методы. Это способ хранить вместе связанные данные — например, координаты точки или настройки игрока.

Объявление и поля

TYPE описывает новый тип с именованными полями. Каждое поле имеет свой тип: встроенный, другой пользовательский, массив или фиксированную строку.

TYPE Point
    X AS INTEGER
    Y AS INTEGER
END TYPE

DIM p AS Point
p.X = 10
p.Y = 20
PRINT p.X, p.Y
10 20

Запись создаётся при выполнении объявления DIM. Поля по умолчанию получают нулевые значения своих типов; нужное значение задаётся в объявлении типа после знака равенства.

TYPE Box
    Label AS STRING = "пусто"
    Size AS INTEGER = 3
END TYPE
DIM b AS Box
PRINT b.Label, b.Size
пусто 3

Методы и SELF

Внутри TYPE можно объявить процедуры и функции. Метод получает адресуемого получателя, поэтому изменения, сделанные через SELF, видны сразу после возврата.

TYPE Counter
    Value AS INTEGER
    SUB Add(amount AS INTEGER)
        SELF.Value = SELF.Value + amount
    END SUB
END TYPE

DIM c AS Counter
c.Add(5)
PRINT c.Value
5

В методе собственное поле указывается через SELF; голое имя поля даёт ошибку MB2044. Снаружи поле записывается вместе с получателем, как c.Value.

Создание литералом

Помимо объявления запись создаётся литералом с именованными полями.

DIM p AS Point = Point(X := 3, Y := 4)
PRINT p.X + p.Y
7

Позиционные аргументы и именованные поля в одном литерале не смешиваются (MB2031); неверное число позиционных аргументов даёт MB2032.

Сравнение и копирование

Записи одного типа сравниваются структурно: две независимые записи с одинаковыми полями равны.

DIM a AS Point = Point(X := 1, Y := 2)
DIM b AS Point = Point(X := 1, Y := 2)
PRINT a = b
TRUE

Присваивание и передача параметра по значению копируют запись. Изменение копии не меняет источник; поля-массивы при этом сохраняют правила массивов.
