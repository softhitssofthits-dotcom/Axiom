# Справочник Axiom, второе издание

`docs/manual2/` — самостоятельный интерактивный справочник языка Axiom. Он написан заново по реестру компилятора и не использует текст `docs/manual/`.

## Как открыть

Откройте `docs/manual2/index.html` в браузере. Сервер, сборка сайта и доступ к сети не нужны: оглавление, поиск и подсветка работают локально.

Разделы: 28 глав от первой программы до модулей, файлов, графики, событий и диагностики.

## Состав

```
docs/manual2/
├── index.html            главная страница с плитками глав
├── search.html           страница результатов поиска
├── *.html                главы и каталоги функций
├── data-inventory.json   снимок реестра компилятора (282 функции, 351 форма)
├── styles/manual.css     тема, типографика, адаптивная раскладка
└── scripts/
    ├── navigation.js     порядок глав
    ├── search-index.js   поисковый индекс
    ├── build.mjs         генератор страниц и каталогов
    ├── registry.mjs      чтение реестра и группировка функций
    ├── content-*.mjs     текст тематических глав
    ├── check.mjs         проверка структуры, ссылок и якорей
    ├── browser-test.mjs  браузерная проверка через Playwright
    └── examples-test.mjs запуск примеров текущим CLI
```

## Устройство

Каждая тематическая глава объясняет понятие и содержит проверенные примеры. Каталог функций (`<глава>-functions.html`) строится из `data-inventory.json`: для каждой зарегистрированной формы показаны сигнатура, типы аргументов и правило результата. Карточка создаётся отдельно для каждого имени функции, формы перечислены внутри.

Поиск индексирует главы, функции, операторы, типы и ключевые слова. Подсветка кода использует словарь ключевых слов, типов и встроенных функций.

## Обновление после изменения языка

```powershell
dotnet run --project scripts/language-audit/Axiom.LanguageAudit.csproj -- C:/Axiom --inventory-only --output-dir .artifacts/manual2-inventory
copy .artifacts/manual2-inventory/inventory.json docs/manual2/data-inventory.json
node docs/manual2/scripts/build.mjs
node docs/manual2/scripts/check.mjs
node docs/manual2/scripts/browser-test.mjs
node docs/manual2/scripts/examples-test.mjs
```

Генератор откажется собирать страницы, если какая-то функция реестра не отнесена к главе или зарегистрированный оператор не имеет описания. Это защищает каталог от молчаливой потери имён.

## Границы

Примеры проверены консольным CLI. Графические примеры требуют окна IDE и проверяются в Electron отдельно. Справочник описывает текущий реестр; наличие формы не доказывает все граничные значения её аргументов.
