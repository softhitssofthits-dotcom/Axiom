Циклы: FOR, WHILE, DO

Цикл повторяет блок, пока выполнено условие. FOR отсчитывает счётчик, WHILE проверяет условие перед каждой итерацией, DO позволяет выбрать место проверки.

FOR … NEXT

FOR повторяет блок для каждого значения счётчика от начального до конечного. Счётчик создаётся самим циклом и доступен только внутри него.

FOR i = 1 TO 3
    PRINT i
NEXT
1
2
3

Ключевое слово STEP задаёт шаг, который может быть и отрицательным.

FOR i = 5 TO 1 STEP -2
    PRINT i
NEXT i
5
3
1

После NEXT можно написать имя счётчика; несовпадающее имя — ошибка MB2048. Нулевой шаг бессмыслен и отклоняется с MB3004. Счётчик FOR всегда локальный и не переиспользует одноимённую переменную.

WHILE … END WHILE

WHILE проверяет условие перед каждой итерацией. Если условие ложно с самого начала, тело не выполнится ни разу.

DIM n AS INTEGER = 0
WHILE n < 3
    n = n + 1
    PRINT n
END WHILE
1
2
3

Условие — выражение BOOLEAN, как и у IF. Если программа должна обязательно выполнить тело хотя бы раз, проверку лучше перенести в конец цикла и использовать DO.

DO … LOOP

DO даёт выбрать, где проверяется условие: до тела или после него. Условие перед телом записывается как DO WHILE или DO UNTIL, после тела — как LOOP WHILE или LOOP UNTIL.

DIM n AS INTEGER = 0
DO
    n = n + 1
    PRINT n
LOOP UNTIL n = 2
1
2

Здесь условие проверяется после тела, поэтому блок выполняется хотя бы один раз. WHILE продолжает цикл, пока условие истинно; UNTIL — пока оно ложно. DO без условия повторяется бесконечно до выхода через EXIT или RETURN.

DIM n AS INTEGER = 0
DO WHILE n < 2
    n = n + 1
    PRINT n
LOOP
1
2

EXIT и CONTINUE

EXIT FOR и EXIT DO завершают ближайший цикл соответствующего вида. CONTINUE FOR, CONTINUE WHILE и CONTINUE DO пропускают остаток тела и переходят к следующей итерации.

FOR i = 1 TO 5
    IF i = 2 THEN CONTINUE FOR
    IF i = 4 THEN EXIT FOR
    PRINT i
NEXT
1
3

Значение 2 пропускается командой CONTINUE, а на 4 цикл завершается командой EXIT. Применение этих команд вне подходящего цикла — ошибка: MB2013 для EXIT FOR, MB2014 для EXIT DO, MB2037–MB2039 для CONTINUE.
