Регулярные выражения

Шаблоны Axiom используют синтаксис .NET. Восемь функций проверяют текст, извлекают совпадения, разбивают строку, заменяют фрагменты и считают их.

Проверка и извлечение

PRINT REGEXISMATCH("abc123", "\d+")
PRINT REGEXEXTRACT("abc123", "(\d+)", 1)
PRINT REGEXREPLACE("a-b-c", "-", "+")
PRINT REGEXCOUNT("a1b22", "\d+")
TRUE
123
a+b+c
2

REGEXEXTRACT принимает номер группы: 0 — всё совпадение, 1 и далее — группы. REGEXMATCH возвращает первое совпадение, REGEXMATCHES — массив всех, REGEXEXTRACTALL — массив выбранной группы.

Режимы

Необязательный аргумент modes задаёт режимы буквами: i — без учёта регистра, m — многострочный, s — точка совпадает с переводом строки, x — пробелы шаблона игнорируются. Буквы можно сочетать.

PRINT REGEXISMATCH("ABC", "abc", "i")
TRUE

Неизвестная буква режима даёт MB3007 с перечнем допустимых.

Ошибки и пределы

Неверный шаблон сообщает смещение и вид ошибки. Один синхронный поиск ограничен пятью секундами: превышение даёт MB3007. Отмена между совпадениями завершает запуск как Cancelled и не попадает в пользовательский CATCH. Кэш хранит до 128 сочетаний шаблона и режимов.
