Основы языка

Программа состоит из объявлений, инструкций и выражений. Объявление вводит имя, инструкция выполняет действие, выражение вычисляет значение.

Объявления и инструкции

К объявлениям относятся DIM, CONST, TYPE, SUB, FUNCTION и IMPORT. Остальные записи являются инструкциями: присваивание, вызов, PRINT, циклы и ветви. Инструкции верхнего уровня выполняются в порядке записи; тело подпрограммы — при вызове.

DIM count AS INTEGER = 2
count = count + 1
PRINT count

Результат:

3

Присваивание не объявляет имя. Без предшествующего DIM запись count = 2 получает MB2001.

Блоки

Блок открывается ключевым словом и закрывается парным. IF закрывается END IF, FOR — NEXT, WHILE — END WHILE, DO — LOOP, TRY — END TRY, SUB — END SUB, FUNCTION — END FUNCTION, TYPE — END TYPE. Отступы на смысл не влияют, но показывают вложенность.

IF count > 0 THEN
    PRINT "Есть предметы"
    PRINT count
END IF

Результат:

Есть предметы
3

Выражения

Выражение возвращает значение определённого типа. Оно может быть литералом, именем, вызовом функции или сочетанием операндов. Скобки меняют порядок вычисления; полный список операций приведён в главе об операциях.

DIM price AS DECIMAL = 199.90
DIM quantity AS INTEGER = 3
PRINT price * quantity

Вызов как инструкция

Функция и процедура вызываются одинаковой записью. Отдельная инструкция должна целиком быть вызовом: PrintHeader() или WRITEFILE(path, text). Выражение без вызова самостоятельной инструкцией быть не может и получает MB2040.

Типы

Тип определяет набор значений и допустимые операции. Встроенные типы перечислены в главе о типах; массивы, записи TYPE и функциональные значения описаны в отдельных главах.
