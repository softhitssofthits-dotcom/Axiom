Обработка ошибок

TRY перехватывает ошибку времени выполнения, CATCH получает её сведения, FINALLY выполняется всегда. ERROR создаёт ошибку явно.

TRY, CATCH и FINALLY

DIM divisor AS INTEGER = 0
TRY
    PRINT 10 / divisor
CATCH err
    PRINT "Ошибка "; err.Code
FINALLY
    PRINT "Завершение"
END TRY
Ошибка MB3001
Завершение

CATCH объявляет переменную ошибки; предварительный DIM не нужен. Переменная доступна только для чтения в своём обработчике и содержит поля Code, Message, Line и Column. Хотя бы один из блоков CATCH или FINALLY обязателен. FINALLY выполняется и при успехе, и при перехваченной ошибке, и при RETURN.

Что перехватывается

CATCH перехватывает ошибки времени выполнения: деление на ноль, выход за границы, неверный ввод, отказ ресурса. Синтаксические и семантические диагностики возникают до запуска и в CATCH не попадают. Отмена выполнения завершает запуск как Cancelled и тоже не попадает в CATCH.

Оператор ERROR

TRY
    ERROR "APP001", "Собственная ошибка"
CATCH err
    PRINT err.Code
    PRINT err.Message
END TRY
APP001
Собственная ошибка

Первый аргумент задаёт код, второй — необязательный текст. Текст сохраняется без перевода; без текста Message имеет вид User error APP002.. Повторная передача ERROR err сохраняет исходное сообщение.

Язык Message

Поле Message содержит английское описание системной ошибки независимо от языка интерфейса IDE. Сообщение в панели «Проблемы» остаётся на языке интерфейса.
