PRINT и PRINT USING

PRINT выводит текст и значения. PRINT USING дополнительно раскладывает значения по полям форматной строки, задавая ширину и вид числа.

Список вывода и разделители

PRINT принимает список выражений, разделённых точкой с запятой или запятой. Выражения вычисляются слева направо. Точка с запятой соединяет части без добавочного символа, запятая вставляет один пробел.

PRINT "Имя: "; "Анна"
PRINT "Курс:", 2
PRINT
PRINT "Готово"
Имя: Анна
Курс: 2

Готово

Завершающий разделитель управляет концом строки: без него PRINT заканчивает строку, а с ; или , — откладывает перевод, и следующий вывод продолжает ту же строку. Пустой PRINT выводит только перевод строки.

Место вывода

Обычная программа печатает в консоль. Когда выбран экран SCREEN, текст попадает в его текстовый слой; размещением внутри экрана управляют средства графики. При запуске через командную строку вывод идёт в стандартный поток.

PRINT USING

Форма PRINT USING ставит перед списком форматную строку типа STRING, за которой обязательно следует точка с запятой. Строковые поля ! и & выводят первый символ или строку целиком; поле \ \ задаёт фиксированную ширину. Числовые маски используют #, 0, ., +, -, ,, $, * и ^.

PRINT USING "Итог: ###.##"; 12.5
PRINT USING "###.##^^^^"; 0.001
Итог:  12.50
  1.00E-03

Маска задаёт ширину поля и число дробных разрядов. Символы ^^^^ включают экспоненциальное представление. Половина округляется от нуля. Если значение не помещается в поле, выводится знак процента и обычное представление числа.

Неверный тип формата даёт MB2003. Несоответствие значения числовому полю, нехватка значения или недопустимая форматная строка — ошибка выполнения MB3007.
