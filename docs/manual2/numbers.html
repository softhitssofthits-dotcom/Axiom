Числа

INTEGER, LONG, DOUBLE и DECIMAL различаются диапазоном и точностью. Выбор типа определяет, как хранится значение и как выполняется арифметика.

Четыре числовых типа

ТипЧто этоКогда применять
INTEGER32-разрядное целоесчётчики, индексы, небольшие суммы
LONG64-разрядное целоебольшие целые, размеры в байтах
DOUBLEдвоичная плавающая точкаизмерения, тригонометрия
DECIMALдесятичное числоденьги, точные десятичные величины

Тип задаётся при объявлении и не меняется при присваивании. Значение другого числового типа преобразуется явно функциями CINT, CLNG, CDBL, CDEC либо неявно по правилам совместимости.

Литералы

Целое без точки получает INTEGER, если помещается в 32 разряда, иначе LONG. Число с точкой читается как DOUBLE, кроме случая, когда ожидается DECIMAL и литерал стоит непосредственно в этом контексте.

DIM count AS INTEGER = 42
DIM big AS LONG = 5000000000
DIM ratio AS DOUBLE = 0.75
DIM price AS DECIMAL = 199.90
PRINT count, big, ratio, price
42 5000000000 0.75 199.90

Шестнадцатеричные и двоичные литералы записываются с префиксами &H и &B; отрицательное значение получается унарным минусом. Внутри числа пробелы недопустимы.

Целочисленные границы

Границы и индексы массивов обязаны быть целыми по значению: 1.0 допустим, 1.5 даёт MB3007. Для округления служат FIX, INT, FLOOR, CEIL и ROUND — их точный договор в карточке ROUND.

Переполнение

Результат целочисленной операции проверяется: PRINT 2147483647 + 1 завершается ошибкой MB3008. Неверный аргумент математической функции, например корень из отрицательного числа, даёт MB3012.
