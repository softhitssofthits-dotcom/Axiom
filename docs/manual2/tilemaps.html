Тайловые карты

TILEMAP, TILESET и SPRITE описывают игровые ресурсы. Карта загружается из формата Tiled и предоставляет геометрию, слои и объекты.

Загрузка

DIM map AS TILEMAP
DIM set AS TILESET
set = LOADTILESET("art/tiles.tsx")
map = LOADTILEMAP("art/level.tmx")
PRINT MAPWIDTH(map), MAPHEIGHT(map)

Загрузчик читает поддерживаемый объём формата Tiled. Неподдержанная форма отклоняется с причиной, а не принимается молча.

Слои и объекты

MAPLAYERCOUNT сообщает число слоёв, MAPLAYERNAME, MAPLAYERTYPE и MAPLAYERVISIBLE — свойства слоя. MAPOBJECTCOUNT и функции MAPOBJECT* описывают объекты. Номера слоёв и объектов начинаются с 0.

Рисование

CANVAS 320, 180
BEGINFRAME
DRAWTILEMAP map, 0, 0
PRESENT

DRAWTILEMAP выводит карту, DRAWTILELAYER — один слой, SETMAPTILE меняет тайл клетки. DRAWTILE выводит отдельный тайл набора.
