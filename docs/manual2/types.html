Типы данных

Тип определяет, какие значения можно хранить и какие операции к ним применимы. Тип переменной задаётся при объявлении и не меняется при присваивании.

Совместимость типов

От совместимости типов зависит, можно ли записать значение в переменную или передать его параметру. Строка не становится числом автоматически: DIM n AS INTEGER = "12" — ошибка MB2003. Для разбора текста предусмотрены функции вроде VAL и DATEVALUE. Допустимые переходы между типами описаны в главе о преобразованиях.

Фиксированная строка

Запись STRING * N хранит ровно N кодовых единиц UTF-16, где N — целая константа от 1 до 65535. Короткое значение дополняется пробелами справа, длинное обрезается.

DIM code AS STRING * 4 = "АБ"
PRINT "[" & code & "]"
code = "АБВГД"
PRINT code
[АБ  ]
АБВГ

Первая строка показывает значение, дополненное до четырёх единиц; вторая — результат обрезки пятисимвольной строки.

Составные данные

Массив хранит набор элементов одного типа с явными границами измерений. Пользовательский тип TYPE объединяет поля и методы. Функциональный тип FUNCTION(...) AS ... позволяет передать функцию как значение. Каждый вид данных описан в своей главе.
