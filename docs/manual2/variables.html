Переменные

Переменная — это именованное место, где хранится значение определённого типа. Объявление вводит имя, а присваивание заменяет хранимое значение.

Объявление

Объявление DIM связывает имя с типом и устанавливает начальное значение. Тип указывается после AS; если задано начальное выражение, тип можно опустить — компилятор выведет его сам.

DIM count AS INTEGER = 2
DIM title = "Отчёт"
DIM price AS DOUBLE
PRINT count, title, price
2  Отчёт  0

count объявлена с явным типом INTEGER, title получила тип STRING по литералу, а price без начального выражения приняла значение по умолчанию 0. Опустить одновременно и тип, и начальное выражение нельзя — это ошибка MB2017.

Присваивание

Присваивание записывает в переменную новое значение. Оно не объявляет имя: обращение к необъявленному имени — ошибка MB2001.

DIM count AS INTEGER = 2
count = count + 1
PRINT count
3

Правая часть вычисляется до записи, поэтому в ней можно читать прежнее значение той же переменной. Здесь count + 1 берёт старое значение 2 и записывает результат 3 обратно в count.

Целью присваивания может быть переменная, элемент массива или поле записи. Тип цели сохраняется: записать в INTEGER строку нельзя, а значение другого числового типа преобразуется по правилам совместимости.

Значения по умолчанию

Когда начальное выражение не задано, переменная получает значение по умолчанию своего типа.

ТипНачальное значение
INTEGER, LONG, DOUBLE, DECIMAL0
BOOLEANFALSE
STRINGпустая строка
DATE0001-01-01
TIME00:00:00
DATETIME0001-01-01 00:00:00
UTCDATETIME0001-01-01T00:00:00Z

Область видимости

Имя доступно только в той части программы, где оно объявлено, и во вложенных блоках. Переменная, объявленная внутри ветви IF, после END IF недоступна. Локальная переменная подпрограммы недоступна вызывающему коду. Полные правила, включая глобальные переменные модуля и замыкания, — в разделах о процедурах и модулях.
