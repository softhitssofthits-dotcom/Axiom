Файлы

Программа открывает текстовые файлы через OPEN, читает и записывает их, а также работает с путями, каталогами и метаданными.

Открытие и режимы

DIM f AS FILE
OPEN "data.txt" FOR OUTPUT AS f
WRITE(f, "строка")
CLOSE f

OPEN "data.txt" FOR INPUT AS f
PRINT READLINE(f)
CLOSE f
строка

Режим INPUT открывает файл для чтения, OUTPUT создаёт или перезаписывает, APPEND добавляет в конец. Использование операции не по режиму даёт MB3005. Необязательная часть USING задаёт кодировку.

Чтение и запись

READLINE читает строку, READLINES — несколько строк, READTOEND — остаток до конца. WRITELINE добавляет перевод строки, WRITE пишет текст без него. EOF проверяет досягаемость конца, FILEPOS и SEEKFILE работают с позицией.

Файл целиком

DIM path AS STRING = "manual2-demo.txt"
DIM ok AS BOOLEAN
ok = WRITEFILE(path, "строка")
PRINT ok
PRINT READFILE(path)
PRINT DELETEFILE(path)
TRUE
строка
TRUE

READFILE, READALLLINES, WRITEFILE и APPENDFILE работают без OPEN. APPENDFILE проверяет существующее содержимое перед изменением, поэтому для серии записей надёжнее держать файл открытым в режиме APPEND.

Пути

Пути разрешаются относительно рабочей папки запуска. COMBINEPATH соединяет части, FILENAME и EXTNAME выделяют имя и расширение, ISABSOLUTEPATH проверяет абсолютность. GETFILES и GETDIRS принимают маску только для имени внутри указанного каталога.

Каталоги

MAKEDIR создаёт каталог, DELETEDIR удаляет пустой, DELETEDIRRECURSIVE — вместе с содержимым. MOVEDIR, RENAMEDIR и COPYDIR изменяют каталоги. Копирование не является транзакцией: уже выполненная часть сохраняется при ошибке.
