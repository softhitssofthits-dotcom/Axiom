Клавиатура и мышь

Программа может опрашивать состояние клавиатуры и мыши или регистрировать обработчики, которые вызываются при событии.

Клавиатура

DIM key AS INTEGER
key = INKEY()
IF KEYDOWN("ESC") THEN
    PRINT "Выход"
END IF

INKEY возвращает код ближайшей нажатой клавиши или 0. KEYDOWN проверяет удержание клавиши, KEYPRESS — нажатие с момента предыдущего опроса. Имена клавиш не зависят от регистра.

Мышь

MOUSEX и MOUSEY возвращают координаты в пикселях поверхности, MOUSEBUTTON — состояние кнопки, MOUSEPRESS — ближайшее событие нажатия. Опрос требует выбранного режима: без SCREEN или CANVAS обращение даёт MB2046.

SCREEN 1
PRINT MOUSEX(), MOUSEY()
IF MOUSEBUTTON(1) THEN
    PRINT "Кнопка нажата"
END IF

Обработчики

SUB OnEscape()
    PRINT "Нажата ESC"
END SUB

ON KEY("ESC"), OnEscape
ON MOUSE(1, "DOWN"), OnClick

Обработчик регистрируется командой ON KEY или ON MOUSE и снимается словом OFF. STOP приостанавливает вызов, сохраняя регистрацию. Обработчик выполняется между инструкциями программы и не прерывает текущую инструкцию посередине.

Пауза

SLEEP приостанавливает программу. Без аргумента она ждёт нажатия клавиши, с числовым аргументом — указанное число миллисекунд: SLEEP 10 задерживает выполнение на 10 мс.
