## 2026-10-11 20:16 — Пустой новый документ закрывается без вопроса о сохранении

Язык **0.1.0** · компилятор/CLI **0.1.0** · IDE **0.1.1**

Пустой новый документ не помечается изменённым и закрывается без вопроса о сохранении. Правило распространяется на закрытие вкладки/окна и на возврат нового буфера к пустому состоянию. Непустой новый документ сохраняет запрос подтверждения; пробелы и переводы строк считаются содержимым. Удаление текста сохранённого файла остаётся изменением, требующим сохранения.

## 2026-10-12 08:18 — Подсказки редактора используют типы и области видимости компилятора

Язык **0.1.2** · компилятор/CLI **0.1.2** · IDE **0.2.2**

Подсказки редактора используют типы и области видимости компилятора

Подробности изменения: типы переменных и массивов, выведенные типы, константы, параметры, поля TYPE и подписи пользовательских процедур/функций берутся из семантического анализа с учётом области видимости. Исправлены показ выражений интерполяции, обработка комментариев и строк, подсчёт аргументов вложенных вызовов и выбор перегрузки. Кеш привязан к редакции модели. Поведение исполнения языка не меняется; номера языка и компилятора повышены согласно консервативному правилу для изменений языкового ядра и запускаемых примеров.
