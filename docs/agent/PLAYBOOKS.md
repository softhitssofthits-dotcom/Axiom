# Рабочие сценарии

## Изменение языка

Прочитать действующий план и договор; проверить имя и семантику по BASIC-семейству и проектным источникам. Изменить нужный слой языка и VM. Добавить независимые проверки, короткий русский `.axm`-пример, подробную статью справочника, индекс/поиск и Monaco-подсветку. Сверить реестр компилятора и справочник. Обновить SPECIFICATION3, покрытие/производительные сценарии при необходимости, PLANS4 и WORKLOG5.

## Изменение Electron IDE

Выбрать конкретный незавершённый критерий из матрицы. Использовать существующий сценарий ide/e2e, изолированный профиль и принадлежащий проверке процесс. Не заменять проверку интерфейса только наличием IPC-пакетов. После изменений выполнить адресные проверки; более широкий набор — по изменённым рискам. Зафиксировать результат, ограничения и следующий шаг.

## Изменение документов

Сверить сведения с текущим кодом и последними результатами. Перед архивированием проверить открытые пункты и сохранить действительные остатки в UNFINISHED_WORK. Обновить относительные ссылки и реестр документов. Журналы вести последовательно; менять старую структуру только по прямому поручению на ревизию.

## Продолжение сессии

Сначала обязательные документы из AGENTS.md. Затем CURRENT_STATE и ARCHITECTURE_MAP, при необходимости scripts/ai-context.ps1. Архивные сведения не считать текущим состоянием. Последовательность работ — PLANS4, полный остаток — UNFINISHED_WORK.
