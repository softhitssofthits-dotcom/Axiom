# Текущее состояние Axiom

Снимок на 16 октября 2026 года. Рабочая IDE — Electron; исполнитель языка — `BytecodeVm` через `Axiom.DesktopHost`. Источники продолжения: [PLANS4](../PLANS4.md), [WORKLOG5](../WORKLOG5.md), [SPECIFICATION3](../SPECIFICATION3.md), [ARCHITECTURE](../ARCHITECTURE.md), [UNFINISHED_WORK](../plans/UNFINISHED_WORK.md). Номера версий берутся только из `versions.json`.

Версии: язык **0.1.15**, компилятор **0.1.15**, IDE **0.6.14**.

## Завершённые возможности

- Язык Axiom: числовые, строковые и временные типы, массивы, пользовательские `TYPE` с методами, процедуры и функции, обработка ошибок, текстовые файлы, регулярные выражения, две системы графики (`SCREEN`, `CANVAS`), изображения, спрайты, тайлсеты и тайловые карты. Точный объём — [реестр языка](../registries/LANGUAGE.md).
- Исключительное сохранение документов и восстановление завершённых правок после аварии; ограничения носителя/питания, двух повреждённых снимков и истории отмены записаны в договоре.
- Независимое восстановление бесконечно зависшего renderer в основном процессе Electron.
- Переносимая папка Windows x64 (`scripts/package-ide.mjs`) проходит локальные проверки без SDK/Git/Node. Отдельный чистый компьютер исключён автором из очереди.
- Четыре глобальные темы (светлая, тёмная, QuickBASIC, Borland Pascal), общий реестр `themes.js`, диалог и поэлементная проверка 261 параметра Monaco.
- Навигатор подпрограмм, тематические группы `#region`/`#endregion` и помощник связей вызовов.
- Графика на GPU: `CANVAS` и `SCREEN 1..10` через DirectX, `SCREEN 0` — текстовый режим; `SMOOTH ON/OFF` для готового кадра.
- Двоичные литералы `&B`, точные `&H`/`&B`, однострочный `IF`, исправления `PAINT`/`CIRCLE`/`LINE`.

## Текущая работа и проверки

Ведётся стабилизация существующего исполнения и оболочки: отказы и запоздалые ответы команд привязываются к своей сессии, документу и снимку. 16 октября закрыты по одному этапу: отказы команд отладки (IDE 0.6.9), Stop/Restart (0.6.10), отправки INPUT (0.6.11), фоновой диагностики документа (0.6.12), консольного редактирования INPUT (0.6.13), принадлежность владельца исполнения при `Сохранить как` на паузе (0.6.14). Каждый этап подтверждён адресными проверками Node/Electron и отчётом в `docs/reports/electron/`.

Каталог приёмки — `ide/e2e/SCENARIOS.json` (456 сценариев). Число сценариев не означает число прошедших проверок: полного прогона расширенного каталога после этих этапов не выполнялось, каждый этап закрывался адресной выборкой.

Следующий точный шаг — актуальность результатов и отказов форматирования (правка, смена/закрытие документа, запоздалый ответ, защита исполняемой модели). Полная очередь — [PLANS4](../PLANS4.md) и [UNFINISHED_WORK](../plans/UNFINISHED_WORK.md).

## Открытые границы

- Второй монитор недоступен; разные DPI на двух мониторах, перенос окон и отключение монитора не проверены. Доступные масштабы Windows 100/125/150/175% и физическая мышь `SCREEN` приняты.
- Матрица Electron `docs/plans/IDE_SHELL_FEATURE_MATRIX.csv` содержит условия с частичным доказательством; их полная приёмка не заявлена.
- Независимые ожидания граничных случаев всех форм BytecodeVm и общий аудит форм не завершены.
- Многофайловые проекты и модули, новые конструкции языка и расширения Tiled отложены.
