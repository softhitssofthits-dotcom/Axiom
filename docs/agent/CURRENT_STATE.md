# Текущее состояние Axiom

Актуализация: 15 октября 2026 года. Рабочая IDE — Electron, исполнитель — BytecodeVm через DesktopHost. Источники продолжения: PLANS4, WORKLOG5, SPECIFICATION3/ARCHITECTURE и UNFINISHED_WORK. Версии берутся только из versions.json; после исправления нативного INPUT — язык 0.1.15, компилятор 0.1.15, IDE 0.6.1.

## Завершённые возможности

- Исключительное сохранение и восстановление завершённых правок после аварии реализованы; ограничения питания, носителя, двух повреждённых снимков и истории отмены остаются в договоре.
- Независимое восстановление бесконечно зависшего renderer реализовано в основном процессе Electron. Повторно разрабатывать его не требуется.
- Переносимая папка Windows x64 собирается и прошла локальные 11 проверок без доступных SDK/Git/Node. Отдельный чистый компьютер исключён автором из очереди, а не объявлен проверенным.
- Автор принял доступные системные DPI 100/125/150/175% и физическую мышь SCREEN. Второй монитор остаётся недоступным.
- Четыре глобальные темы, диалог настроек и поэлементная проверка 261 пункта завершены в объёме EDITOR_SETTINGS_LIVE_AUDIT.md; недоступные возможности явно отключены.
- Навигатор подпрограмм, тематические группы и помощник связей реализованы. Готовность команд трассировки при запуске исправлена.
- Двоичные литералы, однострочный IF и исправления PAINT/CIRCLE/LINE реализованы и документированы.
- CANVAS и SCREEN 1..10 используют DirectX; SCREEN 0 сохраняет текстовый путь. Перенос SCREEN опубликован в 719d35a. Результаты: SCREEN_DIRECTX_MIGRATION.md.

## Текущая работа и проверки

Согласование завершения нативного INPUT с Electron и сохранение фокуса SCREEN исправлены в рабочей копии. Новая оконная приёмка SCREEN 0/1 и соседние сценарии: 14/14, 121 утверждение; проверки контроллера/связи: 10/10. Итог — [ревизия документов](../reports/DOCUMENTATION_REVIEW_20261015.md) и конец WORKLOG5. Консольный INPUT CANVAS не превращается в новый графический текстовый режим. Коммит и push этого исправления ещё не выполнялись.

Каталог сценариев определяется ide/e2e/SCENARIOS.json. Число сценариев не означает число прошедших проверок. Сохранённый полный результат Session 1387 — 102/102 и 574 утверждения; после него выполнялись отдельные адресные наборы. Для переноса SCREEN сохранены 164/164 проверки .NET и 20 различных сценариев Electron / 110 утверждений. Полный прогон текущего расширенного каталога не заявлен.

Следующие независимые остатки — условия матрицы за пределами доказанных сценариев и второй монитор. Многофайловые проекты и новые предложения языка не входят в текущую стабилизацию. Полный остаток: [UNFINISHED_WORK.md](../plans/UNFINISHED_WORK.md).
