## Стабильная база

- Ядро языка, интерпретатор, `BytecodeVm`, пайплайн выполнения и WPF-оболочка IDE уже работают.
- Активные источники правды проекта: `PROJECT.md`, `docs/SPECIFICATION3.md`, `docs/ARCHITECTURE.md`, `docs/PLANS4.md`, `docs/WORKLOG5.md`.
- Пользовательский manual живёт в `docs/manual/`.
- Для новых наблюдаемых изменений языка обязательны автотесты, runnable `.axm`-пример, обновление manual и запись в активные реестры.

- Интерпретаторная архитектура остаётся базовой.

- Слои lexer / syntax / parser / semantics / runtime / IDE не смешиваются.
- `docs/PLANS4.md` и `docs/WORKLOG5.md` остаются единственными активными проектными журналами плана и непрерывности.
- Вспомогательные агентные документы не должны расходиться с каноническими документами.
