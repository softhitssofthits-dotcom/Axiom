# Текущее состояние Axiom

Снимок на 16 октября 2026 года. Рабочая IDE — Electron; исполнитель языка — `BytecodeVm` через `Axiom.DesktopHost`. Источники продолжения: [PLANS4](../PLANS4.md), [WORKLOG5](../WORKLOG5.md), [SPECIFICATION3](../SPECIFICATION3.md), [ARCHITECTURE](../ARCHITECTURE.md), [UNFINISHED_WORK](../plans/UNFINISHED_WORK.md). Номера версий берутся только из `versions.json`.

Версии: язык **0.1.19**, компилятор **0.1.19**, IDE **0.6.22**.

## Завершённые возможности

- Язык Axiom: числовые, строковые и временные типы, массивы, пользовательские `TYPE` с методами, процедуры и функции, обработка ошибок, текстовые файлы, регулярные выражения, две системы графики (`SCREEN`, `CANVAS`), изображения, спрайты, тайлсеты и тайловые карты. Точный объём — [реестр языка](../registries/LANGUAGE.md).
- Исключительное сохранение документов и восстановление завершённых правок после аварии; ограничения носителя/питания, двух повреждённых снимков и истории отмены записаны в договоре.
- Независимое восстановление бесконечно зависшего renderer в основном процессе Electron.
- Переносимая папка Windows x64 (`scripts/package-ide.mjs`) проходит локальные проверки без SDK/Git/Node. Отдельный чистый компьютер исключён автором из очереди.
- Четыре глобальные темы (светлая, тёмная, QuickBASIC, Borland Pascal), общий реестр `themes.js`, диалог и поэлементная проверка 261 параметра Monaco.
- Навигатор подпрограмм, тематические группы `#region`/`#endregion` и помощник связей вызовов.
- Графика на GPU: `CANVAS` и `SCREEN 1..10` через DirectX, `SCREEN 0` — текстовый режим; `SMOOTH ON/OFF` для готового кадра.
- Двоичные литералы `&B`, точные `&H`/`&B`, однострочный `IF`, исправления `PAINT`/`CIRCLE`/`LINE`.
