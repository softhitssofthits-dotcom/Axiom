# Текущее состояние Axiom

Рабочая IDE — Electron (`ide/`), язык исполняет BytecodeVm через DesktopHost. Единственные активные журналы — PLANS4 и WORKLOG5. Подробный текущий договор — SPECIFICATION3/ARCHITECTURE; пользовательский справочник — manual/.

Последний продуктовый этап Session 1363: исключительное сохранение и восстановление документов после аварии. Сохранённый результат Electron: 85/85, 466 утверждений; Node: 73/73. Это результаты предыдущего этапа, не повтор на текущем компьютере.

Следующий точный шаг: бесконечное зависание интерфейса с доступной отменой. Затем системные DPI, несколько мониторов и физическая мышь SCREEN; далее остальные условия приёмки Electron и поставка. Многофайловые проекты отложены.

Полный остаток и отличия выполненного от идей — [UNFINISHED_WORK.md](../plans/UNFINISHED_WORK.md). Проверенные результаты ревизии документации — [отчёт](../reports/DOCUMENTATION_REVIEW_20261011.md). Старые планы не задают новую очередь.

С Session 1375 действует обязательное сопровождение версий: читать versions.json, [VERSIONING.md](../VERSIONING.md) и последнюю запись [CHANGELOG.md](../CHANGELOG.md). Перед завершением изменяющей задачи повысить затронутые номера и проверить согласованность. Session 1376: пустой новый документ закрывается без запроса сохранения; версия IDE повышена отдельно.

Последние локальные изменения Sessions 1365–1367: перенос между последовательными INPUT, различие разделителей приглашения по договору QuickBASIC и автоматическое открытие «Проблем» при красном маркере ошибки. INPUT проверен адресно: 4 сценария/23 утверждения. Автоматическое открытие панели пока проверено просмотром кода, без GUI-прогона.

Session 1368: в консоли добавлено контекстное меню копирования выделенного текста и очистки истории с сохранением текущего INPUT. Доработка пока проверена просмотром кода, без GUI-прогона.

Session 1369: устранена воспроизведённая гонка reset/write в xterm. Адресный набор INPUT — 4 сценария/35 утверждений; включает два снимка в одной очереди и пять быстрых повторных запусков. Прежняя проверка с синхронной имитацией терминала не покрывала эту гонку.
