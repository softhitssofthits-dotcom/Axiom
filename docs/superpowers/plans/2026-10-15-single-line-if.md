# Однострочный IF

Согласовано автором 15 октября 2026 года. Цель — формы `IF условие THEN оператор` и `IF условие THEN оператор ELSE оператор`, без END IF и без разделения операторов двоеточием.

Архитектура: парсер различает формы по наличию инструкции после THEN на той же строке. Обе формы передают существующему связывателю один IfStatementSyntax; BytecodeVm использует прежнее ветвление. Условие BOOLEAN и отдельные области видимости ветвей сохраняются. В короткой форме нет ELSEIF, вложенных IF и открывающих блок операторов; комментарий после THEN без инструкции оставляет форму блочной. Перенос строки завершает короткую форму. Пустые ветви и лишние операторы вызывают диагностику.
