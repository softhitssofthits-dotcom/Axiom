# Архив документации Axiom

Здесь сохранены прежние планы, результаты и снимки состояния. Они содержат историю реализации и устаревшие договоры. **Архив не является инструкцией текущего запуска или продолжения.** Рабочий интерфейс — Electron; действующая очередь: [PLANS4](../PLANS4.md), полный остаток: [UNFINISHED_WORK](../plans/UNFINISHED_WORK.md).

Ревизия 11 октября 2026 года перед переносами проверила открытые пункты и сохранила исходный контекст. Папки `root-documents-20261011`, `audits-through-20261011`, `plans-through-20261011`, `meta-20260826` и `state-before-20261011` содержат перенесённый материал. Более ранние архивные папки сохранены.

Архивные упоминания прежних исполнителей, интерфейсов и старых результатов не являются действующей архитектурой. Полный перечень кандидатов — unfinished-candidates-20261011.json; карта перемещений — moves-20261011.csv. Нельзя объявлять историческую находку новым дефектом без воспроизведения.

Ссылки архивных документов перенастроены с учётом перемещения. Файловые артефакты старых проверок в .artifacts не обязаны присутствовать на другом компьютере; переносимые результаты используют отдельные сохранённые сводки.
