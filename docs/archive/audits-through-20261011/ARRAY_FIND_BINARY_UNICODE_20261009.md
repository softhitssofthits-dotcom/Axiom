# Координаты и двоичный поиск Unicode

Session1275. ArrayFindBinaryUnicodeEvidenceTests добавляет4 групповых случая обоих движков с буквальными ожидаемыми результатами. Для ARRAYBINARYSEARCH с двумя и тремя аргументами массив задан заранее в порядке UTF-16: пустая строка, NUL, составной акцент, предварительно составленный символ, старший суррогат, эмодзи, U+E000. Результат поиска младшего суррогата — отсутствие. Эмодзи находится раньше U+E000; это порядок UTF-16, не порядок скалярных значений Unicode.

Соседние LONG выше2^53 остаются различными. Из дубликатов возвращается первый; значение непосредственно ниже LONG.MaxValue отсутствует, само максимальное значение найдено. Источник не меняется.

ARRAYFINDALL на двумерном видимом срезе возвращает только две пары координат0/6 и1/7. Совпадение за пределами среза исключено; целый старший суррогат с NUL не приравнивается к эмодзи или отдельному младшему суррогату. Одномерный массив с составным акцентом возвращает исходные логические индексы, не приравнивая предварительно составленный символ.
