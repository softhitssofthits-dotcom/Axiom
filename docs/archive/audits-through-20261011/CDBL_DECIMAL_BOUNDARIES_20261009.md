# CDBL из точного DECIMAL

Session1232, 2026-10-09. Сверен NumericPromotionContractTests: обычные значения и9007199254740993 уже покрывались. Новый DecimalToDoubleBoundaryEvidenceTests добавляет32 случая двух движков.

Через INPUT непосредственно в DECIMAL задаются семь соседних целых от2^53−1 до2^53+5, каждый с обоими знаками. CLNG(CDBL(value)) сравнивается с буквальным ожидаемым представимым целым; исходный DECIMAL выводится без изменения. Для ±10^-28 отдельно доказаны ненулевой DOUBLE, правильный знак и модуль меньше10^-27, но не точная битовая округлённая дробь. Проверены один вызов ввода и фактический движок.

Совместно с NumericPromotionContractTests — **132/132**, ошибок/пропусков0; .artifacts/test-results/cdbl-decimal-1232/cdbl-decimal-1232.trx. Дефект не обнаружен. Runtime/руководство/наблюдаемое поведение не менялись, новый запускаемый пример не требуется, полный набор не повторялся.

Предел: перечисленные целые и свойства минимальной дроби, не все DECIMAL, не отдельная проверка каждого бита DOUBLE, не все исходные числовые типы. CLNG используется как наблюдение точного целого результата, а не как независимый тест всего преобразования CLNG.
