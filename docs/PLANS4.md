# Текущий план Axiom

Актуализация: 16 октября 2026 года. Рабочий продукт — Electron IDE и компилятор/BytecodeVm на .NET. Полная очередь и её приоритеты: [UNFINISHED_WORK.md](plans/UNFINISHED_WORK.md). Действующий план оболочки: [ELECTRON_IDE_PLAN.md](plans/ELECTRON_IDE_PLAN.md).

Версии на дату обновления (единственный источник — `versions.json`): язык **0.1.15**, компилятор **0.1.15**, IDE **0.6.14**. Каталог Electron — `ide/e2e/SCENARIOS.json` (456 сценариев); размер каталога не равен числу пройденных проверок.

## Где остановились

Из последнего опубликованного этапа: IDE 0.6.14 закрывает принадлежность владельца исполнения при `Сохранить как` на паузе (F9, очистка точек, перенос точки при правке/Undo, повторное открытие) — Session 1503, `docs/reports/electron/TRACE_POINTS_SAVEAS_STABILITY.md`.

До этого, 16 октября, единым этапом закрыты отказы команд отладки (IDE 0.6.9), Stop/Restart (0.6.10), отправки INPUT (0.6.11), фоновой диагностики документа (0.6.12), консольного редактирования INPUT (0.6.13). Каждая задача — с адресными проверками Node/Electron и отчётом в `docs/reports/electron/`. Полного прогона всего расширенного каталога Electron после этих этапов не выполнялось.

## Следующий точный шаг

**Актуальность результатов и отказов форматирования.** Проверить, что результат форматирования, поздние ответы и отказы привязаны к текущему документу и снимку: правка, смена/закрытие документа, запоздалый ответ прежнего запроса, защита исполняемой модели. Сначала сверить существующие проверки и воспроизвести конкретное нарушение; новых языковых сущностей не добавлять.

## Затем

1. Остальные адресные участки очереди отказов существующих функций: оставшиеся условия IDE15–29 и IDE37–41 по матрице.
2. Второй монитор и оставшиеся независимые условия матрицы `docs/plans/IDE_SHELL_FEATURE_MATRIX.csv` (редактор/документы, трассировка, настройки, журнал, локализация, доступность).
