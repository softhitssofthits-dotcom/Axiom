# Действующие графические поверхности

SCREEN и CANVAS — две поддержанные поверхности языка Axiom. Electron отображает отдельное окно CANVAS, а DesktopHost создаёт нативное окно SCREEN. Координаты и преобразования вычисляет VM; интерфейс передаёт события и готовые кадры.

CANVAS поддерживает BEGINFRAME/PRESENT, DRAW*/FILL*, изображения, спрайты, CAMERA/RESETCAMERA/VIEWPORT и тайловые карты. Поддержанные формы PSET/PRESET, POINT, PAINT и GET/PUT следует применять по их справочным страницам. Индекс палитры POINT и RGB-код не являются взаимозаменяемыми результатами.

Точные формы, единицы, ограничения и границы: [графика](../manual/graphics.html), [примитивы](../manual/graphics-primitives.html), [современная графика](../manual/modern-graphics.html), [тайловый договор](TILEMAP.md).

Клавиатура и мышь используют разные договоры состояния и очереди событий. При потере фокуса удержанные состояния освобождаются. Отмена INPUT и закрытие поверхности принадлежат текущей сессии. Проверены выбранные реальные события CANVAS и клавиатуры SCREEN; полная аппаратная матрица DPI/мониторов/мыши SCREEN остаётся открытой.

Планы удобной анимации, столкновений и перевода Maze Chase на TILEMAP не объявляются реализованными только по наличию DRAWSPRITE. См. [UNFINISHED_WORK.md](../plans/UNFINISHED_WORK.md).
