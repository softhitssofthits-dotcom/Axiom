## Различение дефектов и потребностей

Новых дефектов исполнителя не подтверждено. CHR(ASC("é")) не возвращает "é" из-за исторической подмены младшего диапазона; уже существующая пара CHRW/ASCW решает задачу. Новая функция для этого не нужна. Обрезка явного набора работает по UTF-16, REVERSE сохраняет пары, но не графемы. Это разные договоры, которые теперь прямо описаны в manual; потребность в отдельном графемном API без сценария не подтверждена.
