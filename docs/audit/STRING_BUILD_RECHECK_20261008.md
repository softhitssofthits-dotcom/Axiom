## Документация и потребности

Manual построения поясняет UTF-16, первый заполнитель, границы INSERT/REMOVE, четыре отдельные формы SPLIT/JOIN и запятую по умолчанию. При нечётном дополнении CENTER дополнительная единица находится справа. Для повторения всего Unicode-фрагмента уже есть REPEAT; новый дубль STRING не требуется. Для разделения по строке, включая эмодзи, уже есть SPLIT(text, separator); отдельный Unicode-разделитель не нужен. Нормализация/графемы и ширина экранного символа не доказываются этой моделью строк и не добавляются без сценария.

Первый редакционный ориентир SPACE/STRING — Зельднер, страницы 295–296. SPLIT из книги относится к экранному разделению, не массивам; жанровые ориентиры для строковых массивов — [Microsoft Learn Split](https://learn.microsoft.com/en-us/dotnet/api/microsoft.visualbasic.strings.split?view=net-10.0), [Join](https://learn.microsoft.com/en-us/dotnet/api/microsoft.visualbasic.strings.join?view=net-10.0). Исторические разделители по умолчанию и модели пустого результата VB не перенесены.
