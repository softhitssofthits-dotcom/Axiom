## Внешний формат

Актуальная официальная [спецификация JSON Tiled](https://doc.mapeditor.org/en/stable/reference/json-map-format/) описывает properties как массивы на карте, слоях, объектах и тайлах, а objects как массив объектного слоя. Это ориентир формы входных данных; объём Axiom определяется проектным договором. Большие фрагменты внешнего текста не копировались.

## План исправления и границы

Полное закрытие исходного договора требует сохранения типизированных входных свойств с утверждённой текстовой нормализацией, модели объектов и их геометрии/класса/видимости, чтения inline/внешних тайлсетов, функций доступа, диагностики неправильных/неподдержанных форм, обоих движков, manual/подсветки/примеров. Добавление одной функции поверх пустой модели проблему не исправит. Один отказ загрузки карты лишь остановил бы молчаливую потерю, но не реализовал утверждённую возможность.

Перед изменениями нужно сопоставить точный набор из действующего договора с моделями, реестром, загрузчиком и текущими ручными страницами, выбрать общий путь нормализации и добавить проверки необходимых полей/типов. Текущие отрицательные тесты сохраняют свидетельство исходного состояния; после реализации их ожидания потребуется пересмотреть, не оставить отсутствие API условием успеха.

Заголовок TILEMAP_CONTRACT «код этого слоя ещё не реализован» уже не отражает существующие TILEMAP/загрузку/рисование/клетки. Ниже к документу добавлена датированная проверка состояния без удаления исходного проектного договора. Runtime в этой сессии не изменён. Общий аудит продолжается.
