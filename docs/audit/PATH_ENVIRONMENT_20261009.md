# Раскрытие переменных окружения в путях

Session1224, 2026-10-09. Проверены функции пути и чтение настоящего файла с русским именем и emoji.

PathEnvironmentEvidenceTests создаёт уникальную переменную окружения с полным путём к собственному каталогу .artifacts и настоящий текстовый файл. В обоих движках FULLPATH, READFILE, FILEEXISTS, FILENAME, DIRNAME и EXTNAME используют раскрытую переменную; ISABSOLUTEPATH возвращает TRUE. COMBINEPATH сохраняет буквальное %ИМЯ% и только соединяет компоненты. Ожидаемый путь и содержимое заданы независимо от раскрытия CLR; после проверки исходное значение переменной восстанавливается, файл удаляется без рекурсивного обхода.

Для уникальной неизвестной переменной FULLPATH сохраняет %ИМЯ% как буквальный компонент и разрешает строку относительно базы программы; ISABSOLUTEPATH возвращает FALSE; COMBINEPATH сохраняет компонент. Каталог результата не создаётся. Эти4 новых случая проверяют Windows данного компьютера, не общую грамматику всех операционных систем.

Два дополнительных случая запускают `samples/functions/isabsolutepath/environment_expansion.axm`, проверяют вывод относительно установленной TEMP и отсутствие создания целевого файла. Эти ожидания являются проверкой примера относительно окружения, а не независимым доказательством алгоритма раскрытия.

## PATH26-004 — неточное описание ISABSOLUTEPATH

P4, ошибка документации: руководство обещало проверку абсолютности «в исходной записи», хотя реализация обоих движков раскрывает переменные до Path.IsPathFullyQualified. Вызов со строкой %ИМЯ% и существующей переменной, содержащей полный путь, возвращает TRUE. Это не обнаруженный дефект реализации: общий файловый договор допускает раскрытие. Исправлено руководство: явно указаны раскрытие, сохранение неизвестной переменной, отличие от FULLPATH/COMBINEPATH и отсутствие проверки существования файла. Добавлен короткий пример и ссылка на запускаемую программу. Нового API или изменения наблюдаемого поведения нет.

Редакционный ориентир для функций пути — ранее прочитанная официальная [Visual Basic FileSystem.GetName](https://learn.microsoft.com/en-us/dotnet/api/microsoft.visualbasic.fileio.filesystem.getname?view=net-10.0); факты Axiom проверены по реализации и тестам, чужая семантика не переносилась. Полный текст Зельднера на этом компьютере недоступен, точный книжный раздел не заявлен прочитанным.

Предел: не проверены рекурсивное раскрытие переменных, все виды значений, изменение окружения одновременно с запуском, URI и пути всех платформ. Успех ISABSOLUTEPATH не является проверкой допустимости формата пути; поведение классификатора на NUL не изменено.

Следующий участок — файловые сведения при путанице файла и каталога: FILESIZE/FILEDATE/DIRDATE и атрибуты, отсутствие изменения данных. Сначала сверить прежние FileMetadataEvidenceTests и пользовательский договор, затем выбирать конкретный неподтверждённый случай.
