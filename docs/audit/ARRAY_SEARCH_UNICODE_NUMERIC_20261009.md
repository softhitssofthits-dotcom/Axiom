# Поиск в массивах: Unicode и точные числа

Session1274. ArraySearchUnicodeNumericEvidenceTests добавляет четыре групповых случая обоих движков с буквальными ожидаемыми результатами. ARRAYCOUNT/ARRAYCONTAINS/ARRAYINDEXOF/ARRAYLASTINDEXOF сравнивают целые значения UTF-16: отдельный суррогат не является эмодзи, строка с NUL отличается от её префикса, составной акцент отличается от предварительно составленного символа. Пустая строка считается целым значением. Видимый срез исключает внешний элемент; логические индексы сохраняются, исходные элементы не меняются.

Соседние LONG 9007199254740992/9007199254740993 и значения у LONG.MaxValue различаются. Соседние DECIMAL у максимума различаются без округления в DOUBLE. Ожидания заданы явно, не вычисляются проверяемым помощником.

Итог39/39 вместе с ArraySearchContractTests/ArraySearchFormEvidenceTests; ошибок/пропусков0, запасной интерпретатор не использован. Прежние проверки подтверждают точные формы/типы, координаты многомерных массивов, отсутствие результата, пустые/нераспределённые массивы, несовместимые типы и крайние индексы. Результат: .artifacts/test-results/array-search-1274/array-search-1274-literals.trx.

Первые три запуска числовой части не дошли до исполнения из-за неверного синтаксиса теста: суффиксы L/D и строковый аргумент CLNG/CDEC не поддерживаются. Исправлены только тестовые программы: LONG выводится из целого литерала, DECIMAL задаётся контекстным литералом с .0. Ошибки теста не являются дефектами языка.

Дефект не найден; Runtime/руководство/поведение не менялись, новый пример не требуется. Проверка ограничена перечисленными случаями. NUM26-CAND-001 и IDE26-CAND-001 открыты. Далее ARRAYFINDALL/ARRAYBINARYSEARCH и независимые координаты Unicode/точных чисел.

Уточнение счётчика по фактическому CSV1274:161 форма SCOPED_EVIDENCE и174 NOT_REVIEWED_IN_RESUMED_PASS, всего335. Числа162/173 выше ошибочны; предыдущий CSV1273 содержит157/178, а не158/177. При дальнейшем учёте использовать группировку CSV, а не перенос чисел из текста.
