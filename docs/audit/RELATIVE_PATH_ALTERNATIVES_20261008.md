## Договор и границы

FULLPATH разрешает неполный путь относительно текущего каталога программы. Для базы D:\Проект\данные: файл.txt → D:\Проект\данные\файл.txt; \файл.txt → D:\файл.txt; D:файл.txt → D:\Проект\данные\файл.txt. Другой неполный диск C:файл.txt разрешается от C:\, без скрытого текущего каталога диска процесса. Для UNC-базы \\server\share\папка запись \файл.txt сохраняет \\server\share\. Полностью абсолютная запись сохраняет собственный корень. Пустая строка возвращает текущий каталог; функции не создают и не требуют наличия файлов.

COMBINEPATH остаётся соединением строк: сохраняет .. и допускает замену левой части корневой правой записью. FULLPATH нормализует результат. Ни COMBINEPATH, ни FULLPATH не вычисляют относительный маршрут между двумя произвольными абсолютными путями и не обеспечивают удержание пути внутри каталога.

## Классификация кандидата

Разрешение и нормализация уже известного относительного пути доступны; отдельный дефект базы исправлен. RuntimeTilemapValue.ResolveRelativePath также разрешает ссылку, а не строит её из двух абсолютных адресов. Path.GetRelativePath найден в IdeSmokeHarness для подписи тестовых артефактов; это не callable API языка. Общий построитель относительного маршрута действительно отсутствует, но обязательный текущий сценарий языка не установлен; кандидат остаётся отложенным удобством. Удаление текстового префикса не предлагается как общий алгоритм.
