# PATH26-003: загрузка ресурса по обрезанному пути

Session 1221, 2026-10-09. P2, отдельное место того же механизма Windows, которое не использует NormalizeFileSystemPath.

## Исходное доказательство

ResourceNullPathEvidenceTests вызывает LOADIMAGE, LOADSPRITE, LOADTILESET и LOADTILEMAP через ProgramRunService и реальный ProgramConsoleService. Для каждой функции взят существующий ресурс репозитория: PNG с корректной сеткой16×16 либо простая карта TMJ. К полному пути добавлены CHR(0) и другое имя. Все восемь случаев (четыре функции × оба движка) вместо MB3005 успешно загрузили префикс и вывели «Ошибочно загружен префикс». Исходный результат0/8, `.artifacts/test-results/resource-null-1221/resource-null-before-1221.trx`.

ResolveResourcePath сначала раскрывал переменные через Environment.ExpandEnvironmentVariables; строка обрезалась по NUL до поиска файла. В отличие от первого PATH26-002 здесь исходный дефект независимо воспроизведён в обоих движках.

## Исправление и предел

GraphicsHostService.ResolveResourcePath отклоняет NUL до раскрытия. LoadImage переводит ожидаемый ArgumentException в прежний null результата загрузки, который LOADIMAGE/LOADSPRITE/LOADTILESET переводят в MB3005. LoadTilemap сохраняет причину через существующий InvalidDataException и MB3005. Новых языковых форм нет; это отказ использования другого ресурса вместо указанного пути.

Восемь случаев после исправления и два реальных запуска `samples/smoke/resources/null_path.axm` прошли. Совместно с ProgramConsoleServiceTests и TilemapLoaderClosureTests — **186/186**, ошибок/пропусков0, `.artifacts/test-results/resource-null-1221/resource-null-final-1221.trx`. После адресного набора начат полный IDE-набор, его итог фиксируется отдельно. Полный предыдущий Axiom.sln6228/6228 относится к состоянию до этой правки и не выдаётся за её полную проверку.

Четыре страницы images.html, sprites.html, tilesets.html, tilemaps.html содержат прямое описание отказа и короткий пример. Редакционный жанр проверки пути сопоставлен с ранее прочитанной официальной [Visual Basic FileSystem.GetName](https://learn.microsoft.com/en-us/dotnet/api/microsoft.visualbasic.fileio.filesystem.getname?view=net-10.0). Это структурный ориентир, семантика взята из Axiom. Предполагаемая страница старой LoadPicture недоступна, не заявлена прочитанной; локальный DjVu Зельднера с другого компьютера отсутствует.

Не проверены все встроенные имена ресурсов Tiled, путь внешнего TSJ с NUL, все повреждённые файловые форматы и доступность сетевых ресурсов. Проверка восьми верхних загрузок не закрывает эти участки автоматически. ISABSOLUTEPATH остаётся отдельным кандидатом: это классификатор абсолютности, его договор не обещает проверку корректности или существования файла. Перед изменением его поведения нужно отдельно установить нарушение договора.
