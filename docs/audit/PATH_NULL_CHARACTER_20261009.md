# PATH26-002: путь обрезался по нулевому символу

Session 1220, 2026-10-09. P2, подтверждённое нарушение существующего договора FULLPATH: руководство обещало MB3007 для нулевого символа, но функция успешно принимала такой путь.

## Исходное воспроизведение

PathNullCharacterEvidenceTests: пять случаев FULLPATH/FILENAME/DIRNAME/EXTNAME/PATHROOT завершились ошибкой ожидания RuntimeFailure: фактически Success. Каждый тест сначала проверял интерпретатор и останавливался на первом несоответствии; исходный TRX не доказывает отдельно прежний результат VM. Совместно с PathComponentEvidenceTests: 14/19 успешно, 5 отказов. TRX `.artifacts/test-results/path-null-1220/path-null-1220.trx`.

Независимая проверка CLR на этой Windows: строка «папка» + NUL + «файл.txt» имела длину14; Environment.ExpandEnvironmentVariables вернул строку длиной5, равную «папка». Общий NormalizeFileSystemPath передавал путь в этот API до Path.GetFullPath, поэтому проверка формата получала уже обрезанную строку. Оба движка используют общий обработчик, однако это структурное объяснение, а не отдельное исходное воспроизведение VM.

## Исправление и проверки

BuiltinFileSystemHelpers.NormalizeFileSystemPath проверяет исходный путь на NUL до раскрытия переменных и выбрасывает ArgumentException. Существующие границы файловых функций переводят его в MB3007. Нового типа диагностики, токена или API нет.

Пять случаев проверяют неперехваченный отказ и положение диагностики, совпадение координат двух движков, TRY/CATCH/FINALLY и продолжение программы. Два дополнительных случая выполняют `samples/functions/fullpath/null_character.axm`. После исправления совместно с PathComponentEvidenceTests, PathBaseResolutionEvidenceTests и FileTransferFailureEvidenceTests — **56/56**, ошибок/пропусков0, `.artifacts/test-results/path-null-1220/path-null-fixed-1220.trx`.

Руководство file-system-functions-paths.html уточняет проверку до раскрытия и содержит короткий пример. Жанровый ориентир — [Visual Basic FileSystem.GetName](https://learn.microsoft.com/en-us/dotnet/api/microsoft.visualbasic.fileio.filesystem.getname?view=net-10.0): параметры, результат, замечания и короткий пример; чужая семантика не переносилась. Локальный структурный материал Зельднера прочитан; указанный в нём DjVu другого компьютера недоступен, точный раздел книги для FULLPATH не заявлен прочитанным.

Предел: новые случаи проверяют пять функций пути и пример, но не все операции чтения/записи/удаления. Проверка общего обработчика применяется шире; сохранность реальных файлов при попытке записи/удаления через NUL ещё требует отдельного доказательства. Нулевой символ, появляющийся в результате раскрытия, будет дополнительно отклонён Path.GetFullPath; отдельная проверка такого значения переменной окружения в этой сессии не выполнена.
