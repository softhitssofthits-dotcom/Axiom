# Пустые документы, вкладки и QuickBASIC

Новый документ, в том числе созданный при первом запуске без восстановленных вкладок, имеет пустой текст. Новый файл проекта тоже пуст. Восстановленные документы и существующие пользовательские файлы не очищаются.

Вкладки размещаются в одной строке постоянной высоты. Справа находятся две кнопки со стрелками и русскими/английскими подсказками. Кнопки перемещают ряд горизонтально и выключаются у соответствующего края. Выбор вкладки показывает её в видимой области. Проверка использует 19 вкладок, немаксимизированное окно шириной 520 пикселей и широкое светлое окно; сохранены снимки document-tabs-scroll.png и document-tabs-light.png.

## Тема QuickBASIC

Главный ориентир по прямому уточнению пользователя — QuickBASIC для DOS. Просмотрены [оригинальные материалы QuickBASIC 4.50](https://www.pcjs.org/software/pcx86/lang/microsoft/basic/quickbasic/4.50/) и [описание QBasic Dark для VS Code](https://marketplace.visualstudio.com/items?itemName=GatewayProgrammingSchoolInc.qbasic-dark). Палитра VS Code не перенесена буквально: её бордовые панели не соответствуют выбранному пользователем направлению. Категории современной подсветки Axiom не выдаются за исторический договор QuickBASIC.

| Элемент | Цвет |
| --- | --- |
| Редактор и консоль | #000080 |
| Рамки, меню, строка состояния | #C0C0C0 |
| Операторы и арифметические знаки | #FFFF55 |
| Типы и переменные | #FFFFFF |
| Встроенные функции и процедуры | #55FFFF |
| Строки и массивы | #AAFFAA |
| Числа и константы | #FFFFAA |
| Комментарии | #B8C7E8 |
| Ошибки | #FFAAAA |

Расчёт контраста основных цветов текста с редактором: от 8,83:1 до 16,01:1. Полосы меню и состояния используют синий текст на сером фоне. Тема выбирается через «Вид», применяется к Monaco, оболочке и xterm и сохраняется в профиле. При перезапуске проверены значение basic и реальные цвета кода. Снимок: ide/e2e/evidence/shots/quickbasic-theme.png.

## Проверки и продолжение

Добавлены document-empty-tabs-scroll и document-basic-theme-persistence в существующий documents.spec.js. Обновлены ожидания startup-ready и files-create-without-overwrite; SCENARIOS.json содержит 77 сценариев. Каталог, новые тесты и результаты отправляются вместе с кодом этапа.

Промежуточная проверка обнаружила остаточное смещение первой вкладки; при выборе первой вкладки прокрутка теперь явно сбрасывается в ноль. Автоматизация размеров снимает максимизацию окна перед уменьшением. Проверка цвета функции ожидает перерисовку Monaco перед чтением DOM. Эти исправления внесены до полного прогона.

Точная следующая задача разработки остаётся в области сохранности документов: внешнее изменение перед сохранением, исчезнувший файл без локальных правок и повторные внешние записи во время чтения. Язык и .NET-код этой задачей не менялись.

Заключительный прогон: 77/77 сценариев Electron, 371 утверждение, ошибок нет; переносимый результат ide/e2e/evidence/tabs-basic-full-results.json. После последнего уточнения названия и удаления пиктограмм отдельно повторены тема/меню: один сценарий с десятью утверждениями и menu-layout с пятью, все успешны. Результаты basic-theme-menu-results.json и results.json сохраняют эти повторы. Все 57 проверок Node успешны, включая девять прежних локальных host-ensure.test.cjs, не включённых в отправку этапа. Изменённые JavaScript и git diff --check проверены. .NET не пересобирался и не проверялся повторно.
