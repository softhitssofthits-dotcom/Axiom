# Исправления глобального аудита графики — 17 октября 2026 года

Работа выполняется в отдельной ветке `codex/graphics-audit-fixes`, без изменений реализации массивов. Исходный подробный аудит сохранён в основной рабочей копии: `docs/audit/GRAPHICS_SUBSYSTEM_AUDIT_2026-10-17.md`.

Порядок реализации и проверки:

1. GFX-002/003: независимые регрессии узорной заливки и GET/PUT с предельными индексами; исправление обхода пикселей без изменения массивов.
2. GFX-004/005/006: перехватываемое переполнение POINT, проверка размеров изображений/спрайтов и координат современных команд CANVAS.
3. GFX-001/010: замена окна при смене графического исполнителя SCREEN; удаление целого текстового элемента при Backspace в нативном INPUT.
4. GFX-008/009: ограниченный видимой областью обход больших эллипсов; справедливый опрос очереди мыши с сохранением необработанных событий.
5. GFX-007/012/014: единые ограничения графических ресурсов, безопасные произведения размеров, перехватываемые ошибки, ограничение работы и выделений.
6. GFX-011: содержательная диагностика Tiled и согласование проверок с английским текстом ERROR.
7. GFX-013: выбор монитора по окну IDE, проверка выбора через внедряемую геометрию; физический второй монитор остаётся внешним условием.
8. GFX-015: пакетная передача PUT без попиксельных обращений к DirectX.
9. Справочник, примеры, реестр покрытия, версии, адресная приёмка .NET и настоящих графических окон Electron. Запись результатов и оставшихся аппаратных ограничений.

Критерий готовности: каждая исправленная группа имеет проверку ожидаемого поведения; ограничения отражены в справочнике; проверки относятся к затронутому слою; основная рабочая копия другого агента не изменена. Полный набор всех слоёв не требуется для этой задачи.

Аппаратное удаление устройства и физическое исчерпание памяти не моделировались разрушительным стрессом. Перехват ошибок выделения проверен управляемыми исключениями и отказами по лимитам. Новая схема отмены сохраняет управление окном в Dispatcher; тяжёлая заливка остаётся синхронной, но реагирует на остановку из отдельного потока чтения команд.

При будущем объединении с веткой массивов требуется согласовать общие версии и последовательность записей журнала. Эта ветка основана на `fd7d3a9c`; чужие незакоммиченные изменения в неё не переносились.
