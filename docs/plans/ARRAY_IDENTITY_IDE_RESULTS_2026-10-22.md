# Круглые скобки, цвета и подсказки массивов

Дата: 22 октября 2026 года. Уточнение этапа 2 плана массивов выполнено по решениям автора после обсуждения перехода на квадратные скобки.

## Принятый договор

```basic
DIM fruits() AS STRING = SPLIT("яблоко,банан", ",")
DIM basket() = fruits()
PRINT basket(2)
```

Программа выводит `банан`. В объявлении скобки после имени задают массив и число измерений. При отсутствии AS тип элементов выводится из выражения; ранг должен совпасть с указанным. Начальное выражение при заданных границах по-прежнему запрещено.

При использовании массива `fruits` и `fruits()` обозначают один массив целиком, без копии. Пустые скобки доступны также для массивных полей, в аргументах, возврате и присваивании, при любом ранге и состоянии выделения. Они не означают, что массив пуст. Индекс `fruits(2)` выбирает элемент; функция `MakeFruits()` вызывается обычным образом. Действие определяет тип цели. Старые формы с типом массива после AS и с неявным объявлением без скобок сохранены.

Объявления `DIM fruit AS STRING` и `DIM fruits() AS STRING` различаются: первое создаёт обычную строку, второе — невыделенный массив строк. Поэтому эквивалентность имени и имени с пустыми скобками в выражениях не означает возможности удалить скобки из любого объявления.

## Реализация

- Binder.DeclarationStatements.cs проверяет начальное значение относительно результирующего типа каждого имени. Для выведенного массива скобки после имени используют его тип элемента и проверяют ранг.
- Binder.InvocationExpressions.cs и Binder.ArrayInvocations.cs разрешают пустые скобки массивной цели в само выражение цели. Путь вызова функции сохраняется. Дополнительных команд VM и изменения формата сериализации нет.
- EditorHoverInfo получил необязательные ElementType и ArrayRank для переменных, параметров и полей. Эти сведения выводятся из ArrayTypeSymbol, а не угадываются по имени.
- Существующий кеш document.hover используется и асинхронным провайдером семантических токенов. Проверяются версия и существование модели, отмена и актуальность захваченного проекта. Предварительная раскраска текста уточняется данными компилятора по точным позициям имён.
- В темах dark, light и basic сохранены отдельные цвета трёх категорий. В borland массив стал светло-зелёным `#AAFFAA`, функции и встроенные функции — голубыми `#55FFFF`; обычная переменная сохранила жёлтый `#FFFF55`.
- Подсказка называет сущность массивом и показывает полный тип, тип элементов и число измерений. Русская и английская локализации обновлены. Автор отдельно выбрал не показывать текущие значения элементов; границы и количество элементов в эту задачу не включены.
