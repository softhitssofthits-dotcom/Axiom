# Общая точка входа и индекс символов редактора

Продолжение MODULE_NAVIGATION_2026-10-19.md после публикации 842ab05.

Выбранное решение: явная точка входа навигации в помощнике, действующая в текущем сеансе для документов той же папки. Состав определяется IMPORT точки входа и общим снимком открытых документов. Файл вне этого состава не получает выдуманных связей. Выбор не меняет запуск и правила языка.

Индекс собирается по связанным символам с документными диапазонами объявлений и использований. Редактор получает переход к объявлению и поиск использований для подпрограмм, переменных, параметров, констант, TYPE и полей. Встроенные имена не получают выдуманных исходных объявлений. Ошибочный текст даёт частичный индекс. Переименование в эту ревизию не входит.

Порядок: адресные тесты индекса; необязательный сбор метаданных Binder; документная проекция Host и точка входа; команды редактора Monaco и выбор точки входа; проверки Node/.NET/Electron; документация и версии.

## Реализация

- [x] Необязательный индекс Binder с идентичностью связанных символов и документными диапазонами.
- [x] Проекция Host, общий корень навигации и проверка принадлежности активного файла его IMPORT.
- [x] Команды редактора F12/Shift+F12, результаты в помощнике, документные переходы и история.
- [x] Жизненный цикл точки входа: снятие при закрытии, сохранение при переименовании и смене идентификатора редакции.
- [x] Устранение замечаний проверки: ссылки CONST в фиксированных размерах, отвергнутые TYPE/поля, отмена перехода при перемещении каретки во время чтения.

Команды используют существующий безопасный переход помощника. Провайдеры встроенных окон Monaco для определений и ссылок в этой ревизии не регистрируются. Самостоятельное сканирование папки и переименование символов не входят в завершённый объём. Результаты проверок и точный следующий шаг записываются в Session 1568 журнала.
