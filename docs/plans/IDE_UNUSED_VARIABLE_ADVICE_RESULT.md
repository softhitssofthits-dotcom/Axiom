# Советы о неиспользуемых переменных

## Исправление

MB2047 указывал на начало всего оператора DIM. Связанный узел объявления теперь отдельно хранит IdentifierLocation; анализ использования берёт диапазон имени. Основной диапазон оператора не меняется, поэтому исправление не переносит точки отладки.

В Electron MB2047 показан как совет: Monaco Hint с Unnecessary и спокойная пиктограмма лампочки. Ошибки и остальные предупреждения сохраняют прежнюю серьёзность. Панель сообщений разделяет категории «Все», «Ошибки», «Предупреждения» и «Советы» со счётчиками. Категории скрыты на других вкладках панели и помещаются в окне шириной 520 пикселей.

Правка немедленно снимает прежние советы активного документа; новый анализ после существующей задержки 600 мс возвращает только актуальные сообщения. Запись через присваивание или INPUT не является чтением значения. Совет исчезает после чтения, например PRINT spare, и не блокирует запуск.

## Ручная проверка

Открыть samples/operators/dim/unused_value_warning.axm в Electron IDE. Проверка должна выделить только spare и показать MB2047 в категории «Советы», но не «Ошибки». Запуск выводит русскую строку и завершается успешно. Добавить PRINT spare: прежний совет снимается сразу и после анализа не возвращается. Если вместо чтения добавить spare = 123, актуальный совет появляется снова.

## Документация

Изменена существующая запись MB2047 в manual/diagnostics.html, ссылка на пример сохранена; новых сущностей и изменений навигации нет. Жанровый ориентир: [официальная страница Visual Basic BC42024](https://learn.microsoft.com/ru-ru/dotnet/visual-basic/misc/bc42024), объясняющая отличие предупреждения от ошибки и проверку имени. Это только редакционный ориентир; договор Axiom проверен по коду и тестам. Локальный файл книги Зельднера и извлечённый текст по путям инструкции на этом компьютере отсутствуют; наличие соответствующего раздела книги не предполагается.

```powershell
dotnet test tests/Axiom.Semantics.Tests/Axiom.Semantics.Tests.csproj --no-restore
dotnet build src/Axiom.DesktopHost/Axiom.DesktopHost.csproj -c Debug --no-restore
node --test ide/tests/*.test.cjs
node ide/e2e/runner.js
node ide/e2e/runner.js problems.spec.js
```

Полный Electron: выполнены 78 сценариев, 379 успешных утверждений, без ошибок страницы. 77 сценариев прошли сразу; один завершился ожиданием строки консоли, перенесённой в узком окне. Перед проверкой вывода тест возвращает широкое окно. Итоговый повтор всего problems.spec.js: 5/5, 23 утверждения, включая настоящий пример, снятие/возврат совета, чтение значения, закрытие документа и скрытие фильтров в консоли. Все 78 сценариев подтверждены с этим целевым повтором; новый полный прогон после последней правки теста не заявляется. Сырые результаты: diagnostics-full-results.json и diagnostics-final-results.json. Снимок unused-variable-advice.png осмотрен.
