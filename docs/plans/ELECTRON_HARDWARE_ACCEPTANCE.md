# Ручная аппаратная приёмка Electron

Статус на 11 октября 2026 года: автор запустил пример `samples/smoke/ide-acceptance/screen_mouse.axm` в SCREEN, наблюдал обновление показаний в графическом окне и подтвердил, что физическая мышь работает отлично. Консольный итог после ESC не требуется. Системные масштабы Windows 100%, 125%, 150% и 175% также работают отлично. В обычном списке автора нет 200%. Второго монитора нет. Масштаб страницы Chromium не заменяет масштаб Windows.

## Физическая мышь SCREEN

Для повторной проверки открыть `samples/smoke/ide-acceptance/screen_mouse.axm` в Electron и выполнить действия по порядку:

1. Переместить указатель к четырём углам графической области. Координаты должны соответствовать положению внутри поверхности, а не всего окна.
2. Нажать и отпустить левую, правую и среднюю кнопки. Счётчики нажатий и отпусканий увеличиваются отдельно; состояния каждой кнопки становятся FALSE после отпускания.
3. Прокрутить колесо в обе стороны. Счётчик увеличивается, знак последнего значения меняется.
4. Удерживая кнопку, переключиться в другое окно, отпустить её снаружи и вернуться. Состояние не должно оставаться нажатым. Повторить с переносом указателя наружу без смены фокуса.
5. Изменить размер окна SCREEN. Повторить движение и щелчок по видимой области; координаты должны оставаться согласованными с графической поверхностью.
6. Достаточно наблюдать, как координаты и счётчики меняются прямо в SCREEN. После ESC пример дополнительно выводит итоговые значения в консоль, но консольный вывод необязательно сохранять или передавать. Повторный запуск начинается с нулевых счётчиков.

## Масштаб Windows

Закрыть Axiom IDE. Щёлкнуть правой кнопкой по свободному месту рабочего стола и выбрать «Параметры экрана». В Windows 11 нужен список «Масштаб» в разделе «Система → Дисплей»; в Windows 10 — «Изменение размера текста, приложений и других элементов». Записать исходное значение. Выбирать обычные значения списка; если нужного процента нет, отметить его как недоступный. Не менять разрешение экрана и отдельный размер текста. Путь к настройке: [официальная инструкция Microsoft](https://support.microsoft.com/ru-ru/accessibility/windows/make-windows-easier-to-see).

Приёмка масштаба автором завершена для доступных значений 100%, 125%, 150% и 175%. При каждом значении Axiom был запущен повторно; автор сообщил, что всё работает отлично. 200% в списке Windows на его компьютере нет, поэтому это значение недоступно для проверки.

| Масштаб Windows | Результат автора для Axiom |
|---|---|
| 100% | Отлично работает |
| 125% | Отлично работает |
| 150% | Отлично работает |
| 175% | Отлично работает |
| 200% | Недоступен в списке Windows автора |

Физическая мышь SCREEN принята автором по запущенному `samples/smoke/ide-acceptance/screen_mouse.axm`. Для CANVAS использовать `samples/operators/on-mouse/canvas_world_handler.axm`; для повторной проверки SCREEN — пример выше. В конце повторной проверки вернуть исходный масштаб Windows.

## Несколько мониторов

Остаётся открытым до появления второго монитора: разные DPI двух экранов, перенос IDE/CANVAS/SCREEN между ними, сохранение положения и размеров, отключение монитора и следующий запуск. Проверка искусственных координат окна не подтверждает эту аппаратную матрицу.
