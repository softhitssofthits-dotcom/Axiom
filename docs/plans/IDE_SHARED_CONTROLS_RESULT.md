# Общие свойства элементов управления Electron

## Результат

Повторяющиеся свойства элементов управления вынесены в `ide/src/renderer/ui-controls.js`: состояние нажатия, раскрытия, доступности, отметка меню, подпись и создание кнопки с пиктограммой. Состояние каждого элемента остаётся независимым и определяется соответствующим контроллером.

Палитры оболочки трёх тем и общие размеры, состояния и оформление кнопок находятся в `design-system.css`. Подсветка языка и графическая палитра сохраняют отдельные договоры. Правило дальнейшего использования общего слоя закреплено в `AGENTS.md`; проверка исходников предотвращает возврат прямых повторяющихся настроек.

Кнопка нижней панели показывает её видимость при нажатии, сочетании клавиш и восстановлении профиля. После «Сохранить всё» добавлены отделённые с двух сторон стрелки отмены и повтора. Их доступность соответствует истории активного документа и режиму только чтения. Команда «Проверить» использует галочку.

## Проверки

- Полный набор Electron: `node ide/e2e/runner.js` — 79/79 сценариев, 405 утверждений, без ошибок страницы.
- Полный набор Node: `node --test ide/tests/*.test.cjs` — 65/65, включая восемь новых проверок общего слоя.
- Отдельный блок оболочки — 2/2 сценария, 30 утверждений.
- Проверены светлая, тёмная и QuickBASIC темы, окна шириной 320, 520, 800 и 1280 пикселей. Снимки `toolbar-light.png`, `toolbar-dark.png`, `toolbar-basic.png` осмотрены.
- Сырой полный результат: `ide/e2e/evidence/toolbar-shared-controls-results.json`.

Первоначальное ожидание цвета в новом сценарии уточнено: проверка ждёт окончания существующих переходов CSS. Окончательный полный прогон выполнен после исправления ожидания. Код .NET не менялся; его проверки на этом этапе не запускались. Прежние местные изменения запуска DesktopHost и примера игры не входят в этот этап.
