# Этап 2: начальные значения массивов

Дата: 22 октября 2026 года. Этап 2 [плана](ARRAYS_COLLECTIONS_ROADMAP_2026-10-22.md) завершён в рабочем дереве.

## Реализация

Поддержаны обе согласованные формы:

```basic
DIM fruits AS STRING () = SPLIT("яблоко,банан", ",")
DIM basket = fruits
PRINT basket(2)
```

Вывод: `банан`. Явный тип позволяет увидеть тип элементов и число измерений в объявлении; неявная форма получает их из выражения. Нового синтаксиса для литералов этот этап не добавляет.

Изменён только путь массивного объявления в `BoundProgramLowerer.Declarations.cs`: вместо отказа BC3001 выражение вычисляется и сохраняется существующей StoreVariable. Связыватель уже распознавал обе формы; его правила типов, ранга и запрета начального выражения при скобках после имени сохранены. Парсер, команды VM и формат сериализации не изменены.

Начальное выражение вычисляется один раз на имя. Группа имён вызывает выражение отдельно для каждого имени, в порядке записи. Общая память, состояния выделения, границы, ограничения строк и представления следуют обычному присваиванию массива. Автоматического ARRAYCLONE нет.
