# Диалог параметров редактора — 14 октября 2026 года

Автор утвердил модальный диалог в главном окне Electron с горизонтальными вкладками по образцу показанного окна Thonny. Цель — дать доступ к широкому набору пользовательских параметров Monaco, включая закрепление строк, шрифты, отступы, подсказки, прокрутку и выделение.

## Договор

ОК применяет значения и закрывает окно. Применить сохраняет значения и оставляет окно открытым. Отмена и Escape отбрасывают изменения после последнего применения. По умолчанию сбрасывает текущую вкладку в черновике. Поиск показывает совпадения из всех вкладок. Для средств, требующих языкового провайдера, пояснение прямо сообщает эту зависимость. Наличие переключателя не утверждает наличие такого провайдера Axiom.

Каталог и диалог находятся в отдельных файлах renderer, а app.js отвечает только за команду открытия, применение к Monaco и существующее сохранение профиля. Схема допускает только известные ключи и значения; повреждённые и устаревшие значения профиля не передаются Monaco. Дополнительные настройки массива колонок и разрешённых символов задаются структурированным JSON с проверкой формы.

## Выбор шрифта и толщины — 2026-10-14

Поле «Шрифт редактора» сохраняет ручной ввод имени или списка запасных шрифтов. Это список готовых вариантов, а не перечень установленных системных шрифтов; указанное семейство должно быть установлено. Поле толщины также содержит выбор normal, bold и числовых значений 100–900. Выбор обновляет черновик и предпросмотр; «Применить» обновляет редактор. Поля лигатур и вариативных параметров сохраняют прежние возможности.
