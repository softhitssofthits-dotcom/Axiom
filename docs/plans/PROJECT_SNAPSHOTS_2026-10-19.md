# Единый снимок открытых модулей

Продолжение модульного этапа после Session 1564. Синтаксис языка, папка поиска импортов и правило сохранённой точки входа не меняются.

## Договор

Перед проверкой, семантической подсказкой или запуском редактор синхронно фиксирует текст, путь, идентификатор и редакцию открытых именованных `.axm` из папки точки входа. Точка входа передаётся основным полем, остальные документы — дополнительным снимком. Открытая зависимость имеет приоритет перед диском; закрытая загружается с диска. В компиляцию входят только явно импортированные документы. Переименование, закрытие, открытие или правка документа снимка делает поздний ответ проверки непригодным. Форматирование одного файла не зависит от изменений соседних модулей.

Работающий запуск использует неизменный снимок. Ошибка зависимости привязана к её тексту на момент запуска; после редактирования старый диапазон не подсвечивается в новом тексте. Диагностика проверки использует текущий проектный снимок. Несохранённый безымянный файл не становится импортируемым модулем автоматически.

## Реализация по порядку

1. SourceProject.LoadDependencies принимает заменяющие тексты открытых документов, разрешает транзитивные импорты по ним и использует диск как запасной источник. SourceProjectTests проверяет приоритет, вложенные зависимости и изоляцию папки.
2. DocumentStore фиксирует проектный снимок и проверяет его актуальность; DocumentServices отправляет его только проектным операциям и отклоняет поздние ответы. Проверки Node покрывают правку зависимости, закрытие, Save As и независимость форматирования.
3. Необязательная часть DocumentSnapshot/пакета запуска проходит через проверку IPC и DesktopHost в загрузчик. ProgramRunService принимает снимок без изменения старого IProgramRunService и инвалидирует компиляцию при смене любого использованного текста.
4. ExecutionController фиксирует тексты зависимостей для запуска и диагностики; старые диапазоны и маркеры после правки не применяются к новому тексту. Проверки Electron используют настоящую несохранённую зависимость и подтверждают неизменность файла на диске.
5. Обновить справочник, спецификацию, архитектуру, план и журнал. Версии повышать только у компилятора и IDE: правила связывания языка не меняются, меняется состав входного снимка редактора. Последовательно проверить Execution и службы IDE, Node и сценарии modules.spec.js, затем справочник и версии.
