# Папка проекта: вкладки и файл запуска

## Договор по запросу автора

«Файл → Открыть проект» выбирает папку и открывает все найденные `.axm` как вкладки. Для Maze Chase это девять вкладок. Пустая стартовая вкладка удаляется; пользовательский текст и существующие модели сохраняются. Файлы прежней папки и внешние документы не закрываются молча: они остаются прочими файлами.

В панели проекта есть поле «Файл запуска». При первом открытии выбирается main.axm непосредственно в корне папки; если такого файла нет и `.axm` единственный, выбирается он. Несколько файлов без main требуют явного выбора: первый файл по алфавиту не становится программой случайно. Выбор запоминается для этой папки в локальном профиле IDE, без нового формата файла проекта. Подпапки видны в списке, но разрешение IMPORT не меняется: модули программы по-прежнему лежат рядом с её точкой входа.

Запуск и начало отладки из вкладки проекта используют выбранный файл. Если его вкладка закрыта, она открывается перед запуском. Внешний документ запускается как самостоятельная программа. Меню проверки и фоновая проверка остаются проверками текущего документа; запуск компилирует весь достижимый состав выбранной программы. Изменение выбора не подменяет уже выполняющуюся сессию.

Открытие папки также выбирает её точку входа для помощника, когда документ открыт. Существующая кнопка точки входа помощника продолжает управлять анализом и не заменяет явный выбор запуска. После закрытия и повторного открытия IDE восстанавливаются вкладки, которые пользователь оставил открытыми, и запомненный запускной файл; закрытые пользователем вкладки не навязываются заново.

## Организация

- `ide/src/renderer/project-session.js` — открытие состава, выбор и сохранение точки входа, отмена запоздалых операций, согласование с переименованием.
- `app.js` — подключение сеанса к меню, открытию документов, запуску, закрытию, восстановлению и списку файлов. Фоновое открытие использует существующие защищённые операции документа.
- `index.html`, `design-system.css`, `locale.js` — подписанный список выбора с общей палитрой и русским/английским текстом.
- Правила языка, DesktopHost, загрузчик IMPORT и формат исходников не меняются.

## Проверки и порядок завершения

1. Проверить сеанс папки отдельно: main, единственный файл, неоднозначность, сохранение выбора, повтор без потери модели, пустые/непустые документы, отмена старого списка и чтения, недоступная папка, закрытие вкладки запуска, переименование и удаление.
2. Проверить настоящие AxiomIDE.openFile: одновременное фоновое чтение и щелчок пользователя не создают вторую модель и не затирают правки. Обычное открытие и переходы отладчика сохраняют прежний договор.
3. В Electron открыть Maze Chase именно через меню: девять вкладок, main в поле запуска, общий анализ помощника, запуск отладки из вкладки героя. Проверить выбор без main, перезапуск IDE, закрытие проекта и прежние операции с файлами.
4. Выполнить ide-unit-delivery и ide-unit-renderer, адресные Electron-проверки, обновить каталог сценариев и документацию. Не запускать .NET-набор ради чистой логики renderer.
5. Повысить только IDE: новый договор проекта меняет прежний запуск активной вкладки внутри проекта, поэтому версия 0.7.0. Язык 0.2.2 и компилятор 0.2.4 сохраняются. Выполнить обе проверки версий и журнал.

## Границы и ошибки

Новая команда открытия и закрытие проекта отменяют позднее чтение предыдущей команды. Ошибка получения состава не заменяет прежнюю папку. Ошибка чтения отдельного файла показывается обычной диагностикой открытия: остальные документы сохраняются, не выбирается другой запускной файл в качестве скрытой подмены. Пока идёт загрузка папки, запуск и изменение выбора недоступны. Переименование сохраняет выбранную точку, удаление снимает её и требует нового выбора.

Автоматическое распознавание программы по тексту процедур, угадывание по наличию PRINT/CANVAS, новый формат проекта и загрузка всех файлов в одну компиляцию не вводятся: состав исполнения определяется IMPORT выбранного исходника.
