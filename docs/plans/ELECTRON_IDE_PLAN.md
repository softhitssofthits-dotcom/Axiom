# Рабочий план Electron IDE

Electron уже является рабочей оболочкой: Monaco, документы, диагностика, форматирование, запуск BytecodeVm через DesktopHost, INPUT, отдельный CANVAS, нативный SCREEN и трассировка реализованы. Создавать оболочку заново по раннему прототипному плану не требуется.

Последний завершённый продуктовый этап — исключительная запись файлов и восстановление документов после аварии (Session 1363). Существующий набор — 85 сценариев в 27 файлах, последний сохранённый полный результат 85/85.

Порядок продолжения:

1. Воспроизвести бесконечное зависание renderer с изолированным профилем. Обеспечить доступное действие отмены/восстановления в main, завершение собственной VM/окон и сохранность завершённых правок; повторить существующие сценарии отказов.
2. Принять системные DPI и несколько мониторов, физическую мышь SCREEN. Явно отделить эти доказательства от масштаба Electron и CANVAS.
3. Закрыть остальные критерии редактора/документов, трассировки, настроек, журнала, локализации и доступности по [матрице](IDE_SHELL_FEATURE_MATRIX.csv).
4. Спроектировать и принять поставку для компьютера без среды разработки.

Проектное дерево и дополнительные языковые предложения не включаются автоматически. Полный остаток, источники и границы — [UNFINISHED_WORK.md](UNFINISHED_WORK.md). Завершённые этапы имеют адресные проверки и отдельный результат в `docs/reports/electron/`; правила публикации определяет конкретное поручение пользователя.
