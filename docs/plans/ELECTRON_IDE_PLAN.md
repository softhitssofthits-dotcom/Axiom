# Рабочий план Electron IDE

Актуализация: 16 октября 2026 года. Electron — рабочая оболочка: Monaco, документы, диагностика, форматирование, запуск BytecodeVm через DesktopHost, `INPUT`, отдельные окна `CANVAS` и `SCREEN`, трассировка. Создавать оболочку заново по раннему прототипному плану не требуется.

Каталог приёмки — `ide/e2e/SCENARIOS.json` (456 сценариев). Число сценариев не равно числу пройденных проверок.

## Реализовано и не требует повторной разработки

- Исключительная запись файлов и восстановление завершённых правок после аварии; независимое восстановление бесконечно зависшего renderer в основном процессе.
- Переносимая папка Windows x64; доступные масштабы Windows 100/125/150/175% и физическая мышь `SCREEN` приняты автором.
- Четыре глобальные темы, общий реестр `themes.js`, диалог и поэлементная проверка 261 параметра Monaco.
- Навигатор подпрограмм, тематические группы и помощник связей вызовов.
- Графика на GPU: `CANVAS`, `SCREEN 1..10` через DirectX, `SCREEN 0` — текстовый режим, `SMOOTH ON/OFF`.

## Порядок продолжения

1. Завершить адресные участки очереди «отказы и запоздалые ответы существующих команд»: принадлежность ответа документу, снимку и сессии. Следующий участок — результаты и отказы форматирования (см. [PLANS4](../PLANS4.md)).
2. Закрыть оставшиеся условия матрицы: редактор/документы, трассировка, настройки, журнал, локализация, доступность — по [IDE_SHELL_FEATURE_MATRIX.csv](IDE_SHELL_FEATURE_MATRIX.csv).
3. Второй монитор и разные DPI на двух мониторах, перенос окон, отключение монитора — по [инструкции аппаратной приёмки](ELECTRON_HARDWARE_ACCEPTANCE.md). Независимая проверка поставки на отдельном чистом компьютере исключена автором из очереди.

Проектное дерево, многофайловые модули и дополнительные языковые предложения не включаются автоматически. Полный остаток, источники и границы — [UNFINISHED_WORK.md](UNFINISHED_WORK.md). Результаты завершённых этапов — в `docs/reports/electron/`; текущее состояние — [agent/CURRENT_STATE.md](../agent/CURRENT_STATE.md).
