
# Принятое оформление новой IDE

Автор подтвердил исправленный макет docs/plans/ide-shell-preview.html и поручил продолжить реализацию по нему. Прежние визуальные варианты не являются текущим ориентиром.

Верхняя строка содержит выпадающее меню. Вторая строка содержит единый набор пиктограмм; названия команд и сочетания клавиш доступны в подсказках. Файлы и структура находятся слева, редактор — в центре, вывод и ошибки — снизу. Дополнительной вертикальной полосы переключателей нет. Не помещающиеся пункты меню переходят в «…», группы кнопок переносятся целиком. Поддерживаются светлая и тёмная темы.

CANVAS представлен самостоятельным изменяемым окном программы, исходный размер около 1280 × 800. После нормального завершения сохраняется последний кадр. Следующий запуск заменяет прежнее окно. Закрытие окна во время выполнения останавливает соответствующую сессию. SCREEN сохраняет существующее нативное окно общей графической подсистемы.

## Реализация и границы проверки

Оформление подключено через ide/src/renderer/shell.css и shell.js поверх прежних обработчиков и элементов, без переписывания app.js. Структура перенесена в левую область вместе с прежним списком навигации. F5 начинает отладку или продолжает остановленную сессию; Ctrl+F5 выполняет обычный запуск; F10/F11 и модификаторы управляют существующим отладчиком.

Окно CANVAS создаёт главный процесс Electron. Изолированный preload предоставляет только получение кадра и его подтверждение. Кадры BGRA8 представляет HTML canvas; JS не исполняет язык. Только собственное окно и текущий frameId могут подтвердить кадр; завершённая графическая сессия остаётся доступной для подтверждения последнего кадра до нового запуска.

Проверены обе темы и размеры 320/520/800/1280, расположение структуры, запуск через кнопку, реальный красный пиксель CANVAS, сохранение зелёного финального кадра и повтор. Это не полная проверка всех DPI, ввода в графическое окно, оконных меню с клавиатуры или всей матрицы функций. Старый редактор сохраняется до функциональной приёмки.

## Работа с буфером — Session 1330, 2026-10-10 09:24

Явные проверка и форматирование новой IDE работают с текущим несохранённым текстом. Форматирование меняет буфер и сохраняет возможность отмены; файл записывается только по команде сохранения. Переход строки использует общие правила закрытия блоков и установки каретки. Ответ обработки не применяется, если пользователь успел изменить текст, закрыть вкладку или выполнить «Сохранить как». Это реализовано и проверено в настоящем Monaco; полная приёмка дополнительных режимов форматирования и всех операций документов остаётся в матрице функций.
