Функции состояния SCREEN

Функции состояния позволяют программе узнать, включён ли графический режим, какой режим выбран, каковы текущие логические размеры окна SCREEN и где находится текущая графическая позиция.

SCREENISACTIVE

SCREENISACTIVE()

Возвращает TRUE, если активен графический режим SCREEN 1..10. В текстовом режиме SCREEN 0 результат равен FALSE, потому что пиксельные графические команды недоступны.

SCREENMODE

SCREENMODE()

Возвращает номер текущего режима SCREEN. Для текстового режима результат равен 0.

SCREENWIDTH

SCREENWIDTH()

Возвращает ширину текущего окна SCREEN в пикселях. Для SCREEN 0 текущий размер равен 640.

SCREENHEIGHT

SCREENHEIGHT()

Возвращает высоту текущего окна SCREEN в пикселях. Для SCREEN 0 текущий размер равен 300.

POINT(number)

POINT(0)
POINT(1)
POINT(2)
POINT(3)

Форма POINT(number) возвращает текущую графическую позицию. Значения 0 и 2 возвращают текущий X, а значения 1 и 3 возвращают текущий Y. Эту форму удобно использовать после PSET, PRESET, LINE и CIRCLE, когда следующая фигура строится относительно предыдущей.

Пример чтения состояния

PRINT SCREENISACTIVE()
SCREEN 5
PRINT SCREENISACTIVE()
PRINT SCREENMODE()
PRINT SCREENWIDTH(); "x"; SCREENHEIGHT()
PSET (10, 20), 12
PRINT POINT(0); ","; POINT(1)
SCREEN 0
PRINT SCREENMODE()
