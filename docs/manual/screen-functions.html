Функции состояния SCREEN

Эта страница описывает встроенные функции языка Axiom, которые сообщают текущее состояние экранного режима SCREEN: активен ли графический экран, какой режим выбран, какие размеры имеет текущее окно и где находится текущая графическая позиция.

Где работают эти функции

Эти функции относятся к экранному договору SCREEN.

Часть функций работает и в SCREEN 0, и в графических режимах SCREEN 1..10. Часть функций имеет смысл именно в графическом режиме.

SCREENISACTIVE

SCREENISACTIVE — встроенная функция языка Axiom, которая сообщает, активен ли графический режим SCREEN 1..10.

SCREENISACTIVE()

Функция возвращает TRUE, если активен графический режим SCREEN 1..10.

Функция возвращает FALSE в режиме SCREEN 0.

SCREENMODE

SCREENMODE — встроенная функция языка Axiom, которая возвращает номер текущего режима SCREEN.

SCREENMODE()

В режиме SCREEN 0 функция возвращает 0.

SCREENWIDTH

SCREENWIDTH — встроенная функция языка Axiom, которая возвращает ширину текущего окна SCREEN в пикселях.

SCREENWIDTH()

Для режима SCREEN 0 функция возвращает 640.

Для режима SCREEN 10 функция возвращает фактически выбранную ширину адаптивного окна.

SCREENHEIGHT

SCREENHEIGHT — встроенная функция языка Axiom, которая возвращает высоту текущего окна SCREEN в пикселях.

SCREENHEIGHT()

Для режима SCREEN 0 функция возвращает 300.

Для режима SCREEN 10 функция возвращает фактически выбранную высоту адаптивного окна.

POINT(selector)

Форма POINT(selector) описана на странице классических операторов рисования, но она тоже относится к функциям состояния графического экрана, потому что может возвращать текущую графическую позицию.

Когда программе нужны координаты текущей графической позиции, следует читать страницу операторов рисования вместе со страницами VIEW и WINDOW.

Правила работы

Режим SCREEN 10 выбирает максимально возможную клиентскую область с соотношением сторон 16:9, которая помещается в рабочую область текущего монитора. Поэтому результаты функций SCREENWIDTH и SCREENHEIGHT в этом режиме зависят от фактического окна.

Текстовая сетка для операторов экранного текста в режиме SCREEN 10 вычисляется как SCREENWIDTH() \ 8 и SCREENHEIGHT() \ 12.

Пример

SCREEN 1
PRINT SCREENISACTIVE()
PRINT SCREENMODE()
PRINT SCREENWIDTH()
PRINT SCREENHEIGHT()
SLEEP

В этом примере встроенные функции состояния SCREEN сообщают, что графический режим активен, какой режим выбран и какие фактические размеры имеет текущее экранное окно.

Ручная проверка

Эти файлы можно открыть в Axiom.Ide и запустить как короткие проверки поведения функций состояния SCREEN.

  • SCREEN: информация о текущем режиме
  • SCREEN 10: адаптивные размеры окна
  • SCREEN: прокрутка экранного текста

Диагностика

Функции SCREENISACTIVE, SCREENMODE, SCREENWIDTH и SCREENHEIGHT сами по себе не требуют отдельной runtime-диагностики отсутствующего графического режима, потому что читают текущее состояние экранного договора SCREEN.

Форма POINT(selector) использует диагностику своей страницы: при недопустимом селекторе функция POINT сообщает MB3007, а при отсутствии графического режима SCREEN 1..10 функция POINT сообщает MB3010.
