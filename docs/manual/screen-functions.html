Функции состояния SCREEN

Раздел экранных функций описывает SCREENISACTIVE, SCREENMODE, SCREENWIDTH и SCREENHEIGHT. Они позволяют узнать режим и размеры окна SCREEN; координаты рисования отдельно возвращает форма POINT(selector).

Где работают эти функции

Функции читают состояние окна SCREEN и не открывают его.

Состояние текстового режима доступно тем же функциям, что и состояние графических режимов. Наличие графики проверяется отдельно.

SCREENISACTIVE

Встроенная функция SCREENISACTIVE проверяет, выбран ли графический режим SCREEN.

SCREENISACTIVE()

Для режимов 1..10 результат равен TRUE.

Для текстового режима 0 результат равен FALSE.

SCREENMODE

Встроенная функция SCREENMODE сообщает номер выбранного режима.

SCREENMODE()

Текстовый режим имеет номер 0.

SCREENWIDTH

Встроенная функция SCREENWIDTH сообщает ширину окна в пикселях.

SCREENWIDTH()

После явного вызова SCREEN 0 ширина равна 640.

В адаптивном режиме 10 возвращается фактическая ширина выбранного окна.

SCREENHEIGHT

Встроенная функция SCREENHEIGHT сообщает высоту окна в пикселях.

SCREENHEIGHT()

После явного вызова SCREEN 0 высота равна 300.

В адаптивном режиме 10 возвращается фактическая высота выбранного окна.

POINT(selector)

Форма POINT(selector) читает координату текущей графической позиции. Её селекторы и ограничения описаны в справочнике POINT.

На результат POINT(selector) влияют настройки VIEW и WINDOW.

Правила работы

Адаптивное окно сохраняет пропорцию 16:9 и помещается в рабочую область монитора. Поэтому его ширину и высоту следует читать после вызова SCREEN 10.

Число текстовых столбцов и строк в этом режиме равно SCREENWIDTH() \ 8 и SCREENHEIGHT() \ 12.

Типы результатов и состояние холста

SCREENISACTIVE возвращает BOOLEAN; SCREENMODE, SCREENWIDTH и SCREENHEIGHT возвращают INTEGER. Аргументов у этих четырёх функций нет. Без открытой поверхности обычная среда возвращает FALSE, 0, 0 и 0 соответственно.

SCREENISACTIVE проверяет именно графический SCREEN: для SCREEN 0 и CANVAS результат FALSE. SCREENMODE возвращает 0 для текстового экрана и холста. SCREENWIDTH и SCREENHEIGHT читают текущую поверхность: после CANVAS они возвращают размеры холста в пикселях. Эти функции не требуют графического режима и не вызывают MB3010 из-за отсутствия окна.

Пример

SCREEN 1
PRINT SCREENISACTIVE()
PRINT SCREENMODE()
PRINT SCREENWIDTH()
PRINT SCREENHEIGHT()
SLEEP

Программа печатает признак активности графики, номер режима и фактические размеры окна.

Запускаемые примеры

Для ручной проверки откройте перечисленные файлы в Electron IDE.

  • SCREEN: информация о текущем режиме
  • SCREEN 10: адаптивные размеры окна
  • SCREEN: прокрутка экранного текста

Диагностика

Четыре функции состояния могут читать состояние без активной графики; отсутствие графического режима само по себе не вызывает ошибку выполнения.

Для формы POINT(selector) действуют отдельные ошибки: MB3007 при неверном селекторе и MB3010 при отсутствии графического SCREEN 1..10.

Короткие проверки функций

До открытия экрана ширина и высота равны 0. После SCREEN 0 они равны 640 и 300, а текст идёт в отдельное окно. Признак SCREENISACTIVE остаётся ложным, поскольку текстовый режим не включает графику.

  • SCREENWIDTH: короткая проверка результата
  • SCREENHEIGHT: короткая проверка результата
  • SCREENMODE: короткая проверка результата
  • SCREENISACTIVE: короткая проверка результата
