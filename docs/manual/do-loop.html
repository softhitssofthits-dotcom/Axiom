Оператор цикла DO ... LOOP

Предусловные, постусловные и безусловные формы цикла.

Циклы

Оператор цикла DO ... LOOP

Семейство DO ... LOOP нужно в тех случаях, когда одной формы цикла уже недостаточно и важно самому выбрать, где именно проверяется условие: до тела, после тела или вообще через отдельный явный выход. Это самая гибкая группа циклов Axiom.

Сводка

Семейство DO ... LOOP используется, когда нужно самому выбрать момент проверки условия. Предусловные формы проверяют условие до тела, постусловные формы после тела, а безусловная форма работает до тех пор, пока цикл не будет завершён внутренней логикой.

Синтаксис

DO WHILE condition
    [statements]
LOOP
DO UNTIL condition
    [statements]
LOOP
DO
    [statements]
LOOP WHILE condition
DO
    [statements]
LOOP UNTIL condition
DO
    [statements]
LOOP

Части записи

condition задаёт логическое выражение, которое управляет продолжением цикла. В формах WHILE цикл продолжается, пока условие истинно. В формах UNTIL цикл продолжается, пока условие ложно.

Между DO и LOOP размещается тело цикла: обычные инструкции программы, например PRINT, INPUT, присваивания и проверки IF.

Замечания

Обычно к DO ... LOOP переходят тогда, когда нужно явно подчеркнуть семантику предусловия или постусловия либо когда цикл естественно завершается через EXIT DO изнутри тела.

  • Условие может стоять только в одном месте: либо после DO, либо после LOOP.
  • DO WHILE и DO UNTIL могут не выполнить тело ни разу.
  • LOOP WHILE и LOOP UNTIL сначала выполняют тело и только затем проверяют условие, поэтому делают как минимум один проход.
  • Форма DO ... LOOP без условия является безусловным циклом.
  • EXIT DO завершает ближайший окружающий цикл DO ... LOOP.
  • Тело цикла образует собственную блочную область видимости.

Пример

DO
    INPUT "Введите число"; value
    IF value = 0 THEN
        EXIT DO
    END IF
LOOP

Ручная проверка

  • DO WHILE: предусловная форма
  • DO UNTIL: предусловная форма
  • LOOP WHILE: постусловная форма
  • LOOP UNTIL: постусловная форма
  • DO ... LOOP: досрочный выход через EXIT DO
  • DO ... LOOP: безусловная форма

Диагностика

Ошибки возникают, если условие после DO или LOOP не имеет логический тип, а также если EXIT DO используется вне цикла DO ... LOOP.
