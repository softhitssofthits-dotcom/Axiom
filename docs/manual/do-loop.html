Цикл DO ... LOOP

DO ... LOOP дает более гибкую форму цикла, чем WHILE: условие можно поставить в начале, в конце или временно не указывать вовсе. В текущей реализации Axiom подтверждены все основные формы семейства.

Сводка

Семейство DO ... LOOP подходит для сценариев, где нужно управлять моментом проверки условия. Предусловные формы могут не выполнить тело ни разу, постусловные гарантируют как минимум один проход, а безусловная форма продолжается до EXIT DO, RETURN или внешнего завершения программы.

Синтаксис

DO WHILE <условие>
    <инструкции>
LOOP
DO UNTIL <условие>
    <инструкции>
LOOP
DO
    <инструкции>
LOOP WHILE <условие>
DO
    <инструкции>
LOOP UNTIL <условие>
DO
    <инструкции>
LOOP

Части синтаксиса

  • <условие> — логическое выражение, которое управляет продолжением цикла.
  • <инструкции> — тело цикла между DO и LOOP.
  • Форма DO ... LOOP без условия — безусловный цикл, который должен завершаться внутренней логикой, например через EXIT DO или RETURN.

Замечания

  • Условие может стоять только в одном месте: либо после DO, либо после LOOP.
  • DO WHILE ... LOOP повторяет тело, пока условие истинно.
  • DO UNTIL ... LOOP повторяет тело, пока условие ложно.
  • DO ... LOOP WHILE и DO ... LOOP UNTIL сначала выполняют тело и только затем проверяют условие.
  • DO ... LOOP без условия образует безусловный цикл.
  • EXIT DO завершает ближайший окружающий цикл DO ... LOOP.
  • Тело цикла образует собственную блочную область видимости.

Ручная проверка

В репозитории уже есть готовые примеры для всех основных форм семейства DO ... LOOP.

  • DO WHILE: предусловная форма
  • DO UNTIL: предусловная форма
  • LOOP WHILE: постусловная форма
  • LOOP UNTIL: постусловная форма
  • DO ... LOOP: досрочный выход через EXIT DO
  • DO ... LOOP: безусловная форма с внутренним завершением

Примеры

DIM i AS INTEGER = 0

DO WHILE i < 3
    PRINT i
    i = i + 1
LOOP
DIM i AS INTEGER = 0

DO
    PRINT i
    i = i + 1
LOOP UNTIL i = 3
DO
    INPUT "Введите число"; value
    IF value = 0 THEN
        EXIT DO
    END IF
LOOP

Диагностика

  • MB2008 — условие после DO или LOOP не имеет тип BOOLEAN.
  • MB2014 — EXIT DO использован вне цикла DO ... LOOP.
