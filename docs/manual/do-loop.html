Оператор DO ... LOOP

DO ... LOOP — оператор языка Axiom, который используется, когда нужно самому выбрать место проверки условия или выйти из цикла в середине тела. Оператор подходит для чтения ввода, ожидания события, повторения до признака завершения и других случаев, где простой счётчик не выражает намерение программы.

Где проверяется условие

Формы с WHILE продолжают цикл, пока условие истинно. Формы с UNTIL продолжают цикл, пока условие ещё ложно, и завершаются, когда оно становится истинным. Если условие стоит после LOOP, тело выполняется минимум один раз.

Синтаксис

DO WHILE <условие>
    <инструкции>
    [CONTINUE DO]
    [<инструкции>]
LOOP
DO UNTIL <условие>
    <инструкции>
    [CONTINUE DO]
    [<инструкции>]
LOOP
DO
    <инструкции>
    [CONTINUE DO]
    [<инструкции>]
LOOP WHILE <условие>
DO
    <инструкции>
    [CONTINUE DO]
    [<инструкции>]
LOOP UNTIL <условие>
DO
    <инструкции>
    [CONTINUE DO]
    [<инструкции>]
LOOP
EXIT DO

Параметры и части синтаксиса

<условие> - логическое выражение типа BOOLEAN.

<инструкции> - тело цикла между DO и LOOP.

EXIT DO немедленно завершает ближайший окружающий цикл DO ... LOOP и передаёт управление инструкции после LOOP.

CONTINUE DO пропускает оставшуюся часть текущей итерации и переходит к проверке условия (для форм с LOOP WHILE или LOOP UNTIL) или к началу следующей итерации. Подробнее — на странице оператора CONTINUE.

Выход из середины цикла

  • DO WHILE и DO UNTIL проверяют условие до первого прохода.
  • LOOP WHILE и LOOP UNTIL проверяют условие после тела, поэтому тело выполняется хотя бы один раз.
  • Форма DO ... LOOP без условия должна иметь понятный путь завершения, обычно через EXIT DO.
  • Вложенный EXIT DO выходит только из ближайшего цикла DO ... LOOP.

Оператор EXIT DO завершает ближайший охватывающий цикл DO ... LOOP. Поддерживаемые формы условия перечислены в разделе «Синтаксис».

Диагностика

Ошибка возникает, если условие цикла не имеет тип BOOLEAN, если DO не закрыт соответствующим LOOP или если EXIT DO записан вне цикла DO ... LOOP.

  • MB2014 — EXIT DO используется вне цикла DO ... LOOP.
  • MB2039 — CONTINUE DO используется вне цикла DO ... LOOP.

Пример выхода по событию

' Ожидаемый вывод:
' 0
' 1
' done
DIM i AS INTEGER = 0

DO WHILE i < 5
    IF i = 2 THEN
        EXIT DO
    END IF

    PRINT i
    i = i + 1
LOOP

PRINT "done"

Запускаемые примеры

  • DO WHILE: условие в начале
  • DO UNTIL: повторение до условия
  • LOOP WHILE: условие в конце
  • LOOP UNTIL: завершение после прохода
  • EXIT DO: досрочный выход
  • CONTINUE DO: пропуск итерации
  • DO ... LOOP: выход из безусловной формы
