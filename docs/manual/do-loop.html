Оператор DO … LOOP

DO … LOOP — оператор языка Axiom, который повторяет блок с условием в начале, условием в конце или без условия. Формы WHILE продолжают повторение при истинном условии, а UNTIL завершают его при истинном условии.

Назначение и контекст

Оператор DO позволяет повторять действия до изменения состояния данных. Цикл работает в консольной и графической программе, на верхнем уровне и внутри подпрограммы; специальный графический режим ему не нужен.

Выбор места проверки

Если записано только одно условие, условие в заголовке проверяется до первого прохода. Условие после LOOP проверяется после тела, поэтому тело выполняется минимум один раз. Форма без условия повторяется до явного выхода или остановки программы.

Синтаксис

DO WHILE <условие>
    [<инструкции>]
LOOP
DO UNTIL <условие>
    [<инструкции>]
LOOP
DO
    [<инструкции>]
LOOP WHILE <условие>
DO
    [<инструкции>]
LOOP UNTIL <условие>
DO
    [<инструкции>]
LOOP

Части конструкции

Условие — выражение типа BOOLEAN, определяющее продолжение или завершение повторений. Инструкции обозначают ноль или несколько операторов тела. Между DO и LOOP находится тело. EXIT DO немедленно завершает ближайший цикл этого вида.

CONTINUE DO пропускает остаток текущего тела. При единственном условии после LOOP проверяется это условие; при единственном условии после DO проверяется заголовок следующего прохода. Без условия начинается следующий проход.

Диагностика

MB2008 возникает, если любое указанное условие не имеет тип BOOLEAN. MB1001 возникает при отсутствии требуемого окончания блока.

Ошибка возникает, если условие цикла не имеет тип BOOLEAN, если DO не закрыт соответствующим LOOP или если EXIT DO записан вне цикла DO ... LOOP.

  • MB2014 — EXIT DO используется вне цикла DO ... LOOP.
  • MB2039 — CONTINUE DO используется вне цикла DO ... LOOP.

Пример

Цикл с проверкой после тела выполняется хотя бы один раз:

DIM count AS INTEGER = 0
DO
    PRINT count
    count = count + 1
LOOP UNTIL count = 3

Результат:

0
1
2

Запускаемые примеры

Откройте нужный файл в IDE и запустите его. Примеры с ошибкой предназначены для проверки сообщения компилятора или выполнения.

  • DO WHILE: условие в начале
  • DO UNTIL: повторение до условия
  • LOOP WHILE: условие в конце
  • LOOP UNTIL: завершение после прохода
  • EXIT DO: досрочный выход
  • CONTINUE DO: пропуск итерации
  • DO ... LOOP: выход из безусловной формы

Сочетание условий в текущей реализации

Разбор допускает условие после DO и условие после LOOP одновременно. В этом сочетании выполняется проверка выражения и вида WHILE или UNTIL из заголовка DO, но проверка происходит после тела из-за наличия условия после LOOP. Выражение после LOOP при исполнении не вычисляется; его тип всё равно проверяется компилятором. Оба условия не объединяются. Чтобы место проверки было однозначно видно из программы, используйте одну из пяти форм с единственным условием или без условия, показанных выше.

DO WHILE <условие заголовка>
    [<инструкции>]
LOOP WHILE <условие окончания>
DO WHILE <условие заголовка>
    [<инструкции>]
LOOP UNTIL <условие окончания>
DO UNTIL <условие заголовка>
    [<инструкции>]
LOOP WHILE <условие окончания>
DO UNTIL <условие заголовка>
    [<инструкции>]
LOOP UNTIL <условие окончания>

Пример сочетания условий

DIM count AS INTEGER = 0
DO WHILE count < 2
    count = count + 1
    PRINT count
LOOP UNTIL TRUE

Ожидаемый вывод:

1
2
