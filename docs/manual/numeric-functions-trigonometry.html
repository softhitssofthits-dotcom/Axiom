Раздел

Тригонометрические функции

Раздел тригонометрических функций описывает средства SIN, COS, TAN, ATN, ATN2, ASIN, ACOS и гиперболические функции — прямые, обратные и гиперболические вычисления с углами. Все функции возвращают значение типа DOUBLE, а углы в Axiom задаются в радианах.

SIN

Функция SIN возвращает синус угла.

Синтаксис

result = SIN(value)

Аргументы

value задаёт угол в радианах.

COS

Функция COS возвращает косинус угла.

Синтаксис

result = COS(value)

Аргументы

value задаёт угол в радианах.

TAN

Функция TAN возвращает тангенс угла.

Синтаксис

result = TAN(value)

Аргументы

value задаёт угол в радианах.

ATN

Функция ATN возвращает арктангенс значения.

Синтаксис

result = ATN(value)

Аргументы

value задаёт числовое выражение, для которого нужно получить угол.

ATN2

Функция ATN2 возвращает угол по координатам точки на плоскости.

Синтаксис

result = ATN2(y, x)

Аргументы

y задаёт ординату точки, а x абсциссу. Функция учитывает квадрант и поэтому подходит для вычисления направления по двум координатам.

ASIN

Функция ASIN возвращает арксинус значения.

Синтаксис

result = ASIN(value)

Аргументы

value должен находиться в диапазоне от -1 до 1 включительно.

ACOS

Функция ACOS возвращает арккосинус значения.

Синтаксис

result = ACOS(value)

Аргументы

value должен находиться в диапазоне от -1 до 1 включительно.

ASINH

Функция ASINH возвращает обратный гиперболический синус.

Синтаксис

result = ASINH(value)

ACOSH

Функция ACOSH возвращает обратный гиперболический косинус.

Синтаксис

result = ACOSH(value)

Аргументы

value должен быть не меньше 1.

ATANH

Функция ATANH возвращает обратный гиперболический тангенс.

Синтаксис

result = ATANH(value)

Аргументы

value должен лежать строго внутри интервала (-1, 1).

SINH

Функция SINH возвращает гиперболический синус.

Синтаксис

result = SINH(value)

COSH

Функция COSH возвращает гиперболический косинус.

Синтаксис

result = COSH(value)

TANH

Функция TANH возвращает гиперболический тангенс.

Синтаксис

result = TANH(value)

Радианы и допустимые значения

  • Все аргументы этой страницы интерпретируются как числовые значения и при необходимости приводятся к DOUBLE.
  • SIN, COS и TAN принимают угол в радианах. Если вы мыслите в градусах, переводите их в радианы вручную.
  • ASIN, ACOS, ACOSH и ATANH имеют ограничения по области допустимых значений. Нарушение этих ограничений даёт диагностику времени выполнения.

Пример тригонометрических вычислений

В этом примере вычисляются синус, косинус и тангенс одного и того же угла, заданного в радианах:

DIM angle AS DOUBLE

angle = 0.5
PRINT SIN(angle)
PRINT COS(angle)
PRINT TAN(angle)

Результат:

0.479425538604203
0.8775825618904129
0.5463024898437905

Ручная проверка

  • SIN: синус угла
  • COS: косинус угла
  • TAN: тангенс угла
  • ATN: арктангенс
  • ATN2: угол по координатам
  • ASIN: арксинус
  • ASIN: значение вне диапазона
  • ACOS: арккосинус
  • ACOS: значение вне диапазона
  • ASINH: обратный гиперболический синус
  • ACOSH: обратный гиперболический косинус
  • ACOSH: аргумент меньше 1
  • ATANH: обратный гиперболический тангенс
  • ATANH: значение вне диапазона
  • SINH: гиперболический синус
  • COSH: гиперболический косинус
  • TANH: гиперболический тангенс
