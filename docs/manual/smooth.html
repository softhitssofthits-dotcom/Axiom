Оператор SMOOTH

SMOOTH — оператор языка Axiom, который включает или отключает сглаживание всего готового графического кадра при изменении размера.

Для чего нужен оператор SMOOTH

Оператор SMOOTH нужен, когда готовый графический кадр выводится в область другого размера и требуется смягчить ступенчатые края линий, окружностей, изображений и растрового текста.

Оператор SMOOTH фильтрует весь кадр целиком. Программа выбирает один режим для результата рисования, а не настраивает отдельно каждую фигуру или надпись.

Где работает оператор SMOOTH

Оператор SMOOTH действует на графические поверхности SCREEN и CANVAS. В обоих случаях он меняет вывод кадра при масштабировании окна или холста, сохраняя исходные пиксели и координаты программы.

В текстовом режиме SCREEN 0 графический кадр не выводится, поэтому сглаживание там не применяется. Режим, выбранный оператором SMOOTH, сохраняется для следующей графической поверхности.

Синтаксис

SMOOTH ON
SMOOTH OFF

Это две отдельные формы одного оператора. После ключевого слова SMOOTH укажите ровно одно состояние.

Состояние ON или OFF

СостояниеЗначение
ONВключает билинейное смешивание соседних пикселей при выводе кадра в другом размере.
OFFОставляет точечную выборку ближайшего исходного пикселя при изменении размера. Это состояние используется по умолчанию при каждом новом запуске программы.

Что делает оператор SMOOTH

SMOOTH ON сразу обновляет способ показа уже опубликованного графического кадра. На CANVAS новый кадр, который программа ещё рисует и не показала оператором PRESENT, остаётся невидимым до публикации; текущий опубликованный кадр при этом переключается сразу.

При изменении размера кадра среда применяет билинейную интерполяцию всего изображения. Она смешивает цвета соседних пикселей, в том числе пикселей текста и геометрии. Оператор SMOOTH OFF немедленно возвращает точечную выборку.

Перемещение и изменение размера окна используют готовый кадр. Операторы рисования программы при этом не выполняются повторно.

Правила работы и ограничения

  • Оператор SMOOTH можно выполнить до открытия SCREEN или CANVAS; выбранное состояние применяется к следующему графическому кадру.
  • Выбранное состояние сохраняется при переключении между SCREEN и CANVAS и сбрасывается в OFF при новом запуске программы.
  • Если размер кадра совпадает с размером области вывода, фильтрация не меняет пиксели.
  • Билинейная интерполяция может смягчить мелкий текст и тонкие линии. При сильном уменьшении мелкие детали всё равно могут потеряться.
  • Оператор SMOOTH меняет только представление кадра. Функция POINT(x, y) продолжает возвращать цвет логического пикселя.

Диагностика

  • MB1001: после SMOOTH не указано состояние или указано не ON/OFF. Допустимы ровно две формы: SMOOTH ON и SMOOTH OFF.
  • MB1004: после состояния ON или OFF переданы лишние токены. После режима должен завершиться оператор.

Пример

' Включаем сглаживание готового кадра SCREEN.
SMOOTH ON
SCREEN 2
CLS
PSET (20, 20), 12
CIRCLE (220, 160), 60, 14
  PRINT "POINT сохраняет логический цвет: "; POINT(20, 20)
SLEEP

Запускаемый пример для изменения размера SCREEN находится в samples/operators/smooth/screen_resize.axm. Перемещение окна SCREEN 8 и переключение режима клавишами проверяет samples/operators/smooth/screen_move_resize.axm. Пример с переключением режима во время работы CANVAS доступен в samples/operators/smooth/canvas_resize.axm.
