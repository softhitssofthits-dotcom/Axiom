Динамические массивы

Динамический массив — тип данных Axiom, границы которого можно установить и изменить во время выполнения. Раздел описывает отдельные операторы DIM, REDIM, REDIM PRESERVE и ERASE; их формы не являются одной инструкцией.

Назначение и контекст

DIM без границ задаёт тип элемента и ранг до получения размера. REDIM выделяет элементы по текущим значениям границ. REDIM PRESERVE сохраняет пересечение старой и новой области. ERASE освобождает хранилище. Эти действия не требуют SCREEN.

Отдельные формы

DIM <массив>() AS <тип элемента>
DIM <массив>(,) AS <тип элемента>
REDIM <массив>(<нижняя граница> TO <верхняя граница>)
REDIM PRESERVE <массив>(<нижняя граница> TO <верхняя граница>)
REDIM PRESERVE <массив>(<границы 1>, <границы 2>)
ERASE <массив>

Части записи

Массив обозначает изменяемое массивное значение или динамическое массивное поле TYPE. Тип элемента и ранг не изменяются. Для многомерного массива после REDIM указываются границы каждого измерения.

Границы задаются числовыми выражениями. INTEGER используется непосредственно; LONG должен помещаться в INTEGER; дробная часть DOUBLE и DECIMAL отбрасывается к нулю. Нижняя граница -2147483648 запрещена, потому что поисковые функции используют нижнюю границу минус 1 как признак отсутствия. Верхняя граница включается в массив. Обратный диапазон допустим только как каноническая пустая форма 1 TO 0 при DIM или REDIM.

Выделение и сохранение

Обычный REDIM заменяет элементы значениями по умолчанию. REDIM PRESERVE сохраняет значения по тем же координатам в пересечении границ всех измерений; новые координаты получают значения по умолчанию. Можно менять несколько измерений и нижние границы одновременно, сохраняя ранг.

Массив, изначально объявленный с границами DIM, также допускает REDIM. Представление не допускает изменения размера. Фиксированное массивное поле TYPE нельзя передавать операторам REDIM или ERASE.

После ERASE ARRAYISALLOCATED возвращает FALSE, ARRAYLENGTH — 0, ARRAYRANK сохраняет ранг. Для повторного доступа нужны REDIM либо присваивание выделенного массива. Выделенный пустой массив 1 TO 0 имеет состояние TRUE, хотя элементов в нём нет.

Диагностика

MB2003 означает несовместимый тип элемента или индекса, MB2004 — неверное число индексов. MB3002 возникает, когда индекс или диапазон при индексировании выходит за границы. MB3005 возникает при доступе к невыделенному массиву либо при недопустимой паре границ. MB3007 сообщает о запрещённой нижней границе -2147483648; выход числового значения за диапазон INTEGER даёт MB3008.

MB2011 возникает, если цель REDIM или ERASE не является массивом. MB2025 запрещает эти операторы для фиксированного массивного поля TYPE. MB3007 запрещает изменение размера представления.

Пример

DIM values() AS INTEGER
PRINT ARRAYISALLOCATED(values)
REDIM values(2 TO 3)
values(2) = 10
values(3) = 30
REDIM PRESERVE values(1 TO 4)
PRINT values(2)
PRINT values(4)
ERASE values
PRINT ARRAYISALLOCATED(values)

Ожидаемый вывод:

FALSE
10
0
FALSE
