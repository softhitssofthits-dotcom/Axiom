REDIM, REDIM PRESERVE и ERASE

Динамические массивы

Изменение границ массива после объявления.

Массивы

Динамические массивы

Сводка

Динамический массив объявляется без конкретных границ, а затем получает их через REDIM. Такой подход удобен, когда размер массива становится известен только во время выполнения программы.

Синтаксис

DIM arrayName() AS elementType
REDIM arrayName(lowerBound TO upperBound)
REDIM PRESERVE arrayName(lowerBound TO upperBound)
ERASE arrayName

Части записи

  • arrayName — имя динамического массива.
  • elementType — тип элементов массива.
  • lowerBound TO upperBound — новые включительные границы массива.

Замечания

  • DIM values() AS INTEGER объявляет динамический массив без выделения памяти для элементов.
  • REDIM задаёт новые границы массива и выделяет память в соответствии с ними.
  • REDIM PRESERVE изменяет размер массива с сохранением тех элементов, которые попадают в область пересечения старых и новых границ.
  • ERASE возвращает динамический массив в невыделенное состояние.
  • После ERASE массив нельзя использовать снова, пока ему не будут заново назначены границы через REDIM.

Пример

' Программа создаёт массив, расширяет его и сохраняет первые значения
' Ожидаемый вывод:
' 10
' 30
DIM values() AS INTEGER

REDIM values(1 TO 3)
values(1) = 10
values(2) = 20
values(3) = 30

REDIM PRESERVE values(1 TO 5)
PRINT values(1)
PRINT values(3)

ERASE values

Ручная проверка

  • DIM: объявление динамического массива
  • REDIM: базовое изменение размера
  • REDIM PRESERVE: сохранение значений
  • ERASE: возврат в невыделенное состояние
