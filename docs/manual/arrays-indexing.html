Массивы

Индексирование массивов

Индексирование указывает, какую часть массива выбирает программа. Если указаны все индексы, результатом становится один элемент. Если часть измерений оставлена диапазоном или не указана до конца, результатом становится видимая часть массива.

Как индексы выбирают данные

Каждый индекс относится к своему измерению массива. В одномерном массиве один индекс выбирает элемент списка. В двумерном массиве первый индекс обычно выбирает строку, второй - столбец. В многомерном массиве порядок индексов совпадает с порядком измерений в объявлении DIM или REDIM.

Границы включительные: индекс должен быть не меньше LBOUND и не больше UBOUND для выбранного измерения.

Синтаксис

<переменная> = <массив>(<индекс>)
<переменная> = <массив>(<индекс 1>, <индекс 2>)
<переменная> = <массив>(<индекс 1>, <индекс 2>, <индекс 3>)

<представление> = <массив>(<фиксированный индекс>, <начало> TO <конец>)
<представление> = <массив>(<начало> TO <конец>, <начало> TO <конец>)
<представление> = <массив>(<фиксированный индекс>)

Части записи

  • <массив> - имя переменной массива или выражение, которое возвращает массив.
  • <индекс> - целочисленное значение внутри границ соответствующего измерения.
  • <начало> TO <конец> - включительный диапазон индексов.
  • <представление> - результат частичного выбора. Обычно он указывает на ту же область данных, а не создаёт независимую копию.

Полная и частичная форма

  • Полная форма указывает индекс для каждого измерения и возвращает конкретный элемент массива.
  • Частичная форма выбирает строку, столбец, прямоугольный диапазон или другой видимый срез массива.
  • Если нужна независимая копия выбранных данных, используйте ARRAYCLONE или создайте новый массив явно.
  • Если индекс или диапазон выходит за границы, выполнение завершается диагностикой времени выполнения.

Пример полного и частичного индексирования

' Ожидаемый вывод:
' 20
' 99
DIM board(1 TO 2, 1 TO 3) AS INTEGER
DIM rowPart() AS INTEGER

board(1, 1) = 10
board(1, 2) = 20
board(2, 3) = 99

PRINT board(1, 2)
PRINT board(2, 3)

rowPart = board(1)
PRINT rowPart(2)
