Индексирование массивов

Раздел индексирования описывает форму выражения Axiom, которая читает элемент массива или создаёт представление выбранной области. Полная запись содержит один индекс для каждого измерения.

Назначение и контекст

Индексирование позволяет читать и изменять отдельные элементы. Фиксированный индекс убирает одно измерение результата; диапазон TO сохраняет измерение с выбранными границами. Если часть конечных измерений не указана, они входят в представление полностью. Для доступа нужен выделенный массив.

Синтаксис

<массив>(<индекс>)
<массив>(<индекс 1>, <индекс 2>)
<массив>(<фиксированный индекс>)
<массив>(<фиксированный индекс>, <начало> TO <конец>)
<массив>(<начало 1> TO <конец 1>, <начало 2> TO <конец 2>)

Аргументы индексирования

Массив является переменной или выражением массивного типа. Каждый индекс и каждая граница диапазона задаются числовым выражением. Положение аргумента соответствует номеру измерения. Начало и конец диапазона включаются в результат. Значение обязано быть целым и помещаться в INTEGER; ненулевая дробная часть вызывает MB3007.

Результат и запись

Индекс должен быть целым числом. Значение DOUBLE или DECIMAL допустимо, только если его дробная часть равна нулю; иначе возникает MB3007. В диапазоне TO нижняя граница не должна быть больше верхней: обратный диапазон вызывает MB3002, а не пустой результат. Если все измерения заданы одиночными индексами, результат имеет тип элемента. При оставшихся измерениях результат является массивным представлением. Представление сохраняет логические границы выбранных измерений; индексы не перенумеровываются.

Для присваивания отдельному элементу укажите все индексы. Для изменения области сначала сохраните представление в массивной переменной и меняйте его элементы либо вызовите ARRAYFILL. Изменение видно в исходном хранилище.

Диагностика

MB2003 означает несовместимый тип элемента или индекса, MB2004 — неверное число индексов. MB3002 возникает, когда индекс или диапазон при индексировании выходит за границы. MB3005 возникает при доступе к невыделенному массиву либо при недопустимой паре границ. MB3007 сообщает о запрещённой нижней границе -2147483648; выход числового значения за диапазон INTEGER даёт MB3008.

Число аргументов чтения должно быть от 1 до ранга. Для записи отдельному элементу требуется ровно столько индексов, каков ранг массива.

Пример полного и частичного доступа

DIM board(1 TO 2, 2 TO 4) AS INTEGER
board(2, 3) = 20
DIM rowPart() AS INTEGER
rowPart = board(2)
PRINT rowPart(3)
rowPart(3) = 99
PRINT board(2, 3)

Ожидаемый вывод:

20
99
