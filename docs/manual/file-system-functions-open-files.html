Раздел

Функции для открытого файла

Раздел функций для открытого файла описывает средства работы с переменной типа FILE после оператора OPEN: чтение, запись, позиционирование и получение сведений об открытом файле.

Функции открытого файла

Функции этой страницы удобно читать по группам. Сначала идут функции состояния и сведений об открытом файле, затем функции чтения, потом функции записи и в конце функции позиционирования.

ISOPEN

Функция ISOPEN проверяет, связан ли объект FILE с открытым файлом в текущий момент.

Синтаксис

result = ISOPEN(file)

Аргументы

file задаёт переменную типа FILE. Функция возвращает TRUE, если файл открыт, и FALSE, если переменная ещё не открыта или уже закрыта.

Пример вызова ISOPEN

' Проверка состояния файла до и после открытия
DIM f AS FILE

PRINT ISOPEN(f)
OPEN "notes.txt" FOR INPUT AS f
PRINT ISOPEN(f)
CLOSE f

FILEPATH

Функция FILEPATH возвращает полный путь файла, который сейчас связан с переменной FILE.

Синтаксис

path = FILEPATH(file)

Аргументы

file задаёт открытую переменную типа FILE. Результатом является строка с полным путём.

Пример вызова FILEPATH

' Получение полного пути открытого файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILEPATH(f)
CLOSE f

FILEMODE

Функция FILEMODE возвращает режим, в котором файл был открыт.

Синтаксис

modeName = FILEMODE(file)

Аргументы

file задаёт открытую переменную типа FILE. Результат обычно имеет вид INPUT, OUTPUT или APPEND.

Пример вызова FILEMODE

' Определение режима открытого файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILEMODE(f)
CLOSE f

FILEPOS

Функция FILEPOS возвращает текущую позицию чтения или записи в открытом файле.

Синтаксис

position = FILEPOS(file)

Аргументы

file задаёт открытую переменную типа FILE. Возвращаемое значение имеет тип LONG.

Пример вызова FILEPOS

' Позиция меняется после чтения строки
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILEPOS(f)
PRINT READLINE(f)
PRINT FILEPOS(f)
CLOSE f

FILELENGTH

Функция FILELENGTH возвращает длину открытого файла в тех же единицах, в которых работает FILEPOS.

Синтаксис

length = FILELENGTH(file)

Аргументы

file задаёт открытую переменную типа FILE. Результатом является число типа LONG.

Пример вызова FILELENGTH

' Получение длины открытого файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILELENGTH(f)
CLOSE f

EOF

Функция EOF показывает, достигнута ли конечная позиция файла при чтении.

Синтаксис

result = EOF(file)

Аргументы

file задаёт файл, открытый для чтения. Функция возвращает TRUE, когда позиция чтения уже дошла до конца файла.

Пример вызова EOF

' Чтение файла до конца
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
DO WHILE NOT EOF(f)
    PRINT READLINE(f)
LOOP
CLOSE f

READTOEND

Функция READTOEND читает остаток файла от текущей позиции до конца и возвращает его одной строкой.

Синтаксис

text = READTOEND(file)

Аргументы

file задаёт файл, открытый для чтения. Возвращается строка с остатком содержимого без дополнительного преобразования в массив строк.

Пример вызова READTOEND

' Чтение первой строки отдельно, а затем остатка файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READLINE(f)
PRINT READTOEND(f)
CLOSE f

READTEXT

READTEXT — встроенная функция языка Axiom, которая читает из открытого файла фрагмент текста длиной до указанного количества символов Unicode. Функция нужна для чтения текста небольшими порциями и работает с файлом, открытым оператором OPEN в режиме FOR INPUT.

Синтаксис

text = READTEXT(file, count)

Аргументы

Аргумент file должен иметь тип FILE и задавать открытый файл для чтения. Аргумент count должен быть неотрицательным целым числом и задаёт максимальное количество символов Unicode в результате.

Результат и правила чтения

Функция возвращает строку. Один символ здесь означает одно скалярное значение Unicode: например, 😀 считается одним символом, хотя в строке он занимает два места UTF-16. Отдельный комбинируемый знак считается отдельным символом; функция не считает целые графемы. Функция LEN продолжает измерять длину строки в единицах UTF-16, поэтому длина результата READTEXT(file, 1) может равняться двум.

При count = 0 возвращается пустая строка без перемещения позиции. В конце файла также возвращается пустая строка, а если осталось меньше символов, чем запрошено, возвращается оставшийся текст. Позиция FILEPOS измеряется в байтах: чтение 😀 из UTF-8 сдвигает позицию на четыре байта. BOM не входит в пользовательскую позицию файла.

Диагностика

Закрытый файл, неподходящий режим чтения, отрицательный аргумент count или чтение UTF-8 с некорректной границы символа дают диагностику MB3007. При ошибке декодирования позиция возвращается к месту начала вызова; ошибку можно обработать через TRY/CATCH.

Пример вызова READTEXT

' Чтение первых пяти символов
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READTEXT(f, 5)
CLOSE f

Чтение emoji по одному символу

DIM path AS STRING = MAKETEMPFILE("readtext_unicode_")
DIM f AS FILE
PRINT WRITEFILE(path, "😀А")
OPEN path FOR INPUT AS f
PRINT READTEXT(f, 1) ' Выводит целый emoji.
PRINT FILEPOS(f)    ' Позиция равна 4 байтам.
PRINT READTEXT(f, 1) ' Выводит букву А.
CLOSE f
PRINT DELETEFILE(path)

Полная запускаемая проверка: чтение Unicode порциями. Путь создаёт функция MAKETEMPFILE; оператор OPEN для чтения сам файл не создаёт.

READLINE

Функция READLINE читает одну текстовую строку от текущей позиции и возвращает её без символов перевода строки.

Синтаксис

lineText = READLINE(file)

Аргументы

file задаёт файл, открытый для чтения. Результатом является одна строка текста.

Пример вызова READLINE

' Последовательное чтение строк
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READLINE(f)
PRINT READLINE(f)
CLOSE f

READLINES

Функция READLINES читает несколько строк подряд и возвращает их как массив STRING().

Синтаксис

lines = READLINES(file, count)

Аргументы

file задаёт файл, открытый для чтения. count задаёт число строк. Результатом является новый массив строк.

Пример вызова READLINES

' Чтение двух строк одним вызовом
DIM f AS FILE
DIM lines() AS STRING

OPEN "notes.txt" FOR INPUT AS f
lines = READLINES(f, 2)
PRINT lines(1)
PRINT lines(2)
CLOSE f

LINENUMBER

Функция LINENUMBER возвращает номер текущей строки чтения в текстовом файле.

Синтаксис

lineNumber = LINENUMBER(file)

Аргументы

file задаёт файл, открытый в режиме INPUT. Результатом является номер строки типа LONG.

Правила и диагностика

Нумерация начинается с 1. CR, LF и CRLF увеличивают номер на одну строку. При явной UTF-16-кодировке номер считается по двухбайтовым единицам, поэтому байт перевода строки внутри другого символа не меняет номер. После SEEKFILE на нечётную позицию UTF-16 функция даёт MB3007; позиция сохраняется, ошибку можно обработать через TRY/CATCH. Сама функция LINENUMBER не перемещает указатель чтения.

Пример неверной позиции UTF-16

DIM folder AS STRING = MAKETEMPDIR("line_seek_")
DIM path AS STRING = COMBINEPATH(folder, "text.txt")
DIM f AS FILE
PRINT WRITEFILE(path, "А", "UTF-16LE")
OPEN path FOR INPUT AS f USING "UTF-16LE"
' Смещение попадает внутрь двухбайтового символа.
PRINT SEEKFILE(f, 1)
TRY
    PRINT LINENUMBER(f)
CATCH err
    PRINT err.Code
END TRY
PRINT FILEPOS(f)
CLOSE f

После отказа функция FILEPOS возвращает 1. Полный пример с восстановлением позиции: номер строки и UTF-16.

Пример вызова LINENUMBER

' Номер строки увеличивается после чтения
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT LINENUMBER(f)
PRINT READLINE(f)
PRINT LINENUMBER(f)
CLOSE f

SKIPLINE

Функция SKIPLINE пропускает текущую строку и переводит позицию к началу следующей строки.

Синтаксис

result = SKIPLINE(file)

Аргументы

file задаёт файл, открытый для чтения. Функция возвращает TRUE, если переход выполнен.

Пример вызова SKIPLINE

' Пропуск первой строки
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT SKIPLINE(f)
PRINT READLINE(f)
CLOSE f

WRITE

WRITE — встроенная функция языка Axiom, которая записывает строку в открытый файл без добавления перевода строки. Функция нужна для последовательной записи нескольких фрагментов текста в режимах OUTPUT и APPEND.

Каждый вызов отдельно кодирует строку в UTF-8 без BOM. Целая пара UTF-16, например 😀, записывается четырьмя байтами. Изолированная половина пары заменяется символом � (U+FFFD), который занимает три байта. Половины из разных вызовов не объединяются; вызов FLUSH между ними не меняет текст или длину файла. Чтобы сохранить эмодзи, передайте целую пару в одном аргументе.

FILEPOS и FILELENGTH учитывают уже закодированные байты, включая ещё не сброшенный буфер. Байты становятся доступны на диске после FLUSH, CLOSE или позиционирования выходного файла. Для закрытого файла или файла в режиме INPUT функция выдаёт диагностику MB3007.

Синтаксис

result = WRITE(file, text)

Аргументы

file задаёт файл, открытый для записи. text задаёт строку, которую нужно записать. Результат имеет тип BOOLEAN.

Запись фрагментов UTF-16

DIM path AS STRING = MAKETEMPFILE("axiom_write_unicode_")
DIM f AS FILE
OPEN path FOR OUTPUT AS f
PRINT WRITE(f, LEFT("😀", 1))
PRINT WRITE(f, RIGHT("😀", 1))
PRINT FILEPOS(f) ' 6 байт: два символа замены, независимо от FLUSH.
CLOSE f
PRINT READFILE(path) = "��" ' TRUE
PRINT DELETEFILE(path)

Полный запускаемый пример: байты фрагментов UTF-16.

Явная кодировка и диагностика

Если файл открыт через OPEN ... USING encoding, текст кодируется строго. Непредставимый символ Windows-1251 или непарный суррогат Unicode дают MB3007, которую можно обработать через TRY/CATCH. Неудачная запись не изменяет буфер, FILEPOS и FILELENGTH; последующая корректная запись остаётся возможной.

DIM folder AS STRING = MAKETEMPDIR("strict_write_")
DIM path AS STRING = COMBINEPATH(folder, "text.txt")
DIM f AS FILE
OPEN path FOR OUTPUT AS f USING "WINDOWS-1251"
PRINT WRITE(f, "А")
' Эмодзи отсутствует в Windows-1251.
TRY
    PRINT WRITE(f, "😀")
CATCH err
    PRINT err.Code
END TRY
PRINT FILEPOS(f)
PRINT WRITE(f, "я")
CLOSE f

Позиция после отказа равна 1; файл содержит «Ая». Полный пример: продолжение после отказа записи.

Пример вызова WRITE

' Запись двух фрагментов в одну строку
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITE(f, "left")
PRINT WRITE(f, "-right")
CLOSE f

WRITELINE

Функция WRITELINE записывает строку и сразу завершает её переводом строки. Перевод строки — один символ LF (U+000A), а не пара CRLF: это нужно учитывать при обмене файлами с программами, ожидающими классические текстовые концы строк Windows.

Этот договор действует также в Windows и в режиме APPEND. Добавленный перевод строки занимает один байт в UTF-8 и WINDOWS-1251, два байта в UTF-16LE и UTF-16BE. Если запись идёт в конец файла, на это число увеличиваются FILEPOS и FILELENGTH; при перезаписи внутри файла длина сохраняется, пока запись не выходит за прежний конец.

Синтаксис

result = WRITELINE(file, text)

Аргументы

file задаёт файл, открытый для записи. text задаёт содержимое строки. Возвращается TRUE, если запись выполнена.

Диагностика явной кодировки

При OPEN ... USING encoding действуют те же строгие правила, что у WRITE. Если текст нельзя закодировать, возникает MB3007; ни текст, ни завершающий перевод строки не попадают в буфер, а позиция и длина сохраняются.

Пример вызова WRITELINE

' Запись двух строк
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITELINE(f, "alpha")
PRINT WRITELINE(f, "beta")
CLOSE f

NEWLINE

Функция NEWLINE добавляет в открытый файл перевод строки без дополнительного текста. Как и у WRITELINE, записывается один символ LF (U+000A). Он занимает один байт в UTF-8 и WINDOWS-1251, два байта в UTF-16LE и UTF-16BE. При записи внутри файла существующий хвост сохраняется; длина увеличивается только при выходе записи за прежний конец.

Синтаксис

result = NEWLINE(file)

Позиции в UTF-16

DIM path AS STRING = MAKETEMPFILE("newline_utf16_")
DIM f AS FILE
OPEN path FOR OUTPUT AS f USING "UTF-16LE"
PRINT NEWLINE(f)
PRINT FILEPOS(f)    ' 2 байта; BOM не входит в позицию.
PRINT WRITELINE(f, "")
PRINT FILEPOS(f)    ' 4 байта.
CLOSE f
PRINT DELETEFILE(path)

Запускаемая проверка: байтовые позиции переводов строк UTF-16.

Аргументы

file задаёт файл, открытый для записи. Результат имеет тип BOOLEAN.

Пример вызова NEWLINE

' Добавление пустой строки между двумя записями
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITELINE(f, "alpha")
PRINT NEWLINE(f)
PRINT WRITELINE(f, "beta")
CLOSE f

FLUSH

Функция FLUSH принудительно сбрасывает накопленную запись в файл.

Синтаксис

result = FLUSH(file)

Аргументы

file задаёт файл, открытый для записи. Результатом является TRUE при успешном сбросе.

Пример вызова FLUSH

' Немедленная запись буфера
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITE(f, "alpha")
PRINT FLUSH(f)
CLOSE f

SEEKFILE

SEEKFILE — встроенная функция языка Axiom, которая задаёт байтовую позицию следующего чтения или записи в открытом файле. Функция нужна для возврата к сохранённой позиции или перезаписи известного участка; она не выполняет замену целого символа текста.

Синтаксис

result = SEEKFILE(file, position)

Аргументы

file задаёт открытую переменную типа FILE. position задаёт целевую позицию типа LONG. Результатом является TRUE, если переход выполнен.

Допустимые режимы. SEEKFILE разрешён для режимов INPUT и OUTPUT. Для режима APPEND явный переход по позиции не поддерживается.

Байтовые позиции и многобайтовый текст

Позиция начинается с 0 и измеряется в байтах текстового содержимого; распознанный BOM в неё не входит. Допустим диапазон от 0 до FILELENGTH(file) включительно. Неправильная позиция или режим APPEND дают MB3007, не меняя текущую позицию. В OUTPUT успешный переход сначала сбрасывает накопленную запись.

Функция SEEKFILE не проверяет границу Unicode-символа. В OUTPUT последующий WRITE заменяет только байты новой строки, сохраняя остальной хвост. Даже запись на границе символа может повредить текст, если новая строка короче прежнего символа: в UTF-8 запись «Z» на позиции 1 в файле «A😀B» оставляет три байта emoji. Строгий READFILE(path, "UTF-8") и OPEN ... USING "UTF-8" отклоняют такой файл с MB3007. Чтение без явной кодировки может выбрать WINDOWS-1251 и не является проверкой целостности UTF-8.

Для замены текста переменной длины прочитайте файл в строку, измените строку через REPLACE, затем запишите весь результат через WRITEFILE в той же кодировке. Такой способ требует размещения текста в памяти и не обещает атомарную замену файла. Пример ниже показывает только собственный временный файл.

DIM path AS STRING = MAKETEMPFILE("replace_unicode_")
PRINT WRITEFILE(path, "A😀B", "UTF-8")
DIM text AS STRING = READFILE(path, "UTF-8")
PRINT WRITEFILE(path, REPLACE(text, "😀", "Z"), "UTF-8")
PRINT READFILE(path, "UTF-8") ' AZB
PRINT DELETEFILE(path)

Запускаемая проверка байтовой перезаписи и полной замены: перезапись многобайтового текста.

Пример вызова SEEKFILE

' Замена одного символа в уже записанном тексте
' Ожидаемый вывод: ABZDE
DIM path AS STRING
DIM f AS FILE

path = MAKETEMPFILE("seekfile_demo_")

OPEN path FOR OUTPUT AS f
PRINT WRITE(f, "ABCDE")
PRINT SEEKFILE(f, 2)
PRINT WRITE(f, "Z")
CLOSE f

PRINT READFILE(path)

REWIND

Функция REWIND возвращает позицию чтения или записи в начало открытого файла.

Синтаксис

result = REWIND(file)

Аргументы

file задаёт открытую переменную типа FILE. Результат имеет тип BOOLEAN.

Допустимые режимы. Как и SEEKFILE, функция используется с режимами INPUT и OUTPUT.

Пример вызова REWIND

' Возврат в начало после чтения первой строки
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READLINE(f)
PRINT REWIND(f)
PRINT FILEPOS(f)
PRINT READLINE(f)
CLOSE f

Позиция, режим и конец файла

  • READTOEND, READTEXT, READLINE, READLINES, LINENUMBER и SKIPLINE предназначены для файла, открытого через FOR INPUT.
  • WRITE, WRITELINE, NEWLINE и FLUSH используются с файлами, открытыми через FOR OUTPUT или FOR APPEND.
  • FILEPOS и FILELENGTH помогают контролировать позицию независимо от того, читаете вы файл или записываете его.
  • Если нужно заново читать файл с начала, обычно удобно вызвать REWIND, а не вычислять начальную позицию вручную.

Диагностика

  • Обращение к закрытому файлу даёт диагностику времени выполнения MB3007.
  • Попытка вызвать функцию чтения или записи в неподходящем режиме открытия также даёт MB3007.
  • Недопустимая позиция для SEEKFILE или попытка позиционирования в режиме APPEND завершается диагностикой времени выполнения MB3007.

Ручная проверка

  • ISOPEN: состояние файла
  • FILEPATH: путь открытого файла
  • FILEMODE: режим открытия
  • FILEPOS: текущая позиция
  • FILELENGTH: длина файла
  • EOF: конец файла
  • READTOEND: остаток файла
  • READTEXT: фрагмент текста
  • READLINE: одна строка
  • READLINES: несколько строк
  • LINENUMBER: номер строки
  • SKIPLINE: пропуск строки
  • WRITE: запись без перевода строки
  • WRITELINE: запись строки
  • NEWLINE: пустая строка
  • FLUSH: сброс буфера
  • SEEKFILE: переход по позиции
  • REWIND: возврат в начало
