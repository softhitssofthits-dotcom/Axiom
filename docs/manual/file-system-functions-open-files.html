Функции для открытого файла

Эти функции работают не с путём к файлу, а с уже открытой переменной типа FILE. Сначала файл открывается оператором OPEN, затем эта переменная передаётся в функции чтения, записи, проверки состояния и перехода по позиции.

Функции открытого файла

Функции этой страницы удобно читать по группам. Сначала идут функции состояния и сведений об открытом файле, затем функции чтения, потом функции записи и в конце функции позиционирования.

ISOPEN

Функция ISOPEN проверяет, связан ли объект FILE с открытым файлом в текущий момент.

Синтаксис

result = ISOPEN(file)

Части записи. file задаёт переменную типа FILE. Функция возвращает TRUE, если файл открыт, и FALSE, если переменная ещё не открыта или уже закрыта.

Пример вызова ISOPEN

' Проверка состояния файла до и после открытия
DIM f AS FILE

PRINT ISOPEN(f)
OPEN "notes.txt" FOR INPUT AS f
PRINT ISOPEN(f)
CLOSE f

FILEPATH

Функция FILEPATH возвращает полный путь файла, который сейчас связан с переменной FILE.

Синтаксис

path = FILEPATH(file)

Части записи. file задаёт открытую переменную типа FILE. Результатом является строка с полным путём.

Пример вызова FILEPATH

' Получение полного пути открытого файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILEPATH(f)
CLOSE f

FILEMODE

Функция FILEMODE возвращает режим, в котором файл был открыт.

Синтаксис

modeName = FILEMODE(file)

Части записи. file задаёт открытую переменную типа FILE. Результат обычно имеет вид INPUT, OUTPUT или APPEND.

Пример вызова FILEMODE

' Определение режима открытого файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILEMODE(f)
CLOSE f

FILEPOS

Функция FILEPOS возвращает текущую позицию чтения или записи в открытом файле.

Синтаксис

position = FILEPOS(file)

Части записи. file задаёт открытую переменную типа FILE. Возвращаемое значение имеет тип LONG.

Пример вызова FILEPOS

' Позиция меняется после чтения строки
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILEPOS(f)
PRINT READLINE(f)
PRINT FILEPOS(f)
CLOSE f

FILELENGTH

Функция FILELENGTH возвращает длину открытого файла в тех же единицах, в которых работает FILEPOS.

Синтаксис

length = FILELENGTH(file)

Части записи. file задаёт открытую переменную типа FILE. Результатом является число типа LONG.

Пример вызова FILELENGTH

' Получение длины открытого файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT FILELENGTH(f)
CLOSE f

EOF

Функция EOF показывает, достигнута ли конечная позиция файла при чтении.

Синтаксис

result = EOF(file)

Части записи. file задаёт файл, открытый для чтения. Функция возвращает TRUE, когда позиция чтения уже дошла до конца файла.

Пример вызова EOF

' Чтение файла до конца
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
DO WHILE NOT EOF(f)
    PRINT READLINE(f)
LOOP
CLOSE f

READTOEND

Функция READTOEND читает остаток файла от текущей позиции до конца и возвращает его одной строкой.

Синтаксис

text = READTOEND(file)

Части записи. file задаёт файл, открытый для чтения. Возвращается строка с остатком содержимого без дополнительного преобразования в массив строк.

Пример вызова READTOEND

' Чтение первой строки отдельно, а затем остатка файла
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READLINE(f)
PRINT READTOEND(f)
CLOSE f

READTEXT

Функция READTEXT читает указанное количество символов или текстовых позиций от текущего места.

Синтаксис

text = READTEXT(file, count)

Части записи. file задаёт файл, открытый для чтения. count задаёт, сколько текста нужно прочитать. Результатом является строка.

Пример вызова READTEXT

' Чтение первых пяти символов
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READTEXT(f, 5)
CLOSE f

READLINE

Функция READLINE читает одну текстовую строку от текущей позиции и возвращает её без символов перевода строки.

Синтаксис

lineText = READLINE(file)

Части записи. file задаёт файл, открытый для чтения. Результатом является одна строка текста.

Пример вызова READLINE

' Последовательное чтение строк
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READLINE(f)
PRINT READLINE(f)
CLOSE f

READLINES

Функция READLINES читает несколько строк подряд и возвращает их как массив STRING().

Синтаксис

lines = READLINES(file, count)

Части записи. file задаёт файл, открытый для чтения. count задаёт число строк. Результатом является новый массив строк.

Пример вызова READLINES

' Чтение двух строк одним вызовом
DIM f AS FILE
DIM lines() AS STRING

OPEN "notes.txt" FOR INPUT AS f
lines = READLINES(f, 2)
PRINT lines(1)
PRINT lines(2)
CLOSE f

LINENUMBER

Функция LINENUMBER возвращает номер текущей строки чтения в текстовом файле.

Синтаксис

lineNumber = LINENUMBER(file)

Части записи. file задаёт файл, открытый в режиме INPUT. Результатом является номер строки типа LONG.

Пример вызова LINENUMBER

' Номер строки увеличивается после чтения
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT LINENUMBER(f)
PRINT READLINE(f)
PRINT LINENUMBER(f)
CLOSE f

SKIPLINE

Функция SKIPLINE пропускает текущую строку и переводит позицию к началу следующей строки.

Синтаксис

result = SKIPLINE(file)

Части записи. file задаёт файл, открытый для чтения. Функция возвращает TRUE, если переход выполнен.

Пример вызова SKIPLINE

' Пропуск первой строки
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT SKIPLINE(f)
PRINT READLINE(f)
CLOSE f

WRITE

Функция WRITE записывает текст в открытый файл без добавления перевода строки.

Синтаксис

result = WRITE(file, text)

Части записи. file задаёт файл, открытый для записи. text задаёт строку, которую нужно записать. Результат имеет тип BOOLEAN.

Пример вызова WRITE

' Запись двух фрагментов в одну строку
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITE(f, "left")
PRINT WRITE(f, "-right")
CLOSE f

WRITELINE

Функция WRITELINE записывает строку и сразу завершает её переводом строки.

Синтаксис

result = WRITELINE(file, text)

Части записи. file задаёт файл, открытый для записи. text задаёт содержимое строки. Возвращается TRUE, если запись выполнена.

Пример вызова WRITELINE

' Запись двух строк
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITELINE(f, "alpha")
PRINT WRITELINE(f, "beta")
CLOSE f

NEWLINE

Функция NEWLINE добавляет в открытый файл перевод строки без дополнительного текста.

Синтаксис

result = NEWLINE(file)

Части записи. file задаёт файл, открытый для записи. Результат имеет тип BOOLEAN.

Пример вызова NEWLINE

' Добавление пустой строки между двумя записями
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITELINE(f, "alpha")
PRINT NEWLINE(f)
PRINT WRITELINE(f, "beta")
CLOSE f

FLUSH

Функция FLUSH принудительно сбрасывает накопленную запись в файл.

Синтаксис

result = FLUSH(file)

Части записи. file задаёт файл, открытый для записи. Результатом является TRUE при успешном сбросе.

Пример вызова FLUSH

' Немедленная запись буфера
DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
PRINT WRITE(f, "alpha")
PRINT FLUSH(f)
CLOSE f

SEEKFILE

Функция SEEKFILE переводит текущую позицию открытого файла в указанное место.

Синтаксис

result = SEEKFILE(file, position)

Части записи. file задаёт открытую переменную типа FILE. position задаёт целевую позицию типа LONG. Результатом является TRUE, если переход выполнен.

Допустимые режимы. SEEKFILE разрешён для режимов INPUT и OUTPUT. Для режима APPEND явный переход по позиции не поддерживается.

Пример вызова SEEKFILE

' Замена одного символа в уже записанном тексте
' Ожидаемый вывод: ABZDE
DIM path AS STRING
DIM f AS FILE

path = MAKETEMPFILE("seekfile_demo_")

OPEN path FOR OUTPUT AS f
PRINT WRITE(f, "ABCDE")
PRINT SEEKFILE(f, 2)
PRINT WRITE(f, "Z")
CLOSE f

PRINT READFILE(path)

REWIND

Функция REWIND возвращает позицию чтения или записи в начало открытого файла.

Синтаксис

result = REWIND(file)

Части записи. file задаёт открытую переменную типа FILE. Результат имеет тип BOOLEAN.

Допустимые режимы. Как и SEEKFILE, функция используется с режимами INPUT и OUTPUT.

Пример вызова REWIND

' Возврат в начало после чтения первой строки
DIM f AS FILE

OPEN "notes.txt" FOR INPUT AS f
PRINT READLINE(f)
PRINT REWIND(f)
PRINT FILEPOS(f)
PRINT READLINE(f)
CLOSE f

Позиция, режим и конец файла

  • READTOEND, READTEXT, READLINE, READLINES, LINENUMBER и SKIPLINE предназначены для файла, открытого через FOR INPUT.
  • WRITE, WRITELINE, NEWLINE и FLUSH используются с файлами, открытыми через FOR OUTPUT или FOR APPEND.
  • FILEPOS и FILELENGTH помогают контролировать позицию независимо от того, читаете вы файл или записываете его.
  • Если нужно заново читать файл с начала, обычно удобно вызвать REWIND, а не вычислять начальную позицию вручную.

Диагностика

  • Обращение к закрытому файлу даёт диагностику времени выполнения MB3007.
  • Попытка вызвать функцию чтения или записи в неподходящем режиме открытия также даёт MB3007.
  • Недопустимая позиция для SEEKFILE или попытка позиционирования в режиме APPEND завершается диагностикой времени выполнения MB3007.

Ручная проверка

  • ISOPEN: состояние файла
  • FILEPATH: путь открытого файла
  • FILEMODE: режим открытия
  • FILEPOS: текущая позиция
  • FILELENGTH: длина файла
  • EOF: конец файла
  • READTOEND: остаток файла
  • READTEXT: фрагмент текста
  • READLINE: одна строка
  • READLINES: несколько строк
  • LINENUMBER: номер строки
  • SKIPLINE: пропуск строки
  • WRITE: запись без перевода строки
  • WRITELINE: запись строки
  • NEWLINE: пустая строка
  • FLUSH: сброс буфера
  • SEEKFILE: переход по позиции
  • REWIND: возврат в начало
