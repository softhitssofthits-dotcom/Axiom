Оператор CONST

CONST — оператор языка Axiom, который вводит в программу именованную константу. Константа получает значение в момент объявления и дальше используется вместо повторяющегося числового, строкового или логического значения, которое не должно меняться во время работы программы.

Назначение

Константа удобна там, где значение имеет постоянный смысл: максимальный счёт, имя приложения, число строк, код режима или другое заранее известное значение. Вместо того чтобы повторять одно и то же число или строку в разных местах программы, можно дать этому значению имя.

Такое имя делает программу легче читать и менять: значение задаётся один раз, а дальше используется как обычное выражение.

Синтаксис

CONST <имя> AS <тип> = <выражение>
CONST <имя1> AS <тип> = <выражение1>, <имя2> AS <тип> = <выражение2>

Параметры и части синтаксиса

  • <имя> — имя объявляемой константы.
  • AS <тип> — тип константы: например INTEGER, LONG, DOUBLE, DECIMAL, STRING или BOOLEAN.
  • = <выражение> — значение константы. Оно обязательно задаётся прямо в объявлении.

Область видимости

При проверке программы Axiom добавляет имя константы в текущую область видимости и помечает его как неизменяемое. После этого имя можно использовать в выражениях, в выводе, в вычислениях и в тех местах, где язык требует константное целочисленное значение.

CONST MAX_SCORE AS INTEGER = 100
CONST APP_NAME AS STRING = "Axiom"

PRINT APP_NAME
PRINT MAX_SCORE + 1

Попытка присвоить новое значение уже объявленной константе является ошибкой: CONST не создаёт переменную, которую можно менять позднее.

Несколько констант

Один оператор CONST может объявить несколько констант, если каждая часть имеет своё имя, тип и начальное значение.

CONST MIN_ROW AS INTEGER = 1, MAX_ROW AS INTEGER = 10
CONST TITLE AS STRING = "Report", ENABLED AS BOOLEAN = TRUE

Такая форма полезна для коротких групп связанных значений. Если объявления становятся длинными, их обычно удобнее разделить на несколько строк.

Константы в размерах

Целочисленные константы могут участвовать в местах, где Axiom требует значение времени связывания. Например, ими можно задавать границы фиксированных массивных полей внутри TYPE.

CONST MIN_SCORE AS INTEGER = 1
CONST MAX_SCORE AS INTEGER = MIN_SCORE + 2

TYPE Player
    Scores(MIN_SCORE TO MAX_SCORE) AS INTEGER
END TYPE

В таких выражениях Axiom вычисляет константное целое значение при проверке программы.

Предопределённые константы

В Axiom есть встроенные именованные константы. Их не нужно объявлять через CONST.

  • PI — значение числа пи типа DOUBLE.
  • ROW — целочисленное значение 1.
  • COLUMN — целочисленное значение 2.
DIM board(10 TO 12, 20 TO 21) AS INTEGER

PRINT LBOUND(board, ROW)
PRINT UBOUND(board, COLUMN)
PRINT PI > 3

ROW и COLUMN служат читаемыми именами для первого и второго измерения массива. Числовые формы 1 и 2 остаются допустимыми там же.

Имена и поддержанные формы

  • Имя константы регистронезависимо: Limit, LIMIT и limit обозначают одно и то же имя.
  • Предопределённые имена PI, ROW и COLUMN нельзя переобъявить через DIM, CONST, SUB или FUNCTION.
  • Форма STRING * N для CONST сейчас не поддерживается. Фиксированные строки поддержаны для DIM и для полей TYPE.
  • Если нужна изменяемая величина, используйте DIM, а не CONST.

Форма задаёт тип явно через AS; суффиксы типов и операторы DEF... не используются.

Диагностика

  • MB2010 — попытка присвоить значение константе.
  • MB2002 — повторное объявление имени, включая попытку переобъявить PI, ROW или COLUMN.
  • MB2003 — значение объявления несовместимо с указанным типом.
  • MB2018 — литерал или константное значение не помещается в целевой тип.
  • MB2026 — фиксированная строка STRING * N использована в месте, где она не поддержана, например в CONST.

Пример именованных постоянных значений

В примере имя приложения и числовой предел вынесены в константы, а затем используются в выражениях.

CONST APP_NAME AS STRING = "Axiom"
CONST MAX_SCORE AS INTEGER = 100

DIM score AS INTEGER = 87

PRINT APP_NAME
PRINT score
PRINT score <= MAX_SCORE

Результат:

Axiom
87
TRUE
