Оператор CONST

CONST — оператор языка Axiom, который объявляет именованное значение с запретом прямого присваивания. Константа используется в выражениях вместо повторяющегося литерала.

Назначение и контекст

Константа подходит для предела, размера, постоянной настройки или подписи. Она объявляется в текущей области видимости. Прямое присваивание нового значения после объявления запрещено.

Синтаксис

CONST <имя> AS <тип> = <выражение>

Части объявления

У каждой константы указываются имя, явный тип после AS и обязательное начальное выражение после =. Один оператор CONST объявляет одну константу. Для нескольких констант запишите отдельные операторы на отдельных строках.

Использование значений

У текущей проверки есть ограничение: константу можно передать параметру BYREF, после чего подпрограмма может изменить её через параметр. Проверка прямого присваивания константе при этом сохраняется. Подробный договор передачи приведён в статье «Вызовы и аргументы».

Имя константы читается как выражение своего типа. Инициализатор вычисляется при выполнении объявления и может обращаться к переменным или вызывать функции. Неизменяемость означает запрет последующего прямого присваивания, а не обязательное вычисление каждого CONST во время компиляции. Если компилятор может вычислить целочисленный инициализатор заранее, такая константа может использоваться в местах, где требуется значение времени проверки программы, например для границ фиксированного массивного поля TYPE.

Форма STRING * N в объявлении константы не поддержана. Правила имён, регистра и повторного объявления совпадают с общими правилами имён.

Предопределённые константы

ИмяЗначениеТип
PIЧисло πDOUBLE
ROW1, первое измерение массиваINTEGER
COLUMN2, второе измерение массиваINTEGER

Эти имена доступны без объявления. Переобъявление через DIM, CONST, SUB или FUNCTION запрещено. Числовые номера измерений можно использовать вместо ROW и COLUMN.

Диагностика

  • MB2010 — попытка присвоить значение константе.
  • MB2002 — повторное объявление имени, включая попытку переобъявить PI, ROW или COLUMN.
  • MB2003 — значение объявления несовместимо с указанным типом.
  • MB2018 — литерал или константное значение не помещается в целевой тип.
  • MB2026 — фиксированная строка STRING * N использована в месте, где она не поддержана, например в CONST.

Пример

Одна константа задаёт предел для проверки:

CONST LIMIT AS INTEGER = 10
DIM count AS INTEGER = 7
PRINT count <= LIMIT

Результат:

TRUE

Запускаемые примеры

Откройте нужный файл в IDE и запустите его. Примеры с ошибкой предназначены для проверки сообщения компилятора или выполнения.

  • CONST: базовое объявление константы
  • CONST: предопределённые PI, ROW, COLUMN
  • Ошибка: фиксированная строка в CONST

Пример вычисляемого начального значения

DIM source AS INTEGER = 5
CONST SNAPSHOT AS INTEGER = source + 1
source = 99
PRINT SNAPSHOT

Ожидаемый вывод:

6
