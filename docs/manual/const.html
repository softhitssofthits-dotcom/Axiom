Оператор CONST

CONST объявляет константу, сохраняя результат выражения под именем, защищённым от присваивания. Константой можно обозначить предельное количество, коэффициент расчёта или строковый заголовок и обращаться к ней по имени в выражениях.

Объявление константы

CONST <имя> AS <тип> = <выражение>

После CONST указываются <имя> константы, её тип после AS и начальное выражение после знака равенства. Тип и выражение обязательны, а результат выражения должен быть совместим с указанным типом. Каждая инструкция объявляет одну константу; для нескольких констант объявления записываются отдельными строками.

CONST допустим на верхнем уровне файла, в подпрограмме и внутри блока. Имя доступно в соответствующей области видимости и может участвовать в выражениях наравне с именами переменных.

CONST LIMIT AS INTEGER = 10
DIM count AS INTEGER = 7
PRINT count <= LIMIT

Результат:

TRUE

Вычисление начального значения

Когда выполнение достигает CONST, программа вычисляет начальное выражение, в котором допустимы обращения к переменным и вызовы функций. Константа сохраняет полученное значение, даже если затем изменятся данные, использованные при вычислении:

DIM source AS INTEGER = 5
CONST SNAPSHOT AS INTEGER = source + 1
source = 99
PRINT SNAPSHOT

Результат:

6

Повторное выполнение CONST заново вычисляет начальное выражение. Поэтому в теле цикла константа получает значение при каждом выполнении её объявления.

В некоторых объявлениях значение требуется ещё при компиляции, например для границ фиксированного массивного поля TYPE. В таких местах допустимы целочисленные константные выражения, которые компилятор может вычислить заранее. Пригодность константы для такого объявления определяется её начальным выражением.

Защита от изменения

Компилятор запрещает прямое присваивание константе и передачу константы параметру BYREF, поскольку такой параметр допускает изменение переданного значения. В обоих случаях выдаётся MB2010. Эти ограничения действуют и для предопределённых констант.

Для данных, которые должна изменять подпрограмма, объявляется обычная переменная через DIM. Правила передачи аргументов приведены в статье «Вызовы и аргументы». Форма STRING * N в CONST не поддерживается.

Следующие имена доступны без объявления:

ROW и COLUMN можно указывать в аргументах, которые задают номер измерения массива, вместо чисел 1 и 2 соответственно. Имена PI, ROW и COLUMN нельзя переобъявлять через DIM или CONST или давать процедурам SUB и функциям FUNCTION верхнего уровня.

Константа модуля

PUBLIC CONST <имя> AS <тип> = <выражение>
PRIVATE CONST <имя> AS <тип> = <выражение>

PUBLIC и PRIVATE допустимы только перед объявлением верхнего уровня файла. С PUBLIC константа доступна файлам, которые явно импортируют этот модуль; с PRIVATE или без модификатора доступ ограничен текущим файлом. Импортируемая константа также защищена от присваивания и передачи BYREF. Правила доступности и импорта приведены в статьях PUBLIC и PRIVATE и IMPORT.

Диагностика

  • MB2010: присваивание константе или передача константы параметру BYREF.
  • MB2002: повторное объявление имени, включая PI, ROW или COLUMN.
  • MB2016: объявление перекрывает доступную внешнюю переменную или константу.
  • MB2003: начальное значение несовместимо с типом константы.
  • MB2018: числовая константа не помещается в указанный тип.
  • MB2026: в CONST использована форма STRING * N.
