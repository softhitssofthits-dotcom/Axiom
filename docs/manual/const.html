Оператор CONST

CONST — оператор языка Axiom, который объявляет константу: именованное значение, защищённое от прямого присваивания после объявления.

Назначение и контекст

Константы используются в выражениях как именованные значения. Оператор CONST разрешён на верхнем уровне программы, внутри подпрограммы или блока; объявленное имя относится к текущей области видимости.

Синтаксис

CONST <имя> AS <тип> = <выражение>

Части объявления

  • <имя> — новое имя константы.
  • <тип> — явно указанный тип значения.
  • <выражение> — выражение, которое вычисляет начальное значение совместимого типа.

Тип после AS и начальное выражение после знака = обязательны. Один оператор CONST объявляет одну константу. Несколько констант объявляются отдельными строками.

Вычисление и использование

После объявления имя константы можно использовать в выражениях так же, как имя переменной. Прямая запись нового значения запрещена.

Начальное выражение вычисляется при выполнении объявления. Оно может читать переменную или вызывать функцию. Поэтому объявление CONST не означает, что значение обязательно вычислено компилятором до запуска программы.

Некоторые целочисленные выражения компилятор может вычислить заранее. Полученная константа подходит для места, где значение должно быть известно до выполнения, например для границ фиксированного массивного поля TYPE.

Правила имён и повторного объявления совпадают с общими правилами. Форма STRING * N для константы не поддерживается.

Предопределённые константы

Следующие имена доступны без отдельного CONST:

ИмяЗначение и назначениеТип
PIЧисло πDOUBLE
ROW1 — первое измерение массиваINTEGER
COLUMN2 — второе измерение массиваINTEGER

Эти имена нельзя переобъявить через DIM, CONST, SUB или FUNCTION. ROW и COLUMN используются там, где требуется номер измерения; вместо них можно указать соответствующее число.

Ограничение передачи через BYREF

В текущей реализации константу можно передать параметру BYREF. Подпрограмма способна изменить её значение через этот параметр, хотя прямое присваивание константе по-прежнему отвергается. Передача через BYREF не гарантирует неизменность значения. Подробнее о передаче по ссылке — в статье «Вызовы и аргументы».

Диагностика

  • MB2010 — попытка присвоить константе новое значение.
  • MB2002 — повторное объявление имени, в том числе PI, ROW или COLUMN.
  • MB2003 — начальное значение несовместимо с указанным типом.
  • MB2018 — числовое значение не помещается в целевой тип.
  • MB2026 — в CONST использована неподдерживаемая форма STRING * N.

Пример

Константа задаёт предел для проверки количества:

CONST LIMIT AS INTEGER = 10
DIM count AS INTEGER = 7
PRINT count <= LIMIT

Программа выводит:

TRUE

Пример вычисляемого начального значения

Константа сохраняет результат выражения на момент выполнения своего объявления. Позднее изменение исходной переменной не пересчитывает константу:

DIM source AS INTEGER = 5
CONST SNAPSHOT AS INTEGER = source + 1
source = 99
PRINT SNAPSHOT

Программа выводит:

6

Запускаемые примеры

Примеры можно открыть в IDE и выполнить. Файлы с ожидаемой ошибкой показывают соответствующее сообщение и причину отказа.

  • CONST: базовое объявление константы

Доступность в модуле

Перед объявлением верхнего уровня можно указать PUBLIC или PRIVATE. Без модификатора имя закрыто внутри файла. Модификатор PUBLIC открывает имя для файлов, которые явно импортируют текущий модуль. Он не меняет остальные правила объявления.

PUBLIC CONST name AS dataType = value
PRIVATE CONST name AS dataType = value

Вложенные объявления не получают модификатора. Подробнее: PUBLIC и PRIVATE и IMPORT.
