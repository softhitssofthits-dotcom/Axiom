Оператор PALETTE

PALETTE — оператор языка Axiom, который задаёт видимый цвет для индекса палитры графического экрана SCREEN. Пиксели сохраняют индексы, а палитра определяет их отображение.

Когда использовать PALETTE

Переназначение палитры меняет вид уже нарисованного изображения без повторного рисования его пикселей.

Так можно переключить цветовую схему, выделить объект или временно изменить цвета, а затем восстановить стандартную палитру.

Контекст выполнения

Оператор требует графического режима SCREEN 1..10.

Для полноцветного холста CANVAS используется RGB. Его цвета задаются непосредственно и не переназначаются оператором PALETTE.

Синтаксис

PALETTE
PALETTE <индекс>, <цвет>
PALETTE USING <массив>

Формы ниже отдельно сбрасывают палитру, меняют один индекс или читают набор цветов из массива.

Параметры

ЧастьОписание
<индекс>Передайте индекс палитры, который оператор PALETTE должен переназначить. Значение приводится к целому и нормализуется по правилу ABS(value) MOD 256.
<цвет>Передайте новый видимый цвет для указанного индекса. Значение приводится к целому и нормализуется по тому же правилу ABS(value) MOD 256.
<массив>Передайте одномерный числовой массив. Видимые элементы массива задают цвета для индексов палитры, начиная с индекса 0.

Что делает оператор PALETTE

Вызов без аргументов восстанавливает стандартную палитру Axiom для текущего экрана.

Форма с двумя аргументами задаёт новый видимый цвет для одного индекса.

Форма USING последовательно задаёт цвета из одномерного числового массива.

Правила работы

Если графический экран не открыт, выполнение завершается диагностикой MB3010.

Сохранённые индексы не изменяются. Например, после рисования цветом 1 и вызова PALETTE 1, 196 изображение имеет вид цвета 196, но POINT(x, y) возвращает 1.

Первый видимый элемент массива задаёт индекс 0, второй — индекс 1. Нижняя граница массива не влияет на нумерацию индексов палитры.

После приведения к целому цвета и индексы нормализуются по правилу ABS(value) MOD 256; это же правило применяется к элементам массива.

Из массива читаются не более 256 видимых элементов. Если элементов меньше, цвета остальных индексов сохраняются.

Смена палитры сохраняет графическую позицию, настройки VIEW, WINDOW и VIEW PRINT, текстовый курсор и состояние мыши.

Типы значений массива

Индекс и цвет отдельного переназначения приводятся к INTEGER. PALETTE USING принимает выделенный одномерный массив с элементами INTEGER, LONG, DOUBLE или DECIMAL. Вещественные элементы сначала усекаются к целому; результат должен помещаться в INTEGER. Не выделенный массив сообщает MB3005, переполнение при приведении сообщает MB3008. Элементы сверх первых 256 не используются.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3005: массив для PALETTE USING объявлен, но ещё не выделен.
  • MB2003: форма PALETTE USING получила не одномерный числовой массив.

Пример

SCREEN 1
LINE (20, 40)-(180, 40), 1
PRINT POINT(20, 40)

PALETTE 1, 196
PRINT POINT(20, 40)

PALETTE
PRINT POINT(20, 40)

Каждый вызов функции POINT печатает 1: меняется только отображение пикселя.

Пример PALETTE USING

SCREEN 1
DIM colors(0 TO 2) AS INTEGER
colors(0) = 16
colors(1) = 196
colors(2) = 46

LINE (20, 40)-(180, 40), 1
PRINT POINT(20, 40)

PALETTE USING colors
PRINT POINT(20, 40)

Массив задаёт цвета индексов 0, 1 и 2. Нарисованная линия продолжает хранить индекс 1.
