Оператор

PALETTE

PALETTE меняет соответствие между номером цвета и видимым цветом на графическом экране. Как в классическом BASIC, графические операторы продолжают хранить в пикселях цветовые индексы, а палитра определяет, каким цветом эти индексы показываются.

Синтаксис

PALETTE
PALETTE <index>, <color>
PALETTE USING <array>

Части синтаксиса

ЧастьОписание
PALETTE без аргументовСбрасывает палитру текущего графического экрана к стандартному отображению цветов Axiom.
<index>Индекс палитры, который нужно переопределить. Значение вычисляется как целое и нормализуется по правилу ABS(value) MOD 256.
<color>Новый цвет для указанного индекса. Значение вычисляется как целое и нормализуется по тому же правилу ABS(value) MOD 256.
<array>Одномерный числовой массив. Его видимые элементы задают цвета для индексов палитры, начиная с индекса 0.

Замечания

PALETTE работает только в графических режимах SCREEN 1 ... SCREEN 10. Без активного графического режима оператор сообщает ошибку времени выполнения MB3010.

Оператор не перерисовывает пиксели и не меняет их сохранённые индексы. Если программа уже нарисовала линию цветом 1, затем выполнила PALETTE 1, 196, эта линия начнёт отображаться как цвет 196, но POINT(x, y) по-прежнему вернёт индекс 1.

Сброс PALETTE возвращает стандартное отображение всех индексов. Это удобно для демонстраций и для программ, которые временно меняют цветовую схему экрана.

Форма PALETTE USING изменяет сразу несколько индексов. Первый видимый элемент массива задаёт цвет для индекса 0, второй — для индекса 1, и так далее. Нижняя граница массива не становится индексом палитры: она только определяет порядок обхода видимых элементов.

Если в массиве больше 256 видимых элементов, Axiom применяет только первые 256. Если элементов меньше, остальные индексы палитры остаются как были. Неинициализированный динамический массив в PALETTE USING даёт ошибку времени выполнения MB3005.

Пример

SCREEN 1
LINE (20, 40)-(180, 40), 1
PRINT POINT(20, 40)

PALETTE 1, 196
PRINT POINT(20, 40)

PALETTE
PRINT POINT(20, 40)

Обе строки PRINT выводят индекс 1, потому что цвет пикселя хранится как индекс палитры. Вид линии меняется после PALETTE 1, 196 и возвращается к стандартному цвету после PALETTE.

Пример PALETTE USING

SCREEN 1
DIM colors(0 TO 2) AS INTEGER
colors(0) = 16
colors(1) = 196
colors(2) = 46

LINE (20, 40)-(180, 40), 1
PRINT POINT(20, 40)

PALETTE USING colors
PRINT POINT(20, 40)

Массив задаёт новые видимые цвета для индексов 0, 1 и 2. Линия по-прежнему хранит индекс 1, но после PALETTE USING colors этот индекс показывается цветом 196.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3005: массив для PALETTE USING объявлен, но ещё не выделен.
  • MB3007: форма PALETTE USING получила не одномерный числовой массив.
