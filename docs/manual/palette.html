Оператор PALETTE

PALETTE — оператор языка Axiom, который меняет соответствие между индексом палитры и видимым цветом на графическом экране SCREEN. Оператор PALETTE нужен для палитровой графики режима SCREEN, где пиксели хранят цветовые индексы, а палитра определяет, каким цветом эти индексы показываются пользователю.

Когда использовать PALETTE

Оператор PALETTE нужен тогда, когда программа хочет изменить вид уже нарисованных индексных пикселей без их перерисовки.

Оператор PALETTE позволяет временно сменить цветовую схему экрана, выделить важный объект, показать эффект тревоги или вернуть стандартную палитру после временной настройки цветов.

Где работает оператор PALETTE

Оператор PALETTE работает только в графических режимах SCREEN 1 ... SCREEN 10.

Оператор PALETTE не относится к современному полноцветному слою CANVAS. В слое CANVAS программа задаёт цвет напрямую через функцию RGB, а не через палитровое переназначение индексов.

Синтаксис

PALETTE
PALETTE index, color
PALETTE USING array

На этой странице показаны три разные формы одного оператора PALETTE. Это не одна общая запись, где нужно указывать все части сразу.

Параметры и части синтаксиса

ЧастьОписание
indexИндекс палитры, который оператор PALETTE должен переназначить. Значение приводится к целому и нормализуется по правилу ABS(value) MOD 256.
colorНовый видимый цвет для указанного индекса. Значение приводится к целому и нормализуется по тому же правилу ABS(value) MOD 256.
arrayОдномерный числовой массив. Видимые элементы массива задают цвета для индексов палитры, начиная с индекса 0.

Что делает оператор PALETTE

Оператор PALETTE без аргументов сбрасывает палитру текущего графического экрана к стандартному отображению цветов Axiom.

Оператор PALETTE index, color переназначает один индекс палитры на другой видимый цвет.

Оператор PALETTE USING array переназначает несколько индексов палитры по значениям одномерного числового массива.

Правила работы

Оператор PALETTE работает только в графических режимах SCREEN 1 ... SCREEN 10. Если графический режим не активен, оператор PALETTE сообщает ошибку времени выполнения MB3010.

Оператор PALETTE не перерисовывает пиксели и не меняет сохранённые индексы пикселей. Если программа нарисовала линию цветом 1, а затем выполнила PALETTE 1, 196, линия начнёт отображаться как цвет 196, но функция POINT(x, y) по-прежнему вернёт индекс 1.

Оператор PALETTE USING читает видимые элементы массива по порядку. Первый видимый элемент массива задаёт цвет для индекса 0, второй элемент задаёт цвет для индекса 1, и так далее. Нижняя граница массива не становится номером индекса палитры.

Элементы массива в операторе PALETTE USING приводятся к целому значению, а затем нормализуются по тому же правилу ABS(value) MOD 256, что и обычные аргументы index и color.

Если массив для оператора PALETTE USING содержит больше 256 видимых элементов, оператор PALETTE использует только первые 256 элементов. Если элементов меньше, остальные индексы палитры сохраняют прежние значения.

Оператор PALETTE не меняет текущую графическую позицию, область VIEW, систему координат WINDOW, область VIEW PRINT, текстовый курсор и состояние мышиного ввода.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3005: массив для PALETTE USING объявлен, но ещё не выделен.
  • MB2003: форма PALETTE USING получила не одномерный числовой массив.

Пример

SCREEN 1
LINE (20, 40)-(180, 40), 1
PRINT POINT(20, 40)

PALETTE 1, 196
PRINT POINT(20, 40)

PALETTE
PRINT POINT(20, 40)

В этом примере функция POINT каждый раз возвращает индекс 1, потому что оператор PALETTE меняет только видимый цвет, а не сохранённый индекс пикселя.

Пример PALETTE USING

SCREEN 1
DIM colors(0 TO 2) AS INTEGER
colors(0) = 16
colors(1) = 196
colors(2) = 46

LINE (20, 40)-(180, 40), 1
PRINT POINT(20, 40)

PALETTE USING colors
PRINT POINT(20, 40)

В этом примере оператор PALETTE USING берёт новые цвета для индексов 0, 1 и 2 из массива colors. При этом линия по-прежнему хранит индекс 1.
