Выражения, сравнения и ветвление

Выражения отвечают за вычисления, а ветвление — за выбор дальнейшего пути выполнения. В Axiom эти две темы тесно связаны: сначала программа получает значение условия, а затем на его основе выбирает нужную ветвь. Эта обзорная страница помогает увидеть раздел как единое целое, прежде чем переходить к точным правилам отдельных операторов.

С чего начинается раздел

Обычно работа с этой частью языка идёт от простого к сложному: сначала арифметика и логика, затем условия, а потом более разветвлённый выбор между несколькими вариантами. Поэтому обзор полезен не только новичку, но и читателю, который хочет быстро восстановить общую картину.

  • выражения вычисляют числа, строки, логические значения и результаты сравнений;
  • IF выбирает между несколькими ветвями по условию;
  • SELECT CASE удобен там, где нужно сравнить одно выражение сразу с несколькими вариантами.

Основные статьи раздела

Арифметика и логика

Операторы +, -, *, /, сравнения, логические операции и приоритет.

Оператор IF

Блочное условие, ветви ELSEIF и ELSE, область видимости внутри ветвей.

Оператор SELECT CASE

Многовариантное ветвление, диапазоны, списки значений и CASE ELSE.

Короткий ориентир

DIM score AS INTEGER = 72

IF score >= 90 THEN
    PRINT "Отлично"
ELSEIF score >= 70 THEN
    PRINT "Хорошо"
ELSE
    PRINT "Нужно повторить тему"
END IF

Здесь сначала вычисляется выражение сравнения, а затем по его результату выбирается нужная ветвь. Именно так выражения и ветвление работают вместе почти во всех практических сценариях языка.

Если условие опирается на несколько операций сразу, сначала полезно открыть страницу по арифметике и логике. Если же вычисление уже понятно, но нужно оформить выбор между ветвями, переходите к IF или SELECT CASE.
