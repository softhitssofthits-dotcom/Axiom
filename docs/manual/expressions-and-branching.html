Выражения, сравнения и ветвление

Раздел выражений и ветвления описывает, как значения выражений управляют условными операторами в Axiom. Выражение вычисляет число, строку, логическое значение или результат сравнения; условный оператор смотрит на это значение и выбирает, какой фрагмент программы выполнять дальше.

Что вычисляет выражение

Выражение можно использовать справа от присваивания, в аргументе вызова, в выводе через PRINT и в условии управляющей конструкции. Для ветвления важен итоговый логический результат: если условие истинно, выполняется выбранная ветвь; если ложно, управление переходит к другой ветви или к инструкции после условного блока.

  • арифметические и строковые выражения вычисляют данные для дальнейших действий;
  • операции сравнения дают логический результат, который обычно становится условием;
  • IF ... THEN ... ELSE выбирает одну из ветвей по условию;
  • SELECT CASE удобен, когда один результат нужно сопоставить с несколькими вариантами.

Как условие выбирает ветвь

В простом линейном фрагменте инструкции выполняются одна за другой. Как только появляется условие, порядок выполнения начинает зависеть от данных: программа сначала вычисляет выражение, затем передаёт управление в нужную ветвь. Такой подход позволяет описывать выбор без переходов на метки и без ручного разрыва текста программы.

DIM score AS INTEGER = 74

IF score >= 60 THEN
    PRINT "зачёт"
ELSE
    PRINT "повторить"
END IF

Здесь выражение score >= 60 превращает число в логический ответ. Именно этот ответ определяет, какая строка будет напечатана.

Выбор между IF и SELECT CASE

Для условий в Axiom используется тип BOOLEAN. Если нужно выбрать между двумя путями, обычно достаточно IF. Если вариантов много и они относятся к одному проверяемому значению, текст чаще получается яснее через SELECT CASE.

В классическом BASIC рядом со структурными операторами существовали переходы на метки. В Axiom в этом разделе описаны реализованные структурные формы: IF, SELECT CASE, циклы и вызовы процедур.
