Оператор DIM

DIM — оператор языка Axiom, который вводит в программу одну или несколько переменных и связывает каждое имя с типом данных. Через оператор DIM объявляют скалярные переменные, массивы с заданными границами, динамические массивы без выделенного диапазона и строки фиксированной длины.

Объявление и тип переменной

Переменная — это именованное место хранения значения, которое может меняться во время выполнения программы. Чтобы Axiom мог проверить типы и обращения к имени, переменная должна быть описана до первого использования.

DIM задаёт имя и тип переменной. Тип можно указать явно после AS или вывести из начального значения. Если после имени стоят скобки, описывается массив, а не скалярная переменная.

Синтаксис

DIM <имя> AS <тип>
DIM <имя> AS <тип> = <выражение>
DIM <имя> = <выражение>
DIM <имя1> AS <тип>, <имя2> AS <тип>
DIM <имя>(<нижняя граница> TO <верхняя граница>) AS <тип>
DIM <имя>(<нижняя1> TO <верхняя1>, <нижняя2> TO <верхняя2>) AS <тип>
DIM <имя>() AS <тип>
DIM <имя>(,) AS <тип>
DIM <имя> AS STRING * <длина>

Параметры и части синтаксиса

  • <имя> — имя объявляемой переменной или массива.
  • AS <тип> — явное указание типа: скалярного, пользовательского TYPE, массивного или фиксированной строки.
  • = <выражение> — начальное значение. В форме без AS это выражение также задаёт выводимый тип переменной.
  • (<нижняя граница> TO <верхняя граница>) — включительный диапазон индексов массива.
  • () — объявление одномерного динамического массива без выделенного диапазона.
  • (,), (,,) и более длинные формы с запятыми — объявление динамического массива указанного ранга.
  • STRING * <длина> — строка фиксированной длины; длина задаётся целочисленной константой.

Создание переменной

При выполнении DIM Axiom создаёт переменную в текущей области видимости и присваивает ей значение по умолчанию для её типа. Числовые переменные получают ноль, логические — FALSE, строки — пустую строку, а записи TYPE получают значения по умолчанию для своих полей.

Без инициализатора переменная типа DATE получает 0001-01-01, типа TIME — 00:00:00, типа DATETIME — 0001-01-01 00:00:00. Повторное выполнение оператора DIM, например внутри цикла, снова задаёт начальное значение. Это правило действует при выполнении скомпилированного байт-кода.

DIM d AS DATE
DIM t AS TIME
DIM dt AS DATETIME
PRINT d   ' 0001-01-01
PRINT t   ' 00:00:00
PRINT dt  ' 0001-01-01 00:00:00

Проверка начальных значений при повторном выполнении DIM

Если в операторе есть инициализатор, значение выражения присваивается сразу после объявления. Если тип указан явно, выражение должно быть совместимо с этим типом. Если тип не указан, Axiom выводит его из инициализатора.

Форма DIM <имя> без AS <тип> и без = <выражение> недопустима: в такой записи язык не получает ни явного типа, ни значения, из которого можно вывести тип.

Объявление нескольких переменных

Один оператор DIM может описывать несколько имён. В текущем Axiom тип после AS применяется к ближайшей группе имён слева, разделённой запятыми.

DIM i AS INTEGER, j AS INTEGER
DIM anotherVar, choice AS BOOLEAN, birthDate AS STRING = "2014-05-01"

Во второй строке anotherVar и choice получают тип BOOLEAN, а birthDate получает тип STRING и начальное значение.

Массивы

Если после имени указаны скобки с диапазоном, DIM объявляет массив и сразу выделяет диапазон его элементов.

DIM numbers(1 TO 3) AS INTEGER
DIM matrix(1 TO 2, 10 TO 11) AS INTEGER

У каждого измерения есть нижняя и верхняя граница. Обращение к элементу должно указывать столько индексов, сколько измерений имеет массив.

Форма без диапазона объявляет динамический массив. Такой массив имеет тип и ранг, но до REDIM не имеет выделенного диапазона элементов.

DIM values() AS INTEGER
DIM matrix(,) AS INTEGER

values() означает одномерный динамический массив. matrix(,) означает двумерный динамический массив; число запятых внутри скобок задаёт ранг.

Фиксированные строки

Для строковых переменных поддержана форма STRING * <длина>. Такая переменная остаётся строковой, но при хранении значение подгоняется к заданной длине.

DIM code AS STRING * 4

code = "AB"
PRINT "[" + code + "]"

code = "Alphabet"
PRINT "[" + code + "]"

Короткая строка дополняется пробелами справа, длинная строка обрезается до указанной длины.

Имена, области видимости и границы

  • DIM объявляет изменяемую переменную. Для неизменяемого именованного значения используйте CONST.
  • Имена в Axiom регистронезависимы: value, Value и VALUE обозначают одно и то же имя.
  • Имя должно начинаться с латинской буквы A–Z, a–z или символа подчёркивания. Далее допускаются только латинские буквы, цифры 0–9 и подчёркивание. Имя не должно совпадать с зарезервированным словом языка. Русская буква, включая смешанное имя aя, вызывает MB0001; строковые значения в кавычках могут содержать русский текст.
  • Динамический массив после DIM обычно нужно выделить через REDIM перед обращением к элементам.
  • Нижняя граница массива -2147483648 запрещена; для такой границы выполнение сообщает ошибку времени выполнения MB3007.

Переменная должна быть явно объявлена через DIM или CONST, а тип определяется из AS либо из инициализатора.

Диагностика

  • MB2001 — имя используется до объявления или вне доступной области видимости.
  • MB2003 — значение инициализатора или присваивания несовместимо с типом переменной.
  • MB3005 — обращение к невыделенному массиву.
  • MB3007 — недопустимый массивный диапазон или запрещённая нижняя граница.

Пример объявления переменных и массива

В этом примере объявляются две скалярные переменные и массив. Затем программа заполняет массив и выводит значения.

DIM title AS STRING = "Оценки"
DIM count = 3
DIM scores(1 TO 3) AS INTEGER

scores(1) = 10
scores(2) = 20
scores(3) = 30

PRINT title
PRINT "счёт=", count
PRINT scores(2)

Результат:

Оценки
счёт= 3
20
