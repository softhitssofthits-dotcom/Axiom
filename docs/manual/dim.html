Оператор DIM

DIM — оператор языка Axiom, который объявляет переменные и определяет их тип. Он также объявляет массивы и места хранения строк фиксированной длины.

Назначение и контекст

Объявление позволяет компилятору проверить обращения к имени и совместимость значений. Оператор DIM можно использовать на верхнем уровне, в подпрограмме или блоке. Имя относится к текущей области видимости.

Синтаксис

DIM <имя> AS <тип>

DIM <имя> AS <тип> = <выражение>

DIM <имя> = <выражение>

DIM <имя1> AS <тип>, <имя2> AS <тип>
DIM <имя>(<нижняя граница> TO <верхняя граница>) AS <тип>

DIM <имя>(<нижняя1> TO <верхняя1>, <нижняя2> TO <верхняя2>) AS <тип>

DIM <имя>() AS <тип>

DIM <имя>(,) AS <тип>

DIM <имя> AS STRING * <длина>

Части объявления

После DIM указывается новое пользовательское имя. Тип — название встроенного типа, ранее объявленного TYPE или допустимая запись функционального типа. Выражение задаёт начальное значение совместимого типа. Часть AS <тип> задаёт тип, а часть = <выражение> — начальное значение. Если явного типа нет, он определяется по выражению. Нельзя одновременно опустить и тип, и выражение.

Скобки после имени обозначают массив. Нижняя и верхняя границы должны быть числовыми выражениями: допустимы INTEGER, LONG, DOUBLE и DECIMAL. Они вычисляются при выполнении объявления; дробная часть DOUBLE и DECIMAL усекается к нулю. После преобразования границы должны помещаться в INTEGER и задают допустимые индексы соответствующего измерения. Формы только с верхней границей без TO нет. Диапазон <нижняя граница> TO <верхняя граница> включает обе границы. Пустые скобки объявляют одномерный динамический массив; запятые без границ задают его ранг. Подробности выделения памяти находятся в главе массивов.

Форма STRING * <длина> задаёт строковое хранение фиксированной длины. Длина задаёт число единиц UTF-16 и должна быть целочисленной константой от 1 до 65535; полный договор приведён в статье строкового типа.

Начальное значение

При выполнении объявления задаётся инициализатор или значение по умолчанию. Если несколько имён объединены одной частью AS и инициализатором, каждый получает указанный тип, а начальное выражение вычисляется отдельно для каждого имени. Для чисел это ноль, для BOOLEAN — FALSE, для обычной строки — пустая строка. Поля записи получают свои значения по умолчанию.

Значения по умолчанию временных типов: DATE — 0001-01-01, TIME — 00:00:00, DATETIME — 0001-01-01 00:00:00. Повторное выполнение DIM, например в цикле, снова задаёт начальное значение.

Несколько переменных

Тип после AS относится к ближайшей группе имён слева. Разные группы могут иметь разные типы:

DIM enabled, visible AS BOOLEAN, title AS STRING = "Отчёт"
PRINT enabled, visible, title

Ожидаемый вывод:

FALSE FALSE Отчёт

В этом объявлении enabled и visible имеют тип BOOLEAN, а title — STRING. Для длинного списка предпочтительны отдельные объявления.

Ограничения

Имя должно соответствовать правилам имён и не перекрывать доступное имя внешней области. Динамический массив после объявления ещё не имеет выделенных элементов. Нижняя граница массива -2147483648 запрещена.

Диагностика

  • MB2017 — объявление не содержит ни типа, ни инициализатора.
  • MB2002 — имя повторно объявлено в той же области.
  • MB2016 — имя перекрывает доступное имя внешней области.
  • MB2026 — недопустимый размер фиксированной строки.
  • MB2001 — имя используется до объявления или вне доступной области видимости.
  • MB2003 — значение инициализатора или присваивания несовместимо с типом переменной.
  • MB3005 — обращение к невыделенному массиву.
  • MB3007 — недопустимый массивный диапазон или запрещённая нижняя граница.

Пример

Объявление задаёт начальное значение, а последующее присваивание изменяет его:

DIM count AS INTEGER = 3
count = count + 2
PRINT count

Результат:

5
