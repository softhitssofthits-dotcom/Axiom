Оператор DIM

DIM — оператор языка Axiom, который объявляет переменную, задаёт её тип и начальное значение. Тем же оператором объявляют массивы и строки фиксированной длины.

Назначение и контекст

Объявление сообщает компилятору, какие данные будут храниться под указанным именем. После объявления переменную можно читать в выражениях и изменять присваиванием. Оператор DIM разрешён на верхнем уровне программы, внутри подпрограммы и внутри блока, например IF или FOR. Место объявления определяет, где доступно имя; см. области видимости.

Оператор DIM нужен для обычных переменных. Параметр подпрограммы, счётчик FOR и переменная после CATCH объявляются соответствующей конструкцией и не требуют отдельного DIM.

Синтаксис

Одна переменная

DIM <имя> AS <тип>
DIM <имя> AS <тип> = <выражение>
DIM <имя> = <выражение>

Несколько переменных

DIM <имя1>, <имя2> AS <тип>
DIM <имя1> AS <тип1>, <имя2> AS <тип2>

Массив с заданными границами

DIM <имя>(<нижняя граница> TO <верхняя граница>) AS <тип элемента>
DIM <имя>(<нижняя1> TO <верхняя1>, <нижняя2> TO <верхняя2>) AS <тип элемента>

Динамический массив

DIM <имя>() AS <тип элемента>
DIM <имя>(,) AS <тип элемента>

Строка фиксированной длины

DIM <имя> AS STRING * <длина>

Части объявления

  • <имя> — новое пользовательское имя. Оно должно соответствовать правилам записи имён.
  • <тип> — тип хранимого значения: встроенный тип, ранее объявленный пользовательский TYPE или функциональный тип.
  • <выражение> — выражение, задающее начальное значение. Его тип должен быть совместим с типом переменной.
  • <тип элемента> — тип каждого элемента массива.
  • <нижняя граница> и <верхняя граница> — первый и последний допустимые индексы измерения. Обе границы включаются в диапазон.
  • <длина> — число кодовых единиц UTF-16 в фиксированной строке. Требуется целочисленная константа от 1 до 65535.

Часть AS <тип> задаёт тип явно. Если она опущена, компилятор определяет тип по начальному выражению. Если выражения нет, явный тип обязателен.

Начальное значение

При выполнении DIM переменная получает указанное начальное значение. Если выражение опущено, используется значение по умолчанию:

ТипНачальное значение
INTEGER, LONG, DOUBLE, DECIMAL0
BOOLEANFALSE
Обычная STRINGПустая строка
DATE0001-01-01
TIME00:00:00
DATETIME0001-01-01 00:00:00

Поля пользовательской записи получают свои значения по умолчанию. Правила фиксированных строк, файлов и графических ресурсов объясняются на страницах соответствующих типов. Если DIM выполняется повторно, например на следующем проходе цикла, начальное значение задаётся снова.

Групповые объявления

Общая часть AS задаёт тип ближайшей группе имён слева:

DIM enabled, visible AS BOOLEAN, title AS STRING = "Отчёт"
PRINT enabled, visible, title

Программа выводит:

FALSE FALSE Отчёт

Здесь enabled и visible имеют тип BOOLEAN, а title — STRING. Если у группы имён есть общее начальное выражение, оно вычисляется отдельно для каждого имени. Общая запись не означает, что выражение будет вычислено только один раз.

Массивы и фиксированные строки

В объявлении массива скобки относятся к имени. Для каждого измерения нужно указать обе границы и слово TO; форма только с верхней границей не поддерживается. Число диапазонов задаёт количество измерений.

Границы вычисляются при выполнении объявления. Они могут иметь тип INTEGER, LONG, DOUBLE или DECIMAL. Дробная часть DOUBLE и DECIMAL отбрасывается к нулю; полученное значение должно помещаться в INTEGER. Нижняя граница −2147483648 запрещена. Другие ограничения диапазонов и выделения элементов описаны в главе массивов.

Пустые скобки () объявляют одномерный динамический массив без выделенных элементов. Запись (,) объявляет двухмерный массив; каждое дополнительное измерение обозначается ещё одной запятой. Для выделения элементов используется REDIM.

Запись STRING * <длина> объявляет строку фиксированной длины. Она отличается от обычной STRING правилами дополнения и обрезки; см. строковый тип.

Диагностика

  • MB2017 — в DIM не указаны ни тип, ни начальное выражение.
  • MB2002 — имя уже объявлено в той же области.
  • MB2016 — новое имя совпадает с доступным именем внешней области.
  • MB2001 — выражение обращается к неизвестному или недоступному имени.
  • MB2003 — начальное значение несовместимо с указанным типом.
  • MB2026 — длина фиксированной строки недопустима.
  • MB3007 — при выполнении получен недопустимый диапазон массива, в том числе запрещённая нижняя граница.
  • MB3005 — программа обращается к динамическому массиву до выделения элементов. Само объявление без элементов допустимо.

Пример

Переменная получает начальное значение 3, затем присваивание заменяет его результатом сложения:

DIM count AS INTEGER = 3
count = count + 2
PRINT count

Программа выводит:

5

Доступность в модуле

Перед объявлением верхнего уровня можно указать PUBLIC или PRIVATE. Без модификатора имя закрыто внутри файла. Модификатор PUBLIC открывает имя для файлов, которые явно импортируют текущий модуль. Он не меняет остальные правила объявления.

PUBLIC DIM name AS dataType
PRIVATE DIM name AS dataType

Вложенные объявления не получают модификатора. Подробнее: PUBLIC и PRIVATE и IMPORT.
