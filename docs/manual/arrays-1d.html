Одномерные массивы

Одномерный массив — тип данных Axiom ранга 1, элементы которого выбираются одним индексом. Он подходит для оценок, измерений, имён и других последовательностей.

Назначение и контекст

У одномерного массива один диапазон индексов. Он может начинаться с отрицательного значения или нуля; начальный индекс 1 используется только там, где он указан в объявлении или выбран функцией, создающей результат.

Работа с массивом разрешена на верхнем уровне, в процедуре и в функции; SCREEN не требуется.

Синтаксис

DIM <имя массива>(<нижняя граница> TO <верхняя граница>) AS <тип элемента>
DIM <имя массива>() AS <тип элемента>
<имя массива>(<индекс>) = <значение>

Части записи

Имя массива обозначает массивную переменную. Тип элемента определяет допустимые значения всех элементов. Индекс является числовым выражением, выбирающим один элемент. Значение присваивания должно быть совместимо с типом элемента.

Границы задаются числовыми выражениями. Допустимы INTEGER, LONG, DOUBLE и DECIMAL, но значение должно быть целым и помещаться в INTEGER. Ненулевая дробная часть вызывает MB3007; усечения нет. Нижняя граница -2147483648 запрещена, потому что поисковые функции используют нижнюю границу минус 1 как признак отсутствия. Верхняя граница включается в массив. Обратный диапазон допустим только как каноническая пустая форма 1 TO 0 при DIM или REDIM.

Действие и ограничения

DIM с границами создаёт элементы со значениями по умолчанию. DIM с пустыми измерениями сохраняет тип и ранг без выделения элементов. Полное индексирование возвращает один элемент; частичное индексирование создаёт представление оставшихся измерений.

Диагностика

MB2003 означает несовместимый тип элемента или индекса, MB2004 — неверное число индексов. MB3002 возникает, когда индекс или диапазон при индексировании выходит за границы. MB3005 возникает при доступе к невыделенному массиву либо при недопустимой паре границ. MB3007 сообщает о запрещённой нижней границе -2147483648; выход числового значения за диапазон INTEGER даёт MB3008.

Пример

DIM scores(1 TO 3) AS INTEGER
scores(1) = 10
scores(2) = 20
scores(3) = 30
FOR i = LBOUND(scores) TO UBOUND(scores)
    PRINT scores(i)
NEXT

Ожидаемый вывод:

10
20
30

Схема индексов

Подписанные координаты выбирают элемент внутри включительных границ. Пустая клетка хранит значение по умолчанию до первого присваивания.

индекс:  1   2   3
        [10][20][30]
