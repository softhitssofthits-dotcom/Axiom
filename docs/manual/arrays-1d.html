Раздел

Одномерные массивы

Раздел одномерных массивов описывает объявление, доступ к элементам и обход по индексам — простой список значений одного типа с доступом по номеру.

Как одномерный массив хранит список

Одномерный массив хранит последовательность значений одного типа под общим именем. Каждый элемент массива выбирается по одному индексу, а диапазон допустимых индексов задаётся при объявлении или при последующем изменении размера через REDIM.

Синтаксис

DIM <имя массива>(<нижняя граница> TO <верхняя граница>) AS <тип элемента>
DIM <имя массива>() AS <тип элемента>
<имя массива>(<индекс>) = <выражение>
<переменная> = <имя массива>(<индекс>)

Части записи

  • <имя массива> — имя массива.
  • <нижняя граница> TO <верхняя граница> — включительный диапазон допустимых индексов.
  • <тип элемента> — тип всех элементов массива.
  • <индекс> — индекс элемента, к которому обращается программа.
  • <выражение> — значение, которое записывается в элемент массива.
  • <переменная> — переменная того же типа, что и элемент массива, или совместимого типа.

Границы и доступ к элементам

  • Все элементы одномерного массива имеют один и тот же тип.
  • Границы массива включаются в диапазон. Если массив объявлен как DIM scores(1 TO 5) AS INTEGER, допустимы индексы от 1 до 5 включительно.
  • Массив можно объявить без выделения памяти, например DIM values() AS INTEGER. В таком виде имя массива уже существует, но доступ к элементам станет возможен только после REDIM.
  • Обращение к элементу за пределами доступного диапазона приводит к диагностике времени выполнения.
  • Для обхода элементов удобно использовать цикл от LBOUND(array) до UBOUND(array), чтобы код не зависел от конкретных числовых границ.

Пример заполнения и обхода списка

' Программа заполняет массив и печатает все его элементы
' Ожидаемый вывод:
' 10
' 20
' 30
DIM scores(1 TO 3) AS INTEGER
DIM index AS INTEGER

scores(1) = 10
scores(2) = 20
scores(3) = 30

FOR index = LBOUND(scores) TO UBOUND(scores)
    PRINT scores(index)
NEXT

Ручная проверка

  • DIM: объявление массива
  • Доступ к элементу массива
  • LBOUND: нижняя граница массива
  • UBOUND: верхняя граница массива
