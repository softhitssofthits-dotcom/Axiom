Типы данных

Тип данных определяет допустимые значения, операции и правила преобразования. Раздел содержит краткую карту типов Axiom; подробные договоры находятся в соответствующих тематических главах.

Как читать тип в объявлении

В записи DIM count AS INTEGER имя count получает тип целого числа. Начальное значение и последующие присваивания должны соответствовать этому типу. Тип также указывается у параметров и результата пользовательской функции. Вывод типа из начального значения не делает переменную свободной от правил типов.

Совместимость значений

Не всякий переход между типами разрешён автоматически. Для числового расширения, явного преобразования и неподдержанных сочетаний используйте правила преобразований. Диапазоны числовых типов собраны в справочной таблице.
