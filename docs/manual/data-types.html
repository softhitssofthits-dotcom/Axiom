Типы данных

Типы данных

Тип данных определяет, какие значения может хранить переменная, как эти значения участвуют в выражениях и какие преобразования допустимы без явного вмешательства программиста. В Axiom типы помогают не только хранить данные, но и заранее удерживать программу в понятных границах поведения.

Что включает этот раздел

На этой обзорной странице собраны основные направления по работе с типами. Она полезна, когда нужно быстро понять общую модель языка, а затем перейти к точной справке по конкретному виду данных.

Скалярные типы и литералы

Целые, вещественные и логические значения, а также формы литералов, с которых обычно начинается работа с выражениями.

STRING, FILE и фиксированная длина

Строковые значения, формат STRING * N и файловые переменные для текстового ввода и вывода.

TYPE, массивы и групповые объявления

Составные данные, именованные поля и контейнеры из нескольких значений одного типа.

Вывод типа и преобразования

Ситуации, где тип вычисляется по инициализатору, и правила явных либо автоматических преобразований.

Как устроена модель типов в Axiom

Большая часть программ Axiom опирается на несколько базовых идей. Переменная всегда имеет определённый тип, массив строится поверх типа элемента, а пользовательские записи описываются явно через TYPE ... END TYPE. Благодаря этому код проще читать и легче проверять ещё до запуска.

  • тип задаёт допустимую форму значения и влияет на результат выражений;
  • массив не считается отдельным базовым типом, а описывает набор элементов уже известного типа;
  • записи через TYPE объединяют несколько именованных полей в одно составное значение;
  • вывод типа из инициализатора работает только в подтверждённых формах, которые отдельно описаны в manual и спецификации.

Небольшой ориентир

Даже короткий пример показывает, что типы участвуют не только в объявлении переменных, но и в выборе допустимых операций.

DIM count AS INTEGER = 3
DIM title AS STRING = "Axiom"
DIM opened AS BOOLEAN = TRUE

PRINT count + 2
PRINT title
PRINT opened

В этом фрагменте числовая переменная участвует в арифметике, строковая хранит текст, а логическая переменная передаёт условное состояние. Дальше manual разбирает каждый такой тип подробнее, включая объявления, литералы и преобразования.

Когда переходить на соседние страницы

Обычно это полезно в трёх случаях:
  • нужно выбрать точный тип для новой переменной или параметра;
  • нужно понять, допустимо ли преобразование между двумя значениями;
  • нужно проверить, как объявляются массивы, записи или строки фиксированной длины.
