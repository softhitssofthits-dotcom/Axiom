Раздел

Типы данных

Раздел типов данных описывает, какого рода значения хранит программа Axiom и как язык различает их назначение: скалярные типы, включая дату и время, строки, файлы, записи, массивы и преобразования между типами.

Основные правила

  • Каждая переменная и константа имеет определённый тип.
  • Тип задаётся явно через AS или выводится из инициализатора там, где такая форма поддержана.
  • Базовые встроенные типы Axiom включают INTEGER, LONG, DOUBLE, DECIMAL, STRING, BOOLEAN, DATE, TIME, DATETIME, FILE, IMAGE, SPRITE, TILESET и TILEMAP.
  • Пользовательские записи объявляются через TYPE ... END TYPE.
  • Массивный тип строится из типа элемента и ранга: INTEGER(), STRING(,), Record(,,).
  • Если операция требует BOOLEAN, числовое значение не заменяет логическое автоматически.

Числовые типы

Числовые данные представляют числа. В Axiom они разделены по назначению: целые значения, длинные целые значения, числа с плавающей точкой и десятичные значения для случаев, где важна десятичная точность.

ТипНазначениеТипичный пример
INTEGER32-битное знаковое целое числоDIM count AS INTEGER = 10
LONG64-битное знаковое целое числоDIM total AS LONG = 1000000
DOUBLE64-битное число с плавающей точкойDIM ratio AS DOUBLE = 0.75
DECIMALдесятичное число для точных десятичных вычисленийDIM price AS DECIMAL = 10.50

Арифметические операции и встроенные числовые функции описаны отдельно, потому что результат выражения зависит не только от имени типа, но и от участвующих операндов. Для быстрой проверки минимальных и максимальных значений есть отдельное приложение Диапазоны и ограничения типов.

Строковые типы

Строка хранит текст. Обычная форма STRING используется для строк переменной длины, а форма STRING * N задаёт фиксированную длину хранения там, где такая запись поддержана: в переменных DIM, полях TYPE и разрешённых постоянных формах внутри записей.

DIM title AS STRING
DIM code AS STRING * 4

title = "Axiom"
code = "AB"

Фиксированная строка остаётся строковым значением, но при записи подгоняется к указанной длине: короткое значение дополняется пробелами справа, длинное обрезается.

Логический тип

BOOLEAN хранит одно из двух значений: TRUE или FALSE. Этот тип используется в условиях IF, циклах с условием, логических выражениях и функциях, которые отвечают на вопрос «да или нет».

DIM ready AS BOOLEAN = TRUE

IF ready THEN
    PRINT "ready"
END IF

Условие документируемых управляющих конструкций должно иметь тип BOOLEAN, поэтому числовое выражение нужно явно превратить в сравнение, например count > 0.

Типы даты и времени

Типы DATE, TIME и DATETIME хранят календарные и суточные значения: DATE хранит дату, TIME хранит время суток, а DATETIME хранит дату и время вместе. Это скалярные типы, поэтому такие значения объявляются, присваиваются, выводятся и сравниваются как обычные данные.

DIM day AS DATE
DIM moment AS TIME
DIM stamp AS DATETIME

day = "2026-08-25"
moment = "14:05:06"
stamp = "2026-08-25 14:05:06"

Каждый тип имеет канонический строковый вид: DATE — yyyy-MM-dd, TIME — HH:mm:ss, DATETIME — yyyy-MM-dd HH:mm:ss. Строка в таком виде неявно преобразуется в соответствующий тип, а значение типа выводится в этом же виде.

Значения DATE и DATETIME охватывают годы с 1 по 9999, а TIME — время суток от 00:00:00 до 23:59:59. Значения этих типов сравниваются операторами =, <, >, <= и >=. Подробности о типах находятся на странице Скалярные типы и литералы, а функции для работы с такими значениями собраны в разделе Функции даты и времени.

Файловый тип

FILE обозначает открытый текстовый файл. Значение этого типа появляется при работе с файловыми операторами и функциями: файл открывается, используется для чтения или записи, а затем закрывается.

Файловые переменные не предназначены для арифметики, строковой конкатенации или сравнения как обычные скалярные данные. Их область — ввод-вывод и функции открытых файлов.

Тип изображения

IMAGE обозначает загруженное полноцветное изображение для графического вывода. Значение появляется через LOADIMAGE(path), его размеры читаются функциями IMAGEWIDTH и IMAGEHEIGHT, а вывод выполняется оператором DRAWIMAGE.

Переменная типа IMAGE хранит ссылку на изображение. Пустое значение допустимо: функции размера возвращают 0, а попытка нарисовать пустое изображение даёт ошибку времени выполнения.

Тип спрайта

SPRITE обозначает загруженный спрайтовый лист для графического вывода. Значение появляется через LOADSPRITE(path, frameWidth, frameHeight), размер одного кадра читается функциями SPRITEWIDTH и SPRITEHEIGHT, число полных кадров — функцией SPRITECOUNT, а вывод выполняется оператором DRAWSPRITE.

Переменная типа SPRITE хранит ссылку на лист и параметры кадра. Пустое значение допустимо: функции размера и числа кадров возвращают 0, а попытка нарисовать пустой спрайт даёт ошибку времени выполнения.

Тип тайлсета

TILESET обозначает загруженный тайловый атлас для современного графического слоя CANVAS. Значение появляется через LOADTILESET(path, tileWidth, tileHeight[, margin[, spacing]]), размер одного тайла читается функциями TILEWIDTH и TILEHEIGHT, число тайлов — функцией TILECOUNT, а вывод выполняется оператором DRAWTILE.

Переменная типа TILESET хранит ссылку на атлас и параметры сетки тайлов. Пустое значение допустимо: функции размера и числа тайлов возвращают 0, а попытка вызвать DRAWTILE для пустого тайлсета даёт ошибку времени выполнения.

TILEMAP обозначает загруженную тайловую карту Tiled для современного графического слоя CANVAS. Значение появляется через LOADTILEMAP(path), размеры читаются функциями MAPWIDTH, MAPHEIGHT, MAPPIXELWIDTH, MAPPIXELHEIGHT, MAPTILEWIDTH, MAPTILEHEIGHT и MAPLAYERCOUNT, содержимое клетки читается функциями MAPTILE, MAPTILESET и MAPTILEFLAGS, а вывод выполняется операторами DRAWTILEMAP и DRAWTILELAYER.

Переменная типа TILEMAP может быть пустой после DIM. Для пустой карты функции размеров и чтения клеток возвращают 0, попытка рисовать пустую карту даёт ошибку времени выполнения, а оператор SETMAPTILE изменяет только существующую клетку загруженного тайлового слоя.

Пользовательские типы TYPE

Если несколько значений описывают один предмет, их удобно объединить в запись. В Axiom такая запись объявляется через TYPE ... END TYPE, а её поля получают собственные имена и типы.

TYPE Student
    Id AS INTEGER
    Name AS STRING * 20
    Score AS DOUBLE
END TYPE

DIM item AS Student

Поля записи могут быть скалярными, строковыми, фиксированными, массивными и пользовательскими в пределах текущего договора языка. Подробности о конструкторах, методах, SELF и массивных полях находятся на странице Тип TYPE.

Массивные типы

Массив хранит группу элементов одного типа. В типе массива важны два свойства: тип элемента и число измерений. Запись INTEGER() означает одномерный массив целых чисел, а INTEGER(,) — двумерный массив целых чисел.

DIM values(1 TO 3) AS INTEGER
DIM names() AS STRING
DIM board(,) AS INTEGER

Массивы могут быть сразу выделены с границами или объявлены как динамические и позже получить область элементов через REDIM.

Функциональные значения

Процедуры и функции Axiom могут использовать типы параметров и результата, а в поддержанных местах функция может выступать как значение. Такой тип записывается через форму вида FUNCTION(INTEGER) AS BOOLEAN и используется, например, в callback-функциях массивов.

Эта тема относится к разделу процедур, функций и встроенных функций массивов, поэтому здесь важно только общее правило: сигнатура функции тоже является частью её типа.

Дополнительные правила типов

Поддержанные скалярные типы перечислены явно, тип задаётся через AS или выводится из инициализатора, а суффиксы имён и DEF...-операторы не являются частью текущего синтаксиса.

Строковые значения работают как современные строки, а точные правила ввода, вывода, длины и символьных функций описываются на страницах строковых функций справочника.
