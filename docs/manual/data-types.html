Типы данных

Раздел «Типы данных» описывает категории значений Axiom, допустимые операции и правила совместимости.

Тип значения

Тип задаёт допустимые значения и операции над ними. Например, INTEGER хранит целое число, STRING — текст, а BOOLEAN — TRUE или FALSE. У выражения тоже есть тип: результат сравнения имеет тип BOOLEAN, результат соединения строк — STRING.

При объявлении переменной тип можно указать после AS или определить по начальному выражению. После объявления тип переменной сохраняется. Присваивание нового значения меняет данные, но не превращает переменную в переменную другого типа. Правила объявления приведены в статье DIM.

Значение ошибки в CATCH

Переменная, объявленная конструкцией CATCH err, получает встроенное значение типа ERROR. Оно содержит код, сообщение, строку и столбец ошибки. Эта переменная объявляется самим CATCH и доступна только для чтения в соответствующем обработчике. Правила и примеры приведены в статье TRY.

Диапазон, точность и преобразование

Числовые типы различаются диапазоном и способом представления числа. Например, INTEGER ограничен 32 разрядами, а DOUBLE может округлять значения. Таблица точных пределов находится в статье о диапазонах.

Не каждое значение разрешено автоматически преобразовать в другой тип. Например, строка "12" сама по себе не становится числом при присваивании числовой переменной. Для таких действий нужны предусмотренные функции. Допустимые переходы и их ограничения объясняются в статье преобразований типов.
