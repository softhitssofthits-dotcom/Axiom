Основы языка

Типы данных

Тип данных определяет, какого рода значение находится в переменной, константе, выражении, параметре процедуры или результате функции. По типу Axiom понимает, какие операции допустимы, какие преобразования возможны и какую диагностику нужно выдать, если значение используется не по назначению.

Главные правила

  • Каждая переменная и константа имеет определённый тип.
  • Тип задаётся явно через AS или выводится из инициализатора там, где такая форма поддержана.
  • Базовые скалярные типы Axiom: INTEGER, LONG, DOUBLE, DECIMAL, STRING, BOOLEAN и FILE.
  • Пользовательские записи объявляются через TYPE ... END TYPE.
  • Массивный тип строится из типа элемента и ранга: INTEGER(), STRING(,), Record(,,).
  • Если операция требует BOOLEAN, числовое значение не заменяет логическое автоматически.

Числовые типы

Числовые данные представляют числа. В Axiom они разделены по назначению: целые значения, длинные целые значения, числа с плавающей точкой и десятичные значения для случаев, где важна десятичная точность.

ТипНазначениеТипичный пример
INTEGER32-битное знаковое целое числоDIM count AS INTEGER = 10
LONG64-битное знаковое целое числоDIM total AS LONG = 1000000
DOUBLE64-битное число с плавающей точкойDIM ratio AS DOUBLE = 0.75
DECIMALдесятичное число для точных десятичных вычисленийDIM price AS DECIMAL = 10.50

Арифметические операции и встроенные числовые функции описаны отдельно, потому что результат выражения зависит не только от имени типа, но и от участвующих операндов.

Строковые типы

Строка хранит текст. Обычная форма STRING используется для строк переменной длины, а форма STRING * N задаёт фиксированную длину хранения там, где такая запись поддержана: в переменных DIM, полях TYPE и разрешённых постоянных формах внутри записей.

DIM title AS STRING
DIM code AS STRING * 4

title = "Axiom"
code = "AB"

Фиксированная строка остаётся строковым значением, но при записи подгоняется к указанной длине: короткое значение дополняется пробелами справа, длинное обрезается.

Логический тип

BOOLEAN хранит одно из двух значений: TRUE или FALSE. Этот тип используется в условиях IF, циклах с условием, логических выражениях и функциях, которые отвечают на вопрос «да или нет».

DIM ready AS BOOLEAN = TRUE

IF ready THEN
    PRINT "ready"
END IF

В QuickBASIC в условных выражениях часто использовалась числовая модель: ноль означал ложь, ненулевое значение — истину. В Axiom условие документируемых управляющих конструкций должно иметь тип BOOLEAN, поэтому числовое выражение нужно явно превратить в сравнение, например count > 0.

Файловый тип

FILE обозначает открытый текстовый файл. Значение этого типа появляется при работе с файловыми операторами и функциями: файл открывается, используется для чтения или записи, а затем закрывается.

Файловые переменные не предназначены для арифметики, строковой конкатенации или сравнения как обычные скалярные данные. Их область — ввод-вывод и функции открытых файлов.

Пользовательские типы TYPE

Если несколько значений описывают один предмет, их удобно объединить в запись. В Axiom такая запись объявляется через TYPE ... END TYPE, а её поля получают собственные имена и типы.

TYPE Student
    Id AS INTEGER
    Name AS STRING * 20
    Score AS DOUBLE
END TYPE

DIM item AS Student

Поля записи могут быть скалярными, строковыми, фиксированными, массивными и пользовательскими в пределах текущего договора языка. Подробности о конструкторах, методах, SELF и массивных полях находятся на странице Тип TYPE.

Массивные типы

Массив хранит группу элементов одного типа. В типе массива важны два свойства: тип элемента и число измерений. Запись INTEGER() означает одномерный массив целых чисел, а INTEGER(,) — двумерный массив целых чисел.

DIM values(1 TO 3) AS INTEGER
DIM names() AS STRING
DIM board(,) AS INTEGER

Массивы могут быть сразу выделены с границами или объявлены как динамические и позже получить область элементов через REDIM.

Функциональные значения

Процедуры и функции Axiom могут использовать типы параметров и результата, а в поддержанных местах функция может выступать как значение. Такой тип записывается через форму вида FUNCTION(INTEGER) AS BOOLEAN и используется, например, в callback-функциях массивов.

Эта тема относится к разделу процедур, функций и встроенных функций массивов, поэтому здесь важно только общее правило: сигнатура функции тоже является частью её типа.

Отличия, важные при чтении старых BASIC-материалов

В QuickBASIC были типы SINGLE, суффиксы имён вроде %, &, !, #, $ и операторы семейства DEF... для задания типа по первой букве имени. В Axiom документируемая модель другая: поддержанные скалярные типы перечислены явно, тип задаётся через AS или выводится из инициализатора, а суффиксы имён и DEF...-операторы не являются частью текущего синтаксиса.

В QuickBASIC строки описывались через байтовую модель исторической кодировки. В Axiom строковые значения работают как современные строки, а точные правила ввода, вывода, длины и символьных функций описываются на страницах строковых функций manual.

Ручная проверка

Эти файлы можно открыть в Axiom.Ide и использовать как короткие проверки объявлений, строк, записей и преобразований.

  • DIM: базовое объявление
  • DIM: явный DECIMAL
  • DIM: вывод типа LONG
  • DIM: фиксированная строка STRING * N
  • TYPE: доступ к полям
  • TYPE: фиксированные строковые поля
  • Автоматические числовые преобразования
