Типы данных

Тип определяет, какие значения можно хранить и какие операции к ним применимы. В Axiom есть числа, текст, логические и временные значения, файловые и графические ресурсы; составные данные представлены массивами, записями и функциональными значениями.

Тип переменной и выражения

Тип переменной указывается после AS или определяется по начальному выражению в объявлении. При последующих присваиваниях тип сохраняется: переменная INTEGER хранит целые числа, STRING хранит текст, а BOOLEAN принимает TRUE или FALSE. Формы объявления приведены в статье DIM.

Результат сравнения имеет тип BOOLEAN, результат соединения строк имеет тип STRING. Для встроенных функций типы аргументов и возвращаемого значения указаны в соответствующих справочных статьях.

Значение ошибки в CATCH

Конструкция CATCH err объявляет переменную типа ERROR, которая содержит код, сообщение, строку и столбец ошибки. В соответствующем обработчике переменная доступна только для чтения. Правила объявления, состав полей и примеры приведены в статье TRY.

Диапазон и совместимость

Диапазон числового типа и способ представления числа ограничивают допустимые значения и точность вычислений. INTEGER использует 32 разряда; DOUBLE допускает округление. Точные пределы приведены в таблице диапазонов.

От совместимости типов зависит, можно ли записать значение в переменную или передать его параметру при вызове. Например, присваивание строки "12" числовой переменной не превращает текст в число автоматически: для разбора нужны функции преобразования. Допустимые переходы, точность и ограничения описаны в статье о преобразованиях типов.
