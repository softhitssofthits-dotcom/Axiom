Запускаемые примеры

Раздел примеров содержит программы для ручной проверки языка. Каждый файл можно открыть в IDE и выполнить; нужные пояснения находятся в его тематической статье.

Как проверять пример

Откройте файл в IDE, выполните проверку, затем запустите программу. Изменяйте одно входное значение или действие за раз и сравнивайте результат. Для ввода ответьте на приглашение; графический пример оценивайте в его окне. Примеры ошибок предназначены для проверки конкретного сообщения и не должны завершаться как обычная программа.

Начать с простой программы

  • Объявление переменной
  • Вывод значения
  • Ввод одного значения

Подборка программ

  • INPUT: одна переменная
  • SELECT CASE: диапазоны и CASE IS
  • SELECT CASE: логические значения
  • SELECT CASE: первая подошедшая ветвь
  • LEFT: базовое использование
  • FUNCTION: базовое определение
  • SCREEN: информация о текущем режиме
  • CANVAS: линии и окружности
  • Общий базовый сценарий
