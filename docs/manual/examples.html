Коротко

Эта страница нужна для практики. Она собирает небольшие запускаемые программы, на которых удобно повторять синтаксис, ввод-вывод, ветвление, циклы и вызовы функций.

Файлы для запуска в IDE

Для запуска в IDE начните с этих образцов.

  • INPUT: одна переменная
  • SELECT CASE: диапазоны и CASE IS
  • SELECT CASE: логические значения
  • SELECT CASE: первая подошедшая ветвь
  • LEFT: базовое использование
  • FUNCTION: базовое определение
  • SCREEN: информация о текущем режиме
  • CANVAS: линии и окружности
  • Общий базовый сценарий

Подборка коротких программ

Каждый пример ниже показывает один небольшой завершённый сценарий. Их можно открывать как образцы для разбора, а можно брать как основу для собственных экспериментов.

1. Карточка студента

DIM name AS STRING
DIM year AS INTEGER

INPUT "Имя: "; name
INPUT "Курс: "; year

PRINT
PRINT "Студент: "; name
PRINT "Курс: "; year

IF year >= 4 THEN
    PRINT "Старшие курсы"
ELSE
    PRINT "Начальный этап"
END IF

Этот пример объединяет INPUT, PRINT, типы данных и оператор IF.

2. Классификация оценки через SELECT CASE

DIM score AS INTEGER
INPUT "Баллы: "; score

SELECT CASE score
    CASE 90 TO 100
        PRINT "Отличный результат"
    CASE 70 TO 89
        PRINT "Уверенный результат"
    CASE 50 TO 69
        PRINT "Есть запас для роста"
    CASE ELSE
        PRINT "Нужно повторить тему"
END SELECT

Этот пример показывает, как одно значение сравнивается с диапазонами и с запасной ветвью CASE ELSE.

3. Функция нормализации строки

FUNCTION NormalizeName(text AS STRING) AS STRING
    IF LEN(text) = 0 THEN
        RETURN ""
    END IF

    IF LEN(text) = 1 THEN
        RETURN UCASE(text)
    END IF

    RETURN UCASE(LEFT(text, 1)) + LCASE(MID(text, 2, LEN(text) - 1))
END FUNCTION

DIM rawName AS STRING
INPUT "Имя в любом регистре: "; rawName

PRINT NormalizeName(rawName)

Этот пример показывает совместную работу пользовательской функции и встроенных строковых операций.

4. Работа с массивом оценок

DIM marks(1 TO 3) AS INTEGER
DIM total AS INTEGER = 0
DIM i AS INTEGER

marks(1) = 4
marks(2) = 5
marks(3) = 3

FOR i = 1 TO 3
    total = total + marks(i)
NEXT

PRINT "Сумма = "; total
PRINT "Среднее = "; total / 3

Этот пример показывает совместную работу массива и цикла FOR.

5. Повторный ввод через DO ... LOOP UNTIL

DIM answer AS STRING

DO
    INPUT "Введите ДА для подтверждения: "; answer
    answer = LCASE(answer)
LOOP UNTIL answer = "да"

PRINT "Подтверждение принято"

Такой образец подходит для повторного запроса пользовательского ввода.

Порядок запуска примеров

  • изменяйте входные данные и наблюдайте, как меняется поведение программы;
  • намеренно вызывайте ошибку и отмечайте, на каком этапе она возникает;
  • выносите повторяющиеся части в собственные SUB и FUNCTION;
  • соберите на основе этих фрагментов собственную небольшую программу.
