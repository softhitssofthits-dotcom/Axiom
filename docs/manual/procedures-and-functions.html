Процедуры и функции

Эта обзорная глава помогает быстро понять, когда нужна подпрограмма, когда нужна функция и как теперь работают функции как значения языка.

Сводка

  • когда нужно понять, чем подпрограмма отличается от функции;
  • когда нужно выбрать форму для вычисления, побочного действия или раннего выхода;
  • когда нужно быстро перейти к точной справке по SUB, FUNCTION или RETURN.

Коротко

SUB выполняет действия и не становится значением. FUNCTION вычисляет значение и теперь сама может быть значением, если для неё указан функциональный тип.

Куда переходить дальше

Подпрограмма SUB

Именованные действия без возвращаемого значения: вывод, проверки, изменение уже доступных переменных.

Функция FUNCTION

Именованные вычисления с обязательным результатом, функциональными типами и возвращаемыми замыканиями.

Оператор RETURN

Возврат значения из функции и досрочное завершение подпрограммы.

Короткий ориентир

SUB ShowBanner(text AS STRING)
    PRINT "=="; text; "=="
END SUB

FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION

ShowBanner("Axiom")
PRINT Square(5)

SUB выполняет действия, а FUNCTION вычисляет и возвращает значение. Оператор RETURN в FUNCTION обязателен для возврата результата, а в SUB используется только для досрочного выхода.

Язык также поддерживает локальные SUB и FUNCTION внутри другой процедуры или функции. Локальная функция может захватывать внешние данные, а если она возвращается наружу, то сохраняет их и после завершения внешней функции.

Функции можно хранить в переменных функционального типа, передавать в параметры и возвращать как результат. Подпрограммы SUB в этой роли не используются.

Показательные примеры

Для проверки раздела через IDE откройте несколько коротких файлов по основным сценариям.

  • SUB: базовый вызов
  • SUB: локальная вложенная подпрограмма
  • SUB: захват внешней локальной переменной
  • FUNCTION: базовое объявление
  • FUNCTION: локальная вложенная функция
  • FUNCTION: захват внешнего параметра и локальной переменной
  • FUNCTION: функция как значение
  • FUNCTION: возвращаемая функция с захваченными данными
  • FUNCTION: общее захваченное состояние
  • RETURN: возврат значения из FUNCTION
  • RETURN: досрочный выход из SUB
