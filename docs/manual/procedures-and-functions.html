Процедуры и функции

Процедуры и функции позволяют разбивать программу на именованные части. В Axiom процедуры удобно использовать для действий, а функции — для вычислений, которые должны вернуть значение. Эта страница помогает увидеть общую картину до перехода к точной справке по SUB, FUNCTION и RETURN.

Сводка

Этот раздел особенно полезен, когда программа перестаёт помещаться в одну линейную последовательность инструкций и возникает естественная потребность выносить повторяющиеся шаги в отдельные именованные блоки.

  • когда нужно понять, чем процедура отличается от функции;
  • когда нужно выбрать форму для вычисления, побочного действия или раннего выхода;
  • когда нужно быстро перейти к точной справке по SUB, FUNCTION или RETURN.

Коротко

SUB выполняет действия и не становится значением. FUNCTION вычисляет значение, а в поддержанных формах функциональных типов сама тоже может использоваться как значение.

Куда переходить дальше

Процедура SUB

Именованные действия без возвращаемого значения: вывод, проверки, изменение уже доступных переменных.

Функция FUNCTION

Именованные вычисления с обязательным результатом, функциональными типами и возвращаемыми замыканиями.

Оператор RETURN

Возврат значения из функции и досрочное завершение процедуры.

Короткий ориентир

Ниже показан минимальный контраст между процедурой и функцией. Он полезен как первая практическая модель: одна конструкция что-то делает, другая возвращает вычисленный результат.

SUB ShowBanner(text AS STRING)
    PRINT "=="; text; "=="
END SUB

FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION

ShowBanner("Axiom")
PRINT Square(5)

SUB выполняет действия, а FUNCTION вычисляет и возвращает значение. Оператор RETURN в FUNCTION обязателен для возврата результата, а в SUB используется только для досрочного выхода.

Параметры процедур и функций по умолчанию передаются как BYVAL. Для явного изменения вызывающей переменной можно отметить параметр как BYREF; это особенно важно на границе работы с пользовательскими записями TYPE, где BYVAL сохраняет копию значения, а BYREF работает с исходной переменной.

Те же формы SUB и FUNCTION можно объявлять и внутри TYPE как методы записи. В таком случае вызов идёт через точку, например counter.Increment(2), а текущая запись внутри метода доступна как SELF.

Axiom также поддерживает локальные SUB и FUNCTION внутри другой процедуры или функции. Локальная функция может захватывать внешние данные, а если она возвращается наружу, то сохраняет их и после завершения внешней функции.

Функции можно хранить в переменных функционального типа, передавать в параметры и возвращать как результат. Процедуры SUB в этой роли не используются, поэтому выбирать между ними стоит не по вкусу, а по реальной модели вызова.

Показательные примеры

Для проверки раздела через IDE лучше открыть несколько коротких файлов по отдельным сценариям: базовый вызов, локальное объявление, захват внешних значений и возврат результата.

  • SUB: базовый вызов
  • SUB: BYREF для записи TYPE
  • SUB: BYVAL и копия записи
  • TYPE: методы и SELF
  • SUB: локальная вложенная процедура
  • SUB: захват внешней локальной переменной
  • FUNCTION: базовое объявление
  • FUNCTION: локальная вложенная функция
  • FUNCTION: захват внешнего параметра и локальной переменной
  • FUNCTION: функция как значение
  • FUNCTION: возвращаемая функция с захваченными данными
  • FUNCTION: общее захваченное состояние
  • RETURN: возврат значения из FUNCTION
  • RETURN: досрочный выход из SUB
