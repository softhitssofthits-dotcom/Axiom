11 · Процедуры и функции

Процедуры и функции

Раздел процедур и функций описывает объявления SUB и FUNCTION, передачу параметров, вызовы и оператор RETURN. SUB объединяет действие без результата, FUNCTION вычисляет значение, а RETURN завершает текущий вызов.

Зачем выделять подпрограмму

Повторяемую последовательность инструкций можно назвать и вызвать из нескольких мест. Параметры передают входные значения, локальные переменные хранят состояние текущего вызова, а функция возвращает вычисленный результат.

Выбор объявления

Используйте SUB для действия, например вывода, записи файла или изменения параметра BYREF. Используйте FUNCTION, если вызывающему коду нужно значение определённого типа. Объявления доступны на верхнем уровне и локально внутри другой подпрограммы.

Передача параметров

Имя обозначает подпрограмму. Список параметров содержит объявления через запятую. Каждый параметр задаёт имя и тип после AS; пустой список допустим. Список аргументов содержит выражения в том же порядке. Тип аргумента должен совпадать с типом параметра либо допускать предусмотренное языком преобразование.

BYVAL применяется по умолчанию и передаёт значение. Присваивание скалярному параметру не меняет переменную вызывающего кода. TYPE копируется с вложенными записями и фиксированными массивными полями; динамические массивные поля обычной длины сохраняют общий массив, как описано в правилах копирования TYPE. Обычный массив при BYVAL сохраняет общее хранилище: изменение элемента видно снаружи, хотя присваивание самому параметру другого массива не заменяет переменную вызывающего кода. Запись BYVAL фиксируется в момент вычисления своего аргумента, до вычисления следующих аргументов: если следующий аргумент меняет исходную запись, параметр сохраняет значение, бывшее на момент его вычисления.

BYREF связывает параметр с простым именем переменной. Тип должен точно совпадать; преобразование аргумента не допускается. Поле записи, элемент массива и вычисляемое выражение не являются допустимым аргументом BYREF. Передача CONST через BYREF отвергается диагностикой MB2010; для изменяемого аргумента используйте обычную переменную DIM.

Функции как значения

Функция без параметров BYREF может сохраняться в функциональной переменной, передаваться аргументом и возвращаться из другой функции. Вложенные функции могут захватывать внешние локальные значения. Такие функции применяются, например, в ARRAYMAP и ARRAYFILTER.

Короткий пример

SUB Banner(text AS STRING)
    PRINT "=="; text; "=="
END SUB
FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION
Banner("Axiom")
PRINT Square(5)

Ожидаемый вывод:

==Axiom==
25
