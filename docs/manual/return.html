Оператор RETURN

RETURN — оператор языка Axiom, который завершает текущий вызов процедуры или функции. В процедуре он возвращает управление, а в функции дополнительно возвращает вычисленное значение.

Назначение и контекст

RETURN позволяет закончить подпрограмму до конца тела, например после проверки входного аргумента. Оператор разрешён только внутри SUB или FUNCTION, включая методы TYPE; на верхнем уровне он недопустим.

Выход из процедуры

RETURN

Возврат из функции

RETURN <выражение>

Части записи

В процедуре аргументов нет. В функции выражение вычисляет результат; его тип должен быть совместим с объявленным типом результата FUNCTION.

Действие и ограничения

После RETURN следующие обычные инструкции тела не выполняются. Завершается только текущий вызов, а вызывающая программа продолжает работу. При RETURN выполняется ближайший активный FINALLY перед возвратом. В текущей реализации RETURN внутри вложенных TRY/FINALLY после ближайшего FINALLY завершает вызов, не выполняя внешние FINALLY; не рассчитывайте на их выполнение при такой форме выхода.

Достижение END SUB завершает процедуру. Достижение END FUNCTION без возвращённого значения является ошибкой времени выполнения.

Диагностика

MB2012 означает RETURN вне подпрограммы. MB2006 означает RETURN со значением в SUB, MB2007 — RETURN без выражения в FUNCTION, MB2003 — несовместимый тип результата. MB3006 возникает, если выполненная ветвь функции дошла до конца без значения.

Пример выхода с FINALLY

FUNCTION Value() AS INTEGER
    TRY
        RETURN 7
    FINALLY
        PRINT "finally"
    END TRY
END FUNCTION
PRINT Value()

Ожидаемый вывод:

finally
7
