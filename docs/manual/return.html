Оператор RETURN

RETURN завершает выполнение текущей процедуры или функции. В FUNCTION он возвращает значение вызывающему коду, а в SUB служит для досрочного выхода без возвращаемого результата.

Сводка

Семантика RETURN зависит от контекста: в функции требуется выражение результата, в подпрограмме значение не допускается. Оператор завершает текущую процедуру или функцию и пропускает оставшиеся инструкции её тела.

Синтаксис

RETURN <выражение>
RETURN

Части синтаксиса

  • <выражение> — значение, которое возвращает текущая функция.
  • Форма RETURN без выражения допустима только в SUB.

Замечания

  • В FUNCTION допустима только форма RETURN <выражение>.
  • В SUB допустима только форма RETURN без значения.
  • RETURN разрешён только внутри SUB или FUNCTION.
  • Те же правила действуют и для локальных SUB/FUNCTION, объявленных внутри другой процедуры или функции.
  • В FUNCTION можно вернуть не только число, строку или логическое значение, но и саму функцию, если тип результата объявлен как функциональный.
  • После выполнения RETURN управление сразу передаётся вызывающему коду.
  • Если функция по реально выполненной ветви дошла до конца без возвращаемого значения, ошибка фиксируется на этапе времени выполнения.

Ручная проверка

Для проверки обеих ролей оператора используйте готовые примеры.

  • RETURN: возврат значения из FUNCTION
  • RETURN: досрочный выход из SUB
  • FUNCTION: возврат функции с захваченными данными

Примеры

FUNCTION DoubleIt(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION
SUB Check(value AS INTEGER)
    IF value < 0 THEN
        PRINT "Нельзя"
        RETURN
    END IF

    PRINT "Можно продолжать"
END SUB
FUNCTION MakeAdder(baseValue AS INTEGER) AS FUNCTION(INTEGER) AS INTEGER
    FUNCTION Add(delta AS INTEGER) AS INTEGER
        RETURN baseValue + delta
    END FUNCTION

    RETURN Add
END FUNCTION

Диагностика

  • MB2012 — RETURN использован вне SUB или FUNCTION.
  • MB2006 — в SUB использован RETURN со значением.
  • MB2007 — в FUNCTION использован RETURN без выражения.
  • MB3006 — функция завершилась без возвращаемого значения по выполненной ветви.
