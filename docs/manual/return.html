Процедуры и функции

Оператор RETURN

RETURN завершает выполнение текущей процедуры или функции. В функции он отдаёт вызывающему коду вычисленное значение, а в процедуре служит досрочным выходом без результата.

Что возвращает RETURN

В FUNCTION оператор RETURN обязателен на исполняемом пути, который должен вернуть результат. В SUB он не обязателен: процедура может спокойно дойти до END SUB, а RETURN нужен только для раннего завершения.

Синтаксис

RETURN <выражение>
RETURN

Части записи

<выражение> - значение, которое возвращает текущая функция. Эта форма допустима только внутри FUNCTION.

Форма RETURN без выражения допустима только внутри SUB.

Завершение текущей процедуры

  • После выполнения RETURN оставшиеся инструкции текущей процедуры или функции не выполняются.
  • RETURN <выражение> должен вернуть значение, совместимое с типом результата текущей функции.
  • RETURN без значения в SUB удобен для проверки особого случая в начале процедуры.
  • RETURN допустим только внутри SUB или FUNCTION.

В QuickBASIC слово RETURN прежде всего связано с подпрограммами GOSUB, а выход из FUNCTION часто оформлялся через присваивание имени функции и EXIT FUNCTION. В Axiom GOSUB не относится к текущей реализованной справке, а RETURN явно обслуживает SUB и FUNCTION.

Пример досрочного возврата

' Ожидаемый вывод:
' 42
' before return
' after if
FUNCTION DoubleValue(value AS INTEGER) AS INTEGER
    RETURN value + value
END FUNCTION

SUB Show(flag AS BOOLEAN)
    IF flag THEN
        PRINT "before return"
        RETURN
    END IF

    PRINT "after if"
END SUB

PRINT DoubleValue(21)
Show(TRUE)
Show(FALSE)

Ручная проверка

  • RETURN: возврат значения из FUNCTION
  • RETURN: досрочный выход из SUB
  • FUNCTION: возврат функции с захваченными данными

Диагностика

Ошибка возникает, если RETURN записан вне SUB или FUNCTION, если SUB возвращает значение, если FUNCTION использует RETURN без значения, если тип возвращаемого выражения не подходит к типу результата функции или если функция завершилась без возвращённого значения.
