Оператор RETURN

Досрочный выход из SUB и возврат значения из FUNCTION.

Процедуры и функции

Оператор RETURN

Оператор RETURN управляет выходом из текущей процедуры или функции. В FUNCTION он завершает вычисление и отдаёт результат вызывающему коду, а в SUB позволяет прервать дальнейшее выполнение раньше конца блока, если логика уже достигла нужной точки.

Сводка

RETURN завершает выполнение текущей процедуры или функции. Внутри FUNCTION он возвращает значение вызывающему коду, а внутри SUB используется для досрочного выхода без результата.

Синтаксис

' Возврат значения из FUNCTION
RETURN expression
' Досрочный выход из SUB
RETURN

Части записи

expression обозначает значение, которое возвращает текущая функция. Форма без выражения допустима только в процедуре SUB.

Замечания

RETURN особенно полезен там, где не хочется строить лишнюю вложенность из нескольких IF только ради того, чтобы дойти до конца процедуры или функции естественным путём.

  • В FUNCTION допустима только форма RETURN expression.
  • В SUB допустима только форма RETURN без значения.
  • RETURN разрешён только внутри SUB или FUNCTION.
  • После выполнения RETURN оставшиеся инструкции текущей процедуры или функции больше не выполняются.
  • Те же правила действуют и для локальных процедур и функций, объявленных внутри другой процедуры или функции.

Пример

' Функция возвращает 42, а процедура выходит раньше
' Ожидаемый вывод:
' 42
' Нельзя
FUNCTION DoubleIt(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION

SUB Check(value AS INTEGER)
    IF value < 0 THEN
        PRINT "Нельзя"
        RETURN
    END IF

    PRINT "Можно продолжать"
END SUB

Ручная проверка

  • RETURN: возврат значения из FUNCTION
  • RETURN: досрочный выход из SUB
  • FUNCTION: возврат функции с захваченными данными

Диагностика

Ошибки возникают, если RETURN используется вне процедуры или функции, если в SUB возвращается значение, если в FUNCTION значение не возвращается вовсе или если вместо требуемой формы используется неподходящий вариант оператора.
