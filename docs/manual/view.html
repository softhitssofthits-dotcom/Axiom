Оператор

VIEW

VIEW задаёт прямоугольную область графического экрана, внутри которой работают графические примитивы, PAINT, DRAW и функция POINT. Родственная форма VIEW PRINT ограничивает не графику, а строки текстового вывода на активном графическом экране.

Синтаксис

VIEW
VIEW SCREEN (<left>, <top>)-(<right>, <bottom>)[, [<заливка>][, <рамка>]]
VIEW (<left>, <top>)-(<right>, <bottom>)[, [<заливка>][, <рамка>]]
VIEW PRINT
VIEW PRINT <верх> TO <низ>

Части синтаксиса

ЧастьОписание
VIEW без аргументовСбрасывает viewport и возвращает графические координаты к полному экрану.
SCREENОставляет координаты абсолютными экранными координатами.
<left>, <top>, <right>, <bottom>Координаты углов viewport. Прямоугольник включителен: обе границы входят в область.
<заливка>Необязательный цвет внутренней области viewport. Если аргумент опущен, существующие пиксели внутри области не меняются.
<рамка>Необязательный цвет рамки viewport. Если аргумент опущен, рамка не рисуется.
VIEW PRINT <верх> TO <низ>Задаёт включительный диапазон строк, в котором прокручиваются последующие PRINT, PRINT USING и подтверждённый INPUT на графическом экране.
VIEW PRINTСбрасывает текстовое окно вывода и возвращает текстовый вывод к полной текстовой сетке текущего графического режима.

Замечания

VIEW работает только в графических режимах SCREEN 1 ... SCREEN 10. Без активного графического режима оператор сообщает ошибку времени выполнения MB3010.

Форма VIEW SCREEN задаёт физический прямоугольник в абсолютных координатах экрана. После неё PSET, LINE, CIRCLE, PAINT, DRAW и POINT(x, y) продолжают принимать абсолютные координаты, но их вывод ограничивается границами viewport.

Форма VIEW без слова SCREEN задаёт viewport относительно текущего viewport. После неё графические координаты становятся локальными: точка (0, 0) означает левый верхний угол нового viewport, а POINT(number) возвращает текущую графическую позицию в той же локальной системе координат.

Если программе нужна не только локальная область вывода, но и собственная логическая шкала координат, поверх VIEW можно включить WINDOW. В этом случае VIEW по-прежнему отвечает только за физические границы рисования.

Когда поверх viewport уже включён WINDOW, функция PMAP переводит координаты между физической системой viewport и логической шкалой окна. Это помогает связывать измерения экрана с координатами самой программы.

При смене viewport Axiom сохраняет физическую точку текущей графической позиции и просто пересчитывает её в новую систему координат. После VIEW без аргументов текущая графическая позиция снова читается в абсолютных координатах экрана.

VIEW не меняет поведение LOCATE и текстового курсора. Текстовые операторы продолжают работать по общему экранному режиму SCREEN.

Если прямоугольник выходит за пределы активного экрана или если левая граница больше правой либо верхняя больше нижней, выполнение сообщает MB3007.

Оператор VIEW PRINT

VIEW PRINT задаёт текстовое окно вывода внутри активного графического режима SCREEN 1 ... SCREEN 10. Это окно измеряется строками текстовой сетки, а не пикселями, и не зависит от графического viewport, заданного обычным VIEW.

После VIEW PRINT верх TO низ последующие строки PRINT, PRINT USING и подтверждённого INPUT прокручиваются только внутри выбранного диапазона. Строки выше и ниже этого диапазона остаются на месте, поэтому их удобно использовать для заголовков, подсказок и строки состояния.

Форма VIEW PRINT без границ сбрасывает ограничение и снова разрешает текстовый вывод по всей текстовой сетке текущего графического режима. Команда работает только при активном графическом SCREEN; в SCREEN 0 используется отдельный договор текстового окна с историей и полосой прокрутки.

Значения верх и низ должны образовывать корректный включительный диапазон строк текущего режима: верх >= 1, низ >= верх, низ не выходит за последнюю строку LOCATE. Нарушение даёт MB3007, а вызов без графического режима даёт MB3010.

SCREEN 1
VIEW PRINT 10 TO 12
FOR i = 1 TO 5
    PRINT "line"; i
NEXT

VIEW PRINT
LOCATE 1, 1
PRINT "VIEW PRINT reset"

Примеры

SCREEN 1
VIEW SCREEN (10, 10)-(100, 80), 3, 9
PSET (11, 11), 6

VIEW (5, 5)-(20, 20), 2, 8
PSET (0, 0), 7
PRINT POINT(0, 0)
PRINT POINT(0), POINT(1)

VIEW

Сначала программа создаёт абсолютный viewport с заливкой и рамкой. Затем она открывает вложенный относительный viewport, рисует в его локальной точке (0, 0), читает локальный цвет и текущую локальную позицию, а после VIEW без аргументов возвращается к полному экрану.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3007: прямоугольник viewport некорректен или выходит за пределы активного экрана.
  • MB3007: строки VIEW PRINT не образуют допустимый диапазон внутри текущей текстовой сетки.

Проверочная программа

Готовые примеры можно открыть в Axiom.Ide и запустить для ручной проверки графического viewport и текстового окна вывода.

  • VIEW: абсолютный и относительный viewport
  • VIEW PRINT: прокрутка внутри строкового диапазона
