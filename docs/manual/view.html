Оператор VIEW

VIEW — оператор языка Axiom, который ограничивает рисование прямоугольной областью экрана. Форма VIEW PRINT независимо задаёт строки, отведённые для экранного текста.

Когда использовать VIEW

Графическая область позволяет рисовать в части экрана, сохраняя остальное изображение. Её границы задаются физическими пикселями.

Текстовую область задают, когда вывод и прокрутка должны занимать только выбранные строки, например под графиком или рядом с ним.

Контекст выполнения

Обе формы требуют графического режима SCREEN 1..10. Они не относятся к холсту CANVAS, у которого есть отдельный оператор VIEWPORT.

Синтаксис оператора VIEW

VIEW
VIEW SCREEN (<левый операнд>, <верхняя граница>)-(<правый операнд>, <нижняя граница>)
VIEW SCREEN (<левый операнд>, <верхняя граница>)-(<правый операнд>, <нижняя граница>), <цвет заливки>
VIEW SCREEN (<левый операнд>, <верхняя граница>)-(<правый операнд>, <нижняя граница>), <цвет заливки>, <цвет границы>
VIEW (<левый операнд>, <верхняя граница>)-(<правый операнд>, <нижняя граница>)
VIEW (<левый операнд>, <верхняя граница>)-(<правый операнд>, <нижняя граница>), <цвет заливки>
VIEW (<левый операнд>, <верхняя граница>)-(<правый операнд>, <нижняя граница>), <цвет заливки>, <цвет границы>

Синтаксис оператора VIEW PRINT

VIEW PRINT
VIEW PRINT <верхняя строка> TO <нижняя строка>

Что делает оператор VIEW

Вызов VIEW без аргументов снимает ограничение и восстанавливает рисование по всему экрану.

Слово SCREEN сохраняет абсолютные экранные координаты после выбора области.

Без слова SCREEN координаты рисования отсчитываются в системе выбранной области.

Необязательный цвет заливки заполняет внутреннюю область; необязательный цвет рамки обводит её границу.

Что делает оператор VIEW PRINT

Вызов VIEW PRINT без аргументов возвращает тексту всю доступную сетку графического экрана.

Диапазон topRow TO bottomRow задаёт строки, внутри которых прокручивается вывод PRINT, PRINT USING и подтверждённый ввод INPUT.

Правила работы

Оператор VIEW определяет физическую область вывода. Для собственной числовой шкалы внутри неё используйте WINDOW.

Ограничение VIEW PRINT влияет на текстовые строки и не меняет область пиксельного рисования.

  • форма VIEW без аргументов и форма VIEW PRINT без аргументов сбрасывают соответствующее ограничение и возвращают вывод ко всему экрану;
  • координаты графической области задаются в пикселях; строки VIEW PRINT задаются в строках текстовой сетки текущего графического режима;
  • недопустимые границы графической области или номера строк завершают выполнение диагностикой MB3007;
  • оператор VIEW действует только в графическом режиме: без активного SCREEN 1..10 выполнение завершается диагностикой MB3010;
  • заливка и рамка графической области становятся видимыми сразу после выполнения оператора VIEW, если указаны соответствующие цвета.

Границы областей и типы аргументов

Координаты графической области приводятся к LONG и задаются в физических пикселях SCREEN. Правая и нижняя границы включаются. Левая граница не должна превышать правую, верхняя — нижнюю; обе противоположные вершины области должны находиться внутри экрана. Частично выходящая за экран область не принимается. Недопустимая область сообщает MB3007. Цвета заливки и рамки приводятся к INTEGER и обозначают нормализованные индексы палитры.

Номера строк VIEW PRINT приводятся к INTEGER. Они начинаются с 1 и должны задавать упорядоченный диапазон внутри текущей текстовой сетки; неверный диапазон сообщает MB3007. VIEW PRINT не меняет графические координаты. Результат настройки и рисования относится к активной странице SCREEN.

Диагностика

  • MB3010: оператор VIEW или оператор VIEW PRINT вызваны без активного графического режима SCREEN 1..10.
  • MB3007: координаты графической области или номера строк имеют недопустимое значение.

Пример

SCREEN 1
VIEW SCREEN (10, 10)-(60, 40), 3, 9
LINE (10, 10)-(60, 40), 14, B

VIEW PRINT 2 TO 4
LOCATE 2, 2
PRINT "Текст внутри окна"
SLEEP

Первый вызов выбирает область рисования, заливает её и рисует рамку. Второй вызов отводит экранному тексту отдельный диапазон строк.
