Вызовы процедур и функций

Вызов — форма языка Axiom, которая передаёт управление процедуре, функции или методу и связывает аргументы с параметрами. Функция возвращает результат; процедура выполняет действие.

Синтаксис

<имя>(<аргументы>)
<получатель>.<метод>(<аргументы>)

Для вызова без аргументов скобки сохраняются: Name(). Вызов функции может входить в выражение или записываться отдельной инструкцией; в последнем случае результат не используется.

Аргументы

Аргументы записываются через запятую в порядке параметров. Число аргументов и их типы должны соответствовать выбранной форме вызова. Формы всех встроенных функций перечислены в полном справочнике функций.

Параметр BYVAL получает значение по правилам копирования соответствующего типа. Параметр BYREF связывается с изменяемым местом хранения; подробные ограничения определены в статьях SUB и FUNCTION.

Именованная запись FieldName := expression служит для полей литерала записи TYPE. Она не является общей формой именованных аргументов процедур и встроенных функций.

Функциональные значения

Функция без параметров BYREF может использоваться как значение: сохраняться в переменной функционального типа, передаваться другой функции и возвращаться из функции. Вызов такого значения записывается со скобками.

Массивные функции обработки принимают функциональные значения с указанным договором: ARRAYEVERY, ARRAYSOME и ARRAYFILTER — FUNCTION(T) AS BOOLEAN; ARRAYMAP — FUNCTION(T) AS U; ARRAYREDUCE — FUNCTION(A, T) AS A. Массивный результат U у функции преобразования не допускается.

Диагностика

  • MB2004 — число аргументов не соответствует форме вызова.
  • MB2003 — тип аргумента несовместим с типом параметра.
  • MB2020 — значение нельзя вызвать.
  • MB2029 — функция с параметром BYREF используется как функциональное значение.
  • MB2040 — отдельная инструкция содержит выражение без вызова, например одиночный литерал или имя.

Пример

FUNCTION DoubleValue(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION

PRINT DoubleValue(7)

Результат:

14
