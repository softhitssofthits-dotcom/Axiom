Выражения

Арифметика и логика

Axiom поддерживает обычную арифметику, сравнения, логические выражения, побитовые операции, сдвиги и шестнадцатеричные литералы. Здесь собраны формы записи, правила типов и подтверждённые примеры поведения.

Сводка

В арифметике доступны +, -, *, /, \, MOD и ^. Для целочисленных типов INTEGER и LONG дополнительно доступны побитовые NOT, AND, OR, XOR, EQV, IMP и сдвиги <<, >>. Литералы вида &HFF задают шестнадцатеричные целые числа.

Части синтаксиса

  • <числовое выражение> — выражение типов INTEGER, LONG, DOUBLE или DECIMAL.
  • <целое выражение> — выражение только типов INTEGER или LONG.
  • <строковое выражение> — выражение типа STRING.
  • <логическое выражение> — выражение типа BOOLEAN.
  • <шестнадцатеричные цифры> — одна или больше цифр 0-9, A-F или a-f.

Арифметика

Числовые операторы

+, - и * работают с числовыми операндами и продвигают тип результата по правилу DOUBLE → DECIMAL → LONG → INTEGER. Смешивать DECIMAL и DOUBLE в одном обычном арифметическом выражении нельзя: такое выражение отвергается ещё на этапе семантического анализа.

Возведение в степень

Оператор ^ возводит левый операнд в степень правого. Он принимает любые числовые операнды, всегда возвращает DOUBLE и связывается справа налево. Поэтому выражение 2 ^ 3 ^ 2 вычисляется как 2 ^ (3 ^ 2), а выражение -2 ^ 2 читается как -(2 ^ 2).

Обычное деление

/ выполняет обычное деление. Если хотя бы один операнд имеет тип DECIMAL и ни один операнд не имеет тип DOUBLE, результат тоже имеет тип DECIMAL. Во всех остальных случаях результат имеет тип DOUBLE.

Целочисленное деление

Целочисленное деление \ работает только с типами INTEGER и LONG, делит левый операнд на правый и отбрасывает дробную часть к нулю. Если хотя бы один операнд имеет тип LONG, результат тоже имеет тип LONG; иначе возвращается INTEGER.

Остаток от деления

Оператор MOD тоже работает только с типами INTEGER и LONG. Тип результата определяется так же, как у \. Знак остатка совпадает со знаком левого операнда, потому что операция следует правилу вычисления, принятому в C#.

Конкатенация строк

Если оба операнда имеют тип STRING, оператор + объединяет их в одну строку.

Шестнадцатеричные литералы

Литерал вида &HFF задаёт неотрицательное целое число в шестнадцатеричной записи. Литерал получает тип INTEGER, если помещается в диапазон INTEGER; иначе, если значение помещается в диапазон LONG, он получает тип LONG. Форма &H без цифр даёт диагностическое сообщение MB0003.

Сравнения

Все операторы сравнения возвращают BOOLEAN. Для чисел поддерживаются все шесть сравнений. Для строк тоже поддерживаются все шесть сравнений, причём упорядочение выполняется по кодам символов без учёта локали. Для BOOLEAN допустимы только = и <>.

Логические и побитовые операторы

NOT, AND, OR, XOR, EQV и IMP работают в двух режимах. С BOOLEAN они выполняют логические операции и возвращают BOOLEAN. С INTEGER и LONG они выполняют побитовые операции. Для бинарных побитовых операций тип результата продвигается до LONG, если хотя бы один операнд имеет тип LONG; иначе результат имеет тип INTEGER.

EQV означает равнозначность: для логических значений результат равен TRUE, когда оба операнда одинаковы. Для целых чисел EQV вычисляет побитовое отрицание результата XOR. IMP означает импликацию: для логических значений результат равен FALSE только в случае TRUE IMP FALSE. Для целых чисел IMP вычисляется как побитовое NOT от левого операнда, затем побитовое OR с правым операндом.

Сдвиги

Операторы << и >> работают только с INTEGER и LONG. Левый операнд задаёт сдвигаемое значение, правый — количество битов для сдвига. Тип результата всегда совпадает с типом левого операнда.

Приоритет

  1. скобки (...);
  2. ^;
  3. унарный - и NOT;
  4. *, /, \, MOD;
  5. +, -;
  6. <<, >>;
  7. сравнения;
  8. AND;
  9. XOR;
  10. OR;
  11. EQV;
  12. IMP.

Примеры

PRINT 2 ^ 3 ^ 2
PRINT &HFF
PRINT 6 AND 3
PRINT 6 XOR 3
PRINT 6 EQV 3
PRINT 6 IMP 3
PRINT 1 + 2 << 1
PRINT "A" + "B"
PRINT 10 > 3 AND NOT FALSE

Диагностика

  • MB0003 — некорректный числовой литерал, например &H без шестнадцатеричных цифр.
  • MB0004 — числовой литерал выходит за диапазон поддерживаемого типа, в том числе слишком большой шестнадцатеричный литерал.
  • MB2003 — оператор применён к несовместимым типам, например 7.5 \ 2, TRUE MOD 2 или TRUE EQV 1.
  • MB3001 — деление на ноль в /, \ или MOD.
  • MB3008 — арифметическое переполнение, в том числе в крайних случаях наподобие деления минимального INTEGER или LONG на -1 и при недопустимом результате ^.
