Раздел

Выражения и операции

Раздел выражений и операций описывает, как Axiom вычисляет значения из литералов, переменных, констант, вызовов функций, полей записей, элементов массивов и операций. Результатом выражения становится число, строка, логическое значение, запись, массив или другое поддержанное значение языка.

Категории операций

В этой главе собраны операции, которые чаще всего встречаются в обычных вычислениях.

  • арифметические операции: +, -, *, /, \, MOD, ^;
  • операции сравнения: =, <>, <, <=, >, >=;
  • логические операции: NOT, AND, OR, XOR, EQV, IMP;
  • побитовые операции и сдвиги для целых чисел;
  • строковые операции: строгое сложение строк через + и построение строки через &.

Синтаксис

<числовое выражение> + <числовое выражение>
<числовое выражение> - <числовое выражение>
<числовое выражение> * <числовое выражение>
<числовое выражение> / <числовое выражение>
<целое выражение> \ <целое выражение>
<целое выражение> MOD <целое выражение>
<числовое выражение> ^ <числовое выражение>
<выражение> = <выражение>
<выражение> <> <выражение>
<выражение> < <выражение>
<выражение> <= <выражение>
<выражение> > <выражение>
<выражение> >= <выражение>
NOT <логическое или целое выражение>
<логическое или целое выражение> AND <логическое или целое выражение>
<логическое или целое выражение> OR <логическое или целое выражение>
<логическое или целое выражение> XOR <логическое или целое выражение>
<логическое или целое выражение> EQV <логическое или целое выражение>
<логическое или целое выражение> IMP <логическое или целое выражение>
<целое выражение> << <целое выражение>
<целое выражение> >> <целое выражение>
<строковое выражение> + <строковое выражение>
<скалярное выражение> & <скалярное выражение>
&H<шестнадцатеричные цифры>

Части записи

  • <числовое выражение> — выражение типов INTEGER, LONG, DOUBLE или DECIMAL.
  • <целое выражение> — выражение типов INTEGER или LONG.
  • <логическое выражение> — выражение типа BOOLEAN.
  • <строковое выражение> — выражение типа STRING.
  • <скалярное выражение> — STRING, INTEGER, LONG, DOUBLE, DECIMAL или BOOLEAN.

Арифметические операции

+, - и * работают с числами и возвращают числовой результат. Если операнды имеют разные числовые типы, Axiom применяет разрешённые расширяющие преобразования. Смешивать DECIMAL и DOUBLE в одном обычном арифметическом выражении нельзя.

/ выполняет обычное деление. Если в выражении участвует DECIMAL и не участвует DOUBLE, результат имеет тип DECIMAL. В остальных случаях результат имеет тип DOUBLE.

\ выполняет целочисленное деление, а MOD возвращает остаток. Эти операции работают только с INTEGER и LONG. Деление на ноль даёт ошибку времени выполнения.

^ возводит левый операнд в степень правого, всегда возвращает DOUBLE и связывается справа налево: 2 ^ 3 ^ 2 вычисляется как 2 ^ (3 ^ 2).

Порядок вычисления

Сначала выполняются операции более высокого приоритета. Скобки позволяют явно изменить порядок вычисления.

  1. скобки (...);
  2. ^;
  3. унарный - и NOT;
  4. *, /, \, MOD;
  5. +, -, &;
  6. <<, >>;
  7. сравнения;
  8. AND, затем XOR, затем OR, затем EQV, затем IMP.
PRINT 3 + 6 / 12 * 3 - 2
PRINT (3 + 6) / (12 * 3 - 2)

Сравнения

Операции сравнения возвращают BOOLEAN. Для чисел поддержаны все шесть сравнений. Для строк также поддержаны все шесть сравнений, и порядок определяется кодами символов. Для BOOLEAN допустимы только = и <>.

PRINT 10 > 3
PRINT "ABC" < "ABD"
PRINT TRUE <> FALSE

Логика и побитовый режим

NOT, AND, OR, XOR, EQV и IMP имеют два режима. С логическими значениями они возвращают BOOLEAN. С целыми числами они работают по битам и возвращают INTEGER или LONG.

EQV означает равнозначность: логический результат равен TRUE, когда оба операнда одинаковы. IMP означает импликацию: TRUE IMP FALSE даёт FALSE, остальные логические сочетания дают TRUE.

PRINT TRUE AND NOT FALSE
PRINT 6 AND 3
PRINT 6 XOR 3
PRINT TRUE IMP FALSE

Сдвиги и шестнадцатеричные числа

<< и >> сдвигают целое значение на указанное число битов. Левый операнд задаёт значение, правый — количество битов. Тип результата совпадает с типом левого операнда.

Литерал вида &HFF задаёт неотрицательное целое число в шестнадцатеричной записи. Если значение помещается в INTEGER, литерал получает тип INTEGER; иначе, если помещается в LONG, получает тип LONG.

Строковые операции

+ объединяет строки только тогда, когда оба операнда имеют тип STRING. Это строгая форма: число или логическое значение нужно преобразовать отдельно либо использовать &.

& строит строку из скалярных значений. Он принимает строки, числа и BOOLEAN, переводит их в текстовый вид, близкий к выводу PRINT, и возвращает STRING.

DIM name AS STRING = "Ada"
DIM age AS INTEGER = 36

PRINT "Name: " + name
PRINT "Age: " & age

В QuickBASIC основная строковая конкатенация обычно записывалась через + и работала со строковыми значениями. В Axiom + для строк тоже строгий, а отдельный & нужен для явного построения строки из смешанных скалярных значений.

Пример вычисления выражений

В примере используются арифметика, сравнение, логика и строковое построение.

DIM x AS INTEGER = 10
DIM y AS INTEGER = 3
DIM ok AS BOOLEAN

ok = x > y AND y > 0

PRINT x \ y
PRINT x MOD y
PRINT "ok=" & ok
PRINT &HFF

Результат:

3
1
ok=TRUE
255

Диагностика

  • MB0003 — некорректный числовой литерал, например &H без цифр.
  • MB0004 — числовой литерал выходит за диапазон поддерживаемого типа.
  • MB2003 — операция применена к несовместимым типам.
  • MB3001 — деление на ноль.
  • MB3008 — арифметическое переполнение или недопустимый результат операции.
