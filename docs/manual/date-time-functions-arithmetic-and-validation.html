Раздел

Арифметика, разбор и проверка

Раздел арифметики, разбора и проверки описывает функции DATEADD, DATEDIFF, DATEPART, DATEVALUE, TIMEVALUE и ISDATE — сдвиг дат, сравнение интервалов, извлечение частей и проверку канонических строк.

DATEADD

Функция DATEADD добавляет к дате, времени или дате-времени указанное число интервалов.

Синтаксис

result = DATEADD(interval, number, value)

Аргументы

interval задаёт токен интервала, number число шагов, а value исходную дату, время или дату-время.

Аргумент value принимает только нативное значение DATE, TIME либо DATETIME — строковые формы не поддерживаются (для получения нативного значения из строки используйте DATESERIAL, TIMESERIAL, DATEVALUE или TIMEVALUE). Функция возвращает нативное значение того же вида: DATE даёт DATE, TIME даёт TIME, DATETIME даёт DATETIME, без промежуточного преобразования в строку.

Единицы прибавления даты и времени

Поддерживаются токены yyyy, q, m, d, h, n, s. Функция сохраняет форму исходного значения: дата остаётся датой, время остаётся временем, дата-время остаётся датой-временем. Интервалы yyyy, q, m и d требуют значения вида DATE или DATETIME, а интервалы h, n и s — значения вида TIME или DATETIME.

Для значения TIME функция DATEADD возвращает время суток: сдвиги h, n и s приводятся к одним суткам. Число интервалов может быть любым значением INTEGER, включая крайние значения. Например, большой сдвиг часов не вызывает переполнение промежуточной длительности. Для DATETIME сохраняется дата; выход за диапазон годов 1–9999 вызывает MB3007.

PRINT DATEADD("h", 2147483647, TIMESERIAL(23, 59, 59)) ' 06:59:59
PRINT DATEADD("h", (-2147483647 - 1), TIMESERIAL(0, 0, 0)) ' 16:00:00

Большой сдвиг времени суток

DATEDIFF

Функция DATEDIFF возвращает разницу между двумя значениями в выбранных интервалах.

Синтаксис

result = DATEDIFF(interval, fromValue, toValue)

Аргументы

interval задаёт единицу измерения, fromValue начальное значение, а toValue конечное. Результат имеет тип LONG.

Аргументы fromValue и toValue принимают только нативные значения DATE, TIME либо DATETIME, причём оба значения должны быть одного вида. Строковые формы не поддерживаются.

Одинаковый временной вид значений

Для интервалов времени h, n и s оба значения должны быть одного временного вида: либо оба временами, либо оба датами-временем. Смешение вида, например вызов DATEDIFF("h", timeValue, dateTimeValue), не проходит проверку типов и завершается ошибкой компиляции вместо молчаливой разности только по времени суток. Для интервалов дат yyyy, q, m и d оба значения должны быть вида DATE или DATETIME.

DATEPART

Функция DATEPART извлекает указанную часть даты или времени по токену.

Синтаксис

result = DATEPART(part, value)

Аргументы

part задаёт требуемую часть, а value принимает только нативное значение DATE, TIME либо DATETIME (строковые формы не поддерживаются). Результат имеет тип INTEGER.

Проверка перед разбором строки

Поддерживаются токены yyyy, q, m, d, y, w, h, n, s. Токены yyyy, q, m, d, y и w требуют значения вида DATE или DATETIME, а токены h, n и s — значения вида TIME или DATETIME.

DATEVALUE и TIMEVALUE

DATEVALUE возвращает дату из строки даты-времени, а TIMEVALUE возвращает время из той же формы записи.

Синтаксис

result = DATEVALUE(value)
result = TIMEVALUE(value)

Аргументы

value задаёт строку даты-времени в каноническом формате. Функция DATEVALUE возвращает значение DATE, а функция TIMEVALUE — значение TIME.

ISDATE

Функция ISDATE проверяет, является ли строка допустимой канонической датой, временем или датой-временем.

Синтаксис

result = ISDATE(value)

Аргументы

value задаёт строку для проверки. Результат имеет тип BOOLEAN.

Пример календарной арифметики и разбора

' Арифметика и разбор нативных значений даты и времени
PRINT DATEADD("m", 1, DATEVALUE("2026-01-31"))
PRINT DATEDIFF("d", DATEVALUE("2026-04-20 23:59:59"), DATEVALUE("2026-04-21 00:00:00"))
PRINT DATEPART("y", DATEVALUE("2026-04-21"))
PRINT DATEVALUE("2026-04-20 14:05:06")
PRINT TIMEVALUE("2026-04-20 14:05:06")
PRINT ISDATE("2026-04-20 14:05:06")

Пример с нативными значениями

' Типизированный стиль: нативные значения без преобразования в строку
DIM d AS DATE = DATESERIAL(2026, 1, 31)
PRINT DATEADD("m", 1, d)                     ' 2026-02-28, результат имеет тип DATE
DIM t AS TIME = TIMESERIAL(14, 5, 59)
PRINT DATEADD("n", 1, t)                     ' 14:06:59, результат имеет тип TIME
DIM dt AS DATETIME = "2026-04-20 23:05:06"
PRINT DATEADD("h", 2, dt)                    ' 2026-04-21 01:05:06, результат имеет тип DATETIME
PRINT DATEDIFF("m", d, DATEADD("m", 2, d))   ' 2
PRINT DATEPART("q", d)                       ' 1

Диагностика

  • Неканонический текст вроде "20.04.2026" считается ошибкой аргумента встроенной функции.
  • Строковые значения для DATEADD, DATEDIFF и DATEPART не принимаются: преобразуйте строки в нативные значения через DATESERIAL, TIMESERIAL, DATEVALUE или TIMEVALUE.
  • Неподдерживаемые токены для DATEADD, DATEDIFF и DATEPART также приводят к ошибке аргумента.
  • Для интервалов времени h, n и s функция DATEDIFF отвергает смешение временного вида значений: если одно значение является временем, а другое датой-временем, вызов не проходит проверку типов (ошибка компиляции MB2003).
  • Для нативных значений функция DATEADD отвергает несовместимую пару интервала и вида значения: интервалы yyyy, q, m, d не работают с TIME, а интервалы h, n, s — с DATE.
  • Функция DATEDIFF с нативными значениями требует, чтобы значения соответствовали виду интервала: для интервалов дат — DATE или DATETIME, для интервалов времени — TIME или DATETIME.
  • Функция DATEPART с нативным значением требует, чтобы значение соответствовало виду запрошенной части: части даты требуют DATE или DATETIME, части времени — TIME или DATETIME.
  • Если вычисление выходит за допустимый диапазон даты или времени, функция завершается диагностикой времени выполнения.

Ручная проверка

  • DATEADD: сдвиг даты
  • DATEADD, DATEDIFF и DATEPART: нативные значения DATE, TIME и DATETIME
  • DATEDIFF: разница между датами
  • DATEDIFF: смешение временного вида значений
  • DATEPART: извлечение части
  • DATEVALUE: дата из даты-времени
  • TIMEVALUE: время из даты-времени
  • ISDATE: проверка канонической строки
