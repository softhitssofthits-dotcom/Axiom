Раздел

Арифметика, разбор и проверка

Раздел арифметики, разбора и проверки описывает функции DATEADD, DATEDIFF, DATEPART, DATEVALUE, TIMEVALUE и ISDATE — сдвиг дат, сравнение интервалов, извлечение частей и проверку канонических строк.

DATEADD

Функция DATEADD добавляет к дате, времени или дате-времени указанное число интервалов.

Синтаксис

result = DATEADD(interval, number, value)

Аргументы

interval задаёт токен интервала, number число шагов, а value исходную дату, время или дату-время.

Единицы прибавления даты и времени

Поддерживаются токены yyyy, q, m, d, h, n, s. Функция сохраняет форму исходной строки: дата остаётся датой, время остаётся временем, дата-время остаётся датой-временем.

DATEDIFF

Функция DATEDIFF возвращает разницу между двумя значениями в выбранных интервалах.

Синтаксис

result = DATEDIFF(interval, fromValue, toValue)

Аргументы

interval задаёт единицу измерения, fromValue начальное значение, а toValue конечное. Результат имеет тип LONG.

DATEPART

Функция DATEPART извлекает указанную часть даты или времени по токену.

Синтаксис

result = DATEPART(part, value)

Аргументы

part задаёт требуемую часть, а value строку даты, времени или даты-времени. Результат имеет тип INTEGER.

Проверка перед разбором строки

Поддерживаются токены yyyy, q, m, d, y, w, h, n, s.

DATEVALUE и TIMEVALUE

DATEVALUE возвращает дату из строки даты-времени, а TIMEVALUE возвращает время из той же формы записи.

Синтаксис

result = DATEVALUE(value)
result = TIMEVALUE(value)

Аргументы

value задаёт строку даты-времени в каноническом формате. Обе функции возвращают строку.

ISDATE

Функция ISDATE проверяет, является ли строка допустимой канонической датой, временем или датой-временем.

Синтаксис

result = ISDATE(value)

Аргументы

value задаёт строку для проверки. Результат имеет тип BOOLEAN.

Пример календарной арифметики и разбора

' Арифметика и разбор канонических значений даты и времени
PRINT DATEADD("m", 1, "2026-01-31")
PRINT DATEDIFF("d", "2026-04-20 23:59:59", "2026-04-21 00:00:00")
PRINT DATEPART("y", "2026-04-21")
PRINT DATEVALUE("2026-04-20 14:05:06")
PRINT TIMEVALUE("2026-04-20 14:05:06")
PRINT ISDATE("2026-04-20 14:05:06")

Диагностика

  • Неканонический текст вроде "20.04.2026" считается ошибкой аргумента встроенной функции.
  • Неподдерживаемые токены для DATEADD, DATEDIFF и DATEPART также приводят к ошибке аргумента.
  • Если вычисление выходит за допустимый диапазон даты или времени, функция завершается диагностикой времени выполнения.

Ручная проверка

  • DATEADD: сдвиг даты
  • DATEDIFF: разница между датами
  • DATEPART: извлечение части
  • DATEVALUE: дата из даты-времени
  • TIMEVALUE: время из даты-времени
  • ISDATE: проверка канонической строки
