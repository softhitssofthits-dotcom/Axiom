Операторы и инструкции

Здесь собраны объявления, инструкции и управляющие конструкции Axiom с точной формой записи; каждая запись ведёт к основному описанию соответствующей формы.

Содержание

Операторы сгруппированы по роли в программе. В перечень включены объявления, управляющие конструкции, ввод и вывод, графика, события, присваивание и вызов как инструкция. Слова завершения блоков и режимы описываются вместе с соответствующим оператором.

DIM

DIM объявляет переменную с заданным или выведенным из выражения типом и устанавливает её начальное значение. В объявлении массива указывается также число измерений; если заданы границы, DIM выделяет элементы.

Описание DIM: синтаксис, параметры и примеры

CONST

Предельное количество, коэффициент расчёта или неизменный заголовок удобно назвать один раз и дальше ссылаться на это имя в выражениях. CONST сохраняет результат выражения под таким именем и запрещает его переписывать.

Описание CONST: синтаксис, параметры и примеры

TYPE

TYPE — оператор языка Axiom, который объявляет пользовательский тип записи с именованными полями. Тип может содержать методы, перегруженные конструкторы и проверку IsValid после конструктора.

Описание TYPE: синтаксис, параметры и примеры

SUB

Вывод отчёта, изменение набора данных, подготовка файла — такие действия часто повторяются в разных местах программы, и их инструкции приходится дублировать. Чтобы этого избежать, действие оформляют как процедуру: SUB объявляет именованный блок инструкций, который выполняется целиком и не возвращает значения.

Описание SUB: синтаксис, параметры и примеры

FUNCTION

Вычисление, которое повторяется в разных местах программы, удобно вынести под отдельное имя и получать его результат как значение. Для этого служит FUNCTION: объявление задаёт параметры и тип результата, а каждый вызов возвращает значение этого типа.

Описание FUNCTION: синтаксис, параметры и примеры

IMPORT

Программа растёт, и её части удобнее держать в отдельных исходных файлах. Чтобы один файл мог пользоваться подпрограммами, типами и данными другого, он подключает его оператором IMPORT: после этого открытые имена зависимости доступны без префикса.

Описание IMPORT: синтаксис, параметры и примеры

PRINT

Когда программе нужно показать сообщение или результат вычисления, она передаёт значения оператору PRINT. Оператор превращает их в текст и помещает в консоль или в окно программы. Форма PRINT USING решает более узкую задачу: раскладывает значения по полям форматной строки, задавая ширину поля и вид числа.

Описание PRINT: синтаксис, параметры и примеры

PRINT USING

Когда программе нужно показать сообщение или результат вычисления, она передаёт значения оператору PRINT. Оператор превращает их в текст и помещает в консоль или в окно программы. Форма PRINT USING решает более узкую задачу: раскладывает значения по полям форматной строки, задавая ширину поля и вид числа.

Описание PRINT USING: синтаксис, параметры и примеры

INPUT

Значение, которое известно только во время работы программы, приходится спрашивать у пользователя. Для этого служит INPUT: он приостанавливает выполнение, показывает запрос, принимает подтверждённую строку и записывает разобранные из неё значения в заранее объявленные переменные. Число получателей, вид приглашения и строгость разбора задаёт сама запись оператора.

Описание INPUT: синтаксис, параметры и примеры

SLEEP

Готовый результат нужно успеть рассмотреть, а интерактивный цикл — не занимать процессор вхолостую. Оператор SLEEP приостанавливает программу на заданное время или до нажатия клавиши; выбор формы зависит от того, нужна ли фиксированная пауза или ожидание ввода.

Описание SLEEP: синтаксис, параметры и примеры

RANDOMIZE

Последовательность RND воспроизводима только тогда, когда генератор стартует из одного и того же состояния. Задать это состояние заново позволяет RANDOMIZE: с числовым аргументом он заменяет зерно генератора, без аргумента оставляет текущее состояние нетронутым.

Описание RANDOMIZE: синтаксис, параметры и примеры

OPEN

Читать файл по строкам, дописывать текст в конец уже существующего или начать его заново с пустого места — для этого мало пути к файлу, нужен сам открытый ресурс. OPEN открывает текстовый файл и связывает его с заранее объявленной переменной FILE; выбранный режим определяет, будет файл читаться, заменяться или дополняться.

Описание OPEN: синтаксис, параметры и примеры

CLOSE

Открытый файл удерживает ресурс и часть записанного текста до тех пор, пока запись не будет завершена. CLOSE закрывает открытый текстовый файл: передаёт в поток накопленные байты и освобождает переменную FILE, после чего её снова можно открыть оператором OPEN.

Описание CLOSE: синтаксис, параметры и примеры

IF

Перед действием часто нужно проверить данные: выполнять ли его вообще и какое из нескольких действий выбрать. IF принимает логическое условие и выполняет ту ветвь, для которой условие истинно. Если действие в каждой ветви одно, хватает одной строки; для нескольких действий и дополнительных проверок служит блочная запись с ELSEIF, ELSE и END IF.

Описание IF: синтаксис, параметры и примеры

SELECT CASE

Когда действие выбирается по одному значению — коду, категории, диапазону или строке, — цепочка сравнений заставляет повторять это значение в каждом условии. SELECT CASE записывает выражение выбора один раз, а ветви CASE перечисляют его варианты: отдельные значения, диапазоны и проверки отношения. Выполняется первая подошедшая ветвь.

Описание SELECT CASE: синтаксис, параметры и примеры

FOR

Если блок нужно выполнить заданное число раз или пройти по числовому диапазону, счётчик и его изменение удобнее поручить самой конструкции. FOR создаёт счётчик, выполняет тело для каждого допустимого значения и на NEXT переходит к следующему; тело заканчивается, когда счётчик выходит за границу в направлении шага. Начало, конец и шаг задаются в заголовке цикла.

Описание FOR: синтаксис, параметры и примеры

WHILE

Повторять блок до тех пор, пока сохраняется нужное состояние данных, позволяет WHILE. Условие стоит в заголовке и проверяется перед каждым проходом, включая первый, поэтому тело выполняется только при истинном условии, а цикл завершается на том проходе, после которого условие стало ложным.

Описание WHILE: синтаксис, параметры и примеры

DO ... LOOP

Место проверки условия иногда важнее самого условия: блок может требовать хотя бы одного выполнения или, наоборот, не выполняться при ложном условии вовсе. DO … LOOP позволяет выбрать, где стоит проверка — в начале, в конце или нигде, — и как она читается: WHILE продолжает повторение при истинном условии, UNTIL завершает его при истинном.

Описание DO ... LOOP: синтаксис, параметры и примеры

EXIT FOR

Повторения иногда нужно прекратить раньше, чем сработает условие цикла: результат уже найден или продолжать вычисление не требуется. EXIT завершает ближайший охватывающий цикл указанного вида и передаёт управление за его окончание. Форм две — EXIT FOR и EXIT DO; каждая действует только в цикле своего вида и не принимает аргументов.

Описание EXIT FOR: синтаксис, параметры и примеры

EXIT DO

Форм две — EXIT FOR и EXIT DO; каждая действует только в цикле своего вида и не принимает аргументов.

Описание EXIT DO: синтаксис, параметры и примеры

CONTINUE FOR

Часть прохода иногда не имеет смысла: данные не подходят под условие обработки, и остаток тела нужно пропустить, не прекращая цикл. CONTINUE передаёт управление к концу текущего прохода, после чего цикл обычным образом переходит к следующему. Форма выбирается по виду цикла — CONTINUE FOR, CONTINUE WHILE или CONTINUE DO.

Описание CONTINUE FOR: синтаксис, параметры и примеры

RETURN

Иногда подпрограмму нужно закончить раньше последней инструкции тела — например, сразу после проверки входного аргумента. Для досрочного выхода из процедуры и для возврата вычисленного результата из функции служит RETURN; вид оператора зависит от того, в каком объявлении он записан.

Описание RETURN: синтаксис, параметры и примеры

TRY

Недоступный файл, аргумент вне допустимого диапазона, деление на ноль — такой отказ не всегда должен останавливать программу. Часто достаточно пропустить неудавшуюся операцию, записать сведения и перейти к следующему шагу. TRY размечает участок, ошибки внутри которого программа обрабатывает сама: блок CATCH получает возникшую ошибку, блок FINALLY выполняет завершающие инструкции.

Описание TRY: синтаксис, параметры и примеры

ERROR

Прикладное условие не всегда совпадает с возможностями операции: данные могут оказаться неполными, состояние — неподходящим. Когда продолжать нельзя, программа сама создаёт отказ оператором ERROR и задаёт ему собственный код, а обработчик получает этот отказ наравне с системными ошибками. Той же формой со значением ERROR можно передать уже полученную ошибку наружу.

Описание ERROR: синтаксис, параметры и примеры

FOR EACH

Когда нужно выполнить действие с каждым элементом массива, индексы и границы не нужны: достаточно назвать массив и переменную, которая получит очередное значение. Форма `FOR EACH` выполняет тело один раз на элемент и сама следит за порядком и границами.

Описание FOR EACH: синтаксис, параметры и примеры

REDIM

Когда размер массива становится известен только при выполнении, границы задают оператором REDIM. Он выделяет хранилище по новым границам и либо создаёт элементы заново, либо сохраняет те из них, чьи индексы остались в новой области.

Описание REDIM: синтаксис, параметры и примеры

Когда размер массива становится известен только при выполнении, границы задают оператором REDIM. Он выделяет хранилище по новым границам и либо создаёт элементы заново, либо сохраняет те из них, чьи индексы остались в новой области.

Описание REDIM PRESERVE: синтаксис, параметры и примеры

ERASE

Когда элементы массива больше не нужны, занимаемое ими хранилище освобождают оператором ERASE. Имя и объявленный тип при этом сохраняются, поэтому массив остаётся в программе, но переходит в невыделенное состояние.

Описание ERASE: синтаксис, параметры и примеры

SCREEN

Пока программа не выбрала экран, её текст идёт в консоль. Оператор SCREEN открывает отдельное окно программы и задаёт его режим: SCREEN 0 даёт текстовую сетку, SCREEN 1..10 — палитровую графику. Тот же оператор выбирает активную и видимую экранные страницы.

Описание SCREEN: синтаксис, параметры и примеры

SMOOTH

Готовый графический кадр часто выводится в область другого размера, и тогда ступенчатые края линий, окружностей, изображений и растрового текста становятся заметны. Оператор SMOOTH включает или отключает сглаживание такого кадра целиком, не меняя ни исходных пикселей, ни координат программы.

Описание SMOOTH: синтаксис, параметры и примеры

CLS

В окне SCREEN текст размещается не свободно, а по ячейкам сетки, и ему можно задать цвет и фон. Для этого служат три оператора: CLS очищает вывод, COLOR задаёт цвет символов и режим фона, LOCATE выбирает ячейку, с которой начнётся следующий текст.
