Имена и области видимости

Раздел «Имена и области видимости» объясняет, как назвать переменную или подпрограмму и в каких частях программы можно обращаться к этому имени.

Запись имени

Имя начинается с латинской буквы или подчёркивания. Затем можно использовать латинские буквы, цифры и подчёркивание. Например, count, total_price и item2 — допустимые имена; 2items и имя с пробелом — недопустимые. Ключевое слово нельзя использовать как пользовательское имя.

Регистр букв не различается: score, Score и SCORE обозначают одно имя. Повторное объявление с другим регистром не создаёт новую переменную. Русский текст допускается в строках и комментариях, но не в пользовательских именах.

Точка в записи point.X отделяет имя переменной от имени поля. Она не является частью имени point. Аналогично запись err.Code обращается к полю значения ошибки.

Область видимости

Область видимости — часть программы, в которой доступно объявленное имя. Имя может быть доступно во всей программе, только в одной подпрограмме или только внутри отдельного блока. Обращение за пределами этой области считается обращением к неизвестному имени.

Переменные верхнего уровня

Переменная, объявленная на верхнем уровне, называется глобальной. Её могут читать и изменять подпрограммы и методы пользовательских типов. При изменении используется та же переменная, которую объявила основная программа.

Перед проверкой тел подпрограмм компилятор собирает глобальные объявления из всего файла. Поэтому подпрограмма может обращаться к глобальной переменной, объявленной ниже её заголовка. Однако начальные значения задаются при выполнении объявлений: порядок выполнения основной программы сохраняет значение.

Параметры и локальные переменные

Параметры и переменные, объявленные внутри SUB или FUNCTION, доступны в соответствующей подпрограмме. Локальные значения создаются для каждого нового вызова. Правила передачи аргументов приведены в статье о вызовах.

Вложенная подпрограмма может обращаться к доступным переменным внешней подпрограммы. Если такая функция сохраняется как значение, она может сохранить доступ к этим переменным после завершения внешнего вызова. Это называется замыканием; подробности находятся в главе процедур и функций.

Область блока

Ветвь IF, цикл и блок обработки ошибок создают свои области видимости. Объявленное внутри имя недоступно после окончания соответствующего блока:

DIM total AS INTEGER = 0
IF TRUE THEN
    DIM part AS INTEGER = 3
    total = total + part
END IF
PRINT total

Программа выводит:

3

Имя total объявлено до IF и остаётся доступным после END IF. Имя part объявлено внутри IF; прочитать его после END IF нельзя.

Счётчик FOR объявляется самим циклом и относится к его области. Конструкция CATCH err объявляет имя err типа ERROR только для чтения. Оно доступно в соответствующем блоке CATCH и вложенных в него блоках, но недоступно в теле TRY, соседнем FINALLY и после END TRY. Предварительный DIM для него не нужен; см. переменную CATCH.

Повторное объявление и поля

Нельзя повторно объявить переменную в той же области или объявить во вложенной области переменную с именем уже доступной внешней переменной. Например, если в программе есть глобальная переменная count, локальной переменной или параметру нужно дать другое имя. Это правило действует и тогда, когда глобальное объявление находится ниже подпрограммы в файле.

Поля пользовательского TYPE принадлежат записи. Снаружи обращение содержит имя получателя, например point.X. Внутри метода собственное поле читается через SELF. Имена полей также не зависят от регистра.

Запускаемые примеры

Примеры можно открыть в IDE и выполнить. Файлы с ожидаемой ошибкой показывают соответствующее сообщение и причину отказа.

  • Регистр имён: большие и маленькие буквы
  • Глобальные и локальные переменные
  • Области блоков IF, SELECT CASE, FOR
  • Процедура видит глобальную переменную, объявленную ниже
  • Предупреждение MB2045: переменная и процедура с одним именем
  • Ошибка: перекрытие имени (MB2016)
  • Ошибка: переменная блока вне блока (MB2001)
  • Ошибка: голое имя поля без SELF (MB2044)
  • Ошибка: опечатка в поле SELF (MB2023 с подсказкой)
  • Ошибка: оператор CALL отсутствует (MB2001 с подсказкой)
