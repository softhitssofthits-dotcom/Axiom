Имена и области видимости

Раздел имён и областей видимости определяет допустимую запись имени и места программы, где доступно объявленное значение.

Запись имени

Первый символ — латинская буква или подчёркивание. Затем допускаются латинские буквы, цифры и подчёркивание. Пробелы, знаки пунктуации и буквы других алфавитов в имени недопустимы. Ключевое слово нельзя использовать как пользовательское имя.

Точка не входит в имя. В выражении err.Code имя переменной — err, а Code — имя поля её значения. Точка разделяет получателя и поле. Поэтому обращение к полю не нарушает правило записи имён. Например, point.X читает поле пользовательской записи, а err.Code — поле встроенного значения ошибки. Подробнее: поля TYPE и поля ERROR.

Регистр букв не различается: score, Score и SCORE обозначают одно имя. Повторное объявление с другим регистром остаётся повторным объявлением. Русский текст можно писать в строках и комментариях.

Глобальная область

Объявленные на верхнем уровне переменные доступны подпрограммам и методам пользовательских типов. Компилятор собирает глобальные объявления до проверки тел подпрограмм, поэтому тело может обратиться к глобальному имени, объявленному ниже в файле. Порядок выполнения инструкций по-прежнему имеет значение для начальных значений.

Чтение и изменение глобальной переменной из процедуры относятся к той же переменной. Не объявляйте локальное имя или параметр, совпадающие с глобальным именем.

Подпрограмма

Параметры и локальные объявления доступны внутри соответствующей процедуры или функции. При новом вызове создаются новые локальные значения. Точные правила передачи аргументов, вложенных подпрограмм и функций как значений находятся в главе процедур.

Вложенная подпрограмма может обращаться к доступным именам охватывающей подпрограммы. Если функция с захваченными переменными сохраняется как значение, захваченные значения могут продолжить существование после завершения внешнего вызова.

Блок

Ветви условий, циклы и блоки обработки ошибок создают собственные области видимости. Имя, объявленное внутри блока, не доступно после его окончания. Счётчик FOR также относится к области своего цикла. Конструкция CATCH err сама объявляет переменную err типа ERROR только для чтения. Она доступна внутри соответствующего блока CATCH, включая вложенные блоки, но недоступна в защищённом теле TRY, в соседнем FINALLY и после END TRY. Отдельное объявление через DIM или CONST не требуется. Правила и пример приведены в статье TRY.

DIM total AS INTEGER = 0
IF TRUE THEN
    DIM part AS INTEGER = 3
    total = total + part
END IF
PRINT total

Результат:

3

После END IF доступно имя total, но имя part уже недоступно.

Перекрытие и поля записи

Нельзя объявить имя заново в той же области или перекрыть доступное имя внешней области. Для разных уровней программы выбирайте разные имена.

Поля TYPE принадлежат записи и используются через получателя, например point.X. В методе собственное поле обозначается через SELF. Регистронезависимость распространяется и на имена полей.

Запускаемые примеры

Откройте нужный файл в IDE и запустите его. Примеры с ошибкой предназначены для проверки сообщения компилятора или выполнения.

  • Регистр имён: большие и маленькие буквы
  • Глобальные и локальные переменные
  • Области блоков IF, SELECT CASE, FOR
  • Процедура видит глобальную переменную, объявленную ниже
  • Предупреждение MB2045: переменная и процедура с одним именем
  • Ошибка: перекрытие имени (MB2016)
  • Ошибка: переменная блока вне блока (MB2001)
  • Ошибка: голое имя поля без SELF (MB2044)
  • Ошибка: опечатка в поле SELF (MB2023 с подсказкой)
  • Ошибка: оператор CALL отсутствует (MB2001 с подсказкой)
