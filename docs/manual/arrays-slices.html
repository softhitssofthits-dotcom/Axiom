Срезы и представления массивов

Раздел срезов и представлений описывает выбор диапазона индексов без ручного копирования элементов — через TO в индексировании или функцию ARRAYSLICE.

Как срез связан с исходным массивом

Обычный срез является представлением: он смотрит на выбранную часть исходного массива. Если изменить элемент через представление, меняется тот же элемент исходного массива. Это удобно для строк, столбцов и прямоугольных областей, но важно помнить, что представление не является независимой копией.

Синтаксис

<представление> = <массив>(<начало> TO <конец>)
<представление> = <массив>(<строка>, <начало> TO <конец>)
<представление> = <массив>(<начало строки> TO <конец строки>, <начало столбца> TO <конец столбца>)

<часть> = ARRAYSLICE(<массив>, <начальный индекс>, <количество>)
<часть> = ARRAYSLICE(<массив>, <начальный индекс>, <количество>, <измерение>)

Части записи

  • <начало> TO <конец> - включительный диапазон индексов в форме индексирования.
  • <строка> - фиксированный индекс первого измерения, если выбирается часть одной строки.
  • <начальный индекс> - первый индекс для ARRAYSLICE.
  • <количество> - сколько элементов или срезов нужно взять.
  • <измерение> - измерение, вдоль которого строится срез в многомерном массиве.

Когда использовать срез

  • Чтобы передать в процедуру только часть массива.
  • Чтобы обработать одну строку, один столбец или прямоугольный блок двумерного массива.
  • Чтобы избежать ручного цикла копирования, когда копия не нужна.
  • Чтобы явно взять участок по началу и длине через ARRAYSLICE.

Операции, которые меняют размер массива, не выполняются через представление для группы ARRAYPUSH, ARRAYPOP, ARRAYINSERT и ARRAYREMOVE. Для изменения размера используйте сам исходный массив.

Пример среза без ручного копирования

' Ожидаемый вывод:
' 20
' 99
DIM board(1 TO 3, 1 TO 4) AS INTEGER
DIM rowPart() AS INTEGER

board(2, 2) = 20
board(2, 3) = 30
board(2, 4) = 40

rowPart = board(2, 2 TO 4)
PRINT rowPart(2)

rowPart(3) = 99
PRINT board(2, 3)
DIM values(1 TO 5) AS INTEGER
DIM part() AS INTEGER

part = ARRAYSLICE(values, 2, 3)

Ручная проверка

  • Представление на прямоугольный диапазон
  • Представление на часть строки
  • ARRAYSLICE: базовое использование
  • ARRAYSLICE: срез по столбцу
