Срезы и представления

Сводка

Срез позволяет взять не весь массив, а только нужную его часть. В Axiom это можно сделать либо формой индексирования с диапазоном, либо явным вызовом ARRAYSLICE.

В обычном случае результатом становится представление, а не независимая копия. Это значит, что срез смотрит на те же данные, что и исходный массив, и изменения через срез видны в исходном массиве.

Синтаксис

view = array(startIndex TO finishIndex)
view = array(rowStart TO rowFinish, columnStart TO columnFinish)
view = array(rowIndex, columnStart TO columnFinish)
part = ARRAYSLICE(array, startIndex, count)
part = ARRAYSLICE(array, startIndex, count, dimension)

Части записи

  • array — исходный массив, из которого выбирается часть данных.
  • startIndex TO finishIndex — включительный диапазон индексов для одномерного среза.
  • rowStart TO rowFinish и columnStart TO columnFinish — диапазоны строк и столбцов для двумерного среза.
  • rowIndex — фиксированный индекс строки, если нужно взять часть одной строки.
  • view — результат индексирования с диапазоном. Обычно это представление на часть исходного массива.
  • startIndex — индекс первого элемента или первого среза для ARRAYSLICE.
  • count — сколько элементов или срезов нужно взять через ARRAYSLICE.
  • dimension — измерение, вдоль которого строится срез в многомерном массиве.

Замечания

  • Представление не создаёт независимую копию данных. Если изменить элемент через представление, изменится и исходный массив.
  • Срез полезен, когда нужно передать в вычисление только часть массива или работать с отдельной строкой, столбцом либо прямоугольным блоком.
  • Если нужна именно копия, используйте ARRAYCLONE или создайте новый массив отдельно.
  • Операции, меняющие размер массива, не выполняются через представление для группы ARRAYPUSH, ARRAYPOP, ARRAYINSERT и ARRAYREMOVE.
  • ARRAYSLICE полезна там, где нужен явный вызов функции, например при передаче результата как аргумента или когда удобнее задавать начало и длину, а не границы диапазона.

Пример

' Программа берёт часть второй строки и меняет элемент через представление
' Ожидаемый вывод:
' 20
' 99
DIM board(1 TO 3, 1 TO 4) AS INTEGER
DIM rowPart() AS INTEGER

board(2, 2) = 20
board(2, 3) = 30
board(2, 4) = 40

rowPart = board(2, 2 TO 4)
PRINT rowPart(2)

rowPart(3) = 99
PRINT board(2, 3)
' Тот же участок можно взять явным вызовом ARRAYSLICE
DIM values(1 TO 5) AS INTEGER
DIM part() AS INTEGER

part = ARRAYSLICE(values, 2, 3)

Ручная проверка

  • Представление на прямоугольный диапазон
  • Представление на часть строки
