Базовые числовые функции

На этой странице собраны функции общего назначения, которые чаще всего нужны в вычислениях: модуль числа, определение знака, выбор минимального и максимального значения, ограничение диапазона, перенос знака и генерация псевдослучайного числа.

ABS

Функция ABS возвращает модуль числа.

Синтаксис

result = ABS(value)

Части записи. value задаёт числовое выражение. Результат имеет тот же числовой тип, что и исходное значение.

Пример

' Модуль числа всегда неотрицателен
PRINT ABS(-18)
PRINT ABS(3.25)

RND

Функция RND возвращает псевдослучайное число типа DOUBLE.

Синтаксис

result = RND()

Замечания

Функция вызывается без аргументов. Результат лежит в диапазоне от 0 включительно до 1 не включительно. Если нужно получить число в другом диапазоне, обычно результат RND() масштабируют обычными арифметическими операциями.

Пример

' Получение значения в диапазоне от 1 до 10
DIM value AS INTEGER

value = INT(RND() * 10) + 1
PRINT value

SGN

Функция SGN определяет знак числа.

Синтаксис

result = SGN(value)

Части записи. value задаёт числовое выражение. Результат имеет тип INTEGER и равен -1, 0 или 1.

Пример

' Определение знака трёх значений
PRINT SGN(-9)
PRINT SGN(0)
PRINT SGN(9)

MIN

Функция MIN возвращает меньшее из двух чисел.

Синтаксис

result = MIN(left, right)

Части записи. left и right задают сравниваемые числовые выражения. Если аргументы имеют разные числовые типы, язык приводит их к общему числовому типу.

Пример

' Выбор меньшего значения
PRINT MIN(8, 3)
PRINT MIN(2.5, 7)

MAX

Функция MAX возвращает большее из двух чисел.

Синтаксис

result = MAX(left, right)

Части записи. left и right задают сравниваемые числовые выражения. Возвращаемый тип определяется по тем же правилам, что и у MIN.

Пример

' Выбор большего значения
PRINT MAX(8, 3)
PRINT MAX(2.5, 7)

CLAMP

Функция CLAMP ограничивает значение заданным диапазоном.

Синтаксис

result = CLAMP(value, low, high)

Части записи. value задаёт исходное число. low задаёт нижнюю границу, а high верхнюю. Если value меньше нижней границы, возвращается low; если больше верхней, возвращается high.

Замечания

Нижняя граница не должна быть больше верхней. Если диапазон задан неверно, выполнение завершается диагностикой времени выполнения.

Пример

' Ограничение значения диапазоном от 0 до 100
PRINT CLAMP(-5, 0, 100)
PRINT CLAMP(45, 0, 100)
PRINT CLAMP(120, 0, 100)

SETSIGN

Функция SETSIGN переносит знак второго аргумента на первый.

Синтаксис

result = SETSIGN(value, signFrom)

Части записи. value задаёт число, модуль которого нужно сохранить. signFrom задаёт источник знака. Результат возвращается в числовом типе первого аргумента.

Пример

' Знак второго аргумента переносится на первый
PRINT SETSIGN(12, -5)
PRINT SETSIGN(-12, 5)

Замечания

  • ABS, CLAMP и SETSIGN сохраняют тип первого аргумента, если это возможно по правилам языка.
  • MIN и MAX удобно использовать в выражениях, где не хочется писать отдельный IF только ради выбора одного из двух чисел.
  • RND не принимает параметров. Форма вроде RND(1) в Axiom не поддерживается.

Ручная проверка

  • ABS: модуль числа
  • RND: случайное число
  • SGN: знак числа
  • MIN: меньшее из двух чисел
  • MAX: большее из двух чисел
  • CLAMP: ограничение диапазона
  • CLAMP: неверные границы
  • SETSIGN: перенос знака
