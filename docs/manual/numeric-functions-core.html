Раздел

Базовые числовые функции

Раздел базовых числовых функций описывает средства ABS, SGN, MIN, MAX, CLAMP, SETSIGN и RND — модуль числа, определение знака, выбор значения, ограничение диапазона, перенос знака и генерация псевдослучайного числа.

ABS

Функция ABS возвращает модуль числа.

Синтаксис

result = ABS(value)

Аргументы

value задаёт числовое выражение. Результат имеет тот же числовой тип, что и исходное значение.

Пример модуля числа

' Модуль числа всегда неотрицателен
PRINT ABS(-18)
PRINT ABS(3.25)

Результат:

18
3.25

RND

RND — встроенная функция языка Axiom, которая возвращает псевдослучайное число типа DOUBLE. Функция работает в любом режиме программы и не требует оператора SCREEN. Оператор RANDOMIZE позволяет повторить последовательность при одинаковом зерне.

Синтаксис

result = RND()

Случайное число от нуля до единицы

Функция вызывается без аргументов. Результат лежит в диапазоне от 0 включительно до 1 не включительно. Если нужно получить число в другом диапазоне, обычно результат RND() масштабируют обычными арифметическими операциями.

Пример случайного целого числа

' Получение значения в диапазоне от 1 до 10
DIM value AS INTEGER

value = INT(RND() * 10) + 1
PRINT value

Широкий целый диапазон

Формула INT(RND()*(high-low+1))+low требует, чтобы вычисление ширины не переполняло свой целый тип и результат INT помещался в INTEGER. Например, полный диапазон INTEGER имеет ширину 4294967296, которая в INTEGER не помещается. INT всегда возвращает INTEGER, даже если его аргумент был DOUBLE или LONG.

Для полного диапазона INTEGER можно хранить границы и ширину в LONG, округлить произведение функцией FLOOR и преобразовать смещение через CLNG до сложения:

DIM low AS LONG = -2147483648
DIM high AS LONG = 2147483647
DIM width AS LONG = high-low+1
RANDOMIZE 42
DIM value AS LONG = CLNG(FLOOR(RND()*width))+low
PRINT value >= low AND value <= high

Если нижняя граница превышает точность целых чисел DOUBLE, порядок преобразования особенно важен: CLNG(FLOOR(RND()*width))+low прибавляет границу в LONG. Выражение CLNG(FLOOR(RND()*width)+low) сначала выполняет сложение в DOUBLE и может потерять соседнее целое значение.

Ограничения и диагностика

Пример не является общим решением для всех пар LONG. Ширина полного LONG-диапазона не помещается в LONG. Переполнение при вычислении ширины, выход результата INT за INTEGER или результата CLNG за LONG дают MB3008.

Преобразование через умножение и округление не доказывает строго одинаковые вероятности целых результатов. RND выдаёт представимые значения DOUBLE, а не непрерывный источник. Например, восемь равновероятных входов 0, 1/8, ..., 7/8 при умножении на 3 и применении INT распределяются по трём значениям в пропорции 3:3:2. Это иллюстрация на заданном источнике, а не утверждение о частотах текущего генератора.

Запускаемая программа: long_range_conversion.axm. Она проверяет границы результата и повторный посев. См. также оператор RANDOMIZE.

SGN

Функция SGN определяет знак числа.

Синтаксис

result = SGN(value)

Аргументы

value задаёт числовое выражение. Результат имеет тип INTEGER и равен -1, 0 или 1.

Пример знака числа

' Определение знака трёх значений
PRINT SGN(-9)
PRINT SGN(0)
PRINT SGN(9)

Результат:

-1
0
1

MIN

Функция MIN возвращает меньшее из двух чисел.

Синтаксис

result = MIN(left, right)

Аргументы

left и right задают сравниваемые числовые выражения. Если аргументы имеют разные числовые типы, язык приводит их к общему числовому типу.

Пример меньшего и большего значения

' Выбор меньшего значения
PRINT MIN(8, 3)
PRINT MIN(2.5, 7)

Результат:

3
2.5

MAX

Функция MAX возвращает большее из двух чисел.

Синтаксис

result = MAX(left, right)

Аргументы

left и right задают сравниваемые числовые выражения. Возвращаемый тип определяется по тем же правилам, что и у MIN.

Пример большего значения

' Выбор большего значения
PRINT MAX(8, 3)
PRINT MAX(2.5, 7)

Результат:

8
7

CLAMP

Функция CLAMP ограничивает значение заданным диапазоном.

Синтаксис

result = CLAMP(value, low, high)

Аргументы

value задаёт исходное число. low задаёт нижнюю границу, а high верхнюю. Если value меньше нижней границы, возвращается low; если больше верхней, возвращается high.

Нижняя граница не выше верхней

Нижняя граница не должна быть больше верхней. Если диапазон задан неверно, выполнение завершается диагностикой времени выполнения.

Пример ограничения диапазоном

' Ограничение значения диапазоном от 0 до 100
PRINT CLAMP(-5, 0, 100)
PRINT CLAMP(45, 0, 100)
PRINT CLAMP(120, 0, 100)

Результат:

0
45
100

SETSIGN

SETSIGN — встроенная функция языка Axiom, которая переносит знак второго аргумента на первый. Функция нужна, когда величина и направление вычислены отдельно; она работает в BytecodeVm без экранного или файлового режима.

Синтаксис

result = SETSIGN(value, signFrom)

Аргументы

value задаёт число, модуль которого нужно сохранить. signFrom задаёт источник знака. Результат возвращается в числовом типе первого аргумента.

Правила и диагностика

Оба аргумента должны быть числовыми. Тип результата совпадает с типом value; signFrom задаёт только знак. Для DOUBLE учитывается знак нуля: SETSIGN(3, -0.0) возвращает -3, SETSIGN(3, 0.0) возвращает 3. При обычном сравнении эти два нуля равны. SGN(-0.0) возвращает 0, потому что определяет отношение к нулю, а не переносит знак.

Если положительный модуль не помещается в тип value, функция выдаёт MB3008. Например, SETSIGN(-2147483647 - 1, 1) не помещается в INTEGER; SETSIGN(-2147483647 - 1, -1) сохраняет исходное минимальное значение. Ошибку можно перехватить оператором TRY/CATCH. Неверный тип аргумента отклоняется до исполнения.

DIM positive AS DOUBLE = 0.0
DIM negative AS DOUBLE = -0.0
PRINT SETSIGN(3, positive)  ' 3
PRINT SETSIGN(3, negative)  ' -3
PRINT SGN(negative)        ' 0

Запускаемый пример: Знак нуля и перенос знака.

Пример переноса знака

' Знак второго аргумента переносится на первый
PRINT SETSIGN(12, -5)
PRINT SETSIGN(-12, 5)

Результат:

-12
12

Тип результата и область применения

  • ABS и SETSIGN сохраняют тип первого аргумента. Для MIN, MAX и CLAMP аргументы приводятся к общему числовому типу по правилам продвижения типов; результат имеет этот общий тип.
  • MIN и MAX удобно использовать в выражениях, где не хочется писать отдельный IF только ради выбора одного из двух чисел.
  • RND не принимает параметров. Форма вроде RND(1) в Axiom не поддерживается.

Запускаемые примеры

  • ABS: модуль числа
  • RND: случайное число
  • SGN: знак числа
  • MIN: меньшее из двух чисел
  • MAX: большее из двух чисел
  • CLAMP: ограничение диапазона
  • CLAMP: неверные границы
  • SETSIGN: перенос знака
