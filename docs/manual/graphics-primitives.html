Операторы и функция

PSET, PRESET, LINE, CIRCLE и POINT

Графические примитивы работают с пиксельным слоем активного SCREEN. Они используют координаты x, y с началом в левом верхнем углу и цвета из индексной палитры 0..255.

Оператор PSET

PSET (x, y)[, color]

PSET устанавливает один пиксель. Если цвет не указан, используется 15. Координаты вне поверхности игнорируются без ошибки.

SCREEN 1
PSET (10, 10), 12
PRINT POINT(10, 10)
SCREEN 0

Оператор PRESET

PRESET (x, y)[, color]

PRESET использует тот же синтаксис, что и PSET, но без явного цвета ставит цвет 0. Это удобно для стирания отдельного пикселя на обычном чёрном фоне.

SCREEN 1
PSET (10, 10), 12
PRESET (10, 10)
PRINT POINT(10, 10)
SCREEN 0

Оператор LINE

LINE (x1, y1)-(x2, y2)[, color]
LINE (x1, y1)-(x2, y2)[, color], B
LINE (x1, y1)-(x2, y2)[, color], BF

LINE рисует отрезок между двумя точками. Если цвет не указан, используется 15. Суффикс B рисует прямоугольную рамку по двум углам, а BF рисует заполненный прямоугольник.

SCREEN 3
LINE (20, 20)-(220, 80), 10
LINE (30, 100)-(180, 160), 11, B
LINE (220, 100)-(360, 180), 11, BF
SCREEN 0

Оператор CIRCLE

CIRCLE (x, y), radius[, color]

CIRCLE рисует окружность с центром в точке x, y. Радиус задаётся в пикселях. Если цвет не указан, используется 15; отрицательный радиус не рисует пиксели.

SCREEN 3
CIRCLE (420, 160), 50, 14
SCREEN 0

Функция POINT

POINT(x, y)

POINT возвращает цветовой индекс пикселя в указанной точке. Если точка находится вне активной поверхности, результат равен 0. Без активного SCREEN функция сообщает MB3010.

SCREEN 1
PSET (10, 10), 12
PRINT "POINT(10,10)="; POINT(10, 10)
SCREEN 0

Цвета

Все примитивы используют палитру 0..255. Индексы 0..15 совместимы с классическими BASIC-цветами, 16..231 образуют RGB-куб 6x6x6, а 232..255 дают серую шкалу. Значения вне диапазона приводятся по правилу ABS(color) MOD 256.
