Оператор DRAW

DRAW <строковое_выражение>

DRAW читает строку графических команд и выполняет её из текущей графической позиции. Эта форма пришла из BASIC-линейки как компактный макроязык рисования: одна строка может последовательно менять цвет, масштаб, угол, двигать текущую точку, рисовать линии и запускать заливку.

В Axiom текущая графическая позиция для DRAW общая с PSET, PRESET, LINE, CIRCLE, PAINT и предыдущими вызовами DRAW. Поэтому оператор естественно продолжает уже начатый рисунок, а не заводит отдельное внутреннее состояние.

КомандаЧто делает
U n, D n, L n, R nПеремещение вверх, вниз, влево и вправо. Если длина не указана, используется 1.
E n, F n, G n, H nДиагональные перемещения: вверх-вправо, вниз-вправо, вниз-влево и вверх-влево.
BСледующая команда движения или M переносит текущую позицию без рисования.
NСледующая команда движения или M выполняется и затем возвращает текущую позицию в исходную точку.
C nЛокальный цвет линий внутри текущей DRAW-строки.
S nМасштаб. По умолчанию используется 4, а фактическая длина directional-команды считается как n * scale / 4.
A nПоворот на 0, 90, 180 или 270 градусов через значения 0..3.
TA nПроизвольный угол в градусах. Последняя команда A или TA задаёт текущее направление.
M x,yАбсолютное перемещение к экранной точке x,y с рисованием линии.
M +dx,+dyОтносительное перемещение от текущей графической позиции.
P f, P f,bЗаливка из текущей графической позиции через тот же host-контракт, что и отдельный PAINT.

Команды не чувствительны к регистру и допускают пробелы внутри строки. Форма B и N может сочетаться: например, BNR10 переносит позицию вправо без рисования и затем возвращает её назад.

Историческая QuickBASIC-форма X с VARPTR$ в Axiom не поддерживается по проектному решению. Вместо неё нужно собрать итоговую DRAW-строку обычными строковыми выражениями Axiom и передать результат в DRAW.

SCREEN 1
DRAW "R50 D50 L50 U50"

DIM commands$ AS STRING = "C12 TA90 U60 R20"
DRAW commands$

DIM color AS INTEGER = 10
DIM angle AS INTEGER = 45
DRAW "C" + STR$(color) + " TA" + STR$(angle) + " U40"

Готовые запускаемые примеры: samples/operators/draw/square.axm, octagon.axm, blind_and_return.axm, rotated_spokes.axm, paint_segments.axm и dynamic_string.axm.
