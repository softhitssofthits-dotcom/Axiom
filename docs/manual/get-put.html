Операторы GET и PUT

GET и PUT — операторы языка Axiom, которые переносят прямоугольный блок пикселей между графическим экраном SCREEN и обычным двумерным числовым массивом. Оператор GET читает блок с экрана в массив, а оператор PUT возвращает содержимое массива обратно на экран.

Для чего нужны операторы GET и PUT

Операторы GET и PUT нужны тогда, когда программе требуется сохранить часть экрана, временно убрать её, перенести в другое место или наложить на экран разными способами.

Эти операторы относятся к историческому графическому пути SCREEN. Они не работают с современным холстом CANVAS.

Где работают операторы GET и PUT

Операторы GET и PUT работают только после выбора графического режима SCREEN 1..10.

Если программа не вызвала оператор SCREEN или если программа находится в режиме SCREEN 0, операторы GET и PUT не получают подходящего графического экрана.

Синтаксис оператора GET

GET (x1, y1)-(x2, y2), buffer
GET STEP (x1, y1)-STEP (x2, y2), buffer

Оператор GET читает прямоугольник экрана и записывает его в двумерный массив.

Синтаксис оператора PUT

PUT (x, y), buffer
PUT (x, y), buffer, PSET
PUT (x, y), buffer, PRESET
PUT (x, y), buffer, AND
PUT (x, y), buffer, OR
PUT (x, y), buffer, XOR

Оператор PUT берёт прямоугольный блок из двумерного массива и рисует его на экране.

Что такое buffer

В Axiom буфер операторов GET и PUT — это обычный двумерный числовой массив. Это не скрытый packed-формат старых видеорежимов.

Первая размерность массива задаёт ширину блока по оси X, а вторая размерность массива задаёт высоту блока по оси Y.

Буфер может быть массивом или двумерным представлением массива. Допустимы числовые элементы типов INTEGER, LONG, DOUBLE и DECIMAL.

Параметры оператора GET

ПараметрОписание
x1, y1Первая вершина прямоугольника чтения.
x2, y2Вторая вершина прямоугольника чтения.
STEPСлово STEP означает, что координаты задаются как смещение от текущей графической позиции.
bufferДвумерный числовой массив, в который оператор GET записывает пиксели.

Параметры оператора PUT

ПараметрОписание
x, yЛевый верхний угол блока, который оператор PUT выводит на экран.
bufferДвумерный числовой массив, из которого оператор PUT читает пиксели.
PSET, PRESET, AND, OR, XORСпособ наложения буфера на текущие пиксели экрана.

Если программа не указала действие, оператор PUT использует действие XOR.

Что делают действия PUT

ДействиеРезультат
PSETЭкранный пиксель получает нормализованное значение из буфера без учёта прежнего цвета.
PRESETЭкранный пиксель получает значение 255 - source после нормализации значения буфера.
ANDНовый цвет равен destination AND source.
ORНовый цвет равен destination OR source.
XORНовый цвет равен destination XOR source.

Правила работы

Операторы GET и PUT используют текущий экранный договор SCREEN, а также текущие договоры VIEW и WINDOW, если программа их включила.

Оператор GET читает именно видимые экранные значения выбранной активной страницы, а не исходные полноцветные данные из IMAGE или SPRITE.

Оператор PUT пишет блок на активную страницу экрана.

Если часть прямоугольника выходит за границы экрана, результат обрезается по границе доступной области.

Диагностика

  • MB3010: оператор GET или оператор PUT вызваны без активного графического режима SCREEN 1..10.
  • MB3007: буфер имеет неподходящую форму, неподходящий тип элементов или оператор получил недопустимые координаты.

Пример

SCREEN 1
DIM block(0 TO 31, 0 TO 31) AS INTEGER

LINE (20, 20)-(51, 51), 14, BF
GET (20, 20)-(51, 51), block
PUT (80, 20), block, XOR
SLEEP
