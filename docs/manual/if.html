Оператор IF

IF — оператор языка Axiom, который выбирает блок инструкций по логическому условию. Ветви ELSEIF задают дополнительные проверки, а ELSE — действие при отсутствии истинного условия.

Назначение и контекст

Оператор работает на верхнем уровне программы и внутри подпрограмм и блоков, в консольной и графической программе. Специальный графический режим не требуется.

Используйте оператор для проверки данных перед действием или выбора между несколькими условиями. Условие должно иметь тип BOOLEAN; число само по себе не служит логическим условием.

Синтаксис

IF <логическое выражение> THEN
    [<операторы>]
[ELSEIF <логическое выражение> THEN
    [<операторы>]]
[ELSE
    [<операторы>]]
END IF

Части конструкции

THEN завершает запись условия. Логическое выражение задаёт проверяемое условие и должно вернуть BOOLEAN. Операторы обозначают ноль или несколько инструкций выбранной ветви. Далее на отдельных строках расположен блок инструкций. Можно добавить несколько ветвей ELSEIF и одну завершающую ветвь ELSE. Блочная конструкция заканчивается END IF.

Выбор ветви

Условия проверяются сверху вниз. Первое значение TRUE выбирает соответствующий блок; остальные условия и блоки пропускаются. Если все условия ложны, выполняется ELSE. Без ELSE программа продолжает работу после END IF.

Каждая ветвь образует собственную область видимости. Объявленные в ней имена недоступны после завершения ветви. Внутри ветви допускается другой блок IF.

Диагностика

  • MB2008 — условие после IF или ELSEIF не имеет тип BOOLEAN.
  • MB2001 — имя, объявленное внутри ветви, используется после выхода из области видимости.
  • MB1005 — в конструкции IF допускается только один блок ELSE.

Пример

Для значения семь выбирается вторая ветвь:

DIM value AS INTEGER = 7
IF value > 10 THEN
    PRINT "Большое"
ELSEIF value > 5 THEN
    PRINT "Среднее"
ELSE
    PRINT "Малое"
END IF

Результат:

Среднее
