Управление выполнением

Оператор IF

Оператор IF нужен там, где программа должна принять решение по логическому условию и выбрать одну из нескольких ветвей. Это самая прямая форма условного управления выполнением в Axiom: сначала вычисляется условие, затем выполняется только подходящая ветвь.

Сводка

Оператор IF используется, когда программа должна выполнить один набор инструкций при истинном условии и другой набор инструкций при ложном. Если вариантов больше двух, к основной ветви добавляют ELSEIF и ELSE.

Синтаксис

IF condition THEN
    [statements]
END IF
IF condition THEN
    [statements]
    [ELSEIF anotherCondition THEN
        [elseifStatements]] ...
    [ELSE
        [elseStatements]]
END IF

Части записи

condition и anotherCondition — логические выражения, которые проверяет оператор IF.

statements, elseifStatements и elseStatements — одна или несколько инструкций внутри соответствующей ветви.

Замечания

Обычно IF выбирают, когда условие читается естественно как последовательность проверок сверху вниз и когда число вариантов невелико либо сами варианты различаются не только значением, но и логикой проверки.

  • Условие после IF и после каждого ELSEIF должно иметь тип BOOLEAN.
  • Проверки ветвей IF и ELSEIF идут сверху вниз. Как только найдена первая истинная ветвь, остальные больше не рассматриваются.
  • Ветвь ELSE выполняется только тогда, когда ни одно предыдущее условие не оказалось истинным.
  • Блочная форма IF ... END IF является основной документируемой формой Axiom.
  • Каждая ветвь образует собственную блочную область видимости. Имя, объявленное внутри ветви, недоступно после END IF.

Пример

DIM score AS INTEGER = 82

IF score >= 90 THEN
    PRINT "Отлично"
ELSEIF score >= 70 THEN
    PRINT "Хорошо"
ELSE
    PRINT "Нужно доработать"
END IF

Ручная проверка

  • IF: базовая ветвь ELSE
  • IF: цепочка ELSEIF
  • Блочная область видимости

Диагностика

Если в условии используется выражение, которое не даёт логический результат, выполнение завершается диагностикой, связанной с неверным типом условия. Ошибки области видимости возможны, если имя, объявленное внутри ветви, используется уже после END IF.
