Оператор IF

IF — оператор языка Axiom, который выполняет один блок инструкций или другой блок инструкций в зависимости от значения логического выражения. С помощью оператора IF программа переходит от простого последовательного выполнения к условному ветвлению.

Когда использовать IF

Оператор IF используется, когда дальнейшие действия программы зависят от условия. Условие вычисляется как значение типа BOOLEAN: если оно истинно, выполняется ветвь THEN; если ложно, Axiom проверяет следующие ветви ELSEIF или переходит к ветви ELSE.

Когда проверяется одно условие или небольшая цепочка связанных условий, IF обычно читается проще всего. Если же нужно выбрать один вариант из набора значений одного выражения, часто удобнее использовать SELECT CASE.

Синтаксис

IF <логическое выражение> THEN
    [<операторы>]
[ELSEIF <логическое выражение> THEN
    [<операторы>]]
[ELSE
    [<операторы>]]
END IF

Параметры и части синтаксиса

  • <логическое выражение> — выражение типа BOOLEAN, которое определяет, выполняется ли соответствующая ветвь.
  • THEN отделяет условие от блока операторов, выполняемого при истинном значении условия.
  • ELSEIF задаёт дополнительное условие. Таких ветвей может быть несколько.
  • ELSE задаёт блок операторов для случая, когда ни одно предыдущее условие не оказалось истинным.
  • END IF завершает блочную конструкцию.

Как условие выбирает ветвь

Axiom сначала вычисляет условие после IF. Если оно имеет значение TRUE, выполняются операторы первой ветви, а остальные ветви пропускаются.

Если первое условие имеет значение FALSE, Axiom последовательно проверяет ветви ELSEIF сверху вниз. При первом истинном условии выполняется соответствующий блок, после чего управление передаётся на оператор, следующий за END IF.

Если ни одно условие не истинно, выполняется ветвь ELSE. Если ветвь ELSE отсутствует, оператор IF завершается без выполнения какого-либо блока.

Порядок проверки ветвей

  • В Axiom условие IF должно иметь тип BOOLEAN.
  • Документируемая форма оператора — блочная форма с обязательным завершением END IF.
  • Ветви ELSEIF и ELSE необязательны.
  • Каждая ветвь образует собственную блочную область видимости. Имя, объявленное внутри ветви, недоступно после END IF.
  • Блоки IF можно вкладывать друг в друга, если внутренняя проверка относится только к одной ветви внешнего условия.

Такая форма не является правилом IF: числовое выражение нужно явно сравнить или преобразовать так, чтобы результатом стало значение BOOLEAN.

Диагностика

  • MB2008 — условие после IF или ELSEIF не имеет тип BOOLEAN.
  • MB2001 — имя, объявленное внутри ветви, используется после выхода из области видимости.
  • MB1005 — в конструкции IF допускается только один блок ELSE.

Пример выбора ветви

В этом примере проверяется значение переменной value. Первое условие ложно, второе истинно, поэтому выполняется только ветвь ELSEIF.

DIM value AS INTEGER = 7

IF value > 10 THEN
    PRINT "большой"
ELSEIF value > 5 THEN
    PRINT "средний"
ELSE
    PRINT "маленький"
END IF

Результат:

средний
