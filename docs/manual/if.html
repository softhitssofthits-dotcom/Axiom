Оператор IF

IF позволяет выполнить одни инструкции при истинном условии и другие при ложном. Это базовый оператор ветвления, с которого обычно начинают знакомство с управлением потоком выполнения программы.

Общая форма оператора

IF <условие> THEN
    <инструкции>
END IF
IF <условие> THEN
    <инструкции>
[ELSEIF <другое условие> THEN
    <инструкции>]
...
[ELSE
    <инструкции>]
END IF

Если выражение условия истинно, интерпретатор выполняет код между THEN и END IF. Если условие ложно, этот блок пропускается или управление переходит к следующей ветви.

DIM score AS INTEGER = 82

IF score >= 70 THEN
    PRINT "Зачет получен"
END IF

Части синтаксиса

  • <условие> — логическое выражение, которое определяет, выполнять ли ветвь THEN.
  • <другое условие> — дополнительное логическое выражение для ветви ELSEIF.
  • <инструкции> — блок инструкций внутри соответствующей ветви.
  • [ELSEIF ...] и [ELSE ...] — необязательные части конструкции.

Ветви ELSEIF и ELSE

Когда нужно выбрать один вариант из нескольких, в оператор IF добавляют ветви ELSEIF и ELSE.

IF score >= 90 THEN
    PRINT "Отлично"
ELSEIF score >= 70 THEN
    PRINT "Хорошо"
ELSE
    PRINT "Нужно доработать"
END IF

Проверки читаются сверху вниз. Как только находится первая истинная ветвь, остальные уже не рассматриваются.

Важно

В текущей спецификации и реализации Axiom документируется именно блочная форма IF. Однострочный вариант вида IF x > 0 THEN PRINT x не считается основной формой языка.

Область видимости внутри IF

Ветка IF образует собственный блок. Переменная, объявленная внутри него, существует только в пределах этой ветви.

IF TRUE THEN
    DIM message AS STRING = "Внутри блока"
    PRINT message
END IF

' После END IF имя message уже недоступно

Это правило важно помнить, иначе легко получить ошибку при обращении к имени уже после выхода из блока.

Показательные примеры

  • IF: базовая ветвь ELSE
  • IF: цепочка ELSEIF
  • Блочная область видимости
  • Ошибка: условие должно быть логическим

Что важно помнить

  • после IF должно стоять логическое условие;
  • блок всегда должен закрываться через END IF;
  • ELSEIF и ELSE являются необязательными;
  • если условий много и все они сравнивают одно и то же выражение, удобнее может быть SELECT CASE.

Краткий итог

IF в одном абзаце

  • IF выбирает ветвь по условию;
  • ELSEIF добавляет дополнительные проверки;
  • ELSE служит запасной ветвью;
  • локальные имена внутри ветвей не видны после END IF.
