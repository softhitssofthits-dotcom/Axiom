Типы данных

TYPE, массивы и групповые объявления

Помимо встроенных базовых типов Axiom поддерживает пользовательские записи через TYPE. Массивы строятся поверх типа элемента, а AS <тип> относится ко всей ближайшей группе имён.

Пользовательские записи TYPE

TYPE ... END TYPE объявляет новый тип записи с именованными полями. Переменная такого типа объявляется через DIM name AS TypeName, а поля читаются и записываются через точку: name.Field.

Внутри TYPE не пишутся обычные операторы программы. Тело записи состоит только из объявлений полей и их типов.

TYPE Person
    Name AS STRING
    Age AS INTEGER
END TYPE

DIM user AS Person
user.Name = "Алиса"
user.Age = 30

Подробнее синтаксис и ограничения описаны на странице Оператор TYPE.

Групповые объявления

  • AS <тип> относится ко всей ближайшей группе имён слева до начала оператора DIM или до предыдущего разделителя групп.
  • Форма DIM left, right AS BOOLEAN объявляет обе переменные как BOOLEAN.
  • Форма DIM total = 10 выводит тип как INTEGER, а DIM price = 1.5 выводит тип как DOUBLE.

Массивы как тип поверх элемента

Массивы используют тот же базовый набор типов, только через тип элемента, например DIM scores(1 TO 3) AS INTEGER. Отдельный базовый тип массива не вводится: в договоре участвуют тип элемента, ранг и видимые границы.

DIM scores(1 TO 3) AS INTEGER
DIM names(1 TO 2) AS STRING
DIM board(1 TO 3, 1 TO 3) AS BOOLEAN

Ручная проверка

  • DIM: групповые объявления с общим типом
  • TYPE: строковые поля фиксированной длины
  • Многомерные массивы: двумерная сетка
