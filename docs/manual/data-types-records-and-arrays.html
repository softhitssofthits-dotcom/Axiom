Записи TYPE и массивы

Раздел записей TYPE и массивов описывает два способа собрать несколько значений: TYPE делает одну запись с именованными полями, а массив делает набор элементов одного типа с доступом по номеру.

Запись и массив: две разные идеи

Запись похожа на карточку или анкету. В ней есть разные графы: имя, возраст, город. У каждой графы своё имя и свой тип.

Массив похож на ряд ячеек или таблицу. В нём много однотипных элементов: оценки, строки, клетки поля, записи сотрудников.

TYPE Person
    Name AS STRING
    Age AS INTEGER
END TYPE

DIM user AS Person
DIM scores(1 TO 3) AS INTEGER

user хранит одну карточку человека. scores хранит несколько целых чисел.

Когда нужен TYPE

TYPE нужен, когда несколько разных значений описывают один предмет. Например, человек состоит не из одного числа и не из одной строки: у него есть имя, возраст, город и другие свойства.

TYPE Player
    Name AS STRING
    Score AS INTEGER
    Active AS BOOLEAN
END TYPE

DIM current AS Player
current.Name = "Ada"
current.Score = 100
current.Active = TRUE

Точка в current.Name означает: возьми поле Name внутри записи current.

Когда нужен массив

Массив нужен, когда значений много и они однотипные. Вместо отдельных переменных score1, score2, score3 можно завести один массив scores.

DIM scores(1 TO 3) AS INTEGER

scores(1) = 80
scores(2) = 95
scores(3) = 70

PRINT scores(2)

Скобки в scores(2) означают: возьми элемент массива с индексом 2. Подробные правила массивов описаны на странице Массивы.

Массив записей

Самое частое сочетание — массив записей. Это уже не одна карточка, а целая картотека: каждый элемент массива хранит одну запись Person.

TYPE Person
    Name AS STRING
    Age AS INTEGER
END TYPE

DIM people(1 TO 2) AS Person

people(1).Name = "Ada"
people(1).Age = 36

people(2).Name = "Grace"
people(2).Age = 37

PRINT people(1).Name
PRINT people(2).Age

Читается слева направо: people(1) выбирает первую карточку, а .Name берёт поле Name в этой карточке.

Массив внутри записи

Иногда список принадлежит одной записи. Например, у одного ученика может быть несколько оценок. Тогда массив делают полем внутри TYPE.

TYPE Student
    Name AS STRING
    Marks(1 TO 3) AS INTEGER
END TYPE

DIM pupil AS Student

pupil.Name = "Ada"
pupil.Marks(1) = 5
pupil.Marks(2) = 4
pupil.Marks(3) = 5

PRINT pupil.Name
PRINT pupil.Marks(3)

pupil — одна запись ученика. pupil.Marks — массив оценок внутри этой записи.

Запись внутри записи

Поле записи может быть другой записью. Так удобно выделять отдельную часть данных, например адрес.

TYPE Address
    City AS STRING
    Street AS STRING
END TYPE

TYPE Person
    Name AS STRING
    Home AS Address
END TYPE

DIM user AS Person

user.Name = "Ada"
user.Home.City = "London"
user.Home.Street = "King Street"

PRINT user.Home.City

Здесь две точки подряд не означают ничего таинственного: сначала берётся поле Home внутри user, потом поле City внутри Home.

Групповые объявления DIM

DIM может объявлять несколько имён в одной строке. Общий AS <тип> относится к ближайшей группе имён слева.

DIM left, right AS BOOLEAN
DIM total = 10, title AS STRING = "Result"

В первой строке обе переменные получают тип BOOLEAN. Во второй строке total получает тип из значения 10, а title явно объявляется как STRING.

Куда идти за подробностями

  • Если нужно понять сам оператор TYPE, поля, точку и создание записи, откройте Оператор TYPE. Там же разобраны методы записи: SELF как ссылка на текущую запись, SUB New как конструктор и IsValid как проверка после конструктора.
  • Если нужна работа со списками, таблицами, индексами, REDIM, срезами и границами, откройте Массивы.
  • Если нужно объявить переменную, массив или несколько имён в одной строке, откройте Оператор DIM.
