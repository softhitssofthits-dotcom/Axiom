Записи и массивы

Раздел составных данных сопоставляет две формы организации значений: массив содержит элементы одного типа, а запись TYPE объединяет именованные поля.

Выбор формы данных

Используйте массив для списка или таблицы однотипных значений. Используйте запись для объекта с несколькими признаками, например именем и координатами. Эти формы можно объединять: массив записей, массивное поле записи или вложенная запись описаны в главе TYPE.
