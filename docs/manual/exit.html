Оператор EXIT

EXIT — оператор языка Axiom, который завершает ближайший охватывающий цикл указанного вида. На странице описаны две отдельные формы: EXIT FOR и EXIT DO.

Назначение и контекст

Оператор EXIT нужен для прекращения повторений, когда результат уже найден или продолжать вычисление не требуется. Форма EXIT FOR допускается внутри охватывающего FOR, а EXIT DO — внутри охватывающего DO. Обе формы работают в консольных и графических программах, включая вложенные условия и подпрограммы, и не принимают аргументов.

EXIT FOR

EXIT FOR

Форма допускается внутри FOR … NEXT и передаёт управление после соответствующего NEXT. Счётчик завершённого цикла становится недоступен.

EXIT DO

EXIT DO

Форма допускается внутри DO … LOOP и передаёт управление после соответствующего LOOP. Условие завершаемого цикла больше не проверяется.

Вложенные циклы

Завершается ближайший охватывающий цикл именно указанного вида. Другие внешние циклы продолжают работу. Аргументов у этих форм нет; формы EXIT WHILE в Axiom нет.

Диагностика

  • MB2013 — EXIT FOR записан вне цикла FOR.
  • MB2014 — EXIT DO записан вне цикла DO ... LOOP.

Пример

Выход при значении три оставляет два напечатанных числа:

FOR index = 1 TO 5
    IF index = 3 THEN
        EXIT FOR
    END IF
    PRINT index
NEXT

Результат:

1
2
