Оператор EXIT

EXIT — оператор языка Axiom, который немедленно завершает охватывающий цикл FOR или DO. Выполнение продолжается после соответствующего оператора завершения цикла.

Контекст

Форма EXIT FOR допускается внутри цикла FOR; форма EXIT DO — внутри цикла DO ... LOOP. Параметров у оператора нет. Во вложенных циклах завершается ближайший охватывающий цикл указанного вида.

Синтаксис EXIT FOR

EXIT FOR

Управление передаётся на инструкцию после соответствующего NEXT. Счётчик этого цикла за его пределами недоступен.

Синтаксис EXIT DO

EXIT DO

Управление передаётся на инструкцию после соответствующего LOOP. Условие продолжения этого цикла повторно не проверяется.

Диагностика

  • MB2013 — EXIT FOR записан вне цикла FOR.
  • MB2014 — EXIT DO записан вне цикла DO ... LOOP.

Пример

FOR i = 1 TO 5
    IF i = 3 THEN
        EXIT FOR
    END IF
    PRINT i
NEXT

Результат:

1
2
