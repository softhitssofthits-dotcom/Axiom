Справочник языка

RANDOMIZE

RANDOMIZE — оператор языка Axiom, который повторно инициализирует генератор псевдослучайных чисел.

Назначение

Оператор RANDOMIZE задаёт начальное состояние генератора, значения которого возвращает RND. Одинаковое зерно помогает воспроизводить вычисления.

Где работает

Оператор работает в консольных и графических программах и влияет на генератор текущей среды исполнения.

Синтаксис

RANDOMIZE
RANDOMIZE <начальное значение>

Параметр

Начальное значение должно быть INTEGER или LONG в диапазоне INTEGER: от −2147483648 до 2147483647. Передайте его для воспроизводимого начала последовательности. Форма без параметра сохраняет текущее состояние генератора.

Действие

Оператор с параметром заменяет состояние генератора; следующие вызовы RND начинают новую последовательность. Форма без параметра не меняет состояние. Оператор не возвращает значение.

Правила и ограничения

Повторный вызов с тем же зерном повторяет последовательность в текущей среде. Совпадение конкретных чисел между версиями .NET не является договором языка. Отрицательное зерно допустимо.

Диагностика

Несовместимый тип параметра отклоняется при компиляции. LONG вне диапазона INTEGER вызывает MB3008.

Пример

RANDOMIZE 42
DIM first AS DOUBLE = RND()
RANDOMIZE 42
PRINT RND() = first

Ожидаемый вывод:

TRUE
