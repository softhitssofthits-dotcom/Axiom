Раздел

Вывод типа и преобразования

Раздел вывода типа и преобразований описывает, как значение получает тип и когда Axiom допускает переход к другому типу: целое число может стать более широким целым или десятичным числом, строка может быть разобрана как число, а число может быть выведено как текст.

Вывод типа

Если в объявлении DIM не указан тип, Axiom берёт тип из инициализатора. Это удобно для простых локальных значений, но явная форма AS остаётся главным способом записать намерение программы.

DIM count = 10
DIM ratio = 1.5
DIM ready = TRUE
DIM name = "Алиса"
ИнициализаторВыведенный типПояснение
10INTEGERЦелый литерал сначала выбирает INTEGER, если помещается в его диапазон.
21474836479LONGБольшой целый литерал выбирает LONG, если уже не помещается в INTEGER.
1.5DOUBLEДробный литерал с точкой выводится как DOUBLE.
TRUE, FALSEBOOLEANЛогические литералы не смешиваются с числовой моделью.
"Алиса"STRINGСтроковый литерал создаёт строку переменной длины.

Автоматические преобразования

Автоматический переход выполняется только тогда, когда он расширяет числовое значение и не требует угадывать намерение программиста.

ПереходРазрешёнПример
INTEGER → LONGдаDIM wide AS LONG = 10
INTEGER → DOUBLEдаDIM angle AS DOUBLE = 0
INTEGER → DECIMALдаDIM amount AS DECIMAL = 1
LONG → DOUBLEдаDIM value AS DOUBLE = bigLong
LONG → DECIMALдаDIM value AS DECIMAL = bigLong

Переходы в обратную сторону не выполняются автоматически. DOUBLE и DECIMAL тоже не смешиваются молча: обычное арифметическое выражение должно оставаться в одной понятной числовой линии.

Преобразования даты и времени

Типы DATE, TIME и DATETIME участвуют в собственном наборе неявных преобразований: каждый из них переходит в STRING и обратно, а дата и время объединяются с типом DATETIME в обе стороны.

ПереходРазрешёнПример
DATE ↔ STRINGдаDIM day AS DATE = "2026-08-25"
TIME ↔ STRINGдаDIM moment AS TIME = "14:05:06"
DATETIME ↔ STRINGдаDIM stamp AS DATETIME = "2026-08-25 14:05:06"
DATE ↔ DATETIMEдаDIM stamp AS DATETIME = day
TIME ↔ DATETIMEдаDIM stamp AS DATETIME = moment

Строка должна быть записана в каноническом формате нужного типа. Числовые значения не превращаются в дату или время автоматически, и наоборот.

Присваивание полной даты-времени (например, "2026-08-25 14:05:06") переменной типа DATE или TIME запрещено: такая конверсия молча отбрасывала бы время или дату. Компилятор сообщает об ошибке MB2003; для явного извлечения части используйте DATEVALUE или TIMEVALUE. Расширяющие переходы DATE → DATETIME и TIME → DATETIME по-прежнему неявно разрешены.

Для явного разбора строки служат функции DATEVALUE и TIMEVALUE: DATEVALUE возвращает значение типа DATE, а TIMEVALUE — значение типа TIME. Обе функции принимают строку и описаны на странице Арифметика, разбор и проверка.

Явный DECIMAL

Литерал 10.50 сам по себе имеет тип DOUBLE. Если значение должно участвовать в десятичных расчётах, целевой тип нужно указать явно.

DIM price AS DECIMAL = 10.50
DIM tax AS DECIMAL = 0.20
DIM total AS DECIMAL = price + tax

PRINT total

Результат:

10.30

VAL

VAL преобразует строку в число типа DOUBLE. Строка читается в инвариантной числовой форме: десятичная часть отделяется точкой.

DIM text AS STRING = "123.5"
DIM value AS DOUBLE = VAL(text)

PRINT value / 2

Результат:

61.75

Если строку нельзя разобрать как конечное число, VAL возвращает 0. Это поведение полезно для простых проверок старого BASIC-стиля, но для строгого пользовательского ввода лучше отдельно проверять исходный текст.

STR

STR преобразует число в строку. Результат использует тот же отображаемый вид значения, что и PRINT: целые числа печатаются без дробной части, DOUBLE использует общий числовой формат, а DECIMAL сохраняет десятичную запись.

DIM count AS INTEGER = 42
DIM price AS DECIMAL = 10.30

PRINT "Count = " + STR(count)
PRINT "Price = " + STR(price)

Результат:

Count = 42
Price = 10.30

Особое правило деления

Оператор / возвращает DECIMAL, если в выражении участвует DECIMAL и не участвует DOUBLE. Во всех остальных числовых случаях результат обычного деления имеет тип DOUBLE.

DIM price AS DECIMAL = 10.50
PRINT price / 2
PRINT 7 / 2

Результат:

5.25
3.5

Что не преобразуется автоматически

  • STRING не становится числом без VAL.
  • Число не становится строкой для оператора +; используйте STR или оператор &.
  • BOOLEAN не превращается в число и не принимает число вместо TRUE или FALSE.
  • DATE, TIME и DATETIME не смешиваются с числами автоматически.
  • FILE, массивы, записи TYPE и значения функций не участвуют в обычных скалярных преобразованиях.

Отличия, важные при чтении старых BASIC-материалов

В QuickBASIC для явного числового преобразования были функции CINT, CLNG, CSNG и CDBL. В текущем Axiom эти имена не являются частью пользовательского договора; поддержаны ограниченные автоматические числовые переходы, VAL для строки в DOUBLE и STR для значения в строку.

Ручная проверка

Эти программы можно открыть в Axiom.Ide и использовать как короткие проверки вывода типа, десятичных объявлений и строко-числовых переходов.

  • DIM: вывод типа из инициализатора
  • DIM: явное объявление DECIMAL
  • Автоматические числовые преобразования
  • VAL: базовое использование
  • VAL: недопустимый текст
  • STR: базовое использование
  • DATEVALUE: дата из даты-времени
  • TIMEVALUE: время из даты-времени

Диагностика

  • MB2003 — несовместимые типы, например попытка сложить строку и число через + или смешать DOUBLE и DECIMAL в неподдержанной форме.
  • MB2018 — константное числовое значение не помещается в явно указанный целевой тип.
  • MB3008 — арифметическое переполнение или неконечный результат DOUBLE во время выполнения.
