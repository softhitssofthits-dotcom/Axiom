Преобразования типов

Раздел преобразований описывает допустимые переходы между типами Axiom. Автоматическое преобразование выполняется только в поддержанном контексте; оно не разрешает произвольное смешение данных.

Вывод типа и преобразование

Вывод типа выбирает тип нового объявления по инициализатору. Преобразование переводит уже имеющее тип значение в требуемый тип. Например, целочисленный литерал можно присвоить переменной LONG, а дробный литерал сам по себе имеет тип DOUBLE.

Таблица описывает допустимость перехода, а не сохранение всех разрядов: двоичное представление DOUBLE может округлить исходное значение. Обратные переходы требуют предусмотренного явного преобразования.

Особенности контекста

Обычная арифметика с DECIMAL и DOUBLE преобразует DECIMAL в DOUBLE. При этом возможна потеря десятичной точности. Отдельное автоматическое присваивание DECIMAL переменной DOUBLE также допустимо. Числовые встроенные функции MIN, MAX и CLAMP проверяют смешение DECIMAL с DOUBLE иначе и отклоняют такое сочетание аргументов. Числовой литерал в объявлении, присваивании или аргументе, где ожидается числовой тип, разбирается с учётом этого типа. Например, десятичный литерал для DECIMAL читается непосредственно как десятичное значение. Такое чтение литерала отличается от преобразования уже сохранённой переменной.

DIM amount AS DECIMAL = 10.50
DIM extra AS DECIMAL = 0.20
PRINT amount + extra

Результат:

10.70

Правило результата деления и числового продвижения для операций находится в статье операций; оно не дублируется здесь.

Явные преобразования

Числовые преобразования выполняют CINT, CLNG, CDBL и CDEC. Для разбора числового текста служит VAL, для получения текстового представления — STR. У каждой функции есть собственные правила округления, диапазона и некорректного аргумента.

Функции преобразования чисел

Прочие типы

Преобразования между BOOLEAN и числами не предусмотрены ни автоматическим присваиванием, ни функциями CINT, CLNG, CDBL и CDEC. Встроенной функции CBOOL нет. Для числа используйте явное сравнение, а для выбора числового результата по логическому значению — IF. Примеры приведены в статье BOOLEAN. Для соединения числа и строки через + требуется строковое преобразование; операция & имеет собственный договор текстового представления.

Временные типы поддерживают специальные переходы и разбор канонических строк. Их полный договор, включая запрет неявного отбрасывания части даты-времени при присваивании, находится в главе даты и времени.

Открытый файл, массив, запись и функциональное значение не участвуют в общих скалярных преобразованиях. Для них действуют правила соответствующих сущностей.

Диагностика

  • MB2003 — несовместимые типы, например попытка сложить строку и число через + или передать смешанные DOUBLE и DECIMAL в MIN, MAX или CLAMP.
  • MB2018 — константное числовое значение не помещается в явно указанный целевой тип.
  • MB3008 — арифметическое переполнение или неконечный результат DOUBLE во время выполнения.

Запускаемые примеры

Откройте нужный файл в IDE и запустите его. Примеры с ошибкой предназначены для проверки сообщения компилятора или выполнения.

  • DIM: вывод типа из инициализатора
  • DIM: явное объявление DECIMAL
  • Автоматические числовые преобразования
  • VAL: базовое использование
  • VAL: недопустимый текст
  • STR: базовое использование
  • DATEVALUE: дата из даты-времени
  • TIMEVALUE: время из даты-времени
