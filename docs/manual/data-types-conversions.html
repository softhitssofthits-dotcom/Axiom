Вывод типа и преобразования

Эта страница собирает правила, по которым Axiom выводит тип из инициализатора, а также перечисляет разрешённые автоматические и явные преобразования.

Вывод типа в DIM

DIM total = 10
DIM ratio = 1.5
DIM ready = TRUE
DIM name = "Алиса"
  • 10 выводится как INTEGER.
  • 1.5 выводится как DOUBLE.
  • TRUE и FALSE выводятся как BOOLEAN.
  • Строковый литерал выводится как STRING.

Автоматические преобразования

  • Автоматически разрешены только INTEGER -> LONG, INTEGER -> DECIMAL, INTEGER -> DOUBLE, LONG -> DECIMAL и LONG -> DOUBLE.
  • DOUBLE и DECIMAL не смешиваются автоматически.
  • STRING не превращается в число автоматически.
  • FILE не участвует в арифметике и не имеет автоматических преобразований.

Явные переходы через built-in

  • Для преобразования строки в число используйте VAL(...).
  • Для преобразования числа в строку используйте STR(...).
  • Для точного десятичного поведения у дробных литералов указывайте явный тип: AS DECIMAL.
DIM text AS STRING = "123.5"
DIM number AS DOUBLE = VAL(text)
DIM price AS DECIMAL = 10.50

PRINT STR(number)
PRINT price / 2

Особое правило для деления

Оператор / возвращает DECIMAL, если в выражении участвует DECIMAL и не участвует DOUBLE. Во всех остальных случаях результат имеет тип DOUBLE.

Ручная проверка

  • DIM: вывод типа из инициализатора
  • DIM: явное объявление DECIMAL
  • Автоматические числовые преобразования
  • STR: базовое использование
  • VAL: базовое использование
