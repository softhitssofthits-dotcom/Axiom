# Справочник языка Axiom

Главная страница — [index.html](index.html). Справочник открывается непосредственно с диска; сервер, сборка сайта и подключение к сети для чтения не требуются.

## Организация

Основной маршрут содержит 17 глав: знакомство; переменные; выражения; консоль; условия; циклы; числа; строки; дата и время; массивы; процедуры; пользовательские типы; ошибки; файлы; регулярные выражения; графика; события. В каждой области сначала объясняется понятие, затем приводятся точные статьи операторов и функций. Указатели, обозначения, диагностики и примеры доступны отдельно.

Каждое понятие имеет основное место. Например, временные типы и их договор объясняются в главе даты и времени, а интерполяция — в строковой главе. Общая карта типов и алфавитный указатель содержат краткие определения и ссылки. Полные описания не копируются между каталогом и тематическими статьями.

Старые адреса общих и наглядных страниц сохранены для совместимости ссылок. Они направляют читателя к основной теме и не включаются повторно в последовательность чтения.

## Файлы и генерация

- `scripts/chapters.js` — единое оглавление с порядком глав и тематических статей.
- `scripts/manual.js` — боковое оглавление, путь темы, содержание статьи и последовательные переходы.
- `scripts/search.js` — поиск по локальному индексу; запрос передаётся в `search.html?q=...` и восстанавливается в поле шапки.
- `scripts/search-index.js` — сформированный индекс тем и сущностей языка.
- `data/language-reference.json` — снимок точных форм зарегистрированного языка.
- `data/function-explanations.json` — определения функций и объяснения назначения их аргументов для справочного каталога.
- `scripts/highlight.js`, `scripts/code-dictionary.js`, `scripts/semantic-colors.js` и `styles/code-colors.css` — подсветка программ по словарю языка и светлой теме Axiom IDE.
- `../../scripts/manual-page.mjs` — общий каркас HTML с закреплённой шапкой и поиском.

После изменения тематических статей выполнить из корня репозитория:

```powershell
node scripts/build-language-reference.mjs
node scripts/build-manual-index.mjs
node scripts/check-manual.mjs
node --test scripts/manual-browser.test.mjs
node --test scripts/manual-highlight.test.mjs scripts/manual-syntax.test.mjs scripts/manual-search-index.test.mjs
```

Первая команда обновляет три справочных каталога из снимка языка и основных статей. Вторая собирает главную страницу, алфавитный указатель, страницу поиска, индекс и ресурсы подсветки. Индекс содержит одну запись на точный адрес страницы или раздела; дополнительные имена конструкций сохраняются как варианты запроса, без повторного результата. Обе команды сохраняют новую оболочку. При изменении самого языка сначала получить свежий `inventory-only` и передать его генератору через `--inventory`.

## Проверки

Проверка справочника контролирует разметку, ссылки, якоря, оглавление, доступный поиск, числовые пределы и все зарегистрированные формы вызова. Браузерная проверка использует установленный Microsoft Edge и зависимость Playwright из `ide/e2e`; она открывает локальные файлы, проверяет поиск, клавиатуру, закреплённую шапку, хлебные крошки и размещение всех статей на узком экране.

Правила написания — в [AUTHORING.md](AUTHORING.md); операционное применение этих правил выполняет навык [`.opencode/skills/axiom-manual-editor`](../../.opencode/skills/axiom-manual-editor/SKILL.md). Семантика проверяется по реализации, тестам и запускаемым `.axm`, а не по внешнему редакционному образцу.
