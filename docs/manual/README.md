# Ведение справочника языка Axiom

`index.html` — главная страница опубликованного справочника. HTML-файлы открываются локально; сервер и доступ к сети не требуются. Справочник описывает Axiom как самостоятельный язык программирования.

## Редакционный стандарт

Документация имеет формальный справочный характер. Она определяет синтаксис, типы, параметры, результат, правила выполнения, ограничения и диагностику. Исторические сравнения, учебные аналогии, происхождение имён и рассуждения о разработке не включаются в пользовательские статьи.

Первая фраза прямо называет сущность: оператор, встроенную функцию, тип или раздел. Описание использует полные предложения и термины Axiom. Правило объясняется непосредственно через поведение Axiom.

Статья отдельной сущности содержит:

1. назначение и контекст выполнения;
2. каждую форму синтаксиса отдельно;
3. параметры, их типы, допустимые значения, единицы и значения по умолчанию;
4. выполняемое действие или возвращаемое значение;
5. ограничения и пограничные случаи;
6. диагностику с условиями возникновения;
7. короткий пример и ожидаемый результат, когда результат определён;
8. ссылки на связанные сущности и запускаемые файлы `.axm`.

Нельзя придумывать недокументированные коды ошибок, переносить правила по сходству имён или подменять описание перечислением ключевых слов. Для групп функций общие ограничения обозначаются явно. У каждой функции остаётся собственная карточка и отдельный перечень форм вызова.

## Источники и полнота

Факты проверяются по `docs/SPECIFICATION3.md`, реализации языка, тестам и запускаемым примерам. Реестр встроенных функций — `BuiltinFunctions`; формы операторов определяются парсером и синтаксическими узлами. Число форм вызова не равно числу имён: все перегрузки должны присутствовать.

Полные каталоги:

- `function-reference.html` — отдельные карточки всех встроенных функций;
- `operator-reference.html` — все операторы, объявления и формы инструкций;
- `keyword-reference.html` — ключевые слова, встроенные типы и операции в выражениях;
- `notation.html` — обозначения справочного синтаксиса.
- `language-syntax.html` — лексические правила, литералы, формы выражений и интерполированные строки.

`data/language-reference.json` содержит проверенный снимок форм вызова и соответствие операторов синтаксическим узлам. Он хранит контрольную сумму файлов реестра и синтаксиса. Изменение этих исходников требует обновить снимок и повторить сверку.

Подробные описания редактируются на тематических HTML-страницах. Каталоги собираются из этих описаний и снимка языка командой ниже. Не редактируйте собранные каталоги вручную: повторная сборка перезаписывает их.

## Сборка и проверка

Из корня репозитория, последовательно:

```powershell
dotnet run --project scripts/language-audit/Axiom.LanguageAudit.csproj -- C:/Axiom --inventory-only --output-dir .artifacts/manual-reference-inventory
node scripts/build-language-reference.mjs --inventory .artifacts/manual-reference-inventory/inventory.json
node scripts/check-manual.mjs --inventory .artifacts/manual-reference-inventory/inventory.json
```

Без изменений реестра достаточно:

```powershell
node scripts/build-language-reference.mjs
node scripts/check-manual.mjs
```

Проверка сопоставляет все формы функций с загруженным реестром, проверяет соответствие инструкциям парсера, карточки, ключевые слова, типы, операции, локальные ссылки и якоря. Она также запрещает внешние языковые сравнения в опубликованном тексте. Это проверка полноты и структуры документации; она не заменяет проверку семантики каждого примера.

При добавлении сущности обновляются тематическая статья, снимок, каталог, боковая навигация и поисковый индекс. Имена файлов существующих тематических страниц сохраняются, чтобы ссылки из IDE и репозитория продолжали работать.
