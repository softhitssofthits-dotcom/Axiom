Раздел

Все совпадения, группы и разбиение

Раздел всех совпадений, групп и разбиения описывает функции REGEXMATCHES, REGEXEXTRACTALL и REGEXSPLIT — сбор всех совпадений, извлечение групп из всех вхождений и разбиение строки по образцу.

REGEXMATCHES

Функция REGEXMATCHES собирает все найденные совпадения целиком в новый массив строк.

Синтаксис

results = REGEXMATCHES(text, pattern[, modes])

Аргументы

text задаёт исходную строку, pattern регулярное выражение, modes необязательные режимы. Результат имеет тип STRING().

Пустой массив без совпадений

Если совпадений нет, функция возвращает пустой массив с границами 1 TO 0.

Пример массива совпадений

DIM values() AS STRING
values = REGEXMATCHES("Order 42 and 100", "\d+")
PRINT values(1)
PRINT values(2)

Результат:

42
100

REGEXEXTRACTALL

Функция REGEXEXTRACTALL возвращает значения одной и той же группы из всех найденных совпадений.

Синтаксис

results = REGEXEXTRACTALL(text, pattern, groupNumber[, modes])

Аргументы

groupNumber задаёт номер группы. Группа 0 означает всё совпадение целиком.

Явно заданный номер группы

Аргумент groupNumber — номер захватывающей группы, который не обязан быть её порядковым местом. Конструкция (?<10>...) задаёт номер 10. Для отсутствующей положительной группы или необязательной группы без захвата в массив помещается пустая строка. Отрицательный номер даёт MB3007.

DIM values() AS STRING
' Собираем значения одной группы из двух совпадений.
values = REGEXEXTRACTALL("код12 код34", "код(?<10>[0-9]+)", 10)
PRINT values(1)
PRINT values(2)

Результаты: «12» и «34». Запускаемый пример: значения группы 10.

Пустая строка вместо отсутствующей группы

Если в отдельном совпадении нужной группы нет, соответствующий элемент массива получает пустую строку.

Пример массива групп

DIM values() AS STRING
values = REGEXEXTRACTALL("A12 B34", "([A-Z])(\d+)", 2)
PRINT values(1)
PRINT values(2)

Результат:

12
34

REGEXSPLIT

Функция REGEXSPLIT разбивает строку по совпадениям регулярного выражения и возвращает части как новый массив строк.

Синтаксис

parts = REGEXSPLIT(text, pattern[, modes])

Пустые части при разбиении

Пустые части сохраняются, если совпадение стоит в начале, в конце или вплотную к другому совпадению. Для пустого исходного текста функция возвращает пустой массив 1 TO 0.

В примере ниже шаблон "[,;]\s*" читается так: [,;] означает «запятая или точка с запятой», \s означает пробельный символ, а * разрешает ноль или больше таких пробельных символов после разделителя.

Пример разбиения по шаблону

DIM parts() AS STRING
parts = REGEXSPLIT("one, two;three", "[,;]\s*")
PRINT parts(1)
PRINT parts(2)
PRINT parts(3)

Результат:

one
two
three

Запускаемые примеры

  • REGEXMATCHES: все совпадения
  • REGEXEXTRACTALL: значения группы
  • REGEXSPLIT: разбиение по шаблону
