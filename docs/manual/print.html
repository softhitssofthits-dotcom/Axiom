Ввод и вывод

Оператор PRINT

Оператор PRINT выводит значения и результаты выражений в поток вывода программы. Эта глава описывает как обычный вывод со списком выражений, так и форматированный вывод через PRINT USING: строковые поля, числовые маски, завершающие разделители и ограничения текущей реализации.

Главные правила

  • Поддерживаются пустой PRINT, вывод одного выражения и форма со списком вывода с ; и ,.
  • Поддерживается форматированный вывод PRINT USING formatExpression; valueList.
  • Если список вывода не заканчивается на ; или ,, оператор завершает вывод переводом строки.
  • Разделитель ; соединяет соседние элементы без дополнительного текста между ними.
  • Разделитель , в текущей реализации вставляет один пробел и, если стоит в конце, тоже подавляет автоматический перевод строки.
  • Внутри PRINT USING внешний вид результата задаётся строкой формата: литералами, строковыми полями !, &, \ \ и числовыми масками на основе #, 0, ., +, -, ,, $, *, ^.
  • Текущая реализация не эмулирует исторические зоны вывода QuickBASIC и колонное форматирование.

Что делает PRINT

Оператор PRINT отправляет данные в поток вывода программы. Чаще всего это текст, который пользователь видит в окне выполнения программы в IDE.

Простая форма

В самом простом случае после PRINT указывается одно выражение:

PRINT "Привет"
PRINT 42
PRINT 1 + 2 * 3

Сначала выражение вычисляется, затем его результат выводится на экран.

Пустой PRINT

Если оператор записан без аргументов, он просто выводит перевод строки:

PRINT

Это удобно, когда нужно визуально разделить блоки вывода.

Список вывода и разделители

Axiom поддерживает вывод нескольких элементов в одном операторе. Для этого используются разделители ; и ,.

PRINT "Имя: "; "Анна"
PRINT "Курс:", 2
PRINT "A"; "B"; "C"
  • ; соединяет соседние элементы без дополнительного разделителя;
  • , в текущей реализации работает как мягкий разделитель и выводит один пробел;
  • если список не заканчивается на ; или ,, после него автоматически выводится перевод строки;
  • если в конце стоит ; или ,, перевод строки подавляется.
  • Завершающий ; или , сохраняет незавершённую строку вывода и в интерпретаторе, и в байткодном режиме, поэтому несколько выполнений PRINT i, внутри цикла продолжают одну строку.

PRINT USING

PRINT USING выводит значения по строке формата. Формат задаёт литералы и поля, а список значений подставляется в эти поля слева направо.

PRINT USING "Name: \    \|"; "Bob"
PRINT USING "Total: ###.##"; 12.5
PRINT USING "Flag: !"; "XYZ"

Основная форма выглядит так:

PRINT USING formatExpression; expression { ; expression | , expression } [ ; | , ]
  • после USING обязателен формат, который должен иметь тип STRING;
  • после строки формата обязателен разделитель ;;
  • разделители между значениями после формата используются как синтаксис списка аргументов;
  • только завершающий ; или , после последнего аргумента влияет на перевод строки так же, как в обычном PRINT.

Строковые поля PRINT USING

Строковые поля берут очередное значение типа STRING и выводят его по одной из трёх схем.

  • ! — выводит первый символ строки. Если строка пустая, ничего не печатает.
  • & — выводит всю строку целиком без усечения.
  • \ \ — выводит строку в поле фиксированной ширины. Ширина определяется записью между парой обратных слэшей, обычно через нужное число пробелов.
PRINT USING "!"; "Hello"
PRINT USING "&"; "Hello"
PRINT USING "\    \"; "Hi"

Для поля \ \ короткая строка дополняется пробелами справа, а длинная обрезается по ширине поля. Если строковых аргументов не хватило, ! и & дают пустой вывод, а фиксированное поле заполняется пробелами.

Числовые маски PRINT USING

Числовая маска берёт очередное числовое значение типа INTEGER, LONG, DOUBLE или DECIMAL. Поддерживаются следующие символы:

  • # — позиция для цифры.
  • 0 — ещё одна позиция для цифры. В текущей реализации # и 0 работают одинаково: резервируют место, но не добавляют отдельной логики ведущих нулей.
  • . — разделитель целой и дробной части.
  • + — всегда выводит знак числа.
  • - — выводит знак только для отрицательных чисел.
  • , — вставляет разделители тысяч в целую часть.
  • $ — добавляет префикс $.
  • * — заполняет свободное место слева символами *.
  • ^ — включает экспоненциальную запись вида E+NN или E-NN.
PRINT USING "###.##"; 12.5
PRINT USING "+###.##"; 12.5
PRINT USING "$$###.##"; 12.5
PRINT USING "**###.##"; 12.5
PRINT USING "#,###.##"; 1234.5
PRINT USING "##.##^^"; 12.5

Маски можно комбинировать. Например, +$#,###.## означает: знак, префикс доллара, разделители тысяч и две дробные позиции.

Если число не помещается в выделенную ширину, текущая реализация выводит знак % и затем полное исходное числовое представление.

Практические замечания и диагностика

  • Символ _ экранирует следующий символ и заставляет вывести его как литерал. Например, "Cost: _#" печатает решётку как текст, а не как часть маски.
  • Литералы в формате печатаются как есть и не расходуют аргументы.
  • Если строковое поле получает не STRING, а числовое поле получает не число, возникает диагностика времени выполнения PRINT USING.
  • Если числовому полю не хватило аргумента, возникает диагностика времени выполнения.
  • Лишние аргументы, для которых в строке формата не оказалось полей, в текущей реализации просто игнорируются.
  • Длина строки формата ограничена 2048 символами.

Ограничения текущей реализации

Axiom сознательно не повторяет историческую консольную модель QuickBASIC целиком. В частности, текущая реализация не эмулирует старые зоны вывода и сложное поведение по колонкам консоли.

  • нет исторических зон вывода и привязки к ширине консоли в 80 колонок;
  • # и 0 пока не различаются по поведению ведущих нулей;
  • валютный символ фиксирован как $, а не зависит от локали;
  • экспоненциальная запись через ^ использует нормализованный вид E±NN текущей реализации времени выполнения.

Итого

PRINT — это основной оператор вывода в Axiom. Он позволяет печатать отдельные значения, выражения, пустые строки, списки элементов с разделителями ; и ,, а также форматированный вывод через PRINT USING со строковыми и числовыми масками.
