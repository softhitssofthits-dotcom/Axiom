Оператор PRINT

PRINT — оператор языка Axiom, который выводит текст и значения выражений. Форма PRINT USING применяет форматную строку к выводимым значениям.

Назначение и место вывода

В IDE без выбранного SCREEN результат поступает в консоль. В активном SCREEN текст отображается в окне программы. При запуске через CLI используется стандартный поток вывода. Экранное размещение текста регулируется средствами графической главы.

Синтаксис

PRINT

PRINT <список вывода>

PRINT <список вывода> ;

PRINT <список вывода> ,
PRINT USING <формат> ; <список вывода>

PRINT USING <формат> ; <список вывода> ;

PRINT USING <формат> ; <список вывода> ,

Список вывода и разделители

Передайте в список одно или несколько выражений, разделённых точкой с запятой или запятой. Значения выражений задают выводимые данные; завершающий разделитель управляет окончанием строки. Формат в PRINT USING должен быть выражением типа STRING, задающим маску текстовых и числовых полей.

Список состоит из выражений, вычисляемых слева направо. Точка с запятой между значениями не добавляет символов; запятая добавляет один пробел. Запятая не перемещает вывод в фиксированную экранную зону.

Без завершающего разделителя оператор заканчивает строку. Завершающий ; или , откладывает перевод строки, и следующий вывод продолжает её. Пустой PRINT выводит перевод строки.

Представление значения

Обычная форма преобразует значение в отображаемый текст Axiom. Для того же скалярного представления можно использовать соединение через &. Интерполяция позволяет заранее собрать строку с вставками и форматированием; полный договор интерполяции находится в строковой главе.

Интерполяция и числовые форматы

PRINT USING

Сначала вычисляется строка формата типа STRING, затем значения подставляются в её поля по порядку. Форматное поле должно соответствовать типу переданного значения.

Строковое полеДействие
!Выводит первый элемент UTF-16 строки; для пустой строки вывод пуст.
&Выводит строку целиком.
\ \Поле фиксированной ширины. Ширина включает обратные косые черты и пробелы между ними.

Числовые маски используют #, 0, ., +, -, ,, $, * и ^. Маска определяет ширину и представление числа. Неподходящий тип значения или нехватка значения для числового поля приводят к ошибке форматирования. Для отсутствующего строкового значения поле ! или & выводит пустую строку, а фиксированное поле — пробелы. Лишние значения вычисляются, но в результат не включаются. При переполнении ширины числового поля выводятся знак % и обычное представление исходного числа. Числовое округление половин направлено от нуля. Форматная строка ограничена 2048 единицами UTF-16.

Диагностика

  • MB2003 — выражение формата в PRINT USING не имеет тип STRING.
  • MB3007 — ошибка форматирования PRINT USING: неподходящий тип значения для поля, нехватка значения для числового поля или недопустимая форматная строка.

Пример обычного вывода

Разделители позволяют явно выбрать соединение и пробел:

PRINT "Имя: "; "Анна"
PRINT "Курс:", 2
PRINT
PRINT "Готово"

Результат:

Имя: Анна
Курс: 2

Готово

Пример форматирования

PRINT USING "Итог: ###.##"; 12.5

Результат:

Итог:  12.50
