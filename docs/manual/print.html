Оператор PRINT

PRINT выводит текст и значения выражений в консоль или в окно программы. Форма PRINT USING дополнительно раскладывает значения по полям форматной строки, задавая ширину поля и вид числа.

Назначение и место вывода

Место вывода зависит от того, как запущена программа. Если программа не выбрала экран оператором SCREEN, результат поступает в консоль; после выбора экрана текст отображается в окне программы. При запуске через CLI вывод идёт в стандартный поток вывода. Размещением текста внутри графического экрана управляют средства графической главы.

Синтаксис

Обычная форма принимает список вывода, форма USING добавляет перед ним форматную строку. Завершающий разделитель записывается сразу после списка:

PRINT

PRINT <список вывода>

PRINT <список вывода> ;

PRINT <список вывода> ,
PRINT USING <формат> ; <список вывода>

PRINT USING <формат> ; <список вывода> ;

PRINT USING <формат> ; <список вывода> ,

Список вывода и разделители

Список вывода состоит из одного или нескольких выражений, разделённых точкой с запятой или запятой. Выражения вычисляются слева направо, а разделитель между ними определяет, что попадёт между значениями: точка с запятой не добавляет символов, запятая добавляет один пробел. Запятая не перемещает вывод в фиксированную экранную зону.

Завершающий разделитель управляет окончанием строки. Без него оператор заканчивает строку; завершающие ; или , откладывают перевод строки, и следующий вывод продолжает ту же строку. Пустой PRINT выводит только перевод строки.

В форме PRINT USING первым идёт выражение типа STRING — форматная строка с маской текстовых и числовых полей.

Пример обычного вывода

Разделители позволяют явно выбрать соединение и пробел:

PRINT "Имя: "; "Анна"
PRINT "Курс:", 2
PRINT
PRINT "Готово"

Результат:

Имя: Анна
Курс: 2

Готово

Представление значения

Обычная форма преобразует значение в отображаемый текст по правилам Axiom. То же скалярное представление даёт соединение через &. Если строка собирается заранее, со вставками и форматированием, применяется интерполяция; её полный договор находится в строковой главе.

Интерполяция и числовые форматы

PRINT USING

Сначала вычисляется строка формата типа STRING, затем значения подставляются в её поля по порядку. Форматное поле должно соответствовать типу переданного значения.

Строковое полеДействие
!Выводит первый элемент UTF-16 строки; для пустой строки вывод пуст.
&Выводит строку целиком.
\ \Поле фиксированной ширины. Ширина включает обратные косые черты и пробелы между ними.

Числовые маски используют #, 0, ., +, -, ,, $, * и ^. Маска определяет ширину поля и представление числа.

Неподходящий тип значения или нехватка значения для числового поля приводят к ошибке форматирования. Для отсутствующего строкового значения поле ! или & выводит пустую строку, а фиксированное поле — пробелы. Лишние значения вычисляются, но в результат не включаются. При переполнении ширины числового поля выводятся знак % и обычное представление исходного числа.

В обычной десятичной маске половина округляется от нуля: до 28 дробных разрядов для INTEGER, LONG и DECIMAL и до 15 разрядов для DOUBLE. Более длинная дробная часть маски поддерживается: тогда форматируется исходное значение без предварительного округления до этих пределов, но дополнительные позиции не увеличивают точность исходного типа. Форматная строка ограничена 2048 единицами UTF-16.

Четыре символа ^^^^ задают экспоненциальное представление. Знак показателя сохраняется отдельно от знака числа; INTEGER, LONG и DECIMAL форматируются без промежуточного преобразования в DOUBLE.

PRINT USING "###.##^^^^"; 0.001
PRINT USING "###.##^^^^"; 1000

Результат:

  1.00E-03
  1.00E+03

Пример форматирования

Числовая маска задаёт ширину поля и число дробных разрядов:

PRINT USING "Итог: ###.##"; 12.5

Результат:

Итог:  12.50

Диагностика

  • MB2003 — выражение формата в PRINT USING не имеет тип STRING.
  • MB3007 — ошибка форматирования PRINT USING: неподходящий тип значения для поля, нехватка значения для числового поля или недопустимая форматная строка.
