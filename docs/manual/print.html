Ввод и вывод

Оператор PRINT

Оператор PRINT является основным способом показать результат работы программы. Через него Axiom выводит как отдельные значения и выражения, так и составные списки вывода, а при необходимости позволяет применить форматную строку через PRINT USING.

Сводка

Оператор PRINT выводит текст, числа и результаты выражений в поток вывода программы. Он поддерживает пустую форму для перевода строки, список вывода с разделителями и форматированный вывод через PRINT USING.

Синтаксис

PRINT
PRINT [expressionList]
PRINT USING formatExpression; expressionList

Части записи

expressionList обозначает одно или несколько выводимых значений, разделённых ; или ,. Пустая форма PRINT выводит только перевод строки.

formatExpression задаёт строку формата для PRINT USING. Значения после неё подставляются в поля формата слева направо.

Замечания

На практике PRINT используют и как самый простой инструмент отладки, и как обычный пользовательский вывод. Поэтому на одной странице собраны и базовый список вывода, и более формальная форма PRINT USING.

  • Пустой PRINT выводит только перевод строки.
  • Разделитель ; соединяет соседние элементы без дополнительного текста между ними.
  • Разделитель , в текущей реализации вставляет один пробел.
  • Если список вывода не заканчивается на ; или ,, оператор завершает вывод переводом строки.
  • Если в конце стоит ; или ,, автоматический перевод строки подавляется.
  • PRINT USING использует строковые и числовые маски. Поддерживаются строковые поля !, &, \ \ и числовые маски на основе #, 0, ., +, -, ,, $, *, ^.
  • Текущая реализация не повторяет старую зонную модель вывода QuickBASIC и сложное колонное форматирование консоли.

Пример

' Программа печатает обычный и форматированный вывод
' Ожидаемый вывод:
' Имя: Анна
' Курс: 2
'
' Total:  12.50
PRINT "Имя: "; "Анна"
PRINT "Курс:", 2
PRINT
PRINT USING "Total: ###.##"; 12.5

Ручная проверка

  • PRINT: базовое выражение
  • PRINT: пустой оператор
  • PRINT: разделитель ;
  • PRINT: разделитель ,
  • PRINT: смешанный список вывода
  • PRINT USING: базовые маски

Диагностика

Ошибки возможны в режиме PRINT USING, если строка формата имеет неверный вид, если строковое поле получает не строку, если числовое поле получает не число или если числовому полю не хватило аргумента.
