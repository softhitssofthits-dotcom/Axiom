Ввод и вывод

Оператор PRINT

PRINT — оператор вывода, который записывает в поток вывода программы текст, числа и результаты выражений. Его используют для сообщений пользователю, промежуточных результатов и простых таблиц, а форма PRINT USING применяет к значениям форматную строку.

Назначение

Оператор PRINT выводит одно значение, несколько значений или пустую строку. Если программа не выбирала экранный режим через SCREEN, вывод попадает во вкладку IDE Output. В активном SCREEN тот же оператор пишет в текстовый слой экранного окна.

Обычная форма PRINT подходит для прямого вывода значений. Форма PRINT USING нужна, когда требуется управлять шириной поля, количеством десятичных знаков или длиной выводимой строки.

Синтаксис

PRINT
PRINT <список вывода>
PRINT <список вывода> ;
PRINT <список вывода> ,
PRINT USING <формат> ; <список вывода>
PRINT USING <формат> ; <список вывода> ;
PRINT USING <формат> ; <список вывода> ,

Части записи

  • <список вывода> — одно или несколько выражений, которые нужно вывести. Элементы списка разделяются точкой с запятой ; или запятой ,.
  • ; между элементами выводит соседние значения подряд, без добавленного пробела.
  • , между элементами выводит мягкий разделитель: в текущей реализации это один пробел.
  • Завершающий ; или , подавляет автоматический перевод строки после оператора.
  • <формат> в PRINT USING — строковое выражение с полями форматирования.

Логика работы

Пустой оператор PRINT выводит только перевод строки. Если список вывода не пустой, Axiom вычисляет элементы слева направо и записывает их в выходной поток в том же порядке.

Если последний элемент списка не имеет завершающего разделителя, после вывода добавляется перевод строки. Если строка заканчивается точкой с запятой или запятой, следующий PRINT продолжит вывод в той же строке.

Для обычного PRINT значения переводятся в текст в отображаемом формате Axiom. Тот же формат используется оператором строковой конкатенации &, когда он переводит скалярные значения в строку.

PRINT USING

PRINT USING сначала вычисляет строку формата, затем подставляет значения из списка вывода в поля формата слева направо.

Для строк поддержаны поля:

  • ! — первый символ строки;
  • & — вся строка;
  • \ \ — поле фиксированной ширины; число пробелов между обратными косыми чертами задаёт ширину вместе с самими границами поля.

Для чисел поддержаны маски на основе символов #, 0, ., +, -, ,, $, * и ^.

Замечания

  • Обычный PRINT можно использовать без аргументов, чтобы вывести пустую строку.
  • Запятая в Axiom не раскладывает вывод по фиксированным экранным зонам, а добавляет один пробел.
  • Форматная строка PRINT USING должна иметь тип STRING.
  • Если форматное поле ожидает строку, ему нужно передать строковое значение.
  • Если форматное поле ожидает число, ему нужно передать числовое значение.
  • Если значений меньше, чем полей в строке формата, выполнение сообщает ошибку.

В QuickBASIC запятая в PRINT была связана с зонной моделью вывода. В Axiom текущая документируемая модель проще: запятая между элементами списка вывода даёт один пробел, а не переход к следующей фиксированной колонке.

Пример

В этом примере точка с запятой соединяет фрагменты без дополнительного пробела, запятая ставит один пробел, а пустой PRINT выводит пустую строку.

PRINT "Имя: "; "Анна"
PRINT "Курс:", 2
PRINT
PRINT "Готово"

Результат:

Имя: Анна
Курс: 2

Готово

Пример PRINT USING

В этом примере строковое поле ограничивает имя шириной поля, а числовая маска задаёт два знака после десятичной точки.

PRINT USING "Name: \    \|"; "Bob"
PRINT USING "Total: ###.##"; 12.5
PRINT USING "Flag: !"; "XYZ"

Результат:

Name: Bob   |
Total:  12.50
Flag: X

Диагностика

  • MB2003 — выражение формата в PRINT USING не имеет тип STRING.
  • MB3007 — ошибка форматирования PRINT USING: неподходящий тип значения для поля, нехватка значения для числового поля или недопустимая форматная строка.
