Файловая система

Раздел файловой системы описывает оператор OPEN, оператор CLOSE и встроенные функции чтения, записи, путей и управления каталогами. Программа работает с путём STRING либо с открытым ресурсом FILE.

Два способа работы

Для одноразового чтения всего текста используйте READFILE или READALLLINES; для полной записи — WRITEFILE или APPENDFILE. Для последовательного чтения, накопленной записи и позиционирования объявите FILE, откройте его оператором OPEN и передавайте ресурс соответствующим функциям. После завершения закройте его оператором CLOSE.

Пути и кодировки

Относительные пути разрешаются от CURRENTDIR() текущего запуска. Функции создания файлов не создают отсутствующий родительский каталог. MAKEDIR создаёт каталог вместе с недостающими родителями.

Без явной кодировки чтение целого файла и OPEN FOR INPUT проверяют UTF-8, а при недопустимых байтах используют WINDOWS-1251. Запись по умолчанию использует UTF-8 без BOM. Явно можно выбрать UTF-8, WINDOWS-1251, UTF-16LE или UTF-16BE; правила проверки BOM и строгого кодирования описаны в OPEN и текстовых функциях.

Короткий пример

DIM path AS STRING = MAKETEMPFILE("manual_")
WRITEFILE(path, "Axiom")
PRINT READFILE(path)
DELETEFILE(path)

Ожидаемый вывод:

Axiom

Ошибки

Отсутствующий требуемый объект, недопустимый путь, отказ доступа, неверный режим ресурса и недопустимая кодировка обычно дают MB3007 во время выполнения. Ошибки типов и числа аргументов обнаруживаются при проверке программы. Применимые случаи перечислены в карточке каждой операции.
