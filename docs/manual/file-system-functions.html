Функции файловой системы

Функции файловой системы позволяют проверить существование файла или папки, прочитать и записать текстовый файл, скопировать, перенести, переименовать или удалить файл, получить даты и признаки объектов файловой системы, получить сведения о папке и диске, создать временный файл или временную папку, а также работать с открытыми текстовыми файлами через тип FILE и операторы OPEN / CLOSE.

Главные правила

  • Все функции принимают путь как значение типа STRING.
  • Перед обращением к файловой системе путь приводится к полному виду.
  • READFILE и READALLLINES сначала читают текст как строгий UTF-8; если в файле есть недопустимые UTF-8 байты, чтение выполняется как Windows-1251.
  • WRITEFILE и APPENDFILE записывают текст в UTF-8 без BOM.
  • WRITEFILE создаёт новый файл или перезаписывает существующий.
  • APPENDFILE добавляет текст в конец файла и создаёт файл, если его ещё нет.
  • FILEDATE, FILECREATEDATE, FILEACCESSEDDATE и DIRDATE возвращают дату и время в форме yyyy-MM-dd HH:mm:ss.
  • Этот формат согласован со страницей функций даты и времени и подходит для прямой передачи в следующие дата-временные built-ins будущих этапов.
  • EXTNAME возвращает расширение вместе с точкой, например .txt. Если расширения нет, возвращается пустая строка.
  • PATHROOT возвращает корневую часть полного пути, а ISABSOLUTEPATH показывает, был ли путь абсолютным уже в исходном виде.
  • DELETEFILE, DELETEDIR и DELETEDIRRECURSIVE возвращают FALSE, если удаляемого файла или папки нет.
  • DELETEDIR удаляет только пустую папку, а DELETEDIRRECURSIVE удаляет папку вместе со всем содержимым.
  • DIRSIZE считает файлы во вложенных папках, но не заходит в папки-ссылки и другие точки повторного анализа.
  • CHANGEDIR меняет текущую папку программы, и после этого все относительные пути считаются уже от новой папки.
  • FREESPACE возвращает доступное свободное место, TOTALFREESPACE — общее свободное место, а TOTALSPACE — полный размер диска.
  • ISREADONLY и ISHIDDEN проверяют атрибуты файла или папки.
  • DRIVENAME, DRIVEFORMAT и DRIVETYPE возвращают сведения о диске, к которому относится путь.
  • MAKETEMPFILE и MAKETEMPDIR создают новые временные объекты в системной временной папке и возвращают их полный путь.
  • Для открытых текстовых файлов используется специальный тип FILE и операторы OPEN / CLOSE, а не исторические файловые номера.
  • GETFILES и GETDIRS возвращают одномерный массив строк с полными путями файлов или папок ближайшего уровня.
  • READALLLINES возвращает строки текстового файла как одномерный массив STRING().

Проверка существования

Формы вызова:

FILEEXISTS(<путь> AS STRING) AS BOOLEAN
DIREXISTS(<путь> AS STRING) AS BOOLEAN
PATHEXISTS(<путь> AS STRING) AS BOOLEAN

FILEEXISTS проверяет существование файла, DIREXISTS проверяет существование папки, а PATHEXISTS возвращает TRUE, если по указанному пути найден файл или папка.

PRINT FILEEXISTS("notes.txt")
PRINT DIREXISTS(".")
PRINT PATHEXISTS("notes.txt")

Чтение и запись текста

Формы вызова:

READFILE(<путь> AS STRING) AS STRING
READALLLINES(<путь> AS STRING) AS STRING()
WRITEFILE(<путь> AS STRING, <текст> AS STRING) AS BOOLEAN
APPENDFILE(<путь> AS STRING, <текст> AS STRING) AS BOOLEAN

READFILE возвращает содержимое текстового файла целиком. READALLLINES читает весь текстовый файл по строкам и возвращает массив строк без символов перевода строки. При чтении обе функции сначала используют строгий UTF-8, а если файл содержит недопустимые UTF-8 байты, читают его как Windows-1251. Если UTF-8-файл начинается с BOM, эта служебная метка не попадает в результат чтения. WRITEFILE записывает текст в файл с начала в UTF-8 без BOM. APPENDFILE добавляет текст в конец файла в UTF-8 без BOM.

  • Непустой результат READALLLINES получает границы массива 1 TO N.
  • Пустой файл возвращает выделенный пустой массив 1 TO 0.
  • Чтобы обратиться к строкам результата, сначала присвойте результат переменной массива, а затем используйте индексирование вида lines(1).
  • Резервное чтение Windows-1251 нужно для старых или частично повреждённых русскоязычных файлов, где иначе байты превратились бы в символы замены � и уже не могли бы быть восстановлены программой.
DIM path AS STRING = "notes.txt"
DIM lines() AS STRING

PRINT WRITEFILE(path, "Hello")
PRINT APPENDFILE(path, "!")
PRINT READFILE(path)

lines = READALLLINES(path)
PRINT ARRAYLENGTH(lines)

Открытые текстовые файлы

Синтаксис:

DIM f AS FILE

OPEN "data.txt" FOR INPUT AS f
OPEN "log.txt" FOR OUTPUT AS f
OPEN "log.txt" FOR APPEND AS f

CLOSE f

Встроенные функции:

ISOPEN(<file> AS FILE) AS BOOLEAN
FILEPATH(<file> AS FILE) AS STRING
FILEMODE(<file> AS FILE) AS STRING
FILEPOS(<file> AS FILE) AS LONG
FILELENGTH(<file> AS FILE) AS LONG
EOF(<file> AS FILE) AS BOOLEAN
READTOEND(<file> AS FILE) AS STRING
READTEXT(<file> AS FILE, <count> AS INTEGER) AS STRING
READLINE(<file> AS FILE) AS STRING
READLINES(<file> AS FILE, <count> AS INTEGER) AS STRING()
LINENUMBER(<file> AS FILE) AS LONG
SKIPLINE(<file> AS FILE) AS BOOLEAN
WRITE(<file> AS FILE, <текст> AS STRING) AS BOOLEAN
WRITELINE(<file> AS FILE, <текст> AS STRING) AS BOOLEAN
NEWLINE(<file> AS FILE) AS BOOLEAN
FLUSH(<file> AS FILE) AS BOOLEAN
SEEKFILE(<file> AS FILE, <position> AS LONG) AS BOOLEAN
REWIND(<file> AS FILE) AS BOOLEAN

Тип FILE хранит состояние открытого текстового файла. Исторические записи вида AS #1 в Axiom не используются. Вместо этого файл открывается сразу в понятную переменную, например sourceFile или logFile.

  • INPUT открывает существующий файл для чтения.
  • OUTPUT создаёт новый файл или полностью очищает существующий перед записью.
  • APPEND открывает файл для дописывания в конец и при отсутствии создаёт его.
  • ISOPEN удобно проверяет, есть ли сейчас в переменной FILE открытый файл.
  • FILEPATH возвращает полный путь уже открытого файла, а FILEMODE - его режим: INPUT, OUTPUT или APPEND.
  • FILEPOS возвращает текущую позицию внутри уже открытого файла в байтах от начала файла, а FILELENGTH возвращает текущую длину файла в байтах.
  • READTOEND возвращает весь оставшийся текст от текущей позиции до конца файла, а READTEXT читает следующий фрагмент текста длиной до указанного числа символов.
  • READTEXT с нулевым значением count возвращает пустую строку, а если до конца файла осталось меньше текста, то возвращает только доступный остаток.
  • READLINES читает до указанного числа следующих строк и возвращает массив STRING() без символов перевода строки.
  • READLINES с нулевым значением count возвращает выделенный пустой массив 1 TO 0 и не меняет позицию чтения.
  • Если READLINES достигает конца файла раньше указанного количества строк, она возвращает только прочитанные строки. Если файл уже стоит в конце, результатом будет выделенный пустой массив 1 TO 0.
  • EOF, READTOEND, READTEXT, READLINE, READLINES, LINENUMBER и SKIPLINE работают только с файлом, открытым через FOR INPUT.
  • LINENUMBER возвращает номер следующей текстовой строки. Первая строка имеет номер 1.
  • После READLINE, READLINES и SKIPLINE номер следующей строки увеличивается на число фактически прочитанных или пропущенных строк. После SEEKFILE и REWIND функция LINENUMBER пересчитывает его по текущей байтовой позиции.
  • SKIPLINE пропускает одну строку текста без возврата её содержимого. Если файл уже стоит в конце, вызывается диагностика времени выполнения.
  • WRITE, WRITELINE и NEWLINE работают только с файлом, открытым через FOR OUTPUT или FOR APPEND, и записывают данные в буфер.
  • NEWLINE записывает только перевод строки. Это удобная короткая форма для добавления пустой строки.
  • FLUSH работает только с файлом, открытым через FOR OUTPUT или FOR APPEND, и принудительно сбрасывает буфер записи на диск.
  • SEEKFILE переводит уже открытый файл на указанную позицию в байтах от начала файла. Первая позиция равна 0.
  • REWIND переводит уже открытый файл в начало. По смыслу это короткая форма для перехода на позицию 0.
  • SEEKFILE разрешён только для режимов INPUT и OUTPUT. Для режима APPEND явный переход по позиции не поддерживается.
  • REWIND тоже разрешён только для режимов INPUT и OUTPUT. Для режима APPEND он не поддерживается.
  • В режиме записи FILEPOS и FILELENGTH учитывают уже накопленные в буфере данные, даже если отдельный FLUSH ещё не был вызван.
  • Низкоуровневая позиция в FILEPOS, FILELENGTH, SEEKFILE и REWIND всегда считается в байтах, а READLINE, READLINES, READTEXT и READTOEND читают текст по символам.
  • Эти модели можно смешивать, но позиция перед текстовым чтением должна попадать на корректную границу символа UTF-8. Если перейти внутрь многобайтного символа, последующее текстовое чтение даст ошибку времени выполнения.
  • CLOSE тоже завершает запись буфера, поэтому перед закрытием отдельный FLUSH нужен только тогда, когда надо увидеть данные на диске прямо сейчас, не закрывая файл.
  • Переменной FILE нельзя вручную присвоить другое значение обычным оператором присваивания.
DIM path AS STRING = MAKETEMPFILE("open_demo_")
DIM reader AS FILE
DIM writer AS FILE

PRINT WRITEFILE(path, "alpha" + CHR(13) + CHR(10) + "beta")

OPEN path FOR INPUT AS reader
PRINT FILEPOS(reader)
PRINT READTEXT(reader, 2)
PRINT READLINE(reader)
PRINT READTOEND(reader)
PRINT REWIND(reader)
PRINT FILEPOS(reader)
CLOSE reader

OPEN path FOR OUTPUT AS writer
PRINT WRITE(writer, "ABCDE")
PRINT FILELENGTH(writer)
PRINT SEEKFILE(writer, 2)
PRINT WRITE(writer, "Z")
CLOSE writer

PRINT READFILE(path)

Сведения о файле

Формы вызова:

FILESIZE(<путь> AS STRING) AS LONG
FILEDATE(<путь> AS STRING) AS STRING
FILECREATEDATE(<путь> AS STRING) AS STRING
FILEACCESSEDDATE(<путь> AS STRING) AS STRING
DIRDATE(<путь> AS STRING) AS STRING

FILESIZE возвращает размер файла в байтах. FILEDATE возвращает дату и время последнего изменения файла. FILECREATEDATE возвращает дату создания файла. FILEACCESSEDDATE возвращает дату последнего доступа к файлу. DIRDATE возвращает дату последнего изменения папки.

PRINT FILESIZE("notes.txt")
PRINT FILEDATE("notes.txt")
PRINT FILECREATEDATE("notes.txt")
PRINT FILEACCESSEDDATE("notes.txt")

Перечисление файлов и папок

Формы вызова:

GETFILES(<путь> AS STRING) AS STRING()
GETFILES(<путь> AS STRING, <маска> AS STRING) AS STRING()
GETDIRS(<путь> AS STRING) AS STRING()
GETDIRS(<путь> AS STRING, <маска> AS STRING) AS STRING()

GETFILES возвращает массив полных путей файлов из указанной папки. GETDIRS возвращает массив полных путей папок из указанной папки. Обе функции перечисляют только ближайший уровень и не заходят во вложенные папки.

  • Если маска не указана, используется *.
  • Маска применяется как файловая маска текущей платформы, например *.txt или data*.
  • Порядок результата стабилен: пути сортируются без учёта регистра.
  • Непустой результат получает границы массива 1 TO N.
  • Пустой результат возвращается как выделенный пустой массив 1 TO 0.
  • Чтобы обратиться к элементам результата, сначала присвойте результат переменной массива, а затем используйте индексирование вида files(1).
DIM root AS STRING = MAKETEMPDIR("list_")
DIM path AS STRING = COMBINEPATH(root, "notes.txt")
DIM ok AS BOOLEAN
DIM files() AS STRING

ok = WRITEFILE(path, "Hello")
files = GETFILES(root, "*.txt")

PRINT ARRAYLENGTH(files)
PRINT FILENAME(files(1))

Работа с путями

Формы вызова:

COMBINEPATH(<левая часть> AS STRING, <правая часть> AS STRING) AS STRING
FILENAME(<путь> AS STRING) AS STRING
DIRNAME(<путь> AS STRING) AS STRING
EXTNAME(<путь> AS STRING) AS STRING
FULLPATH(<путь> AS STRING) AS STRING
PATHROOT(<путь> AS STRING) AS STRING
ISABSOLUTEPATH(<путь> AS STRING) AS BOOLEAN

COMBINEPATH соединяет две части пути. FILENAME возвращает имя файла, DIRNAME возвращает имя папки из полного пути, EXTNAME возвращает расширение файла, FULLPATH возвращает полный путь, PATHROOT возвращает корень этого пути, а ISABSOLUTEPATH показывает, был ли путь абсолютным уже в исходном виде.

PRINT COMBINEPATH("folder", "notes.txt")
PRINT FILENAME("folder/notes.txt")
PRINT EXTNAME("folder/notes.txt")
PRINT PATHROOT("notes.txt")
PRINT ISABSOLUTEPATH(CURRENTDIR())

Создание папки

Форма вызова:

MAKEDIR(<путь> AS STRING) AS BOOLEAN

MAKEDIR создаёт папку и возвращает TRUE, если операция завершилась успешно. Если папка уже существует, функция также возвращает TRUE.

PRINT MAKEDIR("my_folder")
PRINT DIREXISTS("my_folder")

Операции с файлами

Формы вызова:

DELETEFILE(<путь> AS STRING) AS BOOLEAN
COPYFILE(<исходный путь> AS STRING, <целевой путь> AS STRING[, <перезаписать> AS BOOLEAN]) AS BOOLEAN
MOVEFILE(<исходный путь> AS STRING, <целевой путь> AS STRING[, <перезаписать> AS BOOLEAN]) AS BOOLEAN
RENAMEFILE(<путь> AS STRING, <новое имя> AS STRING) AS BOOLEAN

DELETEFILE удаляет файл и возвращает TRUE, если файл был найден и удалён. Если файла нет, возвращается FALSE.

COPYFILE копирует файл. MOVEFILE переносит файл. Если третий аргумент равен TRUE, существующий целевой файл может быть перезаписан.

RENAMEFILE переименовывает файл в той же папке.

PRINT WRITEFILE("source.txt", "Hello")
PRINT COPYFILE("source.txt", "copy.txt", TRUE)
PRINT MOVEFILE("copy.txt", "moved.txt", TRUE)
PRINT RENAMEFILE("moved.txt", "renamed.txt")
PRINT DELETEFILE("renamed.txt")

Операции с папками

Формы вызова:

DELETEDIR(<путь> AS STRING) AS BOOLEAN
DELETEDIRRECURSIVE(<путь> AS STRING) AS BOOLEAN
COPYDIR(<исходный путь> AS STRING, <целевой путь> AS STRING[, <перезаписать> AS BOOLEAN]) AS BOOLEAN
MOVEDIR(<исходный путь> AS STRING, <целевой путь> AS STRING) AS BOOLEAN
RENAMEDIR(<путь> AS STRING, <новое имя> AS STRING) AS BOOLEAN

DELETEDIR удаляет пустую папку и возвращает TRUE, если папка была найдена и удалена. Если папки нет, возвращается FALSE. Непустая папка не удаляется.

DELETEDIRRECURSIVE удаляет папку вместе со всеми вложенными папками и файлами. Если папки нет, возвращается FALSE.

COPYDIR копирует папку вместе с содержимым. Если третий аргумент равен TRUE, существующие файлы в целевой папке могут быть перезаписаны.

MOVEDIR переносит папку. RENAMEDIR переименовывает папку в той же родительской папке.

PRINT MAKEDIR("source_dir")
PRINT COPYDIR("source_dir", "copy_dir", TRUE)
PRINT MOVEDIR("copy_dir", "moved_dir")
PRINT RENAMEDIR("moved_dir", "renamed_dir")
PRINT DELETEDIR("source_dir")

Текущая папка и временные объекты

Формы вызова:

CURRENTDIR() AS STRING
CHANGEDIR(<путь> AS STRING) AS BOOLEAN
MAKETEMPFILE(<префикс> AS STRING) AS STRING
MAKETEMPDIR(<префикс> AS STRING) AS STRING

CURRENTDIR возвращает текущую папку программы. CHANGEDIR меняет её. После успешного вызова CHANGEDIR все относительные пути считаются уже от новой текущей папки.

MAKETEMPFILE создаёт новый пустой временный файл, а MAKETEMPDIR создаёт новую временную папку. Обе функции возвращают полный путь к созданному объекту.

Аргумент <префикс> задаёт только начало имени. Он не должен содержать путь.

DIM oldDir AS STRING = CURRENTDIR()
DIM tempDir AS STRING = MAKETEMPDIR("demo_")

PRINT CHANGEDIR(tempDir)
PRINT CURRENTDIR() = tempDir
PRINT CHANGEDIR(oldDir)

Признаки объекта файловой системы

Формы вызова:

ISREADONLY(<путь> AS STRING) AS BOOLEAN
ISHIDDEN(<путь> AS STRING) AS BOOLEAN

Эти функции работают и с файлами, и с папками. ISREADONLY возвращает TRUE, если у объекта установлен атрибут только для чтения. ISHIDDEN возвращает TRUE, если объект скрыт.

DIM path AS STRING = "notes.txt"

PRINT WRITEFILE(path, "Hello")
PRINT ISREADONLY(path)
PRINT ISHIDDEN(path)

Сведения о папке и диске

Формы вызова:

DIRSIZE(<путь> AS STRING) AS LONG
FREESPACE(<путь> AS STRING) AS LONG
TOTALFREESPACE(<путь> AS STRING) AS LONG
TOTALSPACE(<путь> AS STRING) AS LONG
DRIVENAME(<путь> AS STRING) AS STRING
DRIVEFORMAT(<путь> AS STRING) AS STRING
DRIVETYPE(<путь> AS STRING) AS STRING

DIRSIZE возвращает суммарный размер файлов в указанной папке и её вложенных папках. FREESPACE возвращает доступное свободное место на диске, TOTALFREESPACE — общее свободное место, а TOTALSPACE — полный размер диска.

DRIVENAME возвращает имя диска, например C:\. DRIVEFORMAT возвращает строковое имя файловой системы, например NTFS. DRIVETYPE возвращает строковое имя типа диска, например Fixed, Network или Removable.

DIRSIZE не заходит в папки-ссылки и другие точки повторного анализа, чтобы не образовывать циклы обхода.

DIM folder AS STRING = MAKETEMPDIR("size_")
DIM filePath AS STRING = COMBINEPATH(folder, "notes.txt")

PRINT WRITEFILE(filePath, "Hello")
PRINT DIRSIZE(folder)
PRINT FREESPACE(folder) > 0
PRINT TOTALSPACE(folder) > 0
PRINT DRIVETYPE(folder)

Будущие расширения файловой подсистемы

Этот раздел фиксирует заранее согласованные направления развития, чтобы они не потерялись. Эти возможности ещё не реализованы и приведены здесь только как проектный список.

OPEN <путь> FOR BINARY AS <file>
READBYTE(<file> AS FILE) AS ...
WRITEBYTE(<file> AS FILE, ...) AS ...
  • Двоичная модель файлов будет выделена в отдельный этап. Там же будут уточнены режим FOR BINARY, побайтовое чтение и запись, а также работа с блоками данных.
  • После двоичной модели список файловых функций будет расширен дальше, но без возврата к старой нумерованной модели файловых каналов.

Пока эти формы и направления приведены в справочнике только как проектный задел. Вызывать их в программе ещё нельзя.

Диагностика

  • неверное число аргументов диагностируется на этапе семантического анализа;
  • неверный тип аргумента диагностируется на этапе семантического анализа;
  • ошибка доступа к файловой системе, недопустимый путь или отсутствие файла для READFILE, READALLLINES, FILESIZE, FILEDATE, FILECREATEDATE, FILEACCESSEDDATE, COPYFILE, MOVEFILE и RENAMEFILE дают диагностику времени выполнения MB3007;
  • попытка вызвать FILEPATH, FILEMODE, FILEPOS, FILELENGTH, EOF, READTOEND, READTEXT, READLINE, READLINES, LINENUMBER, SKIPLINE, WRITE, WRITELINE, NEWLINE, FLUSH, SEEKFILE или REWIND для закрытого FILE даёт диагностику времени выполнения MB3007;
  • попытка вызвать READTOEND, READTEXT, READLINE, READLINES, LINENUMBER или SKIPLINE для файла, открытого не через FOR INPUT, даёт диагностику времени выполнения MB3007;
  • попытка вызвать WRITE, WRITELINE или NEWLINE для файла, открытого не через FOR OUTPUT или FOR APPEND, даёт диагностику времени выполнения MB3007;
  • попытка вызвать SEEKFILE для файла, открытого через FOR APPEND, даёт диагностику времени выполнения MB3007;
  • попытка вызвать REWIND для файла, открытого через FOR APPEND, даёт диагностику времени выполнения MB3007;
  • отрицательная позиция и попытка выйти за пределы файла в SEEKFILE дают диагностику времени выполнения MB3007;
  • отрицательное значение count в READTEXT и READLINES даёт диагностику времени выполнения MB3007;
  • попытка вызвать SKIPLINE, когда файл уже находится в конце, даёт диагностику времени выполнения MB3007;
  • попытка текстового чтения из позиции, которая не попадает на корректную границу символа UTF-8, даёт диагностику времени выполнения MB3007;
  • отсутствие исходной папки для GETFILES, GETDIRS, COPYDIR, MOVEDIR, RENAMEDIR, CHANGEDIR, DIRSIZE и DIRDATE даёт диагностику времени выполнения MB3007;
  • пустая маска в GETFILES и GETDIRS даёт диагностику времени выполнения MB3007;
  • отсутствие файла или папки для ISREADONLY и ISHIDDEN даёт диагностику времени выполнения MB3007;
  • недопустимый префикс имени для MAKETEMPFILE и MAKETEMPDIR даёт диагностику времени выполнения MB3007;
  • попытка удалить непустую папку через DELETEDIR даёт диагностику времени выполнения MB3007;
  • переполнение суммарного размера в DIRSIZE даёт диагностику времени выполнения MB3008.
