Функции файловой системы

Раздел функций файловой системы описывает средства для проверки существования файлов и папок, чтения и записи текста, работы с открытыми файлами типа FILE, разбора путей и управления каталогами.

Группы файловых функций

  • Проверка существования файла, папки или любого пути: FILEEXISTS, DIREXISTS, PATHEXISTS.
  • Чтение и запись целого текстового файла: READFILE, READALLLINES, WRITEFILE, APPENDFILE.
  • Работа с уже открытым текстовым файлом через тип FILE: чтение, запись, позиционирование и служебные сведения.
  • Пути, имена, расширения, сведения о размере и датах, перечисление файлов и папок.
  • Операции создания, удаления, копирования, перемещения, переименования, а также временные файлы и папки.

Пути, кодировка и открытые FILE

  • Все пути передаются как значения типа STRING.
  • Для работы с уже открытым текстовым файлом используется тип FILE вместе с OPEN и CLOSE.
  • Функции READFILE и READALLLINES сначала читают текст как UTF-8, а при недопустимых байтах переходят к Windows-1251.
  • WRITEFILE и APPENDFILE записывают текст в UTF-8 без BOM.
  • Если нужна конкретная функция по имени, используйте поиск по справочнику или соответствующий подраздел ниже.

Ручная проверка

  • FILEEXISTS: проверка файла
  • READFILE: чтение текста
  • WRITEFILE: запись текста
  • FULLPATH: полный путь
  • OPEN: открытие текстового файла
  • CLOSE: закрытие файла
