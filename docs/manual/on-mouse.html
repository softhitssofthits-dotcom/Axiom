Оператор ON MOUSE

ON MOUSE — оператор языка Axiom, который связывает событие мыши с процедурой SUB. Оператор нужен для интерактивных программ, которым удобнее реагировать на нажатие, отпускание или перемещение между обычными операторами, а не постоянно опрашивать состояние мыши через MOUSEX, MOUSEY и MOUSEBUTTON.

Когда использовать ON MOUSE

Оператор ON MOUSE подходит для интерактивных программ, где нужно реагировать на нажатие кнопки, отпускание кнопки, перемещение указателя или прокрутку колеса между обычными операторами. Оператор работает при активном графическом режиме SCREEN и при активном CANVAS.

Где работает оператор ON MOUSE

Оператор ON MOUSE работает при активном графическом режиме SCREEN 1..10 или при активном CANVAS. Без активной рисуемой поверхности выполнение сообщает диагностику MB3010.

При активном SCREEN координаты событий мыши измеряются в пикселях клиентской области активного окна и не пересчитываются через операторы VIEW и WINDOW. При активном CANVAS параметры x и y передаются уже в мировых координатах и учитывают текущие VIEWPORT и CAMERA.

Оператор ON MOUSE выполняется BytecodeVm после компиляции.

Синтаксис

ON MOUSE(buttonNumber), HandlerName
ON MOUSE(buttonNumber), ON
ON MOUSE(buttonNumber), STOP
ON MOUSE(buttonNumber), OFF

ON MOUSE(buttonNumber, "UP"), HandlerName
ON MOUSE(buttonNumber, "UP"), ON
ON MOUSE(buttonNumber, "UP"), STOP
ON MOUSE(buttonNumber, "UP"), OFF

ON MOUSE("MOVE"), HandlerName
ON MOUSE("MOVE"), ON
ON MOUSE("MOVE"), STOP
ON MOUSE("MOVE"), OFF

ON MOUSE("WHEEL"), HandlerName
ON MOUSE("WHEEL"), ON
ON MOUSE("WHEEL"), STOP
ON MOUSE("WHEEL"), OFF

Части записи

buttonNumber и HandlerName в синтаксисе — метапеременные. В реальном коде вместо buttonNumber пишут выражение с номером кнопки, а вместо HandlerName — имя своей процедуры SUB. Строки "UP", "MOVE" и "WHEEL" — имена событий мыши.

ЧастьОписание
buttonNumberНомер кнопки мыши: 1 — левая, 2 — правая, 3 — средняя. Без второго аргумента цель означает нажатие кнопки.
"UP"Строковое имя события отпускания кнопки. Допустимы также формы "RELEASE" и "RELEASED".
"MOVE"Строковое имя события перемещения указателя. Для него номер кнопки не указывается.
"WHEEL"Строковое имя события прокрутки колеса мыши. Допустимы также формы "MOUSEWHEEL", "SCROLL" и "SCROLLED".
HandlerNameИмя процедуры SUB, которая будет вызвана при подходящем событии.

Процедура-обработчик

Процедура-обработчик может быть объявлена без параметров или с тремя параметрами события:

SUB HandleMouse()
END SUB

SUB HandleMouse(value AS INTEGER, x AS LONG, y AS LONG)
END SUB

Во второй форме первый параметр получает числовое значение события. Для нажатия и отпускания это номер фактической кнопки. Для ON MOUSE("MOVE") передаётся 0. Для ON MOUSE("WHEEL") передаётся величина прокрутки: положительное значение означает прокрутку вверх, отрицательное — вниз. Параметры x и y получают текущие координаты указателя на активной поверхности программы в момент обработки события.

Режимы

Слова ON, STOP и OFF после запятой задают состояние уже зарегистрированного обработчика. Эти формы доступны для нажатия кнопки, отпускания "UP", перемещения "MOVE" и колеса "WHEEL". В этой записи они являются режимами оператора ON MOUSE, а не самостоятельными операторами.

  • ON MOUSE(buttonNumber), HandlerName регистрирует и включает обработчик.
  • ON MOUSE(...), STOP временно ставит существующий обработчик на паузу для выбранной цели события.
  • ON MOUSE(...), ON возобновляет ранее зарегистрированный обработчик для той же формы ON MOUSE.
  • ON MOUSE(...), OFF полностью снимает регистрацию для выбранной цели события.

Порядок обработки событий мыши

  • Оператор ON MOUSE проверяет очередь мышиных событий на границах операторов, как ON KEY; в циклах обработчики также получают шанс выполниться на каждой итерации, даже если тело цикла пустое.
  • Если обработчик включён, совпавшее нажатие считается обработанным и не попадёт в последующий MOUSEPRESS.
  • Если обработчик на паузе или не зарегистрирован, нажатие остаётся доступным для MOUSEPRESS.
  • Отпускание, перемещение и колесо не читаются функцией MOUSEPRESS, но доступны обработчикам ON MOUSE(..., "UP"), ON MOUSE("MOVE") и ON MOUSE("WHEEL").
  • При активном SCREEN координаты x и y совпадают с теми же экранными чтениями, которые в этот момент дают MOUSEX и MOUSEY.
  • При активном CANVAS координаты x и y совпадают с теми же мировыми чтениями, которые в этот момент дают MOUSEX и MOUSEY.
  • Операторы VIEW, WINDOW и PMAP не изменяют координаты события в SCREEN. В CANVAS пересчёт идёт по договору VIEWPORT и CAMERA.
  • В панели Output среды разработки уход указателя за пределы поверхности сбрасывает состояние мыши: координаты становятся -1/-1, очередь событий очищается, удержание кнопок снимается.
  • В нативном графическом окне SCREEN уход указателя за видимую область сам по себе не создаёт отдельного сброса координат: без нового события ввода сохраняется последняя известная точка.
  • В текущем срезе нет обработчиков двойного клика и захвата указателя.

Пример обработчика мыши

ON MOUSE(1), HandleMouse
ON MOUSE(1, "UP"), HandleMouse
ON MOUSE("MOVE"), HandleMouse
ON MOUSE("WHEEL"), HandleMouse
DIM marker AS INTEGER = 1

SUB HandleMouse(value AS INTEGER, x AS LONG, y AS LONG)
    PRINT "MOUSE"
    PRINT value
    PRINT x
    PRINT y
END SUB

Ручная проверка

  • ON MOUSE: обработчик левой кнопки мыши в SCREEN
  • ON MOUSE: мировые координаты в CANVAS
  • ON MOUSE: отпускание и перемещение
  • ON MOUSE: колесо мыши

Диагностика

  • MB2035: обработчик оператора ON MOUSE не является подходящей процедурой SUB. Для обработчика события допустимы только формы без параметров или с параметрами INTEGER, LONG, LONG.
  • MB2036: в операторе ON MOUSE указано недопустимое имя события мыши.
  • MB3010: оператор ON MOUSE вызван без активного графического режима SCREEN и без активного CANVAS.
