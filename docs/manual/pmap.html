Функция

PMAP

PMAP переводит одну координату между физической системой текущего viewport и логической системой активного WINDOW. Эта функция нужна, когда программа одновременно работает и с логической шкалой рисунка, и с пиксельными координатами экрана.

Синтаксис

PMAP(<coordinate>, <selector>)

Части синтаксиса

ЧастьОписание
<coordinate>Числовая координата, которую нужно преобразовать. Аргумент вычисляется как DOUBLE.
<selector>Направление преобразования. Значения 0 и 1 переводят координату из логического WINDOW в физический viewport, значения 2 и 3 выполняют обратное преобразование.

Селекторы

СелекторРезультат
0Логическая X-координата WINDOW превращается в физическую X-координату текущего viewport.
1Логическая Y-координата WINDOW превращается в физическую Y-координату текущего viewport.
2Физическая X-координата текущего viewport превращается в логическую X-координату активного WINDOW.
3Физическая Y-координата текущего viewport превращается в логическую Y-координату активного WINDOW.

Замечания

PMAP работает только в графических режимах SCREEN 1 ... SCREEN 10. Без активного графического режима функция сообщает ошибку времени выполнения MB3010.

Физическая сторона преобразования всегда берётся из текущего viewport. После VIEW SCREEN это абсолютные координаты экрана. После VIEW без слова SCREEN это локальные координаты viewport, где левый верхний угол равен (0, 0).

Если WINDOW не активен, PMAP возвращает переданное значение без изменений. В этот момент логическая система координат совпадает с физической системой viewport, и дополнительного пересчёта не требуется.

PMAP не клиппирует координаты по границам viewport или окна. Если значение лежит вне видимой области, функция всё равно выполняет линейное преобразование и возвращает соответствующую координату.

Результат имеет тип DOUBLE и не округляется до пикселя. Если масштаб между WINDOW и viewport не совпадает с целым числом пикселей, дробная часть сохраняется.

PMAP не меняет текущую графическую позицию, framebuffer, настройки VIEW или WINDOW. Для чтения текущей позиции используйте POINT(number).

Примеры

SCREEN 1
VIEW SCREEN (10, 10)-(20, 20)
WINDOW SCREEN (100, 200)-(110, 210)

PRINT PMAP(104, 0), PMAP(205, 1)
PRINT PMAP(14, 2), PMAP(15, 3)

VIEW (2, 3)-(8, 9)
WINDOW SCREEN (100, 200)-(110, 210)
PRINT PMAP(102.5, 0), PMAP(1.5, 2)

Первые две строки переводят координаты между логическим окном и физической областью viewport. В последней строке видно, что PMAP сохраняет дробную часть, если масштаб viewport и окна не совпадает с целыми пикселями.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3007: селектор вне диапазона 0..3, координата не является конечным числом или текущий viewport слишком мал для активного WINDOW.
