Функция PMAP

PMAP — встроенная функция языка Axiom, которая преобразует одну координату между логической шкалой WINDOW и физической системой текущей области VIEW.

Применение

Используйте функцию для вычислений, которым нужны обе системы координат: например, чтобы сопоставить точку графика с её положением в пикселях.

Контекст выполнения

Для вызова требуется графический режим SCREEN 1..10.

Синтаксис

PMAP(<координата>, <селектор>)

Аргументы

АргументОписание
<координата>Передайте числовую координату, которую функция PMAP должна преобразовать. Передаваемое значение имеет тип DOUBLE.
<селектор>Передайте число, которое задаёт направление преобразования. Передаваемое значение имеет тип INTEGER.

Что возвращает функция PMAP

Результат содержит одну координату. Селектор определяет ось и направление преобразования; для точки из двух координат нужны два вызова.

Селекторы

СелекторПреобразование
0Преобразование логической координаты X в физическую координату графической области.
1Преобразование логической координаты Y в физическую координату графической области.
2Преобразование физической координаты X графической области в логическую координату.
3Преобразование физической координаты Y графической области в логическую координату.

Правила работы

Если логическая шкала WINDOW не настроена, функция возвращает исходную координату.

После изменения VIEW или WINDOW та же исходная координата может получить другой результат: функция всегда использует текущие настройки.

Типы аргументов и отсутствие шкалы

Первый аргумент приводится к DOUBLE, второй — к INTEGER. Функция возвращает DOUBLE и сохраняет дробную часть преобразованной координаты. Селектор должен лежать в 0..3, координата должна быть конечной; нарушение сообщает MB3007. Без активного WINDOW функция возвращает переданную координату.

Физическая координата результата относится к системе VIEW: при относительной области это координата внутри неё, при VIEW SCREEN — абсолютная координата экрана. Поэтому при относительной области начало области нужно прибавить отдельно, если требуется абсолютный пиксель. При активном WINDOW слишком узкая область, не позволяющая выполнить преобразование, сообщает MB3007.

Диагностика

  • MB3010: функция PMAP вызвана без активного графического режима SCREEN 1..10.
  • MB3007: селектор функции PMAP имеет недопустимое значение.

Пример

SCREEN 1
VIEW SCREEN (10, 10)-(20, 20)
WINDOW SCREEN (100, 200)-(110, 210)

PRINT PMAP(100, 0)
PRINT PMAP(200, 1)
PRINT PMAP(10, 2)
PRINT PMAP(10, 3)
SLEEP

Первые вызовы вычисляют физическое положение логической точки; последующие вызовы выполняют обратное преобразование.
