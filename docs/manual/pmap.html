Функция PMAP

PMAP — встроенная функция языка Axiom, которая переводит одну координату между логической системой координат оператора WINDOW и физической системой координат текущего viewport.

Для чего нужна функция PMAP

Функция PMAP нужна тогда, когда программе одновременно требуется логическая шкала WINDOW и реальные пиксельные координаты viewport.

Где работает функция PMAP

Функция PMAP работает только после выбора графического режима SCREEN 1..10.

Синтаксис

PMAP(coordinate, selector)

Аргументы

АргументОписание
coordinateЧисловая координата, которую функция PMAP должна преобразовать.
selectorЧисло, которое задаёт направление преобразования.

Что возвращает функция PMAP

Функция PMAP возвращает одну преобразованную координату. Для оси X и для оси Y используются разные селекторы.

Селекторы

СелекторПреобразование
0Преобразование логической координаты X в физическую координату viewport.
1Преобразование логической координаты Y в физическую координату viewport.
2Преобразование физической координаты X viewport в логическую координату.
3Преобразование физической координаты Y viewport в логическую координату.

Правила работы

Если программа не включила оператор WINDOW, функция PMAP работает относительно текущего договора viewport.

Если программа изменила оператор VIEW или оператор WINDOW, результат функции PMAP тоже меняется, потому что меняется связь между логическими и физическими координатами.

Диагностика

  • MB3010: функция PMAP вызвана без активного графического режима SCREEN 1..10.
  • MB3007: селектор функции PMAP имеет недопустимое значение.

Пример

SCREEN 1
VIEW SCREEN (10, 10)-(20, 20)
WINDOW SCREEN (100, 200)-(110, 210)

PRINT PMAP(100, 0)
PRINT PMAP(200, 1)
PRINT PMAP(10, 2)
PRINT PMAP(10, 3)
SLEEP

В этом примере функция PMAP сначала переводит логические координаты WINDOW в физические координаты viewport, а затем переводит координаты viewport обратно в логическую шкалу.
