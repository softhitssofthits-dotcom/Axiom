Справочник языка Axiom

Axiom — язык программирования со статической проверкой типов и выполнением скомпилированного байт-кода. Справочник определяет синтаксис, типы данных, правила выполнения операторов и поведение встроенных функций.

Полный справочник

Справочник содержит 271 встроенную функцию, 335 форм вызова, 67 операторов и форм инструкций, 24 операций в выражениях. Каталоги содержат отдельную карточку для каждой сущности.
