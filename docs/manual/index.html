Введение

Справочное руководство

Это руководство объединяет вводные главы, обзорные главы и справочные статьи по текущей реализации языка. Его можно читать последовательно или использовать как справочник по отдельным операторам, типам данных и функциям.

Содержание

  • Сводка
  • Обзорные главы
  • Последовательность изучения

Сводка

Что включает руководство

  • Материал основан на текущей реализации языка без предположений о будущих возможностях.
  • Операторы и управляющие конструкции вынесены на отдельные страницы.
  • Встроенные функции сгруппированы по смыслу, но внутри описаны поштучно.

Как пользоваться руководством

  • Для поиска отдельной темы начинайте с алфавитного указателя.
  • Для последовательного чтения открывайте темы сверху вниз по меню слева.
  • Для перехода к крупному разделу используйте обзорные главы по темам.
  • Если нужна нормативная точность, сверяйтесь с docs/SPECIFICATION.md.

Обзорные главы

Данные и ввод

Быстрый переход к типам данных, объявлениям, INPUT и PRINT.

Выражения и ветвление

Переход к арифметике, логике, IF и SELECT CASE.

Массивы и встроенные функции

Связка между массивами, строковыми функциями, регулярными выражениями, файловой системой, датой и временем и числовыми функциями.

Процедуры и функции

Переход к SUB, FUNCTION и RETURN с пояснением их назначения.

Последовательность изучения

0. Алфавитный и тематический указатель

Фильтры по первой букве и по разделам: типы данных, ветвление, циклы, массивы, строковые и числовые функции.

1. Старт и первая программа

Структура файла, комментарии, первый PRINT и общий ритм работы в IDE.

2. Типы данных

INTEGER, DOUBLE, STRING, BOOLEAN, память, диапазоны и преобразования.

3. Переменные и константы

DIM, CONST, правила имён, недопустимые примеры и явный режим языка.

4. Оператор PRINT

Печать выражений, пустой PRINT, список выводимых значений и разделители ; и ,.

5. Оператор INPUT

Одиночный и множественный ввод, строки приглашения и ошибки преобразования.

6. Арифметика и логика

Операторы, приоритет, сравнения и логические комбинации условий.

7. Условие IF

Полная блочная форма IF / ELSEIF / ELSE / END IF и блочная область видимости.

8. SELECT CASE

Точные совпадения, списки, диапазоны, формы CASE IS и CASE ELSE.

9. FOR, WHILE, DO ... LOOP

Отдельные страницы по каждому семейству циклов, включая STEP, EXIT FOR и EXIT DO.

10. Процедуры и функции

Обзорная глава с переходом к отдельным статьям по SUB, FUNCTION и RETURN.

11. Массивы

Одномерные массивы, включительные границы и типичные ошибки времени выполнения при индексировании.

12. Строковые функции

LEN, LEFT, RIGHT, MID, LCASE, UCASE с отдельными секциями.

13. Функции регулярных выражений

REGEXISMATCH, REGEXMATCH, REGEXEXTRACT, REGEXREPLACE и REGEXCOUNT для поиска по образцу.

14. Функции файловой системы

READFILE, READALLLINES, READLINES, GETFILES, GETDIRS, запись текста, проверки существования, пути и сведения о файлах.

15. Функции даты и времени

DATE, TIME, NOW и TIMER с каноническими строковыми форматами и счётчиком секунд с полуночи.

16. Числовые и преобразующие функции

INT, STR, VAL с правилами округления вниз, форматирования и преобразования текста в число.

17. Диагностика

Как различать синтаксические ошибки, смысловые ошибки и ошибки времени выполнения.

18. Примеры программ и шпаргалка

Практика, повтор синтаксиса и краткие рабочие образцы.

Последнее структурное обновление руководства: 2026-04-20. Компоновка ориентируется на классические технические справочники, а текст и деление по темам определяются текущей реализацией языка.
