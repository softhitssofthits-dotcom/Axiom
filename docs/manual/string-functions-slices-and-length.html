Раздел

Длина строки и фрагменты

Раздел длины строки и фрагментов описывает функции LEN, LEFT, RIGHT и MID — основные средства измерения текста и извлечения его частей. Ниже приведены отдельные формы четырёх функций, а не одна общая конструкция. Функции работают в текстовых и графических программах без предварительного вызова оператора SCREEN.

LEN

LEN — встроенная функция языка Axiom, которая возвращает длину строки в символах.

Единицей длины служит UTF-16 кодовая единица. Базовые символы кириллицы и латиницы считаются одной единицей, а редкие символы за пределами базовой многоязычной плоскости Unicode — например, эмодзи — считаются двумя: LEN("😀") даёт 2. Из этого следует поведение LEFT, RIGHT и MID: границы фрагментов отсчитываются в тех же единицах, поэтому фрагмент может разрезать такую пару и вернуть отдельную половинку. Полный символ из такой пары читают функции ASC/ASCW и строят CHR/CHRW, а REVERSE переворачивает строку, сохраняя пары целиком.

Синтаксис

length = LEN(text)

Аргументы

text задаёт строку, длину которой нужно получить. Результат имеет тип INTEGER.

Формы LEN, LEFT, RIGHT и MID без аргумента unit измеряют длину и позиции в единицах UTF-16. Пустая строка имеет длину 0; один эмодзи вроде 😀 имеет длину 2. Срез может разделить суррогатную пару, если граница проходит между её двумя единицами; автоматического расширения среза до целого символа нет.

PRINT LEN("А😀Б")        ' 4
PRINT MID("А😀Б", 2, 2)  ' 😀
PRINT LEN(LEFT("😀", 1)) ' 1: половина суррогатной пары

Пример длины строки

' Длина строки "Пример"
PRINT LEN("Пример")

Результат:

6

Форма с выбором единицы

length = LEN(text, unit)

Аргумент text должен быть строкой. Аргумент unit должен быть строкой "UTF16", "CODEPOINT" или "GRAPHEME"; регистр букв не учитывается, пробелы автоматически не удаляются. UTF16 выбирает кодовые единицы UTF-16 и совпадает с прежней формой. CODEPOINT выбирает Unicode-коды и сохраняет целые суррогатные пары. GRAPHEME выбирает составные символы: например, буква с отдельным знаком ударения или семейный эмодзи считаются одной графемой.

Функция возвращает INTEGER — число выбранных единиц. Для пустой строки результат равен 0.

Ограничения и диагностика

Выбор графем использует границы текстовых элементов текущей платформы .NET. Функция не измеряет пиксельную ширину и не нормализует строку. В режиме CODEPOINT отдельная повреждённая суррогатная единица сохраняется и считается одной позицией. Результаты INSTR и других прежних позиционных функций измеряются в UTF-16; их нельзя напрямую использовать как позиции в другой единице.

Неизвестный или пустой unit даёт MB3007, в том числе для пустого text. Неверный тип аргумента отклоняется до исполнения.

Пример составного символа

PRINT LEN("👨‍👩‍👧‍👦", "GRAPHEME") ' 1

Запускаемая программа: unicode_units.axm.

LEFT

LEFT — встроенная функция языка Axiom, которая возвращает указанное количество символов с начала строки.

Синтаксис

part = LEFT(text, count)

Аргументы

text задаёт исходную строку. count задаёт, сколько символов нужно взять слева.

Количество символов слева

Количество символов должно быть строго больше нуля. Иначе выполнение завершается диагностикой MB3007.

Пример первых символов

' Первые два символа строки
PRINT LEFT("abcdef", 2)

Результат:

ab

Форма с выбором единицы

part = LEFT(text, count, unit)

Аргумент text должен быть строкой. Аргумент unit должен быть строкой "UTF16", "CODEPOINT" или "GRAPHEME"; регистр букв не учитывается, пробелы автоматически не удаляются. UTF16 выбирает кодовые единицы UTF-16 и совпадает с прежней формой. CODEPOINT выбирает Unicode-коды и сохраняет целые суррогатные пары. GRAPHEME выбирает составные символы: например, буква с отдельным знаком ударения или семейный эмодзи считаются одной графемой.

Аргумент count должен быть положительным INTEGER и задаёт число выбранных единиц. Если единиц осталось меньше, функция возвращает весь доступный фрагмент. Для пустой строки результат — пустая строка. Результат имеет тип STRING.

PRINT LEFT("éтекст", 1, "GRAPHEME") ' é

RIGHT

RIGHT — встроенная функция языка Axiom, которая возвращает указанное количество символов с конца строки.

Синтаксис

part = RIGHT(text, count)

Аргументы

text задаёт исходную строку. count задаёт, сколько символов нужно взять справа.

Количество символов справа

Количество символов должно быть строго больше нуля. Иначе выполнение завершается диагностикой MB3007.

Пример последних символов

' Последние два символа строки
PRINT RIGHT("abcdef", 2)

Результат:

ef

MID

MID — встроенная функция языка Axiom, которая возвращает фрагмент строки, начиная с заданной позиции.

Синтаксис

part = MID(text, start, count)

Аргументы

text задаёт исходную строку. start задаёт начальную позицию. count задаёт длину фрагмента.

Позиция начала и длина фрагмента

Позиция считается с единицы. Если начало находится правее конца строки, функция возвращает пустую строку. Начальная позиция меньше 1 и количество меньше либо равно нулю дают MB3007.

Пример фрагмента из середины

' Фрагмент строки с третьего символа длиной два знака
PRINT MID("abcdef", 3, 2)

Результат:

cd

Форма с выбором единицы

part = MID(text, start, count, unit)

Аргумент text должен быть строкой. Аргумент unit должен быть строкой "UTF16", "CODEPOINT" или "GRAPHEME"; регистр букв не учитывается, пробелы автоматически не удаляются. UTF16 выбирает кодовые единицы UTF-16 и совпадает с прежней формой. CODEPOINT выбирает Unicode-коды и сохраняет целые суррогатные пары. GRAPHEME выбирает составные символы: например, буква с отдельным знаком ударения или семейный эмодзи считаются одной графемой.

Аргумент count должен быть положительным INTEGER и задаёт число выбранных единиц. Если единиц осталось меньше, функция возвращает весь доступный фрагмент. Для пустой строки результат — пустая строка. Результат имеет тип STRING.

Аргумент start должен быть INTEGER от 1 и задаёт позицию в выбранной единице. Если позиция находится за концом строки, результат — пустая строка. В форме с unit аргумент count обязателен.

PRINT MID("А👨‍👩‍👧‍👦éБ", 2, 2, "GRAPHEME") ' 👨‍👩‍👧‍👦é
