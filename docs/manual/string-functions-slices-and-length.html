Раздел

Длина строки и фрагменты

Раздел длины строки и фрагментов описывает функции LEN, LEFT, RIGHT и MID — основные средства измерения текста и извлечения его частей.

LEN

Функция LEN возвращает длину строки в символах.

Синтаксис

length = LEN(text)

Аргументы

text задаёт строку, длину которой нужно получить. Результат имеет тип INTEGER.

Пример длины строки

' Длина строки "Пример"
PRINT LEN("Пример")

Результат:

6

LEFT

Функция LEFT возвращает указанное количество символов с начала строки.

Синтаксис

part = LEFT(text, count)

Аргументы

text задаёт исходную строку. count задаёт, сколько символов нужно взять слева.

Количество символов слева

Количество символов должно быть строго больше нуля. Иначе выполнение завершается диагностикой MB3007.

Пример первых символов

' Первые два символа строки
PRINT LEFT("abcdef", 2)

Результат:

ab

RIGHT

Функция RIGHT возвращает указанное количество символов с конца строки.

Синтаксис

part = RIGHT(text, count)

Аргументы

text задаёт исходную строку. count задаёт, сколько символов нужно взять справа.

Количество символов справа

Количество символов должно быть строго больше нуля. Иначе выполнение завершается диагностикой MB3007.

Пример последних символов

' Последние два символа строки
PRINT RIGHT("abcdef", 2)

Результат:

ef

MID

Функция MID возвращает фрагмент строки, начиная с заданной позиции.

Синтаксис

part = MID(text, start, count)

Аргументы

text задаёт исходную строку. start задаёт начальную позицию. count задаёт длину фрагмента.

Позиция начала и длина фрагмента

Позиция считается с единицы. Если начало находится правее конца строки, функция возвращает пустую строку. Начальная позиция меньше 1 и количество меньше либо равно нулю дают MB3007.

Пример фрагмента из середины

' Фрагмент строки с третьего символа длиной два знака
PRINT MID("abcdef", 3, 2)

Результат:

cd
