Встроенные функции

Строковые функции

В текущей реализации языка к строковым функциям относятся LEN, LEFT, RIGHT, MID, TRIM, LTRIM, RTRIM, REVERSE, CONTAINS, STARTSWITH, ENDSWITH, REPLACE, INSTR, INSTRREV, SUBSTRCOUNT, REPEAT, SPACE, STRING, PADLEFT, PADRIGHT, CENTER, INSERT, REMOVE, ASC, CHR, LCASE, UCASE, SPLIT и JOIN. Поиск по регулярному выражению вынесен на отдельную страницу функций регулярных выражений. Ниже собраны формы вызова, пограничные случаи и ссылки на короткие примеры для ручной проверки.

Главные правила

  • LEN принимает один строковый аргумент и возвращает длину как INTEGER.
  • Для LEFT и RIGHT количество символов должно быть строго больше нуля; иначе выполнение завершается диагностикой времени выполнения MB3007.
  • Для MID начальная позиция должна быть не меньше 1, а количество символов должно быть строго больше нуля; нарушение любого из условий даёт диагностику времени выполнения MB3007.
  • Если начальная позиция MID выходит за пределы строки, функция возвращает пустую строку.
  • TRIM, LTRIM и RTRIM поддерживают две формы: без второго аргумента они убирают пробелы, а со вторым аргументом убирают по краям символы из указанного набора.
  • REPEAT и SPACE допускают ноль, но не допускают отрицательное количество повторов или пробелов.
  • STRING использует только первый символ строки-заполнителя; пустой заполнитель даёт MB3007.
  • CONTAINS, STARTSWITH, ENDSWITH и REPLACE ищут совпадения строго по кодам символов, с учётом регистра.
  • Для CONTAINS, STARTSWITH и ENDSWITH пустой фрагмент считается найденным и даёт TRUE.
  • REPLACE заменяет все найденные вхождения; пустой заменяемый фрагмент даёт MB3007.
  • INSTR возвращает позицию первого найденного фрагмента, считая с 1, или 0, если совпадение не найдено.
  • INSTRREV возвращает позицию последнего найденного фрагмента, считая с 1, или 0, если совпадение не найдено; форма с начальной позицией ищет назад от указанного места.
  • SUBSTRCOUNT считает непересекающиеся вхождения фрагмента; пустой фрагмент даёт MB3007.
  • LCASE и UCASE возвращают новое строковое значение и не изменяют исходную переменную автоматически.
  • PADLEFT и PADRIGHT дополняют строку до нужной ширины; необязательный заполнитель по умолчанию равен пробелу, а пустой заполнитель даёт MB3007.
  • CENTER центрирует строку в поле заданной ширины; необязательный заполнитель по умолчанию равен пробелу, а при нечётной разнице ширины лишний символ заполнения добавляется справа.
  • INSERT и REMOVE используют начальные позиции с единицы.
  • INSERT при позиции правее конца строки вставляет фрагмент в конец.
  • REMOVE допускает нулевое количество удаляемых символов и мягко обрезает удаление по правому краю строки.
  • ASC и CHR работают с кодами символов Unicode, а не с историческими основными и расширенными однобайтовыми таблицами.
  • ASC возвращает код первого символа строки; пустая строка даёт MB3007.
  • CHR принимает допустимый код символа Unicode; отрицательные значения, коды за верхней границей Unicode и суррогатный диапазон дают MB3007.
  • SPLIT разбивает строку в новый массив строк с границами 1 TO N; пустая исходная строка даёт пустой выделенный массив 1 TO 0.
  • JOIN собирает строковый массив в строку; для невыделенного или пустого массива результатом является пустая строка.

LEN

Форма вызова: LEN(<текст> AS STRING) AS INTEGER

Функция возвращает длину строки в символах.

PRINT LEN("Пример")
  • принимает ровно один строковый аргумент;
  • пустая строка дает результат 0;
  • неверный тип или число аргументов относится к диагностике использования функции.

LEFT

Форма вызова: LEFT(<текст> AS STRING, <количество> AS INTEGER) AS STRING

Функция возвращает указанное число символов с левого края строки.

PRINT LEFT("пример", 3)
  • если количество символов больше длины строки, возвращается вся строка;
  • количество символов меньше 1 даёт диагностику времени выполнения MB3007;
  • сама форма вызова должна соответствовать сигнатуре функции.

RIGHT

Форма вызова: RIGHT(<текст> AS STRING, <количество> AS INTEGER) AS STRING

Функция возвращает указанное число символов с правого края строки.

PRINT RIGHT("пример", 4)
  • если количество символов больше длины строки, возвращается вся строка;
  • функция работает симметрично LEFT, только берет символы справа;
  • количество символов меньше 1 даёт диагностику времени выполнения MB3007.

MID

Форма вызова: MID(<текст> AS STRING, <начало> AS INTEGER, <количество> AS INTEGER) AS STRING

Функция извлекает фрагмент строки, начиная с заданной позиции и длиной в указанное количество символов.

PRINT MID("пример", 3, 4)
  • начальная позиция отсчитывается с единицы;
  • если начало выходит за пределы строки, возвращается пустая строка;
  • начальная позиция меньше 1 или количество символов меньше 1 дают диагностику времени выполнения MB3007.

TRIM

Формы вызова: TRIM(<текст> AS STRING) AS STRING, TRIM(<текст> AS STRING, <символы> AS STRING) AS STRING

Удаляет символы с обоих краёв строки. Без второго аргумента убирает пробелы. Со вторым аргументом убирает по краям любые символы из строки chars.

PRINT TRIM("--пример--", "-")
  • TRIM(" hello ") даёт hello;
  • TRIM("--hello--", "-") тоже даёт hello;
  • если chars пустая строка, исходный текст возвращается без изменений;
  • середина строки не затрагивается.

LTRIM

Формы вызова: LTRIM(<текст> AS STRING) AS STRING, LTRIM(<текст> AS STRING, <символы> AS STRING) AS STRING

Работает как TRIM, но удаляет символы только с левого края строки.

PRINT LTRIM("xyxyhello", "xy")
  • без второго аргумента убирает пробелы слева;
  • со вторым аргументом использует строку chars как набор удаляемых символов;
  • правый край строки не меняется.

RTRIM

Формы вызова: RTRIM(<текст> AS STRING) AS STRING, RTRIM(<текст> AS STRING, <символы> AS STRING) AS STRING

Работает как TRIM, но удаляет символы только с правого края строки.

PRINT RTRIM("helloxyxy", "xy")
  • без второго аргумента убирает пробелы справа;
  • со вторым аргументом использует строку chars как набор удаляемых символов;
  • левый край строки не меняется.

REVERSE

Форма вызова: REVERSE(<текст> AS STRING) AS STRING

Возвращает строку с символами в обратном порядке.

PRINT REVERSE("abcd")
  • принимает один строковый аргумент;
  • пустая строка остаётся пустой;
  • исходная переменная не изменяется автоматически.

CONTAINS

Форма вызова: CONTAINS(<текст> AS STRING, <фрагмент> AS STRING) AS BOOLEAN

Проверяет, есть ли строка fragment внутри строки text.

PRINT CONTAINS("Hello", "ell")
  • возвращает TRUE, если фрагмент найден;
  • сравнение выполняется строго по кодам символов, с учётом регистра;
  • пустой fragment считается найденным и даёт TRUE.

STARTSWITH

Форма вызова: STARTSWITH(<текст> AS STRING, <фрагмент> AS STRING) AS BOOLEAN

Проверяет, начинается ли строка text с указанного фрагмента.

PRINT STARTSWITH("Hello", "He")
  • возвращает TRUE, если начало строки совпадает с fragment;
  • сравнение выполняется строго по кодам символов, с учётом регистра;
  • пустой fragment считается найденным и даёт TRUE.

ENDSWITH

Форма вызова: ENDSWITH(<текст> AS STRING, <фрагмент> AS STRING) AS BOOLEAN

Проверяет, заканчивается ли строка text указанным фрагментом.

PRINT ENDSWITH("Hello", "lo")
  • возвращает TRUE, если конец строки совпадает с fragment;
  • сравнение выполняется строго по кодам символов, с учётом регистра;
  • пустой fragment считается найденным и даёт TRUE.

REPLACE

Форма вызова: REPLACE(<текст> AS STRING, <старый фрагмент> AS STRING, <новый фрагмент> AS STRING) AS STRING

Возвращает новую строку, где все найденные вхождения заменяемого фрагмента заменены на новый фрагмент.

PRINT REPLACE("one two two", "two", "three")
  • если заменяемый фрагмент не найден, возвращается исходный текст без изменений;
  • поиск выполняется строго по кодам символов, с учётом регистра;
  • пустой заменяемый фрагмент даёт диагностику времени выполнения MB3007.

INSTR

Формы вызова: INSTR(<текст> AS STRING, <фрагмент> AS STRING) AS INTEGER, INSTR(<начало> AS INTEGER, <текст> AS STRING, <фрагмент> AS STRING) AS INTEGER

Возвращает позицию первого найденного фрагмента внутри строки. Позиция считается с единицы. Если совпадение не найдено, результат равен 0.

PRINT INSTR("banana", "na")
PRINT INSTR(4, "banana", "na")
  • INSTR("banana", "na") даёт 3;
  • INSTR(4, "banana", "na") начинает поиск с четвёртой позиции и даёт 5;
  • поиск выполняется строго по кодам символов, с учётом регистра;
  • пустой фрагмент возвращает текущую позицию поиска, если она не больше LEN(text) + 1;
  • start < 1 даёт диагностику времени выполнения MB3007.

INSTRREV

Формы вызова: INSTRREV(<текст> AS STRING, <фрагмент> AS STRING) AS INTEGER, INSTRREV(<начало> AS INTEGER, <текст> AS STRING, <фрагмент> AS STRING) AS INTEGER

Возвращает позицию последнего найденного фрагмента внутри строки. Позиция считается с единицы. Если совпадение не найдено, результат равен 0. Форма с начальной позицией начинает поиск назад от указанного места.

PRINT INSTRREV("banana", "na")
  • INSTRREV("banana", "na") даёт 5;
  • INSTRREV(4, "banana", "na") ищет назад от четвёртой позиции и даёт 3;
  • если начальная позиция больше длины строки, поиск начинается с конца строки;
  • поиск выполняется строго по кодам символов, с учётом регистра;
  • пустой фрагмент в форме с двумя аргументами возвращает LEN(text) + 1;
  • пустой фрагмент в форме с начальной позицией возвращает значение начальной позиции плюс 1, но не больше LEN(text) + 1;
  • начальная позиция меньше 1 даёт диагностику времени выполнения MB3007.

SUBSTRCOUNT

Форма вызова: SUBSTRCOUNT(<текст> AS STRING, <фрагмент> AS STRING) AS INTEGER

Возвращает количество непересекающихся вхождений фрагмента внутри строки.

PRINT SUBSTRCOUNT("banana", "na")
PRINT SUBSTRCOUNT("aaaa", "aa")
  • SUBSTRCOUNT("banana", "na") даёт 2;
  • SUBSTRCOUNT("aaaa", "aa") даёт 2, потому что вхождения не пересекаются;
  • поиск выполняется строго по кодам символов, с учётом регистра;
  • пустой фрагмент даёт диагностику времени выполнения MB3007.

REPEAT

Форма вызова: REPEAT(<текст> AS STRING, <количество> AS INTEGER) AS STRING

Повторяет строку text указанное число раз.

PRINT REPEAT("ha", 3)
  • REPEAT("ha", 3) даёт hahaha;
  • нулевое количество повторов даёт пустую строку;
  • отрицательное количество повторов даёт диагностику времени выполнения MB3007.

SPACE

Форма вызова: SPACE(<количество> AS INTEGER) AS STRING

Возвращает строку из указанного числа пробелов.

PRINT "[" + SPACE(4) + "]"
  • нулевое количество пробелов даёт пустую строку;
  • отрицательное количество пробелов даёт диагностику времени выполнения MB3007;
  • функция удобна для выравнивания и простого заполнения строк.

STRING

Форма вызова: STRING(<количество> AS INTEGER, <заполнитель> AS STRING) AS STRING

Создаёт строку заданной длины, заполненную первым символом строки-заполнителя.

PRINT STRING(5, "ab")
  • STRING(5, "ab") даёт aaaaa;
  • нулевая длина даёт пустую строку;
  • если строка-заполнитель пустая, возникает диагностика времени выполнения MB3007.

PADLEFT

Форма вызова: PADLEFT(<текст> AS STRING, <ширина> AS INTEGER[, <заполнитель> AS STRING]) AS STRING

Дополняет строку слева до указанной ширины. Если третий аргумент не передан, используется пробел.

PRINT PADLEFT("7", 3, "0")
  • PADLEFT("7", 3) даёт 7;
  • PADLEFT("7", 3, "0") даёт 007;
  • если ширина меньше или равна длине строки, возвращается исходный текст без изменений;
  • если строка заполнителя содержит несколько символов, используется только первый;
  • отрицательная ширина или пустой заполнитель дают диагностику времени выполнения MB3007.

PADRIGHT

Форма вызова: PADRIGHT(<текст> AS STRING, <ширина> AS INTEGER[, <заполнитель> AS STRING]) AS STRING

Дополняет строку справа до указанной ширины. Если третий аргумент не передан, используется пробел.

PRINT PADRIGHT("7", 3, ".")
  • PADRIGHT("7", 3) даёт 7 ;
  • PADRIGHT("7", 3, ".") даёт 7..;
  • если ширина меньше или равна длине строки, возвращается исходный текст без изменений;
  • если строка заполнителя содержит несколько символов, используется только первый;
  • отрицательная ширина или пустой заполнитель дают диагностику времени выполнения MB3007.

CENTER

Форма вызова: CENTER(<текст> AS STRING, <ширина> AS INTEGER[, <заполнитель> AS STRING]) AS STRING

Центрирует строку в поле указанной ширины. Если третий аргумент не передан, используется пробел.

PRINT "[" + CENTER("A", 4, ".") + "]"
  • CENTER("A", 3) даёт A ;
  • CENTER("A", 4, ".") даёт .A..;
  • CENTER("AB", 5, ".") даёт .AB..;
  • если ширина меньше или равна длине строки, возвращается исходный текст без изменений;
  • если строка заполнителя содержит несколько символов, используется только первый;
  • при нечётной разнице между шириной поля и длиной текста лишний символ заполнения добавляется справа;
  • отрицательная ширина или пустой заполнитель дают диагностику времени выполнения MB3007.

INSERT

Форма вызова: INSERT(<текст> AS STRING, <начало> AS INTEGER, <фрагмент> AS STRING) AS STRING

Вставляет фрагмент в строку перед символом с указанной позицией. Позиция считается с единицы.

PRINT INSERT("abcd", 3, "-")
  • INSERT("abcd", 1, "<") даёт <abcd;
  • INSERT("abcd", 3, "-") даёт ab-cd;
  • если начальная позиция больше LEN(text) + 1, вставка выполняется в конец строки;
  • пустой фрагмент допустим и оставляет строку без изменений;
  • начальная позиция меньше 1 даёт диагностику времени выполнения MB3007.

REMOVE

Форма вызова: REMOVE(<текст> AS STRING, <начало> AS INTEGER, <количество> AS INTEGER) AS STRING

Удаляет из строки указанное количество символов, начиная с заданной позиции. Позиция считается с единицы.

PRINT REMOVE("abcdef", 2, 3)
  • REMOVE("abcdef", 2, 3) даёт aef;
  • если количество равно 0, возвращается исходная строка;
  • если начало находится правее конца строки, возвращается исходная строка без изменений;
  • если удаление выходит за правую границу строки, удаляются все доступные символы до конца;
  • начальная позиция меньше 1 или отрицательное количество дают диагностику времени выполнения MB3007.

ASC

Форма вызова: ASC(<текст> AS STRING) AS INTEGER

Возвращает код первого символа Unicode в строке.

PRINT ASC("A")
PRINT ASC(CHR(1071))
  • ASC("A") даёт 65;
  • ASC(CHR(1071)) даёт 1071;
  • функция использует код символа Unicode, а не исторические основные или расширенные однобайтовые таблицы;
  • пустая строка даёт диагностику времени выполнения MB3007.

CHR

Форма вызова: CHR(<код> AS INTEGER) AS STRING

Возвращает строку из одного символа Unicode с указанным кодом.

PRINT CHR(65)
PRINT ASC(CHR(128512))
  • CHR(65) даёт A;
  • ASC(CHR(128512)) даёт 128512;
  • функция принимает только допустимые коды символов Unicode;
  • отрицательные значения, коды выше 1114111 и суррогатный диапазон 55296..57343 дают диагностику времени выполнения MB3007.

LCASE

Форма вызова: LCASE(<текст> AS STRING) AS STRING

Переводит строку в нижний регистр.

PRINT LCASE("ПРИМЕР")
  • принимает один строковый аргумент;
  • не меняет саму исходную переменную, а возвращает новое строковое значение;
  • ошибка вызова возникает при неправильной сигнатуре.

UCASE

Форма вызова: UCASE(<текст> AS STRING) AS STRING

Переводит строку в верхний регистр.

PRINT UCASE("пример")
  • принимает один строковый аргумент;
  • возвращает новое значение, а не переписывает исходный текст автоматически;
  • по смыслу является парной функцией для LCASE.

SPLIT

Формы вызова: SPLIT(<текст> AS STRING) AS STRING(), SPLIT(<текст> AS STRING, <разделитель> AS STRING) AS STRING()

Разбивает строку на части и возвращает новый одномерный массив строк. Если разделитель не передан, используется запятая.

DIM parts() AS STRING
parts = SPLIT("red,green,blue", ",")

PRINT parts(1)
PRINT parts(2)
PRINT parts(3)
  • результат имеет тип STRING();
  • непустой результат получает компактные границы 1 TO N;
  • пустые части между разделителями сохраняются;
  • пустая исходная строка даёт пустой выделенный массив 1 TO 0;
  • пустой разделитель даёт диагностику времени выполнения MB3007.

JOIN

Формы вызова: JOIN(<части> AS STRING()) AS STRING, JOIN(<части> AS STRING(), <разделитель> AS STRING) AS STRING

Собирает элементы строкового массива в одну строку. Если разделитель не передан, используется запятая.

DIM parts() AS STRING
parts = SPLIT("red,green,blue")

PRINT JOIN(parts, "/")
  • первый аргумент должен иметь тип STRING();
  • элементы берутся в порядке их логических индексов от нижней границы к верхней;
  • невыделенный массив даёт пустую строку;
  • пустой выделенный массив 1 TO 0 тоже даёт пустую строку;
  • пустой разделитель допустим и собирает элементы без промежутка между ними.
