Текущие дата и время

Чтение текущих значений в локальном времени и в UTC.

Дата и время

Текущие дата и время

DATE

Функция DATE возвращает текущую дату в формате yyyy-MM-dd.

Синтаксис

dateText = DATE([timeZone])

Части записи. Если timeZone не указан, используется локальный часовой пояс. Если он указан, возвращается текущая дата для этого пояса.

Пример

' Текущая локальная дата и дата в UTC
PRINT DATE()
PRINT DATE("UTC")

TIME

Функция TIME возвращает текущее время в формате HH:mm:ss.

Синтаксис

timeText = TIME([timeZone])

Части записи. Если timeZone не указан, используется локальный часовой пояс. Если он указан, время вычисляется для этого пояса.

Пример

' Текущее локальное время и время в UTC
PRINT TIME()
PRINT TIME("UTC")

NOW

Функция NOW возвращает текущие дату и время в формате yyyy-MM-dd HH:mm:ss.

Синтаксис

dateTimeText = NOW([timeZone])

Части записи. Если timeZone не указан, используется локальный часовой пояс. Если он указан, дата и время вычисляются для него.

Пример

' Текущие дата и время в локальном поясе и в UTC
PRINT NOW()
PRINT NOW("UTC")

UTCDATE

Функция UTCDATE возвращает текущую дату в UTC.

Синтаксис

dateText = UTCDATE()

UTCTIME

Функция UTCTIME возвращает текущее время в UTC.

Синтаксис

timeText = UTCTIME()

UTCNOW

Функция UTCNOW возвращает текущие дату и время в UTC.

Синтаксис

dateTimeText = UTCNOW()

TIMER

Функция TIMER возвращает число секунд, прошедших с локальной полуночи текущего дня.

Синтаксис

seconds = TIMER()

Части записи. Результат имеет тип DOUBLE.

Замечания

Эта функция удобна для простых измерений времени внутри одного дня.

Пример

' Количество секунд от полуночи
PRINT TIMER()
