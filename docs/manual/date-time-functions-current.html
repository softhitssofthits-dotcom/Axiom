Справочник языка

Текущие дата и время

Раздел описывает встроенные функции DATE, TIME, NOW, UTCDATE, UTCTIME, UTCNOW и TIMER. Они читают часы среды запуска; синтаксис разных функций показан отдельно.

DATE

DATE — встроенная функция языка Axiom, которая возвращает текущую календарную дату.

Назначение

Функция позволяет прочитать системные часы в выбранном часовом поясе.

Где работает

Функция вызывается в выражениях консольных и графических программ; оператор SCREEN или CANVAS не требуется.

Синтаксис

DATE()
DATE(<часовой пояс>)

Аргументы

Форма без аргументов использует местное время среды запуска. Часовой пояс должен быть STRING: "UTC", "LOCAL" или идентификатор, который знает среда запуска. "LOCAL" означает системный местный пояс. Пустая строка и неизвестный идентификатор недопустимы; набор идентификаторов зависит от платформы.

Результат

Результат имеет тип DATE.

Правила и ограничения

Вызов читает часы заново; последовательные вызовы могут относиться к разным мгновениям, особенно около полуночи. Значение не хранит идентификатор пояса. При печати дата имеет форму yyyy-MM-dd, время HH:mm:ss, дата-время yyyy-MM-dd HH:mm:ss.

Диагностика

Компилятор отклоняет неверное количество аргументов и несовместимый тип аргумента. MB3007 возникает при недопустимом часовом поясе.

Пример

DIM value AS DATE = DATE("UTC")
PRINT ISDATE(value & "")

Ожидаемый вывод:

TRUE

Назначение

Аргументы

TIMER

TIMER — встроенная функция языка Axiom, которая возвращает число секунд, прошедших с местной полуночи.

Назначение

Функция позволяет определить положение текущего мгновения внутри местных суток.

Где работает

Функция вызывается в выражениях консольных и графических программ; оператор SCREEN или CANVAS не требуется.

Синтаксис

TIMER()

Аргументы

Аргументов нет.

Результат

Результат DOUBLE в диапазоне от 0 включительно до 86400 исключительно; дробная часть задаёт долю секунды.

Правила и ограничения

Это местные системные часы, а не монотонный счётчик времени работы программы. В полночь значение начинается заново; перевод системных часов может изменить разность двух показаний.

Диагностика

Компилятор отклоняет неверное количество аргументов и несовместимый тип аргумента.

Пример

DIM seconds AS DOUBLE = TIMER()
PRINT seconds >= 0 AND seconds < 86400

Ожидаемый вывод:

TRUE
