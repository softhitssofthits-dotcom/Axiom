Функция KEYPRESS

KEYPRESS — встроенная функция языка Axiom, которая ищет непрочитанное нажатие указанной клавиши. При успехе она возвращает TRUE и удаляет найденное событие из очереди.

Применение

Используйте функцию для однократного действия: подтвердить выбор, открыть меню или переключить режим. Текущее удержание проверяет KEYDOWN, а строку следующей клавиши возвращает INKEY.

Контекст выполнения

Функция читает очередь активной поверхности ввода: текстовой области IDE либо окна SCREEN 0 или SCREEN 1..10.

Направляйте ввод в окно программы; правила фокуса описаны в разделе клавиатуры и мыши.

Синтаксис

KEYPRESS(<клавиша>)

Аргументы

АргументТипОписание
<клавиша>STRINGИмя клавиши. Используются те же имена, что в KEYDOWN и ON KEY; полный перечень приведён в таблице имён клавиш. Например "LEFT", "ESCAPE", "PAGE UP", "A".

Что возвращает функция KEYPRESS

Результат имеет тип BOOLEAN.

  • TRUE, если в очереди есть ещё не прочитанное нажатие указанной клавиши. Это нажатие удаляется из очереди.
  • FALSE, если такого нажатия сейчас нет, имя пустое или среда выполнения не предоставляет клавиатурную очередь.

Поведение очереди

Из очереди удаляется только первое подходящее событие. Остальные клавиши сохраняют порядок и могут быть прочитаны функциями INKEY, KEYPRESS или обработчиком ON KEY.

PRINT KEYPRESS("LEFT")
PRINT KEYPRESS("LEFT")

Если в очереди есть ровно одно нажатие LEFT, первый вызов возвращает TRUE, а следующий — FALSE.

Сравнение с KEYDOWN

ФункцияЧто проверяетЧитает очередь
KEYPRESS("LEFT")Было ли отдельное нажатие LEFTДа, подходящее событие удаляется
KEYDOWN("LEFT")Удерживается ли LEFT прямо сейчасНет

Модификаторы

В сочетании со знаком + последняя часть обозначает клавишу события. Все предыдущие части должны удерживаться.

Вызов KEYPRESS("CTRL+ALT+DELETE") ищет событие DELETE при удержании CTRL и ALT. Найденное событие DELETE удаляется.

IF KEYPRESS("CTRL+LEFT") THEN
    PRINT "CTRL+LEFT"
END IF

IF KEYPRESS("CTRL+ALT+DELETE") THEN
    PRINT "CTRL+ALT+DELETE"
END IF

Аналогично, в KEYPRESS("CTRL+F+A+X") удерживаются CTRL, F и A, а нажатием завершающей клавиши служит X. Проверка удержания всех четырёх выполняется через KEYDOWN.

Electron IDE передаёт модифицированные клавиши из консоли, окна CANVAS или нативного окна SCREEN, имеющего фокус. Клавиша Windows в пользовательский ввод программы не передаётся.

Аргумент функции и сохранение очереди

Передайте STRING с именем клавиши либо сочетанием. KEYPRESS возвращает BOOLEAN: TRUE означает, что функция извлекла одно подходящее событие; FALSE — что подходящего события нет. Остальные события, включая повторные нажатия той же клавиши, остаются в очереди.

Для сочетания последняя клавиша должна находиться в очереди событий, а предыдущие должны удерживаться в момент вызова. Пустая строка возвращает FALSE. Проверка не требует графического окна.

Диагностика

  • MB2004: вызов встроенной функции KEYPRESS получен без аргумента или с лишними аргументами.
  • MB2003: аргумент встроенной функции KEYPRESS нельзя связать как строку.

Пример одноразового нажатия

FOR i = 1 TO 20000
    IF KEYPRESS("ESCAPE") THEN
        PRINT "ESC pressed once"
        EXIT FOR
    END IF
NEXT

Запускаемые примеры

  • KEYPRESS: одиночное нажатие клавиши
  • KEYPRESS: нажатие с модификатором
