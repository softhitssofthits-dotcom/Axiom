Функция KEYPRESS

KEYPRESS — встроенная функция языка Axiom, которая проверяет, была ли указанная клавиша нажата и ещё не прочитана программой. В отличие от KEYDOWN, встроенная функция KEYPRESS не показывает текущее удержание клавиши: одно нажатие даёт один результат TRUE, после чего событие считается израсходованным.

Для чего нужна функция KEYPRESS

Встроенная функция KEYPRESS удобна для действий, которые должны произойти один раз на одно нажатие: открыть меню, подтвердить выбор, переключить режим или обработать одиночную стрелку. Если нужна непрерывная реакция, пока клавиша удерживается, используется встроенная функция KEYDOWN. Если нужно получить саму следующую клавишу как строку, используется встроенная функция INKEY.

Где работает функция KEYPRESS

Встроенная функция KEYPRESS читает клавиатурную очередь активной среды выполнения. Если программа работает без оператора SCREEN, очередь поступает из обычной поверхности ввода среды разработки. Если программа явно выбрала SCREEN 0 или графический режим SCREEN 1..10, очередь поступает из окна SCREEN.

Встроенная функция KEYPRESS выполняется BytecodeVm после компиляции.

Синтаксис

KEYPRESS(keyText)

Аргументы

АргументТипОписание
keyTextSTRINGИмя клавиши. Поддерживаются те же канонические имена и алиасы, что у KEYDOWN и ON KEY, например "LEFT", "ESCAPE", "PAGE UP", "A".

Что возвращает функция KEYPRESS

Тип результата: BOOLEAN.

  • TRUE, если в очереди есть ещё не прочитанное нажатие указанной клавиши. Это нажатие удаляется из очереди.
  • FALSE, если такого нажатия сейчас нет, имя пустое или среда выполнения не предоставляет клавиатурную очередь.

Поведение очереди

Встроенная функция KEYPRESS ищет первое подходящее нажатие в клавиатурной очереди и удаляет только его. Неподходящие клавиши сохраняют порядок и остаются доступными для последующего INKEY, KEYPRESS или ON KEY.

PRINT KEYPRESS("LEFT")
PRINT KEYPRESS("LEFT")

Если пользователь нажал LEFT один раз, первый вызов напечатает TRUE, а второй — FALSE.

Сравнение с KEYDOWN

ФункцияЧто проверяетЧитает очередь
KEYPRESS("LEFT")Было ли отдельное нажатие LEFTДа, подходящее событие удаляется
KEYDOWN("LEFT")Удерживается ли LEFT прямо сейчасНет

Модификаторы

Встроенная функция KEYPRESS умеет проверять строковый аккорд клавиш через знак +. Последняя часть строки считается основной клавишей события, а все предыдущие части должны быть удержаны.

Проще говоря, KEYPRESS("CTRL+ALT+DELETE") значит: CTRL и ALT уже нажаты, а программа ждёт именно нажатие последней клавиши DELETE. Если оно пришло, событие DELETE расходуется.

IF KEYPRESS("CTRL+LEFT") THEN
    PRINT "CTRL+LEFT"
END IF

IF KEYPRESS("CTRL+ALT+DELETE") THEN
    PRINT "CTRL+ALT+DELETE"
END IF

Форма KEYPRESS("CTRL+F+A+X") означает: CTRL, F и A удержаны, а событием пришла клавиша X. Если нужно проверить только удержание всех клавиш, используется встроенная функция KEYDOWN.

В Electron IDE модифицированные клавиши доставляются в очередь программы из активной поверхности ввода программы. Ввод поступает из консоли, окна CANVAS или нативного окна SCREEN, когда соответствующая поверхность имеет фокус. Клавиша Windows не доставляется как часть пользовательского ввода программы.

Диагностика

  • MB2004: вызов встроенной функции KEYPRESS получен без аргумента или с лишними аргументами.
  • MB2003: аргумент встроенной функции KEYPRESS нельзя связать как строку.

Пример одноразового нажатия

FOR i = 1 TO 20000
    IF KEYPRESS("ESCAPE") THEN
        PRINT "ESC pressed once"
        EXIT FOR
    END IF
NEXT

Запускаемые примеры

  • KEYPRESS: одиночное нажатие клавиши
  • KEYPRESS: нажатие с модификатором
