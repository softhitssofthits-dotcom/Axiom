Начало работы

Для первого знакомства с языком достаточно понять три вещи: программа читается сверху вниз, новые имена обычно объявляются через DIM, а результат работы проще всего наблюдать через PRINT.

Главные правила

  • первая программа должна быть короткой и проверяемой за один запуск;
  • для начала достаточно понимать последовательное чтение программы, DIM и PRINT;
  • для подробностей переходите к соседним справочным страницам по PRINT, INPUT и типам данных.

Показательные примеры

Для первых запусков в IDE используйте несколько коротких файлов.

  • PRINT: базовое выражение
  • PRINT: пустой оператор
  • INPUT: одна переменная
  • DIM: базовое объявление
  • Сводный пример для первой проверки

Как устроен файл программы

Исходные тексты обычно хранятся в файлах с расширением .axm. Интерпретатор воспринимает такой файл как последовательность инструкций и блоков. Поэтому программу следует записывать так, чтобы её можно было читать сверху вниз.

Что полезно помнить с самого начала:
  • одна строка обычно содержит одну инструкцию;
  • пустые строки допустимы и помогают отделять смысловые блоки;
  • вложенные конструкции должны быть явно закрыты: END IF, END SELECT, END WHILE, LOOP, NEXT.

Первая программа

Самая простая проверка среды — вывести строку в панель Output.

PRINT "Привет, Axiom!"

Оператор PRINT вычисляет выражение после своего имени и отправляет результат в поток вывода. Если в качестве аргумента дана строка в кавычках, на экран попадает именно этот текст.

PRINT "Заголовок"
PRINT 42
PRINT 1 + 2 * 3
PRINT

Этот пример показывает, что PRINT выводит строки, числа, результаты выражений и пустую строку.

Комментарии

Комментарий можно записать двумя способами: через апостроф ' и через ключевое слово REM. Оба варианта оставляют пояснение для читателя и не влияют на выполнение программы.

' Современная краткая запись комментария
REM Классическая запись комментария

PRINT "Комментарий в вывод не попадает"

Комментарий уместен там, где нужно кратко пояснить назначение блока. Он должен дополнять код, а не пересказывать его построчно.

Как запускать примеры

  1. Откройте Axiom.Ide.
  2. Создайте новый документ или откройте существующий файл .axm.
  3. Вставьте пример программы.
  4. Запустите его через кнопку Run.
  5. Посмотрите результат в панели Output.

Если программа не запускается

Чаще всего причина связана с синтаксисом или с неверным типом данных. В этом случае нужно посмотреть, на какой строке и в каком месте интерпретатор остановил выполнение.

Краткий итог

Что стоит запомнить сразу

  • программа Axiom читается сверху вниз;
  • PRINT является самым простым способом увидеть результат;
  • комментарии задаются через ' или REM;
  • первые примеры должны быть короткими и легко проверяемыми.
