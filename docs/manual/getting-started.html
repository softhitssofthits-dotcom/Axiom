Знакомство с Axiom

Axiom — язык программирования для работы с числами, строками, файлами и графикой. Раздел описывает исходный файл, основные правила записи программы, проверку и выполнение в IDE.

Исходный файл и выполнение

Исходный файл Axiom содержит объявления и исполняемые инструкции. Инструкции верхнего уровня выполняются последовательно. Оператор PRINT направляет вывод в консоль IDE.

Исходные программы хранятся в файлах .axm. IDE предоставляет редактирование, проверку, выполнение и остановку программы. Для графического вывода и обработки действий клавиатуры и мыши предусмотрены отдельные конструкции языка.

Пример консольной программы

Новый документ создаётся командой Файл → Новый (Ctrl+N). Следующая программа объявляет целочисленную переменную и выводит её значение и результат вычисления:

DIM count AS INTEGER = 3
PRINT "Количество: "; count
PRINT count * 2

Оператор DIM объявляет count типа INTEGER с начальным значением 3. В первом PRINT точка с запятой соединяет части вывода без дополнительного разделителя. Второй PRINT выводит результат выражения count * 2; значение переменной не изменяется.

Строки и комментарии

Инструкции разделяются переводом строки. Пустые строки не выполняются. Двоеточие не поддерживается как разделитель инструкций.

Комментарий начинается с апострофа ' и продолжается до конца строки. Допустимы отдельная строка комментария и комментарий после инструкции. Альтернативная форма начинается со слова REM, отделённого от текста пробельным символом. Комментарии исключаются из исполняемых инструкций.

' Количество предметов в коробке.
DIM count AS INTEGER = 3

REM Вывести удвоенное количество.
PRINT count * 2  ' Значение count остаётся прежним.

Программа выводит 6. Текст комментариев и пустая строка на результат не влияют.

Ключевые слова и имена не зависят от регистра букв: PRINT и print обозначают один оператор, а count и Count — одну переменную. В справочнике ключевые слова записаны заглавными буквами. Имена переменных используют латинские буквы, цифры и подчёркивание; начинать имя с цифры нельзя. Русский текст можно писать внутри строк и в комментариях. Подробности приведены в статье «Имена и области видимости».

Группы инструкций

Блоки ограничиваются ключевыми словами соответствующей конструкции. Например, IF выполняет блок при истинном условии и завершается словами END IF:

DIM count AS INTEGER = 3
IF count > 0 THEN
    PRINT "Есть предметы"
    PRINT count
END IF

Программа выводит:

Есть предметы
3

Обе инструкции PRINT принадлежат блоку IF. При ложном условии они пропускаются.

Отступы не определяют границы блока. Цикл FOR завершается оператором NEXT, процедура SUB — словами END SUB.

Диагностика

Диагностика содержит код, описание и место в исходном тексте. Например, обращение PRINT coutn при объявленной переменной count вызывает MB2001: имя coutn не объявлено.

Ошибки выполнения зависят от значений и состояния ресурсов; пример — деление на ноль. Правила перехвата и передачи ошибок описаны в разделе «Обработка ошибок».
