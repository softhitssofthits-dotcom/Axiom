Мышь

Функция MOUSEPRESS

MOUSEPRESS(buttonNumber) проверяет, было ли в очереди мыши ещё не прочитанное нажатие указанной кнопки. Функция подходит для опросного сценария, когда программе нужно один раз заметить факт нажатия, а не только текущее удержание кнопки.

Синтаксис

MOUSEPRESS(buttonNumber)

Аргументы

  • buttonNumber - номер кнопки мыши типа INTEGER.

Возвращаемое значение

Тип результата: BOOLEAN.

  • 1 - левая кнопка;
  • 2 - правая кнопка;
  • 3 - средняя кнопка;
  • для неподдерживаемого номера функция возвращает FALSE.

Очередь нажатий мыши

  • MOUSEPRESS() удаляет только первое подходящее событие нажатия, поэтому повторный вызов вернёт FALSE, пока пользователь не нажмёт кнопку снова;
  • неподходящие нажатия не теряются и остаются доступными для следующих вызовов MOUSEPRESS();
  • это именно нажатие кнопки, а не проверка удержания: для текущего состояния используйте MOUSEBUTTON();
  • в текущем срезе у мыши нет отдельного пользовательского обработчика ON MOUSE, кликов, колеса и захвата указателя.

Пример одноразового нажатия

IF MOUSEPRESS(1) THEN
    PRINT "LEFT ONCE"
END IF

Ручная проверка

  • MOUSEPRESS: одноразовые нажатия кнопок мыши

Диагностика

Диагностика MB2004 возникает, если аргумент не передан, а MB2003 - если передан аргумент неподходящего типа.
