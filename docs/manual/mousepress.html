Функция MOUSEPRESS

MOUSEPRESS — встроенная функция языка Axiom, которая проверяет, было ли в очереди мыши ещё не прочитанное нажатие указанной кнопки. Встроенная функция MOUSEPRESS подходит для опросного сценария, когда программе нужно один раз заметить факт нажатия, а не только текущее удержание кнопки, как у MOUSEBUTTON.

Для чего нужна функция MOUSEPRESS

Встроенная функция MOUSEPRESS нужна для чтения одного события нажатия кнопки мыши из очереди. Функция удаляет только первое подходящее событие, поэтому повторный вызов вернёт FALSE, пока пользователь не нажмёт кнопку снова.

Где работает функция MOUSEPRESS

Встроенная функция MOUSEPRESS работает при активном графическом режиме SCREEN 1..10 или при активном CANVAS. Без активной рисуемой поверхности выполнение сообщает диагностику MB3010.

Встроенная функция MOUSEPRESS выполняется BytecodeVm после компиляции.

Синтаксис

MOUSEPRESS(buttonNumber)

Аргументы

АргументТипОписание
buttonNumberINTEGERНомер кнопки мыши: 1 — левая, 2 — правая, 3 — средняя.

Что возвращает функция MOUSEPRESS

Тип результата: BOOLEAN.

  • TRUE, если в очереди есть ещё не прочитанное нажатие указанной кнопки. Это нажатие удаляется из очереди.
  • FALSE, если такого нажатия сейчас нет или передан неподдерживаемый номер кнопки.

Очередь нажатий мыши

  • Встроенная функция MOUSEPRESS удаляет только первое подходящее событие нажатия, поэтому повторный вызов вернёт FALSE, пока пользователь не нажмёт кнопку снова.
  • Неподходящие нажатия не теряются и остаются доступными для следующих вызовов MOUSEPRESS.
  • Это именно нажатие кнопки, а не проверка удержания: для текущего состояния используется встроенная функция MOUSEBUTTON.
  • Отпускание, перемещение и колесо не читаются функцией MOUSEPRESS, но доступны обработчикам оператора ON MOUSE.

Пример одноразового нажатия

IF MOUSEPRESS(1) THEN
    PRINT "LEFT ONCE"
END IF

Ручная проверка

  • MOUSEPRESS: одноразовые нажатия кнопок мыши

Диагностика

  • MB2004: в встроенную функцию MOUSEPRESS аргумент не передан.
  • MB2003: в встроенную функцию MOUSEPRESS передан аргумент неподходящего типа.
  • MB3010: встроенная функция MOUSEPRESS вызвана без активного графического режима SCREEN и без активного CANVAS.
