Тайлсеты TILESET

TILESET — встроенный тип данных языка Axiom, который хранит атлас одинаковых тайлов. На этой странице собраны разные сущности: тип TILESET, встроенные функции LOADTILESET, TILECOUNT, TILEWIDTH, TILEHEIGHT и оператор DRAWTILE. Синтаксис ниже относится не к одной общей конструкции, а к нескольким разным формам работы с тайлсетом.

Что такое TILESET

TILESET — встроенный тип данных языка Axiom, который хранит загруженное изображение-атлас и разметку одинаковых тайлов внутри этого атласа.

Каждый тайл в значении TILESET имеет одну и ту же ширину и одну и ту же высоту. Нумерация тайлов для пользователя начинается с 1. Первый тайл берётся из левого верхнего угла сетки, затем тайлы идут слева направо и сверху вниз.

Когда использовать TILESET

Тип TILESET нужен для тех случаев, когда одно изображение содержит набор повторно используемых клеток одинакового размера: фрагменты карты, декорации, панели, иконки или небольшие игровые блоки.

Функция LOADTILESET загружает такой атлас, функции TILECOUNT, TILEWIDTH и TILEHEIGHT читают его свойства, а оператор DRAWTILE выводит выбранный тайл на современный холст.

Где работает TILESET

Тип TILESET и функции LOADTILESET, TILECOUNT, TILEWIDTH, TILEHEIGHT работают со значением тайлсета как с данными.

Оператор DRAWTILE работает только при активном CANVAS. Координаты x и y подчиняются тому же договору, что и остальные современные графические операторы: без CAMERA это экранные координаты холста, после CAMERA это мировые координаты, а итоговая отрисовка обрезается активным VIEWPORT.

Синтаксис

DIM name AS TILESET

name = LOADTILESET(path, tileWidth, tileHeight)
name = LOADTILESET(path, tileWidth, tileHeight, margin)
name = LOADTILESET(path, tileWidth, tileHeight, margin, spacing)

TILECOUNT(tileset)
TILEWIDTH(tileset)
TILEHEIGHT(tileset)

DRAWTILE tileset, tileIndex, x, y

LOADTILESET поддерживает три формы. Если аргументы margin и spacing не указаны, они считаются равными 0.

Функции TILECOUNT, TILEWIDTH и TILEHEIGHT читают уже загруженное или пустое значение TILESET.

Оператор DRAWTILE выводит один тайл в его натуральном размере. Отдельной формы масштабирования или поворота у этого оператора в текущем срезе нет.

Части записи

АргументОписание

spacingНеотрицательный промежуток в пикселях между соседними тайлами внутри атласа.

Что делают оператор и функции

Функция LOADTILESET загружает изображение, проверяет, что сетка тайлов точно укладывается в размеры атласа, и возвращает значение TILESET.

Функция TILECOUNT возвращает общее число тайлов в тайлсете. Функции TILEWIDTH и TILEHEIGHT возвращают ширину и высоту одного тайла в пикселях.

Оператор DRAWTILE вырезает из атласа один тайл по номеру tileIndex и рисует его на активном CANVAS.

Правила работы

  • Тип TILESET допускает пустое значение переменной. Например, после DIM tiles AS TILESET переменная уже существует, но ещё не содержит загруженного атласа.
  • Для пустого значения TILESET функции TILECOUNT, TILEWIDTH и TILEHEIGHT возвращают 0.
  • Попытка вызвать оператор DRAWTILE для пустого значения TILESET считается ошибкой времени выполнения.
  • Сетка тайлов должна точно совпадать с размерами изображения с учётом margin и spacing. Частично заполненный последний ряд или последний столбец не допускается.
  • Отступ margin применяется с обеих сторон каждой оси. Если после его вычитания не помещается полный тайл, загрузка завершается ошибкой MB3005, даже для очень большого положительного отступа. Промежуток spacing применяется только между соседними тайлами: для атласа из одного тайла допустим большой неотрицательный промежуток, который не меняет число тайлов. После неудачной загрузки прежнее значение переменной тайлсета сохраняется. Проверить оба случая можно в примере числовых границ.
  • Тайлсеты в текущем срезе работают только как источник одинаковых тайлов. На этой странице не описываются TILEMAP, слои тайловой карты и загрузка карт Tiled.
  • Оператор DRAWTILE рисует тайл в натуральном размере tileWidth x tileHeight. Если нужна произвольная масштабируемая графика, для этого подходят DRAWIMAGE и DRAWSPRITE.

Пример

DIM tiles AS TILESET

' Загружаем атлас из примеров и берём тайлы размером 16 x 16 пикселей.
tiles = LOADTILESET("../../graphics/sprites/assets/walk_sheet.png", 16, 16)

CANVAS 160, 90

BEGINFRAME
' В первом кадре рисуем первый тайл.
CLS RGB(20, 24, 32)
DRAWTILE tiles, 1, 24, 24
PRESENT
SLEEP

BEGINFRAME
' Во втором кадре рисуем четвёртый тайл из того же атласа.
CLS RGB(12, 16, 24)
DRAWTILE tiles, 4, 88, 40
PRESENT
SLEEP

Ручная проверка

Этот файл можно открыть в Axiom.Ide и запустить как короткую проверку поведения типа TILESET и оператора DRAWTILE.

  • DRAWTILE: вывод тайла из тайлсета

Диагностика

  • MB3007: путь path пустой.
  • MB3007: аргументы tileWidth или tileHeight не являются положительными целыми значениями.
  • MB3007: аргументы margin или spacing являются отрицательными.
  • MB3007: аргумент tileIndex не указывает существующий тайл тайлсета.
  • MB3005: файл тайлсета не удалось загрузить, изображение отсутствует или сетка тайлов не совпадает с размерами атласа.
  • MB3005: оператор DRAWTILE получил пустое значение TILESET.
  • MB3010: оператор DRAWTILE вызван без активного CANVAS.

Проверка свойств без графического окна

Эти короткие примеры загружают существующие ресурсы репозитория и выводят свойства тайлсета или карты в текстовую панель IDE. Оператор CANVAS не требуется. Для запуска нужен загрузчик ресурсов IDE; консольный CLI не загружает TILESET и TILEMAP.

  • TILECOUNT: проверка свойства
  • TILEWIDTH: проверка свойства
  • TILEHEIGHT: проверка свойства

Короткие проверки функций

Короткие примеры выводят ожидаемый результат в текстовую панель IDE. Примеры загрузки используют существующие ресурсы репозитория и реальные относительные пути; отдельный графический холст для чтения свойств не требуется.

  • LOADTILESET: короткая проверка результата

Нулевой символ в пути ресурса

Функции LOADIMAGE, LOADSPRITE, LOADTILESET и LOADTILEMAP требуют строковый путь без нулевого символа. Такой символ отклоняется до раскрытия переменных окружения: загрузчик не использует часть пути перед ним. Неверный путь даёт MB3005, которую можно перехватить оператором TRY/CATCH; программа продолжает работу после обработки ошибки.

Короткий запускаемый пример: отказ загрузки изображения по пути с нулевым символом.

DIM picture AS IMAGE
TRY
    picture = LOADIMAGE("рисунок.png" + CHR(0) + "другой.png")
CATCH err
    PRINT "Отказ загрузки: "; err.Code
END TRY
