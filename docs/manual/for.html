Оператор FOR

FOR ... NEXT — оператор языка Axiom, который повторяет блок операторов, пока управляющая переменная проходит заданный числовой диапазон. Такой цикл применяют, когда ход повторения удобно выразить начальным значением, конечным значением и шагом изменения счётчика.

Когда использовать FOR

Оператор FOR используется для циклов с заранее заданным счётом. Перед первым проходом Axiom присваивает счётчику начальное значение, затем перед каждым проходом проверяет, не вышел ли счётчик за конечную границу.

Если повторение зависит от общего логического условия, а не от счётчика, обычно удобнее использовать WHILE или DO ... LOOP. Если же нужно пройти от одного числового значения к другому, FOR делает намерение программы явным.

Синтаксис

FOR <счётчик> = <начало> TO <конец> [STEP <шаг>]
    [<операторы>]
    [EXIT FOR]
    [CONTINUE FOR]
    [<операторы>]
NEXT

Параметры и части синтаксиса

  • <счётчик> — управляющая переменная цикла. Она получает начальное значение перед первым проходом и автоматически изменяется после каждой итерации.
  • <начало> — числовое выражение, задающее первое значение счётчика.
  • <конец> — числовое выражение, задающее конечную границу цикла.
  • STEP <шаг> — необязательная часть, задающая изменение счётчика после прохода. Если STEP не указан, используется шаг 1.
  • <операторы> — инструкции, которые выполняются при каждом проходе цикла.
  • EXIT FOR — необязательный досрочный выход из ближайшего окружающего цикла FOR ... NEXT.
  • CONTINUE FOR — необязательный пропуск оставшейся части текущей итерации с переходом к инкременту счётчика.
  • NEXT завершает тело цикла и возвращает управление к проверке следующего значения счётчика.

Счётчик цикла

Строка FOR всегда создаёт счётчик сама: у цикла есть собственный локальный счётчик, видимый только внутри тела и недоступный после NEXT (обращение к нему вне цикла — ошибка MB2001). В Axiom ровно одна модель счётчика — как в C#/Python/JS.

Имя счётчика не должно быть занято во внешней области: если переменная с таким именем уже объявлена (DIM, CONST, параметр, внешний цикл), строка FOR не может объявить свой счётчик — это ошибка MB2016. Если занявшее имя принадлежит переменной неподходящего типа (например STRING), Axiom сообщает именно про тип — MB2009.

Тип счётчика Axiom выводит из выражений <начало>, <конец> и <шаг>: это INTEGER или DOUBLE (а также LONG). Записать тип внутри строки FOR нельзя — счётчик всегда локальный.

Как счётчик задаёт повторение

При входе в цикл Axiom один раз вычисляет выражения <начало>, <конец> и <шаг>, после чего присваивает начальное значение счётчику.

При положительном шаге тело цикла выполняется, пока текущее значение счётчика не больше конечной границы. После каждого прохода счётчик увеличивается на шаг и проверка повторяется.

При отрицательном шаге цикл идёт в обратном направлении: тело выполняется, пока текущее значение счётчика не меньше конечной границы. После каждого прохода счётчик изменяется на отрицательный шаг.

Если начальное значение уже находится за границей диапазона для указанного направления, тело цикла не выполняется ни одного раза. Если начальное и конечное значения совпадают, цикл выполняется один раз при ненулевом шаге.

Границы, шаг и выход

  • STEP 0 в Axiom считается ошибкой времени выполнения MB3004.
  • EXIT FOR передаёт управление на оператор, следующий после соответствующего NEXT.
  • CONTINUE FOR пропускает оставшуюся часть текущей итерации и переходит к инкременту счётчика через NEXT. Подробнее — на странице оператора CONTINUE.
  • Циклы FOR ... NEXT можно вкладывать друг в друга. Имена счётчиков вложенных циклов не должны совпадать ни между собой, ни с именами переменных во внешней области — иначе связывание сообщит об ошибке MB2016.
  • Форма завершения цикла в Axiom — только NEXT.
  • Если имя счётчика уже занято константой или переменной во внешней области, цикл не связывается как корректный FOR: MB2016 (занятость имени) или MB2009 (неподходящий тип занявшей переменной).

Форма завершения счётного цикла — отдельный оператор NEXT без имени счётчика.

STEP 0 не запускает такой цикл, а сообщает ошибку времени выполнения MB3004.

Значение счётчика после цикла

Счётчик FOR живёт только внутри цикла: после NEXT он исчезает, и обращение к нему — ошибка MB2001 («Имя не объявлено»). Никакого итогового значения в переменной с именем счётчика не остаётся.

Если итоговое значение нужно дальше, скопируйте его в свою переменную внутри тела цикла (см. пример выше). При этом:

  • Нормальное завершение: в копии — последнее обработанное значение (для диапазона 1 TO 3 это 3).
  • Выход через EXIT FOR: в копии — значение на момент выхода.
  • Тело не выполнилось ни разу (начальное значение за границей диапазона): копирование не происходило, переменная-копия сохраняет своё прежнее значение.

Вложенные циклы. Поскольку счётчик каждого цикла локальный и имя не должно пересекаться с внешними, ловушка «внутренний цикл тихо ломает внешний» исчезает на уровне контракта: вложенный FOR i при занятом имени i — ошибка связывания MB2016 ещё до запуска.

FOR i = 1 TO 3
    FOR i = 1 TO 2    ' ошибка MB2016: имя i занято счётчиком внешнего цикла
        PRINT i
    NEXT
NEXT

Диагностика

  • MB2009 — выражение счётчика или занявшее имя переменной имеет тип, который нельзя использовать в FOR.
  • MB2016 — имя счётчика уже занято во внешней области (DIM, CONST, параметр, внешний цикл): счётчик FOR всегда локальный.
  • MB3004 — шаг цикла равен нулю.
  • MB2013 — EXIT FOR используется вне цикла FOR ... NEXT.
  • MB2037 — CONTINUE FOR используется вне цикла FOR ... NEXT.
  • MB2001 — счётчик, созданный самой строкой FOR, используется после выхода из его области видимости.

Пример счётного цикла

В этом примере цикл печатает нечётные числа от 1 до 5. Начальное и конечное значения вычисляются перед запуском цикла, а шаг 2 прибавляется после каждого прохода.

FOR i = 1 TO 5 STEP 2
    PRINT i
NEXT

Результат:

1
3
5

Пример: сохранить значение после цикла

Счётчик после NEXT недоступен, поэтому итоговое значение нужно скопировать в свою переменную внутри тела. В копии окажется последнее обработанное значение.

DIM afterValue AS INTEGER

FOR i = 1 TO 3
    PRINT i
    afterValue = i
NEXT

PRINT "после=" & afterValue

Результат:

1
2
3
после=3

Попытка прочитать сам счётчик после цикла — ошибка MB2001: PRINT i за пределами цикла не скомпилируется.
