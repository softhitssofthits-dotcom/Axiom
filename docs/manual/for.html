Цикл FOR

FOR задает счетный цикл, в котором управляющая переменная проходит диапазон от начального значения до конечного с шагом STEP или со значением шага по умолчанию. Конструкция применяется там, где число проходов определяется диапазоном и направлением счета.

Сводка

FOR создает локальную управляющую переменную цикла и выполняет тело, пока текущее значение не выйдет за пределы диапазона. В Axiom подтверждены формы с TO, необязательным STEP и досрочным выходом через EXIT FOR.

Синтаксис

FOR <счётчик> = <начальное выражение> TO <конечное выражение> [STEP <шаг>]
    <инструкции>
NEXT

Части синтаксиса

  • <счётчик> — управляющая переменная цикла.
  • <начальное выражение> — значение, с которого начинается цикл.
  • <конечное выражение> — значение, которым ограничивается диапазон цикла.
  • [STEP <шаг>] — необязательная часть. Если она опущена, шаг равен 1.
  • <инструкции> — тело цикла между FOR и NEXT.

Замечания

  • Управляющая переменная цикла должна иметь тип INTEGER, LONG или DOUBLE.
  • Если STEP не указан, используется шаг 1 того же числового типа, что и управляющая переменная.
  • Начальное, конечное и шаговое выражения вычисляются один раз перед запуском цикла.
  • Отрицательный STEP поддерживается и используется для убывающего счета.
  • Значение STEP 0 синтаксически допустимо, но приводит к диагностике времени выполнения.
  • Имя счетчика существует только внутри цикла; после NEXT оно недоступно как обычная переменная программы.
  • В текущей реализации после NEXT не указывается имя счетчика.
  • EXIT FOR завершает ближайший окружающий цикл FOR ... NEXT.

Ручная проверка

Для ручной проверки в IDE удобно использовать готовые примеры из тематического каталога цикла FOR.

  • FOR: базовый счет по возрастанию
  • FOR: явный положительный шаг
  • FOR: досрочный выход через EXIT FOR
  • FOR: вложенные циклы

Примеры

FOR i = 1 TO 3
    PRINT i
NEXT
FOR value = 10 TO 2 STEP -2
    PRINT value
NEXT
FOR i = 1 TO 5
    IF i = 3 THEN
        EXIT FOR
    END IF

    PRINT i
NEXT

PRINT "done"

Диагностика

  • MB2009 — управляющая переменная FOR имеет неподдерживаемый тип и не может быть счетчиком цикла.
  • MB2013 — EXIT FOR использован вне ближайшего цикла FOR ... NEXT.
  • MB3004 — цикл запущен с STEP 0.
  • MB2001 — имя счетчика используется после завершения цикла, где оно уже вне области видимости.
