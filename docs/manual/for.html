Оператор FOR

FOR ... NEXT — оператор языка Axiom, который повторяет блок операторов, пока управляющая переменная проходит заданный числовой диапазон. Такой цикл применяют, когда ход повторения удобно выразить начальным значением, конечным значением и шагом изменения счётчика.

Когда использовать FOR

Оператор FOR используется для циклов с заранее заданным счётом. Перед первым проходом Axiom присваивает счётчику начальное значение, затем перед каждым проходом проверяет, не вышел ли счётчик за конечную границу.

Если повторение зависит от общего логического условия, а не от счётчика, обычно удобнее использовать WHILE или DO ... LOOP. Если же нужно пройти от одного числового значения к другому, FOR делает намерение программы явным.

Синтаксис

FOR <счётчик> = <начало> TO <конец> [STEP <шаг>]
    [<операторы>]
    [EXIT FOR]
    [CONTINUE FOR]
    [<операторы>]
NEXT

Части записи

  • <счётчик> — управляющая переменная цикла. Она получает начальное значение перед первым проходом и автоматически изменяется после каждой итерации.
  • <начало> — числовое выражение, задающее первое значение счётчика.
  • <конец> — числовое выражение, задающее конечную границу цикла.
  • STEP <шаг> — необязательная часть, задающая изменение счётчика после прохода. Если STEP не указан, используется шаг 1.
  • <операторы> — инструкции, которые выполняются при каждом проходе цикла.
  • EXIT FOR — необязательный досрочный выход из ближайшего окружающего цикла FOR ... NEXT.
  • CONTINUE FOR — необязательный пропуск оставшейся части текущей итерации с переходом к инкременту счётчика.
  • NEXT завершает тело цикла и возвращает управление к проверке следующего значения счётчика.

Счётчик цикла

Если имя счётчика заранее не объявлено в доступной области, строка FOR создаёт счётчик сама. Такой счётчик видим только внутри тела цикла и после NEXT недоступен.

Если перед циклом уже есть изменяемая переменная с тем же именем, объявленная через DIM как INTEGER, LONG или DOUBLE, Axiom использует эту переменную как счётчик. После завершения цикла она остаётся доступной и содержит итоговое значение.

В Axiom тип счётчика не записывается внутри строки FOR. Для явного типа объявите переменную отдельным оператором DIM перед циклом.

Как счётчик задаёт повторение

При входе в цикл Axiom один раз вычисляет выражения <начало>, <конец> и <шаг>, после чего присваивает начальное значение счётчику.

При положительном шаге тело цикла выполняется, пока текущее значение счётчика не больше конечной границы. После каждого прохода счётчик увеличивается на шаг и проверка повторяется.

При отрицательном шаге цикл идёт в обратном направлении: тело выполняется, пока текущее значение счётчика не меньше конечной границы. После каждого прохода счётчик изменяется на отрицательный шаг.

Если начальное значение уже находится за границей диапазона для указанного направления, тело цикла не выполняется ни одного раза. Если начальное и конечное значения совпадают, цикл выполняется один раз при ненулевом шаге.

Границы, шаг и выход

  • STEP 0 в Axiom считается ошибкой времени выполнения MB3004.
  • EXIT FOR передаёт управление на оператор, следующий после соответствующего NEXT.
  • CONTINUE FOR пропускает оставшуюся часть текущей итерации и переходит к инкременту счётчика через NEXT. Подробнее — на странице оператора CONTINUE.
  • Циклы FOR ... NEXT можно вкладывать друг в друга. Для вложенных циклов используйте разные счётчики.
  • Форма завершения цикла в текущем Axiom — только NEXT.
  • Если счётчик заранее объявлен как константа или как переменная неподдерживаемого типа, цикл не связывается как корректный FOR.

В QuickBASIC после NEXT мог указываться счётчик, например NEXT i, а также встречались формы закрытия нескольких вложенных циклов одной строкой. В Axiom документируемая и поддержанная форма завершения счётного цикла — отдельный оператор NEXT без имени счётчика.

В QuickBASIC нулевой шаг мог приводить к бесконечному циклу. В Axiom STEP 0 не запускает такой цикл, а сообщает ошибку времени выполнения MB3004.

Пример счётного цикла

В этом примере цикл печатает нечётные числа от 1 до 5. Начальное и конечное значения вычисляются перед запуском цикла, а шаг 2 прибавляется после каждого прохода.

FOR i = 1 TO 5 STEP 2
    PRINT i
NEXT

Результат:

1
3
5

Пример с заранее объявленным счётчиком

Если значение счётчика нужно прочитать после цикла, объявите его до строки FOR.

DIM i AS INTEGER

FOR i = 1 TO 3
    PRINT i
NEXT

PRINT "после=" & i

Результат:

1
2
3
после=4

Ручная проверка

Эти файлы можно открыть в Axiom.Ide и запустить как короткие проверки поведения FOR ... NEXT.

  • FOR: базовый счёт по возрастанию
  • FOR: явный шаг
  • FOR: досрочный выход через EXIT FOR
  • FOR: вложенные циклы
  • FOR: заранее объявленный счётчик через DIM
  • Ошибка: STEP 0

Диагностика

  • MB2009 — заранее объявленный счётчик имеет тип, который нельзя использовать в FOR.
  • MB3004 — шаг цикла равен нулю.
  • MB2013 — EXIT FOR используется вне цикла FOR ... NEXT.
  • MB2037 — CONTINUE FOR используется вне цикла FOR ... NEXT.
  • MB2001 — счётчик, созданный самой строкой FOR, используется после выхода из его области видимости.
