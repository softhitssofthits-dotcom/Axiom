Оператор цикла FOR

Цикл FOR подходит для повторения по счётчику, когда диапазон уже известен заранее или естественно выражается начальным, конечным значением и шагом. В такой форме сам язык берёт на себя изменение счётчика, а программа сосредотачивается на действиях внутри каждого прохода.

Сводка

Цикл FOR используется, когда число проходов определяется диапазоном от начального значения до конечного. Счётчик изменяется автоматически, а направление цикла задаётся знаком шага STEP.

Синтаксис

FOR counter = startExpression TO endExpression [STEP stepExpression]
    [statements]
NEXT

Части записи

counter задаёт управляющую переменную цикла. Она получает начальное значение перед первым проходом и затем автоматически изменяется после каждой итерации.

Если имя counter заранее объявлено через DIM как изменяемая переменная типа INTEGER, LONG или DOUBLE, FOR использует эту переменную как счётчик. Если такого объявления нет, FOR создаёт счётчик сам и его область видимости ограничена телом цикла. Форма объявления типа прямо внутри строки FOR в Axiom не вводится: для явного типа используйте отдельный DIM перед циклом.

startExpression и endExpression определяют границы диапазона. Необязательное stepExpression задаёт шаг изменения счётчика. Если шаг не указан, используется 1.

Замечания

Практически FOR выбирают тогда, когда нужно пройти по последовательности значений предсказуемым количеством шагов: например, посчитать элементы, напечатать диапазон или выполнить несколько одинаковых проходов.

  • Начальное, конечное и шаговое выражения вычисляются один раз перед запуском цикла.
  • Отрицательный STEP используется для убывающего счёта.
  • STEP 0 синтаксически допустим, но приводит к ошибке времени выполнения.
  • EXIT FOR завершает ближайший окружающий цикл FOR ... NEXT.
  • Счётчик, созданный самой строкой FOR, существует только внутри цикла и после NEXT недоступен как обычная переменная программы.
  • Счётчик, заранее объявленный через DIM, сохраняет обычную область видимости этой переменной и после NEXT содержит значение, на котором цикл завершился.

Пример

FOR i = 10 TO 2 STEP -2
    IF i = 4 THEN
        EXIT FOR
    END IF

    PRINT i
NEXT

Если нужно явно задать тип счётчика или использовать его после цикла, объявите переменную перед FOR:

DIM i AS INTEGER

FOR i = 1 TO 3
    PRINT i
NEXT

PRINT "after=" & i

Ручная проверка

  • FOR: базовый счёт по возрастанию
  • FOR: явный положительный шаг
  • FOR: досрочный выход через EXIT FOR
  • FOR: вложенные циклы
  • FOR: заранее объявленный счётчик через DIM

Диагностика

Ошибки возможны, если счётчик имеет неподдерживаемый тип, если заранее объявленный счётчик является константой, если используется STEP 0, если EXIT FOR стоит вне цикла или если имя счётчика, созданного самим FOR, используется уже после выхода из своей области видимости.
