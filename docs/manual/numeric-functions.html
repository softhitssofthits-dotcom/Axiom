Встроенные функции

Числовые, математические и преобразующие функции

Axiom использует короткие имена функций в традиции BASIC. Тригонометрические и обратные тригонометрические функции работают в радианах. На этой странице собраны преобразующие, арифметические, тригонометрические, гиперболические и логарифмические функции, подтверждённые текущей реализацией.

Главные правила

  • INT остаётся традиционной функцией BASIC: выполняет округление вниз и возвращает INTEGER с проверкой диапазона.
  • FIX отбрасывает дробную часть к нулю и возвращает тот же числовой тип, что и аргумент.
  • ROUND округляет до целого по правилу округления половин от нуля.
  • RND() не принимает аргументов и возвращает псевдослучайное значение типа DOUBLE в диапазоне [0, 1).
  • ABS, MIN, MAX, CLAMP, SETSIGN, FLOOR, CEIL, ROUND и FIX сохраняют числовое семейство аргумента по контракту функции.
  • SIN, COS, TAN, ATN, ATN2, ASIN, ACOS, ASINH, ACOSH, ATANH, SINH, COSH, TANH, SQR, CBRT, EXP, LOG, LOG10, LOG2 и POW возвращают DOUBLE.
  • Ошибки области допустимых значений идут через диагностику времени выполнения MB3007, а переполнение и неконечные результаты через MB3008.

Традиционные функции и преобразование

INT

Форма вызова: INT(<значение>) AS INTEGER

Округляет значение вниз и затем пытается вернуть результат как INTEGER.

STR

Форма вызова: STR(<значение>) AS STRING

Преобразует числовое значение в строку с инвариантным форматом представления.

VAL

Форма вызова: VAL(<текст> AS STRING) AS DOUBLE

Пытается прочитать число из строки. Некорректный текст даёт 0.

Базовая математика

ABS

ABS(<число>) возвращает модуль числа и сохраняет исходный числовой тип.

RND

RND() возвращает псевдослучайное число типа DOUBLE в диапазоне от 0 включительно до 1 не включительно. В текущей версии языка функция вызывается без аргументов.

SGN

SGN(<число>) возвращает -1, 0 или 1 как INTEGER.

MIN

MIN(<левое число>, <правое число>) возвращает меньшее из двух чисел.

MAX

MAX(<левое число>, <правое число>) возвращает большее из двух чисел.

CLAMP

CLAMP(<значение>, <нижняя граница>, <верхняя граница>) ограничивает значение диапазоном [нижняя граница, верхняя граница]. Если верхняя граница меньше нижней, выполнение завершается диагностикой времени выполнения.

SETSIGN

SETSIGN(<значение>, <источник знака>) переносит знак второго аргумента на первый и возвращает результат в числовом типе первого аргумента.

Тригонометрия

SIN

SIN(<угол>) возвращает синус угла в радианах.

COS

COS(<угол>) возвращает косинус угла в радианах.

TAN

TAN(<угол>) возвращает тангенс угла в радианах.

ATN

ATN(<значение>) возвращает арктангенс значения.

ATN2

ATN2(<ордината>, <абсцисса>) возвращает угол по координатам (абсцисса, ордината) с учётом квадранта.

Обратная тригонометрия

ASIN

ASIN(<значение>) возвращает арксинус. Аргумент должен лежать в диапазоне [-1, 1].

ACOS

ACOS(<значение>) возвращает арккосинус. Аргумент должен лежать в диапазоне [-1, 1].

Гиперболические функции

ASINH

ASINH(<значение>) возвращает обратный гиперболический синус.

ACOSH

ACOSH(<значение>) возвращает обратный гиперболический косинус. Аргумент должен быть не меньше 1.

ATANH

ATANH(<значение>) возвращает обратный гиперболический тангенс. Аргумент должен лежать строго внутри интервала (-1, 1).

SINH

SINH(<значение>) возвращает гиперболический синус.

COSH

COSH(<значение>) возвращает гиперболический косинус.

TANH

TANH(<значение>) возвращает гиперболический тангенс.

Корни, степени и логарифмы

SQR

SQR(<значение>) возвращает квадратный корень. Аргумент должен быть неотрицательным.

CBRT

CBRT(<значение>) возвращает кубический корень.

EXP

EXP(<показатель>) вычисляет e^показатель.

LOG

LOG(<значение>) вычисляет натуральный логарифм. Аргумент должен быть строго больше нуля.

LOG10

LOG10(<значение>) вычисляет десятичный логарифм. Аргумент должен быть строго больше нуля.

LOG2

LOG2(<значение>) вычисляет двоичный логарифм. Аргумент должен быть строго больше нуля.

POW

POW(<основание>, <показатель>) возводит число в степень. Недопустимая область определения даёт диагностику времени выполнения.

Округление и отсечение

FLOOR

FLOOR(<значение>) округляет число вниз и возвращает тот же числовой тип.

CEIL

CEIL(<значение>) округляет число вверх и возвращает тот же числовой тип.

ROUND

ROUND(<значение>) округляет к ближайшему целому по правилу округления половин от нуля.

FIX

FIX(<значение>) отбрасывает дробную часть к нулю без перехода к INTEGER.

Сравнение INT, FIX и ROUND

INT(-3.9) даёт -4, FIX(-3.9) даёт -3, а ROUND(-3.9) даёт -4.
