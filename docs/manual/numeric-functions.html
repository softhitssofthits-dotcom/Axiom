Числовые функции

Числовые функции Axiom помогают преобразовывать данные, выполнять типовые вычисления, работать со случайными значениями, углами, корнями, логарифмами и разными способами округления. Для удобства они разбиты на несколько тематических страниц.

Группы числовых функций

Числовые функции делятся по задаче: преобразование между числом и строкой, базовые вычисления, случайные значения, тригонометрия, корни, логарифмы и округление. Если нужно превратить текст в число, смотри VAL. Если нужно взять модуль, минимум или максимум, смотри базовые функции. Если нужно работать с углами, переходи к тригонометрии.

Тип результата и ошибки

  • RND() вызывается без аргументов и возвращает DOUBLE в диапазоне от 0 включительно до 1 не включительно.
  • INT возвращает результат именно в типе INTEGER, а FLOOR, CEIL, ROUND и FIX обычно сохраняют числовой тип исходного аргумента.
  • Функции вроде SQR, LOG, ASIN, ACOS и ATANH имеют ограничения по области допустимых значений. Если аргумент не подходит, программа получает диагностику времени выполнения.

Ручная проверка

  • INT: округление вниз
  • STR: преобразование числа в строку
  • VAL: чтение числа из строки
  • ABS: модуль числа
  • MIN: меньшее значение
  • RND: случайное значение
  • SIN: синус угла
  • SQR: квадратный корень
  • LOG: натуральный логарифм
  • ROUND: округление к ближайшему
