Оператор ERROR

ERROR — оператор языка Axiom, который создаёт пользовательскую ошибку времени выполнения или повторно передаёт полученное значение ERROR. Он прерывает текущую последовательность инструкций и запускает поиск обработчика.

Назначение и контекст

Оператор позволяет явно отказать в операции, когда прикладное условие не выполнено. Он доступен на верхнем уровне и в подпрограммах; пользовательские ошибки обрабатываются тем же TRY, что и системные.

Создание ошибки с кодом

ERROR <код>

Создание ошибки с сообщением

ERROR <код>, <сообщение>

Повторная передача

ERROR <значение ошибки>

Аргументы

Код имеет тип STRING и обозначает прикладной код ошибки. Он не должен быть пустым или состоять только из пробелов; другие непустые строки разрешены. Сообщение имеет тип STRING и становится текстом ошибки, включая допустимую пустую строку.

Значение ошибки имеет встроенный тип ERROR, обычно это переменная CATCH. Повторная передача сохраняет Code, Message, Line и Column исходной ошибки.

Действие и ограничения

Форма с одним кодом создаёт сообщение «Пользовательская ошибка <код>.». Созданная ошибка получает место текущего оператора. Оставшиеся инструкции текущего защищённого участка не выполняются; управление передаётся ближайшему подходящему CATCH. Без обработчика запуск завершается неуспешно.

Диагностика

MB2003 означает нестрочный код или сообщение либо неподходящее значение для повторной передачи. MB3007 возникает для пустого кода или кода из одних пробелов. Код созданной неперехваченной ошибки равен переданной строке.

Пример

TRY
    ERROR "APP001", "Нет данных"
CATCH err
    PRINT err.Code
    PRINT err.Message
END TRY
PRINT "after"

Ожидаемый вывод:

APP001
Нет данных
after
