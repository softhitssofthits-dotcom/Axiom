Оператор ERROR

ERROR — оператор языка Axiom, который принудительно создаёт ошибку времени выполнения или повторно поднимает уже пойманное значение ERROR. Оператор используют, когда программа сама обнаружила недопустимое состояние либо обработчик должен передать ошибку внешнему CATCH без потери исходных сведений.

Синтаксис

ERROR код
ERROR код, сообщение
ERROR ошибка

ERROR в начале строки — оператор. В форме ERROR ошибка слово ошибка обозначает выражение встроенного типа ERROR, например переменную из CATCH err.

код должен иметь тип STRING. сообщение тоже имеет тип STRING и является необязательным. ошибка должна иметь встроенный тип ERROR.

Параметры и части синтаксиса

код - строковый идентификатор ошибки. Для пользовательских ошибок удобно применять короткие проектные коды, например "APP001" или "FILEMODE".

сообщение - текст, который попадёт в err.Message и в диагностику времени выполнения, если ошибка не будет обработана. Если сообщение не указано, Axiom использует сообщение по умолчанию: Пользовательская ошибка <код>.

ошибка - существующее значение встроенного типа ERROR. Форма ERROR err повторно поднимает его с теми же Code, Message, Line и Column.

Повторный проброс

TRY
    TRY
        ERROR "APP003", "Original failure"
    CATCH err
        ERROR err
    END TRY
CATCH outerErr
    PRINT outerErr.Code
    PRINT outerErr.Message
    PRINT outerErr.Line
END TRY

Форма ERROR err нужна, когда внутренний обработчик не исправляет проблему, а только выполняет локальные действия и передаёт ошибку дальше. Внешний обработчик получает исходный код, сообщение и строку первоначального возникновения ошибки.

Правила

  • Пустой или состоящий только из пробелов код считается ошибкой аргумента времени выполнения.
  • Ошибку, созданную ERROR, можно перехватить тем же TRY/CATCH, что и системную ошибку времени выполнения.
  • ERROR err принимает только значение встроенного типа ERROR; строковый код и сообщение в этой форме не задаются заново.
  • Если обработчика нет, выполнение программы завершается.
  • ERROR выполняется BytecodeVm после компиляции.

Пример пользовательской ошибки

TRY
    ERROR "APP001", "Manual failure"
CATCH err
    PRINT err.Code
    PRINT err.Message
END TRY

PRINT "after"

Пример выводит код APP001, сообщение Manual failure, затем продолжает выполнение после END TRY.

Запускаемые примеры

  • ERROR: пользовательский код и перехват через CATCH
  • ERROR: повторный проброс пойманной ошибки
