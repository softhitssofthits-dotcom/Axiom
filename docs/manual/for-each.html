Обход массива FOR EACH

Когда нужно выполнить действие с каждым элементом массива, индексы и границы не нужны: достаточно назвать массив и переменную, которая получит очередное значение. Форма `FOR EACH` выполняет тело один раз на элемент и сама следит за порядком и границами.

Форма записи

Заголовок состоит из слов `FOR EACH`, необязательного модификатора, имени переменной цикла, необязательного типа после `AS`, слова `IN` и выражения-источника. Тело завершается `NEXT`, после которого можно повторить имя переменной.

FOR EACH ⟦BYVAL | BYREF⟧ <переменная> ⟦AS <тип>⟧ IN <массив>[]
    ⟦<инструкции>⟧
NEXT ⟦<имя переменной>⟧

На этом шаге реализован режим `BYVAL`; он же действует, когда модификатор не указан. Ключевое слово `BYREF` разбирается, но пока отклоняется при проверке программы.

DIM fruits[] AS STRING = ["яблоко", "банан", "апельсин"]
FOR EACH fruit IN fruits[]
    PRINT fruit
NEXT fruit

Программа выводит:

яблоко
банан
апельсин

Слова EACH и IN

`EACH` и `IN` действуют как части заголовка только сразу после `FOR`. Вне заголовка это обычные имена, поэтому переменные с такими названиями остаются допустимыми:

DIM each AS INTEGER = 3
DIM other AS INTEGER = each
PRINT other

Числовой `FOR` с `=` и `TO` продолжает работать без изменений: наличие `EACH` в языке не меняет его разбор.

Переменная цикла и тип

Переменная цикла создаётся самим циклом и доступна только внутри тела. Если тип не указан, он берётся из типа элементов массива:

DIM values[1 TO 3] AS INTEGER
values[1] = 10
values[2] = 20
values[3] = 30
DIM total AS INTEGER
FOR EACH value IN values[]
    total = total + value
NEXT
PRINT total

Программа выводит 60.

Тип после `AS` допускает только расширяющее преобразование каждого значения: например, `INTEGER` в `DOUBLE`. Сужение отклоняется при проверке программы, потому что оно потеряло бы данные.

FOR EACH value AS DOUBLE IN values[]
    PRINT value / 2
NEXT

Копия значения в режиме BYVAL

Переменная цикла получает копию элемента. Присваивание ей меняет только эту копию и не записывается в массив:

DIM values[1 TO 3] AS INTEGER
values[1] = 1
values[2] = 2
values[3] = 3
FOR EACH value IN values[]
    value = 99
NEXT
PRINT values[1], values[2], values[3]

Программа выводит 1 2 3. Если элемент является записью `TYPE`, копируется сама запись, но изменяемые значения внутри неё подчиняются общим правилам ссылок: глубокой неизменяемости `BYVAL` не создаёт.

Источник, порядок и границы

Источник вычисляется ровно один раз, до первого прохода. Поэтому вызов функции в заголовке выполняется однократно, даже если массив большой:

DIM calls AS INTEGER
FUNCTION Make() AS INTEGER[]
    calls = calls + 1
    DIM local[] AS INTEGER = [1, 2, 3]
    RETURN ARRAYCLONE(local[])
END FUNCTION
FOR EACH item IN Make()
    PRINT item
NEXT
PRINT calls

Программа выводит числа 1, 2, 3 и затем 1: функция вызвана один раз.

Обход учитывает фактические границы, включая отрицательные и нулевые. Многомерный массив обходится целиком, причём последнее измерение изменяется быстрее остальных: для массива `[1 TO 2, 1 TO 3]` порядок такой — `11, 12, 13, 21, 22, 23`.

Выделенный пустой массив даёт ноль проходов, то есть тело не выполняется ни разу. Невыделенный массив, объявленный без границ и без значения, сообщает MB3005: обходить нечего.

EXIT FOR и CONTINUE FOR

Внутри обхода действуют те же операторы управления, что и в числовом цикле: `CONTINUE FOR` переходит к следующему элементу, `EXIT FOR` завершает обход целиком.

DIM values[1 TO 5] AS INTEGER
FOR index = 1 TO 5
    values[index] = index
NEXT index
FOR EACH value IN values[]
    IF value = 3 THEN
        CONTINUE FOR
    END IF
    IF value = 5 THEN
        EXIT FOR
    END IF
    PRINT value
NEXT

Программа выводит 1, 2 и 4: тройка пропущена, пятёрка завершила обход.

Диагностика

MB2062 сообщает, что источник не является массивом. MB2063 сообщает о недопустимом типе элемента или о сужающем преобразовании в `AS`. MB2048 сообщает, что имя после `NEXT` не совпадает с именем переменной цикла. MB3005 возникает при обходе невыделенного массива. Повторное использование занятого имени даёт MB2016, как и у числового `FOR`.

Запускаемые примеры
