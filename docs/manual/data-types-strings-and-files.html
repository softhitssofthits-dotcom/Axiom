Тип STRING и фиксированные строки

STRING — тип данных Axiom для текста. Обычная строка имеет переменную длину; форма STRING * N задаёт фиксированную ширину места хранения.

Обычная строка

Строковое значение может быть получено из литерала, ввода или результата функции. Пустая строка содержит ноль единиц текста. Переменная обычного типа STRING может получать строки разной длины.

DIM title AS STRING = "Отчёт"
title = title + " готов"
PRINT title

Результат:

Отчёт готов

Синтаксис кавычек и интерполяции описан отдельно. Функции длины и фрагментов различают единицы UTF-16, кодовые точки и графемы в поддержанных формах.

Фиксированная ширина

Форма нужна для строковых мест хранения с постоянной шириной, например для короткого кода. Её можно объявить в консольной или графической программе; исходное строковое выражение при записи не меняется.

DIM <имя> AS STRING * <длина>

Имя обозначает создаваемую переменную. Длина задаёт ширину в единицах UTF-16 и должна быть целочисленной константой от 1 до 65535. Можно использовать литерал или доступную целочисленную константу. При записи короткое значение дополняется пробелами справа, а длинное обрезается справа до заданной ширины. Начальное значение без инициализатора состоит из указанного числа пробелов. Обрезка считается по UTF-16 и может разделить суррогатную пару; фиксированная ширина не означает число графем или экранных ячеек.

Допустимые объявления

Фиксированная строка поддержана в переменной DIM и поле TYPE. Для константы, параметра процедуры или функции, результата функции и функционального типа используйте обычный STRING; форма фиксированной ширины в этих местах не поддержана.

Пример

Один и тот же размер применяется к каждому присваиванию:

DIM shortCode AS STRING * 4
shortCode = "AB"
PRINT "[" + shortCode + "]"
shortCode = "Alphabet"
PRINT "[" + shortCode + "]"

Результат:

[AB  ]
[Alph]

Диагностика

MB2026 возникает при использовании фиксированной строки в неподдержанном месте, размере вне диапазона 1–65535 или выражении размера, которое нельзя вычислить как целочисленную константу. Несовместимое присваивание обнаруживается при проверке типов. Размер и другие ограничения объявления необходимо соблюдать до запуска программы.

Файловое значение

Текстовый путь хранится в STRING. Открытый файловый ресурс имеет отдельный тип FILE. Его договор перенесён в главу файлов; он не относится к строковому типу.
