Типы данных

STRING, STRING * N и FILE

Строковый тип хранит текст: имена, сообщения, пути, фрагменты файлов и результаты строковых функций. В Axiom рядом с обычным STRING есть фиксированная форма STRING * N для мест хранения заданной ширины и отдельный тип FILE для уже открытого файлового потока.

Обычная строка STRING

STRING хранит последовательность символов. Строковый литерал записывается в двойных кавычках, а переменная типа STRING может получить значение из литерала, выражения, ввода или строковой функции.

DIM title AS STRING = "Axiom"
DIM greeting = "Привет"

PRINT title
PRINT greeting

Оператор + объединяет только две строки. Если нужно собрать строку из текста, чисел и логических значений, используйте оператор &.

DIM count AS INTEGER = 3

PRINT "Count: " & count

Фиксированная строка STRING * N

STRING * N задаёт место хранения ровно на N символов. При записи короткое значение дополняется пробелами справа, а слишком длинное значение обрезается справа.

DIM code AS STRING * 4

code = "AB"
PRINT "[" + code + "]"

code = "Alphabet"
PRINT "[" + code + "]"

Результат:

[AB  ]
[Alph]

Длина N должна быть целочисленной константой от 1 до 65535. Здесь можно использовать числовой литерал, обычную целочисленную CONST или предопределённые ROW и COLUMN, если они делают запись понятнее.

Где поддержан STRING * N

Фиксированная строка поддержана только в местах, где программа действительно хранит значение: в переменной DIM и в поле пользовательской записи TYPE.

DIM shortCode AS STRING * 4

TYPE Person
    Name AS STRING * 12
END TYPE

STRING * N не поддержан в CONST, параметрах SUB и FUNCTION, типе результата FUNCTION и внутри функциональных типов. В этих местах используйте обычный STRING.

Файловое значение FILE

FILE - это не путь к файлу в виде строки. Это значение открытого файла. Его объявляют через DIM, открывают оператором OPEN, передают файловым функциям и закрывают оператором CLOSE.

DIM path AS STRING = "notes.txt"
DIM f AS FILE

OPEN path FOR INPUT AS f

IF ISOPEN(f) THEN
    PRINT READLINE(f)
END IF

CLOSE f

Строка path только указывает, какой файл открыть. Переменная f хранит уже открытый файловый ресурс, с которым работают READLINE, WRITE, FILEPOS, EOF и другие функции открытого файла.

Что важно не путать

  • STRING подходит для обычного текста, путей файловой системы, приглашений INPUT и результатов строковых функций.
  • STRING * N полезен, когда нужна фиксированная ширина хранения, например в поле записи или коротком коде.
  • FILE нельзя создать строковым литералом и нельзя использовать как обычный текстовый путь.
  • Чтобы получить FILE, сначала объявите переменную DIM f AS FILE, затем откройте файл через OPEN ... AS f.
  • После работы с открытым файлом закрывайте его через CLOSE f.

Диагностика

  • MB2003 - значение несовместимо с типом, оператор применён к неподходящему типу или файловое значение используется как обычное присваиваемое значение.
  • MB2026 - форма STRING * N использована там, где фиксированные строки не поддержаны.
  • MB3001 - ошибка времени выполнения при файловой операции, например чтение из закрытого файла.

Ручная проверка

Эти файлы можно открыть в Axiom.Ide и запустить как короткие проверки строк и файлового типа.

  • DIM: фиксированная строка STRING * N
  • TYPE: фиксированные строковые поля
  • Строковая конкатенация через +
  • Строковая конкатенация через &
  • READLINE: чтение строки из FILE
  • WRITELINE: запись строки в FILE
