Типы данных

STRING, FILE и фиксированная длина

Типы STRING и FILE имеют отдельные правила хранения и использования. Здесь же собрана форма STRING * N для фиксированной длины строки.

Тип STRING

Обычная форма STRING хранит строку переменной длины и используется для текста, подсказок INPUT, сообщений и строковых функций.

DIM text AS STRING = "Привет"
DIM name = "Алиса"

Фиксированная длина STRING * N

Если нужен фиксированный размер, можно объявить строку как STRING * N, где N — целочисленная константа в диапазоне от 1 до 65535.

DIM code AS STRING * 4
TYPE Person
    Name AS STRING * 12
END TYPE

Фиксированная строка не вводит отдельного нового типа выражений: строковые функции, сравнения и присваивания работают с ней как со строкой. Отличие проявляется в хранении: пустое значение создаётся как строка из пробелов нужной длины, короткая строка дополняется пробелами справа, длинная строка обрезается справа до заданного размера.

Сейчас форма STRING * N поддержана только как непосредственный тип в DIM и в строковых полях TYPE. В CONST, параметрах и типе результата FUNCTION, а также внутри функциональных типов нужно использовать обычный STRING; неподдержанная форма даёт диагностику MB2026.

Тип FILE

FILE отличается от остальных базовых типов тем, что его значение не задают литералом и не получают обычным присваиванием. Переменная типа FILE получает открытый файл через OPEN, затем используется в ISOPEN, FILEPATH, FILEMODE, FILEPOS, FILELENGTH, LINENUMBER, EOF, READLINE, SKIPLINE, READTEXT, READTOEND, WRITE, WRITELINE, NEWLINE, FLUSH, SEEKFILE, REWIND и освобождается через CLOSE.

DIM f AS FILE
OPEN "notes.txt" FOR INPUT AS f

IF ISOPEN(f) THEN
    PRINT READLINE(f)
END IF

CLOSE f

Ручная проверка

  • DIM: фиксированная строка STRING * N
  • TYPE: фиксированные строковые поля
  • READLINE: чтение строки из FILE
  • WRITELINE: запись строки в FILE
