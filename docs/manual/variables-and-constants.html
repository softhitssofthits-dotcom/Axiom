Переменные, константы и значения

Раздел переменных и констант объясняет, как дать значению имя, хранить его и изменять во время выполнения программы.

Переменная и её значение

Переменная связывает имя с местом хранения значения. Объявление определяет допустимый тип данных, а присваивание записывает новое значение. Например, число покупок может изменяться, но переменная для этого числа остаётся той же:

DIM count AS INTEGER = 2
count = count + 1
PRINT count

Результат:

3

Переменная должна быть объявлена. Одно присваивание не создаёт новое имя. Обычные переменные объявляются оператором DIM, но отдельные конструкции также объявляют собственные имена: параметры в заголовке подпрограммы, счётчик FOR и переменная ошибки после CATCH. Например, CATCH err является объявлением переменной err, поэтому отдельный DIM err не нужен. Полные формы обычных объявлений находятся в статье DIM; специальное объявление обработчика описано в TRY.

Тип и начальное значение

Тип определяет, что хранит переменная и какие операции можно выполнять с её значением. Для первых программ достаточно чисел INTEGER и DOUBLE, текста STRING и логического значения BOOLEAN.

DIM title AS STRING = "Отчёт"
DIM price AS DOUBLE = 12.5
DIM ready AS BOOLEAN = TRUE
DIM count = 3
PRINT title, price, ready, count

Ожидаемый вывод:

Отчёт 12.5 TRUE 3

После AS тип задаётся явно. Если AS отсутствует, инициализатор позволяет определить тип: в последней строке это INTEGER. Объявление без типа и без начального значения недопустимо. Значения по умолчанию и групповые объявления описаны в статье DIM.

Константа

Константа хранит именованное значение, которое программа не может заменить присваиванием. Объявляйте постоянные пределы и настройки оператором CONST:

CONST LIMIT AS INTEGER = 10
DIM count AS INTEGER = 3
PRINT count <= LIMIT

Ожидаемый вывод:

TRUE

В языке уже определены PI, ROW и COLUMN. Их значения и ограничения перечислены в статье CONST.

Имена и доступность

Имена count и Count обозначают одно значение. Имя доступно в своей области видимости. Объявленное внутри ветви или цикла имя не становится глобальным. Правила блоков и запрет перекрытия имён разобраны на отдельной странице.
