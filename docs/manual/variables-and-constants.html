Переменные, константы и значения

Раздел «Переменные, константы и значения» объясняет, как хранить данные в программе, обращаться к ним по имени и задавать новые значения.

Объявление и присваивание

Переменная — именованное место хранения значения определённого типа. Объявление вводит имя, тип и начальное значение; последующее присваивание изменяет сохранённое значение:

DIM count AS INTEGER = 2
count = count + 1
PRINT count

Программа выводит:

3

После объявления count содержит 2. Присваивание записывает результат count + 1 в ту же переменную.

Объявление вводит имя, а присваивание меняет уже сохранённое значение. Запись count = 2 сама по себе не создаёт переменную: без объявления компилятор сообщит об неизвестном имени.

Тип данных и начальное значение

У каждой переменной есть тип данных. Тип определяет допустимые значения и операции: например, INTEGER хранит целые числа, STRING — текст, а BOOLEAN — истину или ложь. В объявлении тип можно указать после AS:

DIM title AS STRING = "Отчёт"
DIM price AS DOUBLE = 12.5
DIM ready AS BOOLEAN = TRUE
PRINT title
PRINT price
PRINT ready

Программа выводит:

Отчёт
12.5
TRUE

Значение после знака = задаёт, что переменная будет хранить сразу после объявления. Это начальное значение; выражение, которое его вычисляет, называют инициализатором. Если тип указан, начальное значение можно опустить: например, DIM count AS INTEGER создаёт переменную со значением 0.

Если начальное значение задано, тип можно не указывать:

DIM count = 3
PRINT count

Программа выводит:

3

Здесь компилятор определяет тип INTEGER по числу 3. Это называется выводом типа. Нельзя опустить одновременно тип и начальное значение. Полные формы объявления и значения по умолчанию приведены в статье DIM.

Константы

Оператор CONST объявляет именованное значение с запретом прямого присваивания. Константа может задавать предел или постоянный параметр программы:

CONST LIMIT AS INTEGER = 10
DIM count AS INTEGER = 7
PRINT count <= LIMIT

Программа выводит:

TRUE

В выражении имя LIMIT используется вместо числа 10. Присвоить константе другое значение инструкцией LIMIT = 20 нельзя. Правила вычисления начального значения и существующее ограничение передачи через BYREF описаны в статье CONST.

Константы PI, ROW и COLUMN уже объявлены языком. Их значения приведены на той же странице.

Области видимости

Имена не зависят от регистра: count и Count обозначают одну переменную. При этом имя доступно только в определённой части программы — своей области видимости. Например, переменная, объявленная внутри IF, недоступна после END IF. Подробные правила и примеры находятся в статье об именах и областях видимости.

Обычные переменные объявляются оператором DIM. Некоторые конструкции объявляют имена самостоятельно: заголовок подпрограммы — параметры, FOR — счётчик цикла, CATCH — переменную со сведениями об ошибке. Например, для CATCH err не нужно предварительно писать DIM err; см. объявление в CATCH.
