Переменные, константы и значения

Переменная хранит значение, которое программа может изменять; константа связывает имя со значением, защищённым от присваивания. Для обоих объявлений существенны тип данных и область видимости: они определяют допустимые значения и места обращения к имени.

Объявление и присваивание

Объявление DIM вводит имя переменной, определяет её тип и устанавливает начальное значение. После объявления присваивание может заменить сохранённое значение результатом другого выражения. Например, счётчик сначала получает 2, затем увеличивается на единицу:

DIM count AS INTEGER = 2
count = count + 1
PRINT count

Программа выводит:

3

В правой части count + 1 читается прежнее значение счётчика, после чего результат записывается в ту же переменную. Само присваивание не объявляет имя: запись count = 2 без предшествующего объявления приводит к диагностике MB2001 «Имя 'count' не объявлено».

Тип данных и начальное значение

Тип ограничивает набор значений переменной и допустимые операции над ними. INTEGER предназначен для целых чисел, STRING — для текста, BOOLEAN — для истины и лжи. Явный тип записывается после AS:

DIM title AS STRING = "Отчёт"
DIM price AS DOUBLE = 12.5
DIM ready AS BOOLEAN = TRUE
PRINT title
PRINT price
PRINT ready

Программа выводит:

Отчёт
12.5
TRUE

Значение после знака = вычисляется при выполнении объявления и становится начальным значением переменной; вычисляющее его выражение называют инициализатором. Если тип указан, инициализатор можно опустить: DIM count AS INTEGER создаёт переменную со значением 0.

Если начальное выражение задано, явное указание типа можно опустить:

DIM count = 3
PRINT count

Программа выводит:

3

Здесь компилятор выводит тип INTEGER из литерала 3; такой приём называют выводом типа. Опустить одновременно тип и начальное значение нельзя. Полные формы объявления и значения по умолчанию приведены в статье DIM.

Константы

Константа объявляется через CONST с явным типом и начальным выражением. Имя константы можно использовать в вычислениях; например, LIMIT задаёт предел для проверки количества:

CONST LIMIT AS INTEGER = 10
DIM count AS INTEGER = 7
PRINT count <= LIMIT

Программа выводит:

TRUE

В выражении имя LIMIT обозначает число 10. Инструкция LIMIT = 20 отклоняется с диагностикой MB2010 «Нельзя присваивать значение константе». Правила вычисления начального значения и ограничение передачи через BYREF описаны в статье CONST.

Язык уже объявляет константы PI, ROW и COLUMN; их значения приведены на той же странице.

Области видимости

Имена не зависят от регистра: count и Count обозначают одну переменную. Доступность имени ограничена областью видимости — частью исходного текста, в которой разрешено обращаться к объявлению. Например, переменная внутри ветви IF недоступна после END IF. Подробные правила и примеры находятся в статье об именах и областях видимости.

Обычные переменные объявляются оператором DIM. Некоторые конструкции объявляют имена самостоятельно: заголовок подпрограммы — параметры, FOR — счётчик цикла, CATCH — переменную со сведениями об ошибке. Например, для CATCH err не нужно предварительно писать DIM err; см. объявление в CATCH.
