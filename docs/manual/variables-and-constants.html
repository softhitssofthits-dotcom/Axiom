Раздел

Переменные и константы

Раздел переменных и констант описывает, как в программе Axiom появляются именованные значения: переменная хранит значение, которое программа может изменить, а константа закрепляет значение, которое после объявления остаётся неизменным.

Главные правила

  • Переменная объявляется через DIM и имеет определённый тип данных.
  • Константа объявляется через CONST, получает значение сразу и позднее не изменяется.
  • Простое присваивание не создаёт новую переменную: имя должно быть объявлено заранее.
  • Тип переменной задаётся после AS или выводится из инициализатора.
  • Форма DIM <имя> без типа и без начального значения недопустима.
  • Имена регистронезависимы: name, Name и NAME обозначают одно и то же имя.

Переменные

Переменная представляет именованное хранилище значения. В тексте программы вы обращаетесь к имени, а Axiom связывает это имя с типом и текущим значением.

DIM score AS INTEGER
score = 10
PRINT score

Тип переменной определяет, какие значения она может хранить. Например, INTEGER предназначен для целых чисел, STRING — для текста, а BOOLEAN — для логических значений TRUE и FALSE.

Описание переменных через DIM

Основной оператор описания переменной — DIM. Он вводит имя в текущую область видимости и задаёт тип явно или через начальное значение.

DIM name AS STRING
DIM age AS INTEGER = 19
DIM total = 10

Для строк поддержана фиксированная форма STRING * N, где N задаёт длину хранения.

DIM code AS STRING * 4

Подробные формы записи, групповые объявления, массивы и диагностика описаны на странице Оператор DIM.

Имена массивов

Если после имени в объявлении стоят скобки, переменная имеет массивный тип. Массив может быть сразу выделен с границами или объявлен как динамический без выделенного диапазона.

DIM values(1 TO 3) AS INTEGER
DIM names() AS STRING
DIM table(,) AS INTEGER

values(1 TO 3) создаёт одномерный массив с доступными индексами от 1 до 3. names() объявляет одномерный динамический массив, который обычно нужно выделить через REDIM перед обращением к элементам. table(,) объявляет двумерный динамический массив.

Общие правила массивов описаны в разделе Массивы, а динамическое выделение — на странице Динамические массивы.

Константы

Константа — это именованное значение, которое не меняется после объявления. Она полезна для чисел, строк и других значений, смысл которых в программе должен быть постоянным.

CONST MAX_SCORE AS INTEGER = 100
CONST APP_NAME AS STRING = "Axiom"

CONST требует значение в момент объявления. Попытка изменить константу позднее не является корректной программой.

Форма STRING * N для CONST сейчас не поддерживается. Если нужна строка фиксированной длины, используйте переменную DIM или поле внутри TYPE.

Подробные формы записи, предопределённые имена и диагностика описаны на странице Оператор CONST.

Предопределённые константы

Axiom предоставляет несколько встроенных именованных констант. Их не нужно объявлять через CONST, и их нельзя переопределить своим DIM, CONST, SUB или FUNCTION.

  • PI — значение числа пи типа DOUBLE.
  • ROW — целочисленная константа со значением 1.
  • COLUMN — целочисленная константа со значением 2.
DIM board(10 TO 12, 20 TO 21) AS INTEGER
PRINT LBOUND(board, ROW)
PRINT UBOUND(board, COLUMN)

ROW и COLUMN удобны в двумерных примерах как читаемые имена для первого и второго измерения. Числовые формы 1 и 2 остаются допустимыми.

Имена

Имена переменных и констант подчиняются общим правилам идентификаторов.

  1. Имя должно начинаться с буквы или символа подчёркивания _.
  2. После первого символа допускаются буквы, цифры и символ подчёркивания.
  3. Имя не должно быть зарезервированным словом языка.
  4. Имя не должно содержать пробелы и знаки пунктуации.

Примеры корректных имён: name, total, version1, _tmp, studentName.

Примеры некорректных имён: 1value, PRINT, user-name, user name.

Явность объявлений

Axiom работает в строгой модели объявлений. Имя должно быть известно до использования, а тип должен быть понятен уже в момент объявления.

DIM count AS INTEGER
count = 5

Такая модель делает ошибки имён и типов видимыми раньше: если переменная не объявлена или имя написано иначе, программа получает диагностику вместо скрытого создания нового имени.

В QuickBASIC тип мог задаваться суффиксом имени, операторами семейства DEF... или умолчанием для неописанных имён. В Axiom документируемая модель строже: переменные объявляются через DIM, константы — через CONST, а тип задаётся явно или выводится из инициализатора.

Ручная проверка

Эти файлы можно открыть в Axiom.Ide и запустить как короткие проверки объявлений, констант и фиксированных строк.

  • DIM: базовое объявление
  • DIM: вывод типа из инициализатора
  • DIM: несколько объявлений в одной инструкции
  • DIM: объявление массива
  • DIM: динамический массив
  • DIM: фиксированная строка STRING * N
  • CONST: базовое объявление константы
  • Предопределённые константы: PI, ROW, COLUMN
  • Ошибка: фиксированная строка в CONST
