Переменные и константы

Эта глава описывает, как Axiom объявляет переменные и константы, как выводит тип из инициализатора и какие требования накладывает на имена и повторное использование значений.

Главные правила

  • Все переменные должны быть объявлены до использования.
  • DIM поддерживает как явное указание типа, так и вывод типа из инициализатора.
  • Форма DIM <имя> без AS <тип> и без = <выражение> недопустима.
  • CONST требует значение в момент объявления и не допускает последующего изменения.
  • Имена регистронезависимы и не могут совпадать с зарезервированными словами языка.
  • Запись вида DIM values() AS INTEGER объявляет имя массива; до первого REDIM его текущее массивное значение существует, но остаётся невыделенным.

Что такое переменная

Переменная в Axiom представляет именованное хранилище значения с определённым типом данных. На уровне записи в программе вы работаете с именем или идентификатором, а в среде выполнения этому имени соответствует значение определённого типа.

Язык не является бестиповым: переменная типа INTEGER не принимает строку без допустимого преобразования, а переменная типа STRING предназначена для текстовых данных.

Описание переменной

В общем случае переменная объявляется через оператор DIM. Базовая форма выглядит так:

DIM <имя> AS <тип>
DIM <имя> AS <тип> = <выражение>
DIM <имя> = <выражение>

Например:

DIM name AS STRING
DIM age AS INTEGER
DIM price AS DOUBLE
DIM ready AS BOOLEAN

Сначала указывается ключевое слово DIM, затем имя переменной, а после слова AS её тип.

Для строк также поддерживается фиксированная форма STRING * N, где N — целочисленная константа длины:

DIM code AS STRING * 4
DIM title AS STRING * 12

Такая переменная по семантике остаётся строкой, но при хранении значения язык автоматически подгоняет его к указанной длине: короткая строка дополняется пробелами справа, длинная — обрезается.

Подробная справочная карточка по формам записи, массивам, фиксированным строкам и диагностике находится на странице Оператор DIM.

Имя массива и невыделенное состояние

DIM values() AS INTEGER
DIM matrix(,) AS INTEGER

REDIM values(1 TO 3)
REDIM matrix(1 TO 2, 10 TO 11)

Если после имени стоят скобки, объявляется не скалярное имя, а имя массива. Форма values() означает одномерный массив, а форма matrix(,) означает двумерный массив.

Отдельного синтаксиса для «имени массива» и для «невыделенного массива» нет. Это один и тот же идентификатор: сначала он объявлен с массивным типом, а до первого успешного REDIM его текущее массивное значение остаётся невыделенным.

Поэтому запись DIM values() AS INTEGER означает сразу две вещи: имя values имеет массивный тип INTEGER(), и в момент объявления в нём ещё нет доступного диапазона индексов.

После REDIM то же самое имя остаётся именем массива, но его текущее значение уже становится выделенным массивом с конкретными границами. После ERASE оно снова возвращается в невыделенное состояние.

Именно поэтому присваивание вроде reversed = ARRAYTOREVERSED(source) не «делает имя reversed массивом» заново. Имя reversed уже было объявлено с массивным типом; вызов только помещает в него новый массив-результат.

Само имя при этом остаётся типизированным как массив. Поэтому запись вида values = 5 для объявления DIM values() AS INTEGER недопустима: здесь пытаются присвоить одно число не элементу, а массивному значению целиком. Скалярное значение присваивается не массиву целиком, а его элементу, например values(1) = 5 после выделения через REDIM.

Части синтаксиса

  • <имя> — имя объявляемой переменной.
  • <тип> — явный тип переменной после AS, в том числе форма фиксированной строки STRING * N.
  • <выражение> — выражение начального значения. В форме без AS оно также определяет выводимый тип.

Присвоение значений и инициализация

После объявления переменной ей можно присвоить значение. Для этого используется оператор =:

DIM name AS STRING
name = "Вася"

Также переменную можно инициализировать сразу в момент объявления:

DIM name AS STRING = "Вася"
DIM age AS INTEGER = 19

Для фиксированной строки те же правила работают с автоматическим дополнением или обрезкой:

DIM code AS STRING * 4
PRINT "[" + code + "]"
code = "AB"
PRINT "[" + code + "]"
code = "Alpha"
PRINT "[" + code + "]"

Кроме того, Axiom поддерживает сокращённую форму, когда тип выводится из инициализатора:

DIM total = 10
DIM title = "Axiom"
DIM ratio = 0.75
DIM passed = TRUE

Важно

Форма DIM <имя> без AS <тип> и без = <выражение> недопустима. В Axiom переменная должна либо получить тип явно, либо вывести его из инициализатора.

Если переменная уже объявлена, её значение можно менять позднее:

DIM name AS STRING
name = "Вася"
PRINT name
name = "Иван"
PRINT name

Групповое объявление переменных

В одном операторе DIM можно объявлять сразу несколько переменных:

DIM x, y AS INTEGER
DIM firstName, lastName AS STRING
DIM left, right = 7

Тип после AS относится ко всей ближайшей группе имён слева. Аналогично работает и форма с выводом типа из инициализатора.

Правила именования переменных

Для имён переменных и констант в Axiom действуют следующие правила:

  1. Имя должно начинаться с буквы или символа подчеркивания _.
  2. После первого символа допускаются буквы, цифры и символ подчеркивания.
  3. Имя не должно быть зарезервированным словом языка.
  4. Имя не должно содержать пробелы и знаки пунктуации.

Примеры корректных имён:

name, total, version1, _tmp, studentName

Примеры некорректных имён:

1value — начинается с цифры, PRINT — ключевое слово языка, user-name — содержит символ пунктуации, user name — содержит пробел.

Обратите внимание

Axiom регистронезависим. Это значит, что name, Name и NAME считаются одним и тем же именем. Язык также не вводит отдельного числового ограничения на длину идентификатора сверх ограничений реализации на платформе .NET/C#.

Константы

Кроме переменных, в Axiom есть константы. Константа — это именованное значение, которое после объявления уже не изменяется. Для объявления константы используется ключевое слово CONST.

CONST APP_NAME AS STRING = "Axiom"
CONST MAX_SCORE AS INTEGER = 100

Константа должна получить значение сразу при объявлении. Изменять её позднее нельзя.

Форма STRING * N в CONST сейчас не поддерживается. Если нужна фиксированная длина хранения, используйте DIM или строковое поле внутри TYPE; для обычной строковой константы объявляйте тип как STRING.

Предопределённые константы

Кроме констант, объявленных через CONST, Axiom предоставляет несколько встроенных именованных значений. Они доступны в любом месте программы без предварительного объявления и не могут быть переопределены через DIM, CONST, SUB или FUNCTION.

PRINT PI
PRINT ROW
PRINT COLUMN
  • PI — число пи типа DOUBLE.
  • ROW — целочисленная константа со значением 1.
  • COLUMN — целочисленная константа со значением 2.

ROW и COLUMN введены как более читаемые синонимы для первых двух измерений массива. Их можно использовать там же, где допустимы обычные числа 1 и 2, например в вызовах LBOUND, UBOUND и в формах, где язык просит номер измерения.

DIM board(10 TO 12, 20 TO 21) AS INTEGER
PRINT LBOUND(board, ROW)
PRINT UBOUND(board, COLUMN)

Числовая форма при этом сохраняется: ROW эквивалентно 1, а COLUMN эквивалентно 2. Для третьего и следующих измерений по-прежнему используются обычные числа.

Явность объявлений

Axiom работает в строгом режиме. Это означает:

  • переменные объявляются только через DIM;
  • константы объявляются только через CONST;
  • простая запись <имя> = <выражение> не создаёт новую переменную автоматически.

Иначе говоря, если имя не объявлено заранее, использовать его как переменную нельзя.

Итого

В Axiom переменная — это именованное значение с определённым типом. Переменные объявляются через DIM, могут инициализироваться сразу или позже, а их имена должны подчиняться формальным правилам языка. Если после имени стоят скобки, переменная имеет массивный тип; до первого REDIM такой массив может оставаться невыделенным. Для текстовых данных доступны и обычные строки, и фиксированная форма STRING * N с автоматическим дополнением или обрезкой до заданной длины. Константы объявляются через CONST, обязаны получить значение в момент объявления и после этого уже не изменяются; фиксированная строковая форма для них сейчас не поддерживается. Дополнительно язык предоставляет встроенные предопределённые константы PI, ROW и COLUMN.
