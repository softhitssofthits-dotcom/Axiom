Тип, функции и операторы

Спрайты SPRITE

Раздел спрайтов описывает тип данных SPRITE, функции LOADSPRITE, SPRITEWIDTH, SPRITEHEIGHT, SPRITECOUNT и оператор DRAWSPRITE. Спрайтовый лист содержит кадры одинакового размера; программа выбирает кадр по номеру.

Что такое тип SPRITE

Тип SPRITE хранит ссылку на спрайтовый лист и его разметку.

Функция LOADSPRITE загружает лист с указанным размером кадра. Для анимации программа меняет номер кадра, передаваемый в DRAWSPRITE.

Где работают функции и оператор

Загрузка и чтение размеров выполняются над значением спрайта и не требуют графического окна.

Оператор DRAWSPRITE требует графического режима SCREEN 1..10 или холста CANVAS.

Синтаксис

DIM <имя> AS SPRITE
LOADSPRITE(<путь>, <ширина кадра>, <высота кадра>)
SPRITEWIDTH(<спрайт>)
SPRITEHEIGHT(<спрайт>)
SPRITECOUNT(<спрайт>)
DRAWSPRITE <спрайт>, <кадр>, <координата X>, <координата Y>
DRAWSPRITE <спрайт>, <кадр>, <координата X>, <координата Y>, <ширина>, <высота>

Параметры

ЧастьОписание
<имя свойства>Переменная типа SPRITE.
<путь>Передайте строковый путь к файлу изображения.
<ширина кадра>, <высота кадра>Передайте положительные размеры одного кадра в пикселях. Каждый перечисленный аргумент имеет тип LONG.
<спрайт>Передайте выражение типа SPRITE.
<кадр>Передайте номер кадра, начиная с 0. Передаваемое значение имеет тип LONG.
<координата X>, <координата Y>Передайте координаты левого верхнего угла вывода. Каждый перечисленный аргумент имеет тип LONG.
<ширина>, <высота>Передайте положительные размеры итогового вывода в пикселях. Каждый перечисленный аргумент имеет тип LONG.

Функция LOADSPRITE

Встроенная функция LOADSPRITE читает изображение, разбивает его на прямоугольные кадры одинакового размера и возвращает значение типа SPRITE.

Синтаксис

LOADSPRITE(<путь>, <ширина кадра>, <высота кадра>)

Аргумент <путь> должен иметь тип STRING. Правила разрешения пути приведены на странице изображений.

Аргументы <ширина кадра> и <высота кадра> задают ширину и высоту одного кадра в пикселях.

Функции SPRITEWIDTH, SPRITEHEIGHT и SPRITECOUNT

Встроенная функция SPRITEWIDTH возвращает INTEGER с шириной кадра в пикселях.

Встроенная функция SPRITEHEIGHT возвращает INTEGER с высотой кадра в пикселях.

Встроенная функция SPRITECOUNT возвращает INTEGER с числом доступных полных кадров листа.

SPRITEWIDTH(<спрайт>)
SPRITEHEIGHT(<спрайт>)
SPRITECOUNT(<спрайт>)

Оператор DRAWSPRITE

Оператор DRAWSPRITE выводит кадр с указанным номером на текущую поверхность.

DRAWSPRITE <спрайт>, <кадр>, <координата X>, <координата Y>
DRAWSPRITE <спрайт>, <кадр>, <координата X>, <координата Y>, <ширина>, <высота>

Без дополнительных размеров кадр выводится в натуральном размере.

С аргументами width и height кадр масштабируется до заданного размера в пикселях.

На экране координаты преобразуются настройками VIEW и WINDOW. На холсте координаты мировые и учитывают камеру.

Правила работы

Порядок кадров соответствует чтению изображения: слева направо, затем сверху вниз.

Неполные участки изображения справа и снизу не образуют кадров, если размер листа не делится на размер кадра без остатка.

При присваивании копируется ссылка на лист. Пиксели не дублируются.

Вывод обрезается по доступным границам экрана или холста.

Встроенная функция SPRITEWIDTH

SPRITEWIDTH — встроенная функция языка Axiom, которая возвращает ширину одного кадра в пикселях. Она читает свойства значения без графического окна; результат доступен сразу.

Синтаксис

SPRITEWIDTH(<спрайт>)

Аргумент

Передайте выражение типа SPRITE, свойства которого нужно прочитать. Пустая переменная после объявления допустима.

Результат, ограничения и диагностика

Функция возвращает INTEGER. Для пустого значения результат равен 0. Чтение свойства не загружает файл и не вызывает ошибку из-за пустого ресурса. Несовместимый тип или неверное число аргументов отклоняется компилятором.

Пример

DIM sheet AS SPRITE
PRINT SPRITEWIDTH(sheet)

Программа печатает 0, поскольку ресурс ещё не загружен. После успешной загрузки функция возвращает фактическое свойство.
