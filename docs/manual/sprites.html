Спрайты SPRITE

Раздел спрайтов описывает тип данных SPRITE, встроенные функции LOADSPRITE, SPRITEWIDTH, SPRITEHEIGHT, SPRITECOUNT и оператор DRAWSPRITE. Тип SPRITE хранит спрайтовый лист — изображение, разбитое на одинаковые кадры.

Что такое тип SPRITE

SPRITE — встроенный ссылочный тип данных языка Axiom.

Значение типа SPRITE хранит спрайтовый лист и сведения о размере одного кадра. Программа обычно получает такое значение через функцию LOADSPRITE, а затем выбирает кадры по номеру через оператор DRAWSPRITE.

Где работают функции и оператор

Функции LOADSPRITE, SPRITEWIDTH, SPRITEHEIGHT и SPRITECOUNT работают с самим значением типа SPRITE.

Оператор DRAWSPRITE работает только при активном графическом выводе. Этот оператор можно использовать либо в палитровом графическом режиме SCREEN 1..10, либо в полноцветном графическом режиме CANVAS.

Синтаксис

DIM name AS SPRITE
name = LOADSPRITE(path, frameWidth, frameHeight)

SPRITEWIDTH(sprite)
SPRITEHEIGHT(sprite)
SPRITECOUNT(sprite)

DRAWSPRITE sprite, frame, x, y
DRAWSPRITE sprite, frame, x, y, width, height

Параметры и части синтаксиса

ЧастьОписание
nameПеременная типа SPRITE.
pathСтроковый путь к файлу изображения.
frameWidth, frameHeightПоложительные размеры одного кадра в пикселях.
spriteВыражение типа SPRITE.
frameНомер кадра, начиная с 0.
x, yКоординаты левого верхнего угла вывода.
width, heightПоложительные размеры итогового вывода в пикселях.

Функция LOADSPRITE

LOADSPRITE — встроенная функция языка Axiom, которая загружает изображение и разбивает его на кадры одинакового размера.

LOADSPRITE(path, frameWidth, frameHeight)

Аргумент path должен быть строкой.

Аргументы frameWidth и frameHeight задают размер одного кадра спрайтового листа.

Функции SPRITEWIDTH, SPRITEHEIGHT и SPRITECOUNT

SPRITEWIDTH возвращает ширину одного кадра в пикселях.

SPRITEHEIGHT возвращает высоту одного кадра в пикселях.

SPRITECOUNT возвращает количество доступных кадров.

SPRITEWIDTH(sprite)
SPRITEHEIGHT(sprite)
SPRITECOUNT(sprite)

Оператор DRAWSPRITE

DRAWSPRITE — оператор языка Axiom, который выводит выбранный кадр спрайтового листа на активную графическую поверхность.

DRAWSPRITE sprite, frame, x, y
DRAWSPRITE sprite, frame, x, y, width, height

Первая форма выводит кадр в натуральном размере.

Вторая форма выводит кадр с масштабированием до размера width x height пикселей.

В режиме SCREEN координаты читаются по экранному договору SCREEN, VIEW и WINDOW. В режиме CANVAS координаты читаются по договору современного слоя и могут зависеть от оператора CAMERA.

Правила работы

Кадры нумеруются слева направо и сверху вниз.

Если изображение спрайтового листа не делится на кадры без остатка, неполные остатки справа и снизу не считаются кадрами.

Значение типа SPRITE копируется как ссылка на один и тот же спрайтовый лист, а не как отдельная копия пикселей.

Если часть спрайта выходит за границы доступной поверхности, результат обрезается по границе экрана или холста.

Пример

SCREEN 1
DIM walk AS SPRITE
walk = LOADSPRITE("assets/walk_sheet.png", 16, 16)

PRINT "Кадров="; SPRITECOUNT(walk)
DRAWSPRITE walk, 1, 16, 24
DRAWSPRITE walk, 3, 64, 24, 32, 32
SLEEP

Запускаемые примеры

Эти файлы можно открыть в Axiom.Ide и запустить как короткие проверки поведения типа SPRITE и оператора DRAWSPRITE.

  • SPRITE: анимация ходьбы
  • SPRITE: анимация со сменой страниц
  • SPRITE: ошибка неверного номера кадра

Диагностика

  • MB3007: путь в функции LOADSPRITE пустой.
  • MB3007: ширина или высота кадра в функции LOADSPRITE меньше либо равна нулю.
  • MB3005: файл спрайтового листа отсутствует, недоступен, повреждён или не поддерживается текущим декодером.
  • MB3005: оператор DRAWSPRITE получил пустое значение SPRITE или лист без доступных кадров.
  • MB3007: номер кадра меньше 0 или не меньше SPRITECOUNT(sprite).
  • MB3007: ширина или высота в масштабированной форме DRAWSPRITE меньше либо равна нулю.
  • MB3010: оператор DRAWSPRITE вызван без активного графического режима SCREEN или CANVAS.

Короткие проверки функций

Короткие примеры выводят ожидаемый результат в текстовую панель IDE. Примеры загрузки используют существующие ресурсы репозитория и реальные относительные пути; отдельный графический холст для чтения свойств не требуется.

  • SPRITEWIDTH: короткая проверка результата
  • SPRITEHEIGHT: короткая проверка результата
  • SPRITECOUNT: короткая проверка результата
  • LOADSPRITE: короткая проверка результата

Нулевой символ в пути ресурса

Функции LOADIMAGE, LOADSPRITE, LOADTILESET и LOADTILEMAP требуют строковый путь без нулевого символа. Такой символ отклоняется до раскрытия переменных окружения: загрузчик не использует часть пути перед ним. Неверный путь даёт MB3005, которую можно перехватить оператором TRY/CATCH; программа продолжает работу после обработки ошибки.

Короткий запускаемый пример: отказ загрузки изображения по пути с нулевым символом.

DIM picture AS IMAGE
TRY
    picture = LOADIMAGE("рисунок.png" + CHR(0) + "другой.png")
CATCH err
    PRINT "Отказ загрузки: "; err.Code
END TRY
