Оператор SCREEN

SCREEN — оператор языка Axiom, который открывает отдельное окно программы и выбирает его режим: текстовую сетку SCREEN 0 или палитровую графику SCREEN 1..10.

Когда использовать SCREEN

Выбирайте оператор SCREEN для вывода по текстовым ячейкам, рисования индексными цветами и подготовки изображения на экранных страницах.

До вызова оператора SCREEN операторы PRINT и INPUT используют текстовую область среды исполнения. После вызова вывод и ввод переходят в открытое экранное окно.

Контекст выполнения

Оператор SCREEN создаёт поверхность, к которой обращаются экранные операторы и функции. Текстовый режим и графические режимы предоставляют разный набор возможностей.

Окно SCREEN заменяет ранее открытый холст CANVAS. Для этих поверхностей действуют разные правила цвета, координат и показа кадра.

Синтаксис

SCREEN <режим>
SCREEN 0
SCREEN <режим>, , <активная страница>
SCREEN <режим>, , <активная страница>, <видимая страница>

Форма с одним аргументом выбирает режим. В формах с дополнительными аргументами программа одновременно выбирает активную и видимую страницы.

Параметры

ЧастьОписание
<режим>Передайте целое число от 0 до 10. Значение 0 выбирает текстовый режим. Значения 1..10 выбирают графический режим. Передаваемое значение имеет тип INTEGER.
<активная страница>Передайте необязательный номер активной графической страницы от 0 до 3. Именно в эту страницу идут операторы рисования и чтение цвета через функцию POINT(x, y). Передаваемое значение имеет тип INTEGER.
<видимая страница>Передайте необязательный номер видимой графической страницы от 0 до 3. Именно эта страница показывается в окне программы. Передаваемое значение имеет тип INTEGER.

Параметр colorSwitch зарезервирован и не поддерживается. При выборе страниц его место оставляют пустым: SCREEN 1, , 1, 0.

Что делает оператор SCREEN

Вызов SCREEN 0 создаёт текстовое окно с видимой сеткой 80 x 25. В нём доступны текстовый вывод и оператор INPUT; оператор LOCATE и графическое рисование требуют режима SCREEN 1..10.

Режимы 1..10 предоставляют графический экран. На нём работают PSET, PRESET, LINE, CIRCLE, PAINT, DRAW, а также VIEW, WINDOW, PCOPY, GET, PUT, COLOR, LOCATE и связанные функции.

Активная страница получает рисование, а видимая страница отображается в окне. Если их номера различаются, программа может подготовить изображение без показа промежуточных изменений, затем скопировать его оператором PCOPY.

Графическое окно

В Electron IDE режимы SCREEN 1..10 используют DirectX. Если подходящее аппаратное устройство недоступно, среда выбирает программное устройство WARP. Палитровые индексы, экранные страницы, текст и правила координат при этом сохраняются. Оператор PRESENT для SCREEN не требуется.

Проверка страниц, переназначенной палитры, обмена пикселями и ввода: directx_pages_input.axm.

Правила работы

В текстовом режиме переход на новую строку из последней видимой строки прокручивает текст вверх. В Electron IDE предыдущие строки остаются доступны через вертикальную полосу прокрутки.

В графических режимах текст рисуется поверх изображения. Ячейка занимает 8 x 12 пикселей; размер сетки определяется размером выбранного экрана.

Для режима 10 среда выбирает наибольшую клиентскую область с пропорцией 16:9, помещающуюся в рабочей области монитора. Функции SCREENWIDTH() и SCREENHEIGHT() сообщают полученные размеры.

Ограничения и пограничные случаи

Допустимые номера режима — целые значения от 0 до 10 включительно.

Обе страницы нумеруются от 0 до 3 включительно.

Если задана только активная страница, она становится и видимой.

Смена номера графического режима сбрасывает настройки VIEW, WINDOW, палитры и страниц в состояние нового режима.

Проверка аргументов и текстовый режим

Режим и номера страниц приводятся к INTEGER. Второй аргумент SCREEN зарезервирован: явное значение в этой позиции запрещает компиляцию с MB2003. Для страниц оставьте вторую позицию пустой. SCREEN 0 открывает текстовую поверхность; COLOR, LOCATE, VIEW PRINT и пиксельные операторы требуют графический SCREEN 1..10.

При повторном выборе того же графического режима с теми же размерами среда сохраняет пиксели страниц и их палитры, затем выбирает переданные активную и видимую страницы. Каждый вызов SCREEN сбрасывает VIEW, WINDOW, графическую позицию, цвет последующего текста и текстовый курсор; текстовый буфер очищается. При смене режима создаются новые страницы и сбрасываются графические настройки. Рисование на скрытой странице становится видимым после её выбора для показа либо копирования на видимую страницу.

Диагностика

  • MB3007: режим SCREEN, активная страница или видимая страница имеют недопустимое значение.
  • MB3005: хост не смог создать экранное окно или выбранный экранный режим недоступен.

Пример

SCREEN 1, , 1, 0
COLOR 15, 1
CLS
PSET (20, 20), 12
PCOPY 1, 0
SLEEP

Программа рисует пиксель на странице 1, сохраняя на экране страницу 0. Экранный текст составляет общий слой поверх видимой страницы и не скрывается выбором другой активной страницы. Оператор PCOPY показывает подготовленное изображение, а оператор SLEEP оставляет его доступным до нажатия клавиши.
