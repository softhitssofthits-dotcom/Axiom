SCREEN и графические команды

SCREEN переводит программу из обычного консольного вывода в отдельное полноэкранное графическое окно. После этого PRINT, PRINT USING, INPUT, CLS, COLOR, LOCATE, мышь и пиксельные команды работают с активной графической поверхностью.

Синтаксис

SCREEN mode
SCREEN 0
CLS
COLOR foreground[, background]
LOCATE row, column
PSET (x, y)[, color]
PRESET (x, y)[, color]
LINE (x1, y1)-(x2, y2)[, color][, B|BF]
CIRCLE (x, y), radius[, color]
POINT(x, y)
SCREENISACTIVE()
SCREENMODE()
SCREENWIDTH()
SCREENHEIGHT()

Режимы

SCREEN 0 выключает графику, закрывает полноэкранное окно и возвращает последующий PRINT в обычный Output. Режимы 1..9 задают фиксированные логические размеры от 320x200 до 2560x1440, а 10 выбирает режим 1280x720 как текущий безопасный полноэкранный вариант.

Ввод, вывод и мышь

В активном SCREEN текстовый слой имеет моноширинный курсор. LOCATE задаёт строку и столбец, COLOR задаёт текущие цвета текста, а CLS очищает текстовый и пиксельный слой. Клавиатура, строка INPUT и мышь принимаются из полноэкранного окна, поэтому MOUSEX(), MOUSEY(), MOUSEBUTTON(), MOUSEPRESS() и ON MOUSE требуют активный SCREEN; без него выполнение получает диагностику MB3010.

Пример

PRINT в графическом текстовом слое перезаписывает символы начиная с текущей позиции LOCATE. Это позволяет обновлять строку состояния без CLS и без заметного мерцания всего окна.

SCREEN 3
COLOR 14, 1
LOCATE 2, 4
PRINT "Axiom SCREEN"
LINE (20, 40)-(200, 120), 10, B
CIRCLE (320, 180), 60, 12
PRINT "width="; SCREENWIDTH()
SCREEN 0
PRINT "Back to Output"
