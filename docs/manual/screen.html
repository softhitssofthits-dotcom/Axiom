Оператор

SCREEN

SCREEN — оператор, который выбирает экранный режим программы. Если оператор SCREEN не указан, программа пишет обычный текст во вкладку Output. После SCREEN 0 открывается отдельное текстовое окно с видимой сеткой 80 x 25 и вертикальной прокруткой, а после SCREEN 1 ... SCREEN 10 — графический экран фиксированного или адаптивно выбранного размера. В графическом режиме можно выбрать активную и видимую страницу для PCOPY.

Для чего нужен оператор SCREEN

Оператор SCREEN применяют тогда, когда программе нужен собственный экран: текстовая область, положение строк, цвет, простая графика, клавиатура или мышь. В обычном режиме без SCREEN вывод идёт во вкладку Output, которую можно понимать как консоль Axiom.

После выбора экранного режима операторы PRINT, PRINT USING и INPUT работают уже в окне SCREEN. В графических режимах там же работают операторы рисования: PSET, PRESET, LINE, CIRCLE и функция POINT.

Для SCREEN 0 действует консольный договор: подтверждённый переход на новую строку из последней видимой строки прокручивает окно вверх на одну строку. Для графических режимов SCREEN 1 ... SCREEN 10 такой автопрокрутки нет.

В текущем окне SCREEN 0 в Axiom.Ide ранние строки не теряются сразу. Когда история становится длиннее видимых 25 строк, справа появляется вертикальная полоса прокрутки, и по ней можно вернуться к предыдущим строкам.

Синтаксис

SCREEN <режим>
SCREEN 0
SCREEN <режим>, , <активная_страница>
SCREEN <режим>, , <активная_страница>, <видимая_страница>

Параметры

ПараметрОписание
<режим>Целое значение от 0 до 10. Значение 0 выбирает текстовое окно. Значения 1..10 выбирают размер графического экрана.
0Текстовый режим окна SCREEN. Графические команды в нём недоступны, но обычный текстовый вывод и INPUT идут в это окно.
<активная_страница>Необязательная графическая страница 0..3, куда идут команды рисования и чтение POINT(x, y). Если не указана, используется страница 0.
<видимая_страница>Необязательная графическая страница 0..3, которая показывается в окне. Если активная страница указана, а видимая нет, видимой становится та же страница.

Пустое место после первой запятой оставлено под исторический параметр colorSwitch. В Axiom этот параметр сейчас не поддерживается, поэтому для страниц используйте форму с пустым полем: SCREEN 1, , 1, 0.

Оператор LOCATE работает не с пикселями, а со строками и столбцами текстовой сетки. Одна текстовая ячейка занимает 8 x 12 пикселей.

Режим SCREEN 10 не привязан к одному заранее записанному разрешению. При каждом входе он выбирает максимально возможную клиентскую область с отношением сторон 16:9, которая помещается в рабочую область монитора без системных панелей. Поэтому фактические значения надо читать через SCREENWIDTH() и SCREENHEIGHT().

Экранные страницы

В графических режимах SCREEN 1 ... SCREEN 10 Axiom держит четыре страницы с номерами 0..3. Активная страница получает графические команды, а видимая страница показывается пользователю. Обычно обе страницы равны 0.

Разделение страниц нужно для оператора PCOPY: программа может подготовить рисунок на скрытой активной странице, а затем скопировать его на видимую страницу одним оператором.

SCREEN 1, , 1, 0
LINE (20, 40)-(180, 40), 12
PCOPY 1, 0

Текст, выведенный через PRINT в графическом режиме, не становится отдельной страницей PCOPY в текущем срезе. Страницы относятся к графическому кадровому буферу и палитре.

Замечания

Значения режима меньше 0 или больше 10 дают ошибку времени выполнения.

Номера активной и видимой страницы меньше 0 или больше 3 дают ошибку времени выполнения.

В SCREEN 0 функция SCREENISACTIVE() возвращает FALSE, потому что графический экран не включён. При этом SCREENMODE() возвращает 0, а SCREENWIDTH() и SCREENHEIGHT() возвращают размер текстового окна.

В текстовом режиме SCREEN 0 одновременно видимы только 25 строк. Новый перевод строки из нижней строки поднимает видимое окно вверх и очищает новую строку 25. Горизонтального автопереноса нет: символы правее столбца 80 не показываются.

Если пользователь оставил окно внизу истории, новый вывод продолжает автоматически показывать последние строки. Если пользователь вручную прокрутил историю вверх, последующий вывод остаётся внизу буфера и не обязан немедленно возвращать окно к последним строкам.

Для SCREEN 10 монитор выбирается по экрану, в котором находится центр главного окна Axiom.Ide в момент запуска режима. Если эту привязку определить нельзя, используется основной монитор.

Вкладка Output используется только программами, которые не выбирали SCREEN явно. После SCREEN 0 или графического SCREEN приглашение INPUT появляется в экранном окне.

Если пользователь закрывает окно SCREEN системной кнопкой закрытия во время выполнения программы, запуск прерывается. Следующие операторы программы не выполняются, а команды IDE снова становятся доступными.

Пример выбора режима

SCREEN 5
PRINT "active="; SCREENISACTIVE()
PRINT "mode="; SCREENMODE()
PRINT "size="; SCREENWIDTH(); "x"; SCREENHEIGHT()

DO WHILE NOT KEYPRESS("ESC")
LOOP

SCREEN 0
PRINT "text mode screen"
