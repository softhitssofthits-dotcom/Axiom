Обработка ошибок

Раздел обработки ошибок описывает оператор TRY с блоками CATCH и FINALLY, оператор ERROR и встроенное значение ERROR. Эти средства позволяют реагировать на ошибки во время выполнения программы.

Перехват и завершение

TRY выделяет защищённый участок. CATCH получает ошибку и выполняет обработку; FINALLY завершает работу с ресурсом при обычном выходе и при передаче ошибки дальше. Операторы предназначены для ошибок уже запущенной программы, а не для ошибок проверки исходного текста.

Сведения об ошибке

Переменная CATCH имеет встроенный тип ERROR и доступна только для чтения. Её поля описывают код, текст и место отказа.

ПолеТипНазначение
CodeSTRINGКод системной или пользовательской ошибки.
MessageSTRINGТекст сообщения.
LineINTEGERНомер строки исходника начиная с 1; 0, если место неизвестно.
ColumnINTEGERНомер столбца исходника начиная с 1; 0, если место неизвестно.

Пользовательские ошибки

ERROR с кодом и необязательным сообщением создаёт новый отказ. ERROR со значением ошибки повторно передаёт его наружу, сохраняя исходное место. После успешной обработки CATCH программа продолжается за END TRY; инструкция, вызвавшая ошибку, не повторяется.

Пример обработки

TRY
    PRINT 10 \ 0
CATCH err
    PRINT err.Code
FINALLY
    PRINT "finally"
END TRY
PRINT "after"

Ожидаемый вывод:

MB3001
finally
after
