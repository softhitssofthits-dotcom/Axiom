Изображения IMAGE

Эта страница описывает встроенный тип данных IMAGE, встроенные функции LOADIMAGE, IMAGEWIDTH, IMAGEHEIGHT и оператор DRAWIMAGE. Тип IMAGE хранит уже загруженное полноцветное изображение, а оператор DRAWIMAGE выводит это изображение на графический экран или на современный холст.

Что такое тип IMAGE

IMAGE — встроенный ссылочный тип данных языка Axiom.

Значение типа IMAGE содержит загруженное изображение. Программа обычно получает такое значение через функцию LOADIMAGE и затем передаёт его в оператор DRAWIMAGE.

Где работают функции и оператор

Функции LOADIMAGE, IMAGEWIDTH и IMAGEHEIGHT работают с самим значением типа IMAGE.

Оператор DRAWIMAGE работает только при активном графическом выводе. Этот оператор можно использовать либо в историческом графическом режиме SCREEN 1..10, либо в современном графическом режиме CANVAS.

Синтаксис

DIM name AS IMAGE
name = LOADIMAGE(path)

IMAGEWIDTH(image)
IMAGEHEIGHT(image)

DRAWIMAGE image, x, y
DRAWIMAGE image, x, y, width, height

Части записи

ЧастьОписание
nameПеременная типа IMAGE.
pathСтроковый путь к файлу изображения.
imageВыражение типа IMAGE.
x, yКоординаты левого верхнего угла вывода.
width, heightПоложительные размеры итогового вывода в пикселях.

Функция LOADIMAGE

LOADIMAGE — встроенная функция языка Axiom, которая загружает файл изображения и возвращает значение типа IMAGE.

LOADIMAGE(path)

Аргумент path должен быть строкой.

Если путь абсолютный, функция использует его как есть. Если путь относительный и программа сохранена, путь считается от каталога файла .axm.

Функции IMAGEWIDTH и IMAGEHEIGHT

IMAGEWIDTH и IMAGEHEIGHT — встроенные функции языка Axiom, которые возвращают размеры изображения в пикселях.

IMAGEWIDTH(image)
IMAGEHEIGHT(image)

Функция IMAGEWIDTH возвращает ширину изображения.

Функция IMAGEHEIGHT возвращает высоту изображения.

Если значение IMAGE пустое, обе функции возвращают 0.

Оператор DRAWIMAGE

DRAWIMAGE — оператор языка Axiom, который выводит изображение на активную графическую поверхность.

DRAWIMAGE image, x, y
DRAWIMAGE image, x, y, width, height

Первая форма выводит изображение в его натуральном размере.

Вторая форма выводит изображение с масштабированием до размера width x height пикселей.

В режиме SCREEN координаты читаются по экранному договору SCREEN, VIEW и WINDOW. В режиме CANVAS координаты читаются по договору современного слоя и могут зависеть от оператора CAMERA.

Альфа-канал изображения учитывается при наложении на текущую поверхность.

Правила работы

Значение типа IMAGE копируется как ссылка на одно и то же загруженное изображение, а не как отдельная копия пикселей.

Оператор DRAWIMAGE в режиме SCREEN рисует на активную страницу графического экрана. Оператор DRAWIMAGE в режиме CANVAS рисует в рабочий кадр современного холста.

Если часть изображения выходит за границы доступной поверхности, результат обрезается по границе экрана или холста.

Пример

SCREEN 1
DIM logo AS IMAGE
logo = LOADIMAGE("../../../src/Axiom.Ide/Assets/axiom.ico")

PRINT "Ширина="; IMAGEWIDTH(logo)
PRINT "Высота="; IMAGEHEIGHT(logo)
DRAWIMAGE logo, 16, 24
DRAWIMAGE logo, 96, 24, 64, 64
SLEEP

Ручная проверка

Эти файлы можно открыть в Axiom.Ide и запустить как короткие проверки поведения типа IMAGE и оператора DRAWIMAGE.

  • IMAGE: загрузка и вывод изображения
  • IMAGE: ошибка отсутствующего файла

Диагностика

  • MB3007: путь в функции LOADIMAGE пустой.
  • MB3005: файл изображения отсутствует, недоступен, повреждён или не поддерживается текущим декодером.
  • MB3005: оператор DRAWIMAGE получил пустое значение IMAGE.
  • MB3007: ширина или высота в масштабированной форме DRAWIMAGE меньше либо равна нулю.
  • MB3010: оператор DRAWIMAGE вызван без активного графического режима SCREEN или CANVAS.
