Изображения IMAGE

Тип IMAGE хранит уже загруженное полноцветное изображение, а функции LOADIMAGE, IMAGEWIDTH и IMAGEHEIGHT позволяют загрузить файл и узнать его размеры. Оператор DRAWIMAGE выводит изображение на активный графический SCREEN в натуральном размере или с масштабированием.

Назначение

Исторические операторы GET и PUT работают с прямоугольным блоком экранных индексов и обычным числовым массивом. Новый слой IMAGE решает другую задачу: он загружает готовый файл изображения и рисует его как полноцветный рисунок с альфа-каналом. Это удобно для фонов, заставок, логотипов и первых игровых заготовок.

В QuickBASIC 4.5 не было встроенной загрузки PNG, JPEG или BMP. Axiom использует современный договор с явным типом IMAGE, но сохраняет BASIC-подобную запись операторов и функций.

Синтаксис

DIM <имя> AS IMAGE
<имя> = LOADIMAGE(<путь>)

IMAGEWIDTH(<image>)
IMAGEHEIGHT(<image>)

DRAWIMAGE <image>, <x>, <y>
DRAWIMAGE <image>, <x>, <y>, <ширина>, <высота>

Части синтаксиса

ЧастьОписание
<имя>Переменная типа IMAGE. До загрузки она содержит пустое значение изображения.
<путь>Строка с путём к файлу изображения. Абсолютный путь используется как есть, относительный путь у сохранённой программы считается от каталога файла .axm.
<image>Выражение типа IMAGE: обычно переменная, получившая результат LOADIMAGE.
<x>, <y>Координаты левого верхнего угла вывода. Если включён WINDOW, координата привязки переводится через текущую логическую систему.
<ширина>, <высота>Положительные размеры итогового вывода в пикселях. Если они не указаны, изображение рисуется в натуральном размере.

Тип IMAGE

IMAGE — ссылочный встроенный тип. Присваивание переменной типа IMAGE копирует ссылку на то же загруженное изображение, а не создаёт новую копию пикселей. Значение можно передавать в SUB и FUNCTION по обычным правилам языка.

Пустое значение IMAGE не содержит пикселей. Для него IMAGEWIDTH(image) и IMAGEHEIGHT(image) возвращают 0, а DRAWIMAGE сообщает ошибку времени выполнения MB3005.

LOADIMAGE

LOADIMAGE(path) загружает файл изображения и возвращает значение типа IMAGE. В Axiom.Ide загрузка выполняется средствами Windows/WPF и приводит изображение к 32-битному формату с альфа-каналом.

Для ручных примеров можно использовать переносимые относительные пути. Если файл программы сохранён, путь считается от папки этой программы. Если программа ещё безымянная, путь считается от текущего рабочего каталога процесса.

Первый срез ориентирован на форматы, которые штатно декодирует хост IDE: PNG, JPEG, BMP и ICO. Если файл отсутствует, недоступен, повреждён или формат не поддержан текущим декодером, LOADIMAGE сообщает MB3005.

DRAWIMAGE

DRAWIMAGE работает только после выбора графического режима SCREEN 1 ... SCREEN 10. В SCREEN 0 и без активного графического экрана оператор сообщает MB3010.

Оператор выводит изображение в текущую область рисования. VIEW обрезает итоговый прямоугольник, а WINDOW влияет на точку привязки x, y. Ширина и высота в форме с масштабированием остаются пиксельными размерами, а не логическими величинами WINDOW.

Альфа-канал изображения учитывается при наложении: полностью прозрачные пиксели не меняют экран, полностью непрозрачные заменяют пиксель, промежуточная прозрачность смешивает цвет изображения с текущим видимым цветом экрана. После успешного вывода текущая графическая позиция становится равной точке привязки.

Палитра, POINT, GET и PCOPY

DRAWIMAGE записывает полноцветные пиксели поверх существующего индексного экрана. Оператор PALETTE меняет только вид индексных пикселей и не перекрашивает уже нарисованное полноцветное изображение.

Если после DRAWIMAGE прочитать точку через POINT(x, y), Axiom возвращает ближайший индекс стандартной палитры, а не исходное RGB-значение. Оператор GET работает так же: область с полноцветными пикселями сохраняется в массив как ближайшие индексы. Такой результат удобен для совместимости с GET / PUT, но он не восстанавливает исходный цвет без потерь.

PCOPY копирует между экранными страницами и индексный слой, и полноцветный слой, поэтому страница с уже нарисованным изображением переносится вместе с ним.

Пример

SCREEN 1
DIM logo AS IMAGE
logo = LOADIMAGE("../../../src/Axiom.Ide/Assets/axiom.ico")

PRINT "image size="; IMAGEWIDTH(logo); "x"; IMAGEHEIGHT(logo)
DRAWIMAGE logo, 16, 24
DRAWIMAGE logo, 96, 24, 64, 64

DO WHILE NOT KEYPRESS("ESC")
LOOP

Программа загружает значок IDE, печатает его размер, выводит изображение один раз в натуральном размере и второй раз с масштабированием до 64 x 64 пикселей.

Диагностика

  • MB3007: путь в LOADIMAGE("") пустой.
  • MB3005: файл изображения отсутствует, недоступен, повреждён или не поддержан декодером.
  • MB3005: DRAWIMAGE получил пустое значение IMAGE.
  • MB3007: ширина или высота в масштабированной форме DRAWIMAGE меньше либо равна нулю.
  • MB3010: DRAWIMAGE вызван без активного графического SCREEN 1..10.
