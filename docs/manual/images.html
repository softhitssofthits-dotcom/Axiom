Тип, функции и операторы

Изображения IMAGE

Раздел изображений описывает тип данных IMAGE, функции LOADIMAGE, IMAGEWIDTH, IMAGEHEIGHT и оператор DRAWIMAGE. Изображение загружается в память, после чего его можно измерять и выводить на экран или холст.

Что такое тип IMAGE

Тип IMAGE хранит ссылку на загруженное полноцветное изображение.

Вызов функции LOADIMAGE создаёт значение, которое затем передают в оператор DRAWIMAGE.

Где работают функции и оператор

Загрузка и измерение относятся к данным изображения; они не требуют открытия графической поверхности.

Для вывода оператором DRAWIMAGE требуется графический SCREEN 1..10 или полноцветный холст CANVAS.

Синтаксис

DIM <имя> AS IMAGE
LOADIMAGE(<путь>)
IMAGEWIDTH(<изображение>)
IMAGEHEIGHT(<изображение>)
DRAWIMAGE <изображение>, <координата X>, <координата Y>
DRAWIMAGE <изображение>, <координата X>, <координата Y>, <ширина>, <высота>

Параметры

ЧастьОписание
<имя свойства>Переменная типа IMAGE.
<путь>Передайте строковый путь к файлу изображения.
<изображение>Передайте выражение типа IMAGE.
<координата X>, <координата Y>Передайте координаты левого верхнего угла вывода. Каждый перечисленный аргумент имеет тип LONG.
<ширина>, <высота>Передайте положительные размеры итогового вывода в пикселях. Каждый перечисленный аргумент имеет тип LONG.

Функция LOADIMAGE

Встроенная функция LOADIMAGE читает файл и возвращает изображение типа IMAGE.

Синтаксис

LOADIMAGE(<путь>)

Передайте путь в аргументе <путь> типа STRING.

Абсолютный путь используется непосредственно. В сохранённой программе относительный путь отсчитывается от каталога её файла .axm.

Функции IMAGEWIDTH и IMAGEHEIGHT

Встроенные функции IMAGEWIDTH и IMAGEHEIGHT измеряют загруженное изображение в пикселях.

IMAGEWIDTH(<изображение>)
IMAGEHEIGHT(<изображение>)

Вызов IMAGEWIDTH возвращает INTEGER с шириной исходного изображения в пикселях.

Вызов IMAGEHEIGHT возвращает INTEGER с высотой исходного изображения в пикселях.

У пустого значения обе величины равны 0.

Оператор DRAWIMAGE

Оператор DRAWIMAGE рисует изображение на текущей поверхности.

DRAWIMAGE <изображение>, <координата X>, <координата Y>
DRAWIMAGE <изображение>, <координата X>, <координата Y>, <ширина>, <высота>

Форма без размеров сохраняет натуральный размер изображения.

Форма с аргументами width и height масштабирует изображение до заданного размера в пикселях.

Экран преобразует координаты текущими VIEW и WINDOW. На холсте координаты мировые и учитывают CAMERA.

Прозрачность альфа-канала учитывается при наложении на уже нарисованные пиксели.

Правила работы

Присваивание значения IMAGE копирует ссылку. Обе переменные указывают на одно изображение; отдельная копия пикселей не создаётся.

На экране рисование изменяет активную страницу, а на холсте — рабочий кадр. Оператор PRESENT явно показывает подготовленный кадр холста. Для подготовки без промежуточного показа используйте пару BEGINFRAME/PRESENT; вне этой пары вывод ресурсов может автоматически обновлять окно.

Часть изображения вне доступных границ экрана или холста обрезается.

Встроенная функция IMAGEWIDTH

IMAGEWIDTH — встроенная функция языка Axiom, которая возвращает ширину исходного изображения в пикселях. Она читает свойства значения без графического окна; результат доступен сразу.

Синтаксис

IMAGEWIDTH(<изображение>)

Аргумент

Передайте выражение типа IMAGE, свойства которого нужно прочитать. Пустая переменная после объявления допустима.

Результат, ограничения и диагностика

Функция возвращает INTEGER. Для пустого значения результат равен 0. Чтение свойства не загружает файл и не вызывает ошибку из-за пустого ресурса. Несовместимый тип или неверное число аргументов отклоняется компилятором.

Пример

DIM picture AS IMAGE
PRINT IMAGEWIDTH(picture)

Программа печатает 0, поскольку ресурс ещё не загружен. После успешной загрузки функция возвращает фактическое свойство.
