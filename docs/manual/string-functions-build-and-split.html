Раздел

Построение строк и массивы строк

Раздел построения строк и массивов строк описывает функции REPEAT, SPACE, STRING, PADLEFT, PADRIGHT, CENTER, INSERT, REMOVE, SPLIT и JOIN — средства создания нового текста, дополнения до заданной ширины и перехода между строкой и массивом строк.

Эти функции не ищут текст внутри строки, а создают новый текст: повторяют фрагмент, дополняют строку до заданной ширины, вставляют или удаляют часть строки, преобразуют коды символов и связывают строку с массивом строк.

REPEAT, SPACE, STRING

Эти функции строят новую строку из повторов, пробелов или символа-заполнителя.

Синтаксис

result = REPEAT(text, count)
result = SPACE(count)
result = STRING(count, fillText)

Аргументы

text задаёт повторяемый фрагмент, count задаёт количество повторов или символов, fillText задаёт заполнитель для STRING.

Количество повторов

REPEAT и SPACE допускают ноль, но не допускают отрицательное количество. STRING использует только первый символ заполнителя.

Функция STRING повторяет первую единицу UTF-16 заполнителя. Если fillText начинается с эмодзи вне основной плоскости, повторяется только первая половина суррогатной пары. Для повтора всего фрагмента используйте REPEAT. При count = 0 функция STRING возвращает пустую строку, в том числе с пустым fillText; при положительном count пустой fillText вызывает MB3007.

Пример повтора и пробелов

PRINT REPEAT("ha", 3)
PRINT "[" + SPACE(4) + "]"

Результат:

hahaha
[    ]

PADLEFT, PADRIGHT, CENTER

Эти функции дополняют строку до нужной ширины слева, справа или с двух сторон.

Синтаксис

result = PADLEFT(text, width[, fillText])
result = PADRIGHT(text, width[, fillText])
result = CENTER(text, width[, fillText])

Аргументы

text задаёт исходную строку, width задаёт итоговую ширину в символах, необязательный fillText задаёт заполнитель.

Ширина и заполнитель

Если строка уже не короче заданной ширины, результат остаётся равным исходной строке. Если fillText не указан, используется пробел.

Ширина измеряется в единицах UTF-16 и должна быть неотрицательным целым числом. Заполнитель использует первую единицу UTF-16. Пустой явный fillText вызывает MB3007 даже тогда, когда дополнение не требуется. CENTER при нечётном числе добавляемых единиц оставляет дополнительную единицу справа.

Пример дополнения до ширины

PRINT PADLEFT("7", 3, "0")

Результат:

007

INSERT и REMOVE

Функция INSERT вставляет фрагмент в строку, а REMOVE удаляет из неё часть символов.

Синтаксис

result = INSERT(text, start, fragment)
result = REMOVE(text, start, count)

Аргументы

text задаёт исходную строку, start задаёт начальную позицию с единицы, fragment задаёт вставляемый текст, count задаёт число удаляемых символов.

Позиции в строке

Позиции считаются с единицы в единицах UTF-16. Вставка или удаление внутри суррогатной пары может разделить её. Позиция меньше 1 вызывает MB3007. INSERT с позицией правее конца строки добавляет fragment в конец. REMOVE с позицией правее конца строки сохраняет исходную строку; слишком большое count удаляет доступный остаток. count = 0 допустимо, отрицательное count вызывает MB3007.

Пример вставки и удаления

PRINT INSERT("abcd", 3, "-")
PRINT REMOVE("abcdef", 2, 3)

Результат:

ab-cd
aef

ASC, ASCW, CHR и CHRW

ASC и CHR сохраняют BASIC/DOS-совместимый договор: коды 0..255 относятся к таблице ASCII/IBM CP866. Для задач, где нужен именно Unicode-код символа, используйте ASCW и CHRW: эта пара не делает CP866-подмену в младшем диапазоне. Полная таблица находится на странице Символы CHR, ASC, CHRW и ASCW.

Синтаксис

code = ASC(text)
unicodeCode = ASCW(text)
charText = CHR(code)
unicodeCharText = CHRW(unicodeCode)

Пример кодов и символов

PRINT CHR(159)
PRINT CHR(219)
PRINT ASC("Я")
PRINT ASC("█")
PRINT ASCW("Я")
PRINT CHRW(1071)
PRINT ASCW(CHRW(128512))

Результат:

Я
█
159
219
1071
Я
128512

SPLIT и JOIN

Функция SPLIT разбивает строку на новый массив строк, а JOIN собирает строкочный массив обратно в одну строку.

Синтаксис

Разделение по запятой:

parts = SPLIT(text)

Разделение по указанной строке:

parts = SPLIT(text, separator)

Соединение через запятую:

text = JOIN(parts)

Соединение через указанную строку:

text = JOIN(parts, separator)

Аргументы

text задаёт исходную строку, parts задаёт массив строк, необязательный separator задаёт разделитель.

Пустая строка и пустой массив

Пустая исходная строка в SPLIT даёт пустой выделенный массив 1 TO 0. Для невыделенного или пустого массива JOIN возвращает пустую строку.

SPLIT сравнивает разделитель точно в UTF-16, с учётом регистра. Разделитель может состоять из нескольких единиц, включая целый эмодзи; пустой separator вызывает MB3007. Последовательные разделители и разделители на краях создают пустые элементы. JOIN принимает одномерный массив STRING, соединяет элементы по возрастанию индекса при любой нижней границе и допускает пустой separator. Массив другого ранга отклоняется при проверке типов.

DIM parts() AS STRING
parts = SPLIT("😀А😀😀Б😀", "😀")
PRINT ARRAYLENGTH(parts) ' 5
PRINT JOIN(parts, "|")  ' |А||Б|

Разделитель Unicode и пустые части

Пример разбиения и сборки

DIM parts() AS STRING
parts = SPLIT("red,green,blue", ",")
PRINT JOIN(parts, "/")

Результат:

red/green/blue
