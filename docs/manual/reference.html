Как читать буквенный фильтр

Буквы относятся к официальным именам синтаксиса Axiom. Например, оператор PRINT попадает под букву P, а функция ROUND — под букву R.

Ручная проверка встроенных функций

Для ручной проверки открывайте готовые примеры из репозитория прямо из IDE.

  • LEN: базовое использование
  • LEFT: ошибка при нулевом количестве символов
  • READFILE: чтение текстового файла
  • READALLLINES: чтение строк файла
  • READLINES: чтение набора строк
  • DATE: текущая локальная дата
  • ABS: базовое использование
  • ASIN: ошибка вне диапазона
  • POW: ошибка области определения
