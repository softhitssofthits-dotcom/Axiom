Двумерные массивы наглядно

Сводка

Двумерный массив удобно понимать как таблицу. Первый индекс выбирает строку, второй индекс выбирает столбец. Поэтому выражение вроде board(2, 3) читается как обращение к ячейке на пересечении второй строки и третьего столбца.

Самая простая схема

DIM board(1 TO 3, 1 TO 4) AS INTEGER
           столбец
         1    2    3    4
строка 1 [ ]  [ ]  [ ]  [ ]
строка 2 [ ]  [ ]  [ ]  [ ]
строка 3 [ ]  [ ]  [ ]  [ ]

У такого массива три строки и четыре столбца. Все ячейки имеют один и тот же тип.

Как читать индексы

board(1, 1)  board(1, 2)  board(1, 3)  board(1, 4)
board(2, 1)  board(2, 2)  board(2, 3)  board(2, 4)
board(3, 1)  board(3, 2)  board(3, 3)  board(3, 4)

Порядок всегда один и тот же: сначала номер строки, потом номер столбца.

Одна конкретная ячейка

board(2, 3) = 99
           1    2    3    4
строка 1  [ ]  [ ]  [ ]  [ ]
строка 2  [ ]  [ ] [99]  [ ]
строка 3  [ ]  [ ]  [ ]  [ ]

Такой вызов изменяет ровно одну ячейку таблицы.

Часть строки как представление

rowView = board(2, 2 TO 4)

Эта запись выбирает часть второй строки. Полученное представление не копирует значения, а работает с тем же участком исходного массива.

Прямоугольный блок

block = board(2 TO 3, 2 TO 4)

Так можно выбрать прямоугольную область таблицы. Это удобно, когда нужно передать в вычисление только часть большого массива.
