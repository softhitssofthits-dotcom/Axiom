Двумерные массивы наглядно

Двумерный массив удобнее всего понимать как таблицу. Первое измерение — это строки, второе измерение — столбцы.

Самая простая картинка

DIM board(1 TO 3, 1 TO 4) AS INTEGER
            столбец
          1    2    3    4
строка 1  [ ]  [ ]  [ ]  [ ]
строка 2  [ ]  [ ]  [ ]  [ ]
строка 3  [ ]  [ ]  [ ]  [ ]

Запись board(2, 3) означает: строка 2, столбец 3.

Как читать индексы

board(1, 1)  board(1, 2)  board(1, 3)  board(1, 4)
board(2, 1)  board(2, 2)  board(2, 3)  board(2, 4)
board(3, 1)  board(3, 2)  board(3, 3)  board(3, 4)

Порядок всегда такой: сначала номер строки, потом номер столбца.

Одна конкретная ячейка

board(2, 3) = 99
            1    2    3    4
строка 1    [ ]  [ ]  [ ]  [ ]
строка 2    [ ]  [ ] [99] [ ]
строка 3    [ ]  [ ]  [ ]  [ ]

Строка как представление

rowView = board(2, 2 TO 4)
исходный board:

            1    2    3    4
строка 1    [ ]  [ ]  [ ]  [ ]
строка 2    [ ] [ ]  [ ]  [ ]
строка 3    [ ]  [ ]  [ ]  [ ]

rowView смотрит на:
строка 2, столбцы 2..4

Это не копия. Это живое представление части исходного массива. Если изменить rowView, изменится и board.

Прямоугольный блок

block = board(2 TO 3, 2 TO 4)
            1    2    3    4
строка 1    [ ]  [ ]  [ ]  [ ]
строка 2    [ ] [ ]  [ ]  [ ]
строка 3    [ ] [ ]  [ ]  [ ]

block тоже не копирует значения. Он смотрит на тот же прямоугольный кусок исходной таблицы.

В каком порядке массив обходится целиком

(1,1) -> (1,2) -> (1,3) -> (1,4)
(2,1) -> (2,2) -> (2,3) -> (2,4)
(3,1) -> (3,2) -> (3,3) -> (3,4)

Сначала перебираются столбцы внутри текущей строки, потом начинается следующая строка. На этом порядке уже основаны многомерные ARRAYCOUNT, ARRAYEVERY, ARRAYSOME и ARRAYREDUCE.

Почему нужны ROW и COLUMN

Когда функция просит номер измерения, числа 1 и 2 работают, но читаются сухо. Поэтому в языке есть предопределённые константы:

PRINT LBOUND(board, ROW)
PRINT UBOUND(board, COLUMN)
  • ROW означает первое измерение, то есть строки;
  • COLUMN означает второе измерение, то есть столбцы;
  • числа 1 и 2 при этом остаются полностью допустимыми.
