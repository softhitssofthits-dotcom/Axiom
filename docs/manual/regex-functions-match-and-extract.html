REGEXISMATCH

Функция REGEXISMATCH проверяет, есть ли в строке хотя бы одно совпадение с указанным регулярным выражением.

Синтаксис

result = REGEXISMATCH(text, pattern[, modes])

Аргументы

text задаёт исходную строку, pattern задаёт регулярное выражение, modes при необходимости включает дополнительные режимы поиска.

Замечания

Результат имеет тип BOOLEAN: функция возвращает TRUE, если совпадение найдено, и FALSE, если совпадений нет.

Пример

PRINT REGEXISMATCH("A12", "\d+")
PRINT REGEXISMATCH("A12", "^a\d+", "i")

REGEXMATCH

Функция REGEXMATCH возвращает первое совпадение целиком.

Синтаксис

result = REGEXMATCH(text, pattern[, modes])

Замечания

Если совпадение найдено, результатом становится найденный фрагмент строки. Если совпадение не найдено, функция возвращает пустую строку.

Пример

PRINT REGEXMATCH("Order 42 and 100", "\d+")
PRINT "[" + REGEXMATCH("Order", "\d+") + "]"

REGEXEXTRACT

Функция REGEXEXTRACT возвращает значение указанной группы из первого найденного совпадения.

Синтаксис

result = REGEXEXTRACT(text, pattern, groupNumber[, modes])

Аргументы

groupNumber задаёт номер группы. Ноль означает всё совпадение целиком, единица первую группу в скобках, двойка вторую и так далее.

Замечания

Если совпадение не найдено или нужной группы в нём нет, функция возвращает пустую строку. Отрицательный номер группы даёт MB3007.

Пример

PRINT REGEXEXTRACT("A12", "([A-Z])(\\d+)", 2)
PRINT REGEXEXTRACT("a12", "([A-Z])(\\d+)", 1, "i")
