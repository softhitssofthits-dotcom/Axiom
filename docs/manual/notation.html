Условные обозначения синтаксиса

Раздел условных обозначений объясняет формальные записи справочника. Обозначения показывают части конструкции, которые нужно подставить, и не являются готовой программой.

Обозначения

ЗаписьКак читать
PRINT, ASКлючевые слова записываются буквально. Регистр не меняет смысл.
<имя>, <выражение>Подставьте имя или выражение, описанное в параметрах. Угловые скобки в программу не переносятся.
⟦STEP <шаг>⟧Необязательная часть. Знаки ⟦ и ⟧ в программу не переносятся; содержимое при выборе этой части записывается буквально.
⟦;|,⟧Необязательный выбор между двумя разделителями.
(, ), [, ], ,, ;Знаки входят в программу, если указаны в выбранной форме.
...Повторение или пропущенная часть; смысл уточняется рядом с записью.

Форма и пример

Формальная запись использует подставляемые части:

FOR <счётчик> = <начало> TO <конец> ⟦STEP <шаг>⟧
    <инструкции>
NEXT

В программе вместо них стоят конкретные значения и инструкции:

FOR index = 1 TO 3
    PRINT index
NEXT

Подписи функций

Квадратные скобки различают массивное имя, элемент и тип: values[] обозначает массив целиком, values[2] — элемент, INTEGER[,] — двумерный массив в описании типа. Вызов MakeValues() сохраняет круглые скобки. В формальной записи <выражение массива> нужно подставить полное массивное выражение: например, values[], values[1 TO 2] или MakeValues(). Суффикс не добавляется к вызову функции только потому, что она возвращает массив.

В формальной подписи LEN(<текст>) запись <текст> обозначает строковый аргумент. Подставьте строковый литерал, переменную или выражение; переменная не обязана называться «текст». Обозначение T используется для типа элемента массива, U — для типа результата преобразования, A — для типа аккумулятора. Несколько поддерживаемых форм показываются отдельными блоками. Все аргументы конкретной полной формы обязательны.

Пример и результат

Блок результата показывает ожидаемый вывод. Ссылки на .axm открывают запускаемые примеры. Формальная запись с угловыми скобками предназначена для чтения синтаксиса и не запускается как исходник.
