Обозначения синтаксиса

Раздел определяет обозначения, используемые в формальных записях справочника. Метапеременные и знаки необязательных частей описывают синтаксис; они не являются текстом программы.

Условные обозначения

ОбозначениеЗначение
PRINT, AS, END IFКлючевые слова. В справочнике записываются заглавными буквами.
<имя>, <выражение>Метапеременные. Вместо них записывается имя, выражение или другая часть, указанная в описании параметров.
[STEP <шаг>]Необязательная часть. Квадратные скобки не переносятся в программу.
;, ,, (, )Знаки, которые записываются буквально, если входят в выбранную форму синтаксиса.
| внутри перечня вариантовРазделитель альтернатив в справочной записи. Например, [;|,] обозначает необязательный выбор точки с запятой или запятой.
... в описании блокаПропущенные инструкции или повторяемые элементы. Смысл уточняется на странице конструкции.

Формы синтаксиса

Разные формы конструкции приводятся отдельными блоками. Описание параметров определяет тип каждого выражения, единицы измерения, допустимые значения и значение по умолчанию для необязательного аргумента.

FOR <счётчик> = <начало> TO <конец> [STEP <шаг>]
    <инструкции>
NEXT

Без части STEP шаг цикла равен 1. Формальная запись отличается от программы-примера:

FOR i = 1 TO 3
    PRINT i
NEXT

Результат:

1
2
3

Справочные подписи функций

В компактных подписях используются имена аргументов, например LEN(text). Имя text обозначает строковое выражение, а не обязательное имя переменной. Обозначение T в подписи функции массива означает тип элемента; T() — массив элементов этого типа.

Записи result = ... и text = ... показывают использование результата. Они не требуют, чтобы переменная называлась result или text. В запускаемой программе переменная объявляется отдельно.

Примеры и диагностика

Блок «Результат» содержит ожидаемый вывод приведённой программы. Раздел «Запускаемые примеры» содержит ссылки на файлы .axm. Диагностика описывает условия возникновения конкретной ошибки; наличие кода ошибки не изменяет синтаксис конструкции.
