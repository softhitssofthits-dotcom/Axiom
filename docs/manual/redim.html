Оператор REDIM

REDIM — оператор языка Axiom, который выделяет хранилище массива с указанными границами. Форма REDIM PRESERVE сохраняет элементы из области пересечения прежних и новых границ.

Контекст

Оператор применяется к массиву, объявленному в программе, или к доступному полю массива. Тип элементов и ранг массива определены объявлением. Экранный или файловый режим не требуется.

Синтаксис

REDIM <массив>(<нижняя граница> TO <верхняя граница>)
REDIM PRESERVE <массив>(<нижняя граница> TO <верхняя граница>)

Для многомерного массива пары границ всех измерений записываются через запятую.

Параметры

  • <массив> — изменяемое значение массива.
  • Нижняя и верхняя границы — целочисленные выражения с допустимыми индексами. Обе границы входят в диапазон.
  • PRESERVE — необязательное ключевое слово сохранения элементов.

Правила работы

Обычный REDIM создаёт новое хранилище и задаёт элементам значения по умолчанию. Форма с PRESERVE копирует элементы с теми же индексами в области пересечения всех измерений; остальные элементы получают значения по умолчанию. Если пересечение пусто, старые значения не сохраняются.

Ранг и тип элементов не меняются. Поле фиксированного массива внутри записи TYPE перераспределять нельзя. Границы, пустые измерения и ограничения индексов описаны в разделе многомерных массивов.

Диагностика

  • MB2011 — цель не является массивом.
  • MB2010 — цель объявлена неизменяемой.
  • MB2004 — число измерений не соответствует рангу массива.
  • MB2025 — цель является фиксированным полем массива в записи TYPE.

Ошибки границ при выполнении описаны в диагностике массивов.

Пример

DIM values() AS INTEGER
REDIM values(1 TO 2)
values(1) = 10
REDIM PRESERVE values(1 TO 3)
PRINT values(1)
PRINT values(3)

Результат:

10
0

Запускаемые примеры: сохранение элементов, пустой массив.
