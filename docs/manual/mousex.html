Функция MOUSEX

MOUSEX — встроенная функция языка Axiom, которая возвращает текущую горизонтальную координату указателя на активной графической поверхности программы. Встроенная функция MOUSEX подходит для опросного режима, когда программе достаточно знать текущее положение указателя, а не получать отдельные события перемещения.

Для чего нужна функция MOUSEX

Встроенная функция MOUSEX нужна для чтения текущей X-координаты указателя мыши. В графическом режиме SCREEN функция возвращает экранную координату клиентской области. В режиме CANVAS функция возвращает мировую координату точки, на которую указывает мышь после пересчёта через VIEWPORT и CAMERA.

Где работает функция MOUSEX

Встроенная функция MOUSEX работает при активном графическом режиме SCREEN 1..10 или при активном CANVAS. Без активной рисуемой поверхности выполнение сообщает диагностику MB3010.

При активном SCREEN оператор VIEW, оператор WINDOW и функция PMAP не изменяют возвращаемую координату: она остаётся в клиентской системе координат активного окна SCREEN. При активном CANVAS возвращаемое значение уже находится в мировой системе координат и учитывает текущие VIEWPORT и CAMERA.

Встроенная функция MOUSEX выполняется BytecodeVm после компиляции.

Синтаксис

MOUSEX()

Встроенная функция MOUSEX поддерживает только форму без аргументов.

Аргументы

У встроенной функции MOUSEX нет аргументов. Пустые скобки остаются частью вызова функции.

Что возвращает функция MOUSEX

Тип результата: LONG.

  • Если активен SCREEN и среда выполнения знает положение указателя, возвращается текущая X-координата в клиентской области активного окна.
  • Если активен CANVAS и среда выполнения знает положение указателя, возвращается мировая X-координата точки под мышью.
  • Если положение указателя недоступно, возвращается -1.

Правила работы

  • Встроенная функция MOUSEX не принимает аргументов.
  • Функция не создаёт очередь мышиных событий и не хранит историю перемещений.
  • Если среда не знает текущее положение указателя, функция возвращает -1.
  • В CANVAS мировая координата считается как положение камеры плюс смещение указателя внутри прямоугольника VIEWPORT.
  • Для вертикальной координаты используется встроенная функция MOUSEY, а для кнопок — встроенная функция MOUSEBUTTON.

Пример чтения координат

PRINT MOUSEX()
PRINT MOUSEY()

Ручная проверка

  • MOUSEX: текущее положение указателя в SCREEN
  • MOUSEX: мировая координата в CANVAS

Диагностика

  • MB2004: в встроенную функцию MOUSEX переданы аргументы.
  • MB3010: встроенная функция MOUSEX вызвана без активного графического режима SCREEN и без активного CANVAS.
