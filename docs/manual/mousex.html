Функция MOUSEX

MOUSEX — встроенная функция языка Axiom, которая возвращает текущую горизонтальную координату указателя в активном графическом режиме SCREEN. Встроенная функция MOUSEX подходит для опросного режима, когда программе достаточно знать текущее положение курсора, а не получать отдельные события перемещения.

Для чего нужна функция MOUSEX

Встроенная функция MOUSEX нужна для чтения текущей X-координаты указателя мыши. Функция возвращает координату в пикселях клиентской области активной поверхности SCREEN и не создаёт очередь мышиных событий и не хранит историю перемещений.

Где работает функция MOUSEX

Встроенная функция MOUSEX работает только при активном графическом режиме SCREEN. Без него выполнение сообщает диагностику MB3010. Операторы VIEW, WINDOW и PMAP не изменяют возвращаемую координату: она остаётся в клиентской системе координат активной поверхности ввода, а не в логической системе графических примитивов.

Встроенная функция MOUSEX поддерживается интерпретатором и BytecodeVm.

Синтаксис

MOUSEX()

Встроенная функция MOUSEX поддерживает только форму без аргументов.

Аргументы

У встроенной функции MOUSEX нет аргументов. Пустые скобки остаются частью вызова функции.

Что возвращает функция MOUSEX

Тип результата: LONG.

  • Если среда выполнения знает положение указателя, возвращается текущая X-координата в клиентской области активной поверхности SCREEN.
  • Если положение указателя недоступно, возвращается -1.

Правила работы

  • Встроенная функция MOUSEX не принимает аргументов.
  • Функция не создаёт очередь мышиных событий и не хранит историю перемещений.
  • Если среда не знает текущее положение указателя, функция возвращает -1.
  • Для вертикальной координаты используется встроенная функция MOUSEY, а для кнопок — встроенная функция MOUSEBUTTON.

Пример чтения координат

PRINT MOUSEX()
PRINT MOUSEY()

Ручная проверка

  • MOUSEX: текущее положение указателя

Диагностика

  • MB2004: в встроенную функцию MOUSEX переданы аргументы.
  • MB3010: встроенная функция MOUSEX вызвана без активного графического режима SCREEN.
