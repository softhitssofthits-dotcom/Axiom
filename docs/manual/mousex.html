Функция MOUSEX

MOUSEX — встроенная функция языка Axiom, которая возвращает текущую горизонтальную координату указателя мыши. Программа выбирает момент чтения, вызывая функцию в своём цикле.

Применение

На экране SCREEN координата X измеряется в пикселях клиентской области. На холсте CANVAS результат соответствует мировому положению указателя после преобразования через VIEWPORT и CAMERA.

Контекст выполнения

Для чтения нужен графический SCREEN 1..10 или активный CANVAS. Отсутствие поверхности сообщает MB3010.

На экране VIEW, WINDOW и PMAP не пересчитывают координату мыши. На холсте учитываются текущие область и камера.

Функция читает текущее положение без извлечения события перемещения. Для процедуры по каждому событию используйте ON MOUSE.

Синтаксис

MOUSEX()

Поддерживается единственная форма MOUSEX().

Аргументы

Аргументов нет; скобки остаются частью вызова.

Что возвращает функция MOUSEX

Координата возвращается как значение типа LONG.

  • Если активен SCREEN и среда выполнения знает положение указателя, возвращается текущая X-координата в клиентской области активного окна.
  • Если активен CANVAS и среда выполнения знает положение указателя, возвращается мировая X-координата точки под мышью.
  • Если положение указателя недоступно, возвращается -1.

Правила работы

  • Встроенная функция MOUSEX не принимает аргументов.
  • Функция не создаёт очередь мышиных событий и не хранит историю перемещений.
  • Если среда не знает текущее положение указателя, функция возвращает -1.
  • В CANVAS мировая координата считается как положение камеры плюс смещение указателя внутри прямоугольника VIEWPORT.
  • Для вертикальной координаты используется встроенная функция MOUSEY, а для кнопок — встроенная функция MOUSEBUTTON.

Начало координат и отрицательные значения

В SCREEN начало клиентской области находится слева сверху; X увеличивается вправо. В CANVAS функция возвращает камера X + физический X - левая граница области. Отрицательное мировое значение может быть допустимой координатой сцены; само по себе оно не доказывает отсутствие указателя.

Диагностика

  • MB2004: в встроенную функцию MOUSEX переданы аргументы.
  • MB3010: встроенная функция MOUSEX вызвана без активного графического режима SCREEN и без активного CANVAS.

Пример чтения координат

SCREEN 1
PRINT MOUSEX()
PRINT MOUSEY()
SLEEP

Программа печатает две координаты указателя в пикселях окна. Если положение ещё неизвестно, выводятся -1 и -1. Затем программа ждёт клавишу.

Запускаемые примеры

  • MOUSEX: текущее положение указателя в SCREEN
  • MOUSEX: мировая координата в CANVAS
