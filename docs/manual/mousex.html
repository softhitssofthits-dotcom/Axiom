Функция MOUSEX

Опрос текущей X-координаты указателя без событийной очереди.

Ввод и вывод

Функция MOUSEX

MOUSEX() возвращает текущую горизонтальную координату указателя мыши на активной поверхности программы. Функция подходит для опросного режима, когда программе достаточно знать текущее положение курсора, а не получать отдельные события перемещения.

Синтаксис

MOUSEX()

Возвращаемое значение

Тип результата: LONG.

  • если среда выполнения знает положение указателя, возвращается текущая X-координата;
  • если положение указателя недоступно, возвращается -1.

Замечания

  • MOUSEX() не принимает аргументов;
  • функция не создаёт очередь мышиных событий и не хранит историю перемещений;
  • в текущем срезе координата относится к активной поверхности выполнения программы в IDE;
  • для вертикальной координаты используйте MOUSEY(), а для кнопок — MOUSEBUTTON().

Пример

PRINT MOUSEX()
PRINT MOUSEY()

Ручная проверка

  • MOUSEX: текущее положение указателя

Диагностика

Диагностика MB2004 возникает, если передать аргументы в MOUSEX().
