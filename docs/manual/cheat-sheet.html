Краткая шпаргалка

Эта страница служит краткой сводкой по основным формам синтаксиса. Откройте её, когда нужно быстро восстановить в памяти форму объявления, цикла, ветвления или вызова встроенной функции.

Когда открывать шпаргалку

  • когда нужна краткая форма конструкции без подробного объяснения;
  • когда нужно восстановить синтаксис перед запуском примера в IDE;
  • когда после шпаргалки требуется перейти к подробной справочной статье.

Условия

IF score >= 90 THEN
    PRINT "Отлично"
ELSEIF score >= 70 THEN
    PRINT "Хорошо"
ELSE
    PRINT "Нужно доработать"
END IF

SELECT CASE score
    CASE 1
        PRINT "Минимум"
    CASE 2, 3
        PRINT "Небольшое значение"
    CASE 10 TO 20
        PRINT "Диапазон от 10 до 20"
    CASE IS > 100
        PRINT "Больше ста"
    CASE ELSE
        PRINT "Другой случай"
END SELECT

Циклы

FOR i = 1 TO 10 STEP 2
    PRINT i
NEXT

WHILE total < 100
    total = total + 10
END WHILE

DO WHILE value <> 0
    INPUT "Введите число"; value
LOOP

DO UNTIL ready = TRUE
    ready = CheckState()
LOOP

DO
    PRINT "Первый проход обязателен"
LOOP WHILE keepRunning

DO
    total = total + 1
LOOP UNTIL total >= 10

DO
    PRINT "Повторение до EXIT DO"
    EXIT DO
LOOP

Процедуры и функции

    PRINT text
END SUB

    RETURN a + b
END FUNCTION

Напоминания

Самые частые правила

  • новые переменные обычно объявляются через DIM;
  • локальная переменная блока недоступна после выхода из блока;
  • FOR-счетчик не требует отдельного предварительного DIM;
  • MID использует позицию с единицы.
