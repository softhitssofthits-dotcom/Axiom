Краткая справка

Краткая справка содержит основные формы синтаксиса Axiom: объявления, ввод и вывод, условия, циклы, процедуры, массивы и небольшую выборку встроенных функций.

Основные группы синтаксиса

  • DIM и CONST вводят имена значений;
  • PRINT показывает результат, а INPUT получает строку от пользователя;
  • IF, SELECT CASE, циклы и вызовы процедур меняют обычный порядок выполнения;
  • встроенные функции вычисляют значения; подробные списки функций находятся в тематических разделах по строкам, числам, датам, файлам, массивам и регулярным выражениям.

Типы и объявления

DIM age AS INTEGER
DIM price AS DOUBLE = 1.5
DIM title = "Пример"
CONST APP_NAME AS STRING = "Demo"

Ввод и вывод

PRINT "Привет"
PRINT 10, 20
PRINT "Имя: "; "Анна"
PRINT

PRINT $"Возраст: {age}"
PRINT $"Цена: {price:F2}"
PRINT $"Имя: |{name,20}|"

INPUT value
INPUT "Введите имя: "; name
INPUT x, y

Условия

IF score >= 90 THEN
    PRINT "Отлично"
ELSEIF score >= 70 THEN
    PRINT "Хорошо"
ELSE
    PRINT "Нужно доработать"
END IF

SELECT CASE score
    CASE 1
        PRINT "Минимум"
    CASE 2, 3
        PRINT "Небольшое значение"
    CASE 10 TO 20
        PRINT "Диапазон от 10 до 20"
    CASE IS > 100
        PRINT "Больше ста"
    CASE ELSE
        PRINT "Другой случай"
END SELECT

Циклы

FOR i = 1 TO 10 STEP 2
    PRINT i
NEXT

WHILE total < 100
    total = total + 10
END WHILE

DO WHILE value <> 0
    INPUT "Введите число"; value
LOOP

DO UNTIL ready = TRUE
    INPUT "Готово"; ready
LOOP

DO
    PRINT "Первый проход обязателен"
LOOP WHILE keepRunning

DO
    total = total + 1
LOOP UNTIL total >= 10

DO
    PRINT "Повторение до EXIT DO"
    EXIT DO
LOOP

Частые правила синтаксиса

Проверьте перед запуском

  • новые переменные обычно объявляются через DIM;
  • локальная переменная блока недоступна после выхода из блока;
  • FOR-счетчик не требует отдельного предварительного DIM;
  • MID использует позицию с единицы.
