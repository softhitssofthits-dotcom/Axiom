Краткая шпаргалка

Эта страница служит краткой сводкой по основным формам синтаксиса. Откройте её, когда нужно быстро восстановить в памяти форму объявления, цикла, ветвления или вызова встроенной функции.

Когда открывать шпаргалку

  • когда нужна краткая форма конструкции без подробного объяснения;
  • когда нужно восстановить синтаксис перед запуском примера в IDE;
  • когда после шпаргалки требуется перейти к подробной справочной статье.

Типы и объявления

DIM age AS INTEGER
DIM price AS DOUBLE = 1.5
DIM title = "Пример"
CONST APP_NAME AS STRING = "Demo"

Ввод и вывод

PRINT "Привет"
PRINT 10, 20
PRINT "Имя: "; "Анна"
PRINT

INPUT value
INPUT "Введите имя: "; name
INPUT x, y

Условия

IF <условие> THEN
    <инструкции>
[ELSEIF <другое условие> THEN
    <инструкции>]
...
[ELSE
    <инструкции>]
END IF

SELECT CASE <выражение>
    CASE 1
        <инструкции>
    CASE 2, 3
        <инструкции>
    CASE 10 TO 20
        <инструкции>
    CASE IS > 100
        <инструкции>
    CASE ELSE
        <инструкции>
END SELECT

Циклы

FOR <счётчик> = <начало> TO <конец> [STEP <шаг>]
    <инструкции>
NEXT

WHILE <условие>
    <инструкции>
END WHILE

DO WHILE <условие>
    <инструкции>
LOOP

DO UNTIL <условие>
    <инструкции>
LOOP

DO
    <инструкции>
LOOP WHILE <условие>

DO
    <инструкции>
LOOP UNTIL <условие>

DO
    <инструкции>
    EXIT DO
LOOP

Подпрограммы и функции

SUB ShowMessage(text AS STRING)
    PRINT text
END SUB

FUNCTION Add(a AS INTEGER, b AS INTEGER) AS INTEGER
    RETURN a + b
END FUNCTION

Массивы

DIM numbers(1 TO 3) AS INTEGER
numbers(1) = 10
PRINT numbers(1)

Встроенные функции

  • LEN(<текст>)
  • LEFT(<текст>, <количество>)
  • RIGHT(<текст>, <количество>)
  • MID(<текст>, <начало>, <количество>)
  • LCASE(text)
  • UCASE(text)
  • INT(value)
  • STR(value)
  • VAL(text)

Напоминания

Самые частые правила

  • новые переменные обычно объявляются через DIM;
  • локальная переменная блока недоступна после выхода из блока;
  • FOR-счетчик не требует отдельного предварительного DIM;
  • MID использует позицию с единицы.
