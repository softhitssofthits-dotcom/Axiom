Операторы

CLS, COLOR и LOCATE

Операторы CLS, COLOR и LOCATE управляют текстом в окне SCREEN. CLS очищает экран, COLOR задаёт цвет символов, а LOCATE переносит текстовый курсор в нужную строку и столбец.

Текст на экране

После выбора экранного режима оператор PRINT выводит текст не во вкладку Output, а в окно программы. В SCREEN 0 это текстовое окно без операторов рисования. В режимах SCREEN 1 ... SCREEN 10 текст выводится поверх графического экрана.

Текстовый SCREEN 0 ведёт себя как короткое консольное окно: одновременно видимы только последние 25 строк, а новый перевод строки из нижней строки прокручивает окно вверх. Графические режимы такой общей автопрокрутки не делают: текст за нижней границей просто не виден, если программа не задала отдельное текстовое окно через VIEW PRINT.

В текущем окне SCREEN 0 в Axiom.Ide ранние строки сохраняются в истории текущего запуска. Когда история становится длиннее видимой области, справа появляется вертикальная полоса прокрутки, и пользователь может вручную просмотреть более ранние строки.

Оператор LOCATE считает не пиксели, а строки и столбцы. Одна текстовая ячейка занимает 8 x 12 пикселей. Поэтому количество строк и столбцов зависит от выбранного режима SCREEN. Для SCREEN 10 эти числа вычисляются от фактически выбранных размеров адаптивного режима 16:9 для текущего монитора.

Оператор CLS

CLS

CLS очищает экран программы и возвращает текстовый курсор в позицию 1, 1. В графическом режиме очищаются и выведенный текст, и нарисованные точки, линии и окружности.

В SCREEN 0 команда также сбрасывает накопленную прокрутку и историю: после CLS снова видна пустая сетка 80 x 25, и следующий вывод начинается с первой строки.

Если программа не выбирала SCREEN, CLS относится к обычному выводу во вкладке Output.

SCREEN 3
PRINT "old text"
PSET (10, 10), 12
CLS
PRINT "Экран очищен"
SCREEN 0

Оператор COLOR

COLOR <цвет символов>
COLOR <цвет символов>, <цвет фона>
COLOR <цвет символов>, TRANSPARENT

COLOR задаёт текущее оформление текста на графическом экране SCREEN. Команда может только сменить цвет символов, включить непрозрачный фон ячеек или явно переключить последующий вывод в прозрачный режим поверх уже нарисованной графики.

ПараметрОписание
<цвет символов>Номер цвета, которым будут выводиться следующие символы.
<цвет фона>Необязательный номер непрозрачного фона за следующими символами.
TRANSPARENTЯвно отключает закраску фона у следующих символов и оставляет видимой графику под текстом.

COLOR foreground, background меняет цвет символов и задаёт новый непрозрачный фон. COLOR foreground меняет только цвет символов и сохраняет текущий режим фона. COLOR foreground, TRANSPARENT меняет цвет символов и включает прозрачный фон для следующего PRINT или INPUT.

Текстовый слой остаётся ячеечным: каждая уже напечатанная ячейка хранит свой символ, цвет символа и режим фона на момент вывода. Последующие вызовы COLOR не перекрашивают ранее выведенный текст.

Команда требует активный графический режим SCREEN 1 ... SCREEN 10. В текстовом SCREEN 0 этот договор цвета пока недоступен.

SCREEN 3
COLOR 14, 1
PRINT "Жёлтый текст на синем фоне"
COLOR 15
PRINT "Белый текст на прежнем фоне"
COLOR 15, TRANSPARENT
PRINT "Прозрачная подпись поверх графики"
COLOR 46
PRINT "Русский текст в графическом режиме"
COLOR 226
PRINT "Цвет с номером 226"
SCREEN 0

Для цветовых таблиц удобно использовать блочные символы. Функция CHR() для кодов 0..255 использует таблицу IBM CP866, поэтому CHR(219), CHR(178), CHR(177) и CHR(176) возвращают █, ▓, ▒ и ░.

SCREEN 10
DIM r AS INTEGER
DIM c AS INTEGER
FOR i = 16 TO 255
    r = ((i - 16) \ 16) + 1
    c = (((i - 16) MOD 16) * 2) + 1
    LOCATE r, c
    COLOR i, 0
    PRINT CHR(219)
NEXT
SCREEN 0

Оператор LOCATE

LOCATE <строка>, <столбец>

LOCATE переносит текстовый курсор в указанную строку и столбец графического экрана. Следующий PRINT начнёт вывод с этой позиции.

ПараметрОписание
<строка>Номер строки текстовой сетки. Строки считаются с 1.
<столбец>Номер столбца текстовой сетки. Столбцы считаются с 1.

Значения меньше 1 приводятся к 1. Если строка или столбец находятся дальше видимой сетки, текст записывается за пределами видимой области и не отображается.

Число столбцов равно SCREENWIDTH() \ 8, а число строк равно SCREENHEIGHT() \ 12.

Если ширина или высота режима не делится на размер ячейки без остатка, оставшиеся пиксели справа или снизу не образуют отдельную текстовую позицию.

В SCREEN 10 ширина и высота подбираются по рабочей области монитора, поэтому и последняя видимая позиция LOCATE определяется только во время запуска.

Последующий PRINT перезаписывает символы с указанной позиции, а не вставляет их в строку. Если новый текст короче старого, хвост старой строки остаётся на экране.

Сам по себе LOCATE не прокручивает SCREEN 0. Прокрутка происходит только тогда, когда PRINT, PRINT USING или подтверждённый INPUT завершают строку ниже строки 25.

Ручная прокрутка полосой прокрутки не меняет текущую позицию LOCATE и не переставляет текстовый курсор программы. Она меняет только то, какую часть истории сейчас видит пользователь.

В графических режимах VIEW PRINT верх TO низ может ограничить прокрутку текстового вывода выбранным диапазоном строк. Обычный VIEW для графики на LOCATE не влияет.

SCREEN 3
LOCATE 2, 4
PRINT "score=120"
LOCATE 2, 4
PRINT "score=9  "
SCREEN 0

Палитра

Цвета имеют индексы 0..255. Индексы 0..15 сохраняют классическую BASIC-палитру, 16..231 образуют RGB-куб 6x6x6, а 232..255 дают серую шкалу. Значения вне диапазона приводятся к палитре по правилу ABS(color) MOD 256.

Экранные символы

CHR() и ASC() используют общий строковый договор Axiom: коды 0..255 соответствуют ASCII/IBM CP866, а коды выше 255 остаются Unicode-кодами. Поэтому русские буквы, рамки и блочные символы работают одинаково в обычном выводе и в активном SCREEN. Для прямой Unicode-работы без CP866-подмены есть CHRW() и ASCW().

Полная таблица кодов вынесена на отдельную страницу Символы CHR, ASC, CHRW и ASCW.

Проверочная программа

Программы можно открыть в Axiom.Ide и запустить для проверки PRINT, LOCATE, COLOR, прокрутки SCREEN 0, полосы прокрутки, палитры и прозрачного текстового фона.

  • SCREEN 0: вертикальная прокрутка и полоса прокрутки
  • Текст, позиция курсора и цвета
  • Прозрачный и непрозрачный текст поверх графики
  • VIEW PRINT: прокрутка внутри строкового диапазона
