Операторы

Текст на экране

Раздел экранного текста описывает операторы CLS, COLOR и LOCATE. Они очищают вывод, задают цвета символов и выбирают ячейку для следующего текста в окне SCREEN.

Где работают эти операторы

Эти операторы управляют экранным текстом. Описание ниже относится к отдельным командам, у каждой из которых есть собственная форма вызова.

Оператор CLS может очистить и обычную текстовую область среды исполнения. Для указанного здесь договора COLOR нужен графический SCREEN 1..10, а LOCATE перемещает курсор в текстовой сетке графического SCREEN 1..10.

Текстовая сетка SCREEN

Позиция текста задаётся строкой и столбцом сетки. Ячейка занимает 8 x 12 пикселей.

Текстовый режим предоставляет сетку 80 x 25. Размеры сеток графических режимов приведены на странице SCREEN; для адаптивного режима 10 они вычисляются как SCREENWIDTH() \ 8 и SCREENHEIGHT() \ 12.

Оператор CLS

Оператор CLS удаляет содержимое вывода.

CLS

В окне SCREEN очистка также возвращает текстовый курсор в ячейку 1, 1.

До открытия окна SCREEN очищается обычная текстовая область среды исполнения.

На графическом экране очистка удаляет одновременно текст и нарисованные пиксели.

SCREEN 3
PRINT "Старая надпись"
CLS
PRINT "Экран очищен"

Оператор COLOR

Оператор COLOR задаёт цвет символов и режим фона для следующих операций текстового вывода.

COLOR <цвет символов>
COLOR <цвет символов>, <фон>
COLOR <цвет символов>, TRANSPARENT

Аргумент foreground содержит номер цвета символов.

Аргумент background содержит номер непрозрачного фона под символами.

Слово TRANSPARENT включает вывод без закрашивания фона под символами.

Форма с одним цветом сохраняет прежний режим фона. Второй числовой аргумент выбирает непрозрачный фон; слово TRANSPARENT вместо него выбирает прозрачный фон.

Этот цветовой договор требует графического режима SCREEN 1..10 и недоступен в текстовом режиме SCREEN 0.

SCREEN 3
COLOR 14, 1
PRINT "Жёлтый текст на синем фоне"
COLOR 15, TRANSPARENT
PRINT "Белый текст поверх графики"

Оператор LOCATE

Оператор LOCATE выбирает строку и столбец текстового курсора.

LOCATE <строка>, <столбец>

Строки row нумеруются с 1.

Столбцы column также нумеруются с 1.

Следующий текстовый вывод начинается в выбранной ячейке.

Для видимого вывода выбирайте номера строки и столбца внутри текущей сетки. Пиксельные координаты в оператор LOCATE не передаются.

SCREEN 1
LOCATE 3, 5
PRINT "Текст начинается с третьей строки и пятого столбца"

Правила работы

В текстовом режиме вывод с переходом из последней видимой строки прокручивает окно вверх на одну строку.

В графическом режиме текст накладывается на изображение. Без отдельной области VIEW PRINT текст ниже нижней границы сетки не виден.

Настройка цвета применяется к последующему выводу. Уже выведенные символы сохраняют своё оформление.

Типы аргументов и границы курсора

COLOR принимает INTEGER: первый аргумент задаёт индекс символов, второй — индекс фона; TRANSPARENT вместо второго аргумента сохраняет пиксели под символами. Индексы нормализуются как ABS(значение) MOD 256. LOCATE принимает два INTEGER: номер строки и номер столбца, начиная с 1. Оба оператора требуют графический SCREEN 1..10.

В действующей среде LOCATE заменяет номер меньше 1 на 1. Большой номер сам по себе не вызывает MB3007: текст за видимой сеткой может оказаться невидимым. Чтобы получить видимый результат, выбирайте ячейку внутри сетки; LOCATE не меняет пиксельную систему VIEW или WINDOW.

CLS без аргумента очищает текущий вывод; на CANVAS он очищает рабочий кадр чёрным цветом. Форма CLS с цветом принимает INTEGER и работает только на CANVAS. Очистка холста становится видимой после PRESENT. Если неподходящий графический режим известен компилятору, он сообщает MB2046; при проверке режима во время выполнения возникает MB3010.

Пример

SCREEN 3
CLS
COLOR 14, 1
LOCATE 3, 5
PRINT "Жёлтый текст на синем фоне"

COLOR 15, TRANSPARENT
LOCATE 5, 5
PRINT "Белый текст поверх графики"
SLEEP

Пример очищает экран, выводит текст с непрозрачным фоном, затем включает прозрачный фон и меняет позицию следующего вывода.

Диагностика

  • MB3010: оператор COLOR вызван без активного графического режима SCREEN 1..10.
  • MB3010: оператор LOCATE вызван без активного графического режима SCREEN 1..10.
