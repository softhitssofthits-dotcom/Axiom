Главная/Графика/Текстовый слой

Операторы

CLS, COLOR и LOCATE

Текстовый слой SCREEN позволяет выводить обычный текст в отдельном окне программы. В SCREEN 0 это консольный текстовый режим без графических команд; в режимах 1..10 тот же текстовый слой рисуется поверх пиксельной поверхности.

Оператор CLS

CLS

В активном экранном выводе оператор CLS очищает текстовый слой, пиксельный слой при наличии графического режима и возвращает текстовый курсор в позицию 1, 1. Без явного SCREEN он очищает обычный вывод пустой строкой.

SCREEN 3
PRINT "old text"
PSET (10, 10), 12
CLS
PRINT "screen cleared"
SCREEN 0

Оператор COLOR

COLOR foreground[, background]

COLOR задаёт текущий цвет текста и, если указан второй аргумент, цвет фона ячейки текста. Команда требует активный графический SCREEN; в текстовом SCREEN 0 этот графический договор цвета пока недоступен.

ПараметрОписание
foregroundЦвет символов.
backgroundНеобязательный цвет фона за символами. Если не указан, текущий фон не меняется.
 
SCREEN 3
COLOR 14, 1
PRINT "yellow text on blue background"
COLOR 15
PRINT "white text, previous background"
COLOR 46
PRINT "Русский текст в графическом режиме"
COLOR 226
PRINT "256-color palette sample"
SCREEN 0

Для текстовых цветовых образцов можно использовать блочные псевдосимволы. Функция CHR() для кодов 0..255 использует таблицу IBM CP866, поэтому CHR(219), CHR(178), CHR(177) и CHR(176) возвращают █, ▓, ▒ и ░. Эти символы работают и в SCREEN, и в обычном выводе.

SCREEN 10
DIM r AS INTEGER
DIM c AS INTEGER
FOR i = 16 TO 255
    r = ((i - 16) \ 16) + 1
    c = (((i - 16) MOD 16) * 2) + 1
    LOCATE r, c
    COLOR i, 0
    PRINT CHR(219)
NEXT
SCREEN 0

Оператор LOCATE

LOCATE row, column

В графическом режиме LOCATE работает не с пикселями, а с текстовой сеткой поверх пиксельного экрана. Одна текстовая ячейка занимает 8 x 12 пикселей: столбец задаёт горизонтальную позицию ячейки, строка задаёт вертикальную позицию ячейки.

LOCATE ставит курсор текстового слоя в указанную строку и столбец. Строки и столбцы считаются с 1. Значения меньше 1 приводятся к 1.

Количество видимых позиций зависит только от логического размера выбранного SCREEN:

columns = SCREENWIDTH() \ 8
rows = SCREENHEIGHT() \ 12

Если ширина или высота режима не делится на размер ячейки без остатка, оставшиеся пиксели справа или снизу не образуют отдельную текстовую позицию. Значения строки или столбца больше видимой сетки сейчас не сообщают ошибку: следующий текст записывается за пределами видимой области и не отображается.

Последующий PRINT перезаписывает символы с этой позиции, а не вставляет их в строку. Если новый текст короче старого, хвост старой строки остаётся на экране.

SCREEN 3
LOCATE 2, 4
PRINT "score=120"
LOCATE 2, 4
PRINT "score=9  "
SCREEN 0

Палитра

Цвета имеют индексы 0..255. Индексы 0..15 сохраняют классическую BASIC-палитру, 16..231 образуют RGB-куб 6x6x6, а 232..255 дают серую шкалу. Значения вне диапазона приводятся к палитре по правилу ABS(color) MOD 256.

Экранные символы

CHR() и ASC() используют общий строковый договор Axiom: коды 0..255 соответствуют ASCII/IBM CP866, а коды выше 255 остаются Unicode-кодами. Поэтому русские буквы, рамки и блочные символы работают одинаково в обычном выводе и в активном SCREEN.

Полная таблица кодов вынесена на отдельную страницу Символы CHR и ASC.
