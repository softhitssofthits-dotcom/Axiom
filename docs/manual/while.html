Оператор цикла WHILE ... END WHILE

Цикл WHILE используют там, где повторение должно продолжаться только пока остаётся истинным некоторое условие. Это предусловная форма: программа сначала проверяет, можно ли входить в очередной проход, и только потом выполняет тело цикла.

Сводка

Цикл WHILE повторяет тело, пока заданное логическое условие остаётся истинным. Поскольку условие проверяется до входа в каждую итерацию, цикл может не выполниться ни разу.

Синтаксис

WHILE condition
    [statements]
END WHILE

Части записи

condition задаёт логическое условие, которое проверяется перед каждой итерацией. Пока результат равен TRUE, цикл продолжается.

statements — одна или несколько инструкций внутри тела цикла.

Замечания

WHILE удобно использовать, когда число повторений заранее неизвестно и зависит от изменяющегося состояния программы, но при этом важно не делать ни одного лишнего прохода после того, как условие стало ложным.

  • Условие WHILE должно иметь тип BOOLEAN.
  • Если условие ложно уже перед первым входом, управление сразу продолжается после END WHILE.
  • Тело WHILE образует собственную блочную область видимости.
  • Отдельного оператора EXIT WHILE не предусмотрено. Обычно завершение достигается изменением условия, а внутри процедуры или функции возможен RETURN.

Пример

DIM i AS INTEGER = 0

WHILE i < 3
    PRINT i
    i = i + 1
END WHILE

Ручная проверка

  • WHILE: базовый цикл с изменением счётчика

Диагностика

Если условие цикла не приводит к логическому значению, выполнение завершается ошибкой, связанной с неверным типом условия.
