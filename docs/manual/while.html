Цикл WHILE

WHILE выполняет тело цикла, пока логическое условие остается истинным. Условие проверяется до входа в каждую итерацию, поэтому цикл может не выполниться ни разу.

Сводка

WHILE используется для повторения по условию, когда число итераций заранее не фиксируется диапазоном. Если выражение условия ложно уже при первой проверке, выполнение сразу продолжается после END WHILE.

Синтаксис

WHILE <условие>
    <инструкции>
END WHILE

Части синтаксиса

  • <условие> — логическое выражение, которое проверяется перед каждой итерацией.
  • <инструкции> — тело цикла между WHILE и END WHILE.

Замечания

  • Условие WHILE должно иметь тип BOOLEAN.
  • Проверка выполняется перед каждой новой итерацией.
  • Тело WHILE образует собственную блочную область видимости.
  • Вложенные циклы разрешены; EXIT FOR внутри вложенного FOR относится именно к ближайшему FOR, а не к окружающему WHILE.
  • Для цикла WHILE не предусмотрен отдельный оператор EXIT WHILE; завершение обычно достигается изменением условия, а внутри процедуры или функции возможен RETURN.

Ручная проверка

Для проверки предусловного поведения используйте краткий готовый пример из тематического каталога.

  • WHILE: базовый цикл с изменением счетчика

Примеры

DIM i AS INTEGER = 0

WHILE i < 3
    PRINT i
    i = i + 1
END WHILE
DIM ready AS BOOLEAN = FALSE

WHILE ready
    PRINT "Этот код не будет выполнен"
END WHILE

Диагностика

  • MB2008 — условие цикла не приводится к BOOLEAN и не может использоваться в WHILE.
