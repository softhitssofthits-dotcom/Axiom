Оператор WHILE

WHILE — оператор языка Axiom, который повторяет блок, пока условие истинно. Условие проверяется перед каждым проходом, включая первый.

Назначение и контекст

Оператор работает на верхнем уровне программы и внутри подпрограмм и блоков, в консольной и графической программе. Специальный графический режим не требуется.

Цикл подходит для работы, продолжительность которой определяется состоянием данных. Если условие изначально ложно, тело полностью пропускается.

Синтаксис

WHILE <условие>
    [<инструкции>]
END WHILE

Условие и тело

Условие после WHILE должно иметь тип BOOLEAN. Инструкции тела расположены до END WHILE. После тела условие проверяется снова; значение FALSE завершает цикл.

CONTINUE WHILE в непосредственном теле WHILE переходит к повторной проверке условия. Особенность переходов внутри разных вложенных видов циклов описана на странице CONTINUE. Изменяйте данные, от которых зависит условие, до такого перехода, если это нужно для завершения. Форма EXIT WHILE не поддержана; для выхода из середины тела используйте DO … LOOP и EXIT DO.

Диагностика

Ошибка возникает, если условие WHILE не имеет тип BOOLEAN, если блок не закрыт END WHILE или если в тексте используется неподдержанная форма выхода вроде EXIT WHILE.

  • MB2008 — условие цикла не имеет тип BOOLEAN.
  • MB1001 — отсутствует требуемое END WHILE.
  • MB2038 — CONTINUE WHILE используется вне цикла WHILE ... END WHILE.

Пример

Условие позволяет выполнить три прохода:

DIM count AS INTEGER = 0
WHILE count < 3
    PRINT count
    count = count + 1
END WHILE

Результат:

0
1
2
