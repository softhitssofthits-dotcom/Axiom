Оператор WHILE

WHILE — оператор языка Axiom, который повторяет блок инструкций до тех пор, пока заданное условие остаётся истинным. Условие проверяется перед каждым проходом, поэтому тело цикла может не выполниться ни одного раза.

Проверка перед входом в цикл

WHILE ... END WHILE подходит для ситуаций, где продолжение работы зависит от состояния программы: пока индекс не дошёл до конца, пока найден следующий элемент, пока пользовательский флаг остаётся истинным. Если состояние уже не подходит перед первым проходом, управление сразу переходит к инструкции после END WHILE.

Синтаксис

WHILE <условие>
    <инструкции>
    [CONTINUE WHILE]
    [<инструкции>]
END WHILE

Части записи

<условие> - логическое выражение типа BOOLEAN. Пока оно равно TRUE, цикл выполняет очередной проход.

<инструкции> - тело цикла. В нём обычно меняют значение, от которого зависит условие, иначе цикл может не завершиться.

CONTINUE WHILE — пропуск оставшейся части текущей итерации с переходом к проверке условия. Подробнее — на странице оператора CONTINUE.

Переход после END WHILE

  • Условие проверяется до входа в тело и затем перед каждым следующим проходом.
  • Когда условие становится FALSE, управление переходит к первой инструкции после END WHILE.
  • Для прямого выхода из середины предусловного цикла используйте DO ... LOOP и EXIT DO: отдельной формы EXIT WHILE в Axiom сейчас нет.
  • CONTINUE WHILE пропускает оставшуюся часть тела и переходит к проверке условия в заголовке цикла.

В QuickBASIC историческая форма записывалась как WHILE ... WEND, и у неё не было EXIT WHILE. В Axiom блок закрывается более явной парой END WHILE; прямой выход из цикла по-прежнему следует выражать через DO ... LOOP и EXIT DO.

Пример предусловного цикла

' Ожидаемый вывод:
' 0
' 1
' 2
DIM i AS INTEGER = 0

WHILE i < 3
    PRINT i
    i = i + 1
END WHILE

Ручная проверка

  • WHILE: базовый предусловный цикл
  • CONTINUE WHILE: пропуск итерации

Диагностика

Ошибка возникает, если условие WHILE не имеет тип BOOLEAN, если блок не закрыт END WHILE или если в тексте используется неподдержанная форма выхода вроде EXIT WHILE.

  • MB2038 — CONTINUE WHILE используется вне цикла WHILE ... END WHILE.
