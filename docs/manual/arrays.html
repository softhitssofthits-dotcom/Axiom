Раздел

Массивы

Раздел массивов описывает, как Axiom объединяет несколько значений одного типа под одним именем: объявление, изменение размеров, индексирование и ARRAY-функции.

Определение массива

Массив — упорядоченный набор элементов одного типа. Положение элемента определяется индексом в каждом измерении. Одномерный массив использует один индекс, двумерный — два, многомерный — число индексов, равное рангу массива.

Границы индексов задаются явно и входят в видимую модель массива. Поэтому массив Axiom не обязан начинаться с единицы: программа может выбрать тот диапазон, который соответствует задаче, а затем использовать LBOUND, UBOUND и другие функции, чтобы читать эти границы без догадок.

Модель массива

  • массив имеет тип элемента, например INTEGER или STRING;
  • каждое измерение имеет собственные включительные границы;
  • поддержаны одномерные, двумерные и многомерные формы;
  • динамические массивы можно перераспределять через REDIM и REDIM PRESERVE;
  • часть ARRAY-функций для ранга 2+ работает по выбранному измерению, а не по скрытому уплощённому списку.

Срезы и частичное индексирование не создают отдельную таблицу автоматически. Там, где страница срезов говорит о представлении, результат смотрит на ту же область хранения, что и исходный массив. Это важно учитывать при изменении элементов через полученный срез.

Формы массивов

Одномерные массивы

Когда нужен обычный список значений и базовые операции по одному индексу.

Двумерные массивы

Когда данные удобнее мыслить как таблицу из строк и столбцов.

Многомерные массивы

Когда важно хранить прямоугольный набор данных ранга выше двух.

Динамические массивы

Когда размер массива известен не сразу или меняется во время работы программы.

Индексирование

Когда нужно точно понять форму доступа к элементам, подмассивам и диапазонным срезам.

Срезы и представления

Когда нужно взять часть массива без ручного копирования и понять, где результат остаётся представлением.

ARRAY-функции

Когда нужна сортировка, фильтрация, объединение, метаданные и другие операции над массивами.

Ошибки массивов

Когда нужно разобраться с неверными границами, невыделенными массивами и конфликтами размерностей.

Обращение к элементу

DIM scores(1 TO 3) AS INTEGER
scores(1) = 10
scores(2) = 20
scores(3) = 30

PRINT scores(2)

Здесь scores — одномерный массив целых чисел, а число в скобках выбирает один элемент. В двумерной форме запись вроде board(row, column) использует уже два индекса. Если индексов указано меньше, чем измерений у многомерного массива, результатом может стать подмассив; если в индексном списке используется диапазон TO, результатом становится срез.

Запускаемые примеры

  • Двумерная сетка и многомерные границы
  • ARRAYPUSH по измерению
  • ARRAYINSERT по измерению
  • ARRAYSLICE для двумерного массива
