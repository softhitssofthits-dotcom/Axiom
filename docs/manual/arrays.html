Массивы

Массив нужен тогда, когда под одним именем требуется хранить сразу несколько значений одного типа. В текущем первом срезе Axiom поддерживает одномерные и многомерные плотные массивы, а большинство функций семейства ARRAY... пока остаются одномерными.

Объявление массива

DIM scores(1 TO 3) AS INTEGER
DIM names() AS STRING
DIM grid(1 TO 2, 10 TO 11) AS INTEGER
DIM matrix(,) AS INTEGER
TYPE Person
    Name AS STRING
END TYPE

DIM people(1 TO 3) AS Person

В первой записи scores это имя массива, а 1 TO 3 задает его нижнюю и верхнюю границу включительно. Тип INTEGER говорит о том, что все элементы массива должны быть целыми числами.

Запись grid(1 TO 2, 10 TO 11) создает двумерный массив: у первого измерения свой диапазон 1 TO 2, у второго свой диапазон 10 TO 11.

Запись names() объявляет динамический одномерный массив без немедленного выделения диапазона элементов, а matrix(,) таким же образом объявляет динамический двумерный массив. Такие массивы уже существуют как значения языка, но ещё не содержат доступного диапазона индексов до следующего REDIM.

Типом элемента может быть встроенный тип или пользовательский тип записи, объявленный через TYPE ... END TYPE. Например, DIM people(1 TO 3) AS Person создаёт массив записей Person.

Поле пользовательской записи тоже может иметь динамический массивный тип, например Scores() AS INTEGER. Для такого поля работают индексирование, REDIM, REDIM PRESERVE и ERASE, но в первом многомерном срезе массивные поля внутри TYPE остаются только одномерными.

Внутри TYPE поддержана и фиксированная массивная форма, например Scores(1 TO 3) AS INTEGER. Такой диапазон создаётся сразу вместе с записью, не требует отдельного REDIM и копируется как часть значения записи.

Для границ фиксированного поля записи можно использовать не только литералы, но и верхнеуровневые CONST, если они сводятся к целочисленному значению. Порядок объявления таких констант относительно TYPE для этой формы не важен.

Если несколько полей записи имеют общий тип, их можно объединить в одну строку. В такой форме скобки указываются у каждого имени отдельно: Scores(), Flags(1 TO 2) AS INTEGER.

REDIM: выделение и смена диапазона

DIM names() AS STRING
REDIM names(1 TO 3)

DIM grid(,) AS INTEGER
REDIM grid(1 TO 2, 10 TO 11)
REDIM PRESERVE grid(2 TO 3, 11 TO 12)

REDIM выделяет диапазон элементов для уже существующего массива и может затем заново задать его границы. На текущем этапе поддерживаются обе формы: обычная и REDIM PRESERVE.

Для массивных полей записей это правило относится только к динамической форме fieldName() AS TYPE. Если поле объявлено внутри TYPE как фиксированный массив с диапазоном, его размеры уже закреплены в объявлении и не меняются через REDIM.

Если массив уже был выделен, обычный REDIM создаёт новый диапазон и заново заполняет все элементы значениями по умолчанию для типа массива. Старое содержимое не сохраняется.

REDIM PRESERVE тоже меняет диапазон, но перед этим сохраняет элементы из пересечения старых и новых границ. Сохраняются именно те индексы, которые существуют в обоих диапазонах. Новые индексы, которых раньше не было, получают значения по умолчанию.

Текущая семантика массивов остаётся ссылочной, поэтому REDIM меняет общее хранилище массива. Если на тот же массив ссылается другая переменная или параметр, она увидит новый диапазон и новые значения по умолчанию.

Форма записи остаётся явной и совпадает с объявлением массива:

Для многомерного массива указываются диапазоны всех измерений в одном списке. Число диапазонов должно совпадать с рангом массива.

REDIM name(<lower> TO <upper>)
REDIM PRESERVE name(<lower> TO <upper>)
REDIM matrix(<rowLower> TO <rowUpper>, <colLower> TO <colUpper>)

Пустой, но уже выделенный массив записывается как 1 TO 0. Такой массив отличается от состояния после DIM name() AS TYPE и ERASE: он считается выделенным, но содержит ноль элементов.

REDIM values(1 TO 0)

Другие диапазоны, где верхняя граница меньше нижней, например 5 TO 3, остаются ошибкой времени выполнения. Пустая форма REDIM name() пока не поддерживается, а для многомерных массивов первый срез пока не вводит отдельную нормальную пустую форму.

ERASE: сброс в невыделенное состояние

DIM values() AS INTEGER
REDIM values(1 TO 3)

ERASE values

ERASE сбрасывает массив обратно в невыделенное состояние. После этого массив остаётся существующим значением языка, но обращаться к его элементам снова нельзя до следующего успешного REDIM или REDIM PRESERVE.

В текущем этапе поддерживается форма ERASE arrayTarget для одного массивного значения. В роли arrayTarget может выступать имя массива, динамическое поле записи массивного типа или такое поле у элемента массива. Список целей через запятую пока не входит в контракт.

Фиксированное массивное поле в TYPE не возвращается в невыделенное состояние: для него ERASE не поддерживается, потому что диапазон такого поля считается частью самой формы записи.

Ссылочная семантика остаётся прежней. Если на тот же массив ссылаются другие переменные или параметры, после ERASE они увидят тот же самый результат: массив станет невыделенным для всех ссылок на это же значение.

Массив как значение

DIM source(1 TO 2) AS INTEGER
DIM alias() AS INTEGER

alias = source

FUNCTION Echo(values AS INTEGER()) AS INTEGER()
    RETURN values
END FUNCTION

На текущем этапе основания массив больше не считается только специальным видом переменной. Его можно присваивать целиком, передавать в параметры и возвращать из FUNCTION для любого поддержанного ранга.

В объявлениях параметров и типа результата массив записывается как тип со скобками нужного ранга: INTEGER(), INTEGER(,), STRING(), FUNCTION(INTEGER) AS INTEGER() и так далее.

Базовая семантика массива остаётся ссылочной: присваивание массива целиком и передача массива в параметр не клонируют весь массив автоматически. Если нужна независимая копия массива, используйте ARRAYCLONE. При этом запись пользовательского типа, которую присваивают отдельному элементу массива, копируется как значение.

Доступ к элементам

scores(1) = 10
scores(2) = 20
scores(3) = 30
PRINT scores(2)

grid(1, 10) = 7
PRINT grid(2, 11)

Элемент массива выбирается через круглые скобки с индексом или списком индексов. Число индексов должно совпадать с числом измерений массива, а каждый индекс должен быть числовым значением, попадающим в диапазон своего измерения.

Если элемент имеет пользовательский тип, после индексирования можно обращаться к его полям:

people(1).Name = "Ada"
PRINT people(1).Name

Частичное индексирование и подмассивы-представления

DIM grid(,) AS INTEGER
DIM row() AS INTEGER

REDIM grid(1 TO 2, 10 TO 11)
grid(2, 10) = 7
grid(2, 11) = 9

row = grid(2)
row(10) = 70

PRINT grid(2, 10)
PRINT row(11)

Если у многомерного массива указать не все индексы, Axiom возвращает не копию, а подмассив-представление по оставшимся измерениям. В примере grid(2) означает всю строку с первым индексом 2.

Границы оставшихся измерений сохраняются как есть. Если второе измерение исходного массива имело диапазон 10 TO 11, то и результат grid(2) имеет те же LBOUND и UBOUND.

Подмассив-представление разделяет то же хранилище элементов. Изменение через представление видно корневому массиву, и наоборот.

DIM block(,) AS INTEGER
DIM row() AS INTEGER

row = grid(2, 10 TO 11)
block = grid(1 TO 2, 10 TO 11)

В списке индексов можно указать включительный диапазон lower TO upper. Одиночный индекс фиксирует измерение и убирает его из результата, а диапазон сохраняет это измерение с указанными границами. Поэтому grid(2, 10 TO 11) возвращает одномерное представление строки, а grid(1 TO 2, 10 TO 11) возвращает двумерное представление прямоугольной области.

Диапазонный срез тоже является представлением без копирования. Изменение элемента через результат видно в исходном массиве. Границы диапазона должны попадать в текущие границы соответствующего измерения. Формы с пропущенной нижней или верхней границей, STEP и перестановка измерений пока не входят в контракт.

Диапазон TO допустим только внутри индексирования массива. Присваивать значение напрямую в диапазонный срез нельзя: сначала сохраните представление в массивную переменную подходящего ранга и затем меняйте отдельные элементы этого представления.

Для одномерного представления можно вызывать существующие одномерные функции ARRAYTAKE, ARRAYSKIP, ARRAYSLICE, ARRAYCLONE и другие. Они принимают представление как обычный одномерный массив, но их собственный результат по-прежнему является новой независимой копией.

REDIM, REDIM PRESERVE и ERASE работают только с самим массивом, а не с подмассивом-представлением.

Информационные встроенные функции

После выделения массива через DIM ... TO ..., REDIM или REDIM PRESERVE программа может узнать его текущее состояние и границы через четыре встроенные функции. Для многомерных массивов LBOUND и UBOUND умеют работать с явным номером измерения.

LBOUND(array[, dimension])

DIM values() AS INTEGER
REDIM values(5 TO 7)

PRINT LBOUND(values)

LBOUND возвращает нижнюю границу выделенного массива. Без второго аргумента используется первое измерение. Если передан dimension, он задаёт номер измерения начиная с 1. Если массив ещё не выделен, во время выполнения возникает та же диагностика состояния массива, что и при попытке индексировать его слишком рано.

UBOUND(array[, dimension])

DIM values() AS INTEGER
REDIM values(5 TO 7)

PRINT UBOUND(values)

UBOUND возвращает верхнюю границу выделенного массива. Без второго аргумента используется первое измерение. Для невыделенного массива эта функция тоже недопустима и завершится диагностикой времени выполнения. Недопустимый номер измерения даёт ошибку аргумента времени выполнения.

ARRAYLENGTH(array)

DIM values() AS INTEGER

PRINT ARRAYLENGTH(values)
REDIM values(5 TO 7)
PRINT ARRAYLENGTH(values)

ARRAYLENGTH возвращает текущее число элементов в массиве. Для многомерного массива это общее число ячеек во всём прямоугольном хранилище. Для невыделенного массива и для пустого выделенного массива 1 TO 0 функция возвращает 0. Различить эти два состояния можно через ARRAYISALLOCATED.

ARRAYISALLOCATED(array)

DIM values() AS INTEGER

PRINT ARRAYISALLOCATED(values)
REDIM values(5 TO 7)
PRINT ARRAYISALLOCATED(values)

ARRAYISALLOCATED возвращает FALSE для невыделенного массива и TRUE после успешного выделения диапазона. Это правило одинаково для одномерных и многомерных массивов. Эту функцию удобно использовать перед вызовом LBOUND и UBOUND, если массив может ещё не иметь доступных индексов.

Чистые функции массива

Ограничение первого многомерного среза

Функции семейства ARRAY... из этого раздела, кроме ARRAYLENGTH и ARRAYISALLOCATED, пока принимают только одномерные массивы. Многомерные формы для них будут проектироваться отдельным следующим этапом.

Первая многомерная группа

ARRAYCLONE, ARRAYFILL, ARRAYCONTAINS и ARRAYCOUNT теперь принимают уже выделенные массивы и представления любого ранга. Они обходят только видимые элементы: для среза меняются или проверяются именно элементы среза, а не весь исходный массив.

ARRAYCLONE(array)

DIM source(5 TO 6) AS INTEGER
DIM copy() AS INTEGER

source(5) = 10
source(6) = 20

copy = ARRAYCLONE(source)
copy(5) = 99

PRINT source(5)
PRINT copy(5)

ARRAYCLONE создаёт новый одномерный массив того же типа, что и исходный аргумент. Исходный массив при этом не изменяется.

Функция сохраняет текущее состояние исходного массива:

  • невыделенный массив клонируется как новый невыделенный массив того же типа;
  • выделенный непустой массив сохраняет те же нижнюю и верхнюю границы;
  • пустой выделенный массив сохраняет форму 1 TO 0.

Результат не разделяет то же хранилище элементов с исходным массивом. Если изменить элементы клона после вызова, исходный массив останется прежним.

Для многомерного массива или представления ARRAYCLONE сохраняет видимый ранг, границы всех видимых измерений и значения, но создаёт независимое хранилище.

ARRAYSLICE(array, start, count)

DIM source(5 TO 7) AS INTEGER
DIM part() AS INTEGER

source(5) = 10
source(6) = 20
source(7) = 30

part = ARRAYSLICE(source, 6, 2)

PRINT LBOUND(part)
PRINT UBOUND(part)
PRINT part(1)
PRINT part(2)

ARRAYSLICE создаёт новый массив из части исходного одномерного массива. Исходный массив при этом не изменяется.

Аргумент start задаёт логический индекс исходного массива, с которого начинается чтение, а count задаёт число элементов результата.

Непустой результат всегда получает компактные границы 1 TO N, даже если исходный массив имел другой нижний индекс. Это позволяет безопасно использовать результат как новый самостоятельный массив.

Если count = 0, функция возвращает пустой выделенный массив 1 TO 0. Если исходный массив ещё не выделен, возникает диагностика состояния массива. Если диапазон от start до start + count - 1 выходит за текущие границы исходного массива, выполнение завершится диагностикой ошибки аргумента.

Как и ARRAYCLONE, результат ARRAYSLICE не разделяет хранилище элементов с исходным массивом.

ARRAYCONCAT(left, right)

DIM left(5 TO 6) AS INTEGER
DIM right(10 TO 11) AS INTEGER
DIM merged() AS INTEGER

left(5) = 10
left(6) = 20
right(10) = 30
right(11) = 40

merged = ARRAYCONCAT(left, right)

PRINT LBOUND(merged)
PRINT UBOUND(merged)
PRINT merged(1)
PRINT merged(4)

ARRAYCONCAT создаёт новый массив из элементов двух исходных одномерных массивов одного и того же типа. Сначала в результат попадают элементы left, затем элементы right.

Результат всегда получает компактные границы 1 TO N. Если оба массива выделены, но суммарно содержат ноль элементов, функция возвращает пустой выделенный массив 1 TO 0.

Оба аргумента должны быть уже выделенными массивами. Невыделенный аргумент даёт диагностику состояния массива во время выполнения.

Как и ARRAYCLONE с ARRAYSLICE, результат ARRAYCONCAT не разделяет хранилище элементов с исходными массивами. Изменение результата после вызова не меняет left и right.

ARRAYTOSORTED(array)

DIM source(5 TO 9) AS INTEGER
DIM sortedValues() AS INTEGER

source(5) = 30
source(6) = 10
source(7) = 20
source(8) = 20
source(9) = 10

sortedValues = ARRAYTOSORTED(source)

PRINT LBOUND(sortedValues)
PRINT UBOUND(sortedValues)
PRINT sortedValues(5)
PRINT sortedValues(9)

ARRAYTOSORTED создаёт новую отсортированную копию уже выделенного одномерного массива и не меняет исходное значение.

В отличие от ARRAYSLICE, ARRAYCONCAT и ARRAYTOREVERSED, функция сохраняет текущие границы исходного массива. Для диапазона 5 TO 9 результат тоже останется в диапазоне 5 TO 9.

Сортировка поддерживается только для числовых и строковых массивов и использует то же упорядоченное сравнение, что уже действует в языке для чисел и строк.

Дубликаты сохраняются. Если исходный массив выделен как пустой 1 TO 0, результатом становится такой же пустой выделенный массив 1 TO 0. Невыделенный аргумент даёт MB3005.

Как и другие чистые операции над массивами, ARRAYTOSORTED не разделяет хранилище элементов с исходным массивом. Изменение результата после вызова не меняет исходные значения.

ARRAYTOREVERSED(array)

DIM source(5 TO 7) AS INTEGER
DIM reversed() AS INTEGER

source(5) = 10
source(6) = 20
source(7) = 30

reversed = ARRAYTOREVERSED(source)

PRINT LBOUND(reversed)
PRINT UBOUND(reversed)
PRINT reversed(1)
PRINT reversed(3)

ARRAYTOREVERSED создаёт новый массив из элементов исходного одномерного массива, но в обратном логическом порядке.

Результат всегда получает компактные границы 1 TO N. Если исходный массив выделен, но пуст, функция возвращает пустой выделенный массив 1 TO 0.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт диагностику состояния массива во время выполнения.

Как и другие чистые операции над массивами, ARRAYTOREVERSED не разделяет хранилище элементов с исходным массивом. Изменение результата после вызова не меняет исходные значения.

ARRAYTAKE(array, count)

DIM source(5 TO 7) AS INTEGER
DIM part() AS INTEGER

source(5) = 10
source(6) = 20
source(7) = 30

part = ARRAYTAKE(source, 2)

PRINT LBOUND(part)
PRINT UBOUND(part)
PRINT part(1)
PRINT part(2)

ARRAYTAKE создаёт новый массив из первых count элементов исходного одномерного массива, считая от его текущей нижней границы.

Результат всегда получает компактные границы 1 TO N. Если count = 0 или исходный массив выделен, но пуст, функция возвращает пустой выделенный массив 1 TO 0.

Если count больше текущей длины массива, функция мягко возвращает весь массив в компактной форме без ошибки.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005, а отрицательный count даёт MB3007.

Как и другие чистые операции над массивами, ARRAYTAKE не разделяет хранилище элементов с исходным массивом. Изменение результата после вызова не меняет исходные значения.

ARRAYSKIP(array, count)

DIM source(5 TO 7) AS INTEGER
DIM part() AS INTEGER

source(5) = 10
source(6) = 20
source(7) = 30

part = ARRAYSKIP(source, 1)

PRINT LBOUND(part)
PRINT UBOUND(part)
PRINT part(1)
PRINT part(2)

ARRAYSKIP создаёт новый массив из элементов исходного одномерного массива после пропуска первых count логических элементов, считая от текущей нижней границы.

Результат всегда получает компактные границы 1 TO N. Если count = 0, функция возвращает весь исходный массив в компактной форме. Если count не меньше текущей длины массива или исходный массив выделен, но пуст, результатом становится пустой выделенный массив 1 TO 0.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005, а отрицательный count даёт MB3007.

Как и другие чистые операции над массивами, ARRAYSKIP не разделяет хранилище элементов с исходным массивом. Изменение результата после вызова не меняет исходные значения.

ARRAYDISTINCT(array)

DIM source(5 TO 9) AS INTEGER
DIM uniqueValues() AS INTEGER

source(5) = 10
source(6) = 20
source(7) = 10
source(8) = 30
source(9) = 20

uniqueValues = ARRAYDISTINCT(source)

PRINT LBOUND(uniqueValues)
PRINT UBOUND(uniqueValues)
PRINT uniqueValues(1)
PRINT uniqueValues(3)

ARRAYDISTINCT создаёт новый массив, в который входят только уникальные элементы исходного одномерного массива.

Порядок результата определяется первым появлением значений в исходном массиве. Если значение встретилось несколько раз, в результат попадает только его первое вхождение.

Результат всегда получает компактные границы 1 TO N. Если исходный массив выделен, но пуст, функция возвращает пустой выделенный массив 1 TO 0.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005.

Как и другие чистые операции над массивами, ARRAYDISTINCT не разделяет хранилище элементов с исходным массивом. Изменение результата после вызова не меняет исходные значения.

Поисковые и счётные функции массива

ARRAYCONTAINS(array, value)

DIM values(0 TO 2) AS INTEGER

values(0) = 10
values(1) = 20
values(2) = 30

PRINT ARRAYCONTAINS(values, 20)
PRINT ARRAYCONTAINS(values, 99)

ARRAYCONTAINS проверяет, содержит ли уже выделенный одномерный массив хотя бы одно значение, равное аргументу value.

Если совпадение найдено, функция возвращает TRUE. Если совпадения нет или массив выделен как пустой 1 TO 0, функция возвращает FALSE.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005.

Для многомерного массива или представления ARRAYCONTAINS проверяет все видимые элементы в стабильном порядке обхода по измерениям.

ARRAYCOUNT(array, value)

DIM values(5 TO 8) AS INTEGER

values(5) = 20
values(6) = 10
values(7) = 20
values(8) = 20

PRINT ARRAYCOUNT(values, 20)
PRINT ARRAYCOUNT(values, 99)

ARRAYCOUNT возвращает число элементов массива, равных аргументу value.

Если совпадений нет, результатом становится 0. Для пустого выделенного массива результат тоже равен 0.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005.

Для многомерного массива или представления ARRAYCOUNT учитывает все видимые элементы, включая элементы диапазонного среза.

ARRAYINDEXOF(array, value)

DIM values(0 TO 3) AS INTEGER

values(0) = 10
values(1) = 20
values(2) = 30
values(3) = 20

PRINT ARRAYINDEXOF(values, 20)
PRINT ARRAYINDEXOF(values, 99)

ARRAYINDEXOF возвращает логический индекс первого совпадения с value в текущем диапазоне массива.

Если совпадения нет, функция возвращает значение строго левее диапазона массива, то есть LBOUND(array) - 1. Для массива 0 TO 3 это будет -1, а для массива 5 TO 7 — 4.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005.

ARRAYLASTINDEXOF(array, value)

DIM values(-3 TO -1) AS INTEGER

values(-3) = 10
values(-2) = 20
values(-1) = 20

PRINT ARRAYLASTINDEXOF(values, 20)
PRINT ARRAYLASTINDEXOF(values, 99)

ARRAYLASTINDEXOF возвращает логический индекс последнего совпадения с value в текущем диапазоне массива.

Если совпадения нет, функция тоже возвращает значение LBOUND(array) - 1, то есть индекс строго левее диапазона текущего массива.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005.

ARRAYFINDALL(array, value)

DIM values(-3 TO 1) AS INTEGER
DIM matches() AS INTEGER

values(-3) = 20
values(-2) = 10
values(-1) = 20
values(0) = 30
values(1) = 20

matches = ARRAYFINDALL(values, 20)

PRINT LBOUND(matches)
PRINT UBOUND(matches)
PRINT matches(1)
PRINT matches(3)

ARRAYFINDALL возвращает новый массив логических индексов всех совпадений с value в текущем диапазоне исходного массива.

Результат всегда имеет тип INTEGER() и компактные границы 1 TO N. Если совпадений нет или исходный массив выделен как пустой 1 TO 0, функция возвращает пустой выделенный массив 1 TO 0.

Внутри результата сохраняются именно логические индексы исходного массива. Для примера выше это будут индексы -3, -1 и 1, а не позиции 1, 2 и 3.

Исходный массив должен быть уже выделен. Невыделенный аргумент даёт MB3005.

ARRAYBINARYSEARCH(array, value)

DIM values(5 TO 9) AS INTEGER

values(5) = 10
values(6) = 20
values(7) = 20
values(8) = 20
values(9) = 30

PRINT ARRAYBINARYSEARCH(values, 20)
PRINT ARRAYBINARYSEARCH(values, 15)

ARRAYBINARYSEARCH выполняет бинарный поиск по уже выделенному и заранее отсортированному одномерному массиву.

Массив должен быть отсортирован по неубыванию в тех же правилах упорядоченного сравнения, которые Axiom использует для чисел и строк. В текущей реализации функция поддерживает только числовые и строковые массивы.

Если совпадение найдено, функция возвращает логический индекс первого равного элемента. Если совпадения нет, результатом становится значение строго левее диапазона массива, то есть LBOUND(array) - 1.

Для пустого выделенного массива 1 TO 0 отсутствие совпадения считается нормальным результатом и тоже даёт 0. Невыделенный массив сообщает MB3005.

Порядок исходного массива функция не проверяет и не изменяет. Если передать неотсортированный массив, результат не определён договором этой функции.

Изменяющие операции массива

ARRAYFILL(array, value)

DIM values(5 TO 7) AS INTEGER

values(5) = 1
values(6) = 2
values(7) = 3

ARRAYFILL(values, 42)

PRINT values(5)
PRINT values(7)

ARRAYFILL заполняет уже выделенный одномерный массив одним значением и меняет его на месте.

Аргумент value должен иметь тот же тип, что и элементы массива. После вызова все логические индексы текущего диапазона будут содержать именно это значение.

Границы массива не меняются. Для пустого выделенного массива 1 TO 0 процедура допустима и ничего не делает. Невыделенный массив сообщает MB3005.

Для многомерного массива или представления ARRAYFILL меняет все видимые элементы на месте. Если аргументом передан срез, изменения видны в исходном массиве.

ARRAYREVERSE(array)

DIM values(5 TO 8) AS INTEGER

values(5) = 10
values(6) = 20
values(7) = 30
values(8) = 40

ARRAYREVERSE(values)

PRINT values(5)
PRINT values(8)

ARRAYREVERSE меняет порядок элементов уже выделенного одномерного массива на обратный.

Операция выполняется на месте и сохраняет текущие логические границы массива. Для диапазона 5 TO 8 результат останется в диапазоне 5 TO 8, но элементы будут переставлены в обратном порядке.

Пустой выделенный массив допустим и остаётся пустым. Невыделенный массив сообщает MB3005.

ARRAYSORT(array)

DIM values(5 TO 9) AS INTEGER

values(5) = 30
values(6) = 10
values(7) = 20
values(8) = 20
values(9) = 10

ARRAYSORT(values)

PRINT values(5)
PRINT values(9)

ARRAYSORT сортирует уже выделенный одномерный массив по неубыванию и меняет его на месте.

Процедура поддерживает только числовые и строковые массивы. Она использует то же упорядоченное сравнение, что язык уже применяет для чисел и строк.

Границы массива не меняются, дубликаты сохраняются. Пустой выделенный массив допустим и остаётся пустым. Невыделенный массив сообщает MB3005.

ARRAYPUSH(array, value)

DIM values(5 TO 6) AS INTEGER

values(5) = 10
values(6) = 20

ARRAYPUSH(values, 30)

PRINT values(5)
PRINT values(6)
PRINT values(7)

ARRAYPUSH расширяет уже выделенный одномерный массив вправо на один логический индекс и записывает туда переданное значение.

Аргумент value должен иметь тот же тип, что и элементы массива. Для непустого массива нижняя граница сохраняется, а верхняя увеличивается на 1.

Для пустого выделенного массива 1 TO 0 процедура создаёт первый элемент и переводит массив в форму 1 TO 1. Невыделенный массив сообщает MB3005.

ARRAYPOP(array)

DIM values(5 TO 7) AS INTEGER

values(5) = 10
values(6) = 20
values(7) = 30

PRINT ARRAYPOP(values)
PRINT LBOUND(values)
PRINT UBOUND(values)

ARRAYPOP снимает последний элемент уже выделенного массива, возвращает его как обычное значение языка и укорачивает сам массив на месте.

Если после снятия элементов массив остаётся непустым, его нижняя граница сохраняется, а верхняя уменьшается на 1. Если массив состоял ровно из одного элемента, результатом мутации становится канонический пустой выделенный массив 1 TO 0.

Пустой выделенный массив не поддерживается: попытка вызвать ARRAYPOP для 1 TO 0 сообщает MB3007. Невыделенный массив сообщает MB3005.

ARRAYINSERT(array, index, value)

DIM values(5 TO 7) AS INTEGER

values(5) = 10
values(6) = 30
values(7) = 40

ARRAYINSERT(values, 6, 20)

PRINT values(5)
PRINT values(6)
PRINT values(7)
PRINT values(8)

ARRAYINSERT вставляет новое значение в уже выделенный одномерный массив по логическому индексу и расширяет массив на месте.

Аргумент index задаётся в логических индексах текущего массива. Для непустого массива допустим диапазон от LBOUND(array) до UBOUND(array) + 1: вставка внутрь диапазона сдвигает хвост вправо, а вставка по UBOUND(array) + 1 работает как добавление в конец.

Нижняя граница непустого массива сохраняется, а верхняя увеличивается на 1. Для пустого выделенного массива 1 TO 0 допустим только индекс 1, после чего массив переходит в форму 1 TO 1. Невыделенный массив сообщает MB3005, а недопустимый индекс или переполнение правой границы сообщает MB3007.

ARRAYREMOVE(array, index)

DIM values(5 TO 8) AS INTEGER

values(5) = 10
values(6) = 20
values(7) = 30
values(8) = 40

PRINT ARRAYREMOVE(values, 6)
PRINT values(5)
PRINT values(6)
PRINT values(7)

ARRAYREMOVE удаляет элемент уже выделенного массива по логическому индексу, возвращает удалённое значение как обычное значение языка и сужает массив на месте.

Аргумент index должен указывать на существующий логический индекс в текущем диапазоне массива. Все элементы правее удаляемого сдвигаются влево на одну позицию.

Если после удаления массив остаётся непустым, его нижняя граница сохраняется, а верхняя уменьшается на 1. Если удалён единственный элемент массива, результат мутации нормализуется к каноническому пустому диапазону 1 TO 0. Невыделенный массив сообщает MB3005, а пустой выделенный массив или индекс вне текущего диапазона сообщает MB3007.

ARRAYEVERY(array, predicate)

DIM values(5 TO 7) AS INTEGER

values(5) = 10
values(6) = 20
values(7) = 30

PRINT ARRAYEVERY(values, IsPositive)

FUNCTION IsPositive(value AS INTEGER) AS BOOLEAN
    RETURN value > 0
END FUNCTION

ARRAYEVERY проверяет, что predicate возвращает TRUE для каждого элемента уже выделенного массива.

Функция принимает не только обычный одномерный массив, но и массив или представление любого ранга. Для многомерного массива или среза проверяются все видимые элементы в стабильном порядке по измерениям.

Аргумент predicate должен быть значением функции или замыкания типа FUNCTION(T) AS BOOLEAN, где T — тип элемента массива. Callback получает только текущее значение элемента и может использовать захваченные внешние данные через обычные замыкания Axiom.

Для пустого выделенного массива 1 TO 0 результатом считается TRUE. Невыделенный массив сообщает MB3005, а пустое значение функционального типа в predicate сообщает MB3009.

ARRAYSOME(array, predicate)

DIM values(5 TO 7) AS INTEGER
DIM limit AS INTEGER = 15

values(5) = 10
values(6) = 20
values(7) = 30

PRINT ARRAYSOME(values, IsAboveLimit)

FUNCTION IsAboveLimit(value AS INTEGER) AS BOOLEAN
    RETURN value > limit
END FUNCTION

ARRAYSOME проверяет, что predicate возвращает TRUE хотя бы для одного элемента уже выделенного массива.

Как и ARRAYEVERY, эта функция работает с массивами и представлениями любого ранга и обходит все их видимые элементы.

Аргумент predicate подчиняется тому же контракту, что и у ARRAYEVERY: это значение функции или замыкания типа FUNCTION(T) AS BOOLEAN, согласованного с типом элемента массива.

Для пустого выделенного массива 1 TO 0 результатом считается FALSE. Невыделенный массив сообщает MB3005, а пустое значение функционального типа в predicate сообщает MB3009.

ARRAYFILTER(array, predicate)

DIM values(5 TO 8) AS INTEGER
DIM filtered() AS INTEGER
DIM threshold AS INTEGER = 25

values(5) = 10
values(6) = 20
values(7) = 30
values(8) = 40

filtered = ARRAYFILTER(values, GreaterThanThreshold)
PRINT LBOUND(filtered)
PRINT UBOUND(filtered)
PRINT ARRAYLENGTH(filtered)

FUNCTION GreaterThanThreshold(value AS INTEGER) AS BOOLEAN
    RETURN value > threshold
END FUNCTION

ARRAYFILTER строит новый массив из элементов, для которых predicate возвращает TRUE.

Аргумент predicate подчиняется тому же контракту, что и у ARRAYEVERY и ARRAYSOME: это значение функции или замыкания типа FUNCTION(T) AS BOOLEAN, согласованного с типом элемента массива.

Исходный массив не меняется. Результат всегда нормализуется к компактным границам 1 TO N, а если совпадений нет, возвращается канонический выделенный пустой массив 1 TO 0. Невыделенный массив сообщает MB3005, а пустое значение функционального типа в predicate сообщает MB3009.

ARRAYMAP(array, selector)

DIM values(5 TO 7) AS INTEGER
DIM prefix AS STRING = "item:"
DIM mapped() AS STRING

values(5) = 10
values(6) = 20
values(7) = 30

mapped = ARRAYMAP(values, FormatValue)
PRINT mapped(1)
PRINT mapped(2)

FUNCTION FormatValue(value AS INTEGER) AS STRING
    RETURN prefix + STR(value)
END FUNCTION

ARRAYMAP строит новый массив, применяя selector к каждому элементу исходного массива.

selector должен быть значением функции или замыкания типа FUNCTION(T) AS U, где T совпадает с типом элемента исходного массива, а U задаёт тип элемента результирующего массива.

Это означает, что ARRAYMAP может не только менять значения, но и переводить массив в другой тип элементов, например из INTEGER() в STRING(). Вложенные массивы по-прежнему не поддерживаются, поэтому U не может быть типом массива.

Исходный массив не меняется. Для массива или представления любого ранга результат сохраняет тот же ранг и те же видимые границы, а меняются только значения и, при необходимости, тип элементов результата. Даже пустое многомерное представление сохраняет свою видимую пустую форму. Невыделенный массив сообщает MB3005, а пустое значение функционального типа в selector сообщает MB3009.

ARRAYREDUCE(array, seed, reducer)

DIM words(3 TO 5) AS STRING

words(3) = "alpha"
words(4) = "bb"
words(5) = "ccc"

PRINT ARRAYREDUCE(words, 0, AddLength)

FUNCTION AddLength(acc AS INTEGER, value AS STRING) AS INTEGER
    RETURN acc + LEN(value)
END FUNCTION

ARRAYREDUCE сворачивает массив в одно итоговое значение, начиная с seed и применяя reducer слева направо.

seed и результат имеют тип аккумулятора A, а reducer должен быть значением функции или замыкания типа FUNCTION(A, T) AS A, где T — тип элемента массива.

Тип аккумулятора может отличаться от типа элемента массива. Например, можно сворачивать STRING() в итоговое INTEGER, суммируя длины строк, или собирать INTEGER() в итоговую строку.

Исходный массив не меняется. Функция работает и с массивами или представлениями любого ранга, обходя все видимые элементы в стабильном порядке по измерениям. Для пустого выделенного массива или пустого представления результатом становится исходный seed. Невыделенный массив сообщает MB3005, а пустое значение функционального типа в reducer сообщает MB3009.

Границы и ошибки

  • индекс вне границ массива приводит к ошибке времени выполнения;
  • массив, объявленный через DIM name() AS TYPE, нельзя индексировать до первого успешного REDIM;
  • диапазон 1 TO 0 задаёт пустой выделенный массив, а не невыделенное состояние;
  • любой другой диапазон, где верхняя граница меньше нижней, недопустим;
  • нижняя граница массива не может быть равна минимальному значению INTEGER;
  • нечисловой индекс недопустим;
  • многомерные массивы первого среза уже поддержаны, но большинство функций семейства ARRAY... пока остаются одномерными.

Иными словами, массивы в Axiom уже полезны для учебных и прикладных задач и теперь охватывают не только одномерный случай, но и первый исполняемый срез многомерных массивов: многомерное DIM, REDIM, REDIM PRESERVE, индексирование array(i, j, ...), а также формы LBOUND и UBOUND с номером измерения. При этом большая часть функций семейства ARRAY... пока сознательно остаётся одномерной, чтобы следующий этап можно было спроектировать отдельно и без скрытых компромиссов.

  • ARRAYSLICE: пустой результат при нулевом количестве
  • ARRAYCONCAT: объединение в новый компактный массив

Краткий итог

Что стоит запомнить про массивы

  • массив хранит несколько однотипных значений;
  • элементом массива может быть пользовательская запись, объявленная через TYPE ... END TYPE;
  • массив можно объявить сразу с диапазоном или в динамической форме name();
  • REDIM выделяет или заново задаёт диапазон уже существующего массива, в том числе динамического массивного поля записи;
  • REDIM PRESERVE сохраняет элементы из пересечения старого и нового диапазона;
  • 1 TO 0 означает пустой выделенный массив с длиной 0;
  • ERASE возвращает массив в невыделенное состояние, в том числе когда массив хранится в динамическом поле записи;
  • фиксированное массивное поле внутри TYPE получает диапазон сразу, копируется вместе с записью и не принимает REDIM или ERASE;
  • LBOUND и UBOUND возвращают текущие границы выделенного массива;
  • ARRAYLENGTH возвращает число элементов, а ARRAYISALLOCATED показывает, выделен ли массив;
  • ARRAYCLONE создаёт независимую копию массива и сохраняет его текущее состояние;
  • ARRAYSLICE создаёт независимый срез и возвращает компактный результат 1 TO N или 1 TO 0;
  • ARRAYCONCAT объединяет два массива одного типа и возвращает новый компактный результат 1 TO N или 1 TO 0;
  • ARRAYFILL меняет уже выделенный массив на месте и записывает одно значение во все его элементы;
  • ARRAYPUSH расширяет уже выделенный массив вправо на один элемент и записывает туда переданное значение;
  • ARRAYPOP возвращает последний элемент уже выделенного массива и укорачивает сам массив на месте;
  • ARRAYINSERT вставляет значение по логическому индексу, сдвигает хвост вправо и расширяет массив на месте;
  • ARRAYREMOVE удаляет элемент по логическому индексу, возвращает его и сдвигает хвост массива влево;
  • ARRAYEVERY возвращает TRUE, если predicate типа FUNCTION(T) AS BOOLEAN истинен для каждого элемента массива;
  • ARRAYSOME возвращает TRUE, если predicate типа FUNCTION(T) AS BOOLEAN истинен хотя бы для одного элемента массива;
  • ARRAYFILTER возвращает новый компактный массив из элементов, для которых predicate типа FUNCTION(T) AS BOOLEAN истинен;
  • ARRAYMAP возвращает новый компактный массив, применяя selector типа FUNCTION(T) AS U к каждому элементу исходного массива;
  • ARRAYREDUCE возвращает итоговое значение типа A, последовательно применяя reducer типа FUNCTION(A, T) AS A к seed и элементам массива;
  • ARRAYREVERSE разворачивает уже выделенный массив на месте и сохраняет его текущие границы;
  • ARRAYSORT сортирует уже выделенный числовой или строковый массив на месте и сохраняет его текущие границы;
  • ARRAYTOSORTED создаёт новую отсортированную копию числового или строкового массива и сохраняет его текущие границы;
  • ARRAYTOREVERSED создаёт новый массив с обратным порядком элементов и возвращает компактный результат 1 TO N или 1 TO 0;
  • ARRAYTAKE возвращает первые элементы массива как новый компактный результат 1 TO N или 1 TO 0;
  • ARRAYSKIP возвращает хвост массива после пропуска первых элементов как новый компактный результат 1 TO N или 1 TO 0;
  • ARRAYDISTINCT возвращает только первые вхождения уникальных значений и создаёт новый компактный результат 1 TO N или 1 TO 0;
  • ARRAYBINARYSEARCH ищет первое совпадение в отсортированном числовом или строковом массиве и при отсутствии совпадения возвращает LBOUND(array) - 1;
  • ARRAYCONTAINS возвращает TRUE или FALSE в зависимости от наличия совпадения;
  • ARRAYCOUNT возвращает число совпадений, а при отсутствии совпадений — 0;
  • ARRAYFINDALL возвращает новый компактный массив индексов типа INTEGER(), а при отсутствии совпадений — пустой выделенный массив 1 TO 0;
  • ARRAYINDEXOF и ARRAYLASTINDEXOF возвращают логические индексы совпадений, а при отсутствии совпадения — значение LBOUND(array) - 1;
  • массив можно присваивать целиком, передавать в параметр и возвращать из функции;
  • обычный REDIM не сохраняет старые элементы и заполняет новый диапазон значениями по умолчанию;
  • границы выделенного массива задаются при объявлении или через REDIM и включаются в диапазон;
  • доступ к элементу записывается как <имя массива>(<индекс>), а доступ к полю записи в элементе — как <имя массива>(<индекс>).<поле>.
