Массивы

Массивы

Массив позволяет хранить под одним именем несколько связанных значений одного типа и обращаться к каждому из них по индексу. В Axiom массивы нужны не только для простых списков, но и для таблиц, многомерных наборов данных, динамических коллекций фиксированного типа и результатов многих встроенных функций.

Что такое массив

Если в программе есть не одно значение, а целый набор однотипных значений, отдельная переменная для каждого элемента быстро делает код громоздким. Массив решает эту задачу: он объединяет такие значения в одну структуру, а отдельный элемент определяется индексом. Поэтому массив удобно использовать там, где данные естественно образуют список, строку таблицы, столбец, прямоугольную сетку или более общий многомерный блок.

Что важно в модели Axiom

  • массив имеет тип элемента, например INTEGER или STRING;
  • каждое измерение имеет собственные включительные границы;
  • поддержаны одномерные, двумерные и многомерные формы;
  • динамические массивы можно перераспределять через REDIM и REDIM PRESERVE;
  • часть ARRAY-функций для ранга 2+ работает по выбранному измерению, а не по скрытому уплощённому списку.

Когда переходить на соседние страницы

Одномерные массивы

Когда нужен обычный список значений и базовые операции по одному индексу.

Двумерные массивы

Когда данные удобнее мыслить как таблицу из строк и столбцов.

Многомерные массивы

Когда важно хранить прямоугольный набор данных ранга выше двух.

Динамические массивы

Когда размер массива известен не сразу или меняется во время работы программы.

Индексирование

Когда нужно точно понять форму доступа к элементам, подмассивам и диапазонным срезам.

Срезы и представления

ARRAY-функции

Когда нужна сортировка, фильтрация, объединение, метаданные и другие операции над массивами.

Когда нужно разобраться с неверными границами, невыделенными массивами и конфликтами размерностей.

Короткий ориентир

DIM scores(1 TO 3) AS INTEGER
scores(1) = 10
scores(2) = 20
scores(3) = 30

PRINT scores(2)

В этом примере scores — это одномерный массив целых чисел, а число в скобках определяет, к какому именно элементу обращается программа. На соседних страницах этот же принцип расширяется до таблиц, многомерных форм, срезов и ARRAY-функций.

Ручная проверка

  • Двумерная сетка и многомерные границы
  • ARRAYPUSH по измерению
  • ARRAYINSERT по измерению
  • ARRAYSLICE для двумерного массива
