Встроенная функция

ISNUMERIC

ISNUMERIC — встроенная функция языка Axiom, которая проверяет, представляет ли вся строка конечное десятичное число типа DOUBLE.

Назначение

Функция ISNUMERIC помогает проверить введённый текст до вызова VAL. Например, строка «12abc» содержит числовой префикс, но не является числом целиком. Проверка возвращает FALSE, тогда как VAL возвращает 12.

Где работает

Функция работает в BytecodeVm после компиляции, в консольных и графических программах. Функция не зависит от языка интерфейса и региональных настроек Windows.

Синтаксис

result = ISNUMERIC(text)

Аргумент

Аргумент text должен быть строкой. Числовой аргумент и BOOLEAN автоматически в строку не преобразуются.

Результат

Функция возвращает BOOLEAN: TRUE, если строка целиком разбирается в конечный DOUBLE, иначе FALSE. Строка не меняется; функция не возвращает само число.

Правила и ограничения

Допускаются цифры 0–9, знак + или -, десятичная точка и экспонента e или E со знаком. Например, «12», «.5», «1.» и «-12.5e2» дают TRUE. По краям допускаются обычный пробел и управляющие пробельные символы U+0009–U+000D; внутри числа пробел недопустим. Пустая строка и строка только из пробелов дают FALSE. Нулевой символ U+0000 в любой позиции даёт FALSE; неразрывный пробел и другие Unicode-пробелы также не считаются допустимыми краевыми пробелами.

Запятая, разделители групп разрядов, валютные знаки, шестнадцатеричные и восьмеричные формы не принимаются. Строки «1,234», «12,5», «&HFF», «NaN», «Infinity», «12abc» дают FALSE. Переполнение «1e999» также даёт FALSE.

Проверка не гарантирует точного сохранения всех цифр или пригодности для INTEGER, LONG либо DECIMAL. Очень малое число, например «1e-999», округляется к конечному нулю и даёт TRUE. Для проверки конкретного числового диапазона нужны дополнительные условия.

Имя унаследовано от Visual Basic, но договор Axiom уже: допускается только STRING и описанный инвариантный десятичный формат. Функция не воспроизводит все преобразования Visual Basic.

Диагностика

При отсутствии аргумента или передаче нескольких аргументов компилятор сообщает неверное число аргументов. При передаче числа, BOOLEAN или массива компилятор сообщает несовместимый тип аргумента. Некорректное содержимое строкового аргумента не вызывает ошибку: результат равен FALSE.

Пример

DIM text AS STRING = "12abc"
' Сначала проверяем строку целиком.
PRINT ISNUMERIC(text)  ' FALSE
' VAL по-прежнему читает числовой префикс.
PRINT VAL(text)        ' 12
PRINT ISNUMERIC("0")   ' TRUE
PRINT ISNUMERIC("1e999") ' FALSE
