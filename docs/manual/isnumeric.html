ISNUMERIC

ISNUMERIC — встроенная функция языка Axiom, которая возвращает признак полной записи конечного числа DOUBLE в строке.

ISNUMERIC

ISNUMERIC — встроенная функция языка Axiom, которая возвращает признак полной записи конечного числа DOUBLE в строке.

Назначение

Функция позволяет проверить пользовательский текст до преобразования в число.

Где работает

Функция вызывается в выражениях консольных и графических программ; оператор SCREEN или CANVAS не требуется.

Синтаксис

ISNUMERIC(<текст>)

Аргументы

Передайте STRING с проверяемой записью; числовой аргумент автоматически строкой не становится.

Результат

Результат BOOLEAN: TRUE для полной конечной записи DOUBLE, FALSE в остальных случаях.

Правила и ограничения

Допустимы знак, десятичная точка, показатель e/E; на краях — обычный пробел и символы U+0009–U+000D. Пустая строка, U+0000, запятые, Unicode-пробелы, постороннее окончание, NaN, Infinity и переполнение дают FALSE. Очень малое число может округлиться к нулю и дать TRUE. TRUE не проверяет диапазон INTEGER, LONG или DECIMAL.

Диагностика

Компилятор отклоняет неверное количество аргументов и несовместимый тип аргумента. Некорректное содержимое строки возвращает FALSE без ошибки выполнения.

Пример

PRINT ISNUMERIC("12abc")
PRINT ISNUMERIC(".5")
PRINT ISNUMERIC("")
PRINT ISNUMERIC("1e999")
PRINT ISNUMERIC("1e-999")

Ожидаемый вывод:

FALSE
TRUE
FALSE
FALSE
TRUE
