Функция ISNUMERIC

ISNUMERIC — встроенная функция языка Axiom, которая проверяет, можно ли преобразовать строку целиком в число типа DOUBLE.

Функция используется для проверки числового текста перед вызовом VAL или другим действием. Результат имеет тип BOOLEAN; исходная строка не изменяется.

Синтаксис

ISNUMERIC(<текст>)

Аргумент

<текст> — строковое выражение типа STRING, которое нужно проверить. Например, это может быть строка "12.5" или строковая переменная. Вызов ISNUMERIC(12.5) недопустим: аргументом должна быть строка.

Возвращаемое значение

Функция возвращает значение типа BOOLEAN:

  • TRUE — если строку целиком можно прочитать как число типа DOUBLE. Допустимые пробельные символы в начале и конце строки не учитываются.
  • FALSE — если строка пуста, содержит недопустимые символы или число слишком велико для типа DOUBLE.

Проверяется вся строка. Поэтому ISNUMERIC("12abc") возвращает FALSE, хотя функция VAL("12abc") возвращает 12: VAL умеет читать число в начале строки.

Правила записи числа

В строке можно использовать цифры от 0 до 9, знак + или - перед числом и точку для дробной части. Экспоненциальная запись тоже допустима: например, "1e3" обозначает 1000. Вместо e можно написать E.

Десятичный разделитель всегда точка, независимо от языка интерфейса и настроек системы. Запятая и разделители групп разрядов не допускаются. Строки с префиксами &H и &B функция не распознаёт.

ВызовРезультатПричина
ISNUMERIC("12")TRUEЦелое число.
ISNUMERIC("12.5")TRUEДробное число с десятичной точкой.
ISNUMERIC("-.5")TRUEОтрицательное число −0,5; ноль перед точкой можно опустить.
ISNUMERIC("1e3")TRUEЧисло в экспоненциальной записи.
ISNUMERIC(" 12 ")TRUEОбычные пробелы по краям допустимы.
ISNUMERIC("")FALSEВ строке нет числа.
ISNUMERIC("12abc")FALSEПосле числа находятся посторонние символы.
ISNUMERIC("12,5")FALSEЗапятая не допускается.

Диапазон и округление

Проверка использует тип DOUBLE. Строка "1e999" содержит слишком большое число и даёт FALSE. Строка "1e-999" даёт TRUE: при чтении такого малого числа в DOUBLE получается ноль. Таким образом, TRUE не гарантирует сохранение исходной точности.

Значения "NaN", "Infinity" и "-Infinity" не считаются допустимыми числами. Результат TRUE также не гарантирует, что число поместится в INTEGER, LONG или DECIMAL. Например, ISNUMERIC("2147483648") возвращает TRUE, хотя это число превышает верхнюю границу INTEGER.

Пробельные и скрытые символы

В начале и конце строки допустимы обычный пробел U+0020 и символы U+0009–U+000D, в том числе табуляция и перевод строки. Пробел внутри числа недопустим. Другие пробельные символы, например неразрывный пробел U+00A0, дают FALSE. Нулевой символ U+0000 недопустим в любой части строки.

Диагностика

Недопустимое содержимое строки возвращает FALSE без ошибки выполнения. Компилятор сообщает об ошибке в следующих случаях:

  • MB2003 — аргумент имеет тип, отличный от STRING. Например, вызов ISNUMERIC(12) передаёт число вместо строки.
  • MB2004 — передано неверное количество аргументов. Функция принимает ровно один аргумент.

Пример

Программа проверяет строку и, если в ней записано число, преобразует её функцией VAL и удваивает полученное значение.

DIM text AS STRING = "12.5"
IF ISNUMERIC(text) THEN
    PRINT VAL(text) * 2
ELSE
    PRINT "Введите число"
END IF

Программа выводит:

25

Если заменить "12.5" на "12abc", программа выведет Введите число.
