Массивы

Функции массивов

Встроенные функции массивов читают границы, проверяют выделение памяти, создают копии, выбирают фрагменты, меняют порядок элементов и ищут значения. Они дополняют объявление через DIM, изменение размера через REDIM и прямой доступ по индексам.

Границы и размер массива

Границы измерения задают допустимые индексы. В Axiom они включительные: если массив объявлен как DIM values(1 TO 3) AS INTEGER, допустимы индексы 1, 2 и 3.

ФункцияЧто возвращаетКогда использовать
LBOUND(array)нижнюю границу первого измеренияцикл должен идти от фактического начала массива
UBOUND(array)верхнюю границу первого измеренияцикл должен остановиться на последнем допустимом индексе
LBOUND(array, dimension)нижнюю границу выбранного измерениянужно обойти строки, столбцы или другое измерение отдельно
UBOUND(array, dimension)верхнюю границу выбранного измерениянужно узнать последний индекс выбранного измерения
ARRAYLENGTH(array)общее число видимых элементовнужно проверить размер результата или пустой срез
ARRAYISALLOCATED(array)TRUE, если массив выделендинамический массив мог быть объявлен, но ещё не получить хранилище
ARRAYRANK(array)число измеренийкод принимает массивы разной формы
ARRAYBOUNDS(array)массив пар нижней и верхней границынужно вывести или передать форму массива целиком

Номер измерения в LBOUND(array, dimension) и UBOUND(array, dimension) считается с единицы. Для двумерных массивов можно использовать предопределённые целочисленные константы ROW и COLUMN: ROW равно 1, COLUMN равно 2. Это не отдельные операторы, а готовые имена для чтения строк и столбцов.

DIM board(1 TO 2, 1 TO 3) AS INTEGER

PRINT LBOUND(board, ROW)
PRINT UBOUND(board, ROW)
PRINT LBOUND(board, COLUMN)
PRINT UBOUND(board, COLUMN)
PRINT ARRAYLENGTH(board)

Копии и представления

Частичное индексирование и диапазонные срезы могут возвращать представление: оно смотрит на те же элементы исходного массива. Когда нужна независимая копия, используйте ARRAYCLONE.

ФункцияРезультатОсобенность
ARRAYCLONE(array)новый массив той же видимой формыкопия не разделяет элементы с исходным массивом или представлением
ARRAYFLATTEN(array)одномерный массив в порядке обходаудобно перед сортировкой или выводом таблицы одной строкой
ARRAYRESHAPE(values, template)новый массив по форме образцачисло элементов плоского массива должно подходить форме образца
 
flat = ARRAYFLATTEN(board)
sorted = ARRAYTOSORTED(flat)
reshaped = ARRAYRESHAPE(sorted, board)

Изменение содержимого

Операции этой группы меняют существующий массив или выбранное представление. Если аргументом передан срез, меняются только элементы, видимые через этот срез.

Функция или операторная формаДействиеЧто важно помнить
ARRAYFILL(array, value)заполняет видимые элементы одним значениемработает на месте
ARRAYPUSH(array, value)добавляет элемент в конец одномерного массиваграницы массива меняются
ARRAYPOP(array)удаляет и возвращает последний элементдля пустого массива нужна отдельная проверка
ARRAYINSERT(array, index, value)вставляет элемент по логическому индексупоследующие элементы сдвигаются
ARRAYREMOVE(array, index)удаляет элемент по логическому индексупоследующие элементы сдвигаются назад
ARRAYREVERSE(array[, dimension])разворачивает элементы на местедля многомерного массива измерение задаёт направление разворота
ARRAYSORT(array[, dimension])сортирует на местедля многомерного массива сортируется выбранное измерение
 
DIM values(1 TO 3) AS INTEGER
values(1) = 30
values(2) = 10
values(3) = 20

ARRAYSORT(values)
ARRAYPUSH(values, 40)
PRINT values(1)
PRINT values(4)

Срезы, объединение и изменение формы

Функции выбора создают новый массив из части исходных данных. Одномерные формы работают с логическим порядком элементов. Многомерные формы используют выбранное измерение: число 1 или константу ROW для строк, число 2 или константу COLUMN для столбцов.

ФункцияЧто выбираетФорма результата
ARRAYSLICE(array, start, count[, dimension])фрагмент с указанной позициисохраняет выбранную форму среза
ARRAYTAKE(array, count[, dimension])первые элементы, строки или столбцырезультат компактный и выделенный
ARRAYSKIP(array, count[, dimension])остаток после пропуска начальной частирезультат компактный и выделенный
ARRAYCONCAT(left, right[, dimension])склеивает совместимые массивыодномерный массив или массив по выбранному измерению
ARRAYDISTINCT(array)уникальные значенияодномерный список значений в порядке первого появления
 
topRows = ARRAYTAKE(board, 2, ROW)
rightPart = ARRAYSKIP(board, 1, COLUMN)
merged = ARRAYCONCAT(topRows, topRows, ROW)

Функции с пользовательской обработкой элемента

ARRAYEVERY, ARRAYSOME, ARRAYFILTER, ARRAYMAP и ARRAYREDUCE вызывают указанную пользователем функцию для каждого видимого элемента массива. Такая функция передаётся по имени и должна иметь подходящие параметры и тип результата.

ФункцияПередаваемая функция должна вернутьРезультат
ARRAYEVERY(array, test)BOOLEANTRUE, если проверка истинна для всех элементов
ARRAYSOME(array, test)BOOLEANTRUE, если проверка истинна хотя бы для одного элемента
ARRAYFILTER(array, test)BOOLEANмассив элементов, прошедших проверку
ARRAYMAP(array, transform)новое значение элементамассив той же видимой формы с преобразованными значениями
ARRAYREDUCE(array, seed, combine)новое значение накопителяодно итоговое значение
 
FUNCTION IsPositive(value AS INTEGER) AS BOOLEAN
    RETURN value > 0
END FUNCTION

FUNCTION Twice(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION

PRINT ARRAYEVERY(values, IsPositive)
mapped = ARRAYMAP(values, Twice)

Поиск значений

Функции поиска обходят видимые элементы массива. Для одномерного массива индекс результата относится к логическому индексу массива. Для многомерного массива функции, возвращающие позицию, используют координаты.

ФункцияРезультат при совпаденииРезультат без совпадения
ARRAYCONTAINS(array, value)TRUEFALSE
ARRAYCOUNT(array, value)число найденных элементов0
ARRAYINDEXOF(array, value)первый индекс или координаты0 для одномерного массива, пустой координатный результат для многомерного
ARRAYLASTINDEXOF(array, value)последний индекс или координаты0 для одномерного массива, пустой координатный результат для многомерного
ARRAYFINDALL(array, value)все индексы или таблица координатпустой массив
ARRAYBINARYSEARCH(array, value[, dimension])позиция в отсортированном массиве0 для одномерного массива, пустой координатный результат для многомерного

ARRAYBINARYSEARCH предполагает, что массив уже отсортирован в том же порядке, в котором выполняется поиск. Если данные не отсортированы, сначала используйте ARRAYSORT или ARRAYTOSORTED.

sortedValues = ARRAYTOSORTED(values)
PRINT ARRAYBINARYSEARCH(sortedValues, 20)
PRINT ARRAYCONTAINS(values, 99)
hits = ARRAYFINDALL(board, 4)

Порядок элементов

Для изменения порядка есть две пары функций: одни меняют исходный массив, другие возвращают новую копию. Выбирайте форму по тому, нужно ли сохранить исходные данные.

ЗадачаМеняет исходный массивВозвращает копию
Развернуть порядокARRAYREVERSE(array[, dimension])ARRAYTOREVERSED(array[, dimension])
ОтсортироватьARRAYSORT(array[, dimension])ARRAYTOSORTED(array[, dimension])
 
copy = ARRAYTOSORTED(values)
ARRAYREVERSE(values)

PRINT values(1)
PRINT copy(1)
