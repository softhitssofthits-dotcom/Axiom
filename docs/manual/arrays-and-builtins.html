Границы и размер массива

Границы измерения задают допустимые индексы. В Axiom они включительные: если массив объявлен как DIM values(1 TO 3) AS INTEGER, допустимы индексы 1, 2 и 3.

ФункцияЧто возвращаетКогда использовать
LBOUND(array)нижнюю границу первого измеренияцикл должен идти от фактического начала массива
UBOUND(array)верхнюю границу первого измеренияцикл должен остановиться на последнем допустимом индексе
LBOUND(array, dimension)нижнюю границу выбранного измерениянужно обойти строки, столбцы или другое измерение отдельно
UBOUND(array, dimension)верхнюю границу выбранного измерениянужно узнать последний индекс выбранного измерения
ARRAYLENGTH(array)общее число видимых элементовнужно проверить размер результата или пустой срез
ARRAYISALLOCATED(array)TRUE, если массив выделендинамический массив мог быть объявлен, но ещё не получить хранилище
ARRAYRANK(array)число измеренийкод принимает массивы разной формы
ARRAYBOUNDS(array)массив пар нижней и верхней границынужно вывести или передать форму массива целиком

Номер измерения в LBOUND(array, dimension) и UBOUND(array, dimension) считается с единицы. Для двумерных массивов можно использовать предопределённые целочисленные константы ROW и COLUMN: ROW равно 1, COLUMN равно 2. Это не отдельные операторы, а готовые имена для чтения строк и столбцов.

DIM board(1 TO 2, 1 TO 3) AS INTEGER

PRINT LBOUND(board, ROW)
PRINT UBOUND(board, ROW)
PRINT LBOUND(board, COLUMN)
PRINT UBOUND(board, COLUMN)
PRINT ARRAYLENGTH(board)

Копии и представления

Частичное индексирование и диапазонные срезы могут возвращать представление: оно смотрит на те же элементы исходного массива. Когда нужна независимая копия, используйте ARRAYCLONE.

ФункцияРезультатОсобенность
ARRAYCLONE(array)новый массив той же видимой формыкопия не разделяет элементы с исходным массивом или представлением
ARRAYFLATTEN(array)одномерный массив в порядке обходаудобно перед сортировкой или выводом таблицы одной строкой
ARRAYRESHAPE(values, template)новый массив по форме образцаисходный массив любого ранга должен иметь столько же элементов, сколько образец
 
flat = ARRAYFLATTEN(board)
sorted = ARRAYTOSORTED(flat)
reshaped = ARRAYRESHAPE(sorted, board)

ARRAYRESHAPE: новая форма массива

ARRAYRESHAPE — встроенная функция языка Axiom, которая создаёт новый массив с границами и рангом образца. Функция нужна, когда те же значения следует расположить в таблице другой формы. Она работает в BytecodeVm без специального режима.

result = ARRAYRESHAPE(source, template)

Аргументы source и template должны быть выделенными массивами с одинаковым типом элементов и одинаковым общим числом видимых элементов. Ранги и границы исходного массива и образца могут различаться. Аргумент source может быть многомерным массивом или представлением; предварительный вызов ARRAYFLATTEN не обязателен. Значения template задают только форму и не переносятся в результат.

Функция читает значения source по возрастанию индексов: последнее измерение меняется быстрее остальных. В таком же порядке функция заполняет форму template. Результат имеет тип элементов source, ранг и все границы template. Изменение INTEGER-элемента результата не меняет исходный массив или образец. Пустые выделенные массивы с нулевым числом элементов также допустимы: результат сохраняет пустую форму образца.

Диагностика

Невыделенный source или template даёт MB3005. Разное число элементов даёт MB3007; обе ошибки перехватываются оператором TRY/CATCH. Разные типы элементов или аргумент, который не является массивом, отвергаются при проверке программы.

Пример

DIM source(-2 TO -1, 4 TO 6) AS INTEGER
DIM template(9 TO 11, -4 TO -3) AS INTEGER
DIM result(,) AS INTEGER
source(-2, 4) = 11
source(-2, 5) = 12
source(-2, 6) = 13
source(-1, 4) = 21
source(-1, 5) = 22
source(-1, 6) = 23
result = ARRAYRESHAPE(source, template)
PRINT result(9, -4)
PRINT result(10, -4)
PRINT result(11, -3)

Программа выводит 11, 13 и 23. Полный запускаемый пример: matrix_to_matrix.axm. См. также: ARRAYFLATTEN и ARRAYCONCAT.

ARRAYFLATTEN: элементы в одномерном массиве

ARRAYFLATTEN — встроенная функция языка Axiom, которая собирает видимые элементы массива в новый одномерный массив. Функция нужна для последовательного вывода или сортировки элементов таблицы. Она работает в BytecodeVm без специального режима.

result = ARRAYFLATTEN(array)

Аргумент array должен быть выделенным массивом или представлением массива. Функция сохраняет тип элементов и читает их по возрастанию индексов, меняя последнее измерение быстрее остальных. Границы результата — 1 TO N, где N означает число видимых элементов. Для пустого выделенного массива результат также выделен и имеет границы 1 TO 0. Изменение INTEGER-элемента результата не меняет исходный массив.

Диагностика

Невыделенный массив даёт MB3005, которую можно перехватить оператором TRY/CATCH. Аргумент другого типа отвергается при проверке программы.

Пример

DIM source(7 TO 7, -2 TO -1) AS INTEGER
DIM flat() AS INTEGER
source(7, -2) = 10
source(7, -1) = 20
flat = ARRAYFLATTEN(source)
PRINT flat(1)
PRINT flat(2)

Программа выводит 10 и 20. См. также: ARRAYRESHAPE, пример обхода таблицы.

Явное измерение преобразования массива

ARRAYTOSORTED, ARRAYTOREVERSED, ARRAYSORT, ARRAYREVERSE, ARRAYBINARYSEARCH, ARRAYPUSH, ARRAYPOP, ARRAYINSERT, ARRAYREMOVE и ARRAYCONCAT — встроенные функции языка Axiom, у которых номер измерения выбирает направление операции. Это разные функции; номер dimension добавляется последним аргументом к каждой её собственной форме. Все функции работают в BytecodeVm без экранного или файлового режима.

Аргумент dimension должен иметь тип INTEGER и лежать в диапазоне от 1 до ARRAYRANK(array). Для одномерного массива номер можно опустить или указать 1. Явно заданный номер проверяется даже для пустого массива и массива из одного элемента: отсутствие работы по сортировке не отменяет проверку аргумента. Для многомерного массива номер требуется явно.

Примеры отдельных форм

sorted = ARRAYTOSORTED(values, 1)
reversed = ARRAYTOREVERSED(values, 1)
ARRAYSORT(values, 1)
ARRAYREVERSE(values, 1)
position = ARRAYBINARYSEARCH(values, value, 1)
ARRAYPUSH(values, value, 1)
last = ARRAYPOP(values, 1)
ARRAYINSERT(values, index, value, 1)
removed = ARRAYREMOVE(values, index, 1)
merged = ARRAYCONCAT(left, right, 1)

Результат и диагностика

ARRAYTOSORTED, ARRAYTOREVERSED и ARRAYCONCAT создают новый массив; ARRAYSORT, ARRAYREVERSE и операции добавления/удаления меняют исходный массив по своему договору. Недопустимый dimension даёт MB3007 до выполнения операции. На выделенном допустимом массиве отказ по измерению не меняет длину, порядок и значения элементов. Ошибка перехватывается оператором TRY/CATCH.

DIM values(1 TO 3) AS INTEGER
values(1) = 30
values(2) = 10
values(3) = 20
TRY
    ARRAYSORT(values, 2)
CATCH err
    PRINT err.Code   ' MB3007
END TRY
PRINT values(1)      ' 30: отказ не отсортировал массив
ARRAYSORT(values, 1)
PRINT values(1)      ' 10

Запускаемый пример: Проверка измерения до сортировки.

Изменение содержимого

Операции этой группы меняют существующий массив или выбранное представление. Если аргументом передан срез, меняются только элементы, видимые через этот срез.

Функция или операторная формаДействиеЧто важно помнить
ARRAYFILL(array, value)заполняет видимые элементы одним значениемработает на месте
ARRAYPUSH(array, value)добавляет элемент в конец одномерного массиваграницы массива меняются
ARRAYPOP(array)удаляет и возвращает последний элементдля пустого массива нужна отдельная проверка
ARRAYINSERT(array, index, value)вставляет элемент по логическому индексупоследующие элементы сдвигаются
ARRAYREMOVE(array, index)удаляет элемент по логическому индексупоследующие элементы сдвигаются назад
ARRAYREVERSE(array[, dimension])разворачивает элементы на местедля многомерного массива измерение задаёт направление разворота
ARRAYSORT(array[, dimension])сортирует на местедля многомерного массива сортируется выбранное измерение
 
DIM values(1 TO 3) AS INTEGER
values(1) = 30
values(2) = 10
values(3) = 20

ARRAYSORT(values)
ARRAYPUSH(values, 40)
PRINT values(1)
PRINT values(4)

ARRAYSORT и ARRAYTOSORTED — встроенные функции сортировки массива. Многомерная сортировка обрабатывает каждую линию выбранного измерения и сохраняет все границы. ARRAYSORT меняет исходные элементы; ARRAYTOSORTED возвращает отдельную копию. Последний индекс INTEGER, равный 2147483647, допустим и для сортируемой линии.

DIM edge(7 TO 7, 2147483646 TO 2147483647) AS INTEGER
edge(7, 2147483646) = 30
edge(7, 2147483647) = 10
ARRAYSORT(edge, 2)
PRINT edge(7, 2147483646)
PRINT edge(7, 2147483647)

Программа выводит 10 и 30. Сравнение сортировки копии и исходного массива: maximum_line_index.axm.

Срезы, объединение и изменение формы

Функции выбора создают новый массив из части исходных данных. Одномерные формы работают с логическим порядком элементов. Многомерные формы используют выбранное измерение: число 1 или константу ROW для строк, число 2 или константу COLUMN для столбцов.

ФункцияЧто выбираетФорма результата
ARRAYSLICE(array, start, count[, dimension])фрагмент с указанной позициисохраняет выбранную форму среза
ARRAYTAKE(array, count[, dimension])первые элементы, строки или столбцырезультат компактный и выделенный
ARRAYSKIP(array, count[, dimension])остаток после пропуска начальной частирезультат компактный и выделенный
ARRAYCONCAT(left, right[, dimension])склеивает совместимые массивыодномерный массив или массив по выбранному измерению
ARRAYDISTINCT(array)уникальные значенияодномерный список значений в порядке первого появления
 
topRows = ARRAYTAKE(board, 2, ROW)
rightPart = ARRAYSKIP(board, 1, COLUMN)
merged = ARRAYCONCAT(topRows, topRows, ROW)

ARRAYCONCAT: границы многомерного результата

ARRAYCONCAT — встроенная функция языка Axiom, которая создаёт новый массив, объединяя элементы двух массивов. Многомерная форма нужна для добавления строк, столбцов или слоёв; она работает в BytecodeVm без специального режима.

merged = ARRAYCONCAT(left, right, dimension)

Аргументы left и right должны быть выделенными массивами совместимой формы и типа элементов. Аргумент dimension должен быть целым номером измерения от 1 до ранга массива. Границы остальных измерений должны совпадать. Функция копирует элементы left, затем элементы right по выбранному измерению; исходные массивы не изменяются.

Если обе части непусты по выбранному измерению, нижняя граница результата совпадает с нижней границей left. Верхняя граница равна нижней границе плюс сумма длин обеих частей минус один. Индекс 2147483647 допустим: два элемента с началом 2147483646 помещаются в результат. Если одна часть пуста по выбранному измерению, функция копирует форму другой части.

Одномерная форма ARRAYCONCAT(left, right) при двух непустых частях создаёт компактный результат с началом 1. Если одна часть пуста, результат копирует границы другой части: например, непустой диапазон 4 TO 6 сохраняется. Это также действует для одномерных представлений.

Диагностика

Если вычисленная верхняя граница превышает 2147483647, функция выдаёт MB3007. Ошибку можно перехватить оператором TRY/CATCH. Отказ не меняет исходные массивы.

Пример

DIM a(7 TO 7, 2147483646 TO 2147483646) AS INTEGER
DIM merged(,) AS INTEGER
a(7, 2147483646) = 42
merged = ARRAYCONCAT(a, a, 2)
PRINT UBOUND(merged, 2)
PRINT merged(7, 2147483647)

Программа выводит 2147483647 и 42. Полная проверка допустимой границы и перехвата ошибки: maximum_index.axm.

См. также: выбор измерения, выбор части массива.

ARRAYSLICE, ARRAYTAKE и ARRAYSKIP: выбор части массива

ARRAYSLICE, ARRAYTAKE и ARRAYSKIP — встроенные функции языка Axiom для создания нового массива из выбранного участка. Синтаксис ниже относится к трём разным функциям. Все функции работают в BytecodeVm без экранного или файлового режима.

Синтаксис

part = ARRAYSLICE(array, start, count)
part = ARRAYSLICE(array, start, count, dimension)
part = ARRAYTAKE(array, count)
part = ARRAYTAKE(array, count, dimension)
part = ARRAYSKIP(array, count)
part = ARRAYSKIP(array, count, dimension)

Аргументы и результат

array должен быть выделенным массивом. start задаёт исходный индекс, count — неотрицательное количество элементов или срезов. start, count и dimension должны иметь тип INTEGER. ARRAYSLICE выбирает участок с start; ARRAYTAKE берёт первые count элементов, ARRAYSKIP пропускает первые count элементов. TAKE и SKIP ограничивают количество длиной выбранного измерения. Результат сохраняет тип элементов и ранг массива; исходный массив не меняется.

Одномерные результаты компактны и начинаются с индекса 1; пустой результат имеет границы 1 TO 0. Многомерные результаты сохраняют индексы выбранного участка и остальные измерения. ARRAYCLONE, в отличие от этих одномерных выборок, сохраняет исходные границы.

Пустой многомерный результат сохраняет ранг и границы остальных измерений. Обычно пустое выбранное измерение задаётся парой соседних индексов: нижняя граница на единицу больше верхней. Если ARRAYSLICE с count=0 получает start=INTEGER.MinValue или ARRAYSKIP пропускает всё измерение с верхней границей INTEGER.MaxValue, такую пару нельзя задать допустимыми индексами; выбранное измерение получает границы 1 TO 0. Результат остаётся выделенным массивом длины 0. Нижняя граница исходного массива INTEGER.MinValue по-прежнему запрещена: это значение зарезервировано для поиска.

DIM values(2147483647 TO 2147483647, 7 TO 7) AS INTEGER
DIM part(,) AS INTEGER
part = ARRAYSKIP(values, 1, 1)
PRINT ARRAYLENGTH(part)  ' 0
PRINT LBOUND(part, 1)    ' 1
PRINT UBOUND(part, 1)    ' 0
PRINT LBOUND(part, 2)    ' 7

Запускаемый пример: Пустое измерение у крайнего индекса.

Измерения и диагностика

Для многомерного массива dimension требуется явно. Для одномерного массива dimension можно опустить или указать 1. Если dimension задан, он всегда проверяется: допустим диапазон от 1 до ARRAYRANK(array). Недопустимый номер, отрицательный count и непустой срез вне границ дают MB3007. Отсутствие обязательного измерения и неверные типы отклоняются при связывании.

Пример проверки измерения

DIM values(5 TO 7) AS INTEGER
DIM part() AS INTEGER
values(5) = 10
part = ARRAYTAKE(values, 1, 1)
PRINT part(1)  ' 10
TRY
    part = ARRAYTAKE(values, 1, 2)
CATCH err
    PRINT err.Code  ' MB3007: у массива только одно измерение
END TRY

Запускаемый пример: Явное измерение одномерного массива.

Функции с пользовательской обработкой элемента

ARRAYEVERY, ARRAYSOME, ARRAYFILTER, ARRAYMAP и ARRAYREDUCE — встроенные функции языка Axiom, которые передают элементы массива указанной пользователем функции. Эти разные встроенные функции нужны для проверки, отбора, преобразования и свёртки данных; пользовательская функция передаётся по имени и должна иметь подходящие параметры и тип результата. Все пять функций работают в BytecodeVm без специального режима.

ФункцияПередаваемая функция должна вернутьРезультат
ARRAYEVERY(array, test)BOOLEANTRUE, если проверка истинна для всех элементов
ARRAYSOME(array, test)BOOLEANTRUE, если проверка истинна хотя бы для одного элемента
ARRAYFILTER(array, test)BOOLEANмассив элементов, прошедших проверку
ARRAYMAP(array, transform)новое значение элементамассив той же видимой формы с преобразованными значениями
ARRAYREDUCE(array, seed, combine)новое значение накопителяодно итоговое значение

Аргумент array должен быть выделенным массивом. Аргумент test принимает элемент и возвращает BOOLEAN; аргумент transform принимает элемент и возвращает преобразованное значение. Аргумент combine принимает текущий накопитель и элемент, затем возвращает новое значение накопителя. Аргумент seed задаёт начальное значение накопителя.

ARRAYEVERY прекращает вызовы после первого FALSE, а ARRAYSOME — после первого TRUE. На пустом выделенном массиве функции не вызывают пользовательскую функцию: ARRAYEVERY возвращает TRUE, ARRAYSOME возвращает FALSE, ARRAYFILTER и ARRAYMAP создают пустой результат, ARRAYREDUCE возвращает seed. ARRAYMAP сохраняет видимые границы исходного массива; ARRAYFILTER собирает выбранные значения в одномерный массив с началом 1.

Последний допустимый индекс 2147483647 обрабатывается как обычный элемент. После его обработки обход завершается, не переходя к переполненному индексу. Например, следующий вызов преобразует единственный элемент и возвращает значение 84:

DIM edge(2147483647 TO 2147483647) AS INTEGER
DIM mapped() AS INTEGER
edge(2147483647) = 42
mapped = ARRAYMAP(edge, Twice)
PRINT mapped(2147483647)
FUNCTION Twice(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION

Проверка всех пяти функций: maximum_callback_index.axm. Невыделенный массив даёт MB3005; неподходящие параметры или тип результата пользовательской функции отвергаются при проверке программы.

При ошибке внутри пользовательской функции обработка останавливается на текущем элементе. Внешний TRY/CATCH вокруг ARRAYMAP может перехватить исходную ошибку, например MB3001 при делении на ноль. Если пользовательская функция содержит собственный TRY/CATCH, она может обработать ошибку и вернуть значение; её FINALLY выполняется до возврата или передачи необработанной ошибки вызывающему коду.

Пример перехвата ошибки преобразования

DIM values(1 TO 3) AS INTEGER
DIM result() AS INTEGER
values(1) = 1
values(2) = 2
values(3) = 3
TRY
    result = ARRAYMAP(values, Quotient)
CATCH err
    PRINT err.Code
END TRY
FUNCTION Quotient(value AS INTEGER) AS INTEGER
    RETURN CINT(10 / (value - 2))
END FUNCTION

При обработке второго элемента программа выводит MB3001; третий элемент не передаётся функции Quotient. Полный запускаемый пример со счётчиком вызовов: catch_callback_error.axm.

FUNCTION IsPositive(value AS INTEGER) AS BOOLEAN
    RETURN value > 0
END FUNCTION

FUNCTION Twice(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION

PRINT ARRAYEVERY(values, IsPositive)
mapped = ARRAYMAP(values, Twice)

Поиск значений

Функции поиска обходят видимые элементы массива. Для одномерного массива индекс результата относится к логическому индексу массива. Для многомерного массива функции, возвращающие позицию, используют координаты.

ФункцияРезультат при совпаденииРезультат без совпадения
ARRAYCONTAINS(array, value)TRUEFALSE
ARRAYCOUNT(array, value)число найденных элементов0
ARRAYINDEXOF(array, value)первый индекс или координатыLBOUND(array) - 1 для одномерного массива, пустой координатный результат для многомерного
ARRAYLASTINDEXOF(array, value)последний индекс или координатыLBOUND(array) - 1 для одномерного массива, пустой координатный результат для многомерного
ARRAYFINDALL(array, value)все индексы или таблица координатпустой массив
ARRAYBINARYSEARCH(array, value[, dimension])позиция в отсортированном массивеLBOUND(array) - 1 для одномерного массива, пустой координатный результат для многомерного

ARRAYBINARYSEARCH предполагает, что массив уже отсортирован в том же порядке, в котором выполняется поиск. Если данные не отсортированы, сначала используйте ARRAYSORT или ARRAYTOSORTED.

У одномерного массива отсутствие значения обозначается индексом на единицу меньше нижней границы. Число 0 получается только при нижней границе 1. Например, для диапазона -4 TO -2 отсутствие значения обозначается числом -5; индекс 0 может быть настоящим индексом найденного элемента. Сравнивайте результат с LBOUND(array), а не всегда с нулём. Для пустого компактного массива 1 TO 0 результат поиска индекса равен 0.

ARRAYINDEXOF и ARRAYLASTINDEXOF в многомерном массиве возвращают координаты первого и последнего совпадения при обходе по возрастанию индексов, когда последнее измерение меняется быстрее остальных. Координаты собраны в INTEGER-массиве 1 TO Rank. ARRAYFINDALL возвращает таблицу: строки 1 TO N соответствуют совпадениям, столбцы 1 TO Rank — измерениям исходного массива. Если совпадений нет, строки имеют границы 1 TO 0, а число столбцов сохраняется.

Многомерный ARRAYBINARYSEARCH требует номер измерения и отсортированность каждой линии вдоль этого измерения. Функция обходит остальные индексы по возрастанию и возвращает первое совпадение в первой подходящей линии; внутри линии выбирается первый повтор. Поэтому изменение dimension может менять найденные координаты. При отсутствии совпадения возвращается выделенный пустой массив координат с границами 1 TO 0.

Аргумент array должен быть выделенным массивом или представлением. Аргумент value проверяется на совместимость с типом элементов массива. Невыделенный массив даёт MB3005; несовместимый тип значения отвергается при проверке программы. Для ARRAYBINARYSEARCH недопустимый номер измерения даёт MB3007. Поиск не изменяет исходные элементы.

Пример отсутствующего значения при отрицательных индексах

DIM values(-4 TO -2) AS INTEGER
values(-4) = 2
values(-3) = 2
values(-2) = 4
PRINT ARRAYINDEXOF(values, 99)
PRINT ARRAYLASTINDEXOF(values, 99)
PRINT ARRAYBINARYSEARCH(values, 99)

Все три вызова возвращают -5. Запускаемый пример: negative_missing_index.axm.

sortedValues = ARRAYTOSORTED(values)
PRINT ARRAYBINARYSEARCH(sortedValues, 20)
PRINT ARRAYCONTAINS(values, 99)
hits = ARRAYFINDALL(board, 4)

Агрегаты: сумма, минимум, максимум и среднее

Функции ARRAYSUM, ARRAYMIN, ARRAYMAX и ARRAYAVERAGE сводят элементы массива к одному итоговому значению и избавляют от ручного цикла накопления. Все четыре функции обходят видимые элементы массива любого ранга.

Синтаксис

result = ARRAYSUM(array)
result = ARRAYMIN(array)
result = ARRAYMAX(array)
result = ARRAYAVERAGE(array)

Аргументы

Аргумент array задаёт выделенный массив. Для ARRAYSUM, ARRAYMIN и ARRAYMAX элементы должны быть числовыми, а для ARRAYMIN и ARRAYMAX дополнительно допускаются строковые массивы со сравнением по кодам символов.

Результат

ARRAYSUM, ARRAYMIN и ARRAYMAX возвращают одно значение того же типа, что и элементы массива. Результат можно присвоить обычной переменной, использовать в выражении или при объявлении переменной без явного типа. Сумма целого массива остаётся целым числом и проверяется на переполнение. ARRAYAVERAGE всегда возвращает DOUBLE.

Ограничения

Функция ARRAYAVERAGE точно накапливает представленные значения DOUBLE и округляет среднее один раз, к ближайшему представимому значению; при равном расстоянии выбирается значение с чётным младшим разрядом. Поэтому среднее двух значений 1e308 равно 1e308, хотя их обычная сумма не помещается в DOUBLE. Взаимное сокращение больших слагаемых сохраняет малый остаток: для 1e308, -1e308 и 1e-308 среднее равно 1e-308 / 3, а не нулю. Результат остаётся приближённым числом DOUBLE; преобразование элементов других числовых типов в DOUBLE выполняется до накопления.

Числовой договор минимума и максимума проверяется и для массива из одного элемента. Массив BOOLEAN не допускается и сообщает MB3007. Все четыре агрегата работают с многомерными массивами без указания измерения и обходят все видимые элементы.

Пример двумерного массива

DIM numbers(1 TO 2, 1 TO 2) AS INTEGER
numbers(1, 1) = 1
numbers(1, 2) = 2
numbers(2, 1) = 3
numbers(2, 2) = 4
PRINT ARRAYSUM(numbers)     ' 10
PRINT ARRAYMIN(numbers)     ' 1
PRINT ARRAYMAX(numbers)     ' 4
PRINT ARRAYAVERAGE(numbers) ' 2.5

Запускаемые проверки: многомерные агрегаты, среднее больших чисел и отклонение логического массива.

  • для пустого выделенного массива функция сообщает диагностику MB3007; для ещё не выделенного массива — MB3005;
  • смешивать строки и числа в одном массиве нельзя: такая диагностика тоже будет MB3007.

Пример агрегатов

Функция ARRAYAVERAGE принимает также массив DECIMAL. Перед накоплением каждый элемент преобразуется в DOUBLE, поэтому точность исходного десятичного числа может уменьшиться. Например, среднее четверти и трёх четвертей равно половине:

DIM fractions(-1 TO 0) AS DECIMAL
fractions(-1) = CDEC(1) / CDEC(4)
fractions(0) = CDEC(3) / CDEC(4)
PRINT ARRAYAVERAGE(fractions) ' 0.5

Запускаемая проверка: среднее десятичных элементов и сохранность массива.

' Сводка оценок без ручного цикла
DIM scores(1 TO 4) AS INTEGER
scores(1) = 5
scores(2) = 4
scores(3) = 5
scores(4) = 3

DIM total AS INTEGER = ARRAYSUM(scores)
DIM lowest AS INTEGER = ARRAYMIN(scores)
DIM highest = ARRAYMAX(scores)
PRINT total
PRINT lowest
PRINT highest
PRINT ARRAYAVERAGE(scores)

Переполнение суммы

Если промежуточная сумма выходит за диапазон INTEGER, LONG или DECIMAL, функция ARRAYSUM сообщает диагностику MB3008 на месте вызова. Для DOUBLE та же диагностика возникает, если итоговая сумма не является конечным числом. Ошибку можно обработать оператором TRY; блок FINALLY выполняется и после переполнения.

DIM values(1 TO 2) AS INTEGER
values(1) = 2147483647
values(2) = 1
TRY
    ' Сумма двух элементов не помещается в INTEGER.
    PRINT ARRAYSUM(values)
CATCH err
    PRINT "Поймана ошибка:", err.Code
FINALLY
    PRINT "Обработка завершена."
END TRY

Запускаемые проверки: скалярные результаты агрегатов и обработка переполнения суммы.

Порядок элементов

Для изменения порядка есть две пары функций: одни меняют исходный массив, другие возвращают новую копию. Выбирайте форму по тому, нужно ли сохранить исходные данные.

ЗадачаМеняет исходный массивВозвращает копию
Развернуть порядокARRAYREVERSE(array[, dimension])ARRAYTOREVERSED(array[, dimension])
ОтсортироватьARRAYSORT(array[, dimension])ARRAYTOSORTED(array[, dimension])
 
copy = ARRAYTOSORTED(values)
ARRAYREVERSE(values)

PRINT values(1)
PRINT copy(1)
