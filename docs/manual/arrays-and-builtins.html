Массивы и встроенные функции

Эта обзорная глава связывает статьи по массивам, строковым функциям, регулярным выражениям, файловой системе, дате и времени и числовым функциям. Она помогает выбрать нужную справочную страницу и не повторяет подробности, вынесенные в отдельные статьи.

Содержание

  • Сводка
  • Навигация по разделу
  • Показательные примеры

Сводка

  • когда нужно перейти от хранения набора значений к операциям над строками и числами;
  • когда важно увидеть, как массивы, строковые функции, функции регулярных выражений, функции файловой системы, функции даты и времени и числовые функции разнесены по отдельным справочным статьям;
  • когда нужен короткий маршрут по связанным разделам без повторения всех сигнатур на одной странице.

Как читать раздел

Если вы только начинаете работу с массивами, откройте сначала справочную статью по массивам. Если нужно обрабатывать текст простыми операциями, переходите к строковым функциям. Если нужен поиск по регулярному выражению, открывайте отдельную страницу по регулярным выражениям. Если нужно читать или записывать текстовые файлы, откройте страницу файловой системы. Если нужны текущие дата и время, переходите к отдельной странице дата-временных функций. Если важны вычисления и преобразование чисел, открывайте главу по числовым функциям.

Навигация по разделу

Одномерные массивы

Объявление, границы, доступ к элементам, информационные функции и операции над массивами.

Строковые функции

LEN, LEFT, RIGHT, MID, SPLIT, JOIN и другие операции над текстом.

Функции регулярных выражений

REGEXISMATCH, REGEXMATCH, REGEXMATCHES, REGEXEXTRACTALL, REGEXSPLIT, REGEXREPLACE и REGEXCOUNT для поиска по образцу.

Функции файловой системы

READFILE, READALLLINES, READLINES, GETFILES, GETDIRS, запись текста, проверки существования, пути и сведения о файлах.

Функции даты и времени

DATE, TIME, NOW и TIMER для чтения локальных даты и времени в каноническом формате.

Числовые функции

INT, STR, VAL и математические функции с отдельными справочными описаниями.

  • READALLLINES: чтение строк файла

  • WRITEFILE: запись текстового файла
