Присваивание

Присваивание — инструкция языка Axiom, которая записывает результат выражения в переменную, элемент массива или поле записи.

Назначение и контекст

Присваивание изменяет сохранённое значение, сохраняя тип назначения. Инструкция разрешена на верхнем уровне программы, внутри подпрограмм и блоков. Назначение должно быть доступно в текущей области видимости и допускать запись.

Синтаксис

<цель> = <выражение>

Цель и новое значение

<цель> — изменяемое назначение: объявленная переменная, индексируемый элемент массива или поле записи. Примеры: count, items(1), point.X.

<выражение> — выражение, вычисляющее новое значение. Его тип должен быть совместим с типом цели. Допустимые переходы описаны в статье преобразований типов.

Вычисление значения

DIM total AS INTEGER = 4
total = total + 3
PRINT total

Программа выводит:

7

Правая часть использует прежнее значение total; результат 7 становится новым значением переменной.

В качестве цели можно указать отдельный элемент массива или поле записи. Это изменит выбранный элемент или поле; правила обращения к ним приведены в статьях индексирования и пользовательских типов.

Ограничения и похожие записи

Присваивание не объявляет имя. Если переменная ещё не объявлена, компилятор сообщает об ошибке. Прямое присваивание константе или переменной только для чтения запрещено.

Знак = в условии или другом выражении проверяет равенство. Например, PRINT total = 7 выводит TRUE или FALSE и не меняет total. Различие определяется местом знака в программе.

Запись <поле> := <значение> используется в литерале записи для указания именованного поля. Она не заменяет обычное присваивание.

Файловые значения FILE нельзя присваивать друг другу общей инструкцией присваивания. Правила копирования записей и связь массивных представлений с исходным массивом описаны в соответствующих разделах.

Диагностика

  • MB2001 — цель или выражение обращается к необъявленному имени.
  • MB2003 — вычисленное значение несовместимо с типом цели.
  • MB2010 — цель является константой или доступна только для чтения.
  • MB3005 — элементы массива ещё не выделены.
  • MB3002 — индекс выходит за границы массива.

Пример

Объявление создаёт переменную. Два следующих присваивания последовательно изменяют её:

DIM count AS INTEGER = 2
count = count + 1
count = count * 2
PRINT count

Программа выводит:

6
