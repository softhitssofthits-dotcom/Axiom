Присваивание

Присваивание — инструкция языка Axiom, которая записывает вычисленное значение в переменную, элемент массива или поле записи.

Синтаксис

<цель> = <выражение>

Части синтаксиса

<цель> — объявленная изменяемая переменная, доступный элемент массива или поле записи. <выражение> — выражение совместимого типа.

Правила работы

Правая часть вычисляется, затем результат записывается в цель. Допустимые неявные преобразования определены правилами преобразования типов. Константе присвоить новое значение нельзя.

Знак = внутри выражения означает сравнение. Запись FieldName := expression применяется к именованным полям литерала записи TYPE; она не заменяет обычное присваивание.

Правила копирования записей и связи массивных представлений с исходным хранилищем определены на страницах TYPE и срезов массива.

Диагностика

  • MB2001 — имя цели или имя в выражении не объявлено.
  • MB2003 — тип значения несовместим с типом цели.
  • MB2010 — попытка присвоить значение константе.
  • MB3005 — хранилище индексируемого массива не выделено.
  • MB3007 — индекс элемента выходит за границы.

Пример

DIM total AS INTEGER = 10
total = total + 5
PRINT total

Результат:

15
