Присваивание

Присваивание вычисляет выражение и записывает его результат в объявленную переменную, элемент массива или поле записи. Значение цели меняется, а её тип сохраняется.

Запись инструкции

<цель> = <выражение>

Цель слева от знака равенства должна допускать запись. Ею может быть имя переменной, элемент массива или поле записи, например count, items(1), point.X. Выражение справа задаёт новое значение, совместимое с типом цели. Допустимые преобразования перечислены в статье о преобразованиях типов.

Присваивание допустимо на верхнем уровне программы, в подпрограммах и блоках. Переменная должна быть объявлена заранее, а её имя доступно в текущей области видимости: само присваивание нового имени не вводит.

Замена сохранённого значения

Правая часть вычисляется до записи результата. Поэтому в ней можно использовать прежнее значение той же переменной:

DIM total AS INTEGER = 4
total = total + 3
PRINT total

Результат:

7

Следующее присваивание использует значение, сохранённое предыдущим. Здесь сначала счётчик увеличивается на единицу, затем полученное значение удваивается:

DIM count AS INTEGER = 2
count = count + 1
count = count * 2
PRINT count
6

Элементы и поля

Для записи в отдельный элемент массива после имени указывается индекс, для записи в поле после точки указывается имя поля:

TYPE Position
    X AS INTEGER
END TYPE

DIM point AS Position
DIM items(1 TO 2) AS INTEGER
items(1) = 8
point.X = items(1) + 1
PRINT items(1), point.X

Результат:

8 9

Запись в элемент массива требует выделенных элементов и индекса в допустимых границах. Подробности обращения к элементам и полям приведены в статьях об индексировании массивов и о полях TYPE. Присваивание массива целиком или записи подчиняется правилам копирования и совместного использования памяти, описанным в статьях о массивных представлениях и о пользовательских типах.

Ограничения и другие значения знака равенства

Константа и переменная только для чтения не могут быть целью присваивания. Значения FILE также нельзя присваивать общей инструкцией: для открытия и закрытия файла предусмотрены OPEN и CLOSE.

В выражениях знак = обозначает сравнение. Поэтому PRINT total = 7 выводит TRUE или FALSE и оставляет total без изменения. Запись <поле> := <значение> задаёт значение именованного поля в литерале записи; как инструкция присваивания она не используется.

Диагностика

  • MB2001: цель или выражение обращается к необъявленному либо недоступному имени.
  • MB2003: значение несовместимо с типом цели либо выполняется прямое присваивание FILE.
  • MB2010: цель является константой или доступна только для чтения.
  • MB3005: элементы массива ещё не выделены.
  • MB3002: индекс выходит за границы массива.

Ошибки вычисления правой части описаны в статьях соответствующих операций и функций.

См. также

DIM объявляет переменную и задаёт её тип; CONST защищает имя от записи. Преобразования типов определяют, какие значения можно записать в цель другого типа.
