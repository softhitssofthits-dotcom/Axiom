Оператор IMPORT

IMPORT — оператор языка Axiom, который подключает открытые объявления другого исходного модуля. Он позволяет вызывать подпрограммы и использовать типы и данные, объявленные в отдельном файле.

Контекст

Оператор записывается в начале файла до объявлений и исполняемых инструкций. Каждый файл задаёт собственные импорты. В IDE открытая именованная зависимость берётся из снимка редактора вместе с несохранёнными правками; закрытая зависимость читается с диска. Уже запущенная программа использует снимок начала запуска. В CLI и IDE поиск выполняется в папке сохранённой точки входа; расширение файла — .axm.

Синтаксис

IMPORT moduleName

Параметры

moduleName — идентификатор, совпадающий с именем файла без расширения. Это имя, а не строковый путь; точки, разделители каталогов, расширение и кавычки не указываются.

Действие

Открытые имена зависимости становятся доступными без префикса. Закрытые имена остаются доступны только внутри исходного модуля. Импортированный модуль и его зависимости инициализируются до текущего модуля. Повторение одного IMPORT не запускает инициализацию повторно.

Правила и ограничения

Циклический импорт запрещён. Встроенные функции нельзя перекрывать импортированными объявлениями. Два импорта с одинаковым открытым именем дают неоднозначность; переименуйте объявление или измените состав импортов. Локальное объявление не может заменять импортированное имя. PUBLIC в импортирующем модуле не переэкспортирует чужие объявления.

Относительные пути файловых операций по-прежнему разрешаются от папки запущенного файла в IDE. Импорт не меняет рабочую папку и не создаёт файлы или каталоги.

Диагностика

MB2049
Модуль отсутствует в составе программы или не найден в папке точки входа.
MB2050
Несколько документов задают одно имя модуля.
MB2051
В явном наборе модулей не найдена точка входа.
MB2052
Обнаружен цикл импорта или импорт самого себя.
MB2053
Внешнее обращение использует закрытое имя.
MB2054
Несколько импортов открывают одинаковое имя.
MB2055
Импортированное имя конфликтует с другим доступным объявлением.
MB1001–MB1002
Нарушена запись или расположение IMPORT.

Пример

IMPORT tools
PRINT Square(5)
