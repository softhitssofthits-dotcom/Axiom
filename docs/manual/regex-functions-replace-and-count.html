Раздел

Замена и подсчёт совпадений

Раздел замены и подсчёта совпадений описывает функции REGEXREPLACE и REGEXCOUNT — массовую замену найденных фрагментов и подсчёт числа совпадений.

REGEXREPLACE

Функция REGEXREPLACE возвращает новую строку, где найденные совпадения заменены указанным текстом.

Синтаксис

result = REGEXREPLACE(text, pattern, replacement[, modes][, count])

Аргументы

replacement задаёт строку замены. Если указан count, заменяются только первые найденные совпадения в этом количестве.

Количество замен и ссылки на группы

Если count равен нулю, функция возвращает исходный текст без изменений. Отрицательное количество замен даёт MB3007. В строке замены можно использовать ссылки на группы через $1, $2 и далее.

Пример замены по шаблону

PRINT REGEXREPLACE("one 12 two 34", "\d+", "#")
PRINT REGEXREPLACE("one 12 two 34", "\d+", "#", 1)
PRINT REGEXREPLACE("A12 B34", "([A-Z])(\\d+)", "$1-$2")

Результат:

one # two #
one # two 34
A-12 B-34

REGEXCOUNT

Функция REGEXCOUNT возвращает количество совпадений с регулярным выражением.

Синтаксис

result = REGEXCOUNT(text, pattern[, modes])

Аргументы

text задаёт исходную строку, pattern задаёт регулярное выражение, modes при необходимости включает дополнительные режимы поиска. Результат имеет тип INTEGER.

Ноль при отсутствии совпадений

Если совпадений нет, результат равен 0. Эта функция удобна, когда нужно только число найденных фрагментов без извлечения самих значений.

Пример подсчёта совпадений

PRINT REGEXCOUNT("one 12 two 34", "\d+")
PRINT REGEXCOUNT("A12 b34", "[a-z]\d+", "i")

Результат:

2
2

Ручная проверка

  • REGEXREPLACE: замена по шаблону
  • REGEXCOUNT: подсчёт совпадений
