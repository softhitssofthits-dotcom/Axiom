Функция MOUSEY

Опрос текущей Y-координаты указателя без событийной очереди.

Ввод и вывод

Функция MOUSEY

MOUSEY() возвращает текущую вертикальную координату указателя мыши на активной поверхности программы. Функция нужна для тех же опросных сценариев, что и MOUSEX(), когда программа сама решает, в какой момент ей нужен снимок текущего состояния мыши.

Синтаксис

MOUSEY()

Возвращаемое значение

Тип результата: LONG.

  • если среда выполнения знает положение указателя, возвращается текущая Y-координата;
  • если положение указателя недоступно, возвращается -1.

Замечания

  • MOUSEY() не принимает аргументов;
  • функция читает только текущее состояние и не сообщает отдельные события перемещения;
  • для горизонтальной координаты используйте MOUSEX().

Пример

PRINT MOUSEY()
PRINT MOUSEX()

Ручная проверка

  • MOUSEY: текущее положение указателя

Диагностика

Диагностика MB2004 возникает, если передать аргументы в MOUSEY().
