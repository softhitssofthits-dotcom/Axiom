Функция MOUSEY

MOUSEY — встроенная функция языка Axiom, которая возвращает текущую вертикальную координату указателя мыши. Программа выбирает момент чтения, вызывая функцию в своём цикле.

Применение

На экране SCREEN координата Y измеряется в пикселях клиентской области. На холсте CANVAS результат соответствует мировому положению указателя после преобразования через VIEWPORT и CAMERA.

Контекст выполнения

Для чтения нужен графический SCREEN 1..10 или активный CANVAS. Отсутствие поверхности сообщает MB3010.

На экране VIEW, WINDOW и PMAP не пересчитывают координату мыши. На холсте учитываются текущие область и камера.

Функция читает текущее положение без извлечения события перемещения. Для процедуры по каждому событию используйте ON MOUSE.

Синтаксис

MOUSEY()

Поддерживается единственная форма MOUSEY().

Аргументы

Аргументов нет; скобки остаются частью вызова.

Что возвращает функция MOUSEY

Координата возвращается как значение типа LONG.

  • Если активен SCREEN и среда выполнения знает положение указателя, возвращается текущая Y-координата в клиентской области активного окна.
  • Если активен CANVAS и среда выполнения знает положение указателя, возвращается мировая Y-координата точки под мышью.
  • Если положение указателя недоступно, возвращается -1.

Правила работы

  • Встроенная функция MOUSEY не принимает аргументов.
  • Функция читает только текущее состояние и не сообщает отдельные события перемещения.
  • Если среда не знает текущее положение указателя, функция возвращает -1.
  • В CANVAS мировая координата считается как положение камеры плюс смещение указателя внутри прямоугольника VIEWPORT.
  • Для горизонтальной координаты используется встроенная функция MOUSEX.

Начало координат и отрицательные значения

В SCREEN начало клиентской области находится слева сверху; Y увеличивается вниз. В CANVAS функция возвращает камера Y + физический Y - верхняя граница области. Отрицательное мировое значение может быть допустимой координатой сцены; само по себе оно не доказывает отсутствие указателя.

Диагностика

  • MB2004: в встроенную функцию MOUSEY переданы аргументы.
  • MB3010: встроенная функция MOUSEY вызвана без активного графического режима SCREEN и без активного CANVAS.

Пример чтения координат

SCREEN 1
PRINT MOUSEY()
PRINT MOUSEX()
SLEEP

Программа печатает две координаты указателя в пикселях окна. Если положение ещё неизвестно, выводятся -1 и -1. Затем программа ждёт клавишу.

Запускаемые примеры

  • MOUSEY: текущее положение указателя в SCREEN
  • MOUSEY: мировая координата в CANVAS
