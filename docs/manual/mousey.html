Функция MOUSEY

MOUSEY — встроенная функция языка Axiom, которая возвращает текущую вертикальную координату указателя на активной графической поверхности программы. Встроенная функция MOUSEY нужна для тех же опросных сценариев, что и MOUSEX, когда программа сама решает, в какой момент ей нужен снимок текущего состояния мыши.

Для чего нужна функция MOUSEY

Встроенная функция MOUSEY нужна для чтения текущей Y-координаты указателя мыши. В графическом режиме SCREEN функция возвращает экранную координату клиентской области. В режиме CANVAS функция возвращает мировую координату точки, на которую указывает мышь после пересчёта через VIEWPORT и CAMERA.

Где работает функция MOUSEY

Встроенная функция MOUSEY работает при активном графическом режиме SCREEN 1..10 или при активном CANVAS. Без активной рисуемой поверхности выполнение сообщает диагностику MB3010.

При активном SCREEN оператор VIEW, оператор WINDOW и функция PMAP не изменяют возвращаемую координату: она остаётся в клиентской системе координат активного окна SCREEN. При активном CANVAS возвращаемое значение уже находится в мировой системе координат и учитывает текущие VIEWPORT и CAMERA.

Встроенная функция MOUSEY поддерживается интерпретатором и BytecodeVm.

Синтаксис

MOUSEY()

Встроенная функция MOUSEY поддерживает только форму без аргументов.

Аргументы

У встроенной функции MOUSEY нет аргументов. Пустые скобки остаются частью вызова функции.

Что возвращает функция MOUSEY

Тип результата: LONG.

  • Если активен SCREEN и среда выполнения знает положение указателя, возвращается текущая Y-координата в клиентской области активного окна.
  • Если активен CANVAS и среда выполнения знает положение указателя, возвращается мировая Y-координата точки под мышью.
  • Если положение указателя недоступно, возвращается -1.

Правила работы

  • Встроенная функция MOUSEY не принимает аргументов.
  • Функция читает только текущее состояние и не сообщает отдельные события перемещения.
  • Если среда не знает текущее положение указателя, функция возвращает -1.
  • В CANVAS мировая координата считается как положение камеры плюс смещение указателя внутри прямоугольника VIEWPORT.
  • Для горизонтальной координаты используется встроенная функция MOUSEX.

Пример чтения координат

PRINT MOUSEY()
PRINT MOUSEX()

Ручная проверка

  • MOUSEY: текущее положение указателя в SCREEN
  • MOUSEY: мировая координата в CANVAS

Диагностика

  • MB2004: в встроенную функцию MOUSEY переданы аргументы.
  • MB3010: встроенная функция MOUSEY вызвана без активного графического режима SCREEN и без активного CANVAS.
