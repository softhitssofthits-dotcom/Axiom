Функция MOUSEY

MOUSEY — встроенная функция языка Axiom, которая возвращает текущую вертикальную координату указателя в активном графическом режиме SCREEN. Встроенная функция MOUSEY нужна для тех же опросных сценариев, что и MOUSEX, когда программа сама решает, в какой момент ей нужен снимок текущего состояния мыши.

Для чего нужна функция MOUSEY

Встроенная функция MOUSEY нужна для чтения текущей Y-координаты указателя мыши. Функция возвращает координату в пикселях клиентской области активной поверхности SCREEN и не создаёт очередь мышиных событий и не хранит историю перемещений.

Где работает функция MOUSEY

Встроенная функция MOUSEY работает только при активном графическом режиме SCREEN. Без него выполнение сообщает диагностику MB3010. Операторы VIEW, WINDOW и PMAP не изменяют возвращаемую координату: она остаётся в клиентской системе координат активной поверхности ввода, а не в логической системе графических примитивов.

Встроенная функция MOUSEY поддерживается интерпретатором и BytecodeVm.

Синтаксис

MOUSEY()

Встроенная функция MOUSEY поддерживает только форму без аргументов.

Аргументы

У встроенной функции MOUSEY нет аргументов. Пустые скобки остаются частью вызова функции.

Что возвращает функция MOUSEY

Тип результата: LONG.

  • Если среда выполнения знает положение указателя, возвращается текущая Y-координата в клиентской области активной поверхности SCREEN.
  • Если положение указателя недоступно, возвращается -1.

Правила работы

  • Встроенная функция MOUSEY не принимает аргументов.
  • Функция читает только текущее состояние и не сообщает отдельные события перемещения.
  • Если среда не знает текущее положение указателя, функция возвращает -1.
  • Для горизонтальной координаты используется встроенная функция MOUSEX.

Пример чтения координат

PRINT MOUSEY()
PRINT MOUSEX()

Ручная проверка

  • MOUSEY: текущее положение указателя

Диагностика

  • MB2004: в встроенную функцию MOUSEY переданы аргументы.
  • MB3010: встроенная функция MOUSEY вызвана без активного графического режима SCREEN.
