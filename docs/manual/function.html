Процедуры и функции

Функция FUNCTION

FUNCTION объявляет именованную функцию, которая вычисляет значение заданного типа. Функцию можно вызывать прямо по имени, хранить в переменной функционального типа, передавать в параметр другой функции и возвращать как результат.

Сводка

У функции всегда есть объявленный тип результата. Рабочая ветвь выполнения должна завершаться формой RETURN <выражение>. Если выполнение дошло до конца функции без возвращаемого значения, возникает ошибка времени выполнения.

Если требуется хранить функцию как значение, используется функциональный тип вида FUNCTION(INTEGER, INTEGER) AS INTEGER. Он разрешён в DIM, в параметрах и в типе результата другой функции.

Если параметр или результат функции должен быть массивом, тип записывается как INTEGER(), STRING() и так далее.

Фиксированная строковая форма STRING * N в параметрах и типе результата FUNCTION сейчас не поддерживается. Для сигнатур функций используйте обычный STRING.

Синтаксис

FUNCTION <имя>([<список параметров>]) AS <тип результата>
    <инструкции>
    RETURN <выражение>
END FUNCTION
<имя>([<список аргументов>])
DIM <переменная> AS FUNCTION([<список типов параметров>]) AS <тип результата>
<переменная> = <имя>

Параметры и части синтаксиса

  • <имя> — имя функции.
  • [<список параметров>] — необязательная часть. Если параметров нет, функция объявляется с пустыми круглыми скобками.
  • <тип результата> — тип значения, которое функция обязана вернуть.
  • <выражение> — выражение, вычисляемое оператором RETURN.
  • [<список аргументов>] — необязательная часть вызова. Если аргументов нет, вызов оформляется с пустыми круглыми скобками.
  • [<список типов параметров>] — список типов внутри функционального типа. Если параметров нет, используется форма FUNCTION() AS <тип результата>.

Как и у SUB, параметры функции передаются по значению и объявляются с обязательным типом. Типом параметра или результата может быть обычный тип данных, массивный тип вида TYPE() или функциональный тип.

Если нужно принимать или возвращать текст, сигнатура функции должна использовать обычный STRING. Форма STRING * N в параметрах, в типе результата и внутри функциональных типов сейчас запрещена диагностикой MB2026.

FUNCTION IsAdult(age AS INTEGER) AS BOOLEAN
    RETURN age >= 18
END FUNCTION
FUNCTION ApplyTwice(op AS FUNCTION(INTEGER) AS INTEGER, value AS INTEGER) AS INTEGER
    RETURN op(op(value))
END FUNCTION
FUNCTION Echo(values AS INTEGER()) AS INTEGER()
    RETURN values
END FUNCTION

Замечания

  • После списка параметров функция обязана объявить тип результата через AS <тип результата>.
  • Форма RETURN <выражение> завершает выполнение функции и передаёт значение наружу.
  • Функцию можно использовать в выражении, в PRINT, в правой части присваивания и как значение функционального типа.
  • Подпрограммы SUB не являются значениями. Их нельзя присваивать переменной и передавать как аргумент.
  • Определение функции может располагаться ниже первого вызова: язык сначала объявляет имена процедур и функций, затем связывает их тела.
  • Внутри FUNCTION можно объявлять локальные SUB и FUNCTION. Их имена доступны только внутри текущей внешней процедуры или функции.
  • Локальная функция может вызываться до своего текстового объявления, потому что её имя заранее регистрируется в теле внешней процедуры или функции.
  • Локальная функция лексически захватывает параметры и локальные переменные внешней процедуры или функции, если они объявлены раньше по тексту.
  • Если такая локальная функция возвращается наружу, она сохраняет захваченные внешние данные и может быть вызвана после завершения внешней функции.
  • Внешние локальные имена, объявленные ниже по тексту после локальной FUNCTION, для неё недоступны.
  • Пустое значение функционального типа вызывать нельзя. Для него возникает отдельная ошибка времени выполнения.
  • RETURN без выражения внутри FUNCTION считается ошибкой семантики.
  • Фиксированная строковая форма STRING * N не используется в сигнатурах функций и в функциональных типах; вместо неё применяйте обычный STRING.

Ручная проверка

Для проверки объявления функции, функциональных типов и возвращаемых замыканий используйте готовые примеры.

  • FUNCTION: базовое объявление и вызов
  • FUNCTION: локальная вложенная функция
  • FUNCTION: захват внешнего параметра и локальной переменной
  • FUNCTION: функция как значение
  • FUNCTION: возвращаемая функция с захваченными данными
  • FUNCTION: общее захваченное состояние между вызовами
  • RETURN: возврат значения из FUNCTION
  • Smoke: массив как параметр и результат функции

Примеры

FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION

PRINT Square(5)
DIM op AS FUNCTION(INTEGER) AS INTEGER
op = DoubleValue
PRINT op(5)

FUNCTION DoubleValue(value AS INTEGER) AS INTEGER
    RETURN value * 2
END FUNCTION
DIM addTen AS FUNCTION(INTEGER) AS INTEGER
addTen = MakeAdder(10)
PRINT addTen(5)

FUNCTION MakeAdder(baseValue AS INTEGER) AS FUNCTION(INTEGER) AS INTEGER
    FUNCTION Add(delta AS INTEGER) AS INTEGER
        RETURN baseValue + delta
    END FUNCTION

    RETURN Add
END FUNCTION

Диагностика

  • MB2019 — попытка использовать SUB как значение.
  • MB2020 — попытка вызвать значение, которое не имеет функционального типа.
  • MB2026 — неподдержанная форма STRING * N использована в параметре, типе результата FUNCTION или внутри функционального типа.
  • MB2007 — в FUNCTION использован RETURN без выражения.
  • MB3006 — выполнение дошло до конца функции без RETURN со значением.
  • MB3009 — попытка вызвать пустое значение функционального типа.
