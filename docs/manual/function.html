Справочник/Оператор FUNCTION

11 · Процедуры и функции

Оператор FUNCTION

FUNCTION — оператор языка Axiom, который объявляет функцию с параметрами и типом возвращаемого значения. Функция вычисляет значение для присваивания, вывода, условия или другого выражения.

Назначение

Функция отделяет повторяемое вычисление от места его использования. Тип после AS определяет результат каждого успешного вызова.

Контекст объявления

Объявление доступно на верхнем уровне программы и внутри другой процедуры или функции. Объявления обрабатываются до вызовов, поэтому верхнеуровневый вызов может находиться раньше текста объявления. Локальная подпрограмма видна в своём внешнем теле и может захватывать доступные параметры и локальные переменные; внешняя локальная переменная должна быть объявлена раньше текста вложенного объявления. Графический режим не требуется.

Объявление и прямой вызов

FUNCTION <имя>([<список параметров>]) AS <тип результата>
    <инструкции>
END FUNCTION
<имя>([<список аргументов>])

Формы параметров

<имя параметра> AS <тип параметра>
BYVAL <имя параметра> AS <тип параметра>
BYREF <имя параметра> AS <тип параметра>

Функциональное значение

DIM <переменная> AS FUNCTION([<типы параметров>]) AS <тип результата>
<переменная> = <имя функции>
<переменная>([<список аргументов>])

Части записи

Имя обозначает подпрограмму. Список параметров содержит объявления через запятую. Каждый параметр задаёт имя и тип после AS; пустой список допустим. Список аргументов содержит выражения в том же порядке. Тип аргумента должен совпадать с типом параметра либо допускать предусмотренное языком преобразование.

BYVAL применяется по умолчанию и передаёт значение. Присваивание скалярному параметру не меняет переменную вызывающего кода. TYPE копируется с вложенными записями и фиксированными массивными полями; динамические массивные поля обычной длины сохраняют общий массив, как описано в правилах копирования TYPE. Обычный массив при BYVAL сохраняет общее хранилище: изменение элемента видно снаружи, хотя присваивание самому параметру другого массива не заменяет переменную вызывающего кода.

BYREF связывает параметр с простым именем переменной. Тип должен точно совпадать; преобразование аргумента не допускается. Поле записи, элемент массива и вычисляемое выражение не являются допустимым аргументом BYREF. Проверка имени CONST в текущей реализации не запрещает запись через BYREF: такая запись может изменить константу. Для изменяемого аргумента используйте обычную переменную DIM.

Тип результата определяет значение вызова. Выражение RETURN должно иметь совместимый тип. В функциональном типе перечисляются типы параметров без имён; сигнатура должна совпадать. Обычные типы, массивные типы и функциональные типы допустимы в параметрах и результате; STRING * N в этих местах не поддерживается.

Возврат и значения функций

RETURN с выражением вычисляет результат и завершает текущий вызов. Если исполнение достигает END FUNCTION без результата, возникает MB3006. Вызов функции отдельной инструкцией допускается: результат отбрасывается.

Функцию без BYREF можно сохранить в переменной, передать другой функции или вернуть как результат. Имя без скобок обозначает функциональное значение; вызов требует скобок. Функция с BYREF допускает прямые вызовы, но не может образовать функциональное значение. Неинициализированная функциональная переменная не содержит вызываемой функции.

Диагностика

MB2004 означает неверное число аргументов; MB2003 — несовместимый тип; MB2005 — неизвестное вызываемое имя. MB2028 возникает для недопустимого аргумента BYREF. Повторное имя в одной области даёт MB2002; запрещённое перекрытие внешнего имени — MB2016. Избыточная рекурсия даёт MB3011 во время выполнения.

MB2007 означает RETURN без выражения в FUNCTION. MB2029 запрещает использование функции с BYREF как значения. MB3006 означает завершение функции без возвращённого значения; MB3009 — вызов пустого функционального значения.

Пример прямого и косвенного вызова

FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION
PRINT Square(5)
DIM operation AS FUNCTION(INTEGER) AS INTEGER
operation = Square
PRINT operation(6)

Ожидаемый вывод:

25
36
