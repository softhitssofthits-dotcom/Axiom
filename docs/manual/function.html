Функция FUNCTION

Объявление функции, параметры, тип результата и возврат значения.

Процедуры и функции

Функция FUNCTION

Функция FUNCTION нужна тогда, когда фрагмент программы должен не просто выполнить действия, а вычислить и вернуть значение. В Axiom такую конструкцию используют в выражениях, присваиваниях, вызовах с параметрами и в более продвинутых сценариях, где функция сама становится значением подходящего функционального типа.

Сводка

FUNCTION ... END FUNCTION объявляет именованную функцию. Функция вычисляет значение и может использоваться в выражениях, присваиваниях и других местах, где ожидается результат совместимого типа.

Синтаксис

FUNCTION name([parameterDeclaration[, anotherParameterDeclaration] ...]) AS resultType
    [statements]
    RETURN expression
END FUNCTION
name([argument[, anotherArgument] ...])
DIM variable AS FUNCTION([parameterType[, anotherParameterType] ...]) AS resultType
variable = name

Части записи

name задаёт имя функции.

parameterDeclaration обозначает объявление параметра вида parameterName AS parameterType.

resultType задаёт тип возвращаемого значения.

statements обозначает любые допустимые инструкции внутри функции.

expression задаёт значение, которое возвращается оператором RETURN.

argument обозначает значение, передаваемое при вызове функции. В функциональном типе после слова FUNCTION перечисляются только типы параметров, без имён.

Замечания

Обычно FUNCTION выбирают в тех случаях, где результат вычисления должен естественно встраиваться в остальной код: например, участвовать в арифметике, проверке условий, формировании строк или передаваться дальше как значение.

  • После списка параметров функция обязана объявить тип результата через AS.
  • В рабочей ветви выполнения функция должна завершаться формой RETURN expression.
  • Если выполнение дошло до конца функции без возвращаемого значения, возникает ошибка времени выполнения.
  • Параметры функции в текущей реализации передаются по значению.
  • Функцию можно использовать как значение, если ожидается совместимый функциональный тип.
  • Типом параметра или результата может быть обычный тип, массивный тип вида INTEGER(), STRING() и так далее, а также функциональный тип.
  • Форма STRING * N в параметрах, в типе результата и внутри функциональных типов сейчас не поддерживается.
  • Внутри FUNCTION можно объявлять локальные SUB и локальные FUNCTION.
  • Локальная функция может захватывать параметры и локальные переменные внешней функции, если эти имена объявлены раньше по тексту.

Пример

' Функция возвращает квадрат числа, поэтому программа печатает 25
' Ожидаемый вывод: 25
FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION

PRINT Square(5)

Ручная проверка

  • FUNCTION: базовое объявление и вызов
  • FUNCTION: локальная вложенная функция
  • FUNCTION: захват внешнего параметра и локальной переменной
  • FUNCTION: функция как значение
  • FUNCTION: возвращаемая функция
  • RETURN: возврат значения из FUNCTION

Диагностика

Ошибки возникают, если в FUNCTION используется RETURN без выражения, если выполнение доходит до конца функции без возврата результата, если вызывается значение неверного типа или если в сигнатуре используется неподдержанная форма STRING * N.
