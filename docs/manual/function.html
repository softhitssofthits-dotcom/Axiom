Функция FUNCTION

Функция FUNCTION описывает именованное вычисление. Она принимает параметры, выполняет инструкции и возвращает одно значение заданного типа. Поэтому функцию можно использовать в выражении: напечатать результат, присвоить его переменной, передать дальше или проверить в условии.

Когда нужен вычисляемый результат

FUNCTION ... END FUNCTION объявляет функцию. Тип результата указывается после списка параметров через AS. Возврат значения выполняется оператором RETURN <выражение>; если выполнение дошло до конца функции без такого возврата, это ошибка времени выполнения.

Синтаксис

FUNCTION <имя>([<список параметров>]) AS <тип результата>
    <инструкции>
    RETURN <выражение>
END FUNCTION
<имя>([<список аргументов>])
DIM <переменная> AS FUNCTION([<типы параметров>]) AS <тип результата>
<переменная> = <имя функции>
[BYVAL | BYREF] <имя параметра> AS <тип параметра>

Части записи

<имя> - имя объявляемой функции или имя функции при вызове.

<список параметров> - объявления параметров через запятую. Каждый параметр имеет тип; BYVAL действует по умолчанию.

BYVAL и BYREF - модификаторы параметра. Они не являются операторами и не возвращают значение; они только задают, получит функция копию значения или связь с исходной переменной.

<тип результата> - тип значения, которое функция должна вернуть.

<выражение> - значение, возвращаемое оператором RETURN. Его тип должен быть совместим с типом результата функции.

<типы параметров> в функциональном типе перечисляют только типы, без имён параметров.

Где работает функция FUNCTION

Объявление FUNCTION допустимо в любом контексте программы: на верхнем уровне, внутри процедуры SUB или другой функции. Функция не зависит от графического режима SCREEN и может работать в текстовом, графическом и консольном режимах одинаково.

RETURN и тип результата

  • Функция возвращает одно значение и может быть частью выражения.
  • В FUNCTION допустима только форма RETURN <выражение>.
  • Параметры без модификатора передаются как BYVAL: функция получает отдельное значение, а для записи TYPE - копию записи.
  • BYREF требует простой переменной в месте вызова и позволяет функции изменить эту переменную до возврата результата.
  • Для BYREF сейчас нельзя передавать выражение, поле записи или элемент массива: total + 1, user.Name и items(1) не являются допустимыми BYREF-аргументами.
  • Функцию можно использовать как значение функционального типа, если сигнатура совместима и в ней нет параметров BYREF.
  • Внутри функции можно объявлять локальные SUB и FUNCTION; локальные функции могут захватывать объявленные раньше внешние имена.
  • Типом параметра или результата может быть обычный тип, массивный тип вроде INTEGER() или функциональный тип. Форма STRING * N в таких местах сейчас не поддерживается.

В QuickBASIC функция FUNCTION была более современной заменой DEF FN, могла участвовать в выражениях и обычно возвращала результат через присваивание имени функции. В Axiom DEF FN не используется, а результат явно возвращается оператором RETURN.

Пример вызова FUNCTION

' Ожидаемый вывод: 25
FUNCTION Square(value AS INTEGER) AS INTEGER
    RETURN value * value
END FUNCTION

PRINT Square(5)

Ручная проверка

  • FUNCTION: базовое объявление и вызов
  • FUNCTION: локальная вложенная функция
  • FUNCTION: захват внешней переменной
  • FUNCTION: функция как значение
  • FUNCTION: возвращаемая функция
  • FUNCTION: общее состояние замыкания
  • RETURN: возврат значения из FUNCTION

Ограничение: BYREF и значения функций

Функцию с параметром BYREF нельзя передавать как значение функционального типа. Это ограничение существует потому, что BYREF требует простой переменной в месте вызова, а значение функции может быть вызвано из любого контекста, где подходящей переменной может не быть.

SUB Modify(BYREF value AS INTEGER)
    value = value + 1
END SUB

' Нельзя: Modify имеет параметр BYREF
' DIM action AS SUB(INTEGER)
' action = Modify

Функции без параметров BYREF можно свободно использовать как значения, передавать в другие функции и возвращать из функций.

Диагностика

Ошибка возникает, если функция объявлена без типа результата, если RETURN внутри FUNCTION не возвращает значение, если возвращаемое выражение несовместимо с типом результата, если функция завершается без RETURN со значением или если функция с параметром BYREF используется как функциональное значение.

  • MB2003 — возвращаемое выражение несовместимо с объявленным типом результата.
  • MB2007 — внутри FUNCTION записан RETURN без выражения.
  • MB2029 — функция с параметром BYREF используется как функциональное значение.
  • MB3006 — выполнилась ветвь FUNCTION, которая завершается без RETURN со значением; ошибка времени выполнения.
