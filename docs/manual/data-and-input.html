Консольный ввод и вывод

Начальное значение программа может взять из исходного текста, а может запросить во время выполнения, и полученный результат нужно показать. Обмен такими данными с пользователем ведут два оператора: PRINT выводит значения, INPUT получает ответ и записывает его в переменную. Остальные статьи главы уточняют, как устроен каждый из них и где появляется текст.

Запрос значения и вывод результата

Программа может использовать начальное значение из исходного текста или запросить его во время выполнения. В следующем примере вводится количество, затем вычисляется удвоенное значение:

DIM count AS INTEGER
INPUT "Введите количество"; count
PRINT "Удвоенное значение: "; count * 2

Если ввести 3, итоговая строка будет Удвоенное значение: 6. Приглашение INPUT с точкой с запятой дополняется вопросом и пробелом, поэтому запрос заканчивается знаком вопроса, а ответ попадает в count до вычисления произведения.

Где отображается текст

Куда попадёт текст, зависит от того, выбран ли экранный режим. Без оператора SCREEN IDE использует консоль; после выбора экрана текстовый вывод и запрос ввода могут отображаться в окне SCREEN. Правила экранного текста описаны в графической главе.

Статьи главы

Вывод и ввод решают разные половины одной задачи, поэтому описываются отдельно; текст внутри графического экрана подчиняется собственным правилам.
