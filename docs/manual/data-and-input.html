Обзор

Типы данных, объявления и ввод

Работа с данными в Axiom начинается не с одной отдельной конструкции, а с целой связки тем: какие значения вообще существуют в языке, как объявлять переменные и константы и каким образом считывать или выводить результат. Эта обзорная страница помогает пройти этот маршрут без лишних повторов точной справки.

Как устроен раздел

Здесь собраны входные точки для тех случаев, когда вы ещё не ищете одну конкретную форму синтаксиса, а хотите сначала понять, где именно находится нужная тема. Обычно это бывает в самом начале работы с языком или при переходе от простых выражений к реальному вводу и выводу данных.

  • сначала полезно понять модель типов и допустимых значений;
  • затем обычно возникает задача объявить переменную или константу;
  • после этого уже нужно либо считать данные через INPUT, либо показать результат через PRINT.

Сводка

Этот раздел особенно полезен тогда, когда нужно связать между собой типы данных, объявления и ввод-вывод, а не рассматривать их как разрозненные статьи.

  • когда нужно понять, с какой справочной главы начать работу с данными;
  • когда требуется перейти от типов данных к объявлениям, а затем к INPUT и PRINT;
  • когда нужна короткая карта раздела без повторения синтаксиса, диагностики и пограничных случаев на одной странице.

Куда переходить дальше

Типы данных

INTEGER, LONG, DOUBLE, DECIMAL, STRING и BOOLEAN, а также основные правила преобразования.

Переменные и константы

Правила именования, DIM, CONST, инициализация и область видимости.

Оператор INPUT

Чтение одного или нескольких значений, строка приглашения, преобразование типов и частые ошибки.

Функция INKEY

Неблокирующее чтение одной клавиши: символ, имя специальной клавиши или пустая строка.

Функция KEYDOWN

Проверка текущего удержания клавиши или модификатора без чтения очереди клавиатуры.

Функция KEYPRESS

Одноразовая проверка нажатия клавиши с удалением события из очереди.

Функция MOUSEX

Текущая горизонтальная координата указателя мыши на активной поверхности программы.

Функция MOUSEY

Текущая вертикальная координата указателя мыши на активной поверхности программы.

Функция MOUSEBUTTON

Проверка удержания левой, правой или средней кнопки мыши по номеру.

Функция MOUSEPRESS

Одноразовая проверка нажатия кнопки мыши с удалением события из очереди.

Оператор ON MOUSE

Обработчик нажатия, отпускания, перемещения и колеса мыши с режимами включения, паузы и отключения.

Оператор PRINT

Вывод строк, чисел, выражений и списков значений с разделителями ; и ,.

Как читать раздел

Если идти по этой теме последовательно, manual обычно удобнее читать именно в таком порядке.

  1. Если важно понять, какие значения можно хранить в программе, начинайте со статьи о типах данных.
  2. Если нужно объявить переменную или константу, переходите к статье о DIM и CONST.
  3. Если нужно считать данные с клавиатуры, мыши или вывести результат, открывайте статьи по INPUT, INKEY(), KEYDOWN(), KEYPRESS(), MOUSEX(), MOUSEY(), MOUSEBUTTON(), MOUSEPRESS(), ON MOUSE и PRINT.
DIM name AS STRING
DIM age AS INTEGER

INPUT "Введите имя: "; name
INPUT "Введите возраст: "; age

PRINT "Пользователь:"; name
PRINT "Возраст:"; age

В этом коротком фрагменте сразу видно весь маршрут раздела: сначала объявляются переменные, затем значения читаются из ввода и после этого выводятся обратно в понятной форме.

Показательные примеры

Для проверки этого маршрута через IDE достаточно открыть несколько коротких файлов из соседних тем.

  • DIM: вывод типа из инициализатора
  • DIM: явный DECIMAL
  • CONST: базовое объявление
  • INPUT: несколько переменных
  • INKEY: опрос клавиатуры в цикле
  • KEYDOWN: удержание модификатора и стрелки
  • KEYDOWN: канонические имена и алиасы клавиш
  • KEYPRESS: одиночное нажатие клавиши
  • KEYPRESS: нажатие с модификатором
  • MOUSEPRESS: одноразовые нажатия кнопок мыши
  • ON MOUSE: обработчик левой кнопки мыши
  • ON MOUSE: отпускание и перемещение
  • ON MOUSE: колесо мыши
  • ON KEY: обработчик любой клавиши
  • ON KEY: имя клавиши в обработчике
  • ON KEY: аккорд клавиш
  • ON KEY: пауза и возобновление обработчика
  • PRINT: разделитель ;
