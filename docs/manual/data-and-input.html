Раздел

Данные, ввод и вывод

Раздел данных, ввода и вывода описывает путь значения от объявления имени до результата на экране: DIM и CONST задают имена, INPUT получает строку от пользователя и разбирает её по типам, опросные функции клавиатуры и мыши читают текущее состояние или очередь событий, а PRINT выводит готовые значения. Если ввод должен сам вызывать реакцию программы между обычными операторами, этот же слой продолжается через ON KEY и ON MOUSE.

Источники данных

В простейшем случае значение уже записано в тексте программы как число, строка или логическая константа. В более живой программе оно появляется после вычисления, чтения строки ввода, нажатия клавиши, действия мыши или файловой операции. Для языка это всё разные источники, но дальнейший маршрут одинаков: значение должно иметь тип, имя или место назначения и понятный способ вывода.

DIM name AS STRING
DIM age AS INTEGER

INPUT "Имя: "; name
INPUT "Возраст: "; age

PRINT "Пользователь: " & name
PRINT "Возраст: " & age

Пример показывает основную цепочку: сначала объявляются места для значений, затем INPUT заполняет их пользовательским вводом, после чего PRINT возвращает результат на экран.

Объявление переменных

Имя в программе полезно только тогда, когда известно, какие значения оно может держать. Для одного числа, строки или логического результата подходят скалярные типы. Для набора однотипных значений используется массив. Для записи с несколькими полями служит TYPE. Для открытого текстового файла используется отдельный тип FILE.

Типы данных

Общая карта чисел, строк, логических значений, файлов, записей, массивов и функциональных типов.

Скалярные типы

INTEGER, LONG, DOUBLE, DECIMAL и BOOLEAN, включая диапазоны чисел.

STRING и FILE

Обычные строки, фиксированные строки STRING * N и файловое значение FILE.

TYPE и массивы

Как отличить одну запись, массив значений, массив записей и массивное поле внутри записи.

Переменные и константы

Имена, область видимости, изменяемые переменные и неизменяемые значения.

Оператор DIM

Объявление переменных, массивов, явного типа и типа, выведенного из начального значения.

Оператор CONST

Именованные значения, которые задаются один раз и потом не изменяются.

Чтение ввода

INPUT останавливает программу в точке, где нужен ответ пользователя, и разбирает введённую строку в одну или несколько переменных. Если программа не должна ждать полной строки, применяются неблокирующие функции клавиатуры и мыши. В этом слое полезно различать три режима: текущее состояние устройства, одноразовое чтение события из очереди и событийный обработчик, который вызывается между обычными операторами программы.

Оператор INPUT

Ввод одного или нескольких значений, приглашение, разделение по запятым и преобразование к типам переменных.

Функция INKEY

Читает одно событие клавиатуры без ожидания; если события нет, возвращает пустую строку.

Функция KEYDOWN

Проверяет, удерживается ли клавиша или сочетание клавиш прямо сейчас.

Функция KEYPRESS

Проверяет одноразовое нажатие и забирает подходящее событие из очереди.

MOUSEX и MOUSEY

Возвращают текущие координаты указателя: в SCREEN это клиентские координаты окна, а в CANVAS — мировые координаты по договору VIEWPORT и CAMERA.

MOUSEBUTTON

Проверяет текущее удержание кнопки мыши, не расходуя очередь нажатий.

MOUSEPRESS

Проверяет одноразовое нажатие кнопки мыши и удаляет подходящее событие из очереди, если обработчик ON MOUSE его ещё не перехватил.

ON KEY

Назначает обработчик клавиши, сочетания клавиш или запасной обработчик для любой клавиши.

ON MOUSE

Назначает обработчик нажатия, отпускания, перемещения или колеса мыши и передаёт те же координаты, которые в этот момент возвращают MOUSEX() и MOUSEY().

Для мыши это особенно важно в графическом окне. При активном SCREEN функции MOUSEX() и MOUSEY() возвращают координаты клиентской области окна и не переводятся в логическую систему рисования через VIEW, WINDOW или PMAP. При активном CANVAS те же функции и параметры x/y обработчика ON MOUSE уже возвращают мировые координаты по договору VIEWPORT и CAMERA.

Вывод результата

PRINT завершает обычный путь данных: берёт готовое значение или выражение и показывает его пользователю. Пока программа не выбрала SCREEN, вывод идёт в обычный поток вывода. После SCREEN 0 или графического режима SCREEN 1..10 тот же вывод направляется в отдельное окно программы.

Оператор PRINT

Вывод одного значения, списка значений, пустой строки и разделителей ; и ,.

Оператор SCREEN

Переключение в текстовое окно SCREEN 0 или графический режим SCREEN 1..10.

Текст на экране

CLS, COLOR и LOCATE для вывода текста в экранном окне.

Связанные разделы

  1. Если непонятно, какой тип выбрать, начните с типов данных и скалярных типов.
  2. Если нужно сохранить значение, откройте DIM или CONST.
  3. Если нужно получить ввод строкой, начните с INPUT, а для неблокирующего опроса переходите к клавиатурным и мышиным функциям.
  4. Если по мыши нужна текущая координата или удержание, идите к MOUSEX() / MOUSEY() и MOUSEBUTTON(); если нужно одноразовое нажатие из очереди, открывайте MOUSEPRESS(); если нужен обработчик, переходите к ON MOUSE.
  5. Если нужно показать результат, переходите к PRINT и, при необходимости, к SCREEN.

Запускаемые примеры

Эти примеры можно открыть в Axiom.Ide и запустить как короткие проверки объявления, ввода, клавиатуры, мыши и вывода.

  • DIM: вывод типа из начального значения
  • CONST: базовое объявление
  • INPUT: несколько переменных
  • INKEY: опрос клавиатуры в цикле
  • KEYDOWN: удержание клавиши
  • KEYPRESS: одиночное нажатие
  • MOUSEPRESS: нажатия кнопок мыши
  • ON MOUSE: обработчик левой кнопки мыши
  • ON KEY: обработчик любой клавиши
  • PRINT: разделитель ;
