Раздел

Сборка даты и календарные части

Раздел сборки даты и календарных частей описывает функции DATESERIAL, TIMESERIAL, YEAR, MONTH, DAY, HOUR, MINUTE, SECOND, WEEKDAY и WEEKYEAR — построение канонических значений и извлечение календарных компонентов.

DATESERIAL

Функция DATESERIAL строит строку даты из года, месяца и дня.

Синтаксис

result = DATESERIAL(year, month, day)

Части записи. year, month и day задают числовые компоненты даты. Результат возвращается как строка формата yyyy-MM-dd.

Проверка реальной календарной даты

Компоненты должны образовывать реальную календарную дату. Автоматического переноса переполненных значений вроде тринадцатого месяца здесь нет.

TIMESERIAL

Функция TIMESERIAL строит строку времени из часов, минут и секунд.

Синтаксис

result = TIMESERIAL(hour, minute, second)

Части записи. hour, minute и second задают числовые компоненты времени. Результат возвращается как строка формата HH:mm:ss.

YEAR, MONTH, DAY

Эти функции извлекают из канонической даты или даты-времени год, номер месяца и номер дня.

Синтаксис

result = YEAR(value)
result = MONTH(value)
result = DAY(value)

Части записи. value задаёт строку даты или даты-времени в каноническом формате. Результат каждой функции имеет тип INTEGER.

HOUR, MINUTE, SECOND

Эти функции извлекают из канонического времени или даты-времени часы, минуты и секунды.

Синтаксис

result = HOUR(value)
result = MINUTE(value)
result = SECOND(value)

WEEKDAY и WEEKDAYNAME

WEEKDAY возвращает номер дня недели, а WEEKDAYNAME его полное английское имя.

Синтаксис

result = WEEKDAY(value)
result = WEEKDAYNAME(weekday)

Части записи. Для WEEKDAY аргумент value задаёт строку даты или даты-времени. Функция возвращает номер по схеме 1 = Monday, 7 = Sunday. Для WEEKDAYNAME аргумент weekday задаёт номер дня недели.

MONTHNAME

Функция MONTHNAME возвращает полное английское имя месяца по его номеру.

Синтаксис

result = MONTHNAME(month)

ISLEAPYEAR, DAYSINMONTH, STARTOFMONTH, ENDOFMONTH, STARTOFYEAR, ENDOFYEAR

Эти функции проверяют свойства календаря и возвращают границы месяца или года.

Синтаксис

result = ISLEAPYEAR(year)
result = DAYSINMONTH(year, month)
result = STARTOFMONTH(value)
result = ENDOFMONTH(value)
result = STARTOFYEAR(value)
result = ENDOFYEAR(value)

Части записи. ISLEAPYEAR возвращает BOOLEAN, DAYSINMONTH возвращает INTEGER, а функции начала и конца месяца или года возвращают строку даты формата yyyy-MM-dd.

Пример сборки и чтения даты

' Сборка даты и работа с календарными частями
PRINT DATESERIAL(2026, 4, 20)
PRINT YEAR("2026-04-20 14:05:06")
PRINT MONTHNAME(4)
PRINT WEEKDAYNAME(WEEKDAY("2026-04-26"))
PRINT DAYSINMONTH(2024, 2)
PRINT ENDOFMONTH("2024-02-11")

Диагностика

  • Неверные компоненты в DATESERIAL и TIMESERIAL приводят к ошибке аргумента встроенной функции.
  • Значения вне диапазона для MONTHNAME, WEEKDAYNAME, ISLEAPYEAR и DAYSINMONTH также считаются ошибкой аргумента.

Ручная проверка

  • DATESERIAL: построение даты
  • TIMESERIAL: построение времени
  • YEAR: извлечение года
  • MONTHNAME: имя месяца
  • WEEKDAYNAME: имя дня недели
  • DAYSINMONTH: количество дней в месяце
