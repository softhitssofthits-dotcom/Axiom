Поиск и замена подстрок

В этом разделе описаны встроенные функции языка Axiom CONTAINS, STARTSWITH, ENDSWITH, INSTR, INSTRREV, SUBSTRCOUNT, REPLACE, REPLACEMANY. Они обрабатывают текст и возвращают результат без изменения исходной строки. Ниже приведён отдельный синтаксис и договор каждой функции.

CONTAINS

CONTAINS — встроенная функция языка Axiom, которая проверяет, содержит ли строка указанный фрагмент.

Назначение и контекст

Функция позволяет проверить наличие слова или фрагмента внутри текста.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма вызова:

CONTAINS(<текст>, <фрагмент>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.
<фрагмент>Передайте строку типа STRING, которую требуется найти в исходном тексте.

Возвращаемое значение

Функция возвращает логическое значение типа BOOLEAN: TRUE при выполнении условия и FALSE в остальных случаях.

Правила и пограничные случаи

Сравнение точное, с учётом регистра, без нормализации Unicode. Пустой фрагмент всегда даёт TRUE, в том числе для пустого текста. Непустой фрагмент в пустом тексте даёт FALSE.

Диагностика

Неверные типы и число аргументов отклоняются при проверке программы.

Пример

PRINT CONTAINS("Abc", "b")
PRINT CONTAINS("Abc", "B")
PRINT CONTAINS("", "")

Программа выводит:

TRUE
FALSE
TRUE

INSTR

INSTR — встроенная функция языка Axiom, которая возвращает позицию первого вхождения фрагмента в строку.

Назначение и контекст

Функция нужна, когда важно не только наличие фрагмента, но и его расположение.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма 1:

INSTR(<текст>, <фрагмент>)

Форма 2:

INSTR(<начальная позиция>, <текст>, <фрагмент>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.
<фрагмент>Передайте строку типа STRING, которую требуется найти в исходном тексте.
<начальная позиция>Передайте целое число типа INTEGER с начальной позицией. Позиции отсчитываются от 1.

Возвращаемое значение

Функция возвращает целое число типа INTEGER — позицию начала совпадения в кодовых единицах UTF-16, считая от 1. Если совпадения нет, результат равен 0.

Правила и пограничные случаи

Без начальной позиции поиск начинается с 1. Сравнение учитывает регистр. Начало больше длины текста плюс 1 даёт 0. Пустой фрагмент возвращает начальную позицию, если она не больше длины текста плюс 1; поэтому INSTR("", "") возвращает 1.

Диагностика

Ошибка MB3007 возникает, если явно заданное начало меньше 1.

Пример

PRINT INSTR("abcabc", "bc")
PRINT INSTR(4, "abcabc", "bc")
PRINT INSTR("", "")

Программа выводит:

2
5
1

INSTRREV

INSTRREV — встроенная функция языка Axiom, которая возвращает позицию вхождения фрагмента, найденного при поиске справа налево.

Назначение и контекст

Функция позволяет найти последнее вхождение или искать назад от заданной позиции.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма 1:

INSTRREV(<текст>, <фрагмент>)

Форма 2:

INSTRREV(<начальная позиция>, <текст>, <фрагмент>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.
<фрагмент>Передайте строку типа STRING, которую требуется найти в исходном тексте.
<начальная позиция>Передайте положительное целое число типа INTEGER с правой границей поиска в кодовых единицах UTF-16. Без аргумента используется длина строки; значение больше длины ограничивается её длиной.

Возвращаемое значение

Функция возвращает целое число типа INTEGER — позицию начала найденного фрагмента, считая от 1. Если совпадения нет, результат равен 0.

Правила и пограничные случаи

Сравнение учитывает регистр. Пустой фрагмент возвращает правую границу поиска плюс 1. Особый случай: INSTRREV("", "") без начальной позиции возвращает 0, а INSTRREV(1, "", "") возвращает 1.

Диагностика

Ошибка MB3007 возникает, если явно заданное начало меньше 1.

Пример

PRINT INSTRREV("abcabc", "bc")
PRINT INSTRREV(3, "abcabc", "bc")
PRINT INSTRREV("", "")
PRINT INSTRREV(1, "", "")

Программа выводит:

5
2
0
1

SUBSTRCOUNT

SUBSTRCOUNT — встроенная функция языка Axiom, которая возвращает количество неперекрывающихся вхождений фрагмента в строку.

Назначение и контекст

Функция подходит для подсчёта слов, разделителей или других точных фрагментов.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма вызова:

SUBSTRCOUNT(<текст>, <фрагмент>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.
<фрагмент>Передайте непустую строку типа STRING с подсчитываемым фрагментом.

Возвращаемое значение

Функция возвращает неотрицательное целое число типа INTEGER.

Правила и пограничные случаи

Сравнение учитывает регистр. После совпадения поиск продолжается за его концом; перекрывающиеся вхождения не считаются. Пустой текст с непустым фрагментом даёт 0.

Диагностика

Ошибка MB3007 возникает, если искомый фрагмент пуст.

Пример

PRINT SUBSTRCOUNT("aaaa", "aa")
PRINT SUBSTRCOUNT("", "a")

Программа выводит:

2
0

REPLACE

REPLACE — встроенная функция языка Axiom, которая возвращает строку, заменив все точные вхождения одного фрагмента другим.

Назначение и контекст

Функция нужна для обычной текстовой замены без регулярного выражения.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма вызова:

REPLACE(<текст>, <исходный текст>, <новый текст>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.
<исходный текст>Передайте непустую строку типа STRING с заменяемым фрагментом.
<новый текст>Передайте строку типа STRING с текстом замены. Пустая строка удаляет найденные фрагменты.

Возвращаемое значение

Функция возвращает строку типа STRING после замены.

Правила и пограничные случаи

Сравнение учитывает регистр. Если совпадений нет или исходный текст пуст, возвращается исходный текст. Новые фрагменты не обрабатываются повторно в том же вызове.

Диагностика

Ошибка MB3007 возникает при пустом заменяемом фрагменте, даже если исходный текст пуст.

Пример

PRINT REPLACE("A a A", "A", "B")
PRINT REPLACE("banana", "na", "")

Программа выводит:

B a B
ba

REPLACEMANY

REPLACEMANY — встроенная функция языка Axiom, которая возвращает строку после одновременной замены нескольких фрагментов по двум массивам правил.

Назначение и контекст

Функция позволяет применить набор замен за один проход без повторной обработки уже вставленного текста.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма вызова:

REPLACEMANY(<текст>, <исходные элементы>, <новые элементы>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.
<исходные элементы>Передайте одномерный массив строк STRING() с заменяемыми непустыми фрагментами.
<новые элементы>Передайте одномерный массив строк STRING() с соответствующими заменами. Длина должна совпадать с длиной массива исходных фрагментов; нижние границы могут различаться.

Возвращаемое значение

Функция возвращает строку типа STRING. Правила сопоставляются по порядку элементов массивов, а не по совпадению их индексов.

Правила и пограничные случаи

Сравнение учитывает регистр. В каждой позиции выигрывает самый длинный подходящий фрагмент; при равной длине выбирается первое правило. Текст замены не просматривается повторно. Пустые или невыделенные массивы трактуются как наборы без правил; при двух таких наборах результат совпадает с исходным текстом.

Диагностика

Ошибка MB3007 возникает при разных длинах наборов правил или пустой строке в массиве заменяемых фрагментов. Эти проверки выполняются и для пустого исходного текста.

Пример

DIM oldItems(5 TO 6) AS STRING
DIM newItems(8 TO 9) AS STRING
oldItems(5)="ab"
oldItems(6)="a"
newItems(8)="X"
newItems(9)="Y"
PRINT REPLACEMANY("aba", oldItems, newItems)

Программа выводит:

XY
