Проверка наличия фрагмента, поиск позиции и замена текста.

Строковые функции

Поиск и замена в строках

CONTAINS, STARTSWITH, ENDSWITH

Эти функции проверяют, содержит ли строка фрагмент, начинается ли она с него и заканчивается ли им.

Синтаксис

result = CONTAINS(text, fragment)
result = STARTSWITH(text, fragment)
result = ENDSWITH(text, fragment)

Замечания

Поиск выполняется с учётом регистра. Пустой фрагмент считается найденным.

REPLACE

Функция REPLACE заменяет все найденные вхождения фрагмента.

Синтаксис

result = REPLACE(text, oldText, newText)

Замечания

Пустой заменяемый фрагмент даёт MB3007.

REPLACEMANY

REPLACEMANY применяет таблицу строковых замен за один проход по исходной строке. Функция нужна для случаев, где обычная цепочка из многих REPLACE слишком дорога: нормализация текста, исправление кодировки, пакетная замена маркеров.

Синтаксис

result = REPLACEMANY(text, oldItems, newItems)

Аргументы

oldItems и newItems должны быть одномерными массивами строк одинаковой длины. Элемент oldItems(i) задаёт искомый фрагмент, а newItems(i) — замену для него.

Замечания

Поиск выполняется с учётом регистра и по точному порядковому сравнению символов. В каждой позиции выбирается самое длинное совпадение из таблицы; при равной длине используется более раннее правило. Пустой элемент в oldItems и разная длина массивов дают MB3007.

DIM oldItems(1 TO 2) AS STRING
DIM newItems(1 TO 2) AS STRING
oldItems(1) = "ab"
newItems(1) = "X"
oldItems(2) = "abc"
newItems(2) = "Y"
PRINT REPLACEMANY("abc ab", oldItems, newItems)

INSTR и INSTRREV

Функции INSTR и INSTRREV возвращают позицию найденного фрагмента, считая с единицы.

Синтаксис

position = INSTR([start, ]text, fragment)
position = INSTRREV([start, ]text, fragment)

Замечания

Если аргумент start не указан, поиск начинается с естественного начала или конца строки. Если совпадение не найдено, результат равен 0.

SUBSTRCOUNT

Функция SUBSTRCOUNT считает непересекающиеся вхождения фрагмента.

Синтаксис

count = SUBSTRCOUNT(text, fragment)

Пример

PRINT CONTAINS("banana", "na")
PRINT STARTSWITH("banana", "ba")
PRINT ENDSWITH("banana", "na")
PRINT REPLACE("banana", "na", "NA")
PRINT INSTR("banana", "na")
PRINT INSTRREV("banana", "na")
PRINT SUBSTRCOUNT("banana", "na")
