Раздел

Поиск и замена в строках

Раздел поиска и замены описывает функции CONTAINS, STARTSWITH, ENDSWITH, INSTR, INSTRREV, SUBSTRCOUNT, REPLACE и REPLACEMANY — средства проверки наличия фрагмента, поиска позиции и замены текста.

Функции поиска отвечают на два разных вопроса: есть ли в строке нужный фрагмент и в какой позиции он находится. Функции замены строят новую строку, где найденные фрагменты заменены другим текстом.

CONTAINS, STARTSWITH, ENDSWITH

Эти функции проверяют, содержит ли строка фрагмент, начинается ли она с него и заканчивается ли им.

Синтаксис

result = CONTAINS(text, fragment)
result = STARTSWITH(text, fragment)
result = ENDSWITH(text, fragment)

Аргументы

text задаёт исходную строку, fragment задаёт искомый фрагмент.

Правила сравнения

Поиск выполняется с учётом регистра. Пустой фрагмент считается найденным. Результат имеет тип BOOLEAN.

Пример проверки наличия фрагмента

PRINT CONTAINS("banana", "na")
PRINT STARTSWITH("banana", "ba")
PRINT ENDSWITH("banana", "na")

Результат:

TRUE
TRUE
TRUE

REPLACE

Функция REPLACE заменяет все найденные вхождения фрагмента.

Синтаксис

result = REPLACE(text, oldText, newText)

Аргументы

text задаёт исходную строку, oldText задаёт заменяемый фрагмент, newText задаёт текст замены.

Ограничение заменяемого фрагмента

Пустой заменяемый фрагмент даёт MB3007.

Пример замены всех вхождений

PRINT REPLACE("banana", "na", "NA")

Результат:

baNANA

REPLACEMANY

REPLACEMANY применяет таблицу строковых замен за один проход по исходной строке. Функция нужна для случаев, где обычная цепочка из многих REPLACE слишком дорога: нормализация текста, исправление кодировки, пакетная замена маркеров.

Синтаксис

result = REPLACEMANY(text, oldItems, newItems)

Аргументы

oldItems и newItems должны быть одномерными массивами строк одинаковой длины. Элемент oldItems(i) задаёт искомый фрагмент, а newItems(i) — замену для него.

Порядок применения правил

Поиск выполняется с учётом регистра и по точному порядковому сравнению символов. В каждой позиции выбирается самое длинное совпадение из таблицы; при равной длине используется более раннее правило. Пустой элемент в oldItems и разная длина массивов дают MB3007.

Пример табличной замены

DIM oldItems(1 TO 2) AS STRING
DIM newItems(1 TO 2) AS STRING
oldItems(1) = "ab"
newItems(1) = "X"
oldItems(2) = "abc"
newItems(2) = "Y"
PRINT REPLACEMANY("abc ab", oldItems, newItems)

Результат:

Y X

INSTR и INSTRREV

Функции INSTR и INSTRREV возвращают позицию найденного фрагмента, считая с единицы.

Синтаксис

Поиск INSTR от начала строки:

position = INSTR(text, fragment)

Поиск INSTR от указанной позиции:

position = INSTR(start, text, fragment)

Поиск INSTRREV от конца строки:

position = INSTRREV(text, fragment)

Поиск INSTRREV в части строки до указанной позиции включительно:

position = INSTRREV(start, text, fragment)

Аргументы

text задаёт исходную строку, fragment задаёт искомый фрагмент. Необязательный start задаёт начальную позицию поиска.

Начальная позиция и отсутствие совпадения

Если аргумент start не указан, поиск начинается с естественного начала или конца строки. Если совпадение не найдено, результат равен 0.

Позиции INSTR и INSTRREV считаются с единицы в единицах UTF-16. Эмодзи вне основной плоскости занимает две позиции: в строке А😀Б буква Б находится на позиции 4. Поиск сравнивает точные единицы UTF-16, учитывает регистр и не нормализует Unicode. Поэтому é и e с отдельным знаком ударения различаются.

Аргумент start должен быть целым числом не меньше 1; иначе возникает MB3007. Для INSTR позиция правее LEN(text) + 1 даёт 0. Для INSTRREV слишком большая позиция ограничивается концом строки; найденный фрагмент должен целиком помещаться до этой позиции.

Пустой fragment имеет отдельный договор: INSTR возвращает допустимую начальную позицию, включая позицию сразу после строки; INSTRREV с явным start возвращает меньшее из start и LEN(text), увеличенное на 1. Без start вызов INSTRREV("", "") возвращает 0, а INSTRREV(1, "", "") — 1. 

PRINT INSTR("А😀Б", "Б")       ' 4
PRINT INSTRREV(3, "А😀Б", "😀") ' 2
PRINT INSTR(4, "abc", "")      ' 4

Позиции Unicode и извлечение найденного фрагмента

Пример поиска позиции

PRINT INSTR("banana", "na")
PRINT INSTRREV("banana", "na")

Результат:

3
5

SUBSTRCOUNT

Функция SUBSTRCOUNT считает непересекающиеся вхождения фрагмента.

Синтаксис

count = SUBSTRCOUNT(text, fragment)

Аргументы

text задаёт исходную строку, fragment задаёт искомый фрагмент.

Пустой fragment вызывает MB3007, даже если исходная строка пустая. Пустая исходная строка с непустым fragment даёт 0. Подсчёт использует точное сравнение UTF-16 и не учитывает перекрывающиеся вхождения: SUBSTRCOUNT("aaa", "aa") возвращает 1.

Пример подсчёта вхождений

PRINT SUBSTRCOUNT("banana", "na")

Результат:

2
