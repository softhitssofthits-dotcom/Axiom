Строковые литералы и интерполяция

Строковый литерал — выражение типа STRING, которое задаёт текст непосредственно в исходной программе. Интерполированная строка дополняет текст вычисленными значениями.

Кавычки и пустая строка

Обычный литерал заключается в двойные кавычки. Две кавычки внутри литерала обозначают одну кавычку в результате. Пустой литерал записывается как "". Обычный литерал не продолжается на следующей физической строке.

PRINT "Он сказал ""Привет""."

Результат:

Он сказал "Привет".

Вставка выражения

Запись начинается с $". Текст задаёт неизменяемые части результата; выражение задаёт вычисляемую вставку любого типа, для которого доступно обычное отображение. Между фигурными скобками указывается выражение. Оно вычисляется по обычным правилам, а результат становится частью строки. Одиночная открывающая скобка в тексте начинает вставку, поэтому буквальная скобка записывается удвоенной; правила записи текста описаны в следующем разделе.

$"<текст>{<выражение>}<текст>"

Выражение вставки может содержать другую интерполированную строку, в том числе в аргументе функции. Внутренняя строка вычисляется как отдельное выражение; её окончание возвращает разбор во внешнюю вставку. Форматирование программы в стилях Classic и Modern сохраняет текст внешней и внутренней строк, выражения, числовые форматы и выравнивание.

PRINT $"a{$"b{1}c"}d"
PRINT $"{LEN($"x{2}")}"

Результат:

ab1cd
2

Текст внутри интерполяции

Текстовая часть интерполированной строки подчиняется собственным правилам записи. Открывающая фигурная скобка начинает вставку выражения, поэтому одиночная скобка в тексте записывается удвоенной: {{ даёт {. Закрывающая скобка записывается так же: }} даёт }. Двойная кавычка внутри интерполяции записывается двумя кавычками, как и в обычном литерале: "" даёт ".

PRINT $"{{x}}"      ' {x}
PRINT $"a""b"      ' a"b
PRINT $"e{{f"      ' e{f
PRINT $"g}}h"      ' g}h

Обратная косая черта не является экраном и выводится как есть: $"c\d" даёт c\d. Запись \{ экраном не считается, поэтому после обратной косой черты начинается вставка выражения.

Интерполированная строка, как и обычный литерал, не продолжается на следующей физической строке. Перевод строки внутри $"…" завершает литерал и вызывает ошибку MB0002 с позицией начала строки; последующие строки программы читаются как обычный код.

Формы вставки

{<выражение>}
{<выражение>,<выравнивание>}
{<выражение>:<формат>}
{<выражение>,<выравнивание>:<формат>}

Выравнивание — целочисленный литерал минимальной ширины поля. Положительное значение дополняет поле слева, отрицательное — справа. Длинный результат не обрезается. Ширина измеряется в единицах UTF-16. Сначала применяется числовой формат, затем выравнивание.

Пробелы по краям спецификатора формата не значимы: записи {n:F2}, {n: F2} и {n:F2 } дают одинаковый результат. Пробел после запятой относится к записи выравнивания, а не к формату.

Числовые форматы

ФорматНазначение
F, F2Фиксированное количество знаков после десятичной точки.
N, N0Число с разделителями групп разрядов.
E, E3Экспоненциальное представление.
P, P1Процент: значение умножается на 100.
B, B8Двоичное представление целого числа с минимальным количеством цифр.
X, X4Шестнадцатеричное представление целого числа.
D, D3Целое число с минимальным количеством цифр и ведущими нулями.
G, G3Общее числовое представление.

В таблице перечислены часто используемые числовые форматы. Формат передаётся числовому форматированию .NET после перевода букв в верхний регистр. Число после буквы уточняет точность или минимальную ширину числовой записи. D, X и B применяются только к INTEGER и LONG; F, N, E, P и G — к числовым типам. Для нечисловых значений спецификатор игнорируется: используется обычное отображаемое значение.

Правила X/B для отрицательных чисел, ведущие нули и отличие числового значения от записи описаны в статье систем счисления. Неверный числовой формат или применение X/B к дробному типу вызывает перехватываемую ошибку MB3007.

Без формата используется обычное текстовое представление значения. Десятичный разделитель — точка; региональные настройки не меняют результат.

Пример

Вставки объединяют числовой формат и ширину поля:

DIM count AS INTEGER = 7
DIM price AS DOUBLE = 12.5
PRINT $"Количество: {count:D3}"
PRINT $"Цена: {price:F2}"
PRINT $"Поле: |{count,3}|"

Результат:

Количество: 007
Цена: 12.50
Поле: |  7|

Предельная длина результата

Итоговый текст и ширина поля выравнивания подчиняются пределу STRING в 16 777 216 единиц UTF-16. Превышение вызывает MB3007; ошибку можно обработать через TRY/CATCH.

Диагностика

Незавершённый литерал вызывает MB0002; это относится и к обычному литералу, и к интерполированной строке, которая не закрыта до конца физической строки или до конца файла. Вставленное выражение проверяется по общим правилам имён и типов; неизвестное имя вызывает MB2001, несовместимое использование — MB2003. Недопустимый числовой формат во время выполнения вызывает MB3007 и может быть обработан через TRY/CATCH.
