Строковые литералы и интерполяция

Строковый литерал — выражение типа STRING, которое задаёт текст непосредственно в исходной программе. Интерполированная строка дополняет текст вычисленными значениями.

Кавычки и пустая строка

Обычный литерал заключается в двойные кавычки. Две кавычки внутри литерала обозначают одну кавычку в результате. Пустой литерал записывается как "". Обычный литерал не продолжается на следующей физической строке.

PRINT "Он сказал ""Привет""."

Результат:

Он сказал "Привет".

Вставка выражения

Запись начинается с $". Текст задаёт неизменяемые части результата; выражение задаёт вычисляемую вставку любого типа, для которого доступно обычное отображение. Между фигурными скобками указывается выражение. Оно вычисляется по обычным правилам, а результат становится частью строки. В текущей реализации текстовые части интерполяции сохраняют исходную запись: {{ и }} не сворачиваются в одиночные скобки. Например, $"{{x}}" даёт текст {{x}}. Буквальные фигурные скобки можно отдельно соединить с вычисленной частью обычной строкой.

$"<текст>{<выражение>}<текст>"

Формы вставки

{<выражение>}
{<выражение>,<выравнивание>}
{<выражение>:<формат>}
{<выражение>,<выравнивание>:<формат>}

Выравнивание — целочисленный литерал минимальной ширины поля. Положительное значение дополняет поле слева, отрицательное — справа. Длинный результат не обрезается. Ширина измеряется в единицах UTF-16. Сначала применяется числовой формат, затем выравнивание.

Числовые форматы

ФорматНазначение
F, F2Фиксированное количество знаков после десятичной точки.
N, N0Число с разделителями групп разрядов.
E, E3Экспоненциальное представление.
P, P1Процент: значение умножается на 100.
B, B8Двоичное представление целого числа с минимальным количеством цифр.
X, X4Шестнадцатеричное представление целого числа.
D, D3Целое число с минимальным количеством цифр и ведущими нулями.
G, G3Общее числовое представление.

В таблице перечислены часто используемые числовые форматы. Формат передаётся числовому форматированию .NET после перевода букв в верхний регистр. Число после буквы уточняет точность или минимальную ширину числовой записи. D, X и B применяются только к INTEGER и LONG; F, N, E, P и G — к числовым типам. Для нечисловых значений спецификатор игнорируется: используется обычное отображаемое значение.

Правила X/B для отрицательных чисел, ведущие нули и отличие числового значения от записи описаны в статье систем счисления. Неверный числовой формат или применение X/B к дробному типу вызывает перехватываемую ошибку MB3007.

Без формата используется обычное текстовое представление значения. Десятичный разделитель — точка; региональные настройки не меняют результат.

Пример

Вставки объединяют числовой формат и ширину поля:

DIM count AS INTEGER = 7
DIM price AS DOUBLE = 12.5
PRINT $"Количество: {count:D3}"
PRINT $"Цена: {price:F2}"
PRINT $"Поле: |{count,3}|"

Результат:

Количество: 007
Цена: 12.50
Поле: |  7|

Диагностика

Незавершённый литерал вызывает MB0002. Вставленное выражение проверяется по общим правилам имён и типов; неизвестное имя вызывает MB2001, несовместимое использование — MB2003. Недопустимый числовой формат во время выполнения вызывает MB3007 и может быть обработан через TRY/CATCH.
