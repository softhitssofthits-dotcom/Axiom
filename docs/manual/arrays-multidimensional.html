Многомерные массивы

Раздел многомерных массивов описывает ранг массива, границы измерений и полную форму — массивы с более чем двумя индексами.

Ранг и форма массива

Многомерный массив хранит значения одного типа в прямоугольной форме из трёх и более измерений. Каждое измерение имеет собственные включительные границы, а число измерений называется рангом массива.

Синтаксис

DIM <имя массива>(<границы измерения 1>, <границы измерения 2>, <границы измерения 3>[, ...]) AS <тип элемента>
DIM <имя массива>(,,) AS <тип элемента>
<имя массива>(<индекс 1>, <индекс 2>, <индекс 3>[, ...]) = <выражение>
DIM cube(1 TO 3, 1 TO 4, 1 TO 2) AS INTEGER
PRINT UBOUND(cube, 2)
PRINT ARRAYRANK(cube)

Параметры и части синтаксиса

  • <границы измерения N> — диапазон вида <нижняя граница> TO <верхняя граница> для отдельного измерения.
  • <тип элемента> — тип всех элементов массива.
  • <индекс N> — индекс в соответствующем измерении. Для полного доступа к элементу нужно указать столько индексов, каков ранг массива.
  • DIM cube(,,) AS DOUBLE объявляет динамический трёхмерный массив без выделенных границ; форму задаёт последующий REDIM.

Границы каждого измерения

  • Ранг массива задаётся его объявлением и показывает количество измерений.
  • Функция ARRAYRANK возвращает число измерений массива.
  • Функции LBOUND и UBOUND позволяют получить границы отдельного измерения.
  • Если нужно получить границы всех измерений сразу, используйте ARRAYBOUNDS.
  • ARRAYBOUNDS возвращает таблицу вида INTEGER(1 TO rank, 1 TO 2), где каждая строка содержит нижнюю и верхнюю границу соответствующего измерения.
  • Точный верхний предел ранга в пользовательском договоре не закреплён. Не рассчитывайте на конкретное число вроде 32, если оно не указано в проверенном примере или отдельном описании реализации.
  • Для невыделенного массива полезно сначала проверять состояние через ARRAYISALLOCATED.

Пример чтения ранга и границ

DIM cube(1 TO 3, 1 TO 4, 1 TO 2) AS INTEGER
DIM bounds(,) AS INTEGER

PRINT ARRAYRANK(cube)

bounds = ARRAYBOUNDS(cube)
PRINT bounds(1, 1)
PRINT bounds(1, 2)
PRINT bounds(2, 1)
PRINT bounds(2, 2)

Запускаемые примеры

  • ARRAYRANK: число измерений
  • ARRAYBOUNDS: полная форма массива
  • Высокий ранг: границы и размерность
