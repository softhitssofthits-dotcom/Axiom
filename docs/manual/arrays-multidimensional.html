Многомерные массивы

Многомерный массив — тип данных Axiom с несколькими измерениями; эта статья рассматривает ранг выше 2. Каждый элемент выбирается набором индексов в порядке измерений объявления.

Назначение и контекст

Массив сохраняет прямоугольную форму во всех измерениях. ARRAYBOUNDS возвращает таблицу (1 TO ранг, 1 TO 2): нижние границы стоят в первом столбце, верхние — во втором. При последовательном обходе встроенных функций последнее измерение меняется быстрее первого.

Работа с массивом разрешена на верхнем уровне, в процедуре и в функции; SCREEN не требуется.

Синтаксис

Ниже показаны формы для трёхмерного массива: объявление с выделением элементов, объявление динамического массива без элементов и присваивание одному элементу. Для каждого выделяемого измерения обе границы и ключевое слово TO обязательны. Для другого ранга число диапазонов или индексов изменяется соответственно.

DIM <имя массива>(<нижняя граница 1> TO <верхняя граница 1>, <нижняя граница 2> TO <верхняя граница 2>, <нижняя граница 3> TO <верхняя граница 3>) AS <тип элемента>
DIM <имя массива>(,,) AS <тип элемента>
<имя массива>(<индекс 1>, <индекс 2>, <индекс 3>) = <значение>

Части записи

Каждые границы измерения записываются как числовое выражение нижней границы TO числовое выражение верхней границы. Индексы выбирают координаты в соответствующих измерениях. Тип элемента общий для всех координат. Для ранга выше 3 список продолжается; число пустых мест в динамическом объявлении задаёт ранг.

Границы задаются числовыми выражениями. Допустимы INTEGER, LONG, DOUBLE и DECIMAL, но значение должно быть целым и помещаться в INTEGER. Ненулевая дробная часть вызывает MB3007; усечения нет. Нижняя граница -2147483648 запрещена, потому что поисковые функции используют нижнюю границу минус 1 как признак отсутствия. Верхняя граница включается в массив. Обратный диапазон допустим только как каноническая пустая форма 1 TO 0 при DIM или REDIM.

Действие и ограничения

DIM с границами создаёт элементы со значениями по умолчанию. DIM с пустыми измерениями сохраняет тип и ранг без выделения элементов. Полное индексирование возвращает один элемент; частичное индексирование создаёт представление оставшихся измерений.

Диагностика

MB2003 означает несовместимый тип элемента или индекса, MB2004 — неверное число индексов. MB3002 возникает, когда индекс или диапазон при индексировании выходит за границы. MB3005 возникает при доступе к невыделенному массиву либо при недопустимой паре границ. MB3007 сообщает о запрещённой нижней границе -2147483648; выход числового значения за диапазон INTEGER даёт MB3008.

Пример

DIM cube(1 TO 2, -1 TO 1, 4 TO 5) AS INTEGER
cube(2, 0, 5) = 8
PRINT ARRAYRANK(cube)
PRINT cube(2, 0, 5)
PRINT LBOUND(cube, 2)
PRINT ARRAYLENGTH(cube)

Ожидаемый вывод:

3
8
-1
12
