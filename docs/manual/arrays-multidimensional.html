Многомерные массивы

Сводка

Многомерный массив хранит значения одного типа в пространстве из трёх и более измерений. Каждое измерение имеет собственные границы, а число измерений называется рангом массива.

Синтаксис

DIM cube(1 TO 3, 1 TO 4, 1 TO 2) AS INTEGER
PRINT UBOUND(cube, 2)
PRINT ARRAYRANK(cube)

Замечания

  • Ранг массива задаётся его объявлением и показывает количество измерений.
  • Функция ARRAYRANK возвращает число измерений массива.
  • Функции LBOUND и UBOUND позволяют получить границы отдельного измерения.
  • Если нужно получить границы всех измерений сразу, используйте ARRAYBOUNDS.
  • ARRAYBOUNDS возвращает таблицу вида INTEGER(1 TO rank, 1 TO 2), где каждая строка содержит нижнюю и верхнюю границу соответствующего измерения.
  • В текущей реализации язык требует только положительный ранг массива. Отдельный верхний предел ранга пока не зафиксирован как часть пользовательского договора, поэтому manual не обещает число вроде 32 заранее.
  • Для невыделенного массива полезно сначала проверять состояние через ARRAYISALLOCATED.

Пример

DIM cube(1 TO 3, 1 TO 4, 1 TO 2) AS INTEGER
DIM bounds(,) AS INTEGER

PRINT ARRAYRANK(cube)

bounds = ARRAYBOUNDS(cube)
PRINT bounds(1, 1)
PRINT bounds(1, 2)
PRINT bounds(2, 1)
PRINT bounds(2, 2)

Ручная проверка

  • ARRAYRANK: число измерений
  • ARRAYBOUNDS: полная форма массива
  • Высокий ранг: ручная metadata-проверка
