Справочник языка

Корни, степени, логарифмы и округление

Математические функции этого раздела делятся на два круга задач. SQR, CBRT, EXP, LOG, LOG10, LOG2 и POW вычисляют нелинейные зависимости и возвращают DOUBLE, а FLOOR, CEIL, ROUND и FIX сводят дробное значение к целому по выбранному правилу. Ограничения области определения у первых и направление округления у вторых определяют, какой результат получится на границе.

SQR

Функция SQR возвращает квадратный корень числа, выполняя это математическое преобразование непосредственно в числовом выражении. Вызывать её можно в выражении консольной или графической программы; оператор SCREEN или CANVAS не требуется.

Синтаксис

SQR(<значение>)

Аргументы

Аргумент должен быть числом типа INTEGER, LONG, DOUBLE или DECIMAL. Передайте выражение, над которым нужно выполнить указанное вычисление.

Результат

Результат имеет тип DOUBLE; числовой аргумент предварительно преобразуется в DOUBLE.

Правила и ограничения

Аргумент должен быть неотрицательным.

Диагностика

Компилятор отклоняет неверное количество аргументов и несовместимый тип аргумента. Аргумент меньше нуля вызывает MB3007. MB3008 возникает, если результат не является конечным DOUBLE.

Пример

PRINT SQR(0)
PRINT SQR(81)

Ожидаемый вывод:

0
9

EXP

Синтаксис

Аргументы

Аргумент должен быть числом типа INTEGER, LONG, DOUBLE или DECIMAL. Передайте выражение, над которым нужно выполнить указанное вычисление.

POW

Функция POW возвращает первое число в степени второго, позволяя вычислить степенную зависимость с целым или дробным показателем. Вызывается она в выражениях консольных и графических программ; оператор SCREEN или CANVAS не требуется.

Синтаксис

POW(<основание>, <показатель степени>)

Аргументы

Передайте два числа. Основание — возводимое число; показатель степени — степень, которая может быть дробной. Оба преобразуются в DOUBLE.

Результат

Функция возвращает значение типа DOUBLE.

Правила и ограничения

Ноль в нулевой степени даёт 1. Отрицательное основание с неподходящим дробным показателем не имеет вещественного результата.

Диагностика

Компилятор отклоняет неверное количество аргументов и несовместимый тип аргумента. MB3007 возникает при неопределённом вещественном результате; MB3008 — при бесконечном результате.

Пример

PRINT POW(2, 3)
PRINT POW(0, 0)

Ожидаемый вывод:

8
1

FLOOR

FLOOR возвращает наибольшее целое значение, не превышающее аргумент, то есть даёт целое по величине значение с указанным правилом округления. Вызывать функцию можно в выражении консольной или графической программы; оператор SCREEN или CANVAS не нужен.

Синтаксис

FLOOR(<значение>)

Аргументы

Аргумент должен быть числом типа INTEGER, LONG, DOUBLE или DECIMAL. Передайте выражение, над которым нужно выполнить указанное вычисление.

Результат

Тип результата совпадает с типом аргумента, включая DOUBLE и DECIMAL.

Правила и ограничения

Округление направлено к минус бесконечности. INTEGER и LONG возвращаются без изменения.

Диагностика

Компилятор отклоняет неверное количество аргументов и несовместимый тип аргумента.

Пример

PRINT FLOOR(-2.8)
PRINT FLOOR(2.8)

Ожидаемый вывод:

-3
2

Синтаксис

ROUND(<значение>)

Аргументы

Результат

Тип результата совпадает с типом аргумента, включая DOUBLE и DECIMAL.

Правила и ограничения

Пример
