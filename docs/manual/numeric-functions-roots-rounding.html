Раздел

Корни, логарифмы и округление

Раздел корней, логарифмов и округления описывает функции SQR, CBRT, EXP, LOG, POW, FLOOR, CEIL, ROUND и FIX — степенные вычисления, получение логарифмов и разные способы перехода от дробного числа к целому значению.

SQR

SQR — встроенная функция языка Axiom, которая возвращает квадратный корень числа. Функция работает в любом режиме программы без предварительного вызова оператора SCREEN.

Синтаксис

result = SQR(value)

Аргументы

value должен быть неотрицательным числом. Результат имеет тип DOUBLE.

Промежуточные вычисления и расстояние

Функция SQR получает результат своего аргумента уже после вычисления выражения. Поэтому формула SQR(x*x + y*y) может завершиться диагностикой MB3008 при умножении, даже если само расстояние помещается в DOUBLE. Для очень малых координат оба квадрата могут округлиться до нуля, и прямое выражение вернёт 0.

Для конечных координат риск промежуточного переполнения можно уменьшить масштабированием: сначала разделить координаты на большую из их абсолютных величин, вычислить корень, затем вернуть масштаб. Для нулевого вектора нужно отдельно вернуть 0 до деления.

FUNCTION StableDistance(x AS DOUBLE, y AS DOUBLE) AS DOUBLE
    DIM scale AS DOUBLE = MAX(ABS(x), ABS(y))
    IF scale = 0 THEN
        RETURN 0
    END IF
    DIM scaledX AS DOUBLE = x / scale
    DIM scaledY AS DOUBLE = y / scale
    RETURN scale * SQR(scaledX * scaledX + scaledY * scaledY)
END FUNCTION

PRINT StableDistance(VAL("3e200"), VAL("4e200"))
PRINT StableDistance(VAL("3e-200"), VAL("4e-200"))

Результаты близки к 5e200 и 5e-200. Небольшое отличие последней цифры допустимо из-за округления DOUBLE. Запись с показателем степени здесь передаётся строкой в VAL. StableDistance — пользовательская функция этого примера, а не новая встроенная функция языка.

Ограничения и диагностика

Отрицательный аргумент SQR даёт MB3007. Неконечный результат арифметики даёт MB3008. Масштабирование не расширяет диапазон DOUBLE: если уже само расстояние невозможно представить конечным числом, последняя операция тоже даст MB3008. Пример не обещает точное округление для всех возможных пар DOUBLE.

Запускаемая программа: scaled_distance.axm.

POW

POW — встроенная функция языка Axiom, которая возводит число в степень и возвращает результат типа DOUBLE. Встроенная функция работает без графического режима.

Синтаксис

result = POW(value, power)

Аргументы

value задаёт основание степени, а power показатель степени.

Точность результата

По принятому договору вычисление POW выполняется готовой функцией System.Math.Pow: конечный результат совпадает с результатом .NET в той же среде, включая округление и знак нуля. Axiom сохраняет собственные сообщения об ошибках: результат NaN преобразуется в MB3007, а бесконечность — в MB3008. Возврат этих особых значений вместо ошибки не поддерживается.

Оба движка преобразуют числовые аргументы в DOUBLE и вычисляют степень через Math.Pow среды .NET. Результат является приближённым: текущая реализация не обеспечивает математически правильное округление каждой степени к ближайшему значению DOUBLE. Последние разряды могут зависеть от операционной системы и архитектуры.

Например, точное значение POW(2, -1075) находится посередине между нулём и минимальным положительным DOUBLE. На проверенной Windows среда .NET возвращает 5E-324; это наблюдение конкретной среды, а не переносимая гарантия результата. Если программе требуется правильно округлённая степень на всех границах, встроенная функция POW текущей реализации не подтверждает такое требование.

' Наблюдаем результат конкретной среды на границе DOUBLE
PRINT POW(2, -1074)
PRINT POW(2, -1075)
PRINT POW(2, -1076)

В проверенной среде строки результата равны 5E-324, 5E-324 и 0. Полный запускаемый пример: граница округления степени.

Диагностика

При отрицательном основании и нецелой степени встроенная функция сообщает MB3007. Если вычисление даёт бесконечный результат, функция сообщает MB3008. Уход слишком малого результата к нулю не вызывает диагностику.

Пример корней и степеней

' Степень, логарифм и квадратный корень
PRINT POW(2, 8)
PRINT LOG10(1000)
PRINT SQR(81)

Результат:

256
3
9

FLOOR

Функция FLOOR округляет число вниз и сохраняет числовой тип аргумента.

Синтаксис

result = FLOOR(value)

CEIL

Функция CEIL округляет число вверх и сохраняет числовой тип аргумента.

Синтаксис

result = CEIL(value)

ROUND

Функция ROUND округляет число к ближайшему целому и сохраняет числовой тип аргумента.

Синтаксис

result = ROUND(value)

Округление и отбрасывание дробной части

В Axiom половины округляются от нуля. Поэтому ROUND(2.5) даёт 3, а ROUND(-2.5) даёт -3.

FIX

Функция FIX отбрасывает дробную часть числа по направлению к нулю и сохраняет числовой тип аргумента.

Синтаксис

result = FIX(value)

Пример округления чисел

' Разница между INT, FLOOR, ROUND и FIX
PRINT INT(-3.9)
PRINT FLOOR(-3.9)
PRINT ROUND(-3.9)
PRINT FIX(-3.9)

Области определения и способы округления

  • SQR не принимает отрицательные значения, а LOG, LOG10 и LOG2 требуют аргумент строго больше нуля.
  • POW может завершиться диагностикой времени выполнения, если комбинация основания и показателя степени выходит за допустимую область определения.
  • INT отличается от FLOOR тем, что возвращает именно INTEGER, а FLOOR сохраняет числовой тип аргумента.
  • FIX удобен там, где нужно просто отбросить дробную часть без смещения вниз для отрицательных чисел.

Ручная проверка

  • SQR: квадратный корень
  • SQR: отрицательный аргумент
  • CBRT: кубический корень
  • EXP: степень числа e
  • LOG: натуральный логарифм
  • LOG: неположительный аргумент
  • LOG10: десятичный логарифм
  • LOG2: двоичный логарифм
  • POW: возведение в степень
  • POW: недопустимая область определения
  • FLOOR: округление вниз
  • CEIL: округление вверх
  • ROUND: округление к ближайшему
  • FIX: отсечение дробной части
