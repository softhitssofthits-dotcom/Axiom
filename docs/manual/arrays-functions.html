Массивы

ARRAY-функции

ARRAY-функции позволяют узнать границы массива, число измерений, количество видимых элементов, выделена ли память, а также взять срез или изменить динамический массив.

Как выбрать функцию

  • LBOUND и UBOUND возвращают нижнюю и верхнюю границу измерения.
  • ARRAYRANK, ARRAYLENGTH и ARRAYBOUNDS описывают форму массива.
  • ARRAYISALLOCATED проверяет, можно ли обращаться к элементам динамического массива.
  • ARRAYSLICE выбирает непрерывную часть массива.
  • ARRAYPUSH, ARRAYPOP, ARRAYINSERT и ARRAYREMOVE меняют размер динамического массива.

В синтаксисе этой страницы имена в угловых скобках, например <массив>, <измерение> и <значение>, являются метапеременными. Это не слова языка: вместо них в программе пишут имя массива, выражение с номером измерения или значение нужного типа.

LBOUND

LBOUND возвращает нижнюю границу выбранного измерения массива.

Синтаксис

LBOUND(<массив>)
LBOUND(<массив>, <измерение>)

Аргументы

  • <массив> - массив, для которого определяется граница.
  • <измерение> - номер измерения. Если аргумент не указан, используется первое измерение. Для двумерного массива ROW означает измерение 1, а COLUMN - измерение 2.

Пример нижней границы

DIM scores(1 TO 5) AS INTEGER
PRINT LBOUND(scores)

UBOUND

UBOUND возвращает верхнюю границу выбранного измерения массива.

Синтаксис

UBOUND(<массив>)
UBOUND(<массив>, <измерение>)

Аргументы

  • <массив> - массив, для которого определяется граница.
  • <измерение> - номер измерения. Для двумерных массивов можно использовать предопределённые целочисленные константы ROW и COLUMN; это готовые имена для строк и столбцов, а не функции.

Пример верхней границы

DIM board(1 TO 3, 1 TO 4) AS INTEGER
PRINT UBOUND(board, COLUMN)

ARRAYLENGTH

ARRAYLENGTH возвращает общее число элементов, видимых через массив или представление.

Синтаксис

ARRAYLENGTH(<массив>)

Что считает ARRAYLENGTH

Для одномерного массива это длина диапазона индексов. Для многомерного массива результатом является произведение длин всех измерений.

Пример длины массива

DIM board(1 TO 2, 1 TO 3) AS INTEGER
PRINT ARRAYLENGTH(board)

ARRAYISALLOCATED

ARRAYISALLOCATED показывает, выделена ли память для элементов массива.

Синтаксис

ARRAYISALLOCATED(<массив>)

Проверка перед доступом к элементам

Функция полезна перед обращением к динамическому массиву. Она не сообщает границы и не заменяет LBOUND или UBOUND.

Пример проверки выделения

DIM values() AS INTEGER
PRINT ARRAYISALLOCATED(values)
REDIM values(1 TO 3)
PRINT ARRAYISALLOCATED(values)

ARRAYRANK

ARRAYRANK возвращает число измерений массива.

Синтаксис

ARRAYRANK(<массив>)

Ранг как число измерений

ARRAYRANK может работать и с ещё не выделенным динамическим массивом, потому что число измерений известно по объявлению.

Пример ранга массива

DIM cube(,,) AS INTEGER
PRINT ARRAYRANK(cube)

ARRAYBOUNDS

ARRAYBOUNDS возвращает таблицу границ массива по всем измерениям.

Синтаксис

ARRAYBOUNDS(<массив>)

Таблица границ измерений

Результатом является новый массив INTEGER(1 TO <ранг>, 1 TO 2). В каждой строке хранится пара границ одного измерения: в первом столбце нижняя граница, во втором - верхняя.

Пример чтения всех границ

DIM board(1 TO 2, 10 TO 11) AS INTEGER
DIM bounds(,) AS INTEGER

bounds = ARRAYBOUNDS(board)
PRINT bounds(1, 1)
PRINT bounds(1, 2)
PRINT bounds(2, 1)
PRINT bounds(2, 2)

ARRAYSLICE

ARRAYSLICE возвращает непрерывную часть массива по начальному индексу и количеству элементов или срезов.

Синтаксис

ARRAYSLICE(<массив>, <начальный индекс>, <количество>)
ARRAYSLICE(<массив>, <начальный индекс>, <количество>, <измерение>)

Аргументы

  • <начальный индекс> - первый индекс выбранного участка.
  • <количество> - сколько элементов или срезов нужно взять.
  • <измерение> - измерение, вдоль которого строится срез.

Пример выборки диапазона

DIM values(1 TO 5) AS INTEGER
DIM part() AS INTEGER

part = ARRAYSLICE(values, 2, 3)

ARRAYPUSH

ARRAYPUSH добавляет элемент в конец одномерного динамического массива или целый срез в конец выбранного измерения многомерного массива.

Синтаксис

ARRAYPUSH(<массив>, <значение>)
ARRAYPUSH(<массив>, <значение>, <измерение>)

Как меняются границы после добавления

Для массива ранга 2 и выше <значение> должно иметь форму, согласованную со всеми остальными измерениями.

Пример добавления элемента

DIM values() AS INTEGER

REDIM values(1 TO 2)
values(1) = 10
values(2) = 20
ARRAYPUSH(values, 30)

ARRAYPOP

ARRAYPOP снимает последний элемент или последний срез и возвращает его как результат.

Синтаксис

ARRAYPOP(<массив>)
ARRAYPOP(<массив>, <измерение>)

Что возвращается при снятии элемента

После вызова исходный массив уменьшается. Для многомерного массива результатом становится отдельный массив, представляющий снятый срез.

Пример снятия последнего элемента

DIM values() AS INTEGER
DIM lastValue AS INTEGER

REDIM values(1 TO 3)
values(3) = 30
lastValue = ARRAYPOP(values)

ARRAYINSERT

ARRAYINSERT вставляет элемент или срез по указанной позиции.

Синтаксис

ARRAYINSERT(<массив>, <индекс>, <значение>)
ARRAYINSERT(<массив>, <индекс>, <значение>, <измерение>)

Как сдвигаются элементы после вставки

Все элементы после точки вставки сдвигаются. Для многомерного массива форма вставляемого значения должна соответствовать выбранному измерению.

Пример вставки по индексу

DIM values() AS INTEGER

REDIM values(1 TO 3)
values(1) = 10
values(2) = 30
values(3) = 40
ARRAYINSERT(values, 2, 20)

ARRAYREMOVE

ARRAYREMOVE удаляет элемент или срез по указанной позиции и возвращает удалённое значение.

Синтаксис

ARRAYREMOVE(<массив>, <индекс>)
ARRAYREMOVE(<массив>, <индекс>, <измерение>)

Как сдвигаются элементы после удаления

После удаления хвост массива сдвигается, а размер массива уменьшается. Для многомерного массива возвращается удалённый срез.

Пример удаления по индексу

DIM values() AS INTEGER
DIM removedValue AS INTEGER

REDIM values(1 TO 3)
values(1) = 10
values(2) = 20
values(3) = 30
removedValue = ARRAYREMOVE(values, 2)

Ручная проверка

  • UBOUND
