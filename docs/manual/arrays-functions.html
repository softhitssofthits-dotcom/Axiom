ARRAY-функции

Сводка

ARRAY-функции помогают узнать форму массива, получить его границы, выделить часть данных или изменить содержимое динамического массива. Ниже каждая функция описана отдельно: сначала назначение, затем запись, замечания и короткий пример вызова.

LBOUND

Функция LBOUND возвращает нижнюю границу выбранного измерения массива.

Синтаксис

LBOUND(array)
LBOUND(array, dimension)

Аргументы

  • array — массив, для которого определяется граница.
  • dimension — номер измерения. Если аргумент не указан, используется первое измерение.

Замечания

Для одномерного массива вызова LBOUND(array) обычно достаточно. Для двумерных и многомерных массивов можно явно указать измерение числом или, когда это уместно, через ROW и COLUMN.

Пример

DIM scores(1 TO 5) AS INTEGER
PRINT LBOUND(scores)

UBOUND

Функция UBOUND возвращает верхнюю границу выбранного измерения массива.

Синтаксис

UBOUND(array)
UBOUND(array, dimension)

Аргументы

  • array — массив, для которого определяется граница.
  • dimension — номер измерения. Если аргумент не указан, используется первое измерение.

Замечания

Эту функцию обычно используют вместе с LBOUND, чтобы обходить массив без жёстко записанных числовых границ.

Пример

DIM board(1 TO 3, 1 TO 4) AS INTEGER
PRINT UBOUND(board, COLUMN)

ARRAYLENGTH

Функция ARRAYLENGTH возвращает общее число элементов, видимых через данный массив.

Синтаксис

ARRAYLENGTH(array)

Замечания

Для одномерного массива это количество элементов в диапазоне. Для многомерного массива функция возвращает произведение длин всех измерений.

Пример

DIM board(1 TO 2, 1 TO 3) AS INTEGER
PRINT ARRAYLENGTH(board)

ARRAYISALLOCATED

Функция ARRAYISALLOCATED показывает, была ли для массива уже выделена память.

Синтаксис

ARRAYISALLOCATED(array)

Замечания

Функция возвращает только признак готовности массива к работе с элементами. Она не сообщает ни число измерений, ни конкретные границы.

Пример

DIM values() AS INTEGER
PRINT ARRAYISALLOCATED(values)
REDIM values(1 TO 3)
PRINT ARRAYISALLOCATED(values)

ARRAYRANK

Функция ARRAYRANK возвращает число измерений массива.

Синтаксис

ARRAYRANK(array)

Замечания

В отличие от функций, которым нужна уже выделенная память, ARRAYRANK может работать и с ещё не выделенным массивом, потому что число измерений известно уже по объявлению.

Пример

DIM cube(,,) AS INTEGER
PRINT ARRAYRANK(cube)

ARRAYBOUNDS

Функция ARRAYBOUNDS возвращает таблицу границ массива по всем его измерениям.

Синтаксис

ARRAYBOUNDS(array)

Замечания

Результатом является новый массив INTEGER(1 TO rank, 1 TO 2). В каждой строке хранится пара границ одного измерения: в первом столбце нижняя граница, во втором — верхняя.

Пример

DIM board(1 TO 2, 10 TO 11) AS INTEGER
DIM bounds(,) AS INTEGER

bounds = ARRAYBOUNDS(board)
PRINT bounds(1, 1)
PRINT bounds(1, 2)
PRINT bounds(2, 1)
PRINT bounds(2, 2)

ARRAYSLICE

Функция ARRAYSLICE возвращает часть массива по заданному диапазону индексов.

Синтаксис

ARRAYSLICE(array, startIndex, count)
ARRAYSLICE(array, startIndex, count, dimension)

Аргументы

  • startIndex — индекс первого элемента или первого среза.
  • count — сколько элементов или срезов нужно взять.
  • dimension — измерение, вдоль которого строится срез.

Замечания

Для одномерного массива функция возвращает непрерывный участок. Для многомерного массива она выбирает согласованный срез по указанному измерению.

Пример

DIM values(1 TO 5) AS INTEGER
DIM part() AS INTEGER

part = ARRAYSLICE(values, 2, 3)

ARRAYPUSH

Функция ARRAYPUSH добавляет элемент в конец одномерного массива или целый срез в конец выбранного измерения многомерного массива.

Синтаксис

ARRAYPUSH(array, value)
ARRAYPUSH(array, value, dimension)

Замечания

Для ранга 2+ аргумент value должен иметь форму, согласованную со всеми остальными измерениями массива.

Пример

DIM values() AS INTEGER

REDIM values(1 TO 2)
values(1) = 10
values(2) = 20
ARRAYPUSH(values, 30)

ARRAYPOP

Функция ARRAYPOP снимает последний элемент или последний срез и возвращает его как результат.

Синтаксис

ARRAYPOP(array)
ARRAYPOP(array, dimension)

Замечания

При вызове исходный массив одновременно уменьшается. Для многомерного массива результатом становится отдельный массив, представляющий снятый срез.

Пример

DIM values() AS INTEGER
DIM lastValue AS INTEGER

REDIM values(1 TO 3)
values(3) = 30
lastValue = ARRAYPOP(values)

ARRAYINSERT

Функция ARRAYINSERT вставляет элемент или срез по указанной позиции.

Синтаксис

ARRAYINSERT(array, index, value)
ARRAYINSERT(array, index, value, dimension)

Замечания

Все элементы после точки вставки сдвигаются. Для многомерного массива форма вставляемого значения должна соответствовать выбранному измерению.

Пример

DIM values() AS INTEGER

REDIM values(1 TO 3)
values(1) = 10
values(2) = 30
values(3) = 40
ARRAYINSERT(values, 2, 20)

ARRAYREMOVE

Функция ARRAYREMOVE удаляет элемент или срез по указанной позиции и возвращает удалённое значение.

Синтаксис

ARRAYREMOVE(array, index)
ARRAYREMOVE(array, index, dimension)

Замечания

После удаления хвост массива сдвигается, а размер массива уменьшается. Для многомерного массива возвращается удалённый срез.

Пример

DIM values() AS INTEGER
DIM removedValue AS INTEGER

REDIM values(1 TO 3)
values(1) = 10
values(2) = 20
values(3) = 30
removedValue = ARRAYREMOVE(values, 2)
