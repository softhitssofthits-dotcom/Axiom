ARRAY-функции

Раздел ARRAY-функций описывает функции для сведений о массиве и операций над его содержимым: границы, число измерений, количество элементов, выделение памяти, срезы и изменение динамического массива.

В подписях встроенных функций IDE обозначение T означает тип элемента массива, а T() — массив этого типа. Это обозначения справочной подписи, а не новые типы языка. Формы LBOUND(array, dimension) и UBOUND(array, dimension) также доступны в подсказках редактора; номер измерения отсчитывается от единицы.

Как выбрать функцию

  • LBOUND и UBOUND возвращают нижнюю и верхнюю границу измерения.
  • ARRAYRANK, ARRAYLENGTH и ARRAYBOUNDS описывают форму массива.
  • ARRAYISALLOCATED проверяет, можно ли обращаться к элементам динамического массива.
  • ARRAYSLICE выбирает непрерывную часть массива.
  • ARRAYPUSH, ARRAYPOP, ARRAYINSERT и ARRAYREMOVE меняют размер динамического массива.

В синтаксисе этой страницы имена в угловых скобках, например <массив>, <измерение> и <значение>, являются метапеременными. Это не слова языка: вместо них в программе пишут имя массива, выражение с номером измерения или значение нужного типа.

LBOUND

LBOUND возвращает нижнюю границу выбранного измерения массива.

Синтаксис

LBOUND(<массив>)
LBOUND(<массив>, <измерение>)

Аргументы

  • <массив> - массив, для которого определяется граница.
  • <измерение> - номер измерения. Если аргумент не указан, используется первое измерение. Для двумерного массива ROW означает измерение 1, а COLUMN - измерение 2.

Пример нижней границы

DIM scores(1 TO 5) AS INTEGER
PRINT LBOUND(scores)

UBOUND

UBOUND возвращает верхнюю границу выбранного измерения массива.

Синтаксис

UBOUND(<массив>)
UBOUND(<массив>, <измерение>)

Аргументы

  • <массив> - массив, для которого определяется граница.
  • <измерение> - номер измерения. Для двумерных массивов можно использовать предопределённые целочисленные константы ROW и COLUMN; это готовые имена для строк и столбцов, а не функции.

Пример верхней границы

DIM board(1 TO 3, 1 TO 4) AS INTEGER
PRINT UBOUND(board, COLUMN)

ARRAYLENGTH

ARRAYLENGTH возвращает общее число элементов, видимых через массив или представление.

Синтаксис

ARRAYLENGTH(<массив>)

Что считает ARRAYLENGTH

Для одномерного массива это длина диапазона индексов. Для многомерного массива результатом является произведение длин всех измерений.

Пример длины массива

DIM board(1 TO 2, 1 TO 3) AS INTEGER
PRINT ARRAYLENGTH(board)

ARRAYISALLOCATED

ARRAYISALLOCATED показывает, выделена ли память для элементов массива.

Синтаксис

ARRAYISALLOCATED(<массив>)

Проверка перед доступом к элементам

Функция полезна перед обращением к динамическому массиву. Она не сообщает границы и не заменяет LBOUND или UBOUND.

Пример проверки выделения

DIM values() AS INTEGER
PRINT ARRAYISALLOCATED(values)
REDIM values(1 TO 3)
PRINT ARRAYISALLOCATED(values)

ARRAYRANK

ARRAYRANK возвращает число измерений массива.

Синтаксис

ARRAYRANK(<массив>)

Ранг как число измерений

ARRAYRANK может работать и с ещё не выделенным динамическим массивом, потому что число измерений известно по объявлению.

Пример ранга массива

DIM cube(,,) AS INTEGER
PRINT ARRAYRANK(cube)

ARRAYBOUNDS

ARRAYBOUNDS возвращает таблицу границ массива по всем измерениям.

Синтаксис

ARRAYBOUNDS(<массив>)

Таблица границ измерений

Результатом является новый массив INTEGER(1 TO <ранг>, 1 TO 2). В каждой строке хранится пара границ одного измерения: в первом столбце нижняя граница, во втором - верхняя.

Пример чтения всех границ

DIM board(1 TO 2, 10 TO 11) AS INTEGER
DIM bounds(,) AS INTEGER

bounds = ARRAYBOUNDS(board)
PRINT bounds(1, 1)
PRINT bounds(1, 2)
PRINT bounds(2, 1)
PRINT bounds(2, 2)

ARRAYSLICE

ARRAYSLICE — встроенная функция языка Axiom, которая возвращает непрерывную часть массива по начальному индексу и количеству элементов или срезов. Функция работает в BytecodeVm без экранного или файлового режима.

Синтаксис

ARRAYSLICE(<массив>, <начальный индекс>, <количество>)
ARRAYSLICE(<массив>, <начальный индекс>, <количество>, <измерение>)

Аргументы

  • <начальный индекс> - первый индекс выбранного участка.
  • <количество> - сколько элементов или срезов нужно взять.
  • <измерение> - измерение, вдоль которого строится срез.

Правила и диагностика

Исходный массив должен быть выделен. Начальный индекс, количество и номер измерения должны иметь тип INTEGER. Номер измерения отсчитывается от единицы и не должен превышать ARRAYRANK(array). Если номер явно указан для одномерного массива, допустимо только 1. Для многомерного массива номер требуется явно; отсутствие отклоняется при связывании.

Одномерный результат имеет компактные границы 1 TO count; многомерный результат сохраняет индексы выбранного участка и границы остальных измерений. Исходный массив не изменяется. Отрицательное количество, недопустимое измерение или непустой участок вне границ дают MB3007. Ошибку можно перехватить оператором TRY/CATCH.

DIM values(5 TO 7) AS INTEGER
DIM part() AS INTEGER
values(6) = 20
part = ARRAYSLICE(values, 6, 1, 1)
PRINT part(1)  ' 20; результат начинается с индекса 1

Пустой многомерный результат сохраняет ранг и границы остальных измерений. Обычно пустое выбранное измерение задаётся парой соседних индексов: нижняя граница на единицу больше верхней. Если ARRAYSLICE с count=0 получает start=INTEGER.MinValue или ARRAYSKIP пропускает всё измерение с верхней границей INTEGER.MaxValue, такую пару нельзя задать допустимыми индексами; выбранное измерение получает границы 1 TO 0. Результат остаётся выделенным массивом длины 0. Нижняя граница исходного массива INTEGER.MinValue по-прежнему запрещена: это значение зарезервировано для поиска.

DIM values(2147483647 TO 2147483647, 7 TO 7) AS INTEGER
DIM part(,) AS INTEGER
part = ARRAYSKIP(values, 1, 1)
PRINT ARRAYLENGTH(part)  ' 0
PRINT LBOUND(part, 1)    ' 1
PRINT UBOUND(part, 1)    ' 0
PRINT LBOUND(part, 2)    ' 7

Запускаемый пример: Пустое измерение у крайнего индекса.

Пример выборки диапазона

DIM values(1 TO 5) AS INTEGER
DIM part() AS INTEGER

part = ARRAYSLICE(values, 2, 3)

ARRAYPUSH

ARRAYPUSH — встроенная функция языка Axiom, которая добавляет элемент в конец одномерного динамического массива или целый срез в конец выбранного измерения многомерного массива. Функция нужна для последовательного накопления значений и работает в BytecodeVm; экранный и файловый режимы не требуются.

Синтаксис

Одномерная форма:

ARRAYPUSH(<массив>, <значение>)

Форма с явным выбором измерения:

ARRAYPUSH(<массив>, <значение>, <измерение>)

У многомерного массива измерение нужно указать явно. У одномерного массива допустим номер 1.

Как меняются границы после добавления

Для массива ранга 2 и выше <значение> должно иметь форму, согласованную со всеми остальными измерениями.

Верхняя граница выбранного измерения увеличивается на один, нижняя сохраняется. Функция изменяет массив и не возвращает отдельного значения. Аргумент <массив> должен быть выделенным динамическим массивом; представление нельзя расширять. Аргумент <значение> должен соответствовать типу элемента, а для многомерной формы — типу и форме добавляемого среза. Номер измерения должен иметь тип INTEGER.

Номер измерения должен лежать в диапазоне от 1 до ARRAYRANK(array). Недопустимый номер или отсутствие номера у многомерного массива вызывает MB3007 до изменения массива. Общие правила выбора измерения.

Диагностика при расширении

Невыделенный массив вызывает MB3005 с именами функции и аргумента. Если верхняя граница равна 2147483647, добавление вызывает MB3007 до изменения массива; прежние границы и элементы сохраняются. Запускаемая проверка отказа.

Пример добавления элемента

DIM values() AS INTEGER

REDIM values(1 TO 2)
values(1) = 10
values(2) = 20
ARRAYPUSH(values, 30)

ARRAYPOP

ARRAYPOP снимает последний элемент или последний срез и возвращает его как результат.

Синтаксис

ARRAYPOP(<массив>)
ARRAYPOP(<массив>, <измерение>)

Что возвращается при снятии элемента

После вызова исходный массив уменьшается. Для многомерного массива результатом становится отдельный массив, представляющий снятый срез.

Пример снятия последнего элемента

DIM values() AS INTEGER
DIM lastValue AS INTEGER

REDIM values(1 TO 3)
values(3) = 30
lastValue = ARRAYPOP(values)

Проверка номера измерения

Если номер измерения указан явно, он должен иметь тип INTEGER и лежать в диапазоне от 1 до ARRAYRANK(array). У одномерного массива допустим только номер 1. Недопустимый номер даёт MB3007 до изменения массива; ошибку можно перехватить оператором TRY/CATCH. Общие правила и пример проверки.

ARRAYINSERT

ARRAYINSERT — встроенная функция языка Axiom, которая вставляет элемент или срез по указанной позиции. Функция нужна для добавления значения перед уже существующими элементами и работает в BytecodeVm без специального режима.

Синтаксис

ARRAYINSERT(<массив>, <индекс>, <значение>)
ARRAYINSERT(<массив>, <индекс>, <значение>, <измерение>)

Как сдвигаются элементы после вставки

Все элементы после точки вставки сдвигаются. Для многомерного массива форма вставляемого значения должна соответствовать выбранному измерению.

Если выбранное измерение пусто, индекс вставки должен быть равен 1. После вставки выбранное измерение получает границы 1 TO 1, даже если пустая форма до вызова имела другие границы, например -4 TO -5. Границы остальных измерений сохраняются. Для одномерного пустого массива действует то же правило. Исходный массив должен быть выделен; изменение размера представления массива запрещено.

Пример вставки в пустую таблицу

DIM seed(-4 TO -4, 7 TO 8) AS INTEGER
DIM table(,) AS INTEGER
DIM values(7 TO 8) AS INTEGER
values(7) = 42
values(8) = 43
table = ARRAYTAKE(seed, 0, 1)
ARRAYINSERT(table, 1, values, 1)
PRINT LBOUND(table, 1)
PRINT UBOUND(table, 1)
PRINT table(1, 7)

Программа выводит 1, 1 и 42. Запускаемый пример: empty_dimension.axm.

Пример вставки по индексу

DIM values() AS INTEGER

REDIM values(1 TO 3)
values(1) = 10
values(2) = 30
values(3) = 40
ARRAYINSERT(values, 2, 20)

Проверка номера измерения

Если номер измерения указан явно, он должен иметь тип INTEGER и лежать в диапазоне от 1 до ARRAYRANK(array). У одномерного массива допустим только номер 1. Недопустимый номер даёт MB3007 до изменения массива; ошибку можно перехватить оператором TRY/CATCH. Общие правила и пример проверки.

ARRAYREMOVE

ARRAYREMOVE удаляет элемент или срез по указанной позиции и возвращает удалённое значение.

Синтаксис

ARRAYREMOVE(<массив>, <индекс>)
ARRAYREMOVE(<массив>, <индекс>, <измерение>)

Как сдвигаются элементы после удаления

После удаления хвост массива сдвигается, а размер массива уменьшается. Для многомерного массива возвращается удалённый срез.

Пример удаления по индексу

DIM values() AS INTEGER
DIM removedValue AS INTEGER

REDIM values(1 TO 3)
values(1) = 10
values(2) = 20
values(3) = 30
removedValue = ARRAYREMOVE(values, 2)

Проверка номера измерения

Если номер измерения указан явно, он должен иметь тип INTEGER и лежать в диапазоне от 1 до ARRAYRANK(array). У одномерного массива допустим только номер 1. Недопустимый номер даёт MB3007 до изменения массива; ошибку можно перехватить оператором TRY/CATCH. Общие правила и пример проверки.
