Условия и выбор действий

Раздел условных конструкций объясняет, как программа выбирает действие по данным. Оператор IF проверяет логическое условие, а SELECT CASE сопоставляет одно значение с несколькими вариантами.

Условие

Операция сравнения отвечает на вопрос о значении и возвращает TRUE или FALSE. Этот результат определяет, какая ветвь программы выполнится:

DIM score AS INTEGER = 74
IF score >= 60 THEN
    PRINT "Зачёт"
ELSE
    PRINT "Нужно повторить"
END IF

Зачёт

Выбор конструкции

Используйте IF, когда условия относятся к разным данным или требуют логического объединения. Используйте SELECT CASE, когда выбираете действие по одному значению: категории, коду, диапазону или строке.

Ветвление выполняет только подходящий блок. После окончания выбранной ветви программа продолжает работу ниже всей условной конструкции. Имена, объявленные внутри ветви, имеют область видимости этой ветви.

Короткая проверка

Если в каждой ветви требуется одно действие, оператор IF можно записать на одной строке:

DIM count AS INTEGER = 0
IF count = 0 THEN PRINT "Пусто" ELSE PRINT "Есть данные"

Пример выводит Пусто. Часть ELSE необязательна. Однострочная форма не требует END IF; несколько действий и дополнительные условия ELSEIF записывают блочной формой. Подробные правила приведены в статье «Оператор IF».
