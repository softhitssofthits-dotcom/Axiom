Подпрограмма SUB

SUB объявляет именованную подпрограмму, которую можно вызывать по имени для выполнения набора действий. В отличие от FUNCTION, подпрограмма не возвращает значение как результат выражения.

Сводка

SUB подходит для именованных операций, где важен побочный эффект: вывод, изменение уже существующих переменных, группировка последовательности действий или ранний выход через RETURN без значения.

Синтаксис

SUB <имя>([<список параметров>])
    <инструкции>
END SUB
<имя>([<список аргументов>])

Параметры

  • <имя> — имя подпрограммы.
  • [<список параметров>] — необязательная часть. Если параметров нет, подпрограмма объявляется с пустыми круглыми скобками.
  • [<список аргументов>] — необязательная часть вызова. Если аргументов нет, вызов оформляется с пустыми круглыми скобками.

В текущей реализации все параметры SUB передаются по значению. Параметр имеет собственное локальное имя и обязательное объявление типа через AS <тип>.

SUB PrintPair(left AS STRING, right AS STRING)
    PRINT left; " / "; right
END SUB

Замечания

  • Подпрограммы объявляются блоком SUB ... END SUB.
  • Вызов оформляется как инструкция <имя>([<список аргументов>]).
  • Параметры и локальные объявления внутри SUB принадлежат области видимости этой подпрограммы.
  • Внутри SUB можно объявлять локальные SUB и FUNCTION. Они видны только внутри текущей внешней процедуры или функции.
  • Локальные SUB/FUNCTION в текущей версии разрешены только прямо в теле внешней процедуры или функции, а не внутри IF, FOR, WHILE, DO или SELECT CASE.
  • Локальная подпрограмма лексически захватывает параметры и локальные переменные внешней процедуры или функции, если они объявлены раньше по тексту самой локальной SUB.
  • Имена, объявленные ниже по тексту после локальной SUB, для неё недоступны и продолжают считаться необъявленными.
  • Даже после появления функций как значений подпрограмма SUB по-прежнему не может быть присвоена в переменную или передана как значение.
  • RETURN внутри SUB допустим только без значения и завершает выполнение подпрограммы досрочно.
  • Подпрограмма может читать и изменять уже существующие доступные переменные программы; сама по себе она не возвращает вычисленный результат вызывающему коду.

Ручная проверка

Для проверки базового объявления и вызова подпрограммы используйте готовые примеры.

  • SUB: базовый вызов подпрограммы
  • SUB: локальная вложенная подпрограмма
  • SUB: захват и изменение внешней локальной переменной
  • RETURN: досрочный выход из SUB

Примеры

SUB ShowBanner(text AS STRING)
    PRINT "=="; text; "=="
END SUB

ShowBanner("Axiom")
SUB CheckValue(value AS INTEGER)
    IF value < 0 THEN
        PRINT "Отрицательное значение недопустимо"
        RETURN
    END IF

    PRINT "Обработка продолжается"
END SUB

Диагностика

  • MB2006 — в SUB использован RETURN со значением.
  • MB2019 — попытка использовать SUB как значение.
