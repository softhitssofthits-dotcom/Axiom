Процедура SUB

Объявление процедуры, параметры и вызов по имени.

Процедуры и функции

Процедура SUB

Процедура SUB подходит для именованных действий, которые нужно вызывать по имени, но не нужно использовать как значение выражения. Через неё удобно собирать вывод, проверки, изменение уже доступных данных и другие шаги, где важен сам эффект выполнения, а не возвращаемый результат.

Сводка

SUB ... END SUB объявляет именованную процедуру. Процедура выполняет последовательность инструкций и вызывается по имени, но не возвращает значение как результат выражения.

Синтаксис

SUB name([parameterDeclaration[, anotherParameterDeclaration] ...])
    [statements]
    [RETURN]
END SUB
name([argument[, anotherArgument] ...])

Части записи

name задаёт имя процедуры.

parameterDeclaration обозначает объявление параметра вида parameterName AS parameterType.

statements обозначает любые допустимые инструкции внутри процедуры.

RETURN без значения завершает процедуру досрочно.

argument обозначает значение, которое передаётся при вызове процедуры. Если параметров несколько, аргументы перечисляются в том же порядке через запятую.

Замечания

На практике SUB выбирают тогда, когда код становится достаточно длинным или повторяющимся и его нужно вынести в отдельный именованный блок без превращения в вычисляющее выражение.

  • Процедуры объявляются блоком SUB ... END SUB.
  • Вызов процедуры оформляется как отдельная инструкция.
  • Параметры SUB в текущей реализации передаются по значению.
  • Параметры и локальные объявления внутри SUB принадлежат области видимости этой процедуры.
  • Внутри SUB допустим RETURN без значения для досрочного выхода.
  • SUB не является значением: процедуру нельзя присваивать переменной, передавать как значение или возвращать из функции.
  • Внутри SUB можно объявлять локальные SUB и локальные FUNCTION.
  • Локальная процедура или функция может захватывать параметры и локальные переменные внешней процедуры, если они объявлены раньше по тексту.

Пример

' Процедура печатает строку вида ==Axiom==
' Ожидаемый вывод: ==Axiom==
SUB ShowBanner(text AS STRING)
    PRINT "=="; text; "=="
END SUB

ShowBanner("Axiom")

Ручная проверка

  • SUB: базовый вызов процедуры
  • SUB: локальная вложенная процедура
  • SUB: захват внешней локальной переменной
  • RETURN: досрочный выход из SUB

Диагностика

Ошибки возникают, если в SUB используется RETURN со значением или если предпринимается попытка использовать саму процедуру как значение.
