Регулярные выражения

Регулярное выражение — строковый шаблон для поиска текста по форме, а не по буквальному фрагменту. Встроенные функции REGEXISMATCH, REGEXMATCH, REGEXEXTRACT, REGEXMATCHES, REGEXEXTRACTALL, REGEXSPLIT, REGEXREPLACE и REGEXCOUNT проверяют, извлекают, разделяют, заменяют и считают совпадения.

Аргументы и режимы

Параметры STRING text и pattern задают текст и шаблон. Необязательный STRING modes объединяет режимы, например "im"; без него поиск выполняется в обычном режиме.

Режим Назначение
iНе различать строчные и прописные буквы.
mСчитать начало и конец каждой строки отдельными границами для ^ и $.
sРазрешить точке . совпадать с переводом строки.
xИгнорировать незначащие пробелы в образце, если они не экранированы и не входят в набор символов.

Шаблон обрабатывается движком .NET Regex. В таблицах приведены основные конструкции, применяемые в подтверждённых примерах Axiom; они составляют язык шаблона внутри строкового аргумента, а не синтаксис самой программы.

Основные правила

  • Нулевая группа представляет всё совпадение. Захватывающие группы нумеруются по правилам .NET, включая явно заданные непоследовательные номера.
  • REGEXMATCHES и REGEXEXTRACTALL при отсутствии совпадений возвращают массив 1 TO 0. REGEXSPLIT также возвращает массив строк, но при отсутствии разделителя сохраняет непустой текст одним элементом.
  • Неверный pattern, неизвестный modes и отрицательный groupNumber вызывают MB3007. Отсутствующая положительная группа даёт пустую строку. При count = 0 REGEXREPLACE пропускает проверку pattern и modes; выражения аргументов всё равно вычисляются.

Unicode и пустые совпадения

Движок сопоставляет единицы UTF-16. Для текста "😀" шаблон "." имеет два совпадения, пустой шаблон — три, по одному на каждой границе. Извлечённый фрагмент может содержать половину суррогатной пары.

Пустой STRING от REGEXMATCH может означать отсутствие совпадения либо успешное пустое совпадение. REGEXISMATCH позволяет их различить. Для пустого text и пустого pattern функция REGEXMATCHES возвращает один пустой элемент; REGEXSPLIT при пустом text возвращает пустой массив. При непустом text разбиение сохраняет крайние пустые части и захватывающие группы разделителя.

Ограничение поиска по времени

Для отдельного поиска установлен предел пять секунд. Превышение вызывает MB3007, доступную для обработки в TRY/CATCH. Предел относится к поиску движка, а не к суммарному времени программы или всех совпадений.

Отмена и ресурсы

При остановке программы исполнитель проверяет запрос отмены перед поиском, после него и между совпадениями. Отмена завершает запуск и не является ошибкой MB3007: пользовательские CATCH и FINALLY не выполняются. Уже начавшийся отдельный поиск движка не прерывается немедленно; до следующей проверки отмены он может занять до пяти секунд. Общее время всех совпадений не ограничивается пятью секундами.

Исполнитель хранит не более 128 последних использованных сочетаний шаблона и режимов. Вытеснение записи влияет только на повторную подготовку шаблона, а не на результат. Разные записи одинаковых режимов, например i, I и ii, не создают отдельные сохранённые строки режимов.

REGEXCOUNT подсчитывает совпадения без коллекции их объектов. Массивные функции выделяют память под результат; число результатов и их длина по-прежнему влияют на расход памяти. REGEXREPLACE выполняет буквальную замену за один проход без предварительного повторного поиска.

Сообщения об ошибках

В поле Message значения ошибки сохраняются английское описание причины и имя аргумента. Неверный шаблон сообщает Invalid pattern, смещение и вид ошибки разбора; неизвестный режим — Unknown mode и допустимые буквы; отрицательная группа или количество — cannot be negative; превышение времени — Pattern matching exceeded the 5 second timeout. Смещение разбора относится к строке шаблона. Поля Line и Column указывают место вызова в программе.

Синтаксис шаблонов

Обратная косая черта в строке Axiom сохраняется буквально. Для класса цифр pattern содержит одну косую черту: \d. Две косые черты нужны самому шаблону для поиска буквальной косой черты. Пример: pattern_backslash.axm.

Повторители в таблице относятся к непосредственно предшествующему элементу: символу, классу или группе. Скобки позволяют объединить последовательность перед применением повторителя.

Буквальные символы и классы

Запись Значение
abcБуквальное совпадение со строкой abc.
.Одна единица UTF-16, кроме LF (CHR(10)). CR (CHR(13)) совпадает и без режима s. В режиме s точка включает также LF.
[abc]Один символ из набора: a, b или c.
[^abc]Один символ, кроме перечисленных в наборе.
[a-z]Один символ из диапазона.
\dЦифра.
\DЛюбой символ, кроме цифры.
\wБуква, десятичная цифра Unicode, комбинируемый знак категории Mn или соединительный знак пунктуации, включая подчёркивание. Например, знак U+0301 также совпадает с \w.
\WЛюбой символ, кроме \w.
\sПробельный символ: пробел, табуляция, перевод строки и подобные.
\SЛюбой символ, кроме пробельного.
\t, \r, \nТабуляция, возврат каретки и перевод строки.
\\Обратная косая черта как буквальный символ.
\., \*, \+, \?Спецсимвол как обычный текст, а не как команда regex.

Повторы и жадность

Запись Значение
*Ноль или больше повторений предыдущего элемента.
+Одно или больше повторений предыдущего элемента.
?Ноль или одно повторение предыдущего элемента.
{n}Ровно n повторений.
{n,}Не меньше n повторений.
{n,m}От n до m повторений включительно.
*?, +?, ??, {n,m}?Нежадные формы: берут минимально возможное совпадение.

Шаблон "[,;]\s*" выбирает запятую либо точку с запятой и следующие за ней пробельные символы; повторитель * разрешает отсутствие таких пробелов.

Границы, группы и ветвление

Запись Значение
^Начало текста. В режиме m также начало каждой строки.
$Конец текста либо позиция перед завершающим LF. В режиме m также позиция перед каждым LF. CR перед LF не пропускается автоматически.
\A, \zСтрогое начало и конец всего текста независимо от режима m. Для проверки всего текста используйте "\Aa\d+\z".
(...)Захватывающая группа. Её можно извлекать через REGEXEXTRACT и REGEXEXTRACTALL.
(?:...)Незахватывающая группа: группирует шаблон, но не создаёт номер группы.
a|bАльтернатива: подходит либо a, либо b.
\1, \2Обратная ссылка на уже захваченную группу по номеру.
(?<name>...)Именованная группа .NET.
\k<name>Обратная ссылка на именованную группу.

Проверки без захвата

Запись Значение
(?=...)Положительный просмотр вперёд: справа должен стоять указанный шаблон.
(?!...)Отрицательный просмотр вперёд: справа не должно быть указанного шаблона.
(?<=...)Положительный просмотр назад: слева должен стоять указанный шаблон.
(?<!...)Отрицательный просмотр назад: слева не должно быть указанного шаблона.

Когда регулярное выражение лучше обычного поиска

Шаблоны подходят для проверки формата, извлечения групп и работы с переменным разделителем. Для буквального фрагмента используйте строковый поиск и замену.

Запускаемые примеры

  • REGEXISMATCH: проверка совпадения
  • REGEXMATCHES: все совпадения
  • REGEXREPLACE: замена по шаблону
  • REGEXCOUNT: подсчёт совпадений
