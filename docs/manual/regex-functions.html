Функции регулярных выражений

Функции регулярных выражений позволяют проверять строку по образцу, брать первое или все совпадения, извлекать группы, разделять строку, заменять найденные части текста и считать количество совпадений.

Имена и историческая линия

Классический QuickBASIC не имел полноценного встроенного слоя регулярных выражений, а Visual Basic исторически давал более простую проверку через Like. Для Axiom выбрана современная линия имён вокруг REGEX...: REGEXMATCH, REGEXMATCHES и REGEXSPLIT согласованы с привычными операциями Match, Matches и Split, а REGEXEXTRACTALL является массивной парой к REGEXEXTRACT.

Главные правила

  • Первый аргумент всегда содержит исходный текст, второй аргумент содержит регулярное выражение.
  • Если совпадение не найдено, REGEXMATCH и REGEXEXTRACT возвращают пустую строку.
  • REGEXEXTRACT использует номер группы: 0 означает всё найденное совпадение, 1 — первую группу в скобках, 2 — вторую группу и так далее.
  • Номер группы не может быть отрицательным; нарушение даёт диагностику времени выполнения MB3007.
  • REGEXMATCHES, REGEXEXTRACTALL и REGEXSPLIT возвращают новый массив STRING() с компактными границами 1 TO N; пустой результат получает форму 1 TO 0.
  • REGEXREPLACE заменяет все совпадения, если не указано ограничение количества замен.
  • Количество замен в REGEXREPLACE не может быть отрицательным; значение 0 возвращает исходный текст без изменений.
  • В строке замены можно ссылаться на группы через $1, $2 и последующие номера.
  • Каждая операция по регулярному выражению ограничена пятью секундами. При превышении ограничения выполнение завершается диагностикой MB3007.
  • Недопустимое регулярное выражение или неизвестный режим также дают диагностику времени выполнения MB3007.

Режимы поиска

Необязательный аргумент <режимы> задаётся строкой. Режимы можно объединять, например "im".

Режим Назначение
i Не различать строчные и прописные буквы.
m Считать начало и конец каждой строки отдельными границами для ^ и $.
s Позволить точке . совпадать с переводом строки.
x Игнорировать незначащие пробелы в регулярном выражении, если они не экранированы и не входят в набор символов.

REGEXISMATCH

Формы вызова:

REGEXISMATCH(<текст> AS STRING, <образец> AS STRING) AS BOOLEAN
REGEXISMATCH(<текст> AS STRING, <образец> AS STRING, <режимы> AS STRING) AS BOOLEAN

Возвращает TRUE, если в тексте найдено хотя бы одно совпадение с регулярным выражением. Если совпадений нет, возвращает FALSE.

PRINT REGEXISMATCH("A12", "\d+")
PRINT REGEXISMATCH("A12", "^a\d+", "i")

REGEXMATCH

Формы вызова:

REGEXMATCH(<текст> AS STRING, <образец> AS STRING) AS STRING
REGEXMATCH(<текст> AS STRING, <образец> AS STRING, <режимы> AS STRING) AS STRING

Возвращает первое найденное совпадение целиком. Если совпадение не найдено, возвращает пустую строку.

PRINT REGEXMATCH("Order 42 and 100", "\d+")
PRINT "[" + REGEXMATCH("Order", "\d+") + "]"

REGEXEXTRACT

Формы вызова:

REGEXEXTRACT(<текст> AS STRING, <образец> AS STRING, <номер группы> AS INTEGER) AS STRING
REGEXEXTRACT(<текст> AS STRING, <образец> AS STRING, <номер группы> AS INTEGER, <режимы> AS STRING) AS STRING

Возвращает значение указанной группы из первого найденного совпадения. Если совпадение не найдено или указанной группы нет, возвращает пустую строку.

PRINT REGEXEXTRACT("A12", "([A-Z])(\d+)", 2)
PRINT REGEXEXTRACT("a12", "([A-Z])(\d+)", 1, "i")

REGEXMATCHES

Формы вызова:

REGEXMATCHES(<текст> AS STRING, <образец> AS STRING) AS STRING()
REGEXMATCHES(<текст> AS STRING, <образец> AS STRING, <режимы> AS STRING) AS STRING()

Возвращает все найденные совпадения целиком как новый массив строк. Если совпадений нет, возвращает пустой выделенный массив с границами 1 TO 0.

DIM values() AS STRING
values = REGEXMATCHES("Order 42 and 100", "\d+")
PRINT values(1)
PRINT values(2)

REGEXEXTRACTALL

Формы вызова:

REGEXEXTRACTALL(<текст> AS STRING, <образец> AS STRING, <номер группы> AS INTEGER) AS STRING()
REGEXEXTRACTALL(<текст> AS STRING, <образец> AS STRING, <номер группы> AS INTEGER, <режимы> AS STRING) AS STRING()

Возвращает значения указанной группы из всех найденных совпадений. Группа 0 означает всё совпадение целиком. Если для отдельного совпадения указанной группы нет, соответствующий элемент массива получает пустую строку.

DIM values() AS STRING
values = REGEXEXTRACTALL("A12 B34", "([A-Z])(\d+)", 2)
PRINT values(1)
PRINT values(2)

REGEXSPLIT

Формы вызова:

REGEXSPLIT(<текст> AS STRING, <образец> AS STRING) AS STRING()
REGEXSPLIT(<текст> AS STRING, <образец> AS STRING, <режимы> AS STRING) AS STRING()

Разделяет строку по совпадениям регулярного выражения и возвращает части как новый массив строк. Пустые части сохраняются, если совпадение стоит в начале, в конце или рядом с другим совпадением. Для пустого исходного текста возвращается пустой массив 1 TO 0.

DIM parts() AS STRING
parts = REGEXSPLIT("one, two;three", "[,;]\s*")
PRINT parts(1)
PRINT parts(2)
PRINT parts(3)

REGEXREPLACE

Формы вызова:

REGEXREPLACE(<текст> AS STRING, <образец> AS STRING, <замена> AS STRING) AS STRING
REGEXREPLACE(<текст> AS STRING, <образец> AS STRING, <замена> AS STRING, <режимы> AS STRING) AS STRING
REGEXREPLACE(<текст> AS STRING, <образец> AS STRING, <замена> AS STRING, <количество> AS INTEGER) AS STRING
REGEXREPLACE(<текст> AS STRING, <образец> AS STRING, <замена> AS STRING, <режимы> AS STRING, <количество> AS INTEGER) AS STRING

Возвращает новую строку, где найденные совпадения заменены указанной строкой. Если указан аргумент <количество>, заменяются только первые найденные совпадения в указанном количестве.

PRINT REGEXREPLACE("one 12 two 34", "\d+", "#")
PRINT REGEXREPLACE("one 12 two 34", "\d+", "#", 1)
PRINT REGEXREPLACE("A12 B34", "([A-Z])(\d+)", "$1-$2")

REGEXCOUNT

Формы вызова:

REGEXCOUNT(<текст> AS STRING, <образец> AS STRING) AS INTEGER
REGEXCOUNT(<текст> AS STRING, <образец> AS STRING, <режимы> AS STRING) AS INTEGER

Возвращает количество найденных совпадений. Если совпадений нет, результат равен 0.

PRINT REGEXCOUNT("one 12 two 34", "\d+")
PRINT REGEXCOUNT("A12 b34", "[a-z]\d+", "i")

Примеры для ручной проверки

  • REGEXISMATCH: базовое использование
  • REGEXMATCH: первое совпадение
  • REGEXEXTRACT: извлечение группы
  • REGEXMATCHES: все совпадения
  • REGEXEXTRACTALL: группы из всех совпадений
  • REGEXSPLIT: разделение по образцу
  • REGEXREPLACE: замена и ограничение количества
  • REGEXCOUNT: подсчёт совпадений
  • REGEXISMATCH: ошибка в образце
  • REGEXISMATCH: неизвестный режим
  • REGEXEXTRACTALL: отрицательный номер группы
  • REGEXREPLACE: отрицательное количество замен
