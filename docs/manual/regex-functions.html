Раздел

Функции регулярных выражений

Раздел функций регулярных выражений описывает средства Axiom для поиска по образцу, проверки соответствия шаблону, извлечения совпадений и групп, разбиения строки и замены найденных фрагментов — там, где обычного поиска подстроки уже недостаточно.

Аргументы и режимы

Первые два аргумента почти у всех функций одинаковы: text задаёт исходную строку, а pattern регулярное выражение. Необязательный аргумент modes задаётся строкой и может объединять несколько режимов сразу, например "im".

Режим Назначение
iНе различать строчные и прописные буквы.
mСчитать начало и конец каждой строки отдельными границами для ^ и $.
sРазрешить точке . совпадать с переводом строки.
xИгнорировать незначащие пробелы в образце, если они не экранированы и не входят в набор символов.

Axiom не вводит отдельный урезанный язык шаблонов: аргумент pattern передаётся в движок .NET Regex. В таблицах ниже показан основной рабочий синтаксис, который уже используется в справочных примерах; для редких возможностей .NET Regex проверяйте поведение отдельным коротким примером.

Основные правила

  • Группа 0 означает всё совпадение. Нумерация захватывающих групп соответствует .NET; явно заданные числовые номера поддерживаются и не обязаны идти подряд.
  • REGEXMATCHES, REGEXEXTRACTALL и REGEXSPLIT возвращают массив строк. Если совпадений нет, результатом обычно становится пустой массив с границами 1 TO 0.
  • Неверный шаблон, неизвестный режим и отрицательный номер группы дают MB3007. Несуществующий положительный номер группы возвращает пустую строку. REGEXREPLACE с count=0 возвращает исходный текст без проверки шаблона и режимов, но выражения аргументов всё равно вычисляются.

Unicode и пустые совпадения

Шаблоны работают с единицами UTF-16 по правилам .NET. REGEXCOUNT("😀", ".") возвращает 2, а REGEXCOUNT("😀", "") возвращает 3: пустой шаблон совпадает на каждой границе UTF-16. Результат совпадения может содержать отдельную половину суррогатной пары.

REGEXMATCH возвращает пустую строку как при отсутствии совпадения, так и при успешном пустом совпадении. Эти случаи можно различить функцией REGEXISMATCH. REGEXMATCHES для пустого текста и пустого шаблона возвращает массив из одной пустой строки. REGEXSPLIT для пустого входного текста возвращает пустой массив; при непустом тексте сохраняет крайние пустые части и захватывающие группы разделителя.

Ограничение поиска по времени

Встроенный движок Regex настроен на предел поиска в пять секунд. Если отдельный поиск слишком долгий, функция даёт MB3007, которую можно перехватить через TRY/CATCH. Это защита от тяжёлого перебора шаблона, а не гарантия общего времени программы или всего набора совпадений.

Синтаксис шаблонов

Строки Axiom не используют обратную косую черту как специальное экранирование. Класс цифр записывается в pattern как \d, с одной косой чертой. Если требуется сопоставить саму обратную косую черту, удвоение необходимо уже по правилам регулярного выражения. Пример: запись класса цифр в строке Axiom.

В таблицах ниже собраны основные конструкции, которые можно писать в аргументе pattern. Во всех случаях повторитель относится к предыдущему элементу шаблона: символу, классу, группе или подшаблону.

Буквальные символы и классы

Запись Значение
abcБуквальное совпадение со строкой abc.
.Любой одиночный символ, кроме перевода строки. В режиме s включает и перевод строки.
[abc]Один символ из набора: a, b или c.
[^abc]Один символ, кроме перечисленных в наборе.
[a-z]Один символ из диапазона.
\dЦифра.
\DЛюбой символ, кроме цифры.
\wБуква, цифра или подчёркивание.
\WЛюбой символ, кроме \w.
\sПробельный символ: пробел, табуляция, перевод строки и подобные.
\SЛюбой символ, кроме пробельного.
\t, \r, \nТабуляция, возврат каретки и перевод строки.
\\Обратная косая черта как буквальный символ.
\., \*, \+, \?Спецсимвол как обычный текст, а не как команда regex.

Повторы и жадность

Запись Значение
*Ноль или больше повторений предыдущего элемента.
+Одно или больше повторений предыдущего элемента.
?Ноль или одно повторение предыдущего элемента.
{n}Ровно n повторений.
{n,}Не меньше n повторений.
{n,m}От n до m повторений включительно.
*?, +?, ??, {n,m}?Нежадные формы: берут минимально возможное совпадение.

Например, в шаблоне "[,;]\s*" часть [,;] означает «запятая или точка с запятой», а \s* означает «после разделителя может идти ноль или больше пробельных символов».

Границы, группы и ветвление

Запись Значение
^Начало текста. В режиме m также начало каждой строки.
$Конец текста. В режиме m также конец каждой строки.
(...)Захватывающая группа. Её можно извлекать через REGEXEXTRACT и REGEXEXTRACTALL.
(?:...)Незахватывающая группа: группирует шаблон, но не создаёт номер группы.
a|bАльтернатива: подходит либо a, либо b.
\1, \2Обратная ссылка на уже захваченную группу по номеру.
(?<name>...)Именованная группа .NET.
\k<name>Обратная ссылка на именованную группу.

Проверки без захвата

Запись Значение
(?=...)Положительный просмотр вперёд: справа должен стоять указанный шаблон.
(?!...)Отрицательный просмотр вперёд: справа не должно быть указанного шаблона.
(?<=...)Положительный просмотр назад: слева должен стоять указанный шаблон.
(?<!...)Отрицательный просмотр назад: слева не должно быть указанного шаблона.

Когда регулярное выражение лучше обычного поиска

Этот раздел нужен для задач вроде проверки формата идентификатора, поиска всех чисел в тексте, извлечения частей по шаблону, разбиения строки по сложному разделителю или массовой замены по образцу. Если достаточно обычного поиска и замены без шаблонов, удобнее использовать строковые функции.

Ручная проверка

  • REGEXISMATCH: проверка совпадения
  • REGEXMATCHES: все совпадения
  • REGEXREPLACE: замена по шаблону
  • REGEXCOUNT: подсчёт совпадений
