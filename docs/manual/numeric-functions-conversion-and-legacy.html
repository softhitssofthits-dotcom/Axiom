Округление и преобразование чисел

Раздел округления и преобразования чисел описывает встроенные функции INT, STR и VAL — переход от строки к числу, от числа к строке и округление числа вниз.

INT

Функция INT округляет число вниз и возвращает результат в типе INTEGER.

Синтаксис

result = INT(value)

Аргументы

value задаёт числовое выражение. Результат всегда имеет тип INTEGER, даже если исходное значение было DOUBLE или LONG.

Округление вниз

INT округляет именно вниз, а не к нулю. Поэтому INT(3.9) даёт 3, а INT(-3.9) даёт -4. Если итоговое значение не помещается в диапазон INTEGER, выполнение завершается диагностикой переполнения.

Пример округления вниз

' Округление вниз для положительных и отрицательных значений
PRINT INT(7.8)
PRINT INT(-7.8)

Результат:

7
-8

STR

Функция STR преобразует число в строку.

Синтаксис

text = STR(value)

Аргументы

value задаёт числовое выражение любого поддерживаемого числового типа. Результат имеет тип STRING.

Текстовое представление числа

STR удобна, когда числовое значение нужно объединить с другим текстом, записать в файл или показать через PRINT как часть более длинной строки. Для обратного преобразования используется VAL.

Пример STR

' Преобразование числа в строку перед объединением
DIM amount AS DOUBLE

amount = 12.5
PRINT "Сумма: " + STR(amount)

Результат:

Сумма: 12.5

VAL

Функция VAL читает число из строки и возвращает результат в типе DOUBLE.

Синтаксис

result = VAL(text)

Аргументы

text задаёт строку, которую нужно интерпретировать как число.

Некорректный текст

Если строка не содержит корректного числового представления, VAL возвращает 0. Поэтому при чтении пользовательского ввода удобно заранее понимать, допускается ли такое значение как осмысленный результат, или дополнительно проверять исходный текст.

Функция VAL возвращает только конечное число DOUBLE. Строки "NaN", "Infinity" и числа, выходящие за диапазон DOUBLE, например "1e309", дают 0. Числовое начало строки сохраняется: VAL("12abc") возвращает 12.

Правила чтения числа

  • десятичным разделителем служит только точка: VAL("1.5") даёт 1.5;
  • запятая внутри числа игнорируется как разделитель групп разрядов, поэтому VAL("1,5") даёт 15, а не 1.5;
  • начальные и конечные пробелы допустимы: VAL(" 12 ") даёт 12;
  • знак ставится перед числом: VAL("-4.5") даёт -4.5, а VAL("+7") даёт 7;
  • экспоненциальная запись поддерживается: VAL("1e2") даёт 100;
  • шестнадцатеричные записи вида &HFF не читаются: VAL("&HFF") даёт 0;
  • если число стоит в начале строки, а дальше следует текст, числовая часть читается: VAL("12abc") даёт 12.

Пример чтения числа из строки

' Преобразование строкового значения в число
DIM text AS STRING

text = "125.75"
PRINT VAL(text) + 10

Результат:

135.75

CINT, CLNG, CDBL и CDEC

Функции CINT, CLNG, CDBL и CDEC явно преобразуют числовое значение к целевому типу: INTEGER, LONG, DOUBLE и DECIMAL. Явные сужающие присваивания в языке запрещены, поэтому эти функции — законная дверь для сужения.

Синтаксис

result = CINT(value)
result = CLNG(value)
result = CDBL(value)
result = CDEC(value)

Аргументы

Аргумент value задаёт числовое значение любого числового типа.

Правила преобразования

  • дробная часть отбрасывается усечением к нулю: CINT(-2.9) даёт -2 (для округления по правилам используйте ROUND, для пола — INT);
  • диапазон CINT проверяется после усечения: CINT(2147483647.9) возвращает 2147483647, а CINT(-2147483648.9) — -2147483648;
  • для функции CLNG значение DOUBLE, равное 2^63, уже выходит за верхнюю границу LONG и даёт MB3008; значение -2^63 допустимо;
  • выход за диапазон целевого типа даёт диагностику MB3008 о переполнении;
  • функция CINT также сообщает MB3008, если исходное значение DOUBLE равно NaN или положительной либо отрицательной бесконечности: такие значения нельзя представить целым числом;
  • CDEC точно представляет все значения INTEGER и LONG. CDBL точно представляет INTEGER, но большие LONG и значения DECIMAL могут округляться при переходе к двоичному DOUBLE.

Явный переход из DECIMAL в DOUBLE

CDBL — встроенная функция языка Axiom, которая возвращает DOUBLE для числового аргумента. Она работает в BytecodeVm без экранного или файлового режима. Аргумент может иметь тип INTEGER, LONG, DOUBLE или DECIMAL. Преобразование не меняет исходную переменную, но может уменьшить точность результата.

MIN, MAX и CLAMP не принимают DECIMAL вместе с DOUBLE без явного преобразования. Если для расчёта выбрана двоичная арифметика, используйте CDBL для десятичного аргумента. Весь диапазон конечных значений DECIMAL помещается в диапазон DOUBLE; это не означает сохранения всех значащих цифр. Неверный нечисловой аргумент отклоняется при проверке типов.

DIM exact AS DECIMAL = CDEC(CLNG(9007199254740993))
' DOUBLE округляет это целое до соседнего представимого значения.
PRINT CLNG(CDBL(exact))  ' 9007199254740992
' Исходное десятичное значение осталось точным.
PRINT exact = CDEC(CLNG(9007199254740993))  ' TRUE
PRINT MIN(CDBL(CDEC(2)), 3.0)  ' 2

Запускаемый пример: Десятичное значение и точность DOUBLE.

Пример явного сужения

' LONG в INTEGER через явное преобразование
DIM big AS LONG
DIM small AS INTEGER
big = 42
small = CINT(big)
PRINT small

Обработка ошибки CINT

Диагностику MB3008 функции CINT можно обработать в блоке CATCH. Блок FINALLY выполняется после ошибки, а после завершения оператора TRY программа продолжает работу.

TRY
    ' Число выходит за диапазон INTEGER.
    PRINT CINT(2147483648.0)
CATCH err
    PRINT "Поймана ошибка:", err.Code
FINALLY
    PRINT "Обработка завершена."
END TRY

Выбор между INT, STR и VAL

  • INT и FIX похожи только на первый взгляд: INT округляет вниз, а FIX отбрасывает дробную часть к нулю.
  • STR и VAL часто используются парой, когда программа читает текстовые данные, а затем возвращает числовой результат обратно в строку.
  • Если нужен числовой результат строго типа INTEGER, используйте INT. Если нужно сохранить исходный числовой тип, обычно подходят FLOOR, CEIL, ROUND или FIX.

Запускаемые примеры

  • INT: округление вниз
  • INT: переполнение результата
  • STR: преобразование числа в строку
  • VAL: чтение числа из строки
  • VAL: некорректный текст возвращает 0

Проверка строки до преобразования

Для проверки полного конечного числа используй встроенную функцию ISNUMERIC. В отличие от VAL, она отклоняет строку с числовым префиксом и текстовым хвостом.
