Обрезка, регистр и разворот

В этом разделе описаны встроенные функции языка Axiom TRIM, LTRIM, RTRIM, LCASE, UCASE, REVERSE. Они обрабатывают текст и возвращают результат без изменения исходной строки. Ниже приведён отдельный синтаксис и договор каждой функции.

Выбор преобразования

Функции TRIM, LTRIM и RTRIM удаляют заполнение у краёв строки; LCASE и UCASE меняют регистр; REVERSE меняет порядок кодов Unicode. Каждая функция ниже имеет собственный синтаксис и результат.

TRIM

TRIM — встроенная функция языка Axiom, которая возвращает строку после удаления заданных символов с обоих краёв текста.

Назначение и контекст

Функция помогает убрать лишнее заполнение с обоих краёв строки, сохранив её содержимое.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма 1:

TRIM(<текст>)

Форма 2:

TRIM(<текст>, <символы>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.
<символы>Передайте строку типа STRING, перечисляющую удаляемые кодовые единицы UTF-16. Это набор отдельных символов, а не подстрока. Если аргумент отсутствует, удаляются пробельные символы, распознаваемые .NET.

Возвращаемое значение

Функция возвращает строку типа STRING после обрезки.

Правила и пограничные случаи

Пустой текст остаётся пустым. Пустой набор символов оставляет текст без изменения. Удаление продолжается до первого символа, который не входит в набор; внутри текста символы сохраняются. Форма без набора удаляет также табуляцию и другие пробельные символы, а не только обычный пробел.

Диагностика

Функция не имеет специальной ошибки для пустого текста или пустого набора. Неверные типы и число аргументов отклоняются при проверке программы.

Пример

PRINT "[" + TRIM("  A  ") + "]"
PRINT TRIM("--A--", "-")
PRINT "[" + TRIM("") + "]"

Программа выводит:

[A]
A
[]

LCASE

LCASE — встроенная функция языка Axiom, которая возвращает строку, преобразовав буквы в нижний регистр.

Назначение и контекст

Функция нужна, когда текст требуется представить в одном регистре.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма вызова:

LCASE(<текст>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.

Возвращаемое значение

Функция возвращает строку типа STRING.

Правила и пограничные случаи

Преобразование использует неизменяемые правила культуры .NET и не зависит от региональных настроек пользователя. Пустая строка остаётся пустой. Символы без соответствующего регистра сохраняются.

Диагностика

Неверные типы и число аргументов отклоняются при проверке программы.

Пример

PRINT LCASE("ПрИвЕт")
PRINT "["+LCASE("")+"]"

Программа выводит:

привет
[]

REVERSE

REVERSE — встроенная функция языка Axiom, которая возвращает строку с обратным порядком кодов Unicode.

Назначение и контекст

Функция позволяет развернуть последовательность символов, сохраняя целыми корректные суррогатные пары.

Функция вызывается в выражении и не требует открытия экрана, холста или файла. Исходные значения аргументов не изменяются.

Синтаксис

Форма вызова:

REVERSE(<текст>)

Аргументы

АргументЧто передать
<текст>Передайте исходную строку типа STRING, которую функция должна обработать.

Возвращаемое значение

Функция возвращает строку типа STRING.

Правила и пограничные случаи

Пустая строка остаётся пустой. Корректная суррогатная пара сохраняется целиком. Отдельные знаки ударения и части составных эмодзи меняют порядок независимо: функция не разворачивает строку по графемам. Изолированные кодовые единицы UTF-16 сохраняются без подмены.

Диагностика

Неверные типы и число аргументов отклоняются при проверке программы.

Пример

PRINT REVERSE("А😀Б")
PRINT "["+REVERSE("")+"]"

Программа выводит:

Б😀А
[]
