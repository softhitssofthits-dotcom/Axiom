Раздел

Обрезка, регистр и разворот строки

Раздел обрезки, регистра и разворота описывает функции TRIM, LTRIM, RTRIM, LCASE, UCASE и REVERSE — средства удаления символов по краям, смены регистра и обратного порядка символов.

Функции этой страницы возвращают новую строку на основе исходной: удаляют лишние символы по краям, переводят буквы в другой регистр или меняют порядок символов на обратный. Исходное значение при этом не изменяется само по себе.

Общие правила и границы

Ни одна из функций не требует экранного или файлового режима. Все аргументы text и chars должны быть строками; результаты имеют тип STRING. Неверный тип отклоняется при проверке типов до исполнения. Пустая исходная строка даёт пустую строку во всех функциях этой страницы.

TRIM, LTRIM и RTRIM без chars удаляют пробельные символы Unicode, включая неразрывный пробел U+00A0 и U+2003. Символ U+200B не удаляется. Явный chars является набором отдельных единиц UTF-16, а не искомой подстрокой: TRIM("абЯба", "аб") возвращает "Я". Пустой набор ничего не удаляет. Если в chars включён эмодзи, его две единицы участвуют в наборе отдельно; обрезка может оставить изолированный суррогат. Для обработки целых фрагментов используйте строковый поиск и срезы с проверенными границами.

LCASE и UCASE используют правила регистра, не зависящие от выбранной культуры компьютера. Кириллица преобразуется непосредственно: UCASE("пример") возвращает "ПРИМЕР". Самодельная функция перекодировки русских букв не требуется. Изолированные единицы UTF-16 сохраняются. Смена регистра не выполняет нормализацию Unicode.

TRIM

Встроенная функция TRIM убирает символы с обоих краёв строки.

Синтаксис

Удаление пробельных символов:

result = TRIM(text)

Удаление указанного набора:

result = TRIM(text, chars)

Аргументы

text задаёт исходную строку. Необязательный chars задаёт набор символов, которые удаляются по краям.

Удаляемые символы

Без аргумента chars удаляются пробельные символы. Если chars указан, по краям убираются все символы из этого набора.

Пример удаления пробелов с двух сторон

PRINT "[" + TRIM("abc   ") + "]"
PRINT "[" + TRIM("   abc") + "]"
PRINT "[" + TRIM("...abc...", ".") + "]"

Результат:

[abc]
[abc]
[abc]

LTRIM

Встроенная функция LTRIM убирает символы только слева.

Синтаксис

Удаление пробельных символов:

result = LTRIM(text)

Удаление указанного набора:

result = LTRIM(text, chars)

Аргументы

text задаёт исходную строку. Необязательный chars задаёт набор символов, которые удаляются слева.

Удаляемые символы

Без аргумента chars убираются пробельные символы слева. Если chars указан, убираются символы из этого набора.

Пример удаления начальных пробелов

PRINT "[" + LTRIM("   abc") + "]"
PRINT "[" + LTRIM("...abc", ".") + "]"

Результат:

[abc]
[abc]

RTRIM

Встроенная функция RTRIM убирает символы только справа.

Синтаксис

Удаление пробельных символов:

result = RTRIM(text)

Удаление указанного набора:

result = RTRIM(text, chars)

Аргументы

text задаёт исходную строку. Необязательный chars задаёт набор символов, которые удаляются справа.

Удаляемые символы

Без аргумента chars убираются пробельные символы справа. Если chars указан, убираются символы из этого набора.

Пример удаления конечных пробелов

PRINT "[" + RTRIM("abc   ") + "]"
PRINT "[" + RTRIM("abc...", ".") + "]"

Результат:

[abc]
[abc]

LCASE и UCASE

Функции LCASE и UCASE возвращают строку в нижнем или верхнем регистре.

Синтаксис

lowerText = LCASE(text)
upperText = UCASE(text)

Аргументы

text задаёт исходную строку.

Возвращаемое значение

Обе функции возвращают новое значение и не меняют исходную строку автоматически.

Пример смены регистра

PRINT LCASE("ПРИМЕР")
PRINT UCASE("пример")

Результат:

пример
ПРИМЕР

REVERSE

Функция REVERSE возвращает строку в обратном порядке символов.

Корректные пары UTF-16 остаются целыми: REVERSE("А😀Б") возвращает "Б😀А". Изолированные единицы UTF-16, полученные, например, функцией LEFT, сохраняются без подмены символом U+FFFD. Комбинируемые знаки разворачиваются отдельно от букв; функция не объединяет графемы. Пустая строка возвращается без изменений.

Синтаксис

result = REVERSE(text)

Аргументы

text задаёт исходную строку.

Пример обратного порядка символов

PRINT REVERSE("abcd")

Результат:

dcba
