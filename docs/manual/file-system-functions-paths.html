Встроенные функции

Пути и сведения о файлах

Эти функции помогают работать с путями, узнавать свойства файлов и папок, перечислять содержимое каталогов и получать сведения о диске, на котором находится путь.

FILESIZE

Функция FILESIZE возвращает размер файла в байтах.

Синтаксис

size = FILESIZE(path)

Части записи. path задаёт путь к файлу. Результат имеет тип LONG.

Пример вызова FILESIZE

' Размер файла в байтах
PRINT FILESIZE("notes.txt")

FILEDATE

Функция FILEDATE возвращает дату и время последнего изменения файла.

Синтаксис

Части записи. path задаёт путь к файлу. Результатом является строка даты и времени.

Пример вызова FILEDATE

' Дата последнего изменения файла
PRINT FILEDATE("notes.txt")

GETFILES

Функция GETFILES возвращает массив полных путей файлов, найденных в папке по маске.

Синтаксис

files = GETFILES(directoryPath[, mask])

Части записи. directoryPath задаёт папку поиска. Необязательный mask задаёт файловую маску, например "*.txt". Если маска не указана, возвращаются все файлы ближайшего уровня. Результатом является массив STRING().

Пример вызова GETFILES

' Список текстовых файлов в текущей папке
DIM files() AS STRING

files = GETFILES(".", "*.txt")
PRINT ARRAYLENGTH(files)

GETDIRS

Функция GETDIRS возвращает массив полных путей дочерних папок, найденных по маске.

Синтаксис

dirs = GETDIRS(directoryPath[, mask])

Части записи. directoryPath задаёт папку поиска. Необязательный mask задаёт маску для имён папок. Если маска не указана, возвращаются все дочерние папки ближайшего уровня. Результатом является массив STRING().

Пример вызова GETDIRS

' Список дочерних папок
DIM dirs() AS STRING

dirs = GETDIRS(".", "*")
PRINT ARRAYLENGTH(dirs)

COMBINEPATH

Функция COMBINEPATH соединяет две части пути в один корректный путь.

Синтаксис

path = COMBINEPATH(leftPart, rightPart)

Части записи. leftPart задаёт левую часть пути. rightPart задаёт правую часть. Результатом является строка.

Пример вызова COMBINEPATH

' Построение пути к подпапке
PRINT COMBINEPATH("docs", "manual")

FILENAME

Функция FILENAME возвращает имя файла вместе с расширением.

Синтаксис

Части записи. path задаёт путь к файлу или папке. Результатом является последняя часть пути, если она выглядит как имя файла.

Пример вызова FILENAME

' Имя файла из полного пути

Пример вызова PATHROOT

ISABSOLUTEPATH

Функция ISABSOLUTEPATH проверяет, является ли путь абсолютным уже в исходной записи.

Синтаксис

result = ISABSOLUTEPATH(path)

Части записи. path задаёт путь для проверки. Функция возвращает TRUE, если путь не зависит от текущей рабочей папки.

Пример вызова ISABSOLUTEPATH

PRINT ISABSOLUTEPATH(FULLPATH("notes.txt"))

Пути, метаданные и доступность

  • FILEDATE, FILECREATEDATE, FILEACCESSEDDATE и DIRDATE возвращают строку формата yyyy-MM-dd HH:mm:ss.
  • GETFILES и GETDIRS можно вызывать как с маской, так и без неё. В обоих случаях возвращается массив полных путей ближайшего уровня.
  • EXTNAME возвращает расширение вместе с точкой, например .txt.
  • DIRSIZE учитывает вложенные файлы, но не уходит в циклические ссылки и другие точки повторного обхода.

Диагностика

  • Отсутствие файла или папки для функций сведений и перечисления даёт диагностику времени выполнения MB3007.
  • Пустая маска в GETFILES и GETDIRS также даёт MB3007.
  • Переполнение суммарного размера в DIRSIZE даёт диагностику времени выполнения MB3008.

  • DIRSIZE: размер папки
  • ISREADONLY: атрибут только для чтения
  • ISHIDDEN: скрытый объект
