Оператор WINDOW

WINDOW — оператор языка Axiom, который задаёт логическую систему координат внутри текущего viewport. После оператора WINDOW программа может рисовать не по физическим пикселям экрана, а по собственной числовой шкале.

Когда использовать WINDOW

Оператор WINDOW нужен тогда, когда программе требуется рисовать графики, оси, фигуры или схемы не в пиксельных координатах, а в собственной логической системе координат.

Где работает оператор WINDOW

Оператор WINDOW работает только после выбора графического режима SCREEN 1..10.

Оператор WINDOW не открывает графический режим сам по себе. Перед оператором WINDOW программа должна вызвать оператор SCREEN.

Синтаксис

WINDOW
WINDOW SCREEN (left, top)-(right, bottom)
WINDOW (left, top)-(right, bottom)

Параметры и части синтаксиса

ЧастьОписание
left, top, right, bottomДве противоположные вершины логического прямоугольника.
SCREENСлово SCREEN сохраняет экранное направление оси Y, то есть увеличение Y вниз.

Что делает оператор WINDOW

Форма WINDOW без аргументов сбрасывает логическое окно и возвращает координаты к текущей системе viewport.

Форма WINDOW SCREEN (...) включает логическую систему координат с экранным направлением оси Y.

Форма WINDOW (...) включает логическую систему координат с математическим направлением оси Y, то есть увеличение Y вверх.

Правила работы

Оператор VIEW выбирает физическую область экрана, а оператор WINDOW задаёт логическую шкалу внутри этой области. Обычно программа сначала настраивает оператор VIEW, а затем при необходимости включает оператор WINDOW.

После оператора WINDOW логические координаты используют операторы PSET, PRESET, LINE, CIRCLE, PAINT, DRAW и форма POINT(x, y).

Для явного перевода между логическими координатами WINDOW и физическими координатами viewport программа использует функцию PMAP.

Диагностика

  • MB3010: оператор WINDOW вызван без активного графического режима SCREEN 1..10.
  • MB3007: границы логического окна имеют недопустимое значение или вырождают логический прямоугольник.

Пример

SCREEN 1
VIEW SCREEN (10, 10)-(20, 20)
WINDOW SCREEN (100, 200)-(110, 210)

PSET (100, 200), 12
PRINT PMAP(100, 0); ","; PMAP(200, 1)
SLEEP

В этом примере оператор WINDOW связывает логические координаты 100..110 и 200..210 с физическим viewport. После этого оператор PSET рисует не по сырым пикселям, а по логической шкале.
