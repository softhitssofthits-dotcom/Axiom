Оператор CONTINUE

CONTINUE — оператор языка Axiom, который пропускает оставшуюся часть текущей итерации цикла и переходит к следующей итерации. Оператор имеет три формы: CONTINUE FOR, CONTINUE WHILE и CONTINUE DO, каждая из которых работает с соответствующим типом цикла.

Назначение

Оператор CONTINUE удобен, когда внутри тела цикла встречается условие, при котором оставшаяся часть итерации не нужна. Вместо вложенного IF ... END IF вокруг остатка тела оператор CONTINUE явно показывает, что программа должна перейти к следующему проходу.

Форма оператора должна совпадать с типом окружающего цикла. Использование CONTINUE FOR вне цикла FOR ... NEXT, CONTINUE WHILE вне цикла WHILE ... END WHILE или CONTINUE DO вне цикла DO ... LOOP приводит к ошибке диагностики.

Синтаксис

CONTINUE FOR
CONTINUE WHILE
CONTINUE DO

Параметры и части синтаксиса

  • CONTINUE FOR — пропускает оставшуюся часть тела цикла FOR ... NEXT и переходит к инкременту счётчика (оператору NEXT), после чего выполняется проверка условия следующей итерации.
  • CONTINUE WHILE — пропускает оставшуюся часть тела цикла WHILE ... END WHILE и переходит к проверке условия в заголовке цикла.
  • CONTINUE DO — пропускает оставшуюся часть тела цикла DO ... LOOP и переходит к проверке условия (если оно есть) или к началу следующей итерации.

Поведение каждой формы

CONTINUE FOR

Оператор CONTINUE FOR передаёт управление на оператор NEXT, который увеличивает счётчик на шаг и затем проверяет, не вышел ли счётчик за границу. Это значит, что CONTINUE FOR не пропускает инкремент счётчика — счётчик изменяется как при обычном завершении итерации.

CONTINUE WHILE

Оператор CONTINUE WHILE передаёт управление обратно к заголовку цикла, где условие проверяется заново. Если условие всё ещё истинно, начинается следующий проход; если ложно — управление переходит к инструкции после END WHILE.

CONTINUE DO

Оператор CONTINUE DO передаёт управление к оператору LOOP. Для форм с LOOP WHILE и LOOP UNTIL это означает проверку постусловия. Для форм с DO WHILE и DO UNTIL управление переходит к началу тела, где условие проверяется перед следующим проходом. Для формы DO ... LOOP без условия следующий проход начинается немедленно.

Вложенные циклы

Оператор CONTINUE действует только на ближайший окружающий цикл указанного типа. Во вложенных циклах CONTINUE во внутреннем цикле не влияет на внешний.

' Ожидаемый вывод:
' j=0 i=0
' j=0 i=1
' j=1 i=0
' j=1 i=1
FOR j = 0 TO 1
    FOR i = 0 TO 2
        IF i = 2 THEN
            CONTINUE FOR
        END IF

        PRINT "j=" & j & " i=" & i
    NEXT
NEXT

Диагностика

  • MB2037 — CONTINUE FOR используется вне цикла FOR ... NEXT.
  • MB2038 — CONTINUE WHILE используется вне цикла WHILE ... END WHILE.
  • MB2039 — CONTINUE DO используется вне цикла DO ... LOOP.

Пример: CONTINUE FOR

В этом примере цикл проходит от 1 до 5, но печатает только нечётные числа: при чётном значении CONTINUE FOR пропускает оператор PRINT.

' Ожидаемый вывод:
' 1
' 3
' 5
FOR i = 1 TO 5
    IF i MOD 2 = 0 THEN
        CONTINUE FOR
    END IF

    PRINT i
NEXT

Пример: CONTINUE WHILE

В этом примере цикл WHILE печатает числа от 0 до 4, пропуская значение 2.

' Ожидаемый вывод:
' 0
' 1
' 3
' 4
DIM i AS INTEGER = 0

WHILE i < 5
    i = i + 1

    IF i = 2 THEN
        CONTINUE WHILE
    END IF

    PRINT i - 1
END WHILE

Пример: CONTINUE DO

В этом примере цикл DO ... LOOP печатает числа от 0 до 4, пропуская значение 3.

' Ожидаемый вывод:
' 0
' 1
' 2
' 4
DIM i AS INTEGER = 0

DO WHILE i < 5
    IF i = 3 THEN
        i = i + 1
        CONTINUE DO
    END IF

    PRINT i
    i = i + 1
LOOP
