Оператор CONTINUE

CONTINUE — оператор языка Axiom, который пропускает остаток текущего прохода цикла. На странице описаны отдельные формы для FOR, WHILE и DO.

Назначение и контекст

Оператор нужен, чтобы пропустить оставшиеся действия текущего прохода и перейти к проверке или изменению счётчика. Каждая форма требует охватывающего цикла названного вида; сама форма не имеет аргументов. Оператор может находиться внутри условия или обработки ошибок, вложенных в цикл.

Синтаксис

CONTINUE FOR
CONTINUE WHILE
CONTINUE DO

Переход каждой формы

ФормаДействие
CONTINUE FORПереходит к NEXT, изменяет счётчик и проверяет границу следующего прохода.
CONTINUE WHILEПереходит к условию в заголовке WHILE.
CONTINUE DOПереходит к предусмотренной формой DO проверке условия или к следующему проходу безусловного цикла.

Форма должна находиться внутри охватывающего цикла соответствующего вида. Для вложения циклов одного вида действие относится к ближайшему циклу. В текущей реализации во вложении разных видов переход определяется самым внутренним циклом независимо от слова после CONTINUE. Компилятор при этом требует наличия охватывающего цикла названного вида. Например, CONTINUE FOR внутри WHILE, вложенного в FOR, проходит проверку, но переходит к условию внутреннего WHILE. Для предсказуемого выбора перехода указывайте вид непосредственного охватывающего цикла. Аргументов у оператора нет.

Изменение состояния

Продолжение не отменяет уже выполненные инструкции. Следите, чтобы нужное изменение состояния не оказалось после CONTINUE: для цикла с условием это может помешать завершению. В FOR изменение счётчика выполняется автоматически.

Диагностика

  • MB2037 — CONTINUE FOR используется вне цикла FOR ... NEXT.
  • MB2038 — CONTINUE WHILE используется вне цикла WHILE ... END WHILE.
  • MB2039 — CONTINUE DO используется вне цикла DO ... LOOP.

Пример

Чётные значения пропускаются, а счётчик продолжает изменяться:

FOR index = 1 TO 5
    IF index MOD 2 = 0 THEN
        CONTINUE FOR
    END IF
    PRINT index
NEXT

Результат:

1
3
5

Запускаемые примеры

Откройте нужный файл в IDE и запустите его. Примеры с ошибкой предназначены для проверки сообщения компилятора или выполнения.

  • CONTINUE FOR: пропуск итерации счётного цикла
  • CONTINUE WHILE: пропуск итерации предусловного цикла
  • CONTINUE DO: пропуск итерации цикла DO ... LOOP

Пример разных вложенных циклов

FOR counter = 1 TO 2
    DIM count AS INTEGER = 0
    WHILE count < 2
        count = count + 1
        CONTINUE FOR
        PRINT "Не выполняется"
    END WHILE
    PRINT counter
NEXT

Ожидаемый вывод:

1
2
