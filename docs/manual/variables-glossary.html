Справочное приложение

Основные термины

Раздел терминов содержит короткие определения для чтения справочника. Полные правила находятся в тематических статьях.

Термины

ТерминОпределение
ПеременнаяИменованное изменяемое место хранения значения.
ОбъявлениеЗапись, которая вводит имя и определяет его свойства.
КонстантаИменованное значение, которое нельзя заменить присваиванием.
Тип данныхДоговор о допустимых значениях и операциях.
ИнициализацияУстановка начального значения.
ВыражениеЗапись, которая вычисляет значение.
ОперандЗначение, к которому применяется операция.
Область видимостиЧасть программы, в которой доступно имя.
ПараметрИмя входного значения в объявлении подпрограммы.
АргументЗначение или переменная, переданные при вызове.
БлокГруппа инструкций внутри конструкции с собственной границей.
ЗамыканиеФункциональное значение, сохраняющее доступ к захваченным переменным.
Ранг массиваКоличество измерений массива.
ПолеИменованная часть записи TYPE.
ДиагностикаСообщение с кодом и местом проблемы в программе.
