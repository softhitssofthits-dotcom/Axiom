Термины переменных и областей видимости: переменные

Этот словарик объясняет термины, которые встречаются в разделе о переменных, без сложного жаргона. Если слово встретилось вам впервые — загляните сюда, а подробности ищите на странице Имена, регистр и область видимости переменных.

Переменная

Именованное хранилище значения. Представьте коробку с наклейкой-именем: в коробке лежит значение, а по имени вы находите коробку. В коробку можно положить новое значение — тогда старое пропадёт. Переменная объявляется через DIM.

Объявление

Строка кода, в которой имя появляется впервые и получает тип. В Axiom имя обязательно объявляют до первого использования: переменную — через DIM, константу — через CONST. Простое присваивание имя не создаёт.

Константа

Именованное значение, которое нельзя изменить после объявления. Объявляется через CONST и сразу получает значение. Попытка записать в константу новое значение — ошибка MB2010.

Тип данных

Описание того, какие значения может хранить переменная: целые числа (INTEGER, LONG), дробные (DOUBLE, DECIMAL), текст (STRING), логические значения (BOOLEAN), а также сложные значения: массивы, записи TYPE, изображения и другие. Тип задаётся после AS или выводится из начального значения.

Инициализация

Присваивание начального значения прямо в момент объявления. Например, в DIM age AS INTEGER = 19 число 19 — это инициализатор. Если начального значения нет, переменная получает значение по умолчанию своего типа.

Значение по умолчанию

«Пустое» значение, которое переменная получает, если её не инициализировали: числа — 0, строка — пустая строка "", логическое значение — FALSE.

Область видимости

«Территория» программы, внутри которой имя можно использовать. Переменная видна только в своей области: глобальной (вся программа), процедурной (одна SUB или FUNCTION), блоковой (один IF, FOR и так далее) или типовой (поля записи).

Глобальная переменная

Переменная, объявленная на верхнем уровне программы — вне всех процедур и типов. Видна и доступна из любого места программы и живёт всё время её работы.

Локальная переменная

Переменная, объявленная внутри SUB, FUNCTION или блока. Снаружи своей области она не видна, а при каждом новом вызове процедуры создаётся заново.

Параметр

Имя, объявленное в заголовке SUB или FUNCTION, через которое процедура получает значения от вызывающего кода. По умолчанию параметр — копия значения (BYVAL); с ключевым словом BYREF процедура получает саму переменную и может её изменить.

Блок

Часть программы между ключевыми словами-границами: IF ... END IF, FOR ... NEXT, WHILE ... END WHILE, DO ... LOOP, SELECT CASE ... END SELECT, TRY ... END TRY. Каждый блок создаёт собственную область видимости.

Перекрытие имён (shadowing)

Ситуация, когда внутренняя область объявляет имя, которое уже занято во внешней. В Axiom это запрещено: вместо перекрытия вы получаете ошибку MB2016 и должны придумать другое имя.

Время жизни

Промежуток времени, в течение которого переменная существует и хранит значение. Например, локальная переменная живёт от вызова процедуры до её завершения, а глобальная — всю программу.

Замыкание

Функция, которая возвращается из другой функции как значение и «забирает» с собой свои переменные. Эти переменные продолжают жить, пока живёт замыкание, — между вызовами замыкания они сохраняют значения.

Массив

Переменная, хранящая несколько значений одного типа, к которым обращаются по номеру (индексу): values(1), values(2). Массив объявляется с границами (DIM values(1 TO 3) AS INTEGER) или как динамический (DIM values() AS INTEGER). При присваивании одного массива другому новый массив не создаётся — обе переменные ссылаются на одно хранилище.

Запись (TYPE), поле, SELF

Запись — это тип, объединяющий несколько полей (TYPE Point: x AS INTEGER: y AS INTEGER: END TYPE). Поле — переменная внутри записи; обращаются к ней через точку: p.x. В методах записи свои поля доступны только через имя SELF: SELF.x. При присваивании запись копируется целиком.

Регистронезависимость

Свойство языка не различать заглавные и строчные буквы в именах: name, Name и NAME — одно и то же имя. Axiom регистронезависим.

Зарезервированное слово

Слово, которое язык использует для своих конструкций (IF, FOR, PRINT, DIM и другие). Его нельзя использовать как имя переменной.

Диагностика (код ошибки)

Сообщение проверяющей программы (компилятора; см. статью «Компилятор» ниже) о проблеме в программе. У каждой диагностики есть код вида MB2001, MB2016 и так далее, по которому можно найти описание проблемы в справочнике диагностик.

Компилятор

Программа, которая разбирает ваш исходный код, проверяет его по правилам языка и готовит к выполнению. Именно компилятор выдаёт диагностики вида MB2001, MB2016 — например, когда вы ошиблись в имени переменной или попытались объявить уже существующее имя. Когда документация говорит «программа не запускается», это и есть работа компилятора: он заметил ошибку раньше, чем код начал выполняться.
