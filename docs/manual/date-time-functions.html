Дата и время

Раздел «Дата и время» описывает типы DATE, TIME и DATETIME, чтение часов, календарные компоненты, арифметику, разбор строк и часовые пояса.

Значения и запись

DATE хранит календарную дату с годом от 1 до 9999. TIME хранит время суток без календарной даты. DATETIME хранит дату и время суток без собственного часового пояса. При печати используются формы yyyy-MM-dd, HH:mm:ss и yyyy-MM-dd HH:mm:ss соответственно.

Начальные значения неинициализированных переменных — 0001-01-01, 00:00:00 и 0001-01-01 00:00:00. Строковая запись остаётся STRING, пока не выполнено допустимое преобразование.

Преобразование и арифметика

Каноническая строка может преобразоваться в временной тип при присваивании. DATE при преобразовании в DATETIME дополняется полуночью; TIME — минимальной календарной датой. Присваивание DATETIME переменной DATE или TIME отклоняется, чтобы не терять часть значения неявно.

DATEADD, DATEDIFF и DATEPART принимают только типизированные временные аргументы, без строкового преобразования. Для строки сначала используют DATEVALUE или TIMEVALUE; для DATETIME можно объявить переменную с канонической строковой инициализацией. Часовой пояс задаётся отдельным строковым аргументом соответствующих функций.

Пример типизированной даты

DIM calendarDay AS DATE = "2024-01-31"
PRINT DATEADD("m", 1, calendarDay)

Ожидаемый вывод:

2024-02-29

  • Календарные компоненты — сборка даты, имена месяцев, високосность и границы периодов.
