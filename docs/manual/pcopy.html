Оператор PCOPY

PCOPY — оператор языка Axiom, который переносит содержимое одной графической страницы SCREEN в другую. Его можно использовать для показа кадра, подготовленного на скрытой странице.

Когда использовать PCOPY

Экранные страницы позволяют отделить рисование следующего изображения от текущего показа.

Например, оператор SCREEN выбирает страницу 1 для рисования и страницу 0 для показа. После подготовки изображения вызов PCOPY 1, 0 копирует его на видимую страницу.

Контекст выполнения

Оператор доступен в графических режимах SCREEN 1..10.

В текстовом режиме SCREEN 0 и на холсте CANVAS экранные страницы оператора PCOPY недоступны.

Синтаксис

PCOPY <исходная страница>, <страница назначения>

Оба аргумента обязательны: сначала укажите источник, затем страницу назначения.

Параметры

ЧастьОписание
<исходная страница>Передайте номер исходной страницы от 0 до 3. Оператор PCOPY читает кадр именно из этой страницы. Передаваемое значение имеет тип INTEGER.
<страница назначения>Передайте номер страницы назначения от 0 до 3. Оператор PCOPY записывает копию кадра именно в эту страницу. Передаваемое значение имеет тип INTEGER.

Что делает оператор PCOPY

Копирование заменяет кадровый буфер страницы назначения содержимым исходной страницы.

Переносятся индексный слой, полноцветный слой и палитра. Поэтому результаты PSET, LINE, DRAWIMAGE, DRAWSPRITE и PALETTE сохраняются вместе.

Правила работы

Вызов без активного графического режима сообщает MB3010.

Допустимые номера обеих страниц — 0..3. Выход за этот диапазон сообщает MB3007.

Копирование сохраняет выбор активной и видимой страниц, графическую позицию, VIEW, WINDOW, VIEW PRINT, текстовый курсор и очереди ввода.

Текстовый буфер PRINT отображается общим слоем поверх видимой страницы. Оператор PCOPY не копирует текстовый буфер и не переносит текст между страницами; LOCATE только задаёт текстовый курсор.

Типы аргументов и видимость копии

Номера обеих страниц приводятся к INTEGER и должны лежать в 0..3. Копирование страницы в саму себя допустимо. Если страница назначения видима, копия появляется в окне; иначе она сохраняется на скрытой странице до её показа. Оператор не меняет выбранные номера активной и видимой страниц.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3007: номер исходной страницы или страницы назначения находится вне диапазона 0..3.

Пример

SCREEN 1, , 1, 0
CLS
LINE (20, 40)-(180, 40), 1
PALETTE 1, 196
PCOPY 1, 0

SCREEN 1, , 0, 0
PRINT POINT(20, 40)

Пример переносит линию и палитру со страницы 1 на страницу 0. Чтение после выбора скопированной страницы возвращает индекс 1, хотя палитра изменила видимый цвет линии.
