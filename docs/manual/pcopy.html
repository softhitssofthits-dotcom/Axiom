Оператор PCOPY

PCOPY — оператор языка Axiom, который копирует одну графическую страницу SCREEN в другую. Оператор PCOPY нужен для показа заранее подготовленного кадра, когда программа рисует на скрытой странице, а затем переносит готовый результат на видимую страницу.

Для чего нужен оператор PCOPY

Оператор PCOPY нужен для работы с экранными страницами исторического графического пути SCREEN.

Обычный сценарий такой: оператор SCREEN делает страницу 1 активной для рисования и страницу 0 видимой для показа, программа собирает следующий кадр на странице 1, а оператор PCOPY 1, 0 переносит готовый кадр на страницу 0.

Где работает оператор PCOPY

Оператор PCOPY работает только в графических режимах SCREEN 1 ... SCREEN 10.

Оператор PCOPY не работает в SCREEN 0 и не относится к современному графическому слою CANVAS.

Синтаксис

PCOPY sourcePage, destinationPage

На этой странице показана одна форма оператора PCOPY. Оператор PCOPY всегда требует номер исходной страницы и номер страницы назначения.

Параметры

ПараметрОписание
sourcePageНомер исходной страницы от 0 до 3. Оператор PCOPY читает кадр именно из этой страницы.
destinationPageНомер страницы назначения от 0 до 3. Оператор PCOPY записывает копию кадра именно в эту страницу.

Что делает оператор PCOPY

Оператор PCOPY копирует кадровый буфер исходной страницы в страницу назначения.

Оператор PCOPY копирует индексный слой, полноцветный слой и палитру исходной страницы. Поэтому кадр с PSET, LINE, DRAWIMAGE, DRAWSPRITE и PALETTE переносится как единое изображение.

Правила работы

Оператор PCOPY работает только после выбора графического режима SCREEN 1 ... SCREEN 10. Если графический режим не активен, оператор PCOPY сообщает ошибку времени выполнения MB3010.

Номера sourcePage и destinationPage должны находиться в диапазоне 0..3. Если программа передаёт номер страницы вне этого диапазона, оператор PCOPY сообщает ошибку времени выполнения MB3007.

Оператор PCOPY не меняет активную страницу, видимую страницу, текущую графическую позицию, область VIEW, систему координат WINDOW, область VIEW PRINT, текстовый курсор и очереди ввода.

Текстовый слой графического режима SCREEN, выведенный через PRINT и LOCATE, относится к той же экранной странице. Поэтому оператор PCOPY переносит и такой текст вместе с остальным содержимым страницы.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3007: номер исходной страницы или страницы назначения находится вне диапазона 0..3.

Пример

SCREEN 1, , 1, 0
CLS
LINE (20, 40)-(180, 40), 1
PALETTE 1, 196
PCOPY 1, 0

SCREEN 1, , 0, 0
PRINT POINT(20, 40)

В этом примере оператор PCOPY переносит со скрытой страницы 1 на видимую страницу 0 и линию, и изменённую палитру. После переключения активной страницы функция POINT всё равно возвращает индекс 1, потому что оператор PALETTE меняет видимый цвет, а не сохранённый индекс пикселя.
