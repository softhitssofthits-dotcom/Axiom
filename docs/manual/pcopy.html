Оператор

PCOPY

PCOPY копирует одну экранную страницу графического SCREEN в другую. Эта форма полезна, когда программа сначала готовит изображение на скрытой странице, а затем переносит готовый кадр на видимую страницу без поэлементного рисования заново.

Синтаксис

PCOPY <источник>, <приёмник>

Части синтаксиса

ЧастьОписание
<источник>Номер экранной страницы, из которой берётся копия. В текущем договоре Axiom допустимы страницы 0..3.
<приёмник>Номер экранной страницы, куда помещается копия. Допустимый диапазон тот же: 0..3.

Экранные страницы

Графический SCREEN может иметь активную страницу и видимую страницу. Активная страница получает команды рисования и чтение через POINT(x, y). Видимая страница показывается в окне программы.

Страницы выбираются через расширенную форму оператора SCREEN:

SCREEN <режим>, , <активная_страница>, <видимая_страница>

Пустое место после первой запятой оставлено под исторический параметр colorSwitch, который в Axiom не поддерживается. Чтобы задать страницы, оставляйте это место пустым.

Замечания

PCOPY работает только в графических режимах SCREEN 1 ... SCREEN 10. В текстовом SCREEN 0 и без выбранного графического режима оператор сообщает MB3010.

Копируется графический кадровый буфер страницы: цветовые индексы пикселей и палитра этой страницы. После копирования POINT(x, y) на странице-приёмнике возвращает те же индексы, которые были в источнике.

Текст, выведенный через PRINT поверх графического экрана, в текущем срезе не является отдельной страницей PCOPY. Оператор не меняет текущий текстовый курсор, VIEW PRINT, обычный VIEW, WINDOW, текущую графическую позицию, активную страницу и видимую страницу.

Если источник и приёмник совпадают, состояние экрана остаётся тем же. Если страница-приёмник сейчас видима, окно программы обновляется сразу после копирования.

Пример

SCREEN 1, , 1, 0
LINE (20, 40)-(180, 40), 1
PALETTE 1, 196

PCOPY 1, 0
SCREEN 1, , 0, 0
PRINT "visible page="; POINT(20, 40)

Программа рисует линию на активной странице 1, пока видимой остаётся страница 0, и меняет вид индекса 1 через PALETTE. Оператор PCOPY 1, 0 переносит готовое изображение и палитру на страницу 0. После переключения активной страницы на 0 функция POINT подтверждает тот же цветовой индекс.

Тот же приём подходит для кадрового вывода спрайтов: программа может рисовать DRAWSPRITE на скрытой странице, а затем переносить готовый кадр на видимую страницу через PCOPY.

Диагностика

  • MB3010: графический режим SCREEN не активен.
  • MB3007: номер страницы источника или приёмника находится вне диапазона 0..3.

Проверочные программы

Готовые примеры для ручной и отрицательной проверки находятся в samples/operators/pcopy/.

  • PCOPY: копирование скрытой страницы на видимую
  • SPRITE и PCOPY: кадр на скрытой странице
  • PCOPY: ошибка неверного номера страницы
  • PCOPY: ошибка в текстовом SCREEN 0
