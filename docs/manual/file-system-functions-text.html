Встроенные функции

Текстовые файлы

Функции этой страницы принимают путь в виде строки и сами открывают файл, читают его или записывают результат. Они удобны, когда не нужно отдельно управлять объектом FILE и текущей позицией внутри файла.

FILEEXISTS

Функция FILEEXISTS проверяет, существует ли файл по указанному пути.

Синтаксис

result = FILEEXISTS(path)

Части записи. path задаёт путь к файлу. Функция возвращает TRUE, если файл найден, и FALSE, если файла нет.

Пример

' Проверка существования файла
PRINT FILEEXISTS("notes.txt")

DIREXISTS

Функция DIREXISTS проверяет, существует ли папка по указанному пути.

Синтаксис

result = DIREXISTS(path)

Части записи. path задаёт путь к папке. Функция возвращает TRUE, если папка найдена.

Пример

' Проверка существования папки
PRINT DIREXISTS(".")

PATHEXISTS

Функция PATHEXISTS проверяет, существует ли по пути файл или папка.

Синтаксис

result = PATHEXISTS(path)

Части записи. path задаёт путь к объекту файловой системы. Результатом является логическое значение.

Пример

' Проверка любого объекта по пути
PRINT PATHEXISTS("notes.txt")
PRINT PATHEXISTS("docs")

READFILE

Функция READFILE читает весь текстовый файл целиком и возвращает одну строку.

Синтаксис

text = READFILE(path)

Части записи. path задаёт путь к текстовому файлу. Результатом является строка с полным содержимым файла.

Пример

' Чтение всего файла одной строкой
DIM text AS STRING

text = READFILE("notes.txt")
PRINT text

READALLLINES

Функция READALLLINES читает текстовый файл построчно и возвращает массив строк.

Синтаксис

lines = READALLLINES(path)

Части записи. path задаёт путь к текстовому файлу. Результатом является массив STRING() с границами 1 TO N.

Пример

' Чтение файла в массив строк
DIM lines() AS STRING

lines = READALLLINES("notes.txt")
PRINT ARRAYLENGTH(lines)
PRINT lines(1)

WRITEFILE

Функция WRITEFILE записывает текст в файл с начала. Если файл уже существует, его содержимое заменяется.

Синтаксис

result = WRITEFILE(path, text)

Части записи. path задаёт путь к файлу. text задаёт строку для записи. Результат имеет тип BOOLEAN.

Пример

' Полная перезапись файла
PRINT WRITEFILE("notes.txt", "Первая строка")

APPENDFILE

Функция APPENDFILE дописывает текст в конец файла. Если файла ещё нет, он создаётся.

Синтаксис

result = APPENDFILE(path, text)

Части записи. path задаёт путь к файлу. text задаёт строку, которую нужно добавить в конец файла. Результат имеет тип BOOLEAN.

Пример

' Добавление новой строки в конец файла
PRINT APPENDFILE("notes.txt", CHR(10) + "Вторая строка")

Замечания

  • READFILE и READALLLINES сначала пытаются читать файл как UTF-8, а при недопустимых байтах переходят к Windows-1251.
  • READALLLINES возвращает компактный массив строк. Для пустого файла это будет пустой массив с границами 1 TO 0.
  • WRITEFILE и APPENDFILE записывают текст в UTF-8 без BOM.
  • Если нужно читать файл частями или управлять позицией вручную, используйте страницу Функции для открытого файла.

Диагностика

  • Отсутствие файла или недоступный путь для READFILE и READALLLINES дают диагностику времени выполнения MB3007.
  • Ошибки доступа к файловой системе при WRITEFILE и APPENDFILE также завершаются диагностикой MB3007.

Ручная проверка

  • FILEEXISTS: проверка файла
  • DIREXISTS: проверка папки
  • PATHEXISTS: проверка пути
  • READFILE: чтение целого файла
  • READALLLINES: чтение строк
  • WRITEFILE: запись текста
  • APPENDFILE: добавление текста
