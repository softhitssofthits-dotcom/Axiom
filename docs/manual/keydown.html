Функция KEYDOWN

KEYDOWN — встроенная функция языка Axiom, которая проверяет текущее удержание клавиши или сочетания клавиш. Повторные вызовы не изменяют очередь ввода.

Применение

Функция подходит для непрерывного управления, например движения при удержании стрелки. Результат равен TRUE, пока нужная клавиша нажата, и FALSE в остальных случаях. Если среда не предоставляет состояние клавиатуры, возвращается FALSE.

Контекст выполнения

Состояние поступает от активной поверхности ввода: текстовой области IDE либо открытого окна SCREEN 0 или SCREEN 1..10.

Правила фокуса и очистки состояния описаны в разделе ввода.

Синтаксис

KEYDOWN(<клавиша>)

Аргументы

АргументТипОписание
<клавиша>STRINGИмя клавиши. Обычные буквенно-цифровые клавиши можно указывать как "A" или "1"; специальные клавиши задаются именами вроде "LEFT", "ESC", "F5".

Что возвращает функция KEYDOWN

Функция возвращает значение типа BOOLEAN.

  • TRUE, если указанная клавиша сейчас удерживается.
  • FALSE, если клавиша не удерживается, имя пустое или среда выполнения не предоставляет состояние клавиатуры.

Имена клавиш

Таблица имён общая для INKEY, KEYDOWN, KEYPRESS и ON KEY. Функция INKEY возвращает каноническое имя, остальные формы принимают и его, и перечисленные варианты записи. Регистр, пробелы, дефисы и подчёркивания в альтернативных именах не меняют смысл. Имя "ANY" зарезервировано только для запасного обработчика ON KEY и не обозначает физическую клавишу.

Печатную клавишу обозначают односимвольной строкой, например "A", "a" или "1". Строковое имя клавиши не является ключевым словом и не конфликтует с функциями LEFT() или RIGHT().

Сочетания клавиш

В строке сочетания части разделяются знаком +. Каждая из перечисленных клавиш должна удерживаться в момент вызова.

Например, KEYDOWN("CTRL+ALT+DELETE") проверяет одновременное удержание всех трёх клавиш. События их нажатия остаются в очереди.

IF KEYDOWN("CTRL+LEFT") THEN
    PRINT "CTRL+LEFT"
END IF

Аргумент функции

Передайте STRING с именем клавиши либо сочетанием, например "CTRL+LEFT". KEYDOWN возвращает BOOLEAN и не извлекает события. Для пустой строки или строки из пробелов возвращается FALSE; неподдержанное имя не обозначает физическую клавишу и не создаёт ошибку аргумента.

Диагностика

  • MB2004: вызов встроенной функции KEYDOWN получен без аргумента или с лишними аргументами.
  • MB2003: аргумент встроенной функции KEYDOWN нельзя связать как строку.

Пример проверки сочетания клавиш

FOR i = 1 TO 20000
    IF KEYDOWN("SHIFT+A") THEN
        PRINT "SHIFT+A"
        EXIT FOR
    END IF
NEXT

Запускаемые примеры

  • KEYDOWN: удержание модификатора и стрелки
  • KEYDOWN: канонические имена и алиасы клавиш
