Функция KEYDOWN

KEYDOWN — встроенная функция языка Axiom, которая проверяет, удерживается ли указанная клавиша прямо сейчас. В отличие от INKEY, встроенная функция KEYDOWN не читает очередь клавиш и не удаляет событие ввода, поэтому функция подходит для циклов управления, проверки стрелок и сочетаний вроде CTRL вместе с другой клавишей.

Для чего нужна функция KEYDOWN

Встроенная функция KEYDOWN нужна для проверки текущего состояния клавиши или сочетания клавиш. Функция возвращает логическое значение. Если среда выполнения знает, что указанная клавиша сейчас нажата, результатом будет TRUE; иначе возвращается FALSE. В средах без источника состояния клавиатуры встроенная функция KEYDOWN также возвращает FALSE.

Где работает функция KEYDOWN

Встроенная функция KEYDOWN читает текущее состояние клавиатуры активной среды выполнения. Если программа работает без оператора SCREEN, состояние поступает из обычной поверхности ввода среды разработки. Если программа явно выбрала SCREEN 0 или графический режим SCREEN 1..10, состояние поступает из окна SCREEN.

Встроенная функция KEYDOWN выполняется BytecodeVm после компиляции.

Синтаксис

KEYDOWN(keyText)

Аргументы

АргументТипОписание
keyTextSTRINGИмя клавиши. Обычные буквенно-цифровые клавиши можно указывать как "A" или "1"; специальные клавиши задаются именами вроде "LEFT", "ESC", "F5".

Что возвращает функция KEYDOWN

Тип результата: BOOLEAN.

  • TRUE, если указанная клавиша сейчас удерживается.
  • FALSE, если клавиша не удерживается, имя пустое или среда выполнения не предоставляет состояние клавиатуры.

Имена клавиш

Имена специальных клавиш общие для INKEY, KEYDOWN, KEYPRESS и ON KEY. Функция INKEY возвращает каноническое имя, а остальные формы принимают как каноническое имя, так и алиасы из таблицы. Регистр букв не важен; пробелы, дефисы и подчёркивания в алиасах не меняют смысл. Для ON KEY дополнительно зарезервировано псевдоимя "ANY", которое означает обработчик любой клавиши, а не физическую клавишу.

Сочетания клавиш

Встроенная функция KEYDOWN умеет проверять строковый аккорд клавиш через знак +. В отличие от KEYPRESS, здесь все части строки равноправны: каждая перечисленная клавиша должна быть удержана прямо сейчас.

Проще говоря, KEYDOWN("CTRL+ALT+DELETE") значит: CTRL, ALT и DELETE сейчас нажаты одновременно. Очередь событий при этом не читается и не расходуется.

IF KEYDOWN("CTRL+LEFT") THEN
    PRINT "CTRL+LEFT"
END IF

Пример проверки сочетания клавиш

FOR i = 1 TO 20000
    IF KEYDOWN("SHIFT+A") THEN
        PRINT "SHIFT+A"
        EXIT FOR
    END IF
NEXT

Ручная проверка

  • KEYDOWN: удержание модификатора и стрелки
  • KEYDOWN: канонические имена и алиасы клавиш

Диагностика

  • MB2004: вызов встроенной функции KEYDOWN получен без аргумента или с лишними аргументами.
  • MB2003: аргумент встроенной функции KEYDOWN нельзя связать как строку.
