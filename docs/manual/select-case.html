Оператор SELECT CASE

Проверка одного выражения против набора вариантов.

Управление выполнением

Оператор SELECT CASE

Оператор SELECT CASE удобен тогда, когда одно и то же выражение нужно сопоставить сразу с несколькими значениями, диапазонами или упорядоченными условиями. Вместо длинной цепочки однотипных проверок страница выбора остаётся привязанной к одному проверяемому выражению и потому обычно читается проще.

Сводка

Оператор SELECT CASE удобен, когда нужно сравнить одно выражение с несколькими значениями, диапазонами или условиями сравнения. Проверяемое выражение вычисляется один раз, а ветви CASE просматриваются сверху вниз.

Синтаксис

SELECT CASE testExpression
    CASE selectorList
        [statements]
    [CASE selectorList
        [statements]] ...
    [CASE ELSE
        [elseStatements]]
END SELECT

Части записи

testExpression — выражение, которое вычисляется один раз перед разбором ветвей CASE.

selectorList — один селектор или несколько селекторов через запятую. Селектором может быть одно значение, диапазон вида 7 TO 10 или сравнение через CASE IS, например CASE IS > 100.

statements — одна или несколько инструкций, которые выполняются в подошедшей ветви CASE.

elseStatements — инструкции запасной ветви CASE ELSE, если ни один обычный селектор не подошёл.

Замечания

SELECT CASE особенно полезен в тех ситуациях, где ветви отличаются прежде всего набором допустимых значений одного выражения, а не самостоятельными логическими формулами в каждой проверке.

  • Проверяемое выражение вычисляется один раз перед разбором ветвей.
  • Выполняется только первая подошедшая ветвь, после чего управление переходит сразу за END SELECT.
  • В одной строке CASE можно перечислять несколько селекторов через запятую.
  • Диапазоны CASE ... TO и упорядоченные сравнения через CASE IS применяются только там, где тип действительно поддерживает такой порядок сравнения.
  • Каждая ветвь CASE и CASE ELSE образует собственную блочную область видимости.

Пример

SELECT CASE age
    CASE 7 TO 10
        PRINT "Младшая группа"
    CASE 11, 12
        PRINT "Средняя группа"
    CASE IS >= 13
        PRINT "Старшая группа"
    CASE ELSE
        PRINT "Вне диапазона"
END SELECT

Ручная проверка

  • SELECT CASE: точные значения
  • SELECT CASE: диапазоны и CASE IS
  • SELECT CASE: смешанные селекторы
  • SELECT CASE: строковые значения
  • SELECT CASE: строковые диапазоны

Диагностика

Ошибки возникают, если проверяемое выражение несовместимо с селектором, если тип не поддерживает диапазон CASE ... TO или если имя, объявленное внутри ветви, используется уже вне своей области видимости.
