Операторы и управление

Оператор SELECT CASE

SELECT CASE выбирает одну из нескольких ветвей по значению одного проверяемого выражения. Выражение вычисляется один раз, ветви проверяются сверху вниз, и выполняется только первая подошедшая ветвь.

Сводка

Используйте SELECT CASE, когда одно выражение нужно сравнить с несколькими значениями, диапазонами или условиями сравнения. Если ни одна обычная ветвь не подошла, можно добавить ветвь CASE ELSE.

Синтаксис

SELECT CASE <проверяемое выражение>
    CASE <селектор 1>[, <селектор 2> ...]
        <инструкции>
    [CASE <селектор 1>[, <селектор 2> ...]
        <инструкции>]
    [CASE ELSE
        <инструкции>]
END SELECT
SELECT CASE score
    CASE 5
        PRINT "Отлично"
    CASE 4
        PRINT "Хорошо"
    CASE ELSE
        PRINT "Нужно доработать"
END SELECT

Части синтаксиса

<проверяемое выражение>
Выражение, значение которого сравнивается со всеми ветвями CASE.
CASE <значение>
Проверяет точное совпадение с одним значением.
CASE <значение 1>, <значение 2>, ...
Проверяет несколько точных значений в одной ветви.
CASE <нижняя граница> TO <верхняя граница>
Проверяет попадание во включительный диапазон.
CASE IS <оператор сравнения> <выражение>
Проверяет условие сравнения через IS, например CASE IS > 100 или CASE IS <= 0.
CASE ELSE
Выполняется, если ни одна предыдущая ветвь не подошла.

Замечания

  • Проверяемое выражение вычисляется один раз перед разбором ветвей.
  • Ветви CASE проверяются строго сверху вниз.
  • После выполнения подошедшей ветви управление переходит сразу за END SELECT.
  • В одной строке CASE можно смешивать точные значения, диапазоны и формы CASE IS через запятую.
  • Точные совпадения работают для совместимых чисел, строк и логических значений.
  • Диапазоны CASE ... TO и упорядоченные сравнения CASE IS <, <=, >, >= допустимы для чисел и строк.
  • Строковые сравнения выполняются по порядку кодов символов без учёта локали.
  • Для BOOLEAN допустимы только точные проверки и формы CASE IS = или CASE IS <>; диапазоны и упорядоченные сравнения для него не используются.
  • Каждая ветвь CASE и CASE ELSE образует собственную блочную область видимости. Имя, объявленное внутри ветви, недоступно после выхода из неё.

Примеры

SELECT CASE age
    CASE 7 TO 10
        PRINT "Младшая группа"
    CASE 11, 12
        PRINT "Средняя группа"
    CASE IS >= 13
        PRINT "Старшая группа"
END SELECT
SELECT CASE command
    CASE "A", "B", "C"
        PRINT "Короткая команда"
    CASE "D" TO "M"
        PRINT "Команда из средней группы"
    CASE ELSE
        PRINT "Другая команда"
END SELECT

Диагностика

  • MB2003 — тип проверяемого выражения несовместим с селектором в ветви CASE.
  • MB2015 — тип не поддерживает диапазон CASE ... TO.
  • MB2001 — имя, объявленное внутри одной ветви, используется вне своей области видимости.
