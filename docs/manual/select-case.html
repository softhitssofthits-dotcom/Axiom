Оператор SELECT CASE

SELECT CASE — оператор языка Axiom, который выбирает блок по значению одного выражения. Ветви CASE могут содержать отдельные значения, диапазоны и сравнения.

Назначение и контекст

Оператор работает на верхнем уровне программы и внутри подпрограмм и блоков, в консольной и графической программе. Специальный графический режим не требуется.

Конструкция удобна для выбора по коду, категории или диапазону. В отличие от цепочки независимых условий, выражение выбора записывается один раз.

Синтаксис

SELECT CASE <выражение выбора>
    CASE <список селекторов>
        [<операторы>]
    [CASE <список селекторов>
        [<операторы>]]
    [CASE ELSE
        [<операторы>]]
END SELECT

Выражение и селекторы

После SELECT CASE записывается выражение выбора типа INTEGER, LONG, DOUBLE, DECIMAL, STRING или BOOLEAN. Список селекторов задаёт варианты проверки, а операторы задают действия выбранной ветви. Значение каждого селектора должно допускать соответствующее сравнение с выражением выбора. Каждая ветвь CASE задаёт один или несколько селекторов через запятую. Точное значение проверяет равенство. Начало и конец диапазона TO задают включённые нижнюю и верхнюю границы; обратный диапазон не подходит ни одному значению. Оператор сравнения в форме IS задаёт одну из поддержанных проверок отношения выражения выбора к значению селектора. Числовые селекторы приводятся к типу выражения выбора; это может усечь дробную часть или вызвать переполнение.

Селектор внутри CASE может быть записан одной из следующих форм:

CASE <значение>
CASE <значение 1>, <значение 2>, <значение 3>
CASE <начало> TO <конец>
CASE IS <оператор сравнения> <значение>
  • CASE <значение> выбирает ветвь при точном совпадении с выражением выбора.
  • Список через запятую выбирает ветвь, если подошёл хотя бы один селектор из списка.
  • CASE <начало> TO <конец> задаёт включительный диапазон.
  • CASE IS задаёт сравнение с выбранным значением через =, <>, <, <=, > или >=.

Порядок выполнения

Выражение выбора вычисляется один раз. Ветви проверяются по порядку до первого совпадения. Выполняется только выбранный блок, после чего управление переходит ниже END SELECT.

Если совпадений нет, выполняется CASE ELSE, когда эта ветвь присутствует. Допускается только одна такая ветвь. Без неё программа продолжает работу после конструкции.

Точное совпадение поддержано для чисел, строк и BOOLEAN. Диапазоны и упорядоченные сравнения поддержаны для числовых и строковых значений. Каждая ветвь имеет собственную область видимости.

Диагностика

  • MB2015 — диапазон CASE ... TO используется с типом, для которого диапазоны не поддержаны.
  • MB2003 — селектор или сравнение несовместимы с типом выражения выбора.
  • MB2001 — имя, объявленное внутри ветви, используется после выхода из области видимости.
  • MB1006 — в конструкции SELECT CASE допускается только один блок CASE ELSE.

Пример

Восемь находится в указанном диапазоне:

DIM value AS INTEGER = 8
SELECT CASE value
    CASE 1, 5 TO 10, IS > 100
        PRINT "Подходит"
    CASE ELSE
        PRINT "Другой вариант"
END SELECT
