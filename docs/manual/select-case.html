Оператор SELECT CASE

SELECT CASE — управляющий оператор, который выполняет один из нескольких блоков операторов в зависимости от значения одного проверяемого выражения. Он удобен, когда программа должна выбрать ветвь по точному значению, диапазону или сравнению.

Назначение

Оператор SELECT CASE применяют там, где одна и та же величина сравнивается с несколькими вариантами. Выражение выбора вычисляется один раз, а затем Axiom просматривает ветви CASE сверху вниз.

Если ветвление строится не вокруг одного значения, а вокруг разных логических условий, обычно лучше использовать IF ... ELSEIF ... ELSE. Если же все варианты относятся к одному выражению, SELECT CASE делает программу короче и нагляднее.

Синтаксис

SELECT CASE <выражение выбора>
    CASE <список селекторов>
        [<операторы>]
    [CASE <список селекторов>
        [<операторы>]]
    [CASE ELSE
        [<операторы>]]
END SELECT

Части записи

  • <выражение выбора> — числовое, строковое или логическое выражение, значение которого сравнивается с селекторами в ветвях CASE.
  • <список селекторов> — один селектор или несколько селекторов через запятую.
  • <операторы> — инструкции, которые выполняются, если соответствующая ветвь выбрана.
  • CASE ELSE — необязательная ветвь для случая, когда ни один обычный CASE не подошёл.
  • END SELECT завершает блочную конструкцию.

Формы селекторов

Селектор внутри CASE может быть записан одной из следующих форм:

CASE <значение>
CASE <значение 1>, <значение 2>, <значение 3>
CASE <начало> TO <конец>
CASE IS <оператор сравнения> <значение>
  • CASE <значение> выбирает ветвь при точном совпадении с выражением выбора.
  • Список через запятую выбирает ветвь, если подошёл хотя бы один селектор из списка.
  • CASE <начало> TO <конец> задаёт включительный диапазон.
  • CASE IS задаёт сравнение с выбранным значением через =, <>, <, <=, > или >=.

Логика работы

Axiom вычисляет выражение после SELECT CASE и сравнивает его с ветвями CASE по порядку. Если выражение удовлетворяет одному из селекторов текущей ветви, выполняются операторы этой ветви.

После выполнения выбранного блока управление передаётся на оператор, следующий за END SELECT. Остальные ветви больше не проверяются.

Если ни одна ветвь CASE не подошла, выполняется CASE ELSE. Если CASE ELSE отсутствует, выполнение просто продолжается после END SELECT.

Замечания

  • Точные значения можно использовать для чисел, строк и BOOLEAN.
  • Диапазоны TO и упорядоченные сравнения через CASE IS поддержаны для числовых и строковых значений.
  • Для диапазона указывают нижнюю и верхнюю границы включительного интервала.
  • Если одно значение подходит нескольким ветвям, выполняется только первая подходящая ветвь.
  • Каждая ветвь CASE и CASE ELSE образует собственную блочную область видимости.
  • Блоки SELECT CASE можно вкладывать друг в друга, если это делает выбор понятнее.

Пример

В этом примере одно числовое значение сравнивается с точным значением, диапазоном и условием CASE IS. Значение 8 попадает в диапазон 5 TO 10, поэтому выполняется первая ветвь.

DIM value AS INTEGER = 8

SELECT CASE value
    CASE 1, 5 TO 10, IS > 100
        PRINT "matched"
    CASE ELSE
        PRINT "other"
END SELECT

Результат:

matched

Диагностика

  • MB2015 — диапазон CASE ... TO используется с типом, для которого диапазоны не поддержаны.
  • MB2003 — селектор или сравнение несовместимы с типом выражения выбора.
  • MB2001 — имя, объявленное внутри ветви, используется после выхода из области видимости.
