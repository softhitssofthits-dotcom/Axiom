Символы CHR, ASC, CHRW и ASCW

Функции CHR(), ASC(), CHRW() и ASCW() — встроенные функции языка Axiom, которые переводят числовые коды в строки и обратно. В диапазоне 0..255 Axiom использует таблицу IBM CP866, чтобы русские буквы, рамки и блочные символы из BASIC/DOS-программ имели устойчивые числовые коды. Пара CHRW() и ASCW() нужна для прямой работы с Unicode-кодами без этой совместимой подмены.

Синтаксис и аргументы

Четыре записи ниже относятся к разным встроенным функциям. Все функции работают со строковыми значениями в обоих движках, без экранного или файлового режима.

code = ASC(text)
unicodeCode = ASCW(text)
text = CHR(code)
text = CHRW(unicodeCode)

Аргумент text должен быть непустой строкой. ASC и ASCW возвращают INTEGER для первого символа; оставшаяся строка не участвует в результате. Целая пара UTF-16 считается одним символом: ASCW("😀Я") возвращает 128512. Если первая единица UTF-16 является изолированным суррогатом, обе функции возвращают код замещающего символа U+FFFD, то есть 65533; исходная строка при этом не изменяется.

Аргументы CHR и CHRW должны иметь тип INTEGER. Допустимы значения от 0 до 1114111, кроме диапазона суррогатов 55296..57343. Возвращаемое значение имеет тип STRING и содержит один символ Unicode; его длина LEN может равняться двум единицам UTF-16.

Обратное преобразование

Для допустимого символа Unicode используйте пару ASCW/CHRW: CHRW(ASCW("é")) возвращает "é". Пара ASC/CHR не обеспечивает такого преобразования для произвольного Unicode: ASC("é") возвращает 233, но CHR(233) берёт символ из CP866. Для каждого кода 0..255 выполняется ASC(CHR(code)) = code.

Диагностика

ASC("") и ASCW("") дают MB3007: в пустой строке нет первого символа. CHR и CHRW дают MB3007 для отрицательного кода, суррогатного кода и значения больше 1114111. Ошибку можно перехватить оператором TRY/CATCH. Неверный тип аргумента отклоняется при проверке типов до исполнения.

Пример Unicode и исторических кодов

' Один и тот же символ имеет разные коды в двух системах.
PRINT ASC("Я")     ' 159 в CP866
PRINT ASCW("Я")    ' 1071 в Unicode
' Unicode-преобразование сохраняет символ за пределами CP866.
PRINT CHRW(ASCW("é")) = "é"  ' TRUE
PRINT ASCW("😀Я")  ' 128512, код первого символа

Правила кодирования

  • CHR(code) для 0..255 возвращает символ из таблицы ASCII/IBM CP866.
  • CHR(code) для значений выше 255 возвращает символ по Unicode-коду, если такой код допустим.
  • ASC(text) для первого символа, представимого в ASCII/IBM CP866, возвращает его код из этой таблицы.
  • ASC(text) для первого символа вне ASCII/IBM CP866 возвращает Unicode-код.
  • CHRW(code) всегда трактует аргумент как Unicode-код, включая диапазон 0..255.
  • ASCW(text) всегда возвращает Unicode-код первого символа строки.
PRINT CHR(159)   ' Я
PRINT CHR(196)   ' ─
PRINT CHR(219)   ' █
PRINT ASC("Я")   ' 159
PRINT ASC("█")   ' 219
PRINT ASCW("Я")  ' 1071
PRINT CHRW(1071) ' Я

Коды 0..31 и 127 в исходной таблице имеют управляющие имена. В колонке «Символ» для них показан экранный знак из справочной таблицы; в обычной строковой обработке эти коды остаются управляющими символами.
