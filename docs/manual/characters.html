Символы и их коды

Раздел «Символы и их коды» объясняет связь функций ASC, ASCW, CHR и CHRW с Unicode и встроенной таблицей CP866.

Строка и код символа

Строка Axiom хранится как UTF-16. Функции ASC и ASCW читают первую кодовую точку Unicode, а не обязательно один элемент UTF-16. Например, символ вне основной многоязычной плоскости занимает два элемента UTF-16, но возвращает один код Unicode.

ASCW возвращает код Unicode; CHRW создаёт символ по такому коду. ASC возвращает код ASCII для значений ниже 128, код CP866 для символов, имеющихся в встроенной таблице, а для остальных — код Unicode. CHR для кодов 0–127 использует ASCII, 128–255 — таблицу CP866, выше 255 — Unicode.

CHR и CHRW допускают коды от 0 до 1114111, кроме суррогатного диапазона 55296–57343; недопустимый код вызывает MB3007. ASC и ASCW не принимают пустую строку: она также вызывает MB3007. Для Unicode-обмена используйте ASCW и CHRW, поскольку таблица CP866 меняет смысл кодов 128–255.

Пример разных кодов

PRINT ASC("А")
PRINT ASCW("А")
PRINT CHR(128)
PRINT CHRW(1040)
PRINT ASCW("😀")
PRINT LEN(CHRW(128512))

Ожидаемый вывод:

128
1040
А
А
128512
2
