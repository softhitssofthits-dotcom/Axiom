Циклы

Цикл — конструкция, которая повторяет блок инструкций. Раздел объединяет счётный цикл FOR, цикл с предварительным условием WHILE и формы DO … LOOP.

Повторение по счётчику

Когда известен диапазон повторений, используйте FOR. Цикл создаёт собственный счётчик, последовательно изменяет его и заканчивается на границе диапазона:

FOR index = 1 TO 3
    PRINT index
NEXT

Результат:

1
2
3

Счётчик доступен внутри цикла. Подробные правила шага, направления и границ собраны в статье FOR.

Повторение по условию

Оператор WHILE проверяет условие до выполнения тела. Формы DO … LOOP позволяют проверить условие в начале или конце. Проверка в конце означает, что тело выполняется хотя бы один раз.

Условие должно иметь тип BOOLEAN. Если значения, от которых оно зависит, не меняются, цикл может продолжаться бесконечно.

Выход и продолжение

Оператор EXIT завершает ближайший цикл указанного вида. Оператор CONTINUE пропускает остаток текущего прохода и переходит к следующему. У каждой формы есть собственный допустимый контекст; общего оператора выхода из любого цикла нет.
