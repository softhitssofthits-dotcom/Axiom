Циклы

Раздел циклов описывает операторы повторения блоков программы: FOR, WHILE и DO ... LOOP. Цикл FOR изменяет счётчик в заданном диапазоне; WHILE проверяет условие перед итерацией; DO ... LOOP допускает проверку перед итерацией, после неё или повторение без условия. Оператор CONTINUE пропускает оставшуюся часть текущей итерации.

Какая часть программы повторяется

Если число повторений выражается через счётчик, обычно подходит FOR ... NEXT. Если перед каждым проходом нужно сначала проверить условие, берут WHILE ... END WHILE. Если условие удобнее поставить в начале или в конце, либо нужен выход из середины тела, используют семейство DO ... LOOP.

  • FOR повторяет тело по диапазону значений счётчика;
  • WHILE проверяет условие до входа в тело и может не выполниться ни разу;
  • DO ... LOOP поддерживает формы с WHILE, UNTIL, постусловием и EXIT DO.

Выбор формы

Счётный цикл хорош там, где программа заранее знает границы. Предусловный цикл удобен для обработки состояния, которое может быть уже завершено перед первым проходом. DO ... LOOP нужен, когда тело должно выполниться хотя бы один раз или когда естественная точка выхода находится внутри тела.

DIM i AS INTEGER = 0

DO
    PRINT i
    i = i + 1

    IF i = 3 THEN
        EXIT DO
    END IF
LOOP

В этом примере условие выхода связано не с заголовком цикла, а с событием внутри тела. Поэтому DO ... LOOP читается естественнее, чем искусственная проверка в начале.

Условие завершения

Условие цикла должно быть логическим выражением. Если условие не меняется внутри тела, цикл может стать бесконечным; для таких случаев в Axiom у DO ... LOOP есть явный выход EXIT DO.

Для пропуска отдельных итераций без выхода из цикла в Axiom используется оператор CONTINUE в одной из трёх форм: CONTINUE FOR, CONTINUE WHILE или CONTINUE DO. Каждая форма работает только с соответствующим типом цикла.

Предусловный цикл записывается как WHILE ... END WHILE. Оператор EXIT DO обеспечивает прямой выход из цикла DO ... LOOP.
