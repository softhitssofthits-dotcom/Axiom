Сводка

FOR подходит для счётного повторения по диапазону, WHILE — для предусловного повторения по логическому условию, а DO ... LOOP — для случаев, где нужно выбирать между предусловием, постусловием и безусловной формой.

Навигация по циклам

FOR

Счетный цикл для случаев, когда диапазон и шаг известны заранее.

WHILE

Цикл с предусловием: тело выполняется, пока условие истинно.

DO ... LOOP

Гибкое семейство циклов с предусловием, постусловием и ручным выходом через EXIT DO.

Показательные примеры

  • FOR: базовый счётный цикл
  • WHILE: предусловный цикл
  • DO WHILE: предусловная форма
  • LOOP UNTIL: постусловная форма
