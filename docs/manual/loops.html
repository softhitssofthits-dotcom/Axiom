Обзор

Циклы

Циклы позволяют повторять один и тот же блок кода столько раз, сколько требует задача. В Axiom разные формы цикла нужны для разных сценариев: где-то заранее известен диапазон, где-то важно предусловие, а где-то удобнее постусловие или явный выход. Эта страница помогает быстро выбрать правильную форму перед переходом к точной справке.

Как выбирать цикл

На практике нужная форма определяется не внешним видом кода, а характером повторения. Поэтому обзорный раздел лучше читать не как список ключевых слов, а как карту типовых случаев.

  • FOR подходит, когда повторение связано со счётчиком, диапазоном и шагом; счётчик можно создать самой строкой FOR или заранее объявить через DIM;
  • WHILE удобно использовать, когда условие должно проверяться до входа в тело;
  • DO ... LOOP остаётся самой гибкой формой, когда нужно выбрать место проверки условия или использовать явный выход.

Сводка

FOR подходит для счётного повторения по диапазону, WHILE — для предусловного повторения по логическому условию, а DO ... LOOP — для случаев, где нужно выбирать между предусловием, постусловием и безусловной формой.

Коротко

Если вы заранее знаете, сколько раз должен выполниться блок, обычно начинайте с FOR. Если число повторений заранее неочевидно и зависит от логического состояния, чаще нужен WHILE или одна из форм DO ... LOOP.

Навигация по циклам

FOR

Счетный цикл для случаев, когда диапазон и шаг известны заранее.

WHILE

Цикл с предусловием: тело выполняется, пока условие истинно.

DO ... LOOP

Гибкое семейство циклов с предусловием, постусловием и ручным выходом через EXIT DO.

Короткий ориентир

FOR i = 1 TO 3
    PRINT "FOR:"; i
NEXT

DIM n AS INTEGER = 0
WHILE n < 2
    PRINT "WHILE:"; n
    n = n + 1
END WHILE

В первом случае язык повторяет блок по счётчику, во втором — пока остаётся истинным условие. Такой контраст обычно помогает сразу выбрать нужную страницу manual для дальнейшего чтения.

Показательные примеры

Для ручной проверки циклов в IDE полезно открывать по одному короткому сценарию на каждую форму повторения.

  • FOR: базовый счётный цикл
  • FOR: заранее объявленный счётчик
  • WHILE: предусловный цикл
  • DO WHILE: предусловная форма
  • LOOP UNTIL: постусловная форма
