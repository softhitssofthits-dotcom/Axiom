Функция INKEY

INKEY — встроенная функция языка Axiom, которая извлекает следующую клавишу из очереди ввода без ожидания. Если очередь пуста, результатом будет пустая строка.

Применение

Вызывайте функцию в интерактивном цикле, когда программе нужна очередная клавиша, а остальная работа должна продолжаться без ожидания Enter.

Контекст выполнения

Функция читает очередь активной поверхности ввода. В обычной текстовой программе это область ввода IDE, а после открытия SCREEN 0 или SCREEN 1..10 — экранное окно.

Источник клавиш определяется поверхностью, имеющей фокус; подробнее см. клавиатура, мышь и события.

Синтаксис

INKEY()

Единственная форма вызова — INKEY().

Аргументы

Аргументов нет; пустые скобки обязательны в записи вызова.

Что возвращает функция INKEY

Результат имеет тип STRING. Таблица показывает, как представляются обычная клавиша, специальная клавиша и отсутствие ввода.

СитуацияРезультат
В очереди есть обычная печатная клавиша.Возвращается её символ, например "A".
В очереди есть специальная клавиша.Возвращается каноническое имя, например "LEFT", "ESC" или "F1".
В очереди нет клавиши.Возвращается пустая строка "".

Правила работы

Функция не показывает приглашение и не читает целую строку. Для ввода строки или нескольких значений используйте оператор INPUT.

Обработчик ON KEY может получить событие раньше вызова функции. Уже обработанная клавиша удаляется из очереди и не возвращается последующим опросом.

Для проверки текущего удержания клавиши используйте KEYDOWN; чтение очереди сообщает события нажатия.

Отсутствие событий и общий ввод

INKEY возвращает STRING без ожидания: пустая очередь даёт пустую строку. Вызов извлекает только одно событие, сохраняя последующие события для следующих вызовов. Опрос не требует графической поверхности и не создаёт её. SLEEP без аргумента также извлекает клавишу из этой очереди.

Диагностика

  • MB2004: вызов встроенной функции INKEY получил один или несколько аргументов.

Пример

DIM pressedKey AS STRING

pressedKey = INKEY()
IF pressedKey = "" THEN
    PRINT "Клавиша пока не нажата"
ELSE
    PRINT "Нажата клавиша: "; pressedKey
END IF

Пример делает один опрос и печатает результат. Пустая очередь не приостанавливает программу.
