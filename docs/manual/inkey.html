Встроенная функция

Функция INKEY

INKEY — встроенная функция языка Axiom, которая читает одну клавишу из очереди клавиатуры и сразу возвращает управление программе. Если очередная клавиша отсутствует, встроенная функция INKEY возвращает пустую строку.

Для чего нужна функция INKEY

Встроенная функция INKEY нужна для неблокирующего опроса клавиатуры. Программа может вызывать эту функцию внутри игрового цикла, цикла ожидания или короткой интерактивной проверки и не останавливаться до тех пор, пока пользователь не нажмёт Enter.

Где работает функция INKEY

Встроенная функция INKEY читает активную клавиатурную очередь программы. Если программа работает без оператора SCREEN, ввод приходит из обычной поверхности ввода среды разработки. Если программа явно выбрала SCREEN 0 или графический режим SCREEN 1..10, ввод приходит из окна SCREEN.

Встроенная функция INKEY выполняется BytecodeVm после компиляции.

Синтаксис

INKEY()

Встроенная функция INKEY поддерживает только форму без аргументов.

Аргументы

У встроенной функции INKEY нет аргументов. Пустые скобки остаются частью вызова функции.

Что возвращает функция INKEY

Встроенная функция INKEY возвращает значение типа STRING.

СитуацияРезультат
В очереди есть обычная печатная клавиша.Возвращается её символ, например "A".
В очереди есть специальная клавиша.Возвращается каноническое имя, например "LEFT", "ESC" или "F1".
В очереди нет клавиши.Возвращается пустая строка "".

Правила работы

Встроенная функция INKEY не показывает приглашение, не ждёт подтверждения Enter и не читает строку целиком. Для обычного пользовательского ввода строки или нескольких значений используется оператор INPUT.

Если для клавиши зарегистрирован обработчик через оператор ON KEY, совпавшая клавиша может быть обработана раньше, чем программа дойдёт до вызова встроенной функции INKEY. В этом случае обработанная клавиша не возвращается функцией INKEY.

Встроенная функция INKEY не сообщает текущее удержание клавиш. Для проверки удержания используется встроенная функция KEYDOWN.

Пример

DIM pressedKey AS STRING

pressedKey = INKEY()
IF pressedKey = "" THEN
    PRINT "Клавиша пока не нажата"
ELSE
    PRINT "Нажата клавиша: "; pressedKey
END IF

В этом примере встроенная функция INKEY делает один неблокирующий опрос клавиатуры. Если клавиши нет, программа всё равно продолжает выполнение.

Ручная проверка

  • INKEY: опрос клавиатуры в цикле

Диагностика

  • MB2004: вызов встроенной функции INKEY получил один или несколько аргументов.
