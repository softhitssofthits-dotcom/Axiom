Клавиатура

Функция INKEY

INKEY() читает одну клавишу из очереди клавиатуры и сразу возвращает управление программе. Если клавиши пока нет, функция возвращает пустую строку, поэтому её удобно использовать в циклах опроса, а не в блокирующем пользовательском вводе.

Как INKEY читает очередь клавиатуры

INKEY() не показывает приглашение и не ждёт подтверждения Enter. Обычная печатная клавиша возвращается как символ, а специальная клавиша возвращается как строковое имя, например "LEFT" или "ESC".

Синтаксис

INKEY()

Возвращаемое значение

Тип результата: STRING.

  • Если в очереди есть обычная клавиша, возвращается её символ, например "A".
  • Если клавиши нет, возвращается пустая строка "".
  • Для специальных клавиш возвращаются имена вроде "LEFT", "RIGHT", "UP", "DOWN", "F1", "ESC", "ENTER", "BACKSPACE".

Ограничения опроса клавиатуры

  • INKEY() не принимает аргументы.
  • Имя функции записывается без суффикса $; алиасы для этой функции не поддерживаются.
  • Функция поддерживается и в интерпретаторе, и в режиме байткода.
  • Для специальных клавиш INKEY() возвращает канонические имена из общей таблицы имён клавиш; алиасы нужны при сравнении с пользовательским текстом в KEYDOWN() и ON KEY.
  • Если для клавиши зарегистрирован обработчик через ON KEY, совпавшая клавиша может быть перехвачена обработчиком раньше, чем до неё дойдёт вызов INKEY().
  • Если среда выполнения не предоставляет источник клавиатуры, функция не блокирует программу и возвращает "".
  • INKEY() не даёт состояния удержания клавиш, модификаторов и мышиных событий.

Пример чтения одной клавиши

DIM pressedKey AS STRING

pressedKey = INKEY()
IF pressedKey = "" THEN
    PRINT "NO KEY"
ELSE
    PRINT pressedKey
END IF

Ручная проверка

  • INKEY: опрос клавиатуры в цикле

Диагностика

Диагностика MB2004 возникает, если передать аргументы в INKEY().
