Открытие текстового файла в переменную FILE

Оператор OPEN

Открытие файла для чтения, записи или дописывания.

Ввод и вывод

Оператор OPEN

Сводка

Оператор OPEN открывает текстовый файл и связывает его с переменной типа FILE. В Axiom файл открывается не по историческому номеру, а сразу в именованную переменную.

Синтаксис

OPEN path FOR INPUT AS fileVariable
OPEN path FOR OUTPUT AS fileVariable
OPEN path FOR APPEND AS fileVariable

Части записи

path задаёт путь к файлу. fileVariable обозначает переменную типа FILE, с которой будет связан открытый файл.

Режим INPUT открывает существующий файл для чтения, OUTPUT создаёт новый файл или полностью перезаписывает существующий, а APPEND открывает файл для дописывания в конец.

Замечания

  • Переменная после AS должна иметь тип FILE.
  • Если в переменной уже есть открытый файл, повторный OPEN даёт ошибку времени выполнения.
  • После открытия файл используется вместе с EOF, READLINE, WRITE, WRITELINE и другими файловыми функциями.

Пример

DIM sourceFile AS FILE
DIM line AS STRING

OPEN "data.txt" FOR INPUT AS sourceFile

WHILE NOT EOF(sourceFile)
    line = READLINE(sourceFile)
    PRINT line
END WHILE

CLOSE sourceFile

Ручная проверка

  • OPEN: базовое открытие файла
  • EOF: чтение до конца файла
  • READLINE: построчное чтение
  • WRITE: запись без перевода строки
  • WRITELINE: запись строки

Диагностика

Ошибки возникают, если после AS указана переменная неверного типа, если файл невозможно открыть в выбранном режиме или если предпринимается повторное открытие уже занятой переменной FILE.
