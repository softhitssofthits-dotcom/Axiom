Ввод и вывод

Оператор OPEN

Оператор OPEN открывает текстовый файл и связывает его с переменной специального типа FILE. В Axiom не используются исторические файловые номера вида #1: файл открывается сразу в именованную переменную.

Главные правила

  • Переменная после AS должна иметь тип FILE.
  • Поддерживаются режимы INPUT, OUTPUT и APPEND.
  • INPUT открывает существующий текстовый файл для чтения.
  • OUTPUT создаёт новый файл или полностью перезаписывает существующий.
  • APPEND открывает файл для дописывания в конец и при отсутствии создаёт его.
  • Если в переменной уже есть открытый файл, повторный OPEN даёт ошибку времени выполнения.

Синтаксис

OPEN <путь> FOR INPUT AS <файл>
OPEN <путь> FOR OUTPUT AS <файл>
OPEN <путь> FOR APPEND AS <файл>

Примеры

DIM sourceFile AS FILE
DIM line AS STRING

OPEN "data.txt" FOR INPUT AS sourceFile

WHILE NOT EOF(sourceFile)
    line = READLINE(sourceFile)
    PRINT line
END WHILE

CLOSE sourceFile
DIM logFile AS FILE

OPEN "log.txt" FOR OUTPUT AS logFile
WRITELINE(logFile, "Первая строка")
CLOSE logFile
DIM logFile AS FILE

OPEN "log.txt" FOR APPEND AS logFile
WRITELINE(logFile, "Добавленная строка")
CLOSE logFile

Ручная проверка

  • OPEN: базовое открытие файла
  • EOF: чтение до конца файла
  • READLINE: построчное чтение
  • WRITE: запись без перевода строки
  • WRITELINE: запись строки
