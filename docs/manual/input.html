Оператор

Оператор INPUT

INPUT — оператор языка Axiom, который останавливает выполнение программы, ждёт строку от пользователя и присваивает введённые значения указанным переменным. Оператор используют в простых интерактивных программах, когда данные должны поступить во время выполнения, а не быть записаны в тексте программы заранее.

Как INPUT получает строку ввода

Оператор INPUT читает одну логическую строку ввода. Если в списке указана одна переменная, вся введённая строка преобразуется к типу этой переменной. Если переменных несколько, строка разбирается как список значений, разделённых запятыми.

Перед ожиданием ввода можно вывести строку приглашения. Если программа не выбирала экранный режим через SCREEN, ввод идёт через нижнюю область Output в IDE. Если активен SCREEN 0 или графический SCREEN, приглашение и ввод отображаются в окне SCREEN.

Синтаксис

INPUT <переменная>
INPUT <переменная1>, <переменная2>[, <переменнаяN>]
INPUT <приглашение> ; <переменная>
INPUT <приглашение> , <переменная>

Параметры и части синтаксиса

  • <приглашение> — строковая константа, которая выводится перед ожиданием ввода.
  • ; или , после приглашения отделяет текст приглашения от списка переменных. Точка с запятой добавляет к тексту приглашения знак вопроса и пробел; запятая выводит приглашение буквально без добавления символов. Разбор ответа и перенос после Enter одинаковы. Это правило относится к оператору INPUT; правила разделителей оператора PRINT описаны отдельно.
  • <переменная> — изменяемая переменная, в которую записывается введённое значение.
  • <переменная1>, <переменная2> — список переменных. Количество введённых значений должно совпадать с количеством переменных.

Как INPUT разбирает введённую строку

Когда выполнение доходит до INPUT, программа ждёт подтверждения строки ввода. После этого Axiom разбирает введённый текст и только затем записывает значения в переменные.

Для одной строковой переменной ввод не разбивается по запятым: вся строка становится значением переменной. Для нескольких переменных запятые разделяют поля ввода, а пробелы вокруг каждого поля отбрасываются.

Числовые значения разбираются в инвариантной записи с точкой как десятичным разделителем. Логическое значение должно быть записано как TRUE или FALSE без учёта регистра. Если преобразование невозможно, выполнение сообщает ошибку времени выполнения.

Если выполнение остановлено командой IDE во время ожидания оператора INPUT, программа завершается с результатом отмены. Отмена не подтверждает пустую строку, не записывает значения в переменные и не вызывает ошибку MB3003. Операторы после отменённого ввода не выполняются.

Приглашение

После подтверждения ответа клавишей Enter следующий запрос начинается на новой строке. Дополнительный оператор PRINT между двумя операторами INPUT не требуется. Запятая между переменными, например в INPUT name, age, имеет другое назначение: она задаёт список получателей, для которых нужно ввести значения через запятую.

DIM name AS STRING, age AS INTEGER
INPUT "Введите ваше имя: ", name
INPUT "Введите ваш возраст"; age

Если ввести имя Иван и возраст 47, во время второго запроса первая строка уже содержит завершённый ответ, а приглашение возраста находится на следующей строке:

Введите ваше имя: Иван
Введите ваш возраст? 47

Если приглашение не указано, программа показывает стандартное приглашение ? . После приглашения с точкой с запятой всегда добавляются ? , даже если текст уже заканчивается вопросом или двоеточием. После приглашения с запятой дополнительные символы не добавляются. Пробелы в тексте сохраняются. Пустая строка с запятой скрывает приглашение; пустая строка с точкой с запятой показывает ? .

DIM name AS STRING
INPUT "Введите имя"; name
PRINT name

Для строки приглашения "Введите имя" пользователь увидит приглашение вида Введите имя? .

Ввод нескольких значений

Если в операторе перечислено несколько переменных, пользователь должен ввести столько же значений через запятую.

DIM name AS STRING
DIM age AS INTEGER

INPUT name, age
PRINT name, age

Для этого примера можно ввести:

Ada, 42

Результат:

Ada 42

Ограничения целей ввода

  • INPUT записывает значения только в изменяемые переменные поддержанных скалярных типов.
  • Поддержанные типы ввода: INTEGER, LONG, DOUBLE, DECIMAL, STRING и BOOLEAN.
  • Массивное значение целиком не может быть целью INPUT; вводите значение в отдельную скалярную переменную или элемент после отдельной обработки.
  • Для нескольких переменных число полей ввода должно точно совпадать с числом целей.
  • В активном SCREEN нижняя вкладка Output не принимает ввод для текущего INPUT; видимая поверхность ввода — окно SCREEN.

После строки приглашения допускаются разделители ; и ,. Обе формы используют одинаковые правила отображения приглашения в среде исполнения программы.

Диагностика

  • MB3003 — число введённых значений не совпадает с числом переменных или введённый текст нельзя преобразовать к требуемому типу.

Пример ввода двух значений

В этом примере программа запрашивает имя и возраст, затем выводит полученные значения.

DIM name AS STRING
DIM age AS INTEGER

INPUT "Name"; name
INPUT "Age"; age

PRINT "Name:"; " "; name
PRINT "Age:", age

Если ввести Ada, затем 42, результат будет таким:

Name: Ada
Age: 42
