Оператор INPUT

Оператор INPUT читает одну логическую строку ввода и преобразует её к типу одной или нескольких целевых переменных. Глава описывает базовую форму, варианты со строкой приглашения и условия возникновения диагностики времени выполнения.

Главные правила

  • INPUT поддерживает чтение одной переменной, списка переменных и формы с текстом приглашения.
  • При вводе нескольких переменных строка разбирается как минимальный список значений, разделённых запятыми.
  • Количество введённых значений должно совпадать с количеством целевых переменных.
  • Для INTEGER, LONG, DOUBLE, DECIMAL и BOOLEAN ввод преобразуется из текста после минимальной нормализации пробелов.
  • Если преобразование невозможно или число значений не совпадает, возникает диагностика времени выполнения MB3003.

Ручная проверка

Для ручной проверки используйте файлы примеров, которые можно открыть в IDE и выполнить с разными вариантами ввода.

  • INPUT: одна переменная
  • INPUT: несколько переменных
  • INPUT: приглашение через ;
  • INPUT: приглашение через ,

Базовая форма INPUT

Dim name As String
INPUT name

В этом случае программа ожидает, что пользователь введёт одно значение, и затем записывает его в указанную переменную.

Ввод нескольких значений

Dim first As Integer
Dim second As Integer

INPUT first, second

Здесь пользователь должен ввести значения в одной строке, разделяя их запятыми. Количество введённых значений должно совпасть с количеством переменных.

Форма с приглашением

Перед списком переменных можно указать текст приглашения:

INPUT "Введите имя"; name
INPUT "Введите два числа", first, second

В текущей реализации обе формы, через ; и через ,, синтаксически поддерживаются, но не разводятся в две отдельные модели консольного форматирования.

Преобразование значений

После ввода данные преобразуются к типу целевой переменной.

  • для INTEGER, LONG, DOUBLE, DECIMAL и BOOLEAN значение читается из текста и преобразуется;
  • для STRING текст берётся как есть;
  • если переменных несколько, ввод разбирается как минимальный список значений, разделённых запятыми.

Когда возникает ошибка

Диагностика времени выполнения MB3003 появляется в двух типичных ситуациях:

  • число введённых значений не совпадает с числом переменных;
  • введённый текст нельзя преобразовать к требуемому типу.

Итого

INPUT позволяет считать одно или несколько пользовательских значений, при необходимости показать приглашение и затем преобразовать ввод к типу целевых переменных.
