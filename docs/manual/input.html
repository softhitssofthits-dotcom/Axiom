Оператор INPUT

Чтение одной или нескольких переменных из строки ввода.

Ввод и вывод

Оператор INPUT

Оператор INPUT связывает программу с пользовательским вводом. Он ожидает строку данных, разбирает её по правилам языка и пытается распределить полученные значения по указанным переменным в нужных типах.

Сводка

Оператор INPUT читает одну логическую строку ввода и преобразует её к типу одной или нескольких целевых переменных. При необходимости перед списком переменных можно вывести строку приглашения.

Синтаксис

INPUT [promptText{;|,}] variableList

Части записи

promptText обозначает строку приглашения, которая выводится перед ожиданием ввода.

variableList обозначает одну или несколько переменных, в которые будет записан введённый результат.

Замечания

INPUT особенно удобен для простых интерактивных сценариев, где программа последовательно запрашивает значения и сразу использует их в вычислениях или выводе.

  • При вводе нескольких переменных строка разбирается как минимальный список значений, разделённых запятыми.
  • Количество введённых значений должно совпадать с количеством целевых переменных.
  • Для STRING текст берётся как есть.
  • Для числовых и логических типов текст преобразуется к типу целевой переменной.
  • Обе формы приглашения, через ; и через ,, синтаксически поддерживаются.

Пример

' Программа запрашивает имя и возраст
DIM name AS STRING
DIM age AS INTEGER

INPUT "Введите имя"; name
INPUT "Введите возраст"; age

Ручная проверка

  • INPUT: одна переменная
  • INPUT: несколько переменных
  • INPUT: приглашение через ;
  • INPUT: приглашение через ,

Диагностика

Диагностика времени выполнения MB3003 возникает, если число введённых значений не совпадает с числом переменных или если введённый текст нельзя преобразовать к требуемому типу.
