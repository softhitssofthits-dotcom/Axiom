Оператор INPUT

INPUT — оператор языка Axiom, который ожидает подтверждённую строку пользовательского ввода и записывает полученные значения в объявленные переменные.

Строгая запись временных значений

Строгая временная запись допускает дробную часть секунд только после точки с одной–семью цифрами. Точка без цифр, восемь цифр долей, NUL и невозможный календарный день отклоняются. Для UTCDATETIME признак Z ставится после секунд или их дробной части: например, 2024-02-29T12:34:56.1234567Z; запись 2024-02-29T12:34:56.Z недопустима.

При неверном временном поле INPUT сообщает MB3003 и не меняет ни одного получателя. Одиночный ответ проверяется целиком; у нескольких получателей внешние пробелы каждого поля удаляются до разбора, как и для остальных типов.

Назначение и место ввода

Программа приостанавливается на время ожидания ответа. Без оператора SCREEN пользователь вводит ответ в консоли IDE. После включения SCREEN, включая текстовый режим SCREEN 0, оператор INPUT работает только в окне этого режима: приглашение и набираемый текст отображаются в окне, а консоль IDE их не дублирует и не принимает ответ. IDE не переводит фокус в свою консоль при таком запросе. После Enter программа продолжает работу, а прежний запрос в интерфейсе закрывается. Оператор CANVAS сам по себе не меняет консольное место ввода оператора INPUT.

Синтаксис

INPUT <переменная>

INPUT <переменная1>, <переменная2>[, <переменнаяN>]

INPUT <приглашение> ; <переменная>[, <переменнаяN>]

INPUT <приглашение> , <переменная>[, <переменнаяN>]

Переменные и приглашение

Получателями служат изменяемые скалярные переменные типов INTEGER, LONG, DOUBLE, DECIMAL, STRING и BOOLEAN. Передайте имена уже объявленных изменяемых переменных; поле записи и элемент массива в синтаксисе получателя не допускаются. Массив целиком не может быть получателем. Фиксированная строка принимает ответ с обычным дополнением или обрезкой до своей ширины.

Приглашение — строковый литерал перед списком переменных, задающий текст запроса. Переменную STRING, соединение строк или другое выражение вместо литерала передать нельзя. Разделитель ; добавляет к тексту ? , разделитель , выводит текст буквально. Это правило приглашения отличается от правил разделителей PRINT.

Вид приглашения

Без приглашения показывается ? . Точка с запятой добавляет вопрос и пробел даже к строке, которая уже заканчивается вопросом или двоеточием. Пробелы исходного текста сохраняются. Пустой литерал с запятой скрывает приглашение, а с точкой с запятой оставляет ? .

DIM name AS STRING
INPUT "Введите имя: ", name
PRINT "Здравствуйте, "; name

Разбор ответа

Для одной переменной типа STRING ответ сохраняется целиком, включая запятые. Для нескольких переменных запятые разделяют поля, а пробелы по краям полей отбрасываются. Число полей должно точно совпасть с числом получателей. Кавычки не экранируют запятые: каждая запятая в ответе считается разделителем. Этот разбор не является универсальным чтением CSV. Все поля преобразуются до записи получателей; если одно поле ошибочно, прежние значения всех переменных сохраняются.

Числа записываются с точкой как десятичным разделителем независимо от региональных настроек. INTEGER и LONG принимают целую десятичную запись со знаком; DOUBLE допускает десятичную дробь и показатель e или E, но результат должен быть конечным. DECIMAL принимает десятичную запись, включая разделитель групп запятую и знак после числа; показатель степени не поддержан. Разделитель групп запятую можно передать только единственному DECIMAL: при нескольких получателях каждая запятая сначала разделяет поля. Логический ответ — TRUE или FALSE, без учёта регистра. Временной ответ записывается в канонической форме: yyyy-MM-dd для DATE, HH:mm:ss для TIME и yyyy-MM-dd HH:mm:ss для DATETIME; для TIME и DATETIME допускается дробная часть секунд после точки. Региональные формы вроде 29.02.2024 и запись с разделителем T не принимаются: для ввода действует тот же строгий договор, что и для неявного преобразования строки, поэтому текст из другого источника сначала разбирают DATETIMEVALUE или DATEVALUE. Для единственного BOOLEAN пробелы вокруг ответа не удаляются и делают ответ недопустимым; для нескольких получателей края полей очищаются до разбора. Некорректный ответ вызывает ошибку выполнения, а не автоматический повтор приглашения. Если нужен повторный запрос, организуйте его в программе с обработкой ошибки.

Подтверждение и отмена

После Enter следующий запрос начинается на новой строке; дополнительный PRINT между запросами не требуется. Остановка программы во время ожидания отменяет ввод: значения не записываются, пустая строка не подтверждается и инструкции после ввода не выполняются. Такая отмена не является ошибкой MB3003.

Диагностика

  • MB2001 — имя получателя не объявлено.
  • MB2010 — получатель является константой.
  • MB3005 — получатель имеет неподдержанный тип, например массив, запись или файл.
  • MB3003 — число введённых значений не совпадает с числом переменных или введённый текст нельзя преобразовать к требуемому типу.

Пример нескольких значений

Введите Анна, 42 в ответ на один запрос:

DIM name AS STRING
DIM age AS INTEGER
INPUT name, age
PRINT name, age

Результат:

Анна 42

Запускаемые примеры

Откройте нужный файл в IDE и запустите его. Примеры с ошибкой предназначены для проверки сообщения компилятора или выполнения.

  • INPUT: одна переменная
  • INPUT: остановка во время ожидания
  • INPUT: несколько переменных
  • INPUT: сравнение запятой и точки с запятой
  • INPUT: приглашение через ;
  • INPUT: приглашение через ,
  • INPUT: ввод в окне SCREEN 0
  • INPUT: последовательные запросы и повтор после ошибки в SCREEN

Backspace в экранном окне

В нативном окне SCREEN одно нажатие Backspace удаляет последний целый текстовый элемент: обычную букву, символ с объединяемым знаком или emoji. Пара UTF-16 не разделяется, поэтому удаление emoji не оставляет повреждённый символ в результате строкового ввода. Пустая строка остаётся пустой.
