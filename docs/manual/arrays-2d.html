Табличная форма данных с двумя независимыми индексами.

Массивы

Двумерные массивы

Сводка

Двумерный массив хранит значения одного типа в виде таблицы. Для доступа к элементу используются два индекса: первый выбирает строку, второй — столбец.

Синтаксис

DIM arrayName(rowLowerBound TO rowUpperBound, columnLowerBound TO columnUpperBound) AS elementType
DIM arrayName(,) AS elementType
arrayName(rowIndex, columnIndex) = expression
variable = arrayName(rowIndex, columnIndex)

Части записи

  • arrayName — имя двумерного массива.
  • rowLowerBound TO rowUpperBound — включительный диапазон индексов по строкам.
  • columnLowerBound TO columnUpperBound — включительный диапазон индексов по столбцам.
  • elementType — тип всех элементов массива.
  • rowIndex и columnIndex — индексы строки и столбца для доступа к элементу.

Замечания

  • Оба измерения имеют включительные границы.
  • Первое измерение соответствует строкам, второе — столбцам.
  • Если массив объявлен как DIM board(1 TO 3, 1 TO 4) AS INTEGER, у него три строки и четыре столбца.
  • Двумерный массив можно объявить без выделения памяти, например DIM board(,) AS INTEGER, а затем задать границы через REDIM.
  • Для обращения к элементу необходимо указывать оба индекса, если только вы не работаете со срезом или представлением на отдельной странице.

Пример

' Программа заполняет несколько ячеек таблицы и печатает их
' Ожидаемый вывод:
' 20
' 99
DIM board(1 TO 2, 1 TO 3) AS INTEGER

board(1, 1) = 10
board(1, 2) = 20
board(2, 3) = 99

PRINT board(1, 2)
PRINT board(2, 3)

Ручная проверка

  • Двумерная таблица с изменением границ
  • ARRAYBOUNDS: форма двумерного массива
