Двумерные массивы

Двумерный массив — тип данных Axiom ранга 2, элементы которого выбираются парой индексов. Два измерения удобно понимать как строки и столбцы таблицы.

Назначение и контекст

Двумерный массив прямоугольный: у каждой строки один и тот же диапазон столбцов. ROW равно 1, COLUMN равно 2. LBOUND(board, ROW) получает нижнюю границу строк, UBOUND(board, COLUMN) — верхнюю границу столбцов.

Работа с массивом разрешена на верхнем уровне, в процедуре и в функции; SCREEN не требуется.

Синтаксис

DIM <имя массива>(<первая нижняя граница> TO <первая верхняя граница>, <вторая нижняя граница> TO <вторая верхняя граница>) AS <тип элемента>
DIM <имя массива>(,) AS <тип элемента>
<имя массива>(<первый индекс>, <второй индекс>) = <значение>

Части записи

Имя массива обозначает таблицу. Две пары границ задают независимые диапазоны первого и второго измерения. Первый и второй индексы являются числовыми выражениями; значение должно быть совместимо с типом элемента.

Границы задаются числовыми выражениями. INTEGER используется непосредственно; LONG должен помещаться в INTEGER; дробная часть DOUBLE и DECIMAL отбрасывается к нулю. Нижняя граница -2147483648 запрещена, потому что поисковые функции используют нижнюю границу минус 1 как признак отсутствия. Верхняя граница включается в массив. Обратный диапазон допустим только как каноническая пустая форма 1 TO 0 при DIM или REDIM.

Действие и ограничения

DIM с границами создаёт элементы со значениями по умолчанию. DIM с пустыми измерениями сохраняет тип и ранг без выделения элементов. Полное индексирование возвращает один элемент; частичное индексирование создаёт представление оставшихся измерений.

Диагностика

MB2003 означает несовместимый тип элемента или индекса, MB2004 — неверное число индексов. MB3002 возникает, когда индекс или диапазон при индексировании выходит за границы. MB3005 возникает при доступе к невыделенному массиву либо при недопустимой паре границ. MB3007 сообщает о запрещённой нижней границе -2147483648; выход числового значения за диапазон INTEGER даёт MB3008.

Пример

DIM board(-1 TO 0, 3 TO 4) AS INTEGER
board(-1, 3) = 7
board(0, 4) = 9
PRINT board(-1, 3)
PRINT board(0, 4)
PRINT ARRAYLENGTH(board)

Ожидаемый вывод:

7
9
4

Схема индексов

Подписанные координаты выбирают элемент внутри включительных границ. Пустая клетка хранит значение по умолчанию до первого присваивания.

          столбец 3   столбец 4
строка -1     [7]        [0]
строка  0     [0]        [9]
