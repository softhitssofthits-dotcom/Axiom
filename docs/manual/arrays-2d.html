Двумерные массивы

Как двумерный массив хранит таблицу

Двумерный массив хранит значения одного типа в виде таблицы. Для доступа к элементу используются два индекса: первый выбирает строку, второй — столбец.

Синтаксис

DIM <имя массива>(<нижняя строка> TO <верхняя строка>, <нижний столбец> TO <верхний столбец>) AS <тип элемента>
DIM <имя массива>(,) AS <тип элемента>
<имя массива>(<индекс строки>, <индекс столбца>) = <выражение>
<переменная> = <имя массива>(<индекс строки>, <индекс столбца>)

Части записи

  • <имя массива> — имя двумерного массива.
  • <нижняя строка> TO <верхняя строка> — включительный диапазон индексов по строкам.
  • <нижний столбец> TO <верхний столбец> — включительный диапазон индексов по столбцам.
  • <тип элемента> — тип всех элементов массива.
  • <индекс строки> и <индекс столбца> — индексы строки и столбца для доступа к элементу.
  • <выражение> — значение, которое записывается в выбранную ячейку.

Строки, столбцы и границы

  • Оба измерения имеют включительные границы.
  • Первое измерение соответствует строкам, второе — столбцам.
  • Если массив объявлен как DIM board(1 TO 3, 1 TO 4) AS INTEGER, у него три строки и четыре столбца.
  • Двумерный массив можно объявить без выделения памяти, например DIM board(,) AS INTEGER, а затем задать границы через REDIM.
  • Для обращения к элементу необходимо указывать оба индекса, если только вы не работаете со срезом или представлением на отдельной странице.

Пример записи и чтения ячеек таблицы

' Программа заполняет несколько ячеек таблицы и печатает их
' Ожидаемый вывод:
' 20
' 99
DIM board(1 TO 2, 1 TO 3) AS INTEGER

board(1, 1) = 10
board(1, 2) = 20
board(2, 3) = 99

PRINT board(1, 2)
PRINT board(2, 3)
