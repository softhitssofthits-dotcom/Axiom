Простые значения и литералы

Раздел простых значений помогает перейти от общего понятия типа к числам, логическим значениям, строкам и временным данным. Подробные договоры собраны в соответствующих главах.

Литерал

Литерал записывает значение непосредственно: 42, 1.5, TRUE, "Текст". Ключевые слова TRUE и FALSE задают два значения типа BOOLEAN. Логический тип не является целочисленным типом.
