Раздел

Скалярные типы и литералы

Раздел скалярных типов и литералов описывает значения, которые хранятся непосредственно: целые числа, вещественные числа, десятичные числа, логические значения TRUE / FALSE, а также дату, время суток и дату со временем.

Данные и их типы

Тип определяет, какие значения может хранить переменная или константа и какие операции разрешены над этим значением. Числовой тип участвует в арифметике, логический тип участвует в условиях и логических выражениях, а неподходящее сочетание типов останавливается диагностикой до выполнения программы или во время выполнения.

Скалярные типы не содержат других значений внутри себя. Массивы, записи TYPE, строки и файловые значения описаны на соседних страницах, потому что у них есть отдельные правила хранения и обращения.

Числовые типы данных

Числовые данные представляют числа. В Axiom они разделены на четыре типа: два целочисленных, один вещественный с плавающей точкой и один точный десятичный.

ТипЧто хранитДиапазонКогда использовать
INTEGER 32-битное знаковое целое число. от -2147483648 до 2147483647. Счётчики, индексы, небольшие целые значения, номера строк и столбцов.
LONG 64-битное знаковое целое число. от -9223372036854775808 до 9223372036854775807. Целые значения, которые могут выйти за диапазон INTEGER, например размер файла или длительность в миллисекундах.
DOUBLE 64-битное число с плавающей точкой. приблизительно от -1.7976931348623157E+308 до 1.7976931348623157E+308; минимальная положительная величина около 4.9406564584124654E-324. Дробные величины, результаты обычного деления, тригонометрия и большая часть математических функций.
DECIMAL Точное десятичное число. от -79228162514264337593543950335 до 79228162514264337593543950335; до 28-29 значащих десятичных цифр. Денежные и табличные расчёты, где важна десятичная точность и не подходит двоичная погрешность DOUBLE.

Диапазон относится к значениям типа, а не ко всем возможным формам записи литерала. Целый десятичный литерал без точки сначала выбирает INTEGER или LONG; если он не помещается в LONG, лексический анализ сообщает MB0004. Чтобы получить DECIMAL для дробного значения, укажите целевой тип явно в DIM. Короткая таблица тех же границ вынесена в приложение Диапазоны и ограничения типов.

DOUBLE хранит приближённые двоичные значения и не обязан точно представлять каждую десятичную дробь. DECIMAL хранит десятичные значения точнее, но его диапазон меньше, чем у DOUBLE.

Логический тип

BOOLEAN хранит только два значения: TRUE и FALSE. Такой тип используется в условиях IF, WHILE, DO ... LOOP, в результатах сравнений и во встроенных функциях, которые отвечают на вопрос «да или нет».

DIM ready AS BOOLEAN = TRUE

IF ready THEN
    PRINT "готово"
END IF

В QuickBASIC условие часто опиралось на числовую модель: ноль означал ложь, ненулевое значение — истину. В Axiom условие документируемых управляющих конструкций должно иметь тип BOOLEAN, поэтому числовое значение нужно явно сравнить, например count > 0.

Типы даты и времени

Типы DATE, TIME и DATETIME хранят значения календаря и часов: дату, время суток и дату вместе со временем. Эти типы являются скалярными, поэтому для них работает обычное объявление, присваивание, вывод и сравнение.

ТипЧто хранитКанонический строковый видДиапазон
DATE Календарную дату без времени суток. yyyy-MM-dd, например 2026-08-25. годы с 1 по 9999.
TIME Время суток без даты. HH:mm:ss, например 14:05:06. от 00:00:00 до 23:59:59.
DATETIME Дату и время суток вместе. yyyy-MM-dd HH:mm:ss, например 2026-08-25 14:05:06. годы с 1 по 9999.

Значения этих типов объявляются через AS, как любой другой скалярный тип:

DIM day AS DATE
DIM moment AS TIME
DIM stamp AS DATETIME

day = "2026-08-25"
moment = "14:05:06"
stamp = "2026-08-25 14:05:06"

Строковый литерал в каноническом формате неявно преобразуется в нужный тип при присваивании. Значения DATE, TIME и DATETIME сравниваются операторами =, <, >, <= и >=.

Функции, которые получают текущие значения, собирают дату из частей и выполняют календарную арифметику, описаны в разделе Функции даты и времени. Короткая таблица всех диапазонов находится в приложении Диапазоны и ограничения типов.

Литералы

Литерал — это значение, записанное прямо в тексте программы. По форме литерала Axiom выбирает исходный тип, если рядом нет явного объявления, которое задаёт другой допустимый тип.

ЗаписьТипПравило
10INTEGERЦелый десятичный литерал получает INTEGER, если помещается в его диапазон.
21474836479LONGЕсли целое число не помещается в INTEGER, но помещается в LONG, типом становится LONG.
1.5DOUBLEЛитерал с десятичной точкой получает DOUBLE.
TRUE, FALSEBOOLEANЛогические литералы не считаются числами.
&HFFINTEGER или LONGШестнадцатеричный литерал выбирает целочисленный тип по диапазону значения.

Ведущие нули в числовых литералах не допускаются: формы вроде 001 и 01.25 дают диагностическое сообщение MB0003. Отрицательное значение записывается через унарный минус перед литералом: -7, -1.5.

Научная нотация (1.5E10, 3.14e-2) в текущей версии не поддерживается. Большие и малые вещественные значения нужно записывать десятичной точкой полностью.

Литерал DECIMAL не имеет собственного суффикса. Чтобы получить значение типа DECIMAL, укажите целевой тип явно в DIM или CONST.

Шестнадцатеричные литералы не поддерживают суффикс & для явного выбора LONG. Тип определяется по диапазону значения: от &H0 до &H7FFFFFFF даёт INTEGER, от &H80000000 до &H7FFFFFFFFFFFFFFF даёт LONG. Значения выше &H7FFFFFFFFFFFFFFF сообщают MB0004.

Явное объявление и вывод типа

В объявлении DIM тип можно указать явно через AS или дать Axiom вывести тип из инициализатора. Явный тип полезен, когда важен именно договор переменной, а не только форма первого значения.

DIM count AS INTEGER = 10
DIM big AS LONG = 21474836479
DIM ratio AS DOUBLE = 1.5
DIM price AS DECIMAL = 10.50
DIM ready AS BOOLEAN = TRUE

Если тип не указан, DIM берёт его из инициализатора:

DIM total = 10
DIM fraction = 1.5
DIM flag = FALSE

Дробный литерал сам по себе выводится как DOUBLE. Чтобы получить DECIMAL, укажите целевой тип явно:

DIM amount AS DECIMAL = 10.50

Преобразования

Axiom допускает только ограниченный набор автоматических числовых преобразований. INTEGER может перейти в LONG, DOUBLE или DECIMAL; LONG может перейти в DOUBLE или DECIMAL. Обратные переходы не выполняются молча.

DOUBLE и DECIMAL не смешиваются автоматически в одном обычном арифметическом выражении. BOOLEAN также не превращается в число и не принимает число вместо TRUE или FALSE.

Пример объявления скалярных значений

DIM count AS INTEGER = 10
DIM big = 21474836479
DIM ratio = 1.5
DIM price AS DECIMAL = 10.50
DIM ready AS BOOLEAN = count > 0

PRINT count + 5
PRINT big + 1
PRINT ratio / 2
PRINT price / 2

IF ready THEN
    PRINT "YES"
END IF

Результат:

15
21474836480
0.75
5.25
YES

Отличия, важные при чтении старых BASIC-материалов

В QuickBASIC INTEGER был 16-битным целым типом с диапазоном от -32768 до 32767, LONG был 32-битным типом с диапазоном от -2147483648 до 2147483647, а для вещественных чисел отдельно использовался SINGLE. В Axiom INTEGER является 32-битным типом, LONG — 64-битным, а отдельного типа SINGLE в текущем договоре языка нет.

В QuickBASIC тип переменной мог задаваться суффиксом имени или операторами семейства DEF.... В Axiom тип записывается через AS или выводится из инициализатора в поддержанных формах; суффиксы имён не являются частью текущего синтаксиса.

Диагностика

  • MB0003 — некорректный числовой литерал, например запись с ведущими нулями.
  • MB0004 — числовой литерал выходит за диапазон поддерживаемого типа.
  • MB2003 — выражение или оператор применены к несовместимым типам.
  • MB2018 — константное числовое значение не помещается в явно указанный целевой тип.
  • MB3008 — арифметическое переполнение или неконечный результат DOUBLE во время выполнения.
