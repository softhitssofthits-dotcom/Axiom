02 · Переменные и значения

Логический тип BOOLEAN

Логический тип BOOLEAN содержит два значения: TRUE (истина) и FALSE (ложь). Значения этого типа служат результатами проверок и логических операций, а в условиях определяют выбор ветви или продолжение цикла.

Литералы и начальное значение

Литерал TRUE обозначает истину, литерал FALSE обозначает ложь. Оба имеют тип BOOLEAN, отдельный от чисел -1, 1 и 0 и от строк.

Без кавычек TRUE записывает логическое значение, а "TRUE" в кавычках записывает строковый литерал типа STRING. Хотя при выводе текст совпадает, типы этих значений различаются. Регистр букв в логических литералах не учитывается: true, True и TRUE задают одно значение.

Переменная BOOLEAN без инициализатора получает FALSE. Такое же начальное значение получают элементы массива логического типа. Логические значения могут храниться в переменных, константах, полях и массивах, передаваться в параметры и возвращаться из функций.

Объявление и получение значения

Обычная переменная объявляется через DIM. Тип можно указать явно или вывести из начального логического выражения. Константа объявляется через CONST с явным типом:

DIM <имя> AS BOOLEAN
DIM <имя> AS BOOLEAN = <логическое выражение>
DIM <имя> = <логическое выражение>
CONST <имя> AS BOOLEAN = <логическое выражение>

Имя обозначает объявленную переменную или константу. Начальное выражение должно иметь тип BOOLEAN: им может быть логический литерал, сравнение, логическая операция или вызов функции с логическим результатом. Инициализатор CONST вычисляется при выполнении объявления, поэтому может читать переменные или вызывать функции; его значение не обязательно известно при компиляции. После объявления константе нельзя присвоить новое значение. Передача константы параметру BYREF также запрещена и вызывает MB2010; подробнее в статье CONST.

DIM ready AS BOOLEAN
DIM allowed = 2 > 1
CONST enabled AS BOOLEAN = NOT FALSE
PRINT ready
PRINT allowed
PRINT enabled

Результат:

FALSE
TRUE
TRUE

Сравнения и условия

Сравнение возвращает результат типа BOOLEAN: например, count > 0 проверяет положительность числа, а name = "Ada" проверяет равенство строки заданному тексту. Два логических значения можно сравнить только на равенство = или неравенство <>. Сравнение порядка, например FALSE < TRUE, не поддерживается.

В IF, ELSEIF, WHILE, DO WHILE и DO UNTIL условие должно иметь тип BOOLEAN. Ни ненулевое число, ни строка "TRUE" условием не считаются. Число проверяют сравнением, например number <> 0. В SELECT CASE по логическому значению допустим выбор отдельных значений TRUE и FALSE; диапазон для логических значений не задаётся.

Логические операции

Логическое отрицание и бинарные операции имеют самостоятельные формы записи:

NOT <логическое выражение>
<левое условие> AND <правое условие>
<левое условие> OR <правое условие>
<левое условие> XOR <правое условие>
<левое условие> EQV <правое условие>
<левое условие> IMP <правое условие>

Операнды каждой формы должны иметь тип BOOLEAN; результат также имеет тип BOOLEAN. NOT меняет истину на ложь и ложь на истину. AND возвращает истину, если истинны оба операнда; для OR достаточно одного истинного операнда. XOR возвращает истину при разных значениях операндов, а EQV возвращает истину при одинаковых. IMP возвращает ложь только при истинном левом и ложном правом операнде.

Полное и условное вычисление

AND, OR, XOR, EQV и IMP вычисляют левый операнд, затем правый. Правый операнд вычисляется и тогда, когда результат уже известен по левому значению. Вызов функции справа может изменить данные, вывести текст или вызвать ошибку.

Для условного вычисления предназначены отдельные формы:

<левое условие> ANDALSO <правое условие>
<левое условие> ORELSE <правое условие>

Оба операнда и результат должны иметь тип BOOLEAN. ANDALSO даёт тот же логический результат, что AND, а ORELSE даёт тот же результат, что OR. Однако ANDALSO не вычисляет правый операнд, если слева получено FALSE, а ORELSE не вычисляет его, если слева получено TRUE. В остальных случаях правый операнд вычисляется.

PRINT FALSE ANDALSO (1 / 0 > 0)
PRINT TRUE ORELSE (1 / 0 > 0)

Результат:

FALSE
TRUE

Деление на ноль в этом примере не выполняется. Если заменить ANDALSO на AND или ORELSE на OR, деление выполнится и возникнет MB3001. Компилятор проверяет и пропускаемый правый операнд: неизвестное имя или неверный тип в нём вызывает ошибку.

Отличие от побитовых операций

Имена NOT, AND, OR, XOR, EQV и IMP также используются для побитовых операций над целыми числами. Вид операции определяется типами операндов. Для INTEGER и LONG результат имеет целочисленный тип, а не BOOLEAN. В одной бинарной операции нельзя смешивать логическое значение и число. Побитовые формы также не принимают дробные числа и строки.

PRINT NOT FALSE
PRINT NOT 0
PRINT 5 AND 3

Результат:

TRUE
-1
1

NOT 0 меняет все биты целого нуля и получает целое -1. Этот результат не означает, что логическое TRUE равно -1. Выражения TRUE = -1, FALSE = 0 и TRUE AND 1 отклоняются из-за несовместимых типов. Формы ANDALSO и ORELSE не имеют побитового варианта.

Разрядность, смешение INTEGER и LONG и сдвиги описаны в разделе операций.

Скобки и приоритет

Унарный NOT имеет больший приоритет, чем сравнения. Затем логические операции следуют в порядке AND/ANDALSO, XOR, OR/ORELSE, EQV, IMP. Операции одного уровня связываются слева направо. Например, a IMP b IMP c означает (a IMP b) IMP c.

Для отрицания целого сравнения заключайте его в скобки: NOT (number = 2). Запись NOT number = 2 сначала применяет побитовый NOT к числу, затем сравнивает результат с 2. Например, NOT 1 = 2 возвращает FALSE, а NOT (1 = 2) возвращает TRUE. Полная таблица приоритетов находится в разделе операций.

Текстовое представление и INPUT

PRINT выводит логические значения словами TRUE и FALSE. Операция & и вставка в интерполированную строку используют такое же текстовое представление. Это преобразование для вывода не меняет тип исходного значения. Операция + не соединяет строку с логическим значением.

INPUT для BOOLEAN принимает текст TRUE или FALSE без учёта регистра. Ответы 1, 0, -1, пустая строка и русские слова не принимаются. Для единственного получателя пробелы вокруг ответа делают его недопустимым; при нескольких получателях пробелы по краям каждого поля удаляются до разбора. Подробный договор находится в статье INPUT.

Преобразования в число и обратно

Автоматические присваивания между BOOLEAN и числовыми типами не поддерживаются. Функции CINT, CLNG, CDBL, CDEC и STR не принимают BOOLEAN. Встроенной функции CBOOL в текущем языке нет.

Для получения логического значения из числа явно запишите нужную проверку, например number <> 0. Для получения числа из логического значения выберите числовой результат в IF:

DIM flag AS BOOLEAN = TRUE
DIM number AS INTEGER = 0
IF flag THEN
    number = -1
END IF
PRINT number
PRINT number <> 0

Результат:

-1
TRUE

Программа сама задаёт число -1 для истинного значения флага. Вместо него допустимо присвоить 1 или другое число, поскольку язык не устанавливает числового кода истины.

Диагностика

  • MB2003: присваивание числа или строки переменной BOOLEAN, присваивание BOOLEAN числовой переменной, смешение логического и числового операндов, упорядоченное сравнение BOOLEAN или вызов числового преобразования с BOOLEAN.
  • MB2008: условие IF, WHILE или DO не имеет типа BOOLEAN.
  • MB2005: вызов отсутствующей функции, например CBOOL.
  • MB2001: использование необъявленного имени, в том числе в пропускаемом правом операнде ANDALSO или ORELSE.
  • MB3003: ответ INPUT не может быть разобран как BOOLEAN.
  • MB3001: вычисляемый операнд выполняет деление на ноль; AND и OR не защищают от такой ошибки.
