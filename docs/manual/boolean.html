02 · Переменные и значения

Логический тип BOOLEAN

BOOLEAN — тип данных языка Axiom, который хранит одно из двух логических значений: TRUE (истина) или FALSE (ложь). Он используется для результатов проверок, условий и логических операций.

Два значения BOOLEAN

Логическое значение обозначает результат проверки: истину или ложь. TRUE означает истину, FALSE — ложь. Оба значения имеют тип BOOLEAN. Они не являются числами -1, 1 или 0 и не являются строками.

Запись TRUE без кавычек является логическим литералом. Запись "TRUE" в кавычках является строковым литералом типа STRING. Одинаковый текст при выводе не делает эти значения одним типом. Регистр логических литералов не различается: true, True и TRUE задают одно значение.

Переменная BOOLEAN без инициализатора получает FALSE. Такое же начальное значение получают элементы массива логического типа. Логические значения могут храниться в переменных, константах, полях и массивах, передаваться в параметры и возвращаться из функций.

Объявление и получение значения

Обычная переменная объявляется через DIM. Тип можно указать явно или вывести из начального логического выражения. Константа объявляется через CONST с явным типом:

DIM <имя> AS BOOLEAN
DIM <имя> AS BOOLEAN = <логическое выражение>
DIM <имя> = <логическое выражение>
CONST <имя> AS BOOLEAN = <логическое выражение>

Имя обозначает объявленное значение. Логическое выражение должно иметь тип BOOLEAN, например литерал, сравнение, логическую операцию или вызов функции с логическим результатом. Инициализатор CONST вычисляется при выполнении объявления и может обращаться к переменным или вызывать функции. После объявления прямое присваивание константе запрещено; значение не обязано быть известным во время компиляции. В текущей реализации сохраняется общее ограничение проверки констант: передачу константы параметру BYREF компилятор допускает, и подпрограмма может изменить её через параметр. Это относится и к BOOLEAN; подробнее в статье CONST.

DIM ready AS BOOLEAN
DIM allowed = 2 > 1
CONST enabled AS BOOLEAN = NOT FALSE
PRINT ready
PRINT allowed
PRINT enabled

Результат:

FALSE
TRUE
TRUE

Сравнения и условия

Сравнение возвращает BOOLEAN. Например, count > 0 проверяет число, а name = "Ada" проверяет строку. Для двух логических значений разрешены только равенство = и неравенство <>. Упорядоченные сравнения FALSE < TRUE и аналогичные формы не поддерживаются.

Условия IF, ELSEIF, WHILE, DO WHILE и DO UNTIL требуют BOOLEAN. Число не считается истинным только потому, что оно не равно нулю. Строка "TRUE" также не является условием. Для проверки числа используйте сравнение, например number <> 0. В SELECT CASE с логическим значением можно выбирать отдельные значения TRUE и FALSE; числовой диапазон логических значений не задаётся.

Логические операции

Следующие формы применяются к логическим операндам. Каждая бинарная форма является отдельной операцией, а не частью одной общей конструкции.

NOT <логическое выражение>
<левое условие> AND <правое условие>
<левое условие> OR <правое условие>
<левое условие> XOR <правое условие>
<левое условие> EQV <правое условие>
<левое условие> IMP <правое условие>

Операнды каждой формы должны иметь тип BOOLEAN; результат также имеет тип BOOLEAN. NOT меняет истину на ложь и ложь на истину. AND возвращает истину, если истинны оба операнда; OR — если истинен хотя бы один. XOR возвращает истину, если значения различаются; EQV — если совпадают. IMP возвращает ложь только при истинном левом и ложном правом операнде.

Полное и условное вычисление

AND, OR, XOR, EQV и IMP вычисляют левый операнд, затем правый. Правый операнд вычисляется и тогда, когда результат уже известен по левому значению. Вызов функции справа может изменить данные, вывести текст или вызвать ошибку.

Для условного вычисления предназначены отдельные формы:

<левое условие> ANDALSO <правое условие>
<левое условие> ORELSE <правое условие>

Оба операнда и результат должны иметь тип BOOLEAN. По значению результата ANDALSO соответствует AND, а ORELSE соответствует OR. Различие состоит в вычислении: ANDALSO пропускает правую часть при FALSE слева; ORELSE пропускает правую часть при TRUE слева. В остальных случаях правая часть вычисляется.

PRINT FALSE ANDALSO (1 / 0 > 0)
PRINT TRUE ORELSE (1 / 0 > 0)

Результат:

FALSE
TRUE

Деление на ноль в этом примере не выполняется. Если заменить ANDALSO на AND или ORELSE на OR, деление выполнится и возникнет MB3001. Пропуск выполнения не отменяет проверку исходника: неизвестное имя или неверный тип в правом операнде всё равно вызывает ошибку компилятора.

Отличие от побитовых операций

Имена NOT, AND, OR, XOR, EQV и IMP также используются для побитовых операций над целыми числами. Вид операции определяется типами операндов. Для INTEGER и LONG результат является целым числом, а не BOOLEAN. В одной бинарной операции нельзя смешивать логическое значение и число; дробные числа и строки также не подходят для этих побитовых форм.

PRINT NOT FALSE
PRINT NOT 0
PRINT 5 AND 3

Результат:

TRUE
-1
1

NOT 0 меняет все биты целого нуля и получает целое -1. Этот результат не означает, что логическое TRUE равно -1. Выражения TRUE = -1, FALSE = 0 и TRUE AND 1 отклоняются из-за несовместимых типов. Формы ANDALSO и ORELSE не имеют побитового варианта.

Разрядность, смешение INTEGER и LONG и сдвиги описаны в разделе операций.

Скобки и приоритет

Унарный NOT имеет больший приоритет, чем сравнения. Затем логические операции следуют в порядке AND/ANDALSO, XOR, OR/ORELSE, EQV, IMP. Операции одного уровня связываются слева направо. Например, a IMP b IMP c означает (a IMP b) IMP c.

Для отрицания целого сравнения заключайте его в скобки: NOT (number = 2). Запись NOT number = 2 сначала применяет побитовый NOT к числу, затем сравнивает результат с 2. Например, NOT 1 = 2 возвращает FALSE, а NOT (1 = 2) — TRUE. Полная таблица приоритетов находится в разделе операций.

Текстовое представление и INPUT

PRINT выводит логические значения словами TRUE и FALSE. Операция & и вставка в интерполированную строку используют такое же текстовое представление. Это преобразование для вывода не меняет тип исходного значения. Операция + не соединяет строку с логическим значением.

INPUT для BOOLEAN принимает текст TRUE или FALSE без учёта регистра. Ответы 1, 0, -1, пустая строка и русские слова не принимаются. Для единственного получателя пробелы вокруг ответа делают его недопустимым; при нескольких получателях пробелы по краям каждого поля удаляются до разбора. Подробный договор находится в статье INPUT.

Преобразования в число и обратно

Автоматические присваивания между BOOLEAN и числовыми типами не поддерживаются. Функции CINT, CLNG, CDBL, CDEC и STR не принимают BOOLEAN. Встроенной функции CBOOL в текущем языке нет.

Для получения логического значения из числа явно запишите нужную проверку, например number <> 0. Для получения числа из логического значения выберите числовой результат в IF:

DIM flag AS BOOLEAN = TRUE
DIM number AS INTEGER = 0
IF flag THEN
    number = -1
END IF
PRINT number
PRINT number <> 0

Результат:

-1
TRUE

Число -1 в этом примере выбрано самой программой. Вместо него можно назначить 1 или другое число; язык не задаёт числового кода истинного значения.

Диагностика

  • MB2003 — присваивание числа или строки переменной BOOLEAN, присваивание BOOLEAN числовой переменной, смешение логического и числового операндов, упорядоченное сравнение BOOLEAN или вызов числового преобразования с BOOLEAN.
  • MB2008 — условие IF, WHILE или DO не имеет тип BOOLEAN.
  • MB2005 — вызов отсутствующей функции, например CBOOL.
  • MB2001 — использование необъявленного имени, в том числе в пропускаемом правом операнде ANDALSO или ORELSE.
  • MB3003 — ответ INPUT не может быть разобран как BOOLEAN.
  • MB3001 — вычисляемый операнд выполняет деление на ноль; AND и OR не защищают от такой ошибки.
