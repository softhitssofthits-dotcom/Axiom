Функция MOUSEBUTTON

MOUSEBUTTON — встроенная функция языка Axiom, которая проверяет текущее удержание кнопки мыши. Она читает состояние и сохраняет очередь событий.

Применение

Используйте её для действия, продолжающегося всё время удержания. Нажатая кнопка даёт TRUE, отпущенная — FALSE.

Контекст выполнения

Чтение доступно при графическом SCREEN 1..10 или активном CANVAS. Без рисуемой поверхности возникает MB3010.

Чтобы заметить отдельное нажатие один раз, используйте MOUSEPRESS.

Синтаксис

MOUSEBUTTON(<номер кнопки>)

Аргументы

АргументТипОписание
<номер кнопки>INTEGERНомер кнопки мыши: 1 — левая, 2 — правая, 3 — средняя.

Что возвращает функция MOUSEBUTTON

Результат проверки имеет тип BOOLEAN.

  • TRUE, если указанная кнопка сейчас удерживается.
  • FALSE, если кнопка не удерживается или передан неподдерживаемый номер кнопки.

Правила работы

  • Встроенная функция MOUSEBUTTON не сообщает нажатие как событие и не различает момент нажатия и удержание.
  • События нажатия доступны через MOUSEPRESS, а события отпускания, перемещения и колеса — через ON MOUSE.
  • Координаты мыши читаются через встроенные функции MOUSEX и MOUSEY.
  • Для одноразовой проверки события нажатия кнопки используется встроенная функция MOUSEPRESS.

Аргумент функции

Передайте INTEGER с номером кнопки: 1 — левая, 2 — правая, 3 — средняя. Результат имеет тип BOOLEAN. Чтение удержания не извлекает события нажатия, отпускания, перемещения или колеса. Неподдерживаемый номер возвращает FALSE в действующей среде ввода.

Диагностика

  • MB2004: в встроенную функцию MOUSEBUTTON аргумент не передан.
  • MB2003: в встроенную функцию MOUSEBUTTON передан аргумент неподходящего типа.
  • MB3010: встроенная функция MOUSEBUTTON вызвана без активного графического режима SCREEN и без активного CANVAS.

Пример проверки левой кнопки

IF MOUSEBUTTON(1) THEN
    PRINT "LEFT"
END IF

Запускаемые примеры
