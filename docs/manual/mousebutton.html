Функция MOUSEBUTTON

Проверка удержания кнопки мыши по номеру.

Ввод и вывод

Функция MOUSEBUTTON

MOUSEBUTTON(buttonNumber) возвращает текущее состояние указанной кнопки мыши. Эта функция, как и клавиатурная KEYDOWN(), смотрит только на текущее состояние и не расходует никаких событий.

Синтаксис

MOUSEBUTTON(buttonNumber)

Аргументы

  • buttonNumber — номер кнопки мыши типа INTEGER.

Возвращаемое значение

Тип результата: BOOLEAN.

  • 1 — левая кнопка;
  • 2 — правая кнопка;
  • 3 — средняя кнопка;
  • для неподдерживаемого номера функция возвращает FALSE.

Замечания

  • MOUSEBUTTON() не сообщает нажатие как событие и не различает момент нажатия и удержание;
  • в текущем срезе нет отдельной очереди кликов, колеса мыши и захвата указателя;
  • координаты мыши читаются через MOUSEX() и MOUSEY().

Пример

IF MOUSEBUTTON(1) THEN
    PRINT "LEFT"
END IF

Ручная проверка

  • MOUSEBUTTON: состояние кнопок мыши

Диагностика

Диагностика MB2004 возникает, если аргумент не передан, а MB2003 — если передан аргумент неподходящего типа.
