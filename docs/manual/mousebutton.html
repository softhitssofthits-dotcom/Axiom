Функция MOUSEBUTTON

MOUSEBUTTON — встроенная функция языка Axiom, которая возвращает текущее состояние указанной кнопки мыши. В отличие от MOUSEPRESS, встроенная функция MOUSEBUTTON смотрит только на текущее удержание и не расходует никаких событий, как клавиатурная KEYDOWN.

Для чего нужна функция MOUSEBUTTON

Встроенная функция MOUSEBUTTON нужна для проверки текущего удержания кнопки мыши. Функция возвращает логическое значение: TRUE, если указанная кнопка сейчас нажата, и FALSE в остальных случаях.

Где работает функция MOUSEBUTTON

Встроенная функция MOUSEBUTTON работает при активном графическом режиме SCREEN 1..10 или при активном CANVAS. Без активной рисуемой поверхности выполнение сообщает диагностику MB3010.

Встроенная функция MOUSEBUTTON выполняется BytecodeVm после компиляции.

Синтаксис

MOUSEBUTTON(buttonNumber)

Аргументы

АргументТипОписание
buttonNumberINTEGERНомер кнопки мыши: 1 — левая, 2 — правая, 3 — средняя.

Что возвращает функция MOUSEBUTTON

Тип результата: BOOLEAN.

  • TRUE, если указанная кнопка сейчас удерживается.
  • FALSE, если кнопка не удерживается или передан неподдерживаемый номер кнопки.

Правила работы

  • Встроенная функция MOUSEBUTTON не сообщает нажатие как событие и не различает момент нажатия и удержание.
  • В текущем срезе нет отдельной очереди кликов, колеса мыши и захвата указателя.
  • Координаты мыши читаются через встроенные функции MOUSEX и MOUSEY.
  • Для одноразовой проверки события нажатия кнопки используется встроенная функция MOUSEPRESS.

Пример проверки левой кнопки

IF MOUSEBUTTON(1) THEN
    PRINT "LEFT"
END IF

Ручная проверка

  • MOUSEBUTTON: состояние кнопок мыши

Диагностика

  • MB2004: в встроенную функцию MOUSEBUTTON аргумент не передан.
  • MB2003: в встроенную функцию MOUSEBUTTON передан аргумент неподходящего типа.
  • MB3010: встроенная функция MOUSEBUTTON вызвана без активного графического режима SCREEN и без активного CANVAS.
