Оператор CLOSE

Оператор CLOSE завершает работу с ранее открытым текстовым файлом. После этого переменная типа FILE считается закрытой и не может использоваться в EOF, READLINE, WRITE и WRITELINE, пока файл снова не будет открыт через OPEN.

Главные правила

  • CLOSE принимает переменную типа FILE.
  • Закрывать можно только действительно открытый файл.
  • После CLOSE переменная возвращается в закрытое состояние.
  • Повторный CLOSE для уже закрытой переменной даёт ошибку времени выполнения.

Синтаксис

CLOSE <файл>

Пример

DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
WRITELINE(f, "Первая строка")
CLOSE f

Ручная проверка

  • CLOSE: закрытие файла
  • OPEN: базовое открытие файла
