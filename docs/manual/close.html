Оператор CLOSE

CLOSE — оператор языка Axiom, который закрывает открытый текстовый файл, завершает накопленную запись и освобождает ресурс FILE. Закрытую переменную можно снова использовать в OPEN.

Назначение и контекст

CLOSE завершает текущий период работы с файлом. Он доступен в любом выполняемом участке программы без SCREEN и применяется к ресурсу, ранее открытому оператором OPEN.

Синтаксис

CLOSE <файл>

Аргумент

Файл — простая переменная типа FILE, содержащая открытый ресурс. Выражение пути, поле записи и список нескольких файлов не являются этой формой.

Действие и ограничения

Накопленные байты передаются в поток, затем ресурс освобождается. После успешного закрытия ISOPEN возвращает FALSE; остальные файловые функции, требующие открытого ресурса, недоступны до нового OPEN. Повторное закрытие недопустимо.

Даже при ошибке завершения записи ресурс освобождается. Часть текста могла не сохраниться; повторять CLOSE для этого ресурса не нужно. При завершении запуска исполнитель пытается закрыть все оставшиеся ресурсы. Отказ одного закрытия не отменяет другие попытки.

Диагностика

MB2003 означает переменную другого типа. MB3007 возникает при закрытии неоткрытого ресурса и при ошибке завершения записи; такую ошибку можно перехватить через TRY.

Пример

DIM path AS STRING = MAKETEMPFILE("manual_")
DIM f AS FILE
OPEN path FOR OUTPUT AS f
WRITE(f, "Axiom")
PRINT ISOPEN(f)
CLOSE f
PRINT ISOPEN(f)
PRINT READFILE(path)
DELETEFILE(path)

Ожидаемый вывод:

TRUE
FALSE
Axiom
