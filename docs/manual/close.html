Оператор

Оператор CLOSE

CLOSE — оператор языка Axiom, который завершает работу с переменной типа FILE и освобождает связанный с ней файловый ресурс.

Как CLOSE завершает работу с файлом

Оператор CLOSE завершает работу с ранее открытым текстовым файлом. После этого переменная типа FILE снова считается закрытой и не может использоваться в файловых операциях, пока файл не будет открыт заново.

Синтаксис

CLOSE fileVariable

Части записи

fileVariable обозначает переменную типа FILE, которая уже содержит открытый файл.

Закрытое и открытое состояние

  • Закрывать можно только действительно открытый файл.
  • Оператор CLOSE пытается записать накопленный буфер и затем освобождает файловый ресурс. Даже если завершение записи даёт ошибку, ISOPEN(fileVariable) возвращает FALSE; повторять CLOSE для этого ресурса не нужно.
  • Повторный CLOSE для уже закрытой переменной даёт ошибку времени выполнения.

Пример записи и закрытия файла

DIM f AS FILE

OPEN "notes.txt" FOR OUTPUT AS f
WRITELINE(f, "Первая строка")
CLOSE f

Ручная проверка

  • CLOSE: закрытие файла
  • Состояние ресурсов после завершения записи
  • OPEN: базовое открытие файла

Диагностика

Закрытый файл даёт диагностику MB3007. Ошибка записи при завершении буфера также даёт MB3007; её можно обработать через TRY/CATCH. Файл после такого отказа закрыт, но сохранение всего текста не гарантируется: часть данных могла быть записана до ошибки.

При завершении программы оставшиеся открытые файлы закрываются автоматически. Ошибка одного файла не мешает попытке закрыть остальные; каждый отказ отражается диагностикой MB3007 и делает результат выполнения неуспешным.
