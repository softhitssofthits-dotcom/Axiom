Оператор ERASE

ERASE — оператор языка Axiom, который освобождает хранилище массива и переводит его в невыделенное состояние.

Контекст

Оператор работает с изменяемой переменной массива или доступным полем массива. Экранный и файловый режимы не требуются.

Синтаксис

ERASE <массив>

Параметр

<массив> — значение массива, хранилище которого освобождается.

Правила работы

Имя, тип элементов и ранг массива сохраняются. До следующего REDIM обращаться к элементам нельзя. Функция ARRAYISALLOCATED возвращает FALSE. Оператор не допускается для фиксированного поля массива внутри записи TYPE.

Диагностика

  • MB2011 — цель не является массивом.
  • MB2010 — цель объявлена неизменяемой.
  • MB2025 — цель является фиксированным полем массива в записи TYPE.
  • MB3005 — программа обращается к элементам после освобождения хранилища.

Пример

DIM values() AS INTEGER
REDIM values(1 TO 2)
PRINT ARRAYISALLOCATED(values)
ERASE values
PRINT ARRAYISALLOCATED(values)

Результат:

TRUE
FALSE

Запускаемый пример: освобождение массива.
