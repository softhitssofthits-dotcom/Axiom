Раздел

Одномерные массивы наглядно

Раздел одномерных массивов наглядно показывает, как представить массив глазами и как читать его индексы — визуальная схема для понимания индексации.

Линия ячеек и индексы

Одномерный массив удобно представлять как одну линию ячеек. У массива есть имя, а у каждой ячейки есть свой индекс. Когда программа обращается к элементу массива, она указывает имя массива и номер той ячейки, которую нужно прочитать или изменить.

Схема хранения

DIM scores(1 TO 5) AS INTEGER
индекс:   1    2    3    4    5
        [ ]  [ ]  [ ]  [ ]  [ ]

Здесь scores — имя массива, а диапазон 1 TO 5 задаёт допустимые индексы. В каждой ячейке хранится одно значение типа INTEGER.

Обращение к элементу

scores(3) = 99
PRINT scores(3)

Запись scores(3) означает: «элемент массива scores с индексом 3».

индекс:   1    2    3    4    5
        [ ]  [ ] [99] [ ]  [ ]

Границы не обязаны начинаться с 1

DIM temperatures(-2 TO 2) AS DOUBLE
индекс:  -2   -1    0    1    2
        [ ]  [ ]  [ ]  [ ]  [ ]

В Axiom границы массива включаются в диапазон. Поэтому массив может начинаться не только с 1, но и с 0, отрицательного числа или другого значения, которое подходит задаче.

Применение одномерных массивов

Такой массив хорошо подходит для последовательностей, где элементы идут в один ряд: список имён, цены товаров, результаты вычислений, строки файла, оценки ученика, значения датчиков и похожие данные.
