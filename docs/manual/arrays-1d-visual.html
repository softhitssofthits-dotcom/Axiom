Одномерные массивы наглядно

Одномерный массив удобно представлять как одну линию ячеек. У каждой ячейки есть индекс, а у всего массива есть имя.

Самая простая картинка

DIM scores(1 TO 5) AS INTEGER

индекс:   1    2    3    4    5
         [ ]  [ ]  [ ]  [ ]  [ ]

Здесь scores — это имя массива, а числа 1 TO 5 задают диапазон доступных индексов. Внутри каждой ячейки лежит одно значение типа INTEGER.

Как читать запись

scores(3) = 99
PRINT scores(3)

Запись scores(3) читается как «элемент массива scores с индексом 3».

индекс:   1    2    3    4    5
         [ ]  [ ] [99] [ ]  [ ]

Что важно помнить

  • одномерный массив — это одна линия значений;
  • индекс указывает, в какую именно ячейку мы смотрим;
  • нижняя граница не обязана быть равна 1.
DIM temperatures(-2 TO 2) AS DOUBLE
индекс:  -2   -1    0    1    2
         [ ]  [ ]  [ ]  [ ]  [ ]

Когда это полезно

Одномерный массив хорош, когда данные идут в один ряд: список имён, оценки ученика, цены товаров, строки файла, результаты вычислений.
